# 1. ジェネラティブアートとは？

---

ジェネラティブアート（Generative Art / 生成的芸術）とは、アーティストが作品の最終的な形態を**直接**描画・設計するのではなく、作品を生成するための「ルール」**や**「プロセス（アルゴリズム）」そのものを設計し、そのシステムを実行することで生み出されるアートのこと。

## 1-1. ジェネラティブアートを構成する要素

p5.jsを使ったジェネラティブアートは、主に以下の3つの要素で構成される。

1. **アルゴリズム (Algorithm) - 「ルール」**
    - 「何を」「どこに」「どのように」描画するかを定めた、厳密なルールの集まり。
    - これまでの授業で学んだ「`for`文で図形を並べる」「`if`文で条件分岐する」といった処理が、最も基本的なアルゴリズムにあたる。
2. **偶発性 (Randomness) - 「ゆらぎ」**
    - アルゴリズムに組み込まれる、ランダムな要素のこと。
    - p5.jsの`random()`関数や`noise()`関数がこれにあたる。
    - この偶発性が加わることで、ルールは同じでも、実行するたびに異なる、作者自身も予期しなかったような独自のパターンが生まれる。
3. **自律性 (Autonomy) - 「自動実行」**
    - 設計されたアルゴリズムと偶発性に基づき、コンピュータが自動的に描画処理を実行すること。
    - p5.jsの`draw()`関数が毎フレーム自動で実行され続ける仕組み（ループ）は、まさにこの自律性を実現するためのものである。

<aside>
💡

p5.jsでジェネラティブアートを作成するとは、「`draw()`ループ（自律性）の中で、`for`文などの（アルゴリズム）と`random()`（偶発性）を組み合わせ、複雑で美しいパターンを自動生成させること」

# 2. ランダム

---

`random()`関数は、指定した範囲内でランダムな数値（小数）を返す。`floor()`は小数を切り捨てて整数にする。

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
  background(0);
}

function draw() {
  // background(0)

  // 0から幅/高さまでのランダムな座標
  let x = random(0, width); 
  let y = random(0, height);
  // 0から360までのランダムな色相
  let h = random(0, 360); 
  // 10から50までのランダムなサイズ
  let size = random(10, 50); 

  // HSLの透明度(Alpha)は 0〜1 の小数を指定
  fill(h, 80, 70, 0.3); // 透明度30%
  rect(x, y, size, size);
}
```

## ☆ 練習

1. 色相を固定し、彩度や明度をランダムにしてみる。
2. クリックしたら、色相の色をランダムに変える。

```jsx
let color = 300;

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
}

function draw() {
  let x = random(0, width);
  let y = random(0, height);
  let h = random(0, 360);
  let s = random(0, 100);
  let wid = random(10, 100);
  let hei = random(10, 100);

  fill(color, 100, s, 0.3);
  rect(x, y, wid, hei);
}

function mouseReleased() {
  color = random(0, 360);
}

function keyReleased() {
  if (key === 's') {
    saveCanvas('mySketch', 'png');
  }
}
```

# 3. 座標変換（translate, rotate, scale）

---

キャンバス全体の座標系を変化させる。

| メソッド名 | 説明 |
| --- | --- |
| translate() | 移動 |
| rotate() | 回転 |
| scale() | 拡大縮小 |

座標変換は、これらの影響を他の図形に及ぼさないために、`push()`（現在の座標系を保存）と`pop()`（座標系を元に戻す）で処理を挟むのが基本。

- **`push()`:** `translate()`などで座標系を変更する**前**に呼び出す。現在の座標系の状態（位置、回転、スケールなど）を**保存**する。
- **`pop()`:** `push()`で保存した座標系の状態に**戻す**。

**【ランダムな矩形のコードに、座標変換を適用】**

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL); // HSLモード
  rectMode(CENTER); // 矩形の基準点を中心に
  
  // ★ 角度の単位を「度」（0〜360）に変更（デフォルトはラジアン）
  angleMode(DEGREES); 
  
  noStroke();
  background(0);
}

function draw() {
  // background(0)

  // --- ランダムな値を設定 ---
  let x = random(width);    // 0から幅までのランダムなX座標
  let y = random(height);   // 0から高さまでのランダムなY座標
  let h = random(360);    // 0から360までのランダムな色相
  let size = random(10, 50); // 10から50までのランダムなサイズ
  let r = random(360);    // 0から360までのランダムな回転角度
  let s = random(0.5, 2.0); // 0.5倍から2.0倍までのランダムなスケール

  // --- 座標変換と描画 ---
  push(); // 1. 現在の座標系（デフォルト状態）を保存

  // 2. 座標系の原点を(x, y)に「移動」
  translate(x, y);
  
  // 3. 移動した原点を中心に「回転」
  rotate(r);
  
  // 4. 移動・回転した原点を中心に「拡大縮小」
  scale(s);

  // 5. 色を設定
  fill(h, 80, 70, 0.3); // 透明度30%
  
  // 6. 新しい原点(0, 0)に矩形を描画
  rect(0, 0, size, size);

  pop(); // 7. 座標系を push() した時点の状態に戻す
         // (これにより、次のループの translate(x, y) が正しく動作する)
}
```

## ☆ 練習

1. 図形の種類や色、その他の値を変更して自分好みの作品に改造する。

# 4. グリッド（並べる）

---

ジェネラティブアートの基本は「繰り返し」である。`for`ループを使って、キャンバス全体に図形を規則正しく並べることから始める。

## 4-1. 繰り返しの入れ子によるグリッド

`for`ループを2重に（入れ子に）することで、縦横のグリッド（格子）パターンを作成できる。

```jsx
// 描画する円の直径
const diameter = 20;

function setup() {
  createCanvas(640, 480);
  colorMode(HSL); // HSLモード
  rectMode(CENTER); // 矩形は中心座標指定
  noStroke(); // 線なし
  background(0); // 背景を黒に
  fill(180, 50, 50); // HSLで水色

  // 縦方向の繰り返し (y座標)
  for (let y = 0; y < height; y += diameter) {
    // 横方向の繰り返し (x座標)
    for (let x = 0; x < width; x += diameter) {
      // 円の中心が(x + 直径/2, y + 直径/2)になるよう描画
      ellipse(x + diameter / 2, y + diameter / 2, diameter, diameter);
    }
  }
}

function draw() {
  // setup()で描画が完結するため、draw()は空
}
```

## 4-2. 偶発性（ランダム）の追加

規則的なグリッドに`random()`関数で「偶発性」を加える。これがジェネラティブアートの第一歩である。

```jsx
const diameter = 20;

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
  background(0);

  for (let y = 0; y < height; y += diameter) {
    for (let x = 0; x < width; x += diameter) {
      // 塗りの色相(H)を0〜360でランダムに
      let h = random(360);
      // 円の大きさ(d)を5px〜20pxでランダムに
      let d = random(5, 20);

      fill(h, 80, 70, 0.8); // HSLと透明度
      ellipse(x + diameter / 2, y + diameter / 2, d, d);
    }
  }
}

function draw() {}
```

# 5. インタラクション（反応させる）

---

`setup()`で静的に描画していたグリッドを`draw()`関数に移すことで、アニメーションやインタラクション（マウスへの反応）を追加できる。

## 5-1. マウスに反応するグリッド

`dist()`関数は、2点間の距離を計算する。`mouseX, mouseY`（マウス座標）と、各円の中心座標との距離を計算し、その距離に応じて円の大きさを変化させる。

```jsx
const size = 20; // グリッドの1マスのサイズ

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
}

function draw() {
  background(0); // 毎フレーム背景を塗りつぶす

  for (let y = 0; y < height; y += size) {
    for (let x = 0; x < width; x += size) {
      // マウス座標と円の中心座標との距離を計算
      let distance = dist(x + size / 2, y + size / 2, mouseX, mouseY);

      // 距離が近いほど円が小さくなるように調整 (0.1は調整用の係数)
      let diameter = distance * 0.1;

      fill(180, 50, 50);
      ellipse(x + size / 2, y + size / 2, diameter, diameter);
    }
  }
}
```

## 5-2. ランダム性の制御 (randomSeed)

`draw()`ループ内で`random()`を使うと、毎フレーム違うパターンになり、ちらついてしまう。`randomSeed()`を使うと、ランダムのパターンを「固定」できる。

```jsx
const size = 20;
let seed = 99; // ランダムの種（シード値）を保存する変数

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
}

function draw() {
  background(0);
  randomSeed(seed); // ★ 毎フレーム、ランダム性を同じパターンにリセット

  for (let y = 0; y < height; y += size) {
    for (let x = 0; x < width; x += size) {
      let distance = dist(x + size / 2, y + size / 2, mouseX, mouseY);
      let diameter = distance * 0.1;

      // 毎回同じランダムな色相が選ばれる
      fill(random(360), 80, 70);
      ellipse(x + size / 2, y + size / 2, diameter, diameter);
    }
  }
}

// マウスが離されたら、シード値を新しいランダムな値に変更
function mouseReleased() {
  seed = random(99999);
}
```

## 5-3. 値の制御 (constrain)

`constrain(値, 最小値, 最大値)`は、指定した「値」が最小値と最大値の範囲内に収まるように制限（クランプ）してくれる。

```jsx
const size = 20;
let seed = 99;

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
}

function draw() {
  background(0);
  randomSeed(seed);

  for (let y = 0; y < height; y += size) {
    for (let x = 0; x < width; x += size) {
      let distance = dist(x + size / 2, y + size / 2, mouseX, mouseY);

      // マウスとの距離から円の直径を計算
      let calculatedDiameter = distance * 0.1;

      // --- ★ ここを修正 ---
      // constrain(値, 最小値, 最大値) を使って、直径が 0 より小さくならず、
      // 20 より大きくならないように制限する。
      let diameter = constrain(calculatedDiameter, 0, 20);

      // --- もしくは Math.min() でも可 ---
      // let diameter = Math.min(calculatedDiameter, 20); // 最小値を気にしない場合

      fill(random(360), 80, 70);
      ellipse(x + size / 2, y + size / 2, diameter, diameter);
    }
  }
}

function mouseReleased() {
  seed = random(99999);
}
```

# 6. なだらかなランダム（パーリンノイズ）

---

`random()`は「完全なランダム」だが、`noise()`（パーリンノイズ）は「なだらかに変化するランダム」な値を生成する。これにより、より自然で有機的な表現が可能になる。

## 6-1. noise() の仕組み

- `noise(x)`は、`x`の値が近いほど、近い値（0〜1の範囲）を返す。
- `x`の値を少しずつ（例: `0.01`ずつ）増やしていくと、返される値もなだらかに変化する。

【**静的なノイズ（setup内）**】

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  background(0);

  let noiseOffset = random(100); // ノイズの開始点をランダムに

  for (let x = 0; x < width; x++) {
    noiseOffset += 0.01; // xが進むごとにノイズの引数を少しずつずらす
    
    // ノイズの値(0〜1)を画面の高さ(0〜height)に変換
    let y = noise(noiseOffset) * height; 
    
    stroke(0, 0, 100); // 白い線
    line(x, height, x, y);
    
    console.log(y);
  }
}

function draw() {}
```

## 6-2. ノイズによるアニメーション (draw内)

`noise()`の引数を時間（`frameCount`や、少しずつ加算する変数）と連動させることで、なめらかなアニメーションを生成できる。

```jsx
// 2つのノイズの開始点を別々に管理する
let xOffset = 0;
let yOffset = 10000; // xとyで全く異なる開始点を使う

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  fill(0, 80, 70);
  noStroke();
}

function draw() {
  background(0, 0.1); // 毎フレーム少しだけ透明な黒を重ねる（残像効果）

  // ノイズの値(0〜1)を画面の幅/高さ(0〜width/height)に変換
  let x = noise(xOffset) * width;
  let y = noise(yOffset) * height;

  // ノイズの引数を少しずつ進める
  xOffset += 0.005;
  yOffset += 0.005;

  ellipse(x, y, 20, 20);
}
```
