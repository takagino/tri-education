# 1. **p5.jsとは？**

---

## 1-1. 概要

p5.jsは、クリエイティブ・コーディング（創造的なコーディング）とビジュアルアート（視覚芸術）のために設計されたJavaScriptライブラリ。

| **目的** | アーティスト、デザイナー、教育者、そしてプログラミング初学者が、Webブラウザ上で視覚的な表現やインタラクティブな作品を簡単に作成できるようにすること。 |
| --- | --- |
| **起源** | Javaベースのビジュアルプログラミング言語・環境である「Processing」の考え方を、Web（JavaScript）の世界に持ち込むために開発された。 |
| **機能** | HTMLの`<canvas>`要素に対して、図形の描画、色の操作、アニメーション、インタラクション（マウス操作など）を、シンプルかつ直感的な命令で実行できる。 |

**【公式サイト】**

[p5.js](https://p5js.org//)

**【作品共有サイト】**

[OpenProcessing - Creative Coding for the Curious Mind](https://openprocessing.org/)

【自作のVJツール】

# 2. 図形の描画

---

キャンバスに基本的な図形を描画していきます。

```jsx
function setup() {
  createCanvas(640, 480);

  // 点の描画：point( X座標, Y座標 );
  point(100, 200);

  // 線の描画：line( X座標始点, Y座標始点, X座標終点, Y座標終点 );
  line(10, 10, 200, 180);

  // 矩形（四角）の描画：rect( X座標, Y座標, 幅, 高さ );
  // デフォルトでは、(X, Y)は矩形の左上の角を指す。
  rect(250, 20, 100, 150);

  // 楕円（円）の描画：ellipse( X座標, Y座標, 幅, 高さ );
  // デフォルトでは、(X, Y)は楕円の中心を指す。
  ellipse(500, 100, 150, 150);
}

function draw() {
  // この時点では setup() だけで描画が完結するため、draw()は空
}
```

**【その他の図形】**

`triangle()` (三角形), `quad()` (四角形), `arc()` (円弧) など、多くの図形が用意されている。

[Reference](https://p5js.org//reference/#Shape)

## 2-1. 色とスタイルの指定

図形を描画する前に、`fill()`（塗りつぶしの色）や`stroke()`（線の色）などを指定する。

p5.jsでは、一度指定した色は、次に別の色を指定するまで保持される（ステートフル）。

```jsx
function setup() {
  createCanvas(640, 480);
  background(255, 255, 255); // 背景色を白に (R, G, B)

  // グレースケール（白黒）の場合は、値を1つだけ指定する (0:黒 〜 255:白)
  // background(255);

  //--- 1つ目の図形 ---
  // 塗りの色を指定 (R, G, B)
  fill(255, 0, 0); // 赤色
  // 線の色を指定 (R, G, B)
  stroke(0, 0, 255); // 青色
  // 線の太さを指定 (ピクセル)
  strokeWeight(4);

  ellipse(160, 120, 200, 200);

  //--- 2つ目の図形 ---
  // 16進数カラーコードも使用可能
  fill("#00FF00"); // 緑色
  noStroke(); // 線を描画しない

  rect(320, 40, 150, 150);

  //--- 3つ目の図形 ---
  noFill(); // 塗りつぶしなし
  stroke(0); // 線の色を黒に
  strokeWeight(1);

  ellipse(480, 120, 100, 100);
}
```

## 2-2. 透明度 (アルファ)

`background()`, `fill()`, `stroke()`は、4つ目の引数（`alpha`）で透明度を指定できる（0:透明 〜 255:不透明）。

```jsx
function setup() {
  createCanvas(640, 480);
  background(0, 50); // 黒をうっすらと（透明度50）

  // R, G, B, Alpha
  fill(255, 0, 0, 100); // 赤色を約40%の透明度(100/255)で指定

  // ★ 16進数でも8桁 (RRGGBBAA) で透明度を指定できます
  // stroke("#0000ff", 100); // ← この書き方はできません
  stroke("#0000FFAA"); // 青色を約67%の透明度(AAは16進数で170)で指定
  ellipse(320, 240, 300, 300);
}
```

## 2-3. HSL / HSB カラーモード

`colorMode()`を使うと、色の指定方法をRGBからHSL（色相・彩度・輝度）やHSB（色相・彩度・明度）に変更できる。これにより、色相（`H`）をずらすだけで色を変化させるなど、直感的な色操作が可能になる。

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL); // カラーモードをHSLに変更

  // H(色相:0-360), S(彩度:0-100), L(輝度:0-100), alpha(透明度:0.0-1.0)
  fill(180, 80, 50, 0.5); // H:180(シアン系), S:80%, L:50%
  rect(100, 100, 100, 100);

  fill(240, 80, 50); // H:240(青系), S:80%, L:50%
  rect(200, 100, 100, 100);
}
```

## 2-4. 基準点（座標モード）

`rect()`（四角）と`ellipse()`（楕円）では、**座標の基準点（モード）の初期値が異なる。**

- **`rect()`** の初期値は **`CORNER`** （`x, y` は図形の**左上**の角）。
- **`ellipse()`** の初期値は **`CENTER`** （`x, y` は図形の**中心**）。

`rectMode()` を使うことで、四角形の基準点を中心（`CENTER`）に揃えることができる。

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL); 
  background(0, 0, 80);
  stroke(0, 0, 0);

  fill(0, 100, 50, 0.6); 
  rect(100, 100, 150, 100); // (100, 100)は左上の角
  ellipse(100, 100, 10, 10); // (100, 100)は中心（点の目印）

  // --- モード変更後 ---
  rectMode(CENTER); // ★ 矩形の基準点を中心に変更

  fill(240, 100, 50, 0.6);
  rect(300, 100, 150, 100); // (300, 100)は中心
  ellipse(300, 100, 10, 10); // (300, 100)は中心（点の目印）
}
```

# 3. **アニメーションさせる**

---

`setup()`は一度しか実行されないが、`draw()`は毎フレーム（通常1秒間に60回）繰り返し実行される。

グローバル変数（`setup`や`draw`の外側で宣言された変数）の値を`draw()`の中で少しずつ変化させることで、動きが生まれる。

## 3-1. 動きの基本

```jsx
let x = 0; // 矩形のX座標を保存する変数

function setup() {
  createCanvas(640, 480);
  colorMode(HSL); // HSLモードを設定
  rectMode(CENTER); // 矩形の基準点を中心に
  fill(0, 80, 50); // HSLで赤色
  noStroke();
}

function draw() {
  // xの値を毎フレーム1ずつ増やす
  x++; 
  
  rect(x, height / 2, 50, 50); // x座標を変数xにする
}
```

問題点: このまま実行すると、矩形の軌跡（残像）がキャンバスに残り続ける。

## **3-2. 描画したモノを消す（アニメーションの基本）**

アニメーションは「パラパラ漫画」と同じである。次の絵を描く前に、古い絵を消去する必要がある。

p5.jsでは、`draw()`関数の一番最初に`background()`関数を呼び出し、毎フレームキャンバスを塗りつぶすのが最も一般的で推奨される方法。

```jsx
let x = 0;

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER); // 矩形の基準点を中心に
  fill(0, 80, 50); // HSLで赤色
}

function draw() {
  // 毎フレーム、背景を薄い灰色(HSL: 0, 0, 86)で塗りつぶす
  background(0, 0, 86); 

  x++;
  rect(x, height / 2, 50, 50);

  // 画面端まで行ったらリセット
  if (x > width) {
    x = 0;
  }
}
```

# 4. システム変数（p5.jsが教えてくれる値）

---

p5.jsには、現在の状態を自動で更新してくれる便利な**システム変数**が組み込まれている。

| 変数名 | 説明 |
| --- | --- |
| width | キャンバスの幅 |
| height | キャンバスの高さ |
| frameCount | スケッチが始まってからの経過フレーム数 |
| mouseX, mouseY | キャンバス内でのマウスのX座標とY座標 |
| mouseIsPressed | マウスが**クリックされている間** `true` 、**離されている間** `false`  |

## 4-1. 練習「マウスでお絵描きツール」

`mouseX`, `mouseY` を使ってマウスの位置を取得し、`mouseIsPressed` を使って「クリックしている時だけ」描画する。

```jsx
function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
  background(0, 0, 10); // 最初に一度だけ黒く塗る
}

function draw() {
  // background() を呼ばないので、描画が蓄積される

  // マウスが押されている時だけ、if文の中が実行される
  if (mouseIsPressed === true) {
    fill(180, 80, 70, 0.5);
    // マウスの位置に矩形を描画
    rect(mouseX, mouseY, 10, 10);
  }
}
```

# 5. システム関数（p5.jsが呼び出してくれる関数）

---

特定のアクション（イベント）が発生した**瞬間**に、p5.jsが**一度だけ**自動で呼び出す関数。

| 関数名 | 説明 |
| --- | --- |
| mousePressed() | マウスがクリックされた**瞬間**に実行 |
| mouseReleased() | マウスが離された瞬間に実行 |
| keyPressed() | キーボードが押された瞬間に実行 |
| keyReleased() | キーボードが離された瞬間に実行 |

## 5-1. 練習「スペースキーで画面をリセット」

お絵描きツールに、キー操作で画面をリセットする機能を追加する。

```jsx
// (setup() と draw() は「4-1. 練習」と同じ)

function setup() {
  createCanvas(640, 480);
  colorMode(HSL);
  rectMode(CENTER);
  noStroke();
  background(0, 0, 10);
}

function draw() {
  if (mouseIsPressed === true) {
    fill(180, 80, 70, 0.5);
    rect(mouseX, mouseY, 10, 10);
  }
}

// キーボードのキーが離された瞬間に、この関数が1度だけ実行される
function keyReleased() {
  // スペースキーが押されたか (keyCode 32 はスペースキーを指す)
  if (keyCode === 32) {
    // 背景を塗りつぶして、描画をリセットする
    background(0, 0, 10);
  }
}
```

【`key` と `keyCode` の違い】

`keyPressed()`や`keyReleased()`の中では、押されたキーを2種類の変数で判別できる。

| `key` 変数 | 押されたキーの**文字**（例: `' '`, `'a'`, `'1'`）が入る
「特定の文字が押されたか」の判定に便利 |
| --- | --- |
| `keyCode` 変数 | 押されたキーの**物理的なコード**（例: `32` (スペース), `UP_ARROW` (上矢印)）が入る
「特殊キー」の判定に便利 |
