# 2. Web Audioとp5.soundの基礎知識

## 2-1. p5.sound とは？

**p5.sound** は、p5.js の公式アドオンライブラリであり、ブラウザに標準搭載されている高度な音響API **「Web Audio API」** を直感的かつクリエイティブに扱えるようにラップ（簡略化）したものです。

| 項目 | 内容 |
| --- | --- |
| **できること** | 音声ファイルの再生・停止・逆再生・音程変更、マイクからの音声取得、音量・周波数解析（FFT）、音の波形描画、シンセサイザーによる発音、ディレイ・リバーブ・フィルター等のエフェクト処理 |
| **導入方法** | HTMLの `<script>` タグで CDN から読み込むだけ（インストール不要） |
| **公式サイト** | [https://p5js.org/reference/p5.sound/](https://p5js.org/reference/p5.sound/) |

---

## 2-2. ブラウザの重要ルール「Autoplay Policy（自動再生の禁止）」

Webで音を扱う際、**全Webエンジニアが必ず直面する最も重要なセキュリティ仕様** があります。
それが **「Autoplay Policy（オートプレイ・ポリシー）」** です。

昔のWebサイトでは、ページを開いた瞬間に大音量でBGMや動画広告が鳴り響き、ユーザーを驚かせたり公共の場で恥をかかせたりするトラブルが多発しました。
そのため、現在の主要ブラウザ（Chrome, Safari, Edge, Firefox等）はすべて、

<aside>
💡

**「ユーザーが画面を明示的にクリック（またはタップ・キー押し）するまで、Web Audioの音声出力を自動的にミュート（一時停止）する」**

</aside>

という厳格なセキュリティロックをかけています。

p5.sound では、画面のクリック時などに **`userStartAudio()`** という関数を呼ぶか、イベントの中で `.play()` を実行することで、この制約を安全にクリアできます。

## 3-1. 周波数（Hz）を指定して音を鳴らす（`p5.Oscillator`）

音の正体は **「空気の振動（波）」** です。
1秒間に何回振動するかを **「周波数（単位：Hz / ヘルツ）」** と呼び、この数値が小さいほど「低い音」、大きいほど「高い音」になります。

`p5.sound` の **`p5.Oscillator`（オシレーター / 発振器）** を使うと、プログラムで好きな周波数の音波を生成して鳴らすことができます。

| 波形の種類（引数） | 音色の特徴 |
| --- | --- |
| **`'sine'`**（サイン波・正弦波） | 最も純粋で丸みのある柔らかい音（時報やフルートのような音） |
| **`'triangle'`**（三角波） | サイン波に近いが、少しだけ倍音を含んだあたたかい音 |
| **`'sawtooth'`**（ノコギリ波） | 倍音を豊富に含む、華やかでエッジの効いたシンセサイザーらしい音 |
| **`'square'`**（矩形波） | ファミコン（8bitゲーム）のBGMのようなレトロなデジタル音 |

まずは画面を押している間だけ音が鳴り、マウスの左右の位置で周波数（音の高さ）が変化するスケッチを書いてみましょう。

**`js/osc.js`**

```jsx
// ① 変数の宣言
let osc;
let currentFreq = 440; // 初期周波数：440Hz（ラ / A4の音）

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);

  // ② サイン波（'sine'）のオシレーターを生成
  osc = new p5.Oscillator('sine');
  osc.amp(0); // 最初は音量を 0（無音）にしておく
  osc.freq(currentFreq); // 周波数を設定する
  osc.start(); // オシレーターを起動して待機
}

function mousePressed() {
  // ③ ブラウザのAutoplay制限を解除して発音スタート
  userStartAudio();
  osc.amp(0.3, 0.05); // 0.05秒かけて音量0.3へ滑らかに上げる（プチッというノイズ防止）
}

function mouseReleased() {
  // ④ マウスを離したら0.1秒かけて音量を0にする
  osc.amp(0, 0.1);
}

function draw() {
}

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}
```

## **3-2. 音階をキーボードに割り当てて鳴らす**

周波数の仕組みがわかったら、次はパソコンのキーボード（`A` `S` `D` `F` `G` `H` `J` `K` キー）に **「ド・レ・ミ・ファ・ソ・ラ・シ・ド」** の周波数を割り当てて、ピアノのように演奏できるようにしてみましょう。

**【音階と周波数（Hz）の対応表】**

| キー | 音名（日本） | 音名（英語） | 周波数（Hz） |
| --- | --- | --- | --- |
| **`A`** | ド | C4 | `261.63` |
| **`S`** | レ | D4 | `293.66` |
| **`D`** | ミ | E4 | `329.63` |
| **`F`** | ファ | F4 | `349.23` |
| **`G`** | ソ | G4 | `392.00` |
| **`H`** | ラ | A4 | `440.00` |
| **`J`** | シ | B4 | `493.88` |
| **`K`** | ド（高） | C5 | `523.25` |

キーボードを押したとき（`keyPressed`）に指定した周波数で音を鳴らし、キーを離したとき（`keyReleased`）に音がスーッと消える **`js/osc.js`** を作成します。

**`js/osc.js`** 

```jsx
let osc;
let currentFreq = 0;
let currentNoteName = "";

// キーボードのキーと音階データ（オブジェクト）
const NOTE_MAP = {
  'a': { name: 'ド (C4)', freq: 261.63 },
  's': { name: 'レ (D4)', freq: 293.66 },
  'd': { name: 'ミ (E4)', freq: 329.63 },
  'f': { name: 'ファ (F4)', freq: 349.23 },
  'g': { name: 'ソ (G4)', freq: 392.00 },
  'h': { name: 'ラ (A4)', freq: 440.00 },
  'j': { name: 'シ (B4)', freq: 493.88 },
  'k': { name: 'ド (C5)', freq: 523.25 }
};

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);

  // 三角波（'triangle'）で少し温かみのあるシンセ音にする
  osc = new p5.Oscillator('triangle');
  osc.amp(0);  // 最初は音量を 0（無音）にしておく
  osc.start(); // オシレーターを起動して待機
}

function keyPressed() {
  // 押されたキーを小文字に変換してオブジェクトにあるかチェック
  let k = key.toLowerCase();
  if (NOTE_MAP[k]) {
    userStartAudio();

    let note = NOTE_MAP[k];
    currentNoteName = note.name;
    currentFreq = note.freq;

    // 周波数を設定し、すっと音量を上げる
    osc.freq(note.freq);
    osc.amp(0.3, 0.05); // 0.05秒で音量0.3に立ち上げる
  }
}

function keyReleased() {
  // キーを離したら0.1秒かけて自然に音量を0にする
  osc.amp(0, 0.1);
}

function draw() {
  background(220, 30, 10);

  fill(0, 0, 100);
  textAlign(CENTER, CENTER);
  textSize(22);
  text("A/S/D/F/G/H/J/K キーを押して演奏してみよう！", width / 2, height / 2 - 40);

  if (currentNoteName !== "") {
    fill(180, 80, 100);
    textSize(36);
    text(`♪ ${currentNoteName} : ${currentFreq} Hz`, width / 2, height / 2 + 30);
  }
}

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}
```

## **3-3. ビジュアルと連動させる**

音が鳴るようになったら、次は **「音が鳴った瞬間にビジュアルが弾ける」** 仕組みを作ります。
まずは、**「画面中央からランダムな方向へ飛び出し、徐々に透明になって消えていく円のクラス（`NoteCircle`）」** を設計しましょう。

前回学んだ通り、`js/templates/` フォルダを作ってクラスを別ファイル（`NoteCircle.js`）として切り出します。

**【ディレクトリ構成】**

![Snapzy_2026-10-29_13-21-13_502.png](05_%E9%9F%B3%E6%A5%BD%E3%81%A8%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E9%80%A3%E6%90%BA/Snapzy_2026-10-29_13-21-13_502.png)

**【まずは引数なしで動く基本の `NoteCircle.js` を作る】**

画面中央（`width / 2, height / 2`）で生まれ、ランダムな角度（`0〜360度`）に向かって進みながら、透明度（`alpha`）が `100` から `0` へと減っていくクラスです。

**`js/templates/NoteCircle.js`**

```jsx
class NoteCircle {
  constructor() {
    // 画面中央からスタート
    this.x = width / 2;
    this.y = height / 2;

    // 飛び出す角度（0〜360度）をランダムに決める
    let angle = random(360);
    let speed = 5; // 移動スピード

    // 角度とスピードから、X方向・Y方向の移動量（速度ベクトル）を計算
    this.vx = cos(angle) * speed;
    this.vy = sin(angle) * speed;

    this.size = 60;       // 円のサイズ
    this.hue = 180;       // 色相（0〜360）
    this.lifespan = 100;  // 寿命（100で出現し、0になると消滅する）
    this.fadeSpeed = 1.5; // 寿命が減っていく速さ
  }

  // 毎フレームの座標移動と寿命の更新
  update() {
    this.x += this.vx;
    this.y += this.vy;
    this.lifespan -= this.fadeSpeed; // 寿命を少しずつ減らす
  }

  // 描画処理
  render() {
    push();
    translate(this.x, this.y);
    noStroke();

    // 寿命（100〜0）に合わせて、円のサイズを this.size から 0 へ徐々に小さくする
    let currentSize = map(this.lifespan, 100, 0, this.size, 0);

    // 寿命（lifespan: 100〜0）をそのまま透明度（Alpha）として使う
    fill(this.hue, 80, 100, this.lifespan);
    circle(0, 0, currentSize);
    pop();
  }

  // 寿命が尽きたかどうかを判定するメソッド
  isDead() {
    return this.lifespan <= 0;
  }
}
```

```jsx
  'f': { name: 'ファ (F4)', freq: 349.23 },
  'g': { name: 'ソ (G4)', freq: 392.00 },
  'h': { name: 'ラ (A4)', freq: 440.00 },
```

## **3-4. 引数で変化させる**

円が飛び出るようになりましたが、今のままではどのキー（ド〜高いド）を押してもすべて同じ色（水色）・同じスピード・同じサイズの円しか出ません。
そこで、`NoteCircle` の **`constructor(hue, speed, size)` に引数を渡せるように進化** させ、音階ごとのイメージをビジュアルに反映させましょう。

**【音階ごとのビジュアルイメージ設計】**

| キー | 音階 | 音のイメージ | 色相 (`hue`) | スピード (`speed`) | サイズ (`size`) |
| --- | --- | --- | --- | --- | --- |
| **`A`** | ド (C4) | どっしり重い基底の音 | `0`（赤） | `2.5`（ゆっくり） | `110`（特大） |
| **`S`** | レ (D4) | 温かく動き出す音 | `35`（オレンジ） | `3.5` | `95` |
| **`D`** | ミ (E4) | 明るく輝く音 | `60`（黄色） | `4.5` | `85` |
| **`F`** | ファ (F4) | 穏やかで爽やかな音 | `130`（緑） | `5.5` | `75` |
| **`G`** | ソ (G4) | 澄み渡る空のような音 | `190`（シアン） | `6.5` | `65` |
| **`H`** | ラ (A4) | 凛としたクールな音 | `230`（青） | `7.5` | `55` |
| **`J`** | シ (B4) | 鋭く神秘的な音 | `280`（紫） | `9.0` | `45` |
| **`K`** | ド (C5) | 軽やかに弾ける高い音 | `330`（マゼンタ） | `11.0`（高速） | `35`（小粒） |

**【引数を受け取るように `NoteCircle.js` をアップデート】**

`NoteCircle.js` の `constructor(hue, speed, size)` に引数を追加し、固定値だった `speed`・`size`・`hue` を引数から受け取るように変更します（変更するのは `constructor` 内の数行だけです）。

**`js/templates/NoteCircle.js`**

```jsx
class NoteCircle {
  // ① 引数で「色相(hue)」「速さ(speed)」「大きさ(size)」を受け取る
  constructor(hue, speed, size) {
    this.x = width / 2;
    this.y = height / 2;
    let angle = random(360);
    //let speed = 5;        
    this.vx = cos(angle) * speed; // 引数のスピードを直接設定
    this.vy = sin(angle) * speed;
    this.size = size;     // 引数のサイズを設定
    this.hue = hue;       // 引数の色相を設定
    this.lifespan = 100;
    this.fadeSpeed = 1.5;
  }

  update() {
    this.x += this.vx;
    this.y += this.vy;
    this.lifespan -= this.fadeSpeed;
  }

  render() {
    push();
    translate(this.x, this.y);
    noStroke();

    let currentSize = map(this.lifespan, 100, 0, this.size, 0);
    fill(this.hue, 80, 100, this.lifespan);
    circle(0, 0, currentSize);
    pop();
  }

  isDead() {
    return this.lifespan <= 0;
  }
}
```

# 5. 音を視覚化する（周波数解析 FFT）

音が鳴ったら、次は **「音のデータをリアルタイムに数値として取り出す」** ステップに進みます。
メディアアートやVJ演出の主役となるのが、音を周波数帯域ごとに分解する **「周波数解析（`p5.FFT`）」** です。

| 周波数帯域 | 取得データ・数値範囲 | 主な対象（楽器・音） | 向いている演出・視覚効果 |
| --- | --- | --- | --- |
| **低音 Bass** | 低音域の強さ 
(`0.0 〜 1.0`) | キック、ベース | 迫力・衝撃波（画面の拡大・脈動） |
| **中音 Mid** | 中音域の強さ 
(`0.0 〜 1.0`) | ボーカル、シンセ | 形状変化・うねり（波打ち・変形） |
| **高音 Treble** | 高音域の強さ 
(`0.0 〜 1.0`) | ハイハット、シンバル | スパーク・光の粒（火花・きらめき） |

**【FFT（Fast Fourier Transform）とは？】**

どんなに複雑な音楽も、数学的には **「様々な高さ（周波数）の純音（サイン波）が幾重にも重なり合ってできたもの」** です。
FFT（高速フーリエ変換）とは、この混ざり合った音の波を瞬時に分解し、**「どの周波数（低音・中音・高音）が、いまどれくらいの強さで鳴っているか」** を配列として取り出すアルゴリズムです。

## **5-2. 平方根で中音・高音を見やすくする**

一般的な音楽は、物理的な音のエネルギーが「低音」に大きく集中しており、「中音」「高音」の数値は `0.01` や `0.002` といった非常に小さな値になります。

**`0.0 〜 1.0` の小数に対して平方根 `sqrt(値)` をとる** と、人間の耳の感覚（対数特性）に近づき、**小さな値だけをグッと大きく持ち上げる** ことができます。

- 例：`0.01`（とても小さい高音） ➔ `sqrt(0.01)` ＝ **`0.10`（10倍に拡大）**
- 例：`0.04`（中くらいの音） ➔ `sqrt(0.04)` ＝ **`0.20`（5倍に拡大）**
- 例：`0.49`（大きい低音） ➔ `sqrt(0.49)` ＝ **`0.70`（大きすぎず程よくキープ）**

<aside>
💡

**平方根（ルート / `sqrt`）とは？**

**平方根（Square Root）** とは、数学の「$\sqrt{\quad}$（ルート）」のことで、**「同じ数を2回掛けて（2乗して）、その数になる元の数」** を求める計算です。p5.js では英語の **Sq**uare **R**oo**t** を略した **`sqrt()`** 関数を使います。

- **普通の整数（1より大きい数）の場合**：
    - `3 × 3 = 9` なので、`sqrt(9)` は **`3`** になります（元の数より小さくなる）。
    - `2 × 2 = 4` なので、`sqrt(4)` は **`2`** になります。
- **`0.0 〜 1.0` の小数の場合**：
    - `1` より小さい小数は、掛け算すると `0.1 × 0.1 = 0.01` のように **どんどん小さくなる** 性質があります。
    - そのため、逆算である平方根 `sqrt()` をとると、`sqrt(0.01)` ➔ **`0.1`** のように **数値がグッと大きくなる** のです。
    - しかも、`sqrt(0) = 0`、`sqrt(1) = 1` なので、**最小値 `0.0` と最大値 `1.0` の範囲（枠）からはみ出さずに、小さな値だけを底上げできる** という、映像表現にとって非常に便利な性質を持っています。
</aside>

## 7-1. **音響エネルギーのデータパイプライン**

FFTの `spectrum` から取得した値は高音ほど小さいため、平方根 `sqrt()` で小さな値を持ち上げた上で、前回のクラスたちが受け取る `0.0〜1.0` の範囲へ感度調整と平滑化（Lerp）を行います。

**`js/sketch.js`**

```jsx
let bgm;
let fft;

// ① 平滑化された音響エネルギー（0.0 〜 1.0）
let smoothBass = 0;
let smoothMid = 0;
let smoothTreble = 0;

async function setup() {
    createCanvas(windowWidth, windowHeight);
    rectMode(CENTER);
    imageMode(CENTER);
    angleMode(DEGREES);
    colorMode(HSB, 360, 100, 100, 100);

    bgm = await loadSound('assets/bgm.mp3');
    bgm.loop();
    fft = new p5.FFT(64);
    bgm.connect(fft);
}

function mousePressed() {
    userStartAudio();

    if (!bgm) return;

    if (bgm.isPlaying()) {
        bgm.pause();
    } else {
        bgm.play();
    }
}

function draw() {
    background(220, 30, 10);

    fill(0, 0, 100);
    textAlign(CENTER, CENTER);
    textSize(24);

    // ② constrain(), map() で値の範囲を調整
    let spectrum  = fft.analyze();
    let rawBass   = constrain(map(sqrt(spectrum[0]), 0, 0.8, 0.0, 1.0), 0.0, 1.0);
    let rawMid    = constrain(map(sqrt(spectrum[12]), 0, 0.4, 0.0, 1.0), 0.0, 1.0);
    let rawTreble = constrain(map(sqrt(spectrum[28]), 0, 0.2, 0.0, 1.0), 0.0, 1.0);
    
    // ③ 0.0〜1.0 への感度調整とLerp平滑化
    smoothBass = lerp(smoothBass, rawBass, 0.2);
    smoothMid = lerp(smoothMid, rawMid, 0.2);
    smoothTreble = lerp(smoothTreble, rawTreble, 0.2);
    
    if (!bgm) {
        text("⏳ 音声ファイルを読み込み中...", width / 2, height / 2);
    } else if (!bgm.isPlaying()) {
        text("▶ 画面クリックで音楽を再生", width / 2, height / 2);
    } else {
        // ④ 出力値を変更
        text(`低音：${smoothBass.toFixed(2)}, 中音：${smoothMid.toFixed(2)}, 高音：${smoothTreble.toFixed(2)}`, width / 2, height / 2);
    }
}
```

## **7-2. 音響連動VJの実装**

**`js/sketch.js`**

```jsx
let bgm;
let fft;

// ① クラスのインスタンス配列
let orbs = [];
let ripples = [];
let waveLines = [];

let smoothBass = 0;
let smoothMid = 0;
let smoothTreble = 0;

async function setup() {
    createCanvas(windowWidth, windowHeight);
    rectMode(CENTER);
    imageMode(CENTER);
    angleMode(DEGREES);
    colorMode(HSB, 360, 100, 100, 100);

    bgm = await loadSound('assets/bgm.mp3');
    bgm.loop();
    fft = new p5.FFT(64);
    bgm.connect(fft);
    
    // ② インスタンスの生成
    // Orb（発光球）を30個生成
    for (let i = 0; i < 30; i++) {
        let rx = random(width * 0.1, width * 0.9);
        let ry = random(height * 0.1, height * 0.9);
        orbs.push(new Orb(rx, ry));
    }

    // Ripple（波紋）を8個生成
    for (let i = 0; i < 8; i++) {
        let rx = random(width * 0.2, width * 0.8);
        let ry = random(height * 0.2, height * 0.8);
        ripples.push(new Ripple(rx, ry));
    }

    // WaveLine（波打つライン）を5本生成
    for (let i = 0; i < 5; i++) {
        let y = map(i, 0, 4, height * 0.2, height * 0.8);
        waveLines.push(new WaveLine(y));
    }
}

function mousePressed() {
    userStartAudio();

    if (!bgm) return;

    if (bgm.isPlaying()) {
        bgm.pause();
    } else {
        bgm.play();
    }
}

function draw() {
    background(220, 30, 10);

    let spectrum  = fft.analyze();
    let rawBass   = constrain(map(sqrt(spectrum[0]), 0, 0.8, 0.0, 1.0), 0.0, 1.0);
    let rawMid    = constrain(map(sqrt(spectrum[12]), 0, 0.4, 0.0, 1.0), 0.0, 1.0);
    let rawTreble = constrain(map(sqrt(spectrum[28]), 0, 0.2, 0.0, 1.0), 0.0, 1.0);
    
    smoothBass = lerp(smoothBass, rawBass, 0.2);
    smoothMid = lerp(smoothMid, rawMid, 0.2);
    smoothTreble = lerp(smoothTreble, rawTreble, 0.2);
    
    // ③ 各クラスに最適な周波数帯域を割り振って更新・描画
    // 【背景レイヤー】WaveLine には中音（ボーカル・シンセ旋律）を渡す
    for (let line of waveLines) {
        line.update(smoothMid);
        line.render();
    }

    // 【中間レイヤー】Ripple には高音（シンバル・ビートの粒）を渡す
    for (let ripple of ripples) {
        ripple.update(smoothTreble);
        ripple.render();
    }

    // 【前面レイヤー】Orb には重低音（キック・ベースの爆発）を渡す
    for (let orb of orbs) {
        orb.update(smoothBass);
        orb.render();
    }
    
    // 再生待機中のみ案内テキストを表示
    noStroke();
    fill(0, 0, 100);
    textAlign(CENTER, CENTER);
    textSize(24);
    if (!bgm) {
        text("⏳ 音声ファイルを読み込み中...", width / 2, height / 2);
    } else if (!bgm.isPlaying()) {
        text("▶ 画面クリックで音楽を再生", width / 2, height / 2);
    }
}

function windowResized() {
    resizeCanvas(windowWidth, windowHeight);
}
```

- バスドラム（低音）の重低音に合わせて `Orb` がドクンと鼓動して光を放ち、
- メロディ（中音）に合わせて背景の `WaveLine` が生き物のように波打ち、
- ハイハット（高音）に合わせて `Ripple` の波紋がパッパッと弾ける。

前回のクラス設計を一切変えることなく、音響データと完璧に同期した圧巻のオーディオビジュアルが完成しました。
これがプログラミングにおける **「モジュール化（カプセル化）」** の最大のメリットです。
