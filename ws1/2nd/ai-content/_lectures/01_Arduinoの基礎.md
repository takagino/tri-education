# 2. Arduinoとは？

**Arduino（アルディーノ）** は、マイコン（マイクロコントローラ）を搭載した基板と、それを動かすためのソフトウェア環境（Arduino IDE）がセットになったオープンソースの電子工作プラットフォームです。

複雑な電気・電子工学の専門知識がなくても、C/C++ベースの直感的なコードを書くだけで、センサーからの入力を読み取ったり、モーターやLEDなどの出力を制御したりできます。

## **2-1. 本授業で使用するボード：Arduino Nano R4**

本授業では、小型かつ高性能な **Arduino Nano R4** を使用します。

- **MCU:** ルネサス製 RA4M1（Arm Cortex-M4 / 48MHz動作）
- **動作電圧:** 5Vロジック
- **USBコネクタ:** USB Type-C
- **ピン配置:** ブレッドボードに直接差し込んで使えるDIP形状

[Arduino - Home](https://www.arduino.cc/hardware#nano-family)

<aside>
⚠️

**安全のための注意**

電子回路は接続を誤ると部品が発熱・焼損したり、マイコン本体やPCのUSBポートを破損する恐れがあります。**回路を組み替える際は、必ずUSBケーブルをPCから抜いた状態で行ってください。**

</aside>

# **3. 電子パーツの確認**

**【ブレッドボード】**

- 穴（ソケット）にパーツを挿すだけで半田付けなしに回路が組める試作ボード。
- 外側の青ライン（**`-`**）と赤ライン（**`+`**）は縦方向に、中央の端子列（**`a〜e`**、**`f〜j`**）は横方向に内部で導通しています。

![board.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/board.png)

**【ジャンパーワイヤー：赤・黒・青・黄・白、各2本】**

- パーツ間やArduinoとブレッドボードを繋ぐ配線コード。

![2e5beab0-778f-4fa3-a4ac-d51e6d8c9741.jpg](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/2e5beab0-778f-4fa3-a4ac-d51e6d8c9741.jpg)

**【抵抗器（レジスタ）：330Ω × 2、10kΩ × 3】**

- 電流の流れを制限するパーツ。LEDなどの定格を超える過剰な電流が流れて焼き切れるのを防ぎます。
- 4本線の色（カラーコード）によって、抵抗の大きさ（電流の流れにくさ）が決まっています。

![61M5lVkhcEL._SX342_.jpg](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/61M5lVkhcEL._SX342_.jpg)

[カラー抵抗早見表！](https://www.freelab.jp/fl_part/s_regi_list.html)

**【LED（発光ダイオード）：赤・緑・黄・白、各1個】**

- 足が長いほうがアノード（**`+`**）、短いほうがカソード（**`-`**）。逆向きに挿すと点灯しません。

![led_kyokusei_nagaihou.jpg](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/led_kyokusei_nagaihou.jpg)

**【タクトスイッチ：3個】**

- 押している間だけ回路が繋がり、指を離すと元に戻る押しボタンスイッチ。
- デジタル入力（ON/OFF、0/1）の判定に使用します。

![soten3_a11110900ux0115.jpg](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/soten3_a11110900ux0115.jpg)

**【距離センサー：シャープ測距モジュール（GP2Y0A21YK）】**

- 赤外線を照射し、対象物に反射して戻ってくる角度から距離を測定するセンサー（測定範囲：およそ10cm〜80cm）。
- 手や物との距離に応じた電圧（アナログ値）を出力するため、「手を近づけると変化する演出」などに利用します。

[シャープ測距モジュール GP2Y0A21YK](https://akizukidenshi.com/catalog/g/g102551/)

**【明るさセンサー：CdSセル】**

- 当たる光の量（照度）によって抵抗値が変わる光センサー。
- 明るい場所では抵抗が小さくなり、手で覆って暗くすると抵抗が大きくなります。アナログ入力として環境の明暗を読み取ります。

[CdSセル 5mmタイプ](https://akizukidenshi.com/catalog/g/g100110/)

**【サーボモーター：Miuzei MS18】**

- プログラムで指定した角度（0度〜180度）へ正確に軸を回転・静止させることができる小型モーター。
- 通常の回転し続けるモーターと異なり、針を指し示すメーター表現や、ギミックの物理的な開閉アクションに適しています。
- 油でベトベトしているものがありますが、内部の油が漏れ出しているだけなので気にしないでください。

![619ROTAQBlL._AC_UF350,350_QL80_.jpg](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/619ROTAQBlL._AC_UF350350_QL80_.jpg)

という閉じた一本の輪（回路／サーキット）を描くように流れます。抵抗を挟まずに電源とGNDを直接ショートさせないよう注意してください。

## **4-3. LEDを点灯させる回路（電流の流れを理解する）**

プログラムでの制御に入る前に、まずはArduinoを「単なる5Vの電池」として使い、電気が流れる仕組み（回路）をブレッドボード上で作ってみましょう。

以下の順序でパーツを繋ぎ、ぐるっと一周する「電気の道筋（回路）」を作ります。

**【配線手順】**

![Snapzy_2026-10-01_15-54-54_840.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/Snapzy_2026-10-01_15-54-54_840.png)

1. Arduinoの **5V** ピン → ブレッドボードの空いている行へ
2. その行から **330Ωの抵抗** の片足 → 別の行へ
3. 抵抗の先の行から **LEDの長い足（＋）** → **短い足（ー）** を別の行へ
4. LEDの短い足の行 → Arduinoの **GND** ピンへ

<aside>
💡

配線が完了した瞬間、LEDがピカッと光りっぱなしになります。
電気は水と同じで、高いところ（5V）から低いところ（GND）へ向かって流れます。この「5V → 抵抗 → LED → GND」という道筋が途切れずに繋がっている（＝電流が流れている）ため、LEDが光るのです。ここではまだプログラムは一切関係しておらず、物理的な電気の通り道ができている状態です。

</aside>

# 5. プログラムによる制御（デジタル出力）

先ほどは「指でボタンを押す」という物理的なアクションで電気をコントロールしましたが、今度はこれを**プログラムの力でコントロール**してみましょう。

## **5-1. デジタル出力（Lチカ：LEDの点滅）**

ブレッドボード上のパーツ（タクトスイッチ・抵抗・LED）はそのままにして、電源の入り口だけをプログラムで操れる「デジタルピン」に変更します。

**【配線手順】**

![Snapzy_2026-10-01_16-13-03_951.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/Snapzy_2026-10-01_16-13-03_951.png)

1. 先ほどArduinoの「5V」ピンに挿していたジャンパーワイヤーを抜き、そのまま「D21」ピンに挿し替えてください。

**【プログラムの書き込み】**

1. 「Arduino IDE」を立ち上げます。
2. 新規ファイルを開き、以下のコードを書いて検証・書き込みを行います。
    
    ```cpp
    const int ledPin = 21; // LEDに繋いだピン番号
    
    void setup() {
      // D21ピンを「出力（OUTPUT）」モードに設定
      pinMode(ledPin, OUTPUT);
    }
    
    void loop() {
      digitalWrite(ledPin, HIGH); // 5Vを出力（点灯）
      delay(1000);                // 1000ms（1秒）待機
      digitalWrite(ledPin, LOW);  // 0Vを出力（消灯）
      delay(1000);                // 1000ms（1秒）待機
    }
    ```
    
3. 書き込みが終わったら、タクトスイッチを指で押しっぱなしにしてみてください。
指で押している間だけ、LEDが「1秒ついて、1秒消える」という点滅（通称：Lチカ）を繰り返すはずです。

<aside>
💡

**「5V」の時と「D21」の時の違い**

- **5Vピンの場合（常に水が流れている水道）**
    
    5Vピンからは、常に電気が一定の圧力で押し出されています。そのため、間にあるタクトスイッチ（跳ね橋）を物理的に下ろした（ONにした）瞬間、いつでも電気が流れてLEDが光りました。
    
- **D21ピンの場合（蛇口をプログラムでひねる）**
    
    デジタルピンは、プログラムからの指示によって「5V（HIGH）を出す」と「0V（LOW）にする」を自由に切り替えることができます。
    今回はプログラムで「1秒間5Vを出し、1秒間止める」という命令（**`digitalWrite`**）を出しています。
    
</aside>

---

## **5-2. アナログ出力（PWMによる蛍のような明滅）**

Arduinoのデジタルピンのうち、チルダ記号（**`~`**）が付いたピン（D3, D5, D6, D9, D10, D11等）は **PWM（パルス幅変調）** による擬似的なアナログ電圧出力（0〜255）が可能です。

**【配線手順】**

![Snapzy_2026-10-01_16-18-48_418.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/Snapzy_2026-10-01_16-18-48_418.png)

1. 先ほどArduinoの「D21」ピンに挿していたジャンパーワイヤーを抜き、そのまま反対側の「D2」ピンに挿し替えてください。

**【プログラムの書き込み】**

1. 以下のコードを書いて検証・書き込みを行います。
    
    ```cpp
    const int ledPin = 2;
    
    void setup() {
      // analogWrite() を使用する場合、pinModeの指定は省略可能
    }
    
    void loop() {
      // 徐々に明るくする
      for (int val = 0; val <= 255; val += 5) {
        analogWrite(ledPin, val);
        delay(20);
      }
      // 徐々に暗くする
      for (int val = 255; val >= 0; val -= 5) {
        analogWrite(ledPin, val);
        delay(20);
      }
    }
    ```
    

<aside>
💡

**PWM（パルス幅変調）とは？**

**`analogWrite()`** は、本当に電圧を1V、2V…と無段階に変えているわけではありません。
「5Vと0Vを超高速（1秒間に数百回）でパチパチと切り替え、5Vを出している時間の割合（パルス幅）を変えることで、人間の目には明るさが変わっているように錯覚させている」のです。これをPWM（Pulse Width Modulation）と呼びます。

- **`analogWrite(ledPin, 255);`** → ずっと5V（100%点灯）
- **`analogWrite(ledPin, 127);`** → 半分の時間だけ5V（50%の明るさに見える）
- **`analogWrite(ledPin, 0);`** → ずっと0V（消灯）
</aside>

## **6-2. シリアルモニタで値を確認する**

読み取ったセンサーの数値をPCの画面に表示させるには、**シリアル通信**という機能を使います。

**【プログラムの書き込み】**

以下のコードを書いて検証・書き込みを行います。

```cpp
const int sensorPin = A7; // センサーを繋いだアナログピン
int sensorValue = 0;      // 読み取った値を保存する変数

void setup() {
  // PCとの通信（シリアル通信）を 9600bps の速度で開始する
  Serial.begin(9600);
}

void loop() {
  // A7ピンの電圧を 0〜1023 の数値として読み取る
  sensorValue = analogRead(sensorPin);

  // 読み取った数値をPCへ送信し、改行する
  Serial.println(sensorValue);

  // 50ミリ秒待つ（早すぎるとPC側がフリーズするため）
  delay(50);
}
```

**【動作確認：シリアルモニタとシリアルプロッタ】**

2. センサーの前に手をかざし、距離を変えると数値が変化することを確認します。
（※このセンサーは、対象物が近いほど数値が大きくなり、遠ざかると小さくなる特性があります）
3. シリアルモニタを一度閉じ、右上の **「波形アイコン（シリアルプロッタ）」** をクリックすると、値の変化がリアルタイムにグラフ化されます。

# 7. サーボモーターの制御と連動

## **7-1. サーボモーターの回路を組む（電源ラインの活用）**

これまでのパーツはArduinoのピンに直接繋いできましたが、センサーやモーターが増えると、Arduino本体にある数少ない「5V」や「GND」のピンがすぐに足りなくなってしまいます。

そこで、ブレッドボードの左右にある「＋（赤線）」**と**「ー（青線）」の列（電源ライン）を使って、電気をタコ足配線のように分配する練習をしましょう。

<aside>
⚠️

**配線間違いに注意**

サーボモーターは動く瞬間に比較的大きな電流を消費します。ブレッドボードの「＋」と「ー」を直接繋いでショートさせたり、モーターの線の色を逆接したりしないよう、電源を入れる（USBを挿す）前にもう一度確認してください。

</aside>

**【配線手順】**

まずは、Arduinoからブレッドボード全体へ電気を供給する「大元の道」を作ります。

![Snapzy_2026-10-01_16-47-15_780.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/Snapzy_2026-10-01_16-47-15_780.png)

1. Arduinoの **5V** ピン → ブレッドボードの **「＋（赤線）」** の列のどこかへ繋ぐ
2. Arduinoの **GND** ピン → ブレッドボードの **「ー（青線）」** の列のどこかへ繋ぐ

<aside>
💡

**ブレッドボードの構造の復習**

中央のエリアは「横方向」に電気が繋がっていましたが、外側の「＋」「ー」の列は「縦方向」に下までズラッと繋がっています。
これで、ブレッドボードの「＋」「ー」の列のどこにジャンパーワイヤーを挿しても、それぞれ「5V」「GND」として使えるようになりました！

</aside>

**【距離センサーを繋ぎ直す】**

1. **赤色の線 (向かって右)：**ブレッドボードの **「＋（赤線）」** の列へ
2. **黒色の線 (中央)：**ブレッドボードの **「ー（青線）」** の列へ
3. **黄色の線 (向かって左)：**Arduinoの **A7** ピンへ

**【サーボモーターを繋ぐ】**

![Snapzy_2026-10-01_17-05-09_838.png](01_Arduino%E3%81%AE%E5%9F%BA%E7%A4%8E/Snapzy_2026-10-01_17-05-09_838.png)

1. サーボモーターの **茶色（または黒）の線：**ブレッドボードの **「ー（青線）」** の列へ
2. サーボモーターの **赤色の線：**ブレッドボードの **「＋（赤線）」** の列へ
3. サーボモーターの **オレンジ（または黄色）の線：**Arduinoの **D2** ピンへ

このように電源ラインを使うことで、今後の授業で「パーツを3つも4つも同時に使う」ときにも対応できるようになります。

## **7-2. プログラムで角度を変える**

サーボモーターを動かすための複雑な通信は、「ライブラリ（便利なプログラムのまとまり）」を読み込むことで簡単に記述できます。まずは基本の動きを確認します。

**【プログラムの書き込み】**

```cpp
#include <Servo.h> // サーボモーター用ライブラリを読み込む

Servo myServo; // 制御用の変数を作成

void setup() {
  myServo.attach(2); // 信号線が「2番ピン」であることを設定
}

void loop() {
  myServo.write(0);   // 0度の位置へ回転
  delay(1000);        // 1秒待機

  myServo.write(90);  // 90度の位置へ回転
  delay(1000);        // 1秒待機

  myServo.write(180); // 180度の位置へ回転
  delay(1000);        // 1秒待機
}
```

書き込み後、モーターが1秒ごとに3つの角度を行き来すれば成功です。

## **7-3. 距離センサーで角度を変える（入力と出力の連動）**

最後に、「距離センサー（入力）」と「サーボモーター（出力）」を連動させます。
センサーから読み取った値（例：100〜500程度）を、サーボモーターの角度（0〜180）に変換して動かします。

**【プログラムの書き込み】**

```cpp
#include <Servo.h>

Servo myServo;
const int sensorPin = A7;
int sensorValue = 0;

void setup() {
  Serial.begin(9600);
  myServo.attach(2);
}

void loop() {
  // 1. センサーの値を読み取る
  sensorValue = analogRead(sensorPin);
  
  Serial.println(sensorValue); // 確認用に出力

  // 2. 読み取った値を角度に変換する（map関数）
  // 構文：map(変換したい値, 現在の最小値, 現在の最大値, 変換後の最小値, 変換後の最大値)
  // ※センサーの最小・最大値（ここでは100と500）は、実際のシリアルモニタの数値に合わせて調整してください
  int angle = map(sensorValue, 100, 500, 0, 180);

  // 3. 角度の範囲を0〜180に制限する（constrain関数）
  // センサーの値が想定より大きくなった時にエラーを防ぐための安全処理です
  angle = constrain(angle, 0, 180);

  // 4. サーボモーターに角度を指示する
  myServo.write(angle);

  delay(30);
}
```

手をかざす距離に合わせて、サーボモーターがリアルタイムに追従して動くようになります。入力と出力が繋がった、インタラクティブなシステムの完成です。

# **8. Web Serial API によるブラウザ連携**

これまで、センサーの値はArduino IDEの「シリアルモニタ」という開発用の画面で確認していました。
しかし、**Web Serial API** という最新の技術を使うと、中継サーバーなどを一切立てることなく、**Webブラウザ（のJavaScript）で直接Arduinoと通信し、値を受け取る**ことができます。

これにより、「手をかざすとWebサイトのデザインが変わる」「物理的な距離に合わせてブラウザ上のアニメーションが動く」といった表現が可能になります。

※サーボモーターは使わないので、外して大丈夫です。

---

## **8-1. Arduino側の準備（データを送信する）**

まずはArduinoから、距離センサーの値をPCに向かってひたすら送信し続けるプログラムを書きます。（※6-2で書いたものとほぼ同じです）

```cpp
const int sensorPin = A7;
int sensorValue = 0;

void setup() {
  // ブラウザ側と通信速度を合わせる（9600bps）
  Serial.begin(9600);
}

void loop() {
  sensorValue = analogRead(sensorPin);
  
  // 値を改行付きで送信する
  Serial.println(sensorValue);
  
  delay(50);
}
```

<aside>
⚠️

**【重要】シリアルモニタを必ず閉じる**

ArduinoとPCの通信ポート（USBの通り道）は、同時に1つのアプリしか使うことができません。
Arduino IDEの「シリアルモニタ」や「シリアルプロッタ」が開いたままだと、この後ブラウザから接続しようとした時にエラーになってしまいます。

**書き込みが終わったら、必ずシリアルモニタのタブを「×」で閉じてください。**

</aside>

---

## **8-2. Webブラウザ側の準備（データを受信する）**

VS Code等のエディタを開き、デスクトップなどに適当なフォルダを作って、以下の **`index.html`** ファイルを作成します。

**`index.html`** 

```markup
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>Web Serial API テスト</title>
  <style>
    body {
      font-family: sans-serif;
      text-align: center;
      margin-top: 50px;
      background-color: #222;
      color: #fff;
    }
    button {
      padding: 10px 20px;
      font-size: 16px;
      cursor: pointer;
    }
    #box {
      width: 100px;
      height: 100px;
      background-color: #00d26a;
      margin: 50px auto;
      border-radius: 10px;
      /* 動きを滑らかにするためのCSSアニメーション */
      transition: transform 0.1s ease-out; 
    }
  </style>
</head>
<body>

  <h1>ブラウザ連携テスト</h1>
  <button id="connect-btn">Arduinoと接続</button>
  <p>距離センサーの値: <span id="val-display">0</span></p>
  
  <!-- この箱の大きさをセンサーで変化させます -->
  <div id="box"></div>

  <script>
    const connectBtn = document.getElementById('connect-btn');
    const valDisplay = document.getElementById('val-display');
    const box = document.getElementById('box');

    // ボタンをクリックした時の処理
    connectBtn.addEventListener('click', async () => {
      try {
        // 1. ポートを選択して開く
        const port = await navigator.serial.requestPort();
        await port.open({ baudRate: 9600 }); // Arduino側のSerial.beginと合わせる
        
        connectBtn.textContent = "接続済み";
        connectBtn.disabled = true;

        // 2. 送られてきたデータをテキストに変換する準備
        const textDecoder = new TextDecoderStream();
        port.readable.pipeTo(textDecoder.writable);
        const reader = textDecoder.readable.getReader();

        let buffer = "";

        // 3. データを継続的に読み込むループ
        while (true) {
          const { value, done } = await reader.read();
          if (done) break;
          
          buffer += value;
          const lines = buffer.split('\n');
          buffer = lines.pop(); // 途切れたデータは次回のループへ残す

          for (const line of lines) {
            // 文字列を数値（整数）に変換
            const num = parseInt(line.trim(), 10);
            
            // 正しい数値が取れた場合のみDOMを更新
            if (!isNaN(num)) {
              valDisplay.textContent = num;
              
              // センサーの値（例:100〜500）を使って、CSSのscale（倍率）を計算
              // ※値が大きくなりすぎないように調整（ここでは数値を200で割る）
              const scaleValue = num / 200;
              box.style.transform = `scale(${scaleValue})`;
            }
          }
        }
      } catch (error) {
        console.error('通信エラー:', error);
      }
    });
  </script>
</body>
</html>
```
