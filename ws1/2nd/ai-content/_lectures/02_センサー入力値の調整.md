# 2. スイッチによるデジタル制御

## 2-1. スイッチの基本と「浮遊（オープン）状態」

タクトスイッチは、押している間だけ回路が繋がり、指を離すと切れる押しボタンスイッチです。

単純に「5V ➔ スイッチ ➔ デジタルピン」と繋ぐだけでは、スイッチから指を離した瞬間にピンがどこにも繋がっていない状態（**オープン／浮遊状態**）になり、空中ノイズを拾って `0` と `1` がデタラメに暴れてしまいます。

**【配線】**

![Snapzy_2026-10-08_22-16-03_696.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/Snapzy_2026-10-08_22-16-03_696.png)

- スイッチの片足 ➔ Arduinoの **D2 ピン**
- スイッチのもう片足 ➔ Arduinoの **GND ピン**

※ スペースが狭いので上手く差し込んでください。

**【プログラムの書き込み】**

以下のコードを書いて検証・書き込みを行います。

```cpp
const int SWITCH_PIN = 2;

void setup() {
  Serial.begin(9600);
  pinMode(SWITCH_PIN, INPUT);
}

void loop() {
  int val = digitalRead(SWITCH_PIN);

  if (val == LOW) { // 押されたとき
    Serial.println("スイッチが押されています！");
  } else {
    Serial.println("離されています");
  }

  delay(50);
}
```

| メソッド / 構文 | 役割・説明 | 備考・注意点 |
| --- | --- | --- |
| **`Serial.begin(通信速度);`** | PCとArduino間のシリアル通信を開始する | 通信速度（転送レート）は **`9600`** bps が標準。シリアルモニタ右下の設定と一致させる必要があります。 |
| **`pinMode(ピン番号, モード);`** | 指定したデジタルピンを「入力」にするか「出力」にするか設定する | モードには **`INPUT`**（通常の入力）、**`OUTPUT`**（LED等の出力）、**`INPUT_PULLUP`**（内蔵プルアップ入力）があります。 |
| **`digitalRead(ピン番号);`** | 指定したデジタルピンの電圧（HIGH / LOW）を読み取る | **`HIGH`**（1 / 約5V）または **`LOW`**（0 / 0V）の2つの値のいずれかを返します。 |
| **`Serial.println(値);`** | シリアルモニタにデータを出力し、**末尾で改行する** | 文字列や変数の値を出力できます。改行せずに横に続けたい場合は **`Serial.print()`** を使います。 |
| **`delay(ミリ秒);`** | 指定した時間（ミリ秒）だけプログラムの実行を一時停止する | **`1000`** で1秒（50ミリ秒＝0.05秒）。マイコンの過度な負荷を抑え、安定動作させるために挟みます。 |

これを防ぐため、通常は**プルアップ抵抗**または**プルダウン抵抗**を回路に入れます。

- **プルアップ抵抗：** 通常時を確実に **`5V (HIGH=1)`** に引っ張り上げ、スイッチを押すと **`GND (LOW=0)`** に落とす。
    
    ![pullup.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/pullup.png)
    
- **プルダウン抵抗：** 通常時を確実に **`GND (LOW=0)`** に落とし、スイッチを押すと **`5V (HIGH=1)`** に上げる。
    
    ![pulldown.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/pulldown.png)

## 2-2. 内部プルアップ（INPUT_PULLUP）

Arduino Nano R4のマイコン内部には、あらかじめ便利なプルアップ抵抗が組み込まれています。

プログラム側で **`pinMode(pin, INPUT_PULLUP)`** と指定するだけで、外付け抵抗を配線することなく、スイッチとGNDを直結するだけで安定した入力が実現できます。

**【プログラムの書き込み】**

以下のコードを書いて検証・書き込みを行います。

```cpp
const int SWITCH_PIN = 2;

void setup() {
  Serial.begin(9600);
  // 内部プルアップを有効化（離すと HIGH=1、押すと LOW=0 になる）
  pinMode(SWITCH_PIN, INPUT_PULLUP);
}

void loop() {
  int val = digitalRead(SWITCH_PIN);

  if (val == LOW) { // 押されたとき
    Serial.println("スイッチが押されています！");
  } else {
    Serial.println("離されています");
  }

  delay(50);
}
```

**【動作確認：シリアルモニタとシリアルプロッタ】**

1. Arduino IDEの右上にある **「虫眼鏡アイコン（シリアルモニタ）」** をクリックします。
2. スイッチを押して値が変化することを確認します。
3. シリアルモニタを一度閉じ、右上の **「波形アイコン（シリアルプロッタ）」** をクリックすると、値の変化がリアルタイムにグラフ化されます。

# 3. 明るさセンサー（CdSセル）の認識

## 3-1. CdSセルとは？

**CdS（硫化カドミウム）セル**は、光の強さ（照度）によって電気抵抗が変化する光センサー素子です。

- **明るいとき：** 抵抗が小さくなる（電流が流れやすい）→ 値は大きくなる
- **暗いとき（手で覆ったとき）：** 抵抗が大きくなる（電流が流れにくい）→ 値は小さくなる

極性（プラス・マイナスの向き）はありません。どちら向きに挿しても動作します。

---

## 3-2. CdSセルの回路を組む

<aside>
⚠️

**安全のための注意**

回路を組み替える際は、**必ずUSBケーブルをPCから抜いてから作業してください。**

</aside>

**【配線手順】**

![Snapzy_2026-10-08_22-47-20_383.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/Snapzy_2026-10-08_22-47-20_383.png)

1. **CdSセルの片足** を **Arduinoの 5V** へ挿す。
2. CdSセルの **もう片足** を、別の空いている行へ挿す。
3. その行に **10kΩ抵抗（茶黒橙金）の片足** を挿す。
4. 同じ行からジャンパーワイヤーを伸ばし、**Arduinoの A7 ピン** へ繋ぐ。
5. 10kΩ抵抗の **もう片足** を、**Arduinoの GND** ピンへ繋ぐ。

**【プログラムの書き込み】**

1. 以下のコードを書いて検証・書き込みを行います。
2. 手でCdSセルを覆って暗くしたり、スマホのライトを当てたりして、シリアルモニタで数値が変化することを確認しましょう。

```cpp
const int CDS_PIN = A7;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // A7ピンのアナログ電圧を読み取る
  int lightValue = analogRead(CDS_PIN);

  Serial.print("Light Value: ");
  Serial.println(lightValue);

  delay(50);
}
```

| メソッド / 構文 | 役割・説明 | 備考・注意点 |
| --- | --- | --- |
| **`analogRead(アナログピン番号);`** | 指定したアナログピン（A0〜A7）の電圧を数値として読み取る | **`0V〜5V`** の電圧を、**`0 〜 1023`**（10ビットの整数値）に変換して返します。 |
| **`Serial.print(値);`** | シリアルモニタにデータを出力する（**改行しない**） | **`Serial.println()`** と違い、末尾で改行しません。
「項目名」を出力した直後に数値を並べて表示したい場合などに使います。 |

<aside>
💡

**なぜアナログピン（A0〜A7）には `pinMode()` の設定が不要なのか？**

アナログピンは最初から「電圧を読み取る（入力）」専用の回路（ADコンバータ）として設計されているため、**`setup()`** 内で **`pinMode()`** を宣言する必要がありません。そのまま **`analogRead()`** を呼び出すだけで値を取得できます。

</aside>

# 4. 距離センサーの認識（復習）

## 4-1. 距離センサー（シャープ測距モジュール）の配線復習

第1回でも扱った、赤外線で手や物との距離を測るセンサー（GP2Y0A21YK）を復習しましょう。

**【配線手順】**

![Snapzy_2026-10-01_16-38-29_543.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/Snapzy_2026-10-01_16-38-29_543.png)

2. **黒色の線 (中央)：**Arduinoの **GND** ピンへ
3. **黄色の線 (向かって左)：**Arduinoの **A7** ピンへ

## 4-2. `analogRead()` によるアナログ値の取得

距離センサーは、手との距離に応じた電圧（約0.4V〜2.5V）を出力します。
Arduinoはこれを **`0 〜 1023`** の数値（アナログ値）として読み取ります。

```cpp
const int DISTANCE_PIN = A7;

void setup() {
  Serial.begin(9600);
  // アナログ入力ピンはピンモード設定（pinMode）不要
}

void loop() {
  // A7ピンから値を読み取る（距離に応じておよそ 50〜650 で変化）
  int distanceValue = analogRead(DISTANCE_PIN);

  Serial.print("Distance Value: ");
  Serial.println(distanceValue);

  delay(50);
}
```

## **4-3. シリアルモニタとシリアルプロッタで「揺らぎ」を観察する**

1. プログラムを書き込み、画面右上の「シリアルモニタ」を開きます。
2. 手を近づけたり遠ざけたりして、距離に応じて数値が変わることを確認します。
3. 次に、その隣の「**シリアルプロッタ**」を開いてみましょう。

<aside>
⚠️

**シリアルプロッタには「数値のみ」を送ることに注意**

Arduino IDEのシリアルプロッタは、文字列（テキスト）が混ざると波形グラフが正しく描画されません。  
そのため、プロッタで波形を観察する際は `Serial.print("Distance: ");` などの文字出力をコメントアウトし、**数値だけ**を `Serial.println()` で送信するようにしてください。

```cpp
const int DISTANCE_PIN = A7;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int distanceValue = analogRead(DISTANCE_PIN);

  // 文字列は出力せず、数値だけを送る！
  // Serial.print("Distance Value: ");
  Serial.println(distanceValue);

  delay(50);
}
```

</aside>

手を動かさずにじっと止めていても、波形が小刻みにトゲトゲと激しく震えている（**ジッター・揺らぎ**）のが観察できます。

赤外線反射を使う距離センサーは、光の環境や反射角度の影響を受けやすく、**CdSセルよりもはるかに値の揺らぎが大きい**という特徴があります。

もしこの生の数値をそのままサーボモーターの角度に送ってしまうと、モーターが「ジジジジ…！」と常に小刻みに震え続け、異音や故障の原因になってしまいます。

そのため、次のステップである「値の加工」と「ゆらぎの軽減」が不可欠になります。

# 5. センサー値の加工（適切な範囲への変換）

## 5-1. 生データの3大問題

ここまでで、入力パーツ（スイッチ、明るさセンサ、そして激しい揺らぎを持つ距離センサ）が出揃いました。

しかし、センサーの生データ（**`analogRead`**）をそのままモーターなどの出力に使おうとすると、以下の問題が発生します。

1. **測定範囲が中途半端：**距離センサーは約 `50〜650`、CdSは約 `150〜850` など、部品や部屋の環境でバラバラ。
2. **出力パーツと範囲が合わない：**
    - サーボモーターが受け付ける角度は **`0 〜 180`** 度。
    - 振動モーターやLEDのPWM制御は **`0 〜 255`**。
    
3. **外乱ノイズで値が飛び跳ねる：**想定外の大きな値や小さな値が一瞬混ざる。

これを解決するのが **`constrain()`** と **`map()`** 関数です。

---

## 5-2. `constrain()`：値を一定範囲に制限する

測定値が想定外の範囲に飛び出さないよう、最小値と最大値の間に強制的に収めます。

```cpp
int distanceValue = analogRead(DISTANCE_PIN);

// 書式: constrain(制限したい値, 最小値, 最大値);
int safeValue = constrain(distanceValue, 100, 600);

Serial.println(safeValue);
```

- もし **`distanceValue`** が 700 なら ➔ **`600`** にクリップ
- もし **`distanceValue`** が 30 なら ➔ **`100`** にクリップ

---

## 5-3. `map()`：範囲を別の範囲へ比率変換する

ある数値範囲を、目的の出力範囲へ一発でスケーリング（伸縮）します。

```cpp
int distanceValue = analogRead(DISTANCE_PIN);
int safeValue = constrain(distanceValue, 100, 600);

// 書式: map(変換したい値, 変換前最小, 変換前最大, 変換後最小, 変換後最大);
int angle = map(safeValue, 100, 600, 0, 180);

Serial.println(angle);
```

**【コード例：変数でわかりやすく整理する】**

```cpp
const int SENSOR_PIN = A7; // 距離センサー

// 事前にシリアルモニタで実測して決めた最小値・最大値
const int SENSOR_MIN = 100;
const int SENSOR_MAX = 600;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);

  // 1. まず異常値を切り詰める
  int clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);

  // 2. サーボモーターの角度（0〜180度）に変換
  int angle = map(clamped, SENSOR_MIN, SENSOR_MAX, 0, 180);

  Serial.print("Raw:");
  Serial.print(raw);
  Serial.print(" -> Angle:");
  Serial.println(angle);

  delay(30);
}
```

| メソッド / 関数 | 役割・説明 |
| --- | --- |
| **`constrain(x, a, b);`** | 数値 **`x`** を最小値 **`a`** と最大値 **`b`** の範囲内に強制的に収める |
| **`map(x, in_min, in_max, out_min, out_max);`** | 数値 `x` を、現在の範囲から目的の範囲へ比率変換（スケーリング）する |

# 6. ゆらぎの軽減（フィルタリング処理）

センサーに手を触れていなくても、シリアルモニタをよく観察すると、値が `245`, `248`, `244`, `246` のように微小に揺らいでいます（空気中の電気ノイズや環境光の細かな変化）。

この生の値をそのままサーボモーターに送ると、**サーボのギアが「ジジジジ…」と小刻みに震え続け、異音・発熱・ギアの摩耗の原因**になります。

**【ゆらぎを軽減する3つのアプローチ】**

| 手法 | 仕組み | メリット | デメリット |
| --- | --- | --- | --- |
| **① 分解能を下げる** | 端数を10などで切り捨てる（**`val / 10 * 10`**） | 計算が最も簡単 | 動きが階段状にカクカクする |
| **② 単純移動平均** | 20回測って合計し平均を出す | ゆらぎがしっかり消える | ループが重くなりレスポンス低下 |
| **③ 指数平滑フィルタ** | 過去の値9割 ＋ 今回の値1割で更新 | **超軽量でヌルヌル滑らか！** | わずかな追従の遅れ（調整可能） |

---

## 6-1. 指数平滑（RCローパスフィルタ）で滑らかにする

**「前回の値の9割 ＋ 新しく読み取った値の1割」** をブレンドして滑らかに更新していく手法です。

$$
\text{現在の値} = (1 - \alpha) \times \text{過去の値} + \alpha \times \text{今回の測定値} \quad (0 < \alpha \le 1)
$$

```cpp
const int SENSOR_PIN = A7; // 距離センサー（揺らぎが大きいピン）

const int SENSOR_MIN = 100;
const int SENSOR_MAX = 600;

// 滑らかに追従させたい現在値（初期値は0）
float currentAngle = 0;
const float FILTER_WEIGHT = 0.1; // 0.1＝重み10%（追従速度：小さいほど滑らか・大きいほど機敏）

void setup() {
  Serial.begin(9600);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);

  // 1. 【第5章の加工】生データを制限し、目標の角度（0〜180度）へ加工する
  int clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
  int targetAngle = map(clamped, SENSOR_MIN, SENSOR_MAX, 0, 180);

  // 2. 【第6章のフィルタ】加工した目標値（targetAngle）に向かって、現在値を滑らかに追従させる！
  currentAngle = (1.0 - FILTER_WEIGHT) * currentAngle + FILTER_WEIGHT * targetAngle;

  // ★シリアルプロッタで「加工直後のガタつく目標値」と「滑らかに追従する値」を2本同時に比較表示！
  Serial.print("Target:");
  Serial.print(targetAngle);
  Serial.print(" Smoothed:");
  Serial.println((int)currentAngle);

  // 値を微調整
  delay(20);
}
```

**【シリアルプロッタで効果を確認】**

このプログラムを書き込んで「シリアルプロッタ」を開くと、**トゲトゲ激しく震える「Raw（生データ）」の線に対し、「Filtered（平滑化データ）」の線が驚くほど滑らかな美しい曲線を描いて追従する様子**が2色でリアルタイムに確認できます。

# 7. モーターを動かす（フィジカル出力）

## 7-1. サーボモーターの制御（角度 0〜180度）

サーボモーターは、プログラムで指定した角度（0度〜180度）へ軸を正確に回転・静止させることができるアクチュエータです。

**【配線手順】**

![Snapzy_2026-10-01_17-05-09_838.png](02_%E3%82%BB%E3%83%B3%E3%82%B5%E3%83%BC%E5%85%A5%E5%8A%9B%E5%80%A4%E3%81%AE%E8%AA%BF%E6%95%B4/Snapzy_2026-10-01_17-05-09_838.png)

- サーボモーターの **茶色（または黒）の線：**ブレッドボードの **「ー（青線）」** の列へ
- サーボモーターの **赤色の線：**ブレッドボードの **「＋（赤線）」** の列へ
- サーボモーターの **オレンジ（または黄色）の線：**Arduinoの **D2** ピンへ

**【まずは「フィルタなし」で動かしてみる（問題の体感）】**

第5章で学んだ加工（`constrain` と `map`）だけで、フィルタをかけずにそのままサーボモーターを動かしてみましょう。

```cpp
#include <Servo.h>

const int SENSOR_PIN = A7; // 距離センサー
const int SERVO_PIN = 2;   // サーボ信号線
Servo myServo;

const int SENSOR_MIN = 100;
const int SENSOR_MAX = 600;

void setup() {
  Serial.begin(9600);
  myServo.attach(SERVO_PIN);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);

  // 加工した目標角度をそのままサーボに送る（フィルタなし）
  int clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
  int angle = map(clamped, SENSOR_MIN, SENSOR_MAX, 0, 180);

  myServo.write(angle);

  Serial.print("Angle:");
  Serial.println(angle);

  delay(20);
}
```

**【指数平滑フィルタ」を入れて動かしてみる】**

次に、加工した目標角度（`targetAngle`）に対して、第6章の指数平滑フィルタを入れて動かしてみましょう。

```cpp
#include <Servo.h>

const int SENSOR_PIN = A7; // 距離センサー
const int SERVO_PIN = 2;   // サーボ信号線
Servo myServo;

const int SENSOR_MIN = 100;
const int SENSOR_MAX = 600;

// 滑らかに追従させる現在値（初期値は0）
float currentAngle = 0;
const float FILTER_WEIGHT = 0.1; // 滑らかさの調整（0.05〜0.2：小さいほど滑らか）

void setup() {
  Serial.begin(9600);
  myServo.attach(SERVO_PIN);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);

  // 1. 【値の加工】生データを制限し、目標の角度（0〜180度）を計算
  int clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
  int targetAngle = map(clamped, SENSOR_MIN, SENSOR_MAX, 0, 180);

  // 2. 【ゆらぎ軽減】加工した目標角度に、現在値をじわっと滑らかに追従させる！
  currentAngle = (1.0 - FILTER_WEIGHT) * currentAngle + FILTER_WEIGHT * targetAngle;

  // 3. 【出力】滑らかになった角度をサーボモーターに出力
  myServo.write((int)currentAngle);

  // デバッグ用表示（シリアルプロッタ対応）
  Serial.print("Target:");
  Serial.print(targetAngle);
  Serial.print(" Current:");
  Serial.println((int)currentAngle);

  delay(20);
}
```

| メソッド / 構文 | 役割・説明 | 備考・注意点 |
| --- | --- | --- |
| **`#include <Servo.h>`** | サーボモーターを動かすためのArduino標準ライブラリを取り込む | プログラムの一番先頭に記述します。自前で難しいPWM波形を作らなくても、角度指定だけで制御できるようになります。 |
| **`Servo 変数名;`** | サーボモーターを操作するためのインスタンス（変数）を宣言する | 例: **`Servo myServo;`** と宣言することで、以降 **`myServo.〜`** という形式で命令を出せるようになります。 |
| **`サーボ変数.attach(ピン番号);`** | サーボモーターの信号線を接続したデジタルピンを割り当てる | **`setup()`** の中で1回だけ実行します。 |
| **`サーボ変数.write(角度);`** | サーボモーターの軸を指定した角度（**`0 〜 180`**度）へ回転・保持させる | 角度の数値を渡すだけで、内部のモーターが自動でその角度まで回転してピタッと止まります。 |
| **`(int)小数変数`** | 小数（float）の小数点以下を切り捨てて整数（int）に変換する | **`constrain`** や **`map`** は整数を前提としているため、指数平滑で計算した小数を安全に整数へ整えるために使います。 |

## 7-2. 振動モーターの制御（PWMアナログ出力 0〜255）

携帯電話のバイブレーションのような小型振動モーターです。**`analogWrite()`** を使うことで、振動の強さを **`0`**（停止）〜 **`255`**（最強）で制御できます。

**【配線手順】**

- **青色の線（マイナス）：** Arduinoの **GND**
- **赤色の線（プラス）：** Arduinoの **D3 ピン**（PWM対応「~」ピン）  
  ※ArduinoのD2ピンはPWM非対応のため、基板上で「~」マークが付いているD3ピンを使用します。

```cpp
const int SENSOR_PIN = A7; // 例: 明るさセンサー（CdS）
const int MOTOR_PIN = 3;   // 振動モーター（PWM対応ピン）

const int SENSOR_MIN = 150;
const int SENSOR_MAX = 800;

// 滑らかに追従させる現在のパワー
float currentPower = 0;
const float FILTER_WEIGHT = 0.1;

void setup() {
  Serial.begin(9600);
  pinMode(MOTOR_PIN, OUTPUT);
}

void loop() {
  int raw = analogRead(SENSOR_PIN);

  // 1. 【値の加工】センサー値を制限し、目標のパワー（0〜200）を計算
  int clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
  int targetPower = map(clamped, SENSOR_MIN, SENSOR_MAX, 0, 200);

  // 2. 【ゆらぎ軽減】加工した目標パワーに向かって滑らかに追従
  currentPower = (1.0 - FILTER_WEIGHT) * currentPower + FILTER_WEIGHT * targetPower;

  // 3. 【出力】滑らかになったパワーを振動モーターに出力
  analogWrite(MOTOR_PIN, (int)currentPower);

  delay(20);
}
```

| メソッド / 構文 | 役割・説明 | 備考・注意点 |
| --- | --- | --- |
| **`analogWrite(ピン番号, 出力値);`** | 指定したPWM対応ピンから、疑似的なアナログ電圧（PWM信号）を出力する | 出力値は `0`（完全停止 / 0V）〜 `255`（フルパワー / 5V）の256段階。超高速でON/OFFを繰り返す比率（デューティ比）を変えることで、振動の強さやLEDの明るさを滑らかに調節できます。 |

# 9. （発展）次週へのステップ：Web連携でのデータ正規化とLerp

今回Arduino側で学んだ「目標値に向かって現在値を滑らかに追従させる式」：

```cpp
currentAngle = (1.0 - weight) * currentAngle + weight * targetAngle;
```

実はこの式、数学的に整理すると以下のように書き換えることができます：

$$
\text{currentAngle} = \text{currentAngle} + (\text{targetAngle} - \text{currentAngle}) \times \text{weight}
$$

つまり、**「現在の位置から目標の位置までの距離を測り、その10%ずつ近づく」** という計算をしています。

そしてこの数式は、**次週以降のJavaScript（ブラウザ表現）で頻出する「Lerp（ラープ / Linear Interpolation: 線形補間）」と全く同じコード**です！

```javascript
// JavaScriptでのイージング（Lerp追従）
// 1. センサー値から目標座標（targetX）を計算
let targetX = map(sensorValue, 0, 1, 0, windowWidth);

// 2. 目標座標に向かって、現在位置（currentX）を滑らかに追いつかせる！
currentX += (targetX - currentX) * 0.1;
```

さらに、センサーの生データを `0.0 〜 1.0`（0%〜100%）に換算しておく（**正規化 / Normalize**）ことで、次回扱う「連番画像アニメーションのコマ送り」や、その後の「p5.js」「Tone.js」のあらゆる演出パラメータに自在に接続できるようになります。

次回は、この正規化したセンサー値を使って、**パラパラマンガのように画像が滑らかに切り替わる「センサー連動フレームアニメーション」**に挑戦します。お楽しみに！
