## 2-2. Arduinoプログラム（1つの距離値をシンプルに送信）

アナログピン（A7）から距離センサーの電圧を読み取り、1行に1つの数値をPCへ送信します。

```cpp
void setup() {
  Serial.begin(9600); // 転送レート 9600bps でシリアル通信開始
}

void loop() {
  Serial.println(analogRead(A7)); // A7ピンのアナログ値（0〜1023）を読み取ってPCへ送信（改行付き）

  delay(20); // 20ミリ秒待機（1秒間に約50回送信）
}
```

**【動作確認と重要ルール】**

1. コードをArduino Nano R4に書き込みます。
2. Arduino IDE右上の **「シリアルモニタ」** を開き、`320` や `450` などの数値が1行ずつ流れることを確認します。
3. センサーの前に手をかざし、手を近づけると数値が大きくなり、遠ざけると小さくなることを確かめます。
4. **確認したら、必ずArduino IDEのシリアルモニタを「閉じて」ください。**
(シリアルモニタが開いていると、ブラウザのWeb Serial APIがポートを占有できず接続エラーになります)

```jsx
let isConnected = false;

// シリアル通信の接続と受信を行う関数
const connect = async () => {
    try {
        // 1. シリアルポートを選択して開く（転送レート 9600bps）
        const port = await navigator.serial.requestPort();
        await port.open({ baudRate: 9600 });
        isConnected = true;
        console.log("🟢 Arduinoに接続しました");

        // 2. 受信バイト列を文字列（UTF-8）に変換する準備
        const textDecoder = new TextDecoderStream();
        port.readable.pipeTo(textDecoder.writable);
        const reader = textDecoder.readable.getReader();

        let buffer = '';

        // 3. 受信ループ（データが届くたびに繰り返し実行）
        while (true) {
            const { value, done } = await reader.read();
            if (done) break;

            buffer += value;
            const lines = buffer.split('\n');
            buffer = lines.pop(); // 未完了の行をバッファに残す

            for (const line of lines) {
                const trimmed = line.trim();
                if (!trimmed) continue;

                // 文字列から整数へ変換
                const raw = parseInt(trimmed, 10);
                if (!isNaN(raw)) {
                    // ★ コンソールに出力して確認！
                    console.log("生データ (raw):", raw);
                }
            }
        }
    } catch (err) {
        console.error("シリアル接続エラー:", err);
    }
}

// キーボードの [C] キーが押されたときに connect() を実行
window.addEventListener('keydown', (e) => {
    if ((e.key === 'c' || e.key === 'C') && !isConnected) {
        connect();
    }
});

```

# 4. シリアル通信を独立した部品にする

## 4-1. なぜ通信処理を独立させるのか？（p5.js非依存の部品化）

Web Serial API の接続処理や非同期受信ループは、毎回記述するにはコード量が多く複雑です。
また、この通信処理を p5.js のコードと混ぜてしまうと、再利用性が失われてしまいます。

そこで、**「シリアル通信でデータを受信し、最新の生データ（`raw`）を保持する」機能だけに特化した独立ファイルとなるように修正**します。

このモジュールは **p5.js に一切依存しない純粋な JavaScript（Vanilla JS）** で作られているため、次週以降の音響合成（Tone.js）や他のWeb制作でもそのまま使い回すことができます。

```

├── js/
│   ├── sensor.js    # 【再利用部品】シリアル通信受信モジュール（純粋なJS）
│   ├── sketch.js    # 【ハブ】p5.js によるデータ加工 ＆ アート制御
```

## 4-2. 独立モジュール `sensor.js` の全貌

 **`js/sensor.js`** 

```jsx
/**
 * sensor.js - Arduino シリアル通信受信モジュール
 * -------------------------------------------------------------
 * Web Serial API を用いて Arduino からのシリアル通信を受信し、
 * 生の数値（Sensor.raw）を保持するだけの純粋な JavaScript モジュールです。
 */

const Sensor = {
  isConnected: false, // Arduinoと接続中かどうか
  raw: 0,             // センサーから届いた最新の生値（0〜1023）

  // Web Serial API で Arduino への接続を開始する
  async connect() {
    if (!('serial' in navigator)) {
      alert('Google Chrome または Microsoft Edge を使用してください。');
      return false;
    }

    try {
      // 1. ポートを選択して開く（転送レート 9600bps）
      const port = await navigator.serial.requestPort();
      await port.open({ baudRate: 9600 });
      this.isConnected = true;
      console.log('🟢 Arduinoに接続しました');

      // 2. 受信ストリームを文字列としてデコード
      const textDecoder = new TextDecoderStream();
      port.readable.pipeTo(textDecoder.writable);
      const reader = textDecoder.readable.getReader();

      let buffer = '';

      // 3. 受信ループ（第3章のコードと全く同じ構造です）
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;

        buffer += value;
        const lines = buffer.split('\n');
        buffer = lines.pop(); // 未完了の行をバッファに残す

        for (const line of lines) {
          const trimmed = line.trim();
          if (!trimmed) continue;

          // 文字列から整数へ変換
          const num = parseInt(trimmed, 10);
          if (!isNaN(num)) {
            // ★ 第3章で console.log していた値を、変数に保持するだけ！
            this.raw = num;
          }
        }
      }
    } catch (err) {
      console.error('シリアル接続エラー:', err);
    }
  }
};
```

このモジュールを読み込んでおけば、スケッチ側からは **`Sensor.connect()`** を自由に呼び出し、 **`Sensor.raw`** を参照するだけで、いつでも最新のアナログ値（生データ）を取得できます。

## 4-4. コンソールから分かる「生データ」の3つの課題

コンソールに出力される数値をよく観察すると、生データをそのままグラフィックの描画に利用できない理由が分かります。

1. **課題①：突発的な外れ値（ノイズ）の混入**
    
    手を素早く動かしたり、センサーの測定限界（10cm未満または80cm以上）から外れた瞬間、突発的に `800` や `30` といった極端な数値が混ざることがあります。
    
2. **課題②：数値の範囲が直感に反して扱いにくい**
    
    手元で動かしても、数値は「遠くで約100 〜 近くで約600」といった中途半端な範囲です。これをそのまま画面上の座標や色相、回転角に使うと、計算が複雑になります。
    
3. **課題③：手を静止させていても小刻みに数値がブレる（チャタリング）**
    
    手を空中でピタッと静止させていても、コンソールには `342, 345, 340, 344` と毎フレーム小刻みにブレた値が出力されます。このブレをそのまま図形の位置やサイズに反映すると、画面上でプルプルと細かく震えてしまいます。
    

p5.js が提供する関数（`constrain`、`map`、`lerp`）を使って、この生データをグラフィック描画に適した滑らかな値へと加工していきましょう。

## 5-1. ステップ1：`constrain()` で範囲外の数値を制限する

`constrain()` は、指定した数値を **「最小値」と「最大値」の範囲内に収める関数** です。

 **`js/sketch.js`** 

```jsx
if (Sensor.isConnected) {
  let raw = Sensor.raw;
	
	// 書式: constrain(調べる値, 最小値, 最大値);
	let clamped = constrain(raw, 100, 600);
	
	console.log("生値:", raw, "➔ constrain後:", clamped);
		.
		.
		.
}
```

<aside>
💡

**なぜ最初に行うのか？**

突発的な外れ値をこの段階で遮断しておくことで、後続の `map()` による計算結果が想定範囲外に飛び出すのを防ぎます。

</aside>

## 5-2. ステップ2：`map()` で「0.0 〜 1.0」に正規化する

`map()` は、ある範囲の数値を **別の範囲の数値へ比率を保ったまま変換する関数** です。

 **`js/sketch.js`** 

```jsx
if (Sensor.isConnected) {
  let raw = Sensor.raw;
	let clamped = constrain(raw, 100, 600);
	
	// 書式: map(変換したい値, 現在の最小, 現在の最大, 変換後の最小, 変換後の最大);
	sensorTarget = map(clamped, 100, 600, 0.0, 1.0);
	
	console.log("生値:", raw, "➔ 正規化値:", sensorTarget.toFixed(2));
		.
		.
		.
}
```

<aside>
💡

**なぜ「0.0 〜 1.0」にするのか？（正規化の利点）**

`0.0 〜 1.0` は、百分率でいう **「0% 〜 100%」** と同じです。
このように値を特定の統一規格（0.0〜1.0）に揃えることを **正規化（Normalization）** と呼びます。

正規化値にしておくと、後からどのような描画パラメータにも掛け算ひとつで直接適用できます：

- 円の半径に使いたい場合：`sensorTarget * 300`（0px 〜 300px に変化）
- 色相（Hue）に使いたい場合：`sensorTarget * 360`（赤から一巡して赤へ変化）
- 回転速度に使いたい場合：`sensorTarget * 0.05`（静止から高速回転へ変化）
- 透明度に使いたい場合：`map(sensorTarget, 0, 1, 20, 100)`

「手が最も遠いときが `0.0`、最も近いときが `1.0`」という基準ができるため、表現の設計が格段に扱いやすくなります。

</aside>

---

## 5-3. ステップ3：`lerp()` で滑らかに追従させる（平滑化）

正規化によって `0.0 〜 1.0` に変換できましたが、手の静止時でも値が小刻みに変動する問題は残っています。
ここで使用するのが **`lerp()`（線形補間: Linear Interpolation）** です。

`lerp()` は、**「現在の値から目標値に向かって、指定した割合だけ段階的に近づける関数」** です。

 **`js/sketch.js`** 

```jsx
if (Sensor.isConnected) {
  let raw = Sensor.raw;
	let clamped = constrain(raw, 100, 600);
	sensorTarget = map(clamped, 100, 600, 0.0, 1.0);
	
	// 書式: lerp(現在の値, 目標の値, 近づく割合);
	sensorValue = lerp(sensorValue, sensorTarget, 0.08);
	
	console.log("生値:", raw, "➔ 値:", sensorValue.toFixed(2));
		.
		.
		.
}
```

**【計算の仕組み】**

```jsx
次の現在値 = 現在値 + (目標値 - 現在値) × 割合
```

毎フレーム（秒間60回）実行される `draw()` の中で `lerp(..., 0.08)` を呼び出すと、以下の動作特性が得られます。

1. **差が大きいとき（手を急に動かした瞬間）**:
    
    目標値との差が大きいため、8%分の移動量も大きくなり、**素早く目標値に向かって加速** します。
    
2. **差が小さいとき（目標値に近づいたとき）**:
    
    目標値との差がわずかになるため、8%分の移動量も小さくなり、**自然に減速してピタッと安定** します。
    

この動作はアニメーションにおける **イージング（緩急）** と同じ効果をもたらします。

## 5-4. 3関数のデータパイプラインまとめ

| 順番 | 関数名 | 処理内容 | 目的・効果 |
| --- | --- | --- | --- |
| **1** | **`constrain(raw, 100, 600)`** | **【範囲制限】** 値を 100〜600 の間に制限 | センサーの突発的なノイズ・外れ値を遮断する |
| **2** | **`map(clamped, 100, 600, 0.0, 1.0)`** | **【正規化】** 生値を 0.0（遠い）〜 1.0（近い）の割合に変換 | 各種描画パラメータに掛け算で適用しやすくする |
| **3** | **`lerp(current, target, 0.08)`** | **【平滑化】** 現在値を目標値へ毎フレーム8%ずつ追従 | 手のブレを吸収し、滑らかな加減速動作を作る |

```jsx
const LERP_RATE  = 0.08;   // 平滑化の追従スピード（0.02: ゆったり 〜 0.15: 素早い）

let sensorTarget = 0.2;    // 目標値（0.0: 遠い 〜 1.0: 至近）

function setup() {

	  imageMode(CENTER);
	  angleMode(DEGREES);
    textSize(24);

}

function draw() {
    background(20);

    if (Sensor.isConnected) {
        let raw = Sensor.raw;
        let clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
		    sensorTarget = map(clamped, SENSOR_MIN, SENSOR_MAX, 0.0, 1.0);
        sensorValue = lerp(sensorValue, sensorTarget, LERP_RATE);
        console.log("生値:", raw, "➔ 値:", sensorValue.toFixed(2));

        fill(0, 255, 204);

    }

function keyPressed() {
```

# 6. クラス（Class）の基礎

ここからは、このセンサー値を使って **「生き物のように自律して動くジェネラティブグラフィック」** を作っていきます。
そのために不可欠となるのが、JavaScriptの **「クラス（Class）」** という仕組みです。

## 6-1. クラスとは何か？（設計図と実体）

クラスとは、**「プロパティ（状態や設定）」** と **「メソッド（動作や振る舞い）」** を1つにまとめた **「雛形（設計図）」** のようなものです。

クラスという設計図から作られた実体のオブジェクトを **「インスタンス」** と呼びます。

- **クラスの宣言**: `class Orb { ... }`（クラス名の先頭文字は大文字にするのが慣例）
- **コンストラクタ**: `constructor(...) { ... }`（オブジェクト生成時に1度だけ呼び出される特別な初期化処理）
- **プロパティ**: `this.x = x;`（オブジェクト固有の状態や変数。必ず `this.` をつける）
- **メソッド**: `update() { ... }`（オブジェクトの動作・振る舞い。クラスの直下に定義）
- **インスタンス化**: `const myOrb = new Orb();`（`new` 演算子を使って設計図から実体を生み出す）

## 6-2. ステップ1：まずはクラスを使わずに1つだけ動かしてみる（前回の復習）

まずは前回の単元3で学んだ **「ジェネラティブ表現の5大数理」** をコードを書き足しながら順番に復習していきましょう。
静止した1つの円が、段階的に命を吹き込まれ、幻想的な「発光オーブ」へと進化していくプロセスを体験します。

**【復習する5大要素】**

1. **HSBカラーモード**：色相（0〜360度）、彩度、明度で直感的に配色
2. **アルファ付き背景**：`background(H, S, B, Alpha)` で幻想的な残像エフェクト
3. **パーリンノイズ（`noise`）**：カクカクせず滑らかに有機的に位置を揺らす
4. **三角関数（`sin`）**：呼吸のようにサイズを脈動させる
5. **座標変換（`translate`, `push` / `pop`）**：原点を中心に置いて描画

**【初期状態】ただの円を画面に1つ描く**

まずは `circle()` で画面中央に円を置くだけの最もシンプルなコードです。

**【復習① HSBカラーモード】光が滲み出るような発光感を作る**

RGBではなく、**HSBモード（色相 Hue: 0〜360度 / 彩度 Saturation / 明度 Brightness）** を設定します。
同心円を2重に重ね、外側を半透明（アルファ 40%）にすることで、内側から光が滲み出ているような質感を演出します。

**`js/sketch.js`**

**【復習② 三角関数（`sin`）】呼吸のような脈動アニメーションをつける**

サイズに `sin(frameCount * 速度) * 振幅` を加えることで、まるで生き物が息をしているように、規則正しく滑らかに膨張・収縮する動きを作ります。

**`js/sketch.js`**

```jsx
let x = 300;
let y = 300;
let baseSize = 40;
let hueValue = 200;

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);

function draw() {

  fill(hueValue, 60, 100, 90);
  circle(x, y, currentSize);

```

**【復習③ パーリンノイズ（`noise`）】有機的な浮遊とゆらぎを与える**

`random()` だと激しく痙攣してしまいますが、**`noise()`** を使うことで、水面を漂うプランクトンのように滑らかに位置が揺らぎます。
（※ 前回学んだ通り、X軸とY軸で波が同じにならないよう `+ 100` のオフセットをつけます）

**`js/sketch.js`**

```jsx
let baseSize = 40;
let hueValue = 200;
let timeOffset = 0; // ノイズ用の時間オフセット

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);
  noStroke();
}

function draw() {
  background(220, 30, 10);

  // ★ パーリンノイズで滑らかな座標のゆらぎを作る
  timeOffset += 0.01;
  let moveX = (noise(timeOffset) - 0.5) * 300;
  let moveY = (noise(timeOffset + 100) - 0.5) * 300; // Y軸はオフセットをずらす

  let currentX = width / 2 + moveX;
  let currentY = height / 2 + moveY;

  let pulse = sin(frameCount * 3) * 15;
  let currentSize = baseSize + pulse;

  // 外側の淡い光
  fill(hueValue, 80, 100, 40);
  circle(currentX, currentY, currentSize * 1.8);

  // 中心の核
  fill(hueValue, 60, 100, 90);
  circle(currentX, currentY, currentSize);
}
```

**【復習⑤ 座標変換（`translate` と `push`/`pop`）】基準座標を整理する（クラス化への布石）**

直接 `circle(currentX, currentY, ...)` と描画する代わりに、**`push() ➔ translate() ➔ pop()`** を使ってキャンバスの原点（0, 0）をオーブの中心へ移動させてから描画します。
こうすることで、「オーブ自身の中心から見た相対座標」でコードが書けるようになり、次のステップである **「クラス化」** が格段にスムーズになります。

**`js/sketch.js`**

```jsx
let baseSize = 40;
```

## 6-3. ステップ2：複数に増やそうとすると…？（クラスが必要な理由）

「この幻想的なオーブを、画面いっぱいに **30個、50個** と増やして群れ（自律的集合体）にしたい！」と思ったとします。
もしクラスを使わずにこれを実現しようとすると、どうなるでしょうか？

```jsx
// 1個目のオーブ
let x1, y1, baseSize1, hue1, offset1;
// 2個目のオーブ
let x2, y2, baseSize2, hue2, offset2;
// 3個目のオーブ
let x3, y3, baseSize3, hue3, offset3;
// ... 50個分書く！？

function draw() {
  // 1個目の計算と描画...
  // 2個目の計算と描画...
  // 3個目の計算と描画...
  // ➔ コードが数百行のコピペ地獄になって破綻する！
}
```

- オーブ1つにつき5個の変数が必要 ➔ 50個なら **250個の変数** が必要になってしまいます。
- 途中で「動きのスピードを変えたい」と思ったら、50箇所すべて手作業で書き換える必要があります。
- どの変数がどのオーブのものか分からなくなります。

このように、**「同じ性質や動作を持ったオブジェクトを複数作ったり、後から改造したいとき」に、クラスを使わない書き方は限界を迎えます**。

そこで、**オーブの性質（位置・色・脈動）と動作（更新・描画）を1つの「設計図（クラス）」にまとめます**。

## 6-4. ステップ3：クラスを作って設計図にする

オーブの設計図となる `Orb` クラスを作ってみましょう。
クラスは **「宣言」➔「コンストラクタ（初期化）」➔「引数とプロパティ（個性・状態）」➔「メソッド（動作と描画）」** の順に段階的に組み立てていきます。

**【① クラスの宣言】**

まずはクラスの枠組みを宣言します。

**`js/sketch.js`**

```jsx
class Orb {

}
```

- クラス名は分かりやすい名前をつけます。
- **先頭の文字は大文字** にするのが JavaScript の慣例です（例: `Orb`, `Person`, `Button`）。

**【② コンストラクタ（`constructor`）の設定】**

オブジェクト作成時に自動的に実行される特別な初期化処理を用意します。

**`js/sketch.js`**

```jsx
class Orb {
  constructor() {

  }
}
```

- `constructor` は、`new Orb()` でオブジェクトが作られた瞬間に **一度だけ呼び出される特別な関数** です。
- 1つのクラスに1つしか定義できません。

**【③ 引数とプロパティの設定（固有の状態・個性を与える）】**

引数を受け取り、生成されるオーブごとの状態（位置、色、サイズ、動き）をプロパティとして設定します。

**`js/sketch.js`**

```jsx
class Orb {
  constructor(x, y) {
    this.x = x;                         // 初期X座標（引数から代入）
    this.y = y;                         // 初期Y座標（引数から代入）
    this.baseSize = random(20, 60);     // ランダムな基本サイズ
    this.hue = random(180, 260);        // 青〜紫系のランダムな色相
    this.timeOffset = random(1000);     // ノイズ用の固有の時間
    this.speed = random(0.005, 0.02);   // ゆらめきのスピード
    this.pulseSpeed = random(2, 4);     // 呼吸のスピード（度数法）
  }
}
```

- **引数の設定**: `(x, y)` を引数で渡すことで、生成する位置をオブジェクトごとに自由に変えられます。
- **プロパティの設定**: プロパティ（オブジェクトが保持する値・引き出し）には、**必ず `this.` をつけます**。
- `random()` を活用することで、同じクラスから作られても **1つ1つのオーブが異なる個性（色・大きさ・テンポ）** を持ちます。

**【④ 描画メソッド（`render`）の追加】**

オブジェクトの振る舞い（動作）を定義する **メソッド** を追加します。まずは画面にオーブを描画する `render()` メソッドです。

**`js/sketch.js`**

```jsx
class Orb {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.baseSize = random(20, 60);
    this.hue = random(180, 260);
    this.timeOffset = random(1000);
    this.speed = random(0.005, 0.02);
    this.pulseSpeed = random(2, 4);
  }

  // ★ 描画メソッドを追加
  render() {
    push();
    translate(this.x, this.y);
    noStroke();

    // 外側の光
    fill(this.hue, 80, 100, 30);
    circle(0, 0, this.baseSize * 1.8);

    // 中心の核
    fill(this.hue, 60, 100, 90);
    circle(0, 0, this.baseSize);
    pop();
  }
}
```

- メソッドは **クラスの直下（`constructor` と並列）** に記述します（`function` キーワードは不要です）。
- 描画時にも、自分自身のプロパティを使う場合は `this.x` や `this.hue` のように **`this.`** を使って取り出します。

**【⑤ 状態更新メソッド（`update`）の追加】**

続いて、毎フレームの時間経過による移動（パーリンノイズ）や脈動（三角関数）を計算する `update()` メソッドを追加してクラスを完成させます。

**`js/sketch.js`**

```jsx
class Orb {
  // 1. コンストラクタ：初期状態の設定
  constructor(x, y) {
    this.x = x;                         // 初期X座標
    this.y = y;                         // 初期Y座標
    this.baseSize = random(20, 60);     // ランダムな基本サイズ
    this.hue = random(180, 260);        // 青〜紫系のランダムな色相
    this.timeOffset = random(1000);     // 個体ごとの固有のノイズ時間
    this.speed = random(0.005, 0.02);   // ゆらめきのスピード
    this.pulseSpeed = random(2, 4);     // 呼吸のスピード（度数法）
  }

  // 2. 状態の更新メソッド（位置のゆらぎやサイズ計算）
  update() {
    this.timeOffset += this.speed;
    this.pulse = sin(frameCount * this.pulseSpeed) * 12;
  }

  // 3. 描画メソッド
  render() {
    // 個体ごとのノイズ座標を計算
    let moveX = (noise(this.timeOffset) - 0.5) * 200;
    let moveY = (noise(this.timeOffset + 100) - 0.5) * 200;

    push();
    translate(this.x + moveX, this.y + moveY);
    noStroke();

    // 外側の光
    fill(this.hue, 80, 100, 30);
    circle(0, 0, (this.baseSize + this.pulse) * 1.8);

    // 中心の核
    fill(this.hue, 60, 100, 90);
    circle(0, 0, this.baseSize + this.pulse);
    pop();
  }
}
```

<aside>
💡

**「計算（`update`）」と「描画（`render`）」を分ける理由**

「位置やサイズを計算する処理（`update`）」と「画面に描く処理（`render`）」を別々のメソッドに分けることは、ゲーム開発やクリエイティブコーディングにおける最も重要な設計パターンです。

後でセンサーと連携させるときも、`update(sensorValue)` のように **「計算側にだけセンサー値を渡す」** ことができ、設計が非常にシンプルになります。

</aside>

**【配列を使って50個に増殖させる】**

JavaScriptの **配列（Array）** と **`for` ループ** を組み合わせるだけで、何個でも一瞬で増やすことができます。

**`js/sketch.js`**

```jsx
// オーブたちを格納する配列
let orbs = [];

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);
  noStroke();

  // for ループで50個のインスタンスを一気に入れ物（配列）に追加！
  for (let i = 0; i < 50; i++) {
    let rx = random(width * 0.2, width * 0.8);
    let ry = random(height * 0.2, height * 0.8);
    orbs.push(new Orb(rx, ry));
  }
}

function draw() {
  background(220, 30, 10, 20);

  // 配列に入っているすべてのオーブを一斉に更新＆描画！
  for (let orb of orbs) {
    orb.update();
    orb.render();
  }
}

// 設計したクラス
class Orb {
	.
	.
	.
}
```

たったこれだけのコードで、画面上に50個の美しい発光オーブが、それぞれ異なる色相・サイズ・呼吸スピードで自律的に優雅に舞い始めます。

変数が散らかることも一切ありません。これが **「クラスによるカプセル化と量産」** の威力です。

# 7. ファイル分割する（モジュール化）

ここまでのコードは、すべて **1つのファイル（`sketch.js`）** の中に `class Orb { ... }` も `setup()` も `draw()` もまとめて書いていました。

しかし、このままでは以下の問題が出てきます：

1. **コードが長くなり、見通しが悪くなる**（スクロールが大変になる）
2. **オーブの動きをもっと高度に改造したり、別の新しいクラス（魚や蝶など）を追加したときに `sketch.js` が何百行にも膨れ上がって破綻する**
3. **他の作品を作るときに、この `Orb` クラスだけをサッと再利用できない**

# 8. クラスとセンサーを連携させる

## **8-1. `js/templates/Orb.js`（部品）の `update()` に引数を追加する**

`js/templates/Orb.js` を開き、`update()` メソッドに引数 `sensor` を追加して、手の接近度合（0.0〜1.0）に応じて動き・色・呼吸が変化するように改造します。

**`js/templates/Orb.js`**

```jsx
class Orb {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.baseSize = random(20, 60);
    this.hue = random(180, 240);
    this.timeOffset = random(1000);
    this.speed = random(0.005, 0.02);
    this.pulseSpeed = random(2, 4);
  }

  // ★ センサー値（0.0: 遠い 〜 1.0: 近い）を引数で受け取る！
  update(sensor) {
    // 手を近づけると移動スピードが加速
    this.timeOffset += this.speed * (1 + sensor * 3);

    // 手を近づけると脈動が激しくなり、サイズも大きく膨張
    let pulseScale = 12 + sensor * 30;
    this.pulse = sin(frameCount * (this.pulseSpeed + sensor * 3)) * pulseScale;

    // 手を近づけると色相が青からマゼンタ・ピンクへシフト
    this.currentHue = (this.hue + sensor * 100) % 360;
  }

  render() {
    let moveX = (noise(this.timeOffset) - 0.5) * 200;
    let moveY = (noise(this.timeOffset + 100) - 0.5) * 200;

    push();
    translate(this.x + moveX, this.y + moveY);
    noStroke();

    // 外側の光（センサー値に応じて光の広がりも変化）
    fill(this.currentHue, 80, 100, 30);
    circle(0, 0, (this.baseSize + this.pulse) * 1.8);

    // 中心の核
    fill(this.currentHue, 60, 100, 90);
    circle(0, 0, this.baseSize + this.pulse);
    pop();
  }
}
```

## **8-2. `js/sketch.js`（ハブ）からセンサー値を部品に届ける**

続いて、`js/sketch.js` の `draw()` ループの中で、第5章のデータ処理パイプラインを動かし、計算された `sensorValue` を各オーブの `update(sensorValue)` に渡します。

**`js/sketch.js`**

```jsx
const SENSOR_MIN = 100;
const SENSOR_MAX = 600;
const LERP_RATE  = 0.08;

let sensorTarget = 0.2;
let sensorValue  = 0.2;
let orbs = [];

function setup() {
  createCanvas(windowWidth, windowHeight);
  rectMode(CENTER);
  imageMode(CENTER);
  angleMode(DEGREES);
  colorMode(HSB, 360, 100, 100, 100);
  noStroke();

  for (let i = 0; i < 50; i++) {
    let rx = random(width * 0.2, width * 0.8);
    let ry = random(height * 0.2, height * 0.8);
    orbs.push(new Orb(rx, ry));
  }
}

function draw() {
  background(220, 30, 10, 20);

  // ① センサー値のデータ処理（第5章のパイプライン）
  if (Sensor.isConnected) {
    let raw = Sensor.raw;
    let clamped = constrain(raw, SENSOR_MIN, SENSOR_MAX);
    sensorTarget = map(clamped, SENSOR_MIN, SENSOR_MAX, 0.0, 1.0);
    sensorValue = lerp(sensorValue, sensorTarget, LERP_RATE);
  }

  // ② すべてのオーブに加工済みのセンサー値を流し込んで描画！
  for (let orb of orbs) {
    orb.update(sensorValue); // ★ ハブから部品へ数値を渡す！
    orb.render();
  }

  // 接続ステータス表示
  if (Sensor.isConnected) {
    fill(0, 255, 204);
    textSize(18);
    textAlign(CENTER, CENTER);
    text(`🟢 接続中 - raw: ${Sensor.raw} ➔ val: ${sensorValue.toFixed(2)}`, width / 2, height - 40);
  } else {
    fill(200);
    textSize(20);
    textAlign(CENTER, CENTER);
    text("キーボードの [C] キーを押して Arduino に接続してください", width / 2, height / 2);
  }
}

// キーボードの [C] キーで接続開始
function keyPressed() {
  if ((key === 'c' || key === 'C') && !Sensor.isConnected) {
    Sensor.connect();
  }
}
```

# 9. 2つ目のクラスを追加して表現を重ねる

ジェネラティブアートの醍醐味は、**「異なる特徴を持った複数のパーツ（クラス）を重ね合わせ、1つの豊かな空間（生態系）を作り出すこと」** です。

ここでは、`Orb` の柔らかな光の球体と相性抜群の2つ目のクラス **`Ripple`（空間に広がる光の波紋リング）** を一緒に作って組み込んでみましょう！

## 9-1. ステップ1：`js/templates/Ripple.js` を新規作成する

VS Code の `js/templates/` フォルダの中に、新しく **`Ripple.js`** を作成し、以下のコードを記述します。

**`js/templates/Ripple.js`**

```jsx
/**
 * Ripple.js - 光の波紋リング（描画部品テンプレート）
 */
class Ripple {
  constructor(x, y) {
    this.x = x;                         // 中心のX座標
    this.y = y;                         // 中心のY座標
    this.radius = random(10, 40);       // 初期の半径
    this.maxRadius = random(120, 260);  // 最大の半径
    this.speed = random(1.0, 2.5);      // 広がる基本スピード
    this.hue = random(160, 220);        // シアン〜青系の初期色相
    this.weight = random(1.5, 3.0);     // 線の太さ
  }

  // ★ センサー値（0.0: 遠い 〜 1.0: 近い）を受け取って更新
  update(sensor) {
    // 手を近づけると波紋が広がるスピードが急加速
    this.radius += this.speed * (1 + sensor * 4);

    // 最大サイズを超えたら中心に戻ってリセット（無限ループ）
    if (this.radius > this.maxRadius + sensor * 150) {
      this.radius = 0;
    }

    // 手を近づけると色相が青からエメラルドグリーン・紫へとシフト
    this.currentHue = (this.hue + sensor * 80) % 360;

    // 外側に広がるほど透明度を下げ、自然にフェードアウトさせる
    let progress = this.radius / (this.maxRadius + sensor * 150);
    this.alpha = map(progress, 0, 1, 80, 0);
  }

  render() {
    push();
    translate(this.x, this.y);

    noFill();                           // 中は塗らない（線のみ）
    stroke(this.currentHue, 70, 100, this.alpha);
    strokeWeight(this.weight);

    // 波紋の同心円を描く
    circle(0, 0, this.radius * 2);
    pop();
  }
}
```

<aside>
💡

**`Ripple` クラスの注目ポイント**

- `noFill()` と `stroke()` を使うことで、`Orb` と重なったときに互いの光を邪魔せず、綺麗な重なりを作ります。
- `map(progress, 0, 1, 80, 0)` を使って、輪が広がるにつれてスッと空気に溶けるように消えるフェードアウトを実装しています。
- 最大サイズに達したら `this.radius = 0` でリセットされるため、永遠に新しい波紋が生まれ続けます。
</aside>

## ⭐️ 練習

次は、丸い形（`Orb`, `Ripple`）とは全く異なる、**`line()` をベースにした「折れ線グラフ（オシロスコープ波形）」のような3つ目のクラス `WaveLine`** をプロジェクトに追加してみましょう。

ここでは **`WaveLine.js` のクラスコードのみ** を提示します。
これまでの手順（ファイルの作成 ➔ `index.html` への登録 ➔ `sketch.js` での呼び出し）を思い出しながら、自分の手で動かしてみてください。

**`js/templates/WaveLine.js`**

```jsx
class WaveLine {
  constructor(y, optY) {
    // 引数が (y) でも (x, y) でも正しくY座標を受け取れるように設定
    this.y = (optY !== undefined) ? optY : y;
    this.baseHue = random(140, 210);    // エメラルド〜シアン系の初期色相
    this.speed = random(0.015, 0.035);  // 横に流れる基本スピード
    this.timeOffset = random(1000);     // ノイズ用の固有の時間
    this.step = 16;                     // 折れ線の細かさ（ピクセル間隔）
  }

  // ★ センサー値（0.0 〜 1.0）を受け取って計算
  update(sensor) {
    // 手が近づくほど波が流れるスピードが加速
    this.timeOffset += this.speed * (1 + sensor * 4);

    // ★ 手が近づくほど振れ幅（折れ線の上下の揺れ）が急拡大！
    // 遠いときは穏やかな波（±15px）、手が近づくと激しい折れ線スパイク（±160px）に！
    this.amplitude = map(sensor, 0, 1, 15, 160);

    // 手が近づくと金色やネオンマゼンタへと色が劇的に変化
    this.currentHue = (this.baseHue + sensor * 150) % 360;

    // 手が近づくと線が太く・明るく発光
    this.strokeW = map(sensor, 0, 1, 1.5, 4.0);
    this.alpha = map(sensor, 0, 1, 50, 95);
  }

  render() {
    push();
    noFill();
    stroke(this.currentHue, 80, 100, this.alpha);
    strokeWeight(this.strokeW);

    // 画面の左端（x = 0）から右端（x = width）まで line() で折れ線を繋ぐ
    let prevX = 0;
    let prevY = this.y + (noise(this.timeOffset) - 0.5) * this.amplitude;

    for (let x = this.step; x <= width; x += this.step) {
      // パーリンノイズで各ポイントの高さを決定（折れ線の波形）
      let n = noise(this.timeOffset + x * 0.006);
      let currY = this.y + (n - 0.5) * this.amplitude;

      // 前の点と現在の点を line() で結んで折れ線グラフにする
      line(prevX, prevY, x, currY);

      prevX = x;
      prevY = currY;
    }

    pop();
  }
}
```

```markdown
### 2. 必須のクラス設計（インターフェース仕様）
クラス名はモチーフに合わせた英単語（例: CrystalShard, ElectricTendril, MandalaRing など）とし、以下の3つのメソッドを実装してください：

1. `constructor(x, y)`:
   - 位置 `(x, y)` や初期サイズ、基本色相、個体ごとの速度・ノイズオフセットなどを `this.` プロパティとして設定すること。
   - `random()` を活用し、個体ごとに個性を持たせること。

2. `update(sensor)`:
   - 引数 `sensor` には、Arduinoの距離センサーから加工された数値（0.0: 手が遠い 〜 1.0: 手が至近）が毎フレーム渡されます。
   - この `sensor`（0.0〜1.0）を使って、スピード、サイズ、脈動の振幅、色相シフト、形状の変形などを滑らかに変化させてください。
   - 画面外に出た場合のループ処理や、寿命が尽きた際のリセット処理も含めてください。

3. `render()`:
   - キャンバスはすでに `colorMode(HSB, 360, 100, 100, 100);` に設定されています。
   - 必ず `push()` と `pop()` で囲み、描画スタイルの設定が他のクラスに影響を与えないようにすること。
   - `translate(this.x, this.y)` を使用し、オブジェクト自身の相対座標で描画命令（circle, line, rect, beginShape / endShape 等）を記述すること。
```
