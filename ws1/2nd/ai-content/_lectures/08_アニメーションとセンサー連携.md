## 2-1. 連番画像からアニメーションを作る

ファイル名の末尾に連続した番号が付いている画像（例：`hiyoko_idle1.png` 〜 `hiyoko_idle4.png`）は、`loadAni(最初のファイル, 最後の番号)` だけで自動的に読み込んでアニメーション化できます。

```javascript
let idleAni;

function setup() {
  new Canvas(500, 160);

  // loadAni(最初のファイルパス, 最後のフレーム番号)
  idleAni = loadAni('assets/hiyoko_idle1.png', 4);
  idleAni.frameDelay = 12; // 12フレームごとに次のコマへ進む
}

function draw() {
  clear();
  background('#1a1f36');
  // 指定した座標 (250, 80) にアニメーションを描画
  animation(idleAni, 250, 80);
}
```

## 2-2. 複数の画像ファイルを順番に並べる

連番になっていない別々の画像ファイルを順番に並べてパラパラ漫画にすることもできます。
また、**`frameDelay`** プロパティを変更すると、1コマあたり何フレーム待機するか（＝再生スピード）を調整できます。数値が大きいほどゆっくり再生されます（デフォルトは `4`）。

```javascript
let transformAni;

function setup() {
  new Canvas(500, 160);

  // loadAni(画像1, 画像2, 画像3, ...)
  transformAni = loadAni(
    'assets/hiyoko_step1.png', // 丸いタマゴ
    'assets/hiyoko_step2.png', // ヒビ入りタマゴ
    'assets/hiyoko_step3.png', // 殻から顔を出したヒヨコ
    'assets/hiyoko_step4.png'  // 王冠をかぶったヒヨコ
  );

  // 20フレームごとに次のコマへ進む（ゆっくり変身する）
  transformAni.frameDelay = 20;
}

function draw() {
  clear();
  background('#1a1f36');
  animation(transformAni, 250, 80);
}
```

## 2-3. スプライトシート（1枚の画像）から切り出す

複数のコマが1枚の画像に等間隔で並んでいる画像を **スプライトシート（Sprite Sheet）** と呼びます。
`loadAni()` の第2引数に `{ width: 1コマの幅, height: 1コマの高さ, frames: コマ数 }` を指定すると、自動で切り出してアニメーションにしてくれます。

```javascript
let effectAni;

function setup() {
  new Canvas(500, 200);

  // loadAni(スプライトシート画像, アトラス設定：1コマ 64x64 が 4コマ)
  effectAni = loadAni('assets/hiyoko_effect.png', {
    width: 64, height: 64, frames: 4
  });
  effectAni.frameDelay = 8;
}

function draw() {
  clear();
  background('#1a1f36');
  animation(effectAni, 100, 100);

  // 参考：元のスプライトシート全体（256x64）も右側に表示してみる
  image(effectAni.spriteSheet, 200, 70, 256, 64);
}
```

### 特定のフレーム番号だけを抜き出して使う

`frames` に配列 `[0, 1, 2, 1]` を渡すと、スプライトシートの中から **使いたいコマ番号だけ** を順番にピックアップしてアニメーションを作れます（フレーム番号は `0` から始まります）。

```javascript
let twinkleAni;

function setup() {
  new Canvas(500, 200);

  twinkleAni = loadAni('assets/hiyoko_effect.png', {
    width: 64, height: 64, frames: [0, 1, 2, 1]
  });
  twinkleAni.frameDelay = 10;
}

function draw() {
  clear();
  background('#1a1f36');
  animation(twinkleAni, 250, 100);
}
```

## 2-4. アニメーションをグループ化して量産する

前回まで使ってきた **`Group`** にもアニメーションを登録できます。
たとえば、画面をクリックするたびにその場所でキラキラ羽根エフェクトが再生される演出は、わずか数行で実装できます。

```javascript
let effects;

function setup() {
  new Canvas(500, 160);

  effects = new Group();
  effects.collider = 'none'; // エフェクト同士がぶつからないようにする
  effects.addAni('assets/hiyoko_effect.png', {
    width: 64, height: 64, frames: 4
  });
}

function draw() {
  clear();
  background('#1a1f36');

  // マウスをクリックした位置にアニメーション付きスプライトを生成
  if (mouse.presses()) {
    new effects.Sprite(mouse.x, mouse.y);
  }
}
```

# 3. スプライトシートを使ったアニメーション制作

ここからは、実際のゲーム制作やインタラクティブ作品で最もよく使われる **「スプライトシートを使って、キャラクターの複数モーションを切り替える方法」** に絞って詳しく学んでいきます。

---

## 3-1. なぜスプライトシートを使うのか？

キャラクターに「待機・走り・ジャンプ・転がる・攻撃」といった複数の動きを持たせたい場合、バラバラの画像ファイルを何十枚も管理するのは大変です。

**スプライトシート** では、1枚の大きな画像の中に **行（`row`）ごとに異なるモーション** を格子状に並べておきます（今回の `assets/hiyoko_sheet.png` は `256 × 256` px、1コマ `64 × 64` px の 4列 × 4行 です）：

```text
┌────────────────────────────────────┐
│ row 0 (run  / 走る)   : [1][2][3][4] │  ← 4コマ
│ row 1 (jump / 跳ぶ)   : [1][2][3][4] │  ← 4コマ
│ row 2 (roll / 転がる) : [1][2][3][4] │  ← 4コマ
│ row 3 (stand/ 待機)   : [1][2][3][4] │  ← 4コマ
└────────────────────────────────────┘
  ※ 1コマあたりの幅(64px)・高さ(64px)がすべて同じサイズ！
```

p5play では、この1枚の画像を **`sprite.addAnis()`** で読み込むだけで、すべてのモーションに名前を付けて一括登録できます。

---

## 3-2. 複数モーションの登録と切り替え（`addAnis` / `changeAni`）

ここからは `js/sketch.js` を少しずつ書き足しながら、ヒヨコのキャラクター（`hiyoko`）を動かしていきます。

### STEP 1：キャンバスの土台を作る

まずは `500 × 300` のキャンバスと背景色だけの最小限のコードを用意します。

**`js/sketch.js`**

```javascript
function setup() {
  new Canvas(500, 300);
}

function draw() {
  clear();
  background('#1a1f36');
}
```

### STEP 2：ヒヨコのスプライトを作成し、スプライトシートを登録する

`setup()` の中に、ヒヨコのスプライト生成と `hiyoko.addAnis()` による4つのモーション（`run`, `jump`, `roll`, `stand`）の一括登録を追加し、最初に `'run'`（走り）を再生して画面に表示されるか確認しましょう。

```javascript
let hiyoko;

function setup() {
  new Canvas(500, 300);

  // ① スプライトを作成（幅64, 高さ64 が1コマの基準サイズになる）
  hiyoko = new Sprite(250, 150, 64, 64);
  hiyoko.anis.frameDelay = 8; // 全体の再生スピード（8フレームごとに1コマ進む）

  // ② スプライトシートから複数アニメーションを一括登録
  hiyoko.addAnis('assets/hiyoko_sheet.png', {
    run:   { row: 0, frames: 4 },
    jump:  { row: 1, frames: 4 },
    roll:  { row: 2, frames: 4, frameDelay: 12 }, // rollだけ少しゆっくり再生
    stand: { row: 3, frames: 4 }
  });

  // ③ 最初は 'run'（走り）アニメーションを再生
  hiyoko.changeAni('run');
}

function draw() {
  clear();
  background('#1a1f36');
}
```

### STEP 3：キーボードでモーションを切り替える

`draw()` の中に以下のコードを追加し、`R` / `J` / `L` / `S` キーを押して各アニメーションに切り替わることを確認しましょう。

```javascript
  // draw() の末尾に追加
  // キーを押した瞬間にアニメーションを切り替える
  if (kb.presses('r')) hiyoko.changeAni('run');
  if (kb.presses('j')) hiyoko.changeAni('jump');
  if (kb.presses('l')) hiyoko.changeAni('roll');
  if (kb.presses('s')) hiyoko.changeAni('stand');
```

### コードのポイント解説
- **`hiyoko.addAnis(画像パス, 設定オブジェクト)`**：
  - `row`：スプライトシートの何行目か（一番上が `0` 行目）
  - `frames`：その行に何コマあるか（省略すると1コマ）
  - `frameDelay`：そのモーション専用の再生速度を個別に上書きできます。
- **`hiyoko.changeAni('名前')`**：登録したアニメーション名を指定して切り替えます。

## 3-3. 移動と連動したアニメーション制御（反転・順次再生）

先ほどの `R / J / L / S` キーによる切り替えコード（`draw()` の中身）を書き換え、**「左右に移動しているときは走り（`run`）＋画像の向き反転、止まったら待機（`stand`）、上キーを押したらジャンプ（`jump`）して終わったら待機に戻る」** 制御を順番に組み込みましょう。

### STEP 1：初期状態を待機（`stand`）にし、無重力にする

まず `setup()` を以下のように書き換えます。

```javascript
function setup() {
  world.gravity.y = 0; // 今回は無重力でテスト
  hiyoko.changeAni('stand');
}
```

### STEP 2：1回だけ再生して自動で戻るアクションを追加する

`draw()` の中の `R / J / L / S` のコードを消し、代わりに上・下キーで **単発アクション（再生が終わったら `stand` に戻る）** を追加します。

```javascript
  // draw() の background('#1a1f36'); の後に追加
  // 配列で渡すと「jumpを1回再生したあと、自動でstandに戻る」
  if (kb.presses('up')) {
    hiyoko.changeAni(['jump', 'stand']);
  }
  if (kb.presses('down')) {
    hiyoko.changeAni(['roll', 'stand']);
  }
```

### STEP 3：左右移動と、移動に合わせたアニメ切り替え・左右反転を追加する

続けて `draw()` の末尾に、左右キーでの速度設定と、`hiyoko.scale.x` を使った左右反転・モーション切り替えを追加します。

```javascript
  // draw() の末尾に追加
  // ジャンプ中や転がり中でなければ、左右の移動速度・向き・アニメーションをまとめて制御
  if (hiyoko.ani.name !== 'jump' && hiyoko.ani.name !== 'roll') {
    if (kb.pressing('left')) {
      hiyoko.vel.x = -3;
      hiyoko.scale.x = -1; // 画像を左向きに反転
      hiyoko.changeAni('run');
    } else if (kb.pressing('right')) {
      hiyoko.vel.x = 3;
      hiyoko.scale.x = 1;  // 画像を右向き（元の向き）に戻す
      hiyoko.changeAni('run');
    } else {
      hiyoko.vel.x = 0;
      hiyoko.changeAni('stand');
    }
  }
```

### 重要なテクニック
1. **`hiyoko.changeAni(['jump', 'stand'])`**：
   配列で複数のアニメーション名を渡すと、1つ目のアニメーションを **1回だけ再生** した後、自動的に2つ目のアニメーション（`stand`）へ切り替わります！
2. **`hiyoko.scale.x = -1`**：
   X方向の拡大率を `-1` にすると、スプライトの画像が左右反転します。左向きの絵をわざわざ描かなくても、右向きの絵だけで左右両方の移動に対応できます。
3. **`hiyoko.ani.name`（`if` 文が必要な条件）**：
   現在再生中のアニメーション名を取得できます。
   - **配列指定 `['jump', 'stand']` のような「1回だけ再生するアクション」を使うときは、`if (hiyoko.ani.name !== 'jump' && ...)` が必要です。** これがないと、再生が終わる前に毎フレーム `run` や `stand` で上書きされて途中で止まってしまいます。
   - 逆に、すべて文字列指定（`'run'` や `'stand'` などのループ再生）だけで切り替える場合は、すでに再生中なら自動でスキップされるため、この `if` 文は不要になります。

## ⭐️ 練習2：キーボード操作のキャラクターを拡張しよう

<aside>
⭐

**【練習2の課題】**
3-3 のコードをベースに、以下の拡張を行ってみましょう：

1. `Space` キー（`kb.presses('space')`）を押したときに、ヒヨコがくるんと転がる（`roll`）ようにする。
2. 移動中に画面の左右端からはみ出さないように `constrain()` を追加する（ヒヨコの幅は `64` なので余白は `32`）。
3. **本当にジャンプさせる（前回の復習）**：
   - `world.gravity.y = 10;` で重力を設定し、`hiyoko.rotationLock = true;` で転倒を防止する。
   - 地面となる床スプライト `floor = new Sprite(250, 270, 500, 20, 'static');` を追加する。
   - `up` キーを押したとき、`hiyoko.colliding(floor)`（地面に触れているとき）なら `hiyoko.vel.y = -6;` で実際に跳び上がるようにする。

</aside>

### ✅ 練習2の正解コード（`js/sketch.js`）

```javascript
let hiyoko;
let floor;

function setup() {
  new Canvas(500, 300);
  world.gravity.y = 10; // 重力を設定

  hiyoko = new Sprite(250, 200, 64, 64);
  hiyoko.anis.frameDelay = 8;
  hiyoko.rotationLock = true; // 着地時に回転しないように固定

  hiyoko.addAnis('assets/hiyoko_sheet.png', {
    run:   { row: 0, frames: 4 },
    jump:  { row: 1, frames: 4 },
    roll:  { row: 2, frames: 4, frameDelay: 12 },
    stand: { row: 3, frames: 4 }
  });
  hiyoko.changeAni('stand');

  // 地面となる床を作成
  floor = new Sprite(250, 270, 500, 20, 'static');
  floor.color = '#2ed573';
}

function draw() {
  clear();
  background('#1a1f36');

  // アクション（地面に触れているときだけジャンプ）
  if (kb.presses('up') && hiyoko.colliding(floor)) {
    hiyoko.vel.y = -6; // 上向きの速度を与えて本当に跳び上がる！
    hiyoko.changeAni(['jump', 'stand']);
  }
  if (kb.presses('down') || kb.presses('space')) {
    hiyoko.changeAni(['roll', 'stand']);
  }

  // アクション中でなければ、左右の移動とアニメーションをまとめて制御
  if (hiyoko.ani.name !== 'jump' && hiyoko.ani.name !== 'roll') {
    if (kb.pressing('left')) {
      hiyoko.vel.x = -3;
      hiyoko.scale.x = -1;
      hiyoko.changeAni('run');
    } else if (kb.pressing('right')) {
      hiyoko.vel.x = 3;
      hiyoko.scale.x = 1;
      hiyoko.changeAni('run');
    } else {
      hiyoko.vel.x = 0;
      hiyoko.changeAni('stand');
    }
  }

  // 画面外へのはみ出し防止
  hiyoko.x = constrain(hiyoko.x, 32, width - 32);
}
```

# 4. センサーを組み込む（Web Serial API 連携）

キャラクターのアニメーションを自由自在に制御できるようになったら、いよいよ **Arduinoの物理センサー** を組み込みます！
今回は第4回で使った **「赤外線距離センサー（GP2Y0A21YK）」** を例に、**「手を近づける距離によって、キャラクターのモーションや動きの速さがリアルタイムに変化する」** 仕組みを実装します。

---

## 4-1. センサー値とアニメーションの連動設計

手をかざす距離に応じて取得した値（`0.0` ＝ 遠い 〜 `1.0` ＝ とても近い）を、以下のようにアニメーションへ割り当てます：

| センサー値（`Sensor.value`） | 手の距離のイメージ | キャラクターの反応（アニメーション） |
|---|---|---|
| **`0.00 〜 0.25`** | 手をかざしていない（遠い） | **`stand`**（待機して様子をうかがう） |
| **`0.25 〜 0.70`** | 手をほどよく近づける | **`run`**（走り出す！近づくほど `frameDelay` が小さくなり高速で走る） |
| **`0.70 〜 1.00`** | 手をすぐ近くまで近づける | **`roll`**（くるんと転がる！） |

---

## 4-2. ハードウェアと `js/sensor.js` の準備

### 1. Arduino の配線とスケッチ（第4回と同じ）
- 赤外線距離センサーの信号線（黄色）を **A7ピン**、赤を **5V**、黒を **GND** に接続します。
- Arduino IDE で以下のスケッチを書き込みます（確認後は **シリアルモニタを必ず閉じてください**）。

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.println(analogRead(A7)); // 0〜1023の値を送信
  delay(20);
}
```

### 2. `js/sensor.js` の作成

`08/js/sensor.js` を作成し、Web Serial API で受信した数値を `0.0 〜 1.0` に正規化して `Sensor.value` に保存するモジュールを用意します。

```javascript
// js/sensor.js
const Sensor = {
  isConnected: false,
  rawValue: 0,
  value: 0,      // 0.0 〜 1.0 に調整された値
  minVal: 120,   // 手が遠い時の値（環境に合わせて調整）
  maxVal: 600,   // 手が近い時の値（環境に合わせて調整）

  async connect() {
    if (!('serial' in navigator)) {
      alert('Google Chrome または Microsoft Edge を使用してください。');
      return;
    }

    try {
      const port = await navigator.serial.requestPort();
      await port.open({ baudRate: 9600 });
      this.isConnected = true;
      console.log('🟢 Arduinoに接続しました');

      const textDecoder = new TextDecoderStream();
      port.readable.pipeTo(textDecoder.writable);
      const reader = textDecoder.readable.getReader();

      let buffer = '';
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;

        buffer += value;
        const lines = buffer.split('\n');
        buffer = lines.pop();

        for (const line of lines) {
          const num = parseInt(line.trim(), 10);
          if (!isNaN(num)) {
            this.rawValue = num;
          }
        }
      }
    } catch (err) {
      console.error(err);
      this.isConnected = false;
    }
  },

  // 毎フレーム draw() の中で呼び出して滑らかな 0.0〜1.0 を得る
  update() {
    if (!this.isConnected) return;
    let clamped = constrain(this.rawValue, this.minVal, this.maxVal);
    let mapped = map(clamped, this.minVal, this.maxVal, 0.0, 1.0);
    this.value = lerp(this.value, mapped, 0.2);
  }
};
```

### 3. `js/sketch.js` を複製し、`index.html` の読み込みを切り替える

1. 練習2で作った `js/sketch.js`（キーボード操作版）はそのまま残しておき、複製して **`js/sensor_ani.js`** という新しいファイルを作成します。
2. `index.html` で `js/sensor.js` を追加し、読み込むメインファイルを `js/sensor_ani.js` に切り替えます。

```html

  <!-- ④ センサー通信モジュールとセンサー連携スケッチ -->
  <script src="js/sensor.js"></script>
  <script src="js/sensor_ani.js"></script>
```

## 4-3. `sensor_ani.js` にセンサー連携を組み込む

ここからはゲームの移動やジャンプを離れ、**「センサーの反応に合わせてアニメーションそのものが変化する純粋なインタラクティブ・アニメーション」** へと作り替えていきます。

### STEP 1：複製した `js/sensor_ani.js` から重力と床を削除する

複製した `js/sensor_ani.js` を開き、物理シミュレーション（重力と床）を削除して、ヒヨコを画面中央に配置し直します。

1. `let floor;` の変数宣言を削除する。
2. `setup()` の `world.gravity.y = 10;` を `world.gravity.y = 0;` に戻す（または削除する）。
3. `hiyoko` の初期座標を中央の `(250, 150)` に戻し、`hiyoko.rotationLock = true;` と `floor = new Sprite(...)` の作成コードを削除する。

```javascript

  new Canvas(500, 300);
  world.gravity.y = 0; // 重力は使わない

  // 画面中央に配置し直す

  hiyoko.anis.frameDelay = 8;

  hiyoko.addAnis('assets/hiyoko_sheet.png', {
    run:   { row: 0, frames: 4 },
    jump:  { row: 1, frames: 4 },
    roll:  { row: 2, frames: 4, frameDelay: 12 },
    stand: { row: 3, frames: 4 }
  });
  hiyoko.changeAni('stand');
}
```

### STEP 2：クリックで Arduino に接続する処理を追加する

`js/sensor_ani.js` の一番下に、画面クリックで `Sensor.connect()` を呼び出す `mousePressed()` を追加します。

```javascript
// 画面クリックでArduinoに接続
function mousePressed() {
  if (!Sensor.isConnected) {
    Sensor.connect();
  }
}
```

### STEP 3：`draw()` をセンサー値でアニメーションを切り替える処理に書き換える

`draw()` の中身を、`Sensor.value`（`0.0 〜 1.0`）の値に応じてアニメーションを切り替えるコードに書き換えます。

```javascript
function draw() {
  clear();
  background('#1a1f36');

  // センサー未接続時はここで終了
  if (!Sensor.isConnected) return;

  Sensor.update();
  let v = Sensor.value; // 0.0 〜 1.0

  // センサーの値に応じてアニメーションを切り替える
  if (v > 0.7) {
    // 手がとても近い：くるくる転がり続ける！
    hiyoko.changeAni('roll');
  } else if (v > 0.25) {
    // 手が中くらい：走る（近づくほど速く走る！）
    hiyoko.changeAni('run');
    hiyoko.ani.frameDelay = floor(map(v, 0.25, 0.7, 10, 3));
  } else {
    // 手が遠い：待機
    hiyoko.changeAni('stand');
  }

  // センサーの値を画面左上に表示
  fill('#ffffff');
  noStroke();
  textSize(14);
  text(`Sensor: ${v.toFixed(2)} (raw: ${Sensor.rawValue})`, 16, 24);
}
```

# 5. 自作スプライトシートでオリジナル作品を作る

既存のサンプル画像で仕組みが理解できたら、いよいよ **自分だけのオリジナル・スプライトシートを自作** し、センサーに反応するアニメーション作品を制作します！

---

## 5-1. 自作スプライトシートの作り方と事前設計

### ✏️ 制作前の必須ステップ：必ず先に「紙」に描いて設計する

いきなり Illustrator や Photoshop を開いて描き始めると、途中でコマ数が足りなくなったりサイズが合わなくなったりして作り直しになりがちです。
**必ず最初に紙とペンで設計図（ラフ）を描き、以下を確定させてからソフトを開きましょう！**

1. **どんなモーションを何種類作るか**（例：待機・変化・驚きの3種類 ➔ **縦3行**）
2. **各モーションは何コマで動かすか**（例：最大6コマ ➔ **横6列**）
3. **全体のマス数**：**縦何マス × 横何マス必要か**（例：縦3マス × 横6マス）を紙の上で把握し、1コマのサイズ（例：`128 × 128` px）を決めてからキャンバスを作ります。

---

### スプライトシート作成・3つのルール

p5play で正しく読み込めるスプライトシートを作るには、以下の **3つのルール** を守る必要があります。

1. **1コマのサイズ（幅 × 高さ）をすべて統一する**
   - 例：`64 × 64` px や `128 × 128` px など、すべてのコマを同じサイズの正方形（または長方形）の枠に収めます。
2. **背景を透過（PNG形式）にする**
   - 背景色が入っているとキャラクターの周りに四角い枠が見えてしまうため、背景は透明にして PNG（または WebP）で書き出します。
3. **1行につき1モーションで横に並べる**
   - 0行目（一番上）に「待機（4コマ）」、1行目に「変化・アクション（6コマ）」のように、行ごとにモーションを分けます。

### おすすめの制作ツール

| ツール | 向いている作風 | 作り方 |
|---|---|---|
| **Piskel**（Webアプリ・無料） | ドット絵・ピクセルアート | ブラウザ上でコマアニメを描き、「Export → PNG → Sprite sheet」を選ぶだけで完璧なグリッド画像が書き出せます！ |
| **Figma / Illustrator** | ベクター・フラットイラスト | 同じサイズのフレーム（例：`128×128`）を格子状に隙間なく並べて、全体をまとめてPNG書き出しします。 |
| **Photoshop / CLIP STUDIO 等** | 手描きイラスト・ドット絵 | ガイド機能で等間隔のマス目を引き、レイヤーを複製して少しずつ描き変えながら透過PNGで書き出します。 |

### 🎨 Adobe Illustrator でスプライトシートを作る効率的な手順

Illustrator を使うと、**「グリッドに分割」** 機能を使って1pxのズレもない綺麗なスプライトシートを素早く作ることができます。

1. **アートボードサイズを計算して新規作成する**
   - 単位を必ず **ピクセル（px）** にし、「1コマのサイズ × コマ数」でアートボードを作成します。
   - 例：1コマ **`128 × 128` px** で、横に **4コマ**・縦に **2モーション（2行）** 作る場合 ➔ 幅 **`512` px** × 高さ **`256` px**。
2. **「グリッドに分割」でガイド枠を一瞬で作る**
   - 長方形ツール（`M`）でアートボードと全く同じサイズ（`512 × 256` px）の四角形を1つ描き、アートボードにぴったり合わせます。
   - 上部メニューの **`オブジェクト` ➔ `パス` ➔ `グリッドに分割...`** を開き、**「行数：2」「列数：4」「間隔：0 px」** にして「OK」を押します。
   - 分割された四角形をすべて選んだ状態で **`表示` ➔ `ガイド` ➔ `ガイドを作成`（`Cmd + 5` / `Ctrl + 5`）** を実行すると、書き出し時に映らないガイド線に変換されます！
3. **1コマ目を描いて「複製 ➔ 差分だけ編集」する**
   - 左上の1コマ目にベースの絵を描き、グループ化（`Cmd + G` / `Ctrl + G`）します。
   - 選択ツールで選んだまま `Enter` キーを押し、移動ダイアログで **水平：`128 px`、垂直：`0 px`** にして **「コピー」** を押します（あとは `Cmd + D` で横へ等間隔に連続コピーできます！）。
   - 2コマ目以降は、動かしたいパーツ（手・足・目・口など）だけを少し変形・移動させます。
4. **アートボードのサイズそのままに「透過PNG」で書き出す**
   - **`ファイル` ➔ `書き出し` ➔ `書き出し形式...`** を選びます。
   - 形式を **PNG** にし、**「アートボードごとに作成」に必ずチェック** を入れます（チェックを入れないと余白が切り詰められてコマがズレます！）。
   - 解像度は **スクリーン（72 ppi）**（倍率 `1x`）、背景色は **透明** を選んで書き出します。

### 🖌️ Adobe Photoshop でスプライトシートを作る効率的な手順

Photoshop を使う場合は、**「新規ガイドレイアウト」** と **「レイヤー（グループ）複製」** を活用すると効率よく描けます。

1. **キャンバスを「背景：透明」で新規作成する**
   - 紙に描いた設計図をもとに、「1コマのサイズ × マス数」でサイズを計算して新規作成します（例：`128 × 128` px が4列 × 2行なら `512 × 256` px）。
   - このとき **「カンバスカラー：透明」**（または後で背景レイヤーを非表示）にしておきます。
2. **「新規ガイドレイアウト」でマス目を一瞬で引く**
   - 上部メニューの **`表示` ➔ `ガイド` ➔ `新規ガイドレイアウト...`** を開きます。
   - **「列：4（間隔 0 px）」「行：2（間隔 0 px）」「マージン：すべて 0 px」** に設定して「OK」を押すと、1pxのズレもない等間隔のガイド線が引けます。
   - （※ **`表示` ➔ `スナップ`** にチェックを入れておくと、選択範囲や移動がガイド線にピタッと吸着して便利です！）
3. **グループ分け＋複製で描き進める（オニオンスキン風テクニック）**
   - 1コマ目の絵を1つのレイヤーグループ（例：`1コマ目`）にまとめて描きます。
   - グループを選んで **`Cmd + J`（`Ctrl + J`）で複製** し、**`Cmd + T`（自由変形）** の上部オプションバーで「X座標」に `+128` を足して（または `Shift` を押しながら右のマスへドラッグして）隣のマスへ移動させます。
   - 前のコマの不透明度を一時的に下げるか、動きを変えたい部分（手足・目・輪郭）だけを消しゴムとブラシで描き直します。
   - **ドット絵を描く場合のコツ**：ブラシツールではなく **鉛筆ツール（`1 px`）** を使い、拡大・縮小時の補間方式を **「ニアレストネイバー法（ハードな輪郭）」** にすると、ドットがぼやけずにくっきり描けます。
4. **透過PNGで書き出す**
   - 背景レイヤーがある場合は目のアイコンをクリックして非表示にし、市松模様（透明）が見える状態にします。
   - **`ファイル` ➔ `書き出し` ➔ `PNGとしてクイック書き出し`** で保存すれば完成です（ガイド線は書き出し画像には含まれません）。

## 5-2. 自作スプライトシートをプログラムに読み込む

自作したスプライトシート（例：1コマ **`128 × 128` px** の `assets/my_char.png`）を読み込むときは、`new Sprite()` の引数でサイズを指定するか、`frameSize` を明示的に指定します。

```javascript
let myChar;

function setup() {
  // 例：普通の解像度の作品なので大きめのキャンバスを作成
  new Canvas(600, 400);

  // ① 1コマのサイズ（128 x 128）に合わせてスプライトを作成
  myChar = new Sprite(width / 2, height / 2, 128, 128);
  myChar.anis.frameDelay = 10;

  // ② 自作スプライトシートを登録
  myChar.addAnis('assets/my_char.png', {
    idle:   { row: 0, frames: 4 }, // 0行目：4コマの待機アニメ
    active: { row: 1, frames: 6 }  // 1行目：6コマの反応アニメ
  });
}
```

<aside>
⚠️

**【よくあるトラブル】コマがズレて隣の絵が見切れてしまう場合**

1. **画像全体の横幅・縦幅を割り切れるか確認**：
   1コマが `128 × 128` で、横に最大6コマ・縦に2行あるなら、画像全体のサイズは必ず **`768 × 256` px**（`128×6` × `128×2`）になっている必要があります。1pxでもズレているとコマが徐々にズレます。
2. **当たり判定サイズと画像のサイズを分けたい場合**：
   `addAnis` の中で `frameSize: [128, 128]` を指定すると、スプライトの物理サイズとは別に1コマの切り出しサイズを指定できます。

</aside>

## 5-3. 最終課題：センサーに反応するアニメーション作品

今回はゲーム（操作してスコアを競うもの）ではなく、**「センサーに反応して表情や姿が変化する、純粋なアニメーション作品」** を制作します。
自作したスプライトシートと Arduino のセンサーを組み合わせて、**「人の動きや環境に反応して生きているように動く作品」** を作ってみましょう。

### アイデアの例
- 🌸 **近づくと開花する植物・花**：人が近づくにつれてつぼみが開き、一番近づくと満開になって花びらが舞う。
- 👻 **恥ずかしがり屋なおばけ / モンスター**：普段は踊っているけれど、人が近づくと驚いたり隠れたりする（あるいは怒って変身する）。
- 🔥 **呼吸する炎・魔法陣**：距離に応じて炎の勢いやアニメーション速度（`frameDelay`）が激しく変化する。
- 🤖 **感情を持つロボット**：センサーの距離によって「眠い ➔ 気づく ➔ 喜ぶ」の3段階のモーションが切り替わる。

### 提出・制作のポイント（必須条件）
1. **必ず手描きで作成すること（AI生成・既存素材の流用禁止）**：
   - 生成AIで作った画像や既存のフリー素材ではなく、**必ず自分の手で描いたオリジナルのイラスト・ドット絵**（Illustrator、Piskel、Procreate、CLIP STUDIO 等を使用）でスプライトシートを作成してください。
2. **2種類以上のモーションを含める**：
   - 最低 **2種類以上のモーション**（例：`idle` と `action`）を含むスプライトシートを作成する。
3. **センサーとの連動**：
   - 第4章の `sensor.js` を使い、センサーの値に応じて **モーションの切り替え（`changeAni`）** や **再生速度（`frameDelay`）**、背景演出などが反応するように実装する。

2. **状態に応じたモーション制御**：`addAnis()` と `changeAni()` を組み合わせ、配列指定による単発アクションや `scale.x = -1` による反転、`frameDelay` による速度変化を制御できるようになりました。
3. **身体性とアニメーションの結合**：自分の絵がプログラムとセンサーの力で「目の前の人の動きに反応して生きているように動く」インタラクティブ作品を完成させました。
