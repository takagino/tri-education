## 2-2. 自機の生成とキーボード移動（前回の復習）

前回の p5play の基礎を復習しながら、順番にコードを追加して自機を動かしていきましょう。

### STEP 1：自機スプライト（`player`）の追加と背景の塗りつぶし

まずは変数 `player` を宣言し、`setup()` でスプライトを生成します。
また、スプライトが動いたときに残像が残らないよう、`draw()` の中で毎フレーム `background()` を描きます。

```javascript
let player;

function setup() {
  new Canvas(480, 640);

  // 自機スプライトの作成：new Sprite(x座標, y座標, 幅, 高さ)
  player = new Sprite(width / 2, height - 100, 36, 36);
}

function draw() {
  background('#111424');
}
```

### STEP 2：重力の設定と見た目のカスタマイズ

前回は `world.gravity.y = 10` のように重力をかけてキャラクターを落下させましたが、今回は上下左右に自由に飛び回るシューティングゲームなので **重力を `0`（無重力）** に設定します。
あわせて、自機の色・枠線・回転ロック（`rotationLock`）を設定しましょう。

```javascript
let player;

function setup() {
  new Canvas(480, 640);

  // 今回は無重力（上下左右に自由に飛ぶため）
  world.gravity.y = 0;

  // 自機スプライトの作成と見た目の設定
  player = new Sprite(width / 2, height - 100, 36, 36);
  player.color = '#f1c40f';   // 鮮やかなイエロー
  player.stroke = '#ffffff';  // 白い枠線
  player.strokeWeight = 2;    // 枠線の太さ
  player.rotationLock = true; // 衝突時に回転しないように固定
}

function draw() {
  background('#111424');
}
```

### STEP 3：キーボード入力（`kb.pressing`）で自機を移動させる

p5play のキーボード入力オブジェクト **`kb.pressing('キー名')`** を使い、上下左右の矢印キーが押されている方向に速度（`player.vel`）を与えて移動させます。

```javascript
let player;
const SPEED = 6; // 自機の移動速度

function setup() {
  new Canvas(480, 640);

  world.gravity.y = 0;

  player = new Sprite(width / 2, height - 100, 36, 36);
  player.color = '#f1c40f';
  player.stroke = '#ffffff';
  player.strokeWeight = 2;
  player.rotationLock = true;
}

function draw() {
  background('#111424');

  // 左右の移動
  if (kb.pressing('left')) {
    player.vel.x = -SPEED;
  } else if (kb.pressing('right')) {
    player.vel.x = SPEED;
  } else {
    player.vel.x = 0;
  }

  // 上下の移動
  if (kb.pressing('up')) {
    player.vel.y = -SPEED;
  } else if (kb.pressing('down')) {
    player.vel.y = SPEED;
  } else {
    player.vel.y = 0;
  }
}
```

### STEP 4：画面外へのはみ出し防止（`constrain`）

最後に、自機がキャンバスの外へ出てしまわないよう、`draw()` の末尾に **`constrain(値, 最小値, 最大値)`** を追加して移動範囲を画面内に制限します。

```javascript
// draw() の一番下に追加
// 画面外へのはみ出しを防止（スプライトの中心座標なので幅・高さの半分を余白にする）
player.x = constrain(player.x, player.w / 2, width - player.w / 2);
player.y = constrain(player.y, player.h / 2, height - player.h / 2);
```

<aside>
💡

**ポイント: なぜ直接座標（`player.x +=`）ではなく `player.vel` を使うのか？**
p5playのスプライトは物理エンジンで動いています。速度（`vel`）を与えて動かすことで、後ほど敵と衝突した際の当たり判定が正確に計算され、慣性やコライダーの挙動もスムーズになります。

</aside>

## 2-3. オート連射弾（`bullets` グループ）の実装

プレイヤーの前方から、一定間隔（8フレームごと）で自動的に弾が発射されるようにします。

```javascript
let bullets;

// setup() 内に追加
bullets = new Group();
bullets.w = 6;
bullets.h = 16;
bullets.color = '#ffffff';
bullets.collider = 'none'; // 弾同士の物理反発は不要
```

`draw()` 内で定期発射と画面外削除を行います：

```javascript
// draw() 内に追加
// 8フレームごとに自機から自動発射（オート連射）
if (frameCount % 8 === 0) {
  let b = new bullets.Sprite(player.x, player.y - player.h / 2);
  b.vel.y = -14; // 高速で上方へ飛ぶ
}

// 画面上部から消えた弾をメモリ解放（削除）
for (let b of bullets) {
  if (b.y < -20) {
    b.remove();
  }
}
```

<aside>
⚠️

**【メモリ管理の鉄則】画面外に出た弾は必ず `remove()` する！**
弾を無限に生成し続けると、画面外に残ったスプライトが何百個にも増え、ブラウザの動作が急速に重くなってフリーズします。画面上部外（`b.y < -20`）に出た弾は必ず `b.remove()` で削除しましょう。

</aside>

## 2-4. 背景の流れる星屑（スターフィールド）

宇宙や大空を飛行しているスピード感を演出するため、上から下へ流れる星屑のパーティクルを配置します。

```javascript
let stars = [];

// setup() 内で星を初期化
for (let i = 0; i < 50; i++) {
  stars.push({
    x: random(width),
    y: random(height),
    speed: random(2, 6),
    size: random(1, 3)
  });
}

// 星屑の更新と描画を行う関数
function drawStars() {
  noStroke();
  fill(255, 255, 255, 180);
  for (let s of stars) {
    ellipse(s.x, s.y, s.size, s.size);
    s.y += s.speed;
    if (s.y > height) {
      s.y = 0;
      s.x = random(width);
    }
  }
}
```

`draw()` の冒頭で `background()` の直後に `drawStars();` を呼び出します。

## 3-1. 敵グループの定義とスポーン

自機と同様に、敵キャラクター用の画像（`assets/enemy_day.png`）を `preload()` で読み込み、`enemies` グループに設定します。
グループに対して `.img` や `.scale` を設定しておくと、そのグループから生成されるすべての敵スプライトに自動で画像とサイズが適用されます。

```javascript
let enemies;
let enemyDayImg;
let score = 0;

// preload() 内に追加
enemyDayImg = loadImage('assets/enemy_day.png');

// setup() 内に追加
enemies = new Group();
enemies.img = enemyDayImg;
enemies.scale = 0.15;         // 画像サイズに合わせて調整
enemies.w = 34;               // 当たり判定（コライダー）の幅
enemies.h = 34;               // 当たり判定（コライダー）の高さ
enemies.collider = 'kinematic'; // 自機や弾を押しのけないようキネマティックに
```

`draw()` 内で定期的に敵をスポーンさせます：

```javascript
// 40フレームごとに上空からランダムに出現
if (frameCount % 40 === 0) {

// 画面下部に消えた敵を削除
```

## 3-2. 弾と敵の衝突（`overlaps`）

p5playのグループ判定を使えば、わずか数行で衝突処理が書けます。

```javascript
// setup() 内に追加

bullets.overlaps(enemies, (bullet, enemy) => {
  bullet.remove(); // 弾を消す
  enemy.remove();  // 敵を消す
  score += 100;    // スコア加算
});

// 自機と敵が当たったときの処理
player.overlaps(enemies, (p, enemy) => {
  enemy.remove();
  console.log('💥 GAME OVER!');
```

## 5-4. Arduinoスケッチ（CSVシリアル送信）

Arduino IDEを開き、以下のスケッチをArduinoに書き込みます。
3つのアナログ値（`joyX`, `joyY`, `light`）をカンマ区切り（CSV）で1行にまとめて送信します。

```cpp
/**
 * 07_controller.ino
 * ジョイスティック（A0, A1）と明るさセンサー（A2）の値を
 * カンマ区切りのCSV形式でPCへ高速送信する
 */

const int PIN_JOY_X = A0; // ジョイスティック X軸（左右）
const int PIN_JOY_Y = A1; // ジョイスティック Y軸（上下）
const int PIN_LIGHT = A2; // 明るさセンサー（CdSセル）

void setup() {
  Serial.begin(9600); // 9600bpsでシリアル通信開始
}

void loop() {
  int joyX  = analogRead(PIN_JOY_X);
  int joyY  = analogRead(PIN_JOY_Y);
  int light = analogRead(PIN_LIGHT);

  // CSV形式で送信: "512,508,680\n"
  Serial.print(joyX);
  Serial.print(",");
  Serial.print(joyY);
  Serial.print(",");
  Serial.println(light);

  delay(20); // 約50fpsで送信
}
```

書き込んだら、Arduino IDEの「シリアルモニタ」（9600 baud）でスティックを動かした時、手で覆った時に数値が変化することを確認しましょう。
**確認が終わったら、必ずシリアルモニタを閉じてください。**

## 6-1. `js/sensor.js` の追加

`07/js/` フォルダの中に、Web Serial API 受信モジュール `sensor.js` を作成します。

このモジュールは以下の役割を持ちます：
1. Arduinoから届く `512,509,720` をパースする。
2. スティックの静止時のブレを無視する **「デッドゾーン（不感帯）」** を処理し、`-1.0 〜 +1.0` に正規化する。
3. 明るさセンサーの値をしきい値（`lightThreshold = 400`）と比較し、`isNight`（true/false）を自動判定する。

```javascript
// js/sensor.js
const Sensor = {
  isConnected: false,
  joyX: 0,            // -1.0 (左) 〜 +1.0 (右)
  joyY: 0,            // -1.0 (上) 〜 +1.0 (下)
  rawLight: 700,      // 明るさ生値
  isNight: false,     // 昼夜フラグ
  lightThreshold: 400,// 昼夜しきい値
  deadZone: 40,       // ジョイスティック不感帯

  async connect() {
    if (!('serial' in navigator)) {
      alert('Google Chrome または Microsoft Edge を使用してください。');
      return;
    }

    try {
      const port = await navigator.serial.requestPort();
      await port.open({ baudRate: 9600 });
      this.isConnected = true;
      console.log('🟢 Arduinoに接続しました');

      const textDecoder = new TextDecoderStream();
      port.readable.pipeTo(textDecoder.writable);
      const reader = textDecoder.readable.getReader();

      let buffer = '';
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;

        buffer += value;
        const lines = buffer.split('\n');
        buffer = lines.pop();

        for (const line of lines) {
          const parts = line.trim().split(',');
          if (parts.length >= 3) {
            const rawX = parseInt(parts[0], 10);
            const rawY = parseInt(parts[1], 10);
            const rawL = parseInt(parts[2], 10);

            if (!isNaN(rawX) && !isNaN(rawY) && !isNaN(rawL)) {
              this.updateValues(rawX, rawY, rawL);
            }
          }
        }
      }
    } catch (err) {
      console.error(err);
      this.isConnected = false;
    }
  },

  updateValues(rawX, rawY, rawL) {
    // ジョイスティック加工（中心512基準）
    let dx = rawX - 512;
    let dy = rawY - 512;
    if (Math.abs(dx) < this.deadZone) dx = 0;
    if (Math.abs(dy) < this.deadZone) dy = 0;

    this.joyX = Math.max(-1, Math.min(1, dx / (512 - this.deadZone)));
    this.joyY = Math.max(-1, Math.min(1, dy / (512 - this.deadZone)));

    // 明るさ加工
    this.rawLight = rawL;
    this.isNight = (rawL < this.lightThreshold);
  }
};
```

### ✅ 練習4までの完成コード（`js/sketch.js`：センサー連携・最終完成形）

```javascript
// js/sketch.js（第6章・練習4までの完成コード：センサー連携版）
let player;
let playerImg;
let bullets;
let bulletImg;
let enemies;
let enemyDayImg;
let enemyNightImg;
let score = 0;
let isNight = false;
let stars = [];
const SPEED = 6;

function preload() {
  playerImg = loadImage('assets/player.png');
  bulletImg = loadImage('assets/bullet.png');
  enemyDayImg = loadImage('assets/enemy_day.png');
  enemyNightImg = loadImage('assets/enemy_night.png');
}

function setup() {
  new Canvas(480, 640);
  world.gravity.y = 0;

  // ① 自機スプライトの作成
  player = new Sprite(width / 2, height - 100);
  player.img = playerImg;
  player.scale = 0.15;
  player.w = 36;
  player.h = 36;
  player.rotationLock = true;

  // ② 弾グループの作成
  bullets = new Group();
  bullets.img = bulletImg;
  bullets.scale = 0.08;
  bullets.w = 10;
  bullets.h = 16;
  bullets.collider = 'none';

  // ③ 敵グループの作成
  enemies = new Group();
  enemies.scale = 0.15;
  enemies.w = 34;
  enemies.h = 34;
  enemies.collider = 'kinematic';

  // ④ 弾と敵の属性マッチング当たり判定
  bullets.overlaps(enemies, (bullet, enemy) => {
    if (bullet.type === enemy.type) {
      bullet.remove();
      enemy.remove();
      score += 100;
    } else {
      bullet.remove();
    }
  });

  // ⑤ 自機と敵が当たったときの処理
  player.overlaps(enemies, (p, enemy) => {
    enemy.remove();
    console.log('💥 GAME OVER!');
  });

  // ⑥ 背景の星屑を初期化
  for (let i = 0; i < 50; i++) {
    stars.push({
      x: random(width),
      y: random(height),
      speed: random(2, 6),
      size: random(1, 3)
    });
  }
}

function draw() {
  // ① 入力の受付（Arduino接続時はセンサー、未接続時はキーボード）
  if (Sensor.isConnected) {
    player.vel.x = Sensor.joyX * SPEED;
    player.vel.y = Sensor.joyY * SPEED;
    isNight = Sensor.isNight;
  } else {
    if (kb.pressing('left')) {
      player.vel.x = -SPEED;
    } else if (kb.pressing('right')) {
      player.vel.x = SPEED;
    } else {
      player.vel.x = 0;
    }

    if (kb.pressing('up')) {
      player.vel.y = -SPEED;
    } else if (kb.pressing('down')) {
      player.vel.y = SPEED;
    } else {
      player.vel.y = 0;
    }
    isNight = keyIsDown(32);
  }

  // ② 昼夜に応じた背景色の切り替え
  if (isNight) {
    background('#0a0b14'); // 漆黒の宇宙
  } else {
    background('#1a3b68'); // 澄んだ昼空
  }

  drawStars();

  // 画面外へのはみ出しを防止
  player.x = constrain(player.x, player.w / 2, width - player.w / 2);
  player.y = constrain(player.y, player.h / 2, height - player.h / 2);

  // ③ 8フレームごとに現在の属性（day / night）の弾を自動発射
  if (frameCount % 8 === 0) {
    let b = new bullets.Sprite(player.x, player.y - player.h / 2);
    b.vel.y = -14;
    b.type = isNight ? 'night' : 'day';
  }

  for (let b of bullets) {
    if (b.y < -20) {
      b.remove();
    }
  }

  // ④ 40フレームごとに「昼属性」または「夜属性」の敵を出現
  if (frameCount % 40 === 0) {
    let e = new enemies.Sprite(random(40, width - 40), -30);
    e.vel.y = random(2.5, 4.0);

    if (random() < 0.5) {
      e.type = 'day';
      e.img = enemyDayImg;   // 昼属性の敵画像
    } else {
      e.type = 'night';
      e.img = enemyNightImg; // 夜属性の敵画像
    }
  }

  for (let e of enemies) {
    if (e.y > height + 40) {
      e.remove();
    }
  }

  // ⑤ 画面上部のHUD（スコア＆モード表示）を描画
  drawHUD();
}

// 画面クリックでArduinoとのシリアル通信を開始
function mousePressed() {
  if (!Sensor.isConnected) {
    Sensor.connect();
  }
}

function drawStars() {
  noStroke();
  fill(255, 255, 255, 180);
  for (let s of stars) {
    ellipse(s.x, s.y, s.size, s.size);
    s.y += s.speed;
    if (s.y > height) {
      s.y = 0;
      s.x = random(width);
    }
  }
}

function drawHUD() {
  push();
  fill(0, 0, 0, 140);
  noStroke();
  rect(0, 0, width, 45);

  fill('#ffffff');
  textSize(16);
  textAlign(LEFT, CENTER);
  text(`SCORE: ${score}`, 20, 22);

  textAlign(RIGHT, CENTER);
  if (isNight) {
    fill('#e056fd');
    text('🌙 NIGHT MODE', width - 20, 22);
  } else {
    fill('#f1c40f');
    text('☀️ DAY MODE', width - 20, 22);
  }
  pop();
}
```
