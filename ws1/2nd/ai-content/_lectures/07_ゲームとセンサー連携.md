## 1-2. 今回作るゲーム：属性反転シューティング『Eclipse Striker』

今回制作するのは、縦スクロール型の本格シューティングゲーム **『Eclipse Striker（エクリプス・ストライカー）』** です。

```
              ┌────────────────────────┐
              │   ☀️ DAY / 🌙 NIGHT     │
              │  SCORE: 001200         │
              │                        │
              │     [⚪ 白の敵]        │
              │            [⚫ 黒の敵]  │
              │                        │
              │        | 弾 |          │
              │        |    |          │
              │        ▲ 自機          │
              └────────────────────────┘
```

### 🎮 コア・ルール（属性切り替えシステム）

- **自機はオート連射！**
  面倒なボタン連打は不要です。自機の前方から一定間隔で絶え間なく弾が発射されます。
- **☀️ 昼モード（光属性）**:
  - 画面全体が明るい昼空に！自機と弾が太陽ゴールドに発光します。
  - **白の敵（昼属性）を一撃粉砕！** しかし黒の敵には弾かれてノーダメージ。
- **🌙 夜モード（闇属性）**:
  - 画面が一瞬で漆黒の夜空・宇宙へと反転！自機と弾がダークパープルに発光します。
  - **黒の敵（夜属性）を一撃粉砕！** しかし白の敵には弾かれてノーダメージ。

まずはこのゲームを、**キーボード（矢印キーで移動、Spaceキー長押しで夜モード）** で動くように作っていきましょう！

## 2-2. 自機の生成とキーボード移動

縦長のアーケードゲーム画角（`480 x 640`）のキャンバスを用意し、自機スプライトを作成して矢印キーまたはWASDで動かします。

```javascript
// js/sketch.js
let player;
const SPEED = 6; // 自機の移動速度

function setup() {
  new Canvas(480, 640);

  // 今回は無重力（上下左右に自由に飛ぶため）
  world.gravity.y = 0;

  // 自機スプライトの作成
  player = new Sprite(width / 2, height - 100, 36, 36);
  player.color = '#f1c40f'; // 鮮やかなイエロー
  player.stroke = '#ffffff';
  player.strokeWeight = 2;
  player.rotationLock = true; // 回転防止
}

function draw() {
  background('#111424');

  // キーボードによる移動入力の受付
  let moveX = 0;
  let moveY = 0;
  if (kb.pressing('left') || kb.pressing('a')) moveX -= 1;
  if (kb.pressing('right') || kb.pressing('d')) moveX += 1;
  if (kb.pressing('up') || kb.pressing('w')) moveY -= 1;
  if (kb.pressing('down') || kb.pressing('s')) moveY += 1;

  // 速度を設定して滑らかに移動
  player.vel.x = moveX * SPEED;
  player.vel.y = moveY * SPEED;

  // 画面外へのはみ出しを防止
  player.x = constrain(player.x, player.w / 2, width - player.w / 2);
  player.y = constrain(player.y, player.h / 2, height - player.h / 2);
}
```

<aside>
💡

**ポイント: なぜ直接座標（`player.x +=`）ではなく `player.vel` を使うのか？**
p5playのスプライトは物理エンジンで動いています。速度（`vel`）を与えて動かすことで、後ほど敵と衝突した際の当たり判定が正確に計算され、慣性やコライダーの挙動もスムーズになります。

</aside>

## 2-3. オート連射弾（`bullets` グループ）の実装

プレイヤーの前方から、一定間隔（8フレームごと）で自動的に弾が発射されるようにします。

```javascript
let bullets;

// setup() 内に追加
bullets = new Group();
bullets.w = 6;
bullets.h = 16;
bullets.color = '#ffffff';
bullets.collider = 'none'; // 弾同士の物理反発は不要
```

`draw()` 内で定期発射と画面外削除を行います：

```javascript
// draw() 内に追加
// 8フレームごとに自機から自動発射（オート連射）
if (frameCount % 8 === 0) {
  let b = new bullets.Sprite(player.x, player.y - player.h / 2);
  b.vel.y = -14; // 高速で上方へ飛ぶ
}

// 画面上部から消えた弾をメモリ解放（削除）
for (let b of bullets) {
  if (b.y < -20) {
    b.remove();
  }
}
```

<aside>
⚠️

**【メモリ管理の鉄則】画面外に出た弾は必ず `remove()` する！**
弾を無限に生成し続けると、画面外に残ったスプライトが何百個にも増え、ブラウザの動作が急速に重くなってフリーズします。画面上部外（`b.y < -20`）に出た弾は必ず `b.remove()` で削除しましょう。

</aside>

## 2-4. 背景の流れる星屑（スターフィールド）

宇宙や大空を飛行しているスピード感を演出するため、上から下へ流れる星屑のパーティクルを配置します。

```javascript
let stars = [];

// setup() 内で星を初期化
for (let i = 0; i < 50; i++) {
  stars.push({
    x: random(width),
    y: random(height),
    speed: random(2, 6),
    size: random(1, 3)
  });
}

// 星屑の更新と描画を行う関数
function drawStars() {
  noStroke();
  fill(255, 255, 255, 180);
  for (let s of stars) {
    ellipse(s.x, s.y, s.size, s.size);
    s.y += s.speed;
    if (s.y > height) {
      s.y = 0;
      s.x = random(width);
    }
  }
}
```

`draw()` の冒頭で `background()` の直後に `drawStars();` を呼び出します。

# 4. 昼夜切り替えギミックと属性マッチング

いよいよ本作の最大の特徴である **「昼夜切り替え（属性チェンジ）」** を組み込みます！
まずは **Spaceキーを押している間は「夜」、離すと「昼」** に切り替わる仕組みとして作ります。

## 4-1. 昼夜の状態判定とビジュアル反転

真偽値の変数 `isNight` を用意し、Spaceキーの状態に応じて切り替えます。

```javascript
let isNight = false;

// draw() 内でキー判定と演出切り替え
isNight = keyIsDown(32); // 32 = Spaceキーのキーコード

if (isNight) {
  background('#0a0b14');    // 漆黒の宇宙
  player.color = '#9b59b6'; // 月の影（ダークパープル）
  player.stroke = '#e056fd';
} else {
  background('#1a3b68');    // 澄んだ昼空
  player.color = '#f1c40f'; // 太陽（ゴールドイエロー）
  player.stroke = '#ffffff';
}
```

発射する弾にも属性（`type`）を持たせます：

```javascript
if (frameCount % 8 === 0) {
  let b = new bullets.Sprite(player.x, player.y - player.h / 2);
  b.vel.y = -14;
  b.type = isNight ? 'night' : 'day';
  b.color = isNight ? '#e056fd' : '#ffffff';
}
```

## 4-2. 敵に「昼属性（白）」と「夜属性（黒）」を付与する

敵が出現する際、50%の確率で「白（Day）」または「黒（Night）」の属性を持たせます。

```javascript
if (frameCount % 40 === 0) {

    e.stroke = '#9b59b6';

```

## 4-3. 属性マッチング判定（撃破 vs 弾かれ）

弾と敵が衝突したとき、**「弾の属性」と「敵の属性」が一致している場合のみ撃破** できるように当たり判定を分岐します。

```javascript
bullets.overlaps(enemies, (bullet, enemy) => {
  // ① 属性が一致している場合 ➔ 撃破成功！
  if (bullet.type === enemy.type) {
    bullet.remove();
    enemy.remove();
    score += 100;
  } 
  // ② 属性が不一致の場合 ➔ 弾かれる！
  else {
    bullet.remove(); // 弾は消えるが敵は無傷！
  }
});
```

# 5. ハードウェアの準備と回路設計（フェーズ2）

キーボードで遊んでいたゲームを、**「右手：ジョイスティック」＋「左手：明るさセンサーに手かざし」** というフィジカルなアーケードスタイルへと進化させましょう！

---

## 5-1. 使用するパーツ一覧

| パーツ名 | 数量 | 役割 |
|---|:---:|---|
| **Arduino ボード** | 1台 | Nano R4 / Uno 等（PCとUSB接続） |
| **ジョイスティックモジュール（KY-023）** | 1個 | 自機のX軸（左右）・Y軸（上下）のアナログ移動 |
| **明るさセンサー（CdSセル）** | 1個 | 手をかざしたときの明暗（昼夜切り替え）検知 |
| **10kΩ 抵抗（茶・黒・橙・金）** | 1本 | CdSセルの分圧用プルダウン抵抗 |
| **ブレッドボード & ジャンパーワイヤ** | 一式 | 配線用 |

## 5-2. センサーの仕組みとピンアサイン

- **ジョイスティック（KY-023）**:
  - `VRX` ➔ Arduino **A0**（左右の傾き: 0〜1023、中央約512）
  - `VRY` ➔ Arduino **A1**（上下の傾き: 0〜1023、中央約512）
  - `+5V`, `GND` ➔ 電源ライン
  - （※オート連射のため、プッシュスイッチ `SW` は接続不要です！）
- **明るさセンサー（CdSセル）**:
  - 光が当たると抵抗値が下がり、暗くなると抵抗値が跳ね上がる。
  - 10kΩ抵抗と組み合わせて分圧し、Arduino **A2** で読み取る。
  - 明るい時：`600〜800` / 手で覆った時：`100〜300`

## 5-4. Arduinoスケッチ（CSVシリアル送信）

Arduino IDEを開き、以下のスケッチをArduinoに書き込みます。
3つのアナログ値（`joyX`, `joyY`, `light`）をカンマ区切り（CSV）で1行にまとめて送信します。

```cpp
/**
 * 07_controller.ino
 * ジョイスティック（A0, A1）と明るさセンサー（A2）の値を
 * カンマ区切りのCSV形式でPCへ高速送信する
 */

const int PIN_JOY_X = A0; // ジョイスティック X軸（左右）
const int PIN_JOY_Y = A1; // ジョイスティック Y軸（上下）
const int PIN_LIGHT = A2; // 明るさセンサー（CdSセル）

void setup() {
  Serial.begin(9600); // 9600bpsでシリアル通信開始
}

void loop() {
  int joyX  = analogRead(PIN_JOY_X);
  int joyY  = analogRead(PIN_JOY_Y);
  int light = analogRead(PIN_LIGHT);

  // CSV形式で送信: "512,508,680\n"
  Serial.print(joyX);
  Serial.print(",");
  Serial.print(joyY);
  Serial.print(",");
  Serial.println(light);

  delay(20); // 約50fpsで送信
}
```

書き込んだら、Arduino IDEの「シリアルモニタ」（9600 baud）でスティックを動かした時、手で覆った時に数値が変化することを確認しましょう。
**確認が終わったら、必ずシリアルモニタを閉じてください。**

## 6-1. `js/sensor.js` の追加

`07/js/` フォルダの中に、Web Serial API 受信モジュール `sensor.js` を作成します。

このモジュールは以下の役割を持ちます：
1. Arduinoから届く `512,509,720` をパースする。
2. スティックの静止時のブレを無視する **「デッドゾーン（不感帯）」** を処理し、`-1.0 〜 +1.0` に正規化する。
3. 明るさセンサーの値をしきい値（`lightThreshold = 400`）と比較し、`isNight`（true/false）を自動判定する。

```javascript
// js/sensor.js
const Sensor = {
  isConnected: false,
  joyX: 0,            // -1.0 (左) 〜 +1.0 (右)
  joyY: 0,            // -1.0 (上) 〜 +1.0 (下)
  rawLight: 700,      // 明るさ生値
  isNight: false,     // 昼夜フラグ
  lightThreshold: 400,// 昼夜しきい値
  deadZone: 40,       // ジョイスティック不感帯

  async connect() {
    if (!('serial' in navigator)) {
      alert('Google Chrome または Microsoft Edge を使用してください。');
      return;
    }

    try {
      const port = await navigator.serial.requestPort();
      await port.open({ baudRate: 9600 });
      this.isConnected = true;
      console.log('🟢 Arduinoに接続しました');

      const textDecoder = new TextDecoderStream();
      port.readable.pipeTo(textDecoder.writable);
      const reader = textDecoder.readable.getReader();

      let buffer = '';
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;

        buffer += value;
        const lines = buffer.split('\n');
        buffer = lines.pop();

        for (const line of lines) {
          const parts = line.trim().split(',');
          if (parts.length >= 3) {
            const rawX = parseInt(parts[0], 10);
            const rawY = parseInt(parts[1], 10);
            const rawL = parseInt(parts[2], 10);

            if (!isNaN(rawX) && !isNaN(rawY) && !isNaN(rawL)) {
              this.updateValues(rawX, rawY, rawL);
            }
          }
        }
      }
    } catch (err) {
      console.error(err);
      this.isConnected = false;
    }
  },

  updateValues(rawX, rawY, rawL) {
    // ジョイスティック加工（中心512基準）
    let dx = rawX - 512;
    let dy = rawY - 512;
    if (Math.abs(dx) < this.deadZone) dx = 0;
    if (Math.abs(dy) < this.deadZone) dy = 0;

    this.joyX = Math.max(-1, Math.min(1, dx / (512 - this.deadZone)));
    this.joyY = Math.max(-1, Math.min(1, dy / (512 - this.deadZone)));

    // 明るさ加工
    this.rawLight = rawL;
    this.isNight = (rawL < this.lightThreshold);
  }
};
```

## 6-3. `sketch.js` の入力をセンサーに差し替える

ここが最もエキサイティングな瞬間です！
`sketch.js` のキーボード入力部分を、`Sensor` の値に置き換えます。

```javascript
// 【変更前（キーボード）】
// let moveX = 0;
// if (kb.pressing('left')) moveX -= 1;
// ...
// isNight = keyIsDown(32);

// 【変更後（センサー連携）】
if (Sensor.isConnected) {
  // Arduino接続時はセンサー値で動かす
  player.vel.x = Sensor.joyX * SPEED;
  player.vel.y = Sensor.joyY * SPEED;
  isNight = Sensor.isNight;
} else {
  // 未接続時はキーボードで動かす（フォールバック）
  let moveX = 0;
  let moveY = 0;
  if (kb.pressing('left')) moveX -= 1;
  if (kb.pressing('right')) moveX += 1;
  if (kb.pressing('up')) moveY -= 1;
  if (kb.pressing('down')) moveY += 1;
  player.vel.x = moveX * SPEED;
  player.vel.y = moveY * SPEED;
  isNight = keyIsDown(32);
}
```

さらに、画面クリックでArduinoに接続できるように `mousePressed()` を追加します：

```javascript
function mousePressed() {
  if (!Sensor.isConnected) {
    Sensor.connect();
  }
}
```

本単元では、**「ソフトウェア（キーボード操作）先行でゲームの面白さを確実に作り、その後にハードウェア（センサー）を組み込んでフィジカル化する」** という開発プロセスを体験しました。

### 🌟 今回身についたコア技術

1. **2段階開発アプローチ**:
   複雑なハードウェア連携において、まずは純粋なゲームロジックを完成させてからセンサーに置き換える「堅牢な開発設計」。

   生のアナログスティックの微小なブレを吸収し、心地よいゲーム体験に仕立てるチューニング手法。

   単なる「ボタン押し」ではなく、「光を手で遮る」という身体的アクションをゲームのコアギミック（属性反転）へと昇華させるゲームデザイン。
