1-1. クラスとは？
クラスとは動作や状態を定義した雛形のようなもの。クラスからはインスタンスと呼ばれるオブジェクトを作成できる。また、オブジェクト作成時に実行される処理（コンストラクタ）を実装することにより、プロパティに設定される値などをオブジェクトごとに変更できる。

1-2. クラスの定義
【クラスの宣言】
class Person{

}

/*
クラス名はわかりやすい名前を
先頭の文字は大文字にするのが慣例
*/
【コンストラクタの設定】
class Person{
  constructor(){

  }
};

/*
コンストラクタはオブジェクト作成時に呼び出される特別なメソッド
1つのクラスに1つしか定義できない
*/
【引数の設定】
class Person{
  constructor(num){

  }
};

/*
引数に値を渡すことで、動作や状態をオブジェクトごとに変更できる
*/
【プロパティの設定】
class Person{
  constructor(num){
    this.age = num;
  }
};

/*
プロパティはオブジェクトの状態を定義するもの
プロパティには必ず「this」をつける
*/
【メソッドの設定】
class Person{
  constructor(num){
    this.age = num;
  }

  old() {
    this.age++;
  }
};

/*
メソッドはオブジェクトの動作（振る舞い）を定義するもの
メソッドはクラスの直下に記述する
*/
1-3. インスタンス化
クラスからオブジェクトを生成する処理をインスタンス化と呼び、インスタンス化によって生成されるオブジェクトをインスタンスと呼ぶ。


class Person{
  constructor(num){
    this.age = num;
  }

  old() {
    this.age++;
  }
};

const obj = new Person(42);
console.log(obj);

/*
インスタンスを生成するには「new演算子」を使う
*/
【プロパティの取得・変更】
class Person{
  constructor(num){
    this.age = num;
  }

  old() {
    this.age++;
  }
};

const obj = new Person(42);
console.log(obj.age);
console.log(obj['age']);

/*
生成されたインスタンスはオブジェクトなので、ドット記法またはブラケット記法でプロパティを取得できる
*/

obj.age = 52;
console.log(obj.age);

/*
後から変更も可能
*/
【メソッドの実行】
class Person{
  constructor(num){
    this.age = num;
  }

  old() {
    this.age++;
  }
};

const obj = new Person(42);

obj.old();
console.log(obj.age);
