# 05：しゅわしゅわハニーレモン

「05」直下の index.html を Live Server で開き、画面をクリックして再生・一時停止します。
音源は assets/しゅわしゅわハニーレモン350ml.mp3 です。

| 描画クラス | 役割 | 反応する音 |
| --- | --- | --- |
| SodaBubble.js | 帯域ごとに位置と弾け方が違う泡 | 低音・中音・高音 |
| LemonSlice.js | レモンの輪切りと回転 | 中音 |
| SodaIce.js | ふわっと弾む氷 | 低音 |
| SodaSparkle.js | 瞬く四つ角の光 | 高音 |

js/sketch.js は配置、再生、FFT、薄い水色の背景を担当します。
以前の WaveLine.js、Repple.js、Orb.js と楽譜のクラスはファイルとして残していますが、現在の index.html では読み込みません。

泡は下の蜂蜜色（低音）、中央のレモン色（中音）、上の水色（高音）に分かれます。低音は大きな輪と丸い粒、中音は二重の輪、高音は小さな粒が素早く散ります。
