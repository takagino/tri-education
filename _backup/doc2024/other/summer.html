2-1. デザインスクラップブック作成

【〆切】
10/1(火) 高木の最初の授業開始まで
【内容】

日常生活で見つけたデザイン物をスクラッピングして、1冊のスクラップブック（100ページ以上）を作ってください。

【手順】
  1. 各自「マルマン クロッキー帳 Sサイズ」を購入。（名駅の東急ハンズ11Fでも販売しています）
  2. 日常生活で見つけたデザイン物を、のりやマスキングテープなどで貼り付けていく。
  3. できるかぎり、感想や一言、いつどこで見つけたデザイン物なのかをメモする。
  4. 手書きのスケッチ、WebサイトのトレースなどもOK。（ただし、1/3程度に収めること）
  5. 1ページ内に空白が目立つ場合は、0.5ページとみなすことがあるので注意。
  6. （表紙も含め）可愛くデコレーションしてください。
  7. 各ページのどこかにページ番号を書いてください。
  8. 本日からスタート可。
【参考】
  • ウェブDeBlog「専門学校で夏休みの宿題はありますか？」
  • スクラッピングのススメ

2-2. BLOGマークアップ

【〆切】
9/6(金) 18:00まで
【内容】

Webデザインの授業で制作した「ブログ」をマークアップし、Web上で見れるようにする。

※集中授業で使用するので、必ず完成させてください。

【手順】
  1. デザイン通りにマークアップする。
  2. FTPクライアント（Cyberduck）でロリポップのサーバーに接続し、新規フォルダ「blog-html」を作成。
  3. マークアップしたデータをアップロード。
  4. 「http://○○(自分のURL)/blog-html/」にアクセスし、サイトが表示されることを確認。
  5. Discordのメッセージで、高木に上記URLを送信。
【サンプル】
  • 見本
  • zipファイル
【注意点】

  1. ページごとにHTMLファイルを作成すること。
  2. CSSファイルは1つにすること。（ページごとに分けない！）
  3. 共通部分とページごとのCSSを明確に分けること。 
    @charset "utf-8";

/* 共有部分
--------------------------------*/
body{

}

/* header */

/* footer */

/* post */

/* sidebar */

/*index.html
--------------------------------*/

/*single.html
--------------------------------*/

/*about.html
--------------------------------*/

/*contact.html
--------------------------------*/

/*メディアクエリ
--------------------------------*/
@media (min-width:700px){

}
  4. リセットCSSを読み込むこと。
  5. 「viewport」を設定すること。
  6. グローバルメニューや記事タイトルなどにリンクを設定すること。
  7. 「カテゴリーを複数設定する」「ページネーションを置く」など、さまざまな状態を想定すること。
  8. 「カテゴリーで絞り込んだページ」「検索結果のページ」「404ページ」などはマークアップしなくて良いが、ある程度考えておくこと。
  9. 見出しなど、ページごとに変わる可能性がある要素は「class名」で管理すること。
