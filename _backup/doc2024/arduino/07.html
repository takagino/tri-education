1. モジュールのインストール

npm経由でインストール＆読み込む（require）ことで、世界中の誰かさんが作成したモジュールを使用できる。

【npmとは】
正式名称は「Node Package Manager」。その名の通り、Node.jsのパッケージ（Package）を管理する（Manager）ツール。

公式サイト

1-1. 「package.json」の作成

実行中のプログラムの「名前」や「バージョン」、インストールされたモジュールの「名前」や「バージョン」などの情報が記載されているファイル。

【手順】
  1. 新規でフォルダを作成し、VSCodeで開く。
  2. ターミナルを表示、以下のコードを入力し「Enter」。 
    npm init
  3. 色々と出てくるが、すべて「Enter」を押して進める。
  4. VSCodeのファイル一覧に「package.json」が追加されれば完了。
  5. 中身を確認しておく。

※初期設定で作成する場合は「npm init -y」と入力すると便利。

1-2. 「johnny-five」のインストール

JavaScriptでArduino互換のボードを動かすことのできるモジュール。

公式サイト

【手順】
  1. ターミナルに以下のコードを入力し「Enter」。 
    npm install johnny-five
  2. VSCodeのファイル一覧に「node_modules」フォルダと、「package-lock.json」が追加されれば完了。
  3. 中身を確認しておく。
  4. 「package.json」の中身の変化も確認しておく。

2. 「johnny-five」の動作確認

2-1. Arduino側の設定

  1. PCとArduinoを接続。
  2. 「Arduino IDE」を立ち上げる。
  3. 『Select Board』の欄が「Arduino Uno」になっていることを確認。
  4. 『File > Examples > Firmata > StandardFirmataPlus』を開く。
  5. 検証 → 書き込み
  6. 書き込みが完了したらArduinoは終了する。

2-2. モジュール側の設定

  1. フォルダ内に新規ファイル「app.js」を作成。 
    touch app.js
  2. 公式のサンプルコードをコピペして保存。
  3. サンプルページの回路のようにLEDを準備。（足の長いほうが13ピン）
  4. ターミナルに以下のコードを入力し「Enter」。 
    node app.js
  5. ターミナルに「Ready!」と表示され、LEDが点滅したら成功。
  6. 終了はターミナルを選択し「control + c」2回。
【うまくいかない人は】
このサンプルのように、ポートを指定してやるとうまくいくかも。（ポート名はAdruinoのソフトウェアから確認）

2-3. モジュールの読み込み方法2種類

【使用する機能を個別に読み込む】
const { Board, Led } = require("johnny-five");
const board = new Board();

board.on("ready", () => {
  console.log("Ready!");

  const led = new Led(13);
  led.blink(500);
});
【すべての機能を一括で読み込む】
const five = require("johnny-five");
const board = new five.Board();

board.on("ready", () => {
  console.log("Ready!");

  const led = new five.Led(13);
  led.blink(500);
});

2-4. サンプルの確認

  • Board - Cleanup in 'exit' event
  • LED - Fade（LEDを13から11に差し替え）

  button.on("up", () => {

4. ブラウザからArduinoを操作する

4-1. 復習と準備

ブラウザからArduinoを操作するには、前回勉強したモジュール「fs」「http」「socket.io」が必要になる。

【手順】
  1. 「app.js」に下記のコードを記述し、保存。 
    const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;
const index = fs.readFileSync('./template/index.html', 'utf-8');

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    'Content-type': 'text/html'
  });
  res.end(index);
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});
  2. 新規フォルダ「template」を作成し、その中に新規ファイル「index.html」を作成。（可能ならばターミナルで操作する）
  3. 下記のコードをコピペし、保存。 
    <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Arduinoとの連携</title>
</head>
<body>
  <h1>トップページ</h1>
</body>
</html>
  4. ターミナルで「app.js」を実行。
  5. 「http://127.0.0.1:3000/」にアクセスし、動作確認。
  6. 確認後、「control + c」で動作終了しておく。

4-2. socket.ioの設定

【サーバー側の準備】
  1. ターミナルに以下のコードを入力して「Enter」。 
    npm install socket.io
  2. 「package.json」や「node_modules」ファルダを確認しておく。
  3. 「app.js」を以下のように変更する。 
    /* app.js */

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;
const index = fs.readFileSync('./template/index.html', 'utf-8');

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    'Content-type': 'text/html'
  });
  res.end(index);
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);

  //追加
  const io = require("socket.io")(server);
  console.log(io);
});
  4. ターミナルに多くの文字列が表示されたら準備完了。
【クライアント側の準備】
  1. 『template > index.html』を開く。
  2. 公式サイトから「CDN」のパスをコピーし、body要素の一番下にペースト。
  3. 「index.html」を以下のように変更する。 
    <!-- template/index.html -->

<body>
  <h1>トップページ</h1>

  <!-- socket.io CDN -->
  <script src="https://cdn.socket.io/4.6.0/socket.io.min.js" crossorigin="anonymous"></script>

  <!-- 追加 -->
  <script>
    const socket = io();
    console.log(socket);
  </script>
</body>
  4. ターミナルで「app.js」を実行。
  5. ブラウザのコンソールに「a」のようなオブジェクトが表示されたら準備完了。

4-3. ブラウザクリックでLEDを制御

template/click.html
<body>
  <!-- socket.io CDN -->
  <script src="https://cdn.socket.io/4.6.0/socket.io.min.js" crossorigin="anonymous"></script>

  <script>
    const socket = io();
    let flag = false;

    window.addEventListener('click', () => {
      flag = !flag; //ブラウザをクリックする度に「true」「false」を反転
      socket.emit("message", flag); //flagの値をサーバー側に送る
    });
  </script>
</body>
clcik.js
//ここから共通（各種モジュールの読み込みと設定）
const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;
const index = fs.readFileSync('./template/click.html', 'utf-8');

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    'Content-type': 'text/html'
  });
  res.end(index);
});

const five = require('johnny-five');
const board = new five.Board();
//ここまで共通

//Arduinoの準備が完了したら中括弧内を実行する
board.on("ready", () => {
  console.log("Arduino ready!");

  //Arduinoに接続するパーツの指定
  const led = new five.Led(13);

  //サーバーに接続する
  server.listen(port, hostname, () => {
    console.log(`Server running at http://${hostname}:${port}/`);

    //「Socket.io」の準備
    const io = require("socket.io")(server);

    //ブラウザが接続されたら中括弧内を実行する
    io.on("connection", (socket) => {
      console.log(`Connection completed!`);

      //ブラウザからメッセージが送られたら中括弧内を実行する
      socket.on("message", (recieve) => {
        //メッセージの値は「true」ならLEDをON
        if (recieve) {
          led.on();
        } else {
          led.off();
        }
      });
    });
  });

  //Arduinoとの通信が終了したらLEDを消す
  board.on("exit", () => {
    led.off();
  });
});

★ 応用

  1. マウスの位置でLEDを制御する。
  2. スクロール量でLEDを制御する。
  3. ブラウザのサイズでLEDを制御する。
  4. サーボモータを制御する。

5-1. センサーでCSSを変更する

template/sensor.html
<body>

  <!-- socket.io CDN -->
  <script src="https://cdn.socket.io/4.6.0/socket.io.min.js" crossorigin="anonymous"></script>

  <script>

sensor.js
const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;
const index = fs.readFileSync('./template/sensor.html', 'utf-8');

const server = http.createServer((req, res) => {
  res.writeHead(200, {
    'Content-type': 'text/html'
  });
  res.end(index);
});

const five = require('johnny-five');
const board = new five.Board();

board.on("ready", () => {
  console.log("Arduino ready!");

  //センサー用に変更
  const sensor = new five.Sensor({
    pin: "A0",
    freq: 30
  });

  server.listen(port, hostname, () => {
    console.log(`Server running at http://${hostname}:${port}/`);

    const io = require("socket.io")(server);

    io.on("connection", (socket) => {
      console.log(`Connection completed!`);

      //変化に応じて値を送る
      sensor.on("change", () => {
        io.emit('sensor_value', sensor.scaleTo(0, 255));
      });

    });
  });
});

★ 応用

5-2. ボタンでCSSを変更する

template/button.html
<body>

  <!-- socket.io CDN -->
  <script src="https://cdn.socket.io/4.6.0/socket.io.min.js" crossorigin="anonymous"></script>

  <script>
    const socket = io();
    let color = '#fff';

    socket.on('button_value', (recieve) => {
      console.log(recieve);

      if (recieve == 'press') {
        color = '#f00';
      } else if (recieve == 'hold') {
        color = '#0f0';
      } else {
        color = '#fff';
      }

      document.body.style.backgroundColor = color;
    });
  </script>
</body>
