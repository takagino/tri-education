1. データヴィジュアライゼーションとは？

データ可視化（データヴィジュアライゼーション）とは、数値データや情報をグラフィック内にある描画対象物（点や線や棒など）に符号化することで、それを情報伝達するのに用いられる技法を指す。その目的は、利用者に情報を明確かつ効率的に伝達することにある。それはデータ解析やデータサイエンスにおける段階の1つである。（- Wikipediaより）

1-1. インフォグラフックとの違い

【データビジュアライゼーション】
数字や単語が並んだ様々なデータをプログラムによって統計処理し、何らかの意味ある情報を見つけ出しやすくするもの。大量のデータの扱いに長けており、データの全体や一部分などを動的に再処理し出力ができる。
【インフォグラフィックス】
既に見つかっている意味ある情報を整理し、わかりやすく多くの人に興味を持ってもらうために表現するもの。静的にある一時のデータを表現するのは得意だが、データが変化した際には再度作り直す必要がある。

2-2. 要素の選択

【 d3.select(selector) 】
指定したセレクタに一致する一番最初の要素を返す
【 d3.selectAll(selector) 】
指定したセレクタに一致する全ての要素を返す
const container = d3.select("#container");
console.log(container);

const li = d3.selectAll("li");
console.log(li);

2-3. 要素の操作

【 sel.style(name, value) 】
要素に設定されているスタイルの値を取得、または変更する
const li = d3.selectAll("li");

//スタイルの値を取得 (第2引数なし)
console.log(li.style("color"));

//スタイルを変更
li.style("color", "#f00");
【 sel.attr(name, value) 】
属性を取得、または変更する
const container = d3.select("#container");

//属性を取得 (第2引数なし)
console.log(container.attr("id"));

//属性を変更
container.attr("class", "hoge");
console.log(container);
【 sel.classed(name, flag) 】
クラスを持っているかの確認、または追加・削除する
const container = d3.select("#container");

//クラスを持っているかの確認 (第2引数なし)
console.log(container.classed("container"));

const li = d3.selectAll("li");

//クラスの変更
li.classed("hoge fuga", true);

//クラスの削除
li.classed("hoge", false);
【 sel.text(value) 】
要素内のテキストを取得、または変更する
【 sel.html(value) 】
要素内のHTMLを取得、または変更する
const container = d3.select("#container");

//要素内のHTMLを取得 (引数なし)
console.log(wrap.html());

const li = d3.selectAll("li");

//要素内のテキストを変更
li.text("変更しました。");

2-4. メソッドチェーン

「(.)ドット」で繋げることで、複数のメソッド（命令）を続けて実行することが可能。

d3.selectAll("li").text("変更しました。");

2-5. 要素の追加・削除

【 sel.append(item) 】
要素を一番最後に追加する
d3.select("#container").append("h2").text("新規見出し");
【 sel.insert(item, before) 】
要素を指定した位置に追加する
d3.select("#container").insert("h2","ul").text("新規見出し");
【 sel.remove() 】
要素を削除する
d3.select("#container").remove();

ここまでは、JavaScriptやjQueryと挙動や仕組みは変わらない。

3. データのバインド

3-1. 「dataメソッド」と「enterメソッド」

const dataset = [1, 2, 3, 4, 5];

d3.select("#container").selectAll("p")
  .data(dataset)
  .enter()
  .append("p")
  .text("新規本文");
【dataメソッド】
指定された任意の値の配列（データセット）の項目と現在の選択との間に1対1の関係を確立する
【enterメソッド】
データの数に対して要素の数が足りない場合、差分のプレースホルダーを作成する

※プレースホルダーとは、実際の内容を後から挿入するために、とりあえず仮に確保した場所のこと。

3-2. 「dataメソッド」と「exitメソッド」

const dataset = [1];

d3.select("#container").selectAll("li")
  .data(dataset)
  .exit()
  .remove();
【exitメソッド】
要素の数に対してデータの数が足りない場合、差分の要素を選択する。

3-3. データを反映させる

1つ1つの要素に紐づけられた値を、関数を使って取り出す。

const dataset = [1, 2, 3, 4, 5];

d3.select("#container").selectAll("p")
  .data(dataset)
  .enter()
  .append("p")
  .text( (data) => data );
【スタイル属性に紐付ける】
const dataset = [1, 2, 3, 4, 5];

d3.select("#container").selectAll("p")
  .data(dataset)
  .enter()
  .append("p")
  .text( (data) => data )
  .style("font-size", (data) => `${data * 10}px`);

4. グラフの描画

D3.jsでグラフを描く際は、「SVG」の基本図形を使用することが多い。まずは「D3.js」で四角形を描いてみる。 

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>d3.js</title>
    <style>
      svg {
        background-color: #ddd;
      }
    </style>
  </head>
  <body>
    <div id="container">
    </div>

    <script src="https://cdn.jsdelivr.net/npm/d3@7"></script>
    <script>

      // svg要素を生成し変数に代入しておく
      const svg = d3.create("svg")
        .attr("width", 640)
        .attr("height", 480);

      // svg要素に四角形を追加
      svg.append("rect")
        .attr("x", 50)
        .attr("y", 50)
        .attr("width", 100)
        .attr("height", 50)
        .attr("fill", "#ff0000");

      // #containerに追加する（直接id名でいけるっぽい）
      container.append(svg.node());

    </script>
  </body>
</html>

4-1. データからSVGを描画

const dataset = [10, 30, 20, 40];

const svg = d3.create("svg")
  .attr("width", 640)
  .attr("height", 480);

svg.selectAll('rect')
  .data(dataset)
  .enter()
  .append("rect")
  .attr("x", 0)
  .attr("y", 0)
  .attr("width", 20)
  .attr("height", (data) => data)
  .attr('fill', '#ff0000');

container.append(svg.node());

※要素の検証をして、追加されているか確認してみる。

4-2. インデックス番号の活用

引数を入力値とした関数に、第2引数を設定すると、データのインデックス番号が取得できる。

5-1. オブジェクト型式のデータを扱う

const dataset = [
  { title: "シン・エヴァンゲリオン劇場版", num: 102.8 },
  { title: "名探偵コナン 緋色の弾丸", num: 76.5 },
  { title: "竜とそばかすの姫", num: 65.3 },
  { title: "東京リベンジャーズ", num: 44.7 },
  { title: "るろうに剣心 最終章 The Final", num: 43.4 }
];
const width = 640;
const height = 480;

const svg = d3.create("svg")
  .attr("width", width)
  .attr("height", height);

svg.selectAll('rect')
  .data(dataset)
  .enter()
  .append("rect")
  .attr("x", 0)
  .attr("y", (data, index) => index * 30)
  .attr("width", (data) => data.num) //ドットで繋げて指定する
  .attr("height", 20)
  .attr('fill', '#ffff00');

svg.selectAll('text')
  .data(dataset)
  .enter()
  .append("text")
  .attr("font-size", "14")
  .attr("x", (data) => data)
  .attr("y", (data, index) => index * 30 + 14) //ドットで繋げて指定する
  .text((data) => data.title);

container.append(svg.node());
