0. 補足

0-1. プログラミングのコツ

  1. 実現したい動きを分析し、「何のどの値がどう変化しているか」を明確にする。
  2. 手順を文章に書き起こす。（慣れてきたら頭の中で構築できるようになる）
  3. いきなり全てを実装しようとせず、簡単なことから順番にクリアしていく。（小さなまとまりで作業する）
  4. 「値を変化させたい場合」や「数箇所に同じ値が出てくる場合」には変数の使用を考える。
  5. 「もし〜なら」のような箇所が出てきたら条件分岐（if文）の使用を考える。
  6. プログラムは決められた命令の組み合わせでしかない。 
    例）問題03「円が100個になったらそれ以上増えない」の場合

if(円の数 > 100){
  円を描かない //「◯◯を描かない」という命令は無い
}

上記のプログラムは不可能なので、以下のように文章を変換する。

「円が100個になるまでは、円を描く」

if(円の数 <= 100){
  ellipse(mouseX, mouseY, 50, 50);
}
  7. おかしいと思ったらコンソールを見る。（常に表示しておいても良い）
  8. 上記のようなパターンをたくさんインプットし、自分でアレンジしてアウトプットする。
  9. プログラムが書けるようになるとめちゃくちゃ楽しいので、諦めないこと。

2. 変数

プログラムで使われる値を、名前付きで管理するラベルのようなもの。

【変数の使い所】
  1. 同じ値が何度も出てくるとき。
  2. 値を変化させたいとき。
【基本形】
let x = 50;
const y = 100; //定数
var w = 200; //古い書き方なので使用しない

ellipse(x, y, w, w);
【システム変数】
frameCount //ページ読み込み完了時から何フレーム経過したか（1秒間に60回）
width //描画領域の横幅 ※createCanvas(400, 400)の場合は「400」
height //描画領域の横幅 ※createCanvas(400, 400)の場合は「400」
mouseX //マウスのX座標の値
mouseY //マウスのY座標の値
pmouseX //1プレーム前のマウスのX座標の値
pmouseY //1フレーム前のマウスのY座標の値
mouseIsPressed //マウスがクリック状態にあるときにtrue（真）、ないときはfalse（偽）

3. 条件分岐

「もし〜なら」のように、条件によって処理を変えること。

【基本形】
if(条件式){
  //条件式に合致したときに行う処理
}
if(条件式){
  //条件式が「true」のときに行う処理
}else{
  //条件式が「false」のときに行う処理
}
if(条件式A){
  //条件式Aが「true」のときに行う処理
}else if(条件式B){
  //条件式Aが「false」、条件式Bが「true」のときに行う処理
}else{
  //上記の条件式が「false」のときに行う処理
}
【等価演算子】
演算子 用途 例 結果
A == B AとBが等しいことを確認 1 == 1 true
1 == 2 false
A != B AとBが等しくないことを確認 1 != 2 true
1 != 1 false
【関係演算子】
演算子 用途 例 結果
A < B AがBよりも小さいことを確認 1 < 2 true
A > B AがBよりも大きいことを確認 1 > 1 false
A <= B AがB以下であることを確認 1 <= 2 true
A >= B AがB以上であることを確認 1 >= 1 true
【論理演算】
// 論理和（OR） AまたはB
if(条件式A || 条件式B){
  //条件式A、条件式Bどちらかが「true」のときに行う処理
}

// 論理積（AND） AかつB
if(条件式A && 条件式B){ //false
  //条件式A、条件式Bどちらも「true」のときに行う処理
}

4. ランダム

【基本形】
//0.000.... 〜 0.999...の間のランダムな小数を取得する
Math.random();

//0.000.... 〜 9.999...の間のランダムな小数を取得する
Math.random() * 10;

//90.000.... 〜 99.999...の間のランダムな小数を取得する
Math.random() * 10 + 90;

//90〜99の間のランダムな整数を取得する（小数点以下切り捨て）
Math.floor(Math.random() * 10) + 90;
