2. 文字列

文字列（文字の並び）を扱う場合はシンブルクォート(')かダブルクォート(")で囲む。 

console.log("takagi"); //もしくは 'takagi'

2-1. 文字列の結合

//文字列同士は、プラス（+）の演算子を使って結合できる
console.log("takagi" + "hirotaka");

//文字列と数値を結合すると、数字は文字列に変換される
console.log("takagi" + "hirotaka" + 10);

//数値同士の計算との違いに注意する
console.log(20 + 10);
console.log("20" + 10);

//文字列と変数も結合できる
let job = "teacher";
console.log(job + "takagi" + "hirotaka" + 10);

2-2. テンプレートリテラル

テンプレートリテラルを使う場合はバッククォート(`)で囲む。
テンプレートリテラルは、文字列の中で改行をそのまま出力したり、式や変数を埋め込んだりすることができる。 

// 文字列
console.log(`Hello world`)

// 改行
console.log(`Hello
world`);

// 式
console.log(`2 + 5 equal ${2 + 5}`);

// 変数
const person = 'JS Taro';
console.log(`Hello ${person}`);
