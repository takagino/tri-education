さらに円を10個、20個、 100個描くプログラムを作ろうとしたとき、何度も同じ命令を記述するのは現実的ではない。
そんな時は繰り返し処理（for文）を使用すると良い。

2-1. 基本形

括弧内に「初期化処理」「ループ継続の条件式」「ループごとの最後に実行される式」をセミコロン（;）で区切ることで、繰り返し処理を設定する。 

for(初期化処理; ループ継続の条件式; ループごとの最後に実行される式){
  //ループ継続の条件式に合致している間、繰り返し処理される
}
【例】
function mousePressed(){
  for(let i = 0; i < 5; i += 1){
    ellipse(Math.random() * width, Math.random() * height, 50, 50);
  }
}
  1. 変数「i」を宣言し、値「0」を代入。
  2. ループ継続の条件式（i < 5）を検証し、条件に当てはまっていたら中括弧内の処理を実行。
  3. ループごとの最後に実行される式（i += 1）を実行。
  4. 上記2, 3を繰り返す。
  5. 条件に当てはまらなかったら（iが6になったら）、処理終了。
【変数「i」は中括弧内で使用可能】
function draw(){
  //console.log(frameCount);
}

function mousePressed(){
  for(let i = 0; i < 5; i += 1){
    console.log(i);
    ellipse(Math.random() * width, Math.random() * height, 50, 50);
  }
}

※「command + option + j」でコンソールを確認。

繰り返し処理の回数を数える変数のことをループカウンタといい、一般的に変数名に「i」が使われることが多い。
