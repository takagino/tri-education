「アルゴリズム」座標変換 練習01

練習01

  1. 座標変換を使い、ランダムな場所・角度・大きさの矩形を描く。 
function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  angleMode(DEGREES);
}

function draw() {
  translate(Math.random() * width, Math.random() * height);
  rotate(Math.random() * 360);
  scale(Math.random() * 2 + 0.5);

  rect(0, 0, 10, 10);
}
