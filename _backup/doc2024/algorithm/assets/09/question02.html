「アルゴリズム」配列問題

question05.html

  1. 「60, 120, 180, 240, 300, 360」の6つの値が入った配列を宣言する。
  2. 画面をクリックする度に、配列の値の色相（彩度、明度は50）の矩形を順番に描く。
  3. 6個以上は描けない。
  4. 矩形を6️個描いてから3秒経つと、矩形を消去しもう一度描画できる。

※難しい場合は途中までで良い。

const color = [60, 120, 180, 240, 300, 360];

function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw() {}

function mousePressed() {
  fill(180, 50, 50);
  rect(mouseX, mouseY, 50, 50);
}

question06.html

  1. ランダムな場所に矩形（四角形）を10個描く。
  2. 矩形には好きな半透明の色を設定する。
  3. マウスの位置と矩形の中心を線で結ぶ。
  4. マウスの位置と矩形の距離が遠いほど、矩形が大きくなる。
  5. 画面をクリックしたら、矩形の位置がランダムに変わる。

※難しい場合は1個だけでも良い。

question07.html

  1. 画面の中央からマウスの位置に線を描く。
  2. 画面をクリックする度にマウスの位置を記録し、線を描いていく。

question08.html

  1. 画面外のランダムな場所（X座標）からランダムなスピードで円を10個落とす。
  2. 画面の下まで来たらそれ以上は下がらない。
  3. マウスをクリックしている間は、一定のスピードで上にあがる。
  4. マウスを離すと、再度ランダムなスピードで下に落ちる。（最初とは違うランダムな値で良い）

※難しい場合は途中までで良い。

question09.html

  1. 画面の中心に円を5個描く。
  2. 最初の円はマウスに徐々に近づく。
  3. 2個目以降の円は、前の円に徐々に近づく。
