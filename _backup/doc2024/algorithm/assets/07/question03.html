「アルゴリズム」問題03

※毎回リロードしてください。

Level.1

  1. マウスをクリックしている間、マウスの位置に円を描く。
  2. 円が100個になったらそれ以上増えない。
【手順】
  1. もしマウスを押している間、マウスの位置に円を描く。
  2. 円の数を記録するために変数を宣言し、0 を代入しておく。
  3. 円を描くたびに変数の値を 1 増やす。
  4. もし円の数が100個になったら、それ以上は増えない。（もし変数の値が100未満の場合、円を描画する。）
  5. 論理演算を用いて条件分岐をまとめる。
let num = 0;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  if (mouseIsPressed && num < 100) {
    ellipse(mouseX, mouseY, 50, 50);
    num += 1;
  }
}

Level.2

  1. 円が増えるたびに大きくなる。
【手順】
  1. 円の大きさを、円の数と同じにする。
let num = 0;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  if (mouseIsPressed && num < 100) {
    ellipse(mouseX, mouseY, num, num);
    num += 1;
  }
}

Level.3

  1. 円を100個描き終わってから3秒経過すると消え、もう一度100個描くことが出来る。
【手順】
  1. frameCount が3秒（1秒で60）以上になったら、画面をクリアする。
  2. 同時に、円の数を記録している変数の値を 0 に戻す。
  3. マウスを押している間、frameCountを 0 に戻す
  4. 円が100個になる前にクリアされないように修正する。 
let num = 0;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  if (mouseIsPressed && num < 100) {
    frameCount = 0;
    ellipse(mouseX, mouseY, num, num);
    num += 1;
  }

  if (frameCount > 180 && num >= 100) {
    clear();
    num = 0;
  }
}
