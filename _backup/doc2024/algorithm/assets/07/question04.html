【補足】
function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  strokeCap(SQUARE); //追加
}

Level.1

  1. 色をランダムに変更しながら順番に線を描く。
【手順】
  1. 画面の上から下に線を描く。
  2. 横方向に移動させるために変数を宣言し、x座標の値を変数に置き換える。
  3. draw()が実行される度にx座標の値を増やす。
  4. 線の色相をランダムにする。
  5. x座標が画面幅よりも大きくなったら、それ以上は描画されないようにする。 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  strokeCap(SQUARE);
}

function draw(){
  if (x <= width) {
    stroke(Math.random() * 360, 50, 100);
    line(x, 0, x, height);
    x += 1;
  }
}

Level.2

  1. 線の太さもランダムにする。
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  strokeCap(SQUARE);
}

function draw(){
  if (x <= width) {
    strokeWeight(Math.random() * 30 + 10);
    stroke(Math.random() * 360, 50, 100);
    line(x, 0, x, height);
    x += 1;
  }
}

Level.3

  1. 画面上下で描く方向を変える。
【手順】
  1. 線の座標を「0 から 画面の半分」に変更する。
  2. さらに「画面の半分 から 画面の高さ」に新たな線を引く。
  3. 新たな線は画面の反対側から描画していく。（新たな変数は必要ない）
