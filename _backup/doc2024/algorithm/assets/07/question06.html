Level.1

  1. クリックした場所にランダムな大きさの円を1つ描く。
【手順】
  1. mouseReleased() を追加し、中括弧内にランダムな円を描くプログラムを書く。
  2. 今回、draw() の中には何も書かなくてもよい。（draw()自体を削除するとエラーになるかも） 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
}

function mouseReleased(){
  let w = Math.random() * 55 + 5;
  ellipse(mouseX, mouseY, w, w);
}

Level.2

  1. 円・矩形がランダムに出る。
【手順】
  1. 「もし◯◯になったら円を、そうでなければ矩形を描画する」という条件を自分で考えて追加する。
  2. 「Level.1」ですでにランダムの値は取得しているはずなので、それを流用すればよい。 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
}

function mouseReleased(){
  let w = Math.random() * 55 + 5;

  if (w < 30) {
    ellipse(mouseX, mouseY, w, w);
  } else {
    rect(mouseX, mouseY, w, w);
  }
}

Level.3 ※少し難問

  1. 円・矩形・三角がランダムに出る。
【手順】
  1. さらに分岐を追加する。
  2. ランダムな三角形は、三角形の中心をマウスの位置とし、計算をして3点の座標を割り出す。（正三角形でなくてよい） 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
}

function mouseReleased(){
  let w = Math.random() * 55 + 5;

  if (w < 20) {
    ellipse(mouseX, mouseY, w, w);
  } else if (w < 40) {
    rect(mouseX, mouseY, w, w);
  } else {
    triangle(
      mouseX,
      mouseY - w * 0.5,
      mouseX - w * 0.5,
      mouseY + w * 0.5,
      mouseX + w * 0.5,
      mouseY + w * 0.5
    );
  }
}
