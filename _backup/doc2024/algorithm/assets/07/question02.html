「アルゴリズム」問題02

Level.1

  1. 上から下に円を移動させる。
  2. 画面の外に出たら上に戻して移動を繰り返す。
【手順】
  1. x座標が幅の半分、y座標が画面上部の位置に円を描く。
  2. 変数を宣言し、y座標の値を変数に置き換える。
  3. draw()が実行される度にy座標の値を増やす。
  4. もし、y座標の値が画面の高さよりも大きくなったら、y座標の値を0に戻す。
  5. 円の大きさを考慮にいれて微調整する。
let y = 0;
let w = 50;
let speedY = 5;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  clear();
  ellipse(width / 2, y, w, w);
  y += speedY;

  if (y > height + w / 2) {
    y = -w / 2;
  }
}

Level.2

  1. 画面の端に当たったら跳ね返す。
【手順】
  1. もし、y座標の値が画面の高さよりも大きくなったら、移動スピードの符号を逆にする。
  2. もし、y座標の値が0よりも小さくなったら、移動スピードの符号を逆にする。
  3. 円の大きさを考慮にいれて微調整する。
  4. 論理演算を用いて条件分岐をまとめる。
let y = 0;
let w = 50;
let speedY = 5;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  clear();
  ellipse(width / 2, y, w, w);
  y += speedY;

  if (y < w / 2 || y > height - w / 2) {
    speedY = -speedY;
  }
}

Level.3 ※難問

  1. 画面の下で跳ね返るたび、上の端が下がっていく。
【手順】
  1. 跳ね返る基準となる線を画面上部に描く。
  2. 画面の下で跳ね返るたび、線を描画する位置を下げていく。
  3. 上で跳ね返る位置を「0」から「線の高さ」に変更する。
  4. 線の高さが円の大きさよりも小さくなったら、それ以上は変化しない。 
let y = 0;
let w = 50;
let speedY = 5;
let h = 0;

function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  clear();

  line(0, h, p.width, h);
  ellipse(width / 2, y, w, w);
  y += speedY;

  if (y < h + w / 2 || y > height - w / 2) {
    speedY = -speedY;
  }

  if (y > height - w / 2 && height - h > w) {
    h += 20;
  }
}
