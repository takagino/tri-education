「アルゴリズム」問題05

※毎回リロードしてください。

Level.1

  1. マウスを押している間、半透明でランダムな色の円をランダムな場所に描く。
【手順】
  1. もしマウスを押している間、画面内のランダムな位置に円を描く。
  2. 色相をランダムにし、半透明にする。
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  noStroke();
}

function draw(){
  if (mouseIsPressed) {
    fill(Math.random() * 360, 50, 50, 0.2);
    ellipse(Math.random() * width, Math.random() * height, 20, 20);
  }
}

Level.2

  1. マウスの周りにランダムに出現するように変更する。
【手順】
  1. 円が描画される場所を、マウスの位置に変更する。
  2. マウスの位置にランダムな値をプラスする。
  3. このとき、マウスの左側や上側にも円が出るように注意する。 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  noStroke();
}

function draw(){
  if (mouseIsPressed) {
    fill(Math.random() * 360, 50, 50, 0.2);
    ellipse(mouseX + Math.random() * 50 - 25, mouseY + Math.random() * 50 - 25, 20, 20);
  }
}

Level.3 ※少し難問

  1. たまに出るように調整する。
【手順】
  1. 「もし◯◯になった時だけ円を描画する」という条件を自分で考えて追加する。 
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  noStroke();
}

function draw(){
  if (mouseIsPressed && Math.random() < 0.1) {
    fill(Math.random() * 360, 50, 50, 0.2);
    ellipse(mouseX + Math.random() * 50 - 25, mouseY + Math.random() * 50 - 25, 20, 20);
  }
}
