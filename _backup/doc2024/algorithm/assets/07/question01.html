Level.2

  1. 同時にマウスの位置に円を描く。（大きさは自由）
  2. 塗りの色を設定する。（色は自由）
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  clear();
  line(width / 2, height / 2, mouseX, mouseY);

  fill(180, 50, 50);
  ellipse(mouseX, mouseY, 50, 50);
}

Level.3

  1. 中心から離れるほど円が大きくなる。
【手順】
  1. 2点間の距離を求める。
  2. 複数の箇所に使用するので、変数を宣言して代入しておく。
  3. 変数に代入した2点間の距離を、円の大きさに設定する。
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw(){
  clear();
  line(width / 2, height / 2, mouseX, mouseY);

  fill(180, 50, 50);
  const w = dist(width / 2, height / 2, mouseX, mouseY);
  ellipse(mouseX, mouseY, w, w);
}
