2-1. 配列とは

同じような値を管理するための変数が複数必要な時、その都度連番の変数を宣言していると非常に面倒くさいしカッコ悪い。
そんな時は「配列」を使用すると良い。

【変数】
  • 変数の宣言をすることで、1つの値を管理できる。

【配列】
  • 配列の宣言をすることで、複数の値を管理できる。
  • 配列全体には、変数と同じく任意の名前をつけることができる。
  • 配列には、先頭のデータから順番に「0、1、2…」というように番号がついていて、この番号のことを「インデックス」または「添字」と言う。

2-2. 配列の宣言

const 配列 = [値1, 値2, 値3, ...];

//例
const number = [40, 10, 30, 20];
console.log(number);

2-3. 配列の基本操作

【値の取得】
const number = [40, 10, 30, 20];
console.log(number[0]); //インデックスを指定し値を取得する
【値の変更】
const number = [40, 10, 30, 20];
number[1] = 0;
console.log(number);

//配列は「const（定数）」で宣言しているが、入っている値は後から変更できる
//配列自体を変更しようとするとエラーになる
number = [50, 60];
【値の追加】
const number = [40, 10, 30, 20];
number[4] = 50;
console.log(number);

//空の配列を宣言し、後から値を追加することもできる
const number = [];
number[0] = 50;
console.log(number);
【配列の長さ（値の数）を取得する】
const number = [40, 10, 30, 20];
console.log(number.length);

let d = [Math.random() * 50, Math.random() * 50];
let speed = [3, 3];

function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
}

function draw() {
  clear();

  ellipse(100, 100, d[0], d[0]);
  d[0] += speed[0];
  if (d[0] < 0 || d[0] > 100) {
    speed[0] = -speed[0];
  }

  ellipse(100, 200, d[1], d[1]);
  d[1] += speed[1];
  if (d[1] < 0 || d[1] > 100) {
    speed[1] = -speed[1];
  }
}

3. 繰り返し処理と配列

配列は「インデックス」で値を取得し、「インデックス」は基本的に連番（0,1,2,3...）になっているため、繰り返し処理（for文）と相性が良い。

【例01「値をすべて取り出す」】
const number = [40, 10, 30, 20];

for(let i = 0; i < number.length; i += 1){
  console.log(number[i]);
}
【例02「複数の値を代入する」】
const number = [];

for(let i = 0; i < 10; i += 1){
  number[i] = Math.random() * 10;
}
console.log(number);

☆練習01

拡大縮小する円のサンプルを修正し、円を10個に増やす。（場所もランダムにする） 

let x = [];
let y = [];
let d = [];
let speed = [];
const num = 10;

function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);

  for(let i = 0; i < num; i += 1){
    x[i] = Math.random() * width;
    y[i] = Math.random() * height;
    d[i] = Math.random() * 50;
    speed[i] = 3;
  }
}

function draw() {
  clear();

  for(let i = 0; i < num; i += 1){
    ellipse(x[i], y[i], d[i], d[i]);
    d[i] += speed[i];
    if (d[i] < 0 || d[i] > 100) {
      speed[i] = -speed[i];
    }
  }
}
