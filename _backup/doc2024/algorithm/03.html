1-1. 変数とは？

プログラムで使われる値を、名前付きで管理するラベルのようなもの。

【変数の使い所】
  1. 同じ値が何度も出てくるとき。
  2. 値を変化させたいとき。（今日はこちら）
let x = 50;
const y = 100; //定数
var w = 200; //古い書き方なので使用しない

circle(x, y, w, 100);

<!doctype html>
<html lang="ja">
  <head>

  <body>
    <script src="https://cdn.jsdelivr.net/npm/p5@1.9.2/lib/p5.js"></script>
    <script>
      //ページ読み込み時に1度だけ実行される
      function setup(){
        createCanvas(400, 400);
      }

      //ページを表示している間、1秒間に60回実行される
      function draw(){
        console.log(frameCount);
      }
    </script>
  </body>
</html>
frameCount
プログラムの開始以降に表示されたフレームの数（draw関数の実行回数）が格納されている。

※p5.jsに初めから定義されている変数をシステム変数という。

2-1. 値の更新

let x = 0; //変数宣言

function setup() {
  createCanvas(400, 400);
}

function draw() {
  x = x + 1; //変数xに1を足して、xに再代入する
  ellipse(x, 100, 50, 50);
}
【描画した図形を消す】
let x = 0;

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(255); //背景色で塗りつぶす
  clear(); //色を考慮しなくて良いので、こちらのほうが楽

  x = x + 1;
  ellipse(x, 100, 50, 50);
}

☆ 変数を宣言する場所に注意

draw関数の中で宣言すると、毎回別の変数として宣言される。

function setup() {
  createCanvas(400, 400);
}

function draw() {
  clear();

  let x = 0;
  x = x + 1;
  ellipse(x, 100, 50, 50);
}

setup関数の中で宣言するとエラーとなる。

function setup() {
  createCanvas(400, 400);
  let x = 0;
}

function draw() {
  clear();

  x = x + 1;
  ellipse(x, 100, 50, 50);
}

※letとconstは、宣言したブロック内（{}内）でしか使用できない。

2-2. 自己代入演算子

自己代入演算子を使うと、数値計算をより簡潔に記述することができる。 

x += 10;   //x = x + 10; と同じ
x -= 10;  //x = x - 10; と同じ
x *= 10;  //x = x * 10; と同じ
x /= 10;  //x = x / 10; と同じ
x %= 10;  //x = x % 10; と同じ
x **= 10;  //x = x ** 10; と同じ

☆ 練習

let x = 0;

function setup() {
  createCanvas(400, 400);
}

function draw() {
  //clear();

  line(x, 0, x, 400);
  x += 1;
}
let d = 0;

function setup() {
  createCanvas(400, 400);
}

function draw() {
  clear();

  ellipse(200, 200, d, d);
  d += 1;
}
