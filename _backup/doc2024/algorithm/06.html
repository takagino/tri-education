2. ランダム

ランダム（乱数）を使用すると、少ないコードで様々な作品を創ることができる。

【乱数とは】
0から9までの数字が不規則かつ等確率に現れるように配列されたもの。統計の無作為抽出や暗号に使う。

2-1. p5.jsの乱数

【基本形】
//0.000.... 〜 9.999...の間のランダムな小数を取得する
random(10);

//90.000.... 〜 99.999...の間のランダムな小数を取得する
random(90, 100);

//90〜99の間のランダムな整数を取得する（小数点以下切り捨て）
floor(random(90, 100));
function setup() {
  createCanvas(400, 400);

  console.log(random(10));
}

function draw() {}
【例】
function setup() {
  createCanvas(400, 400);
}

function draw() {
  rect(random(width), random(height), 50, 50);
}

☆練習

  1. 矩形の大きさをランダムにする。
  2. 塗りの色をランダムにする。
function setup() {
  createCanvas(400, 400);
  noStroke();
}

function draw() {
  fill(random(255), random(255), random(255));
  rect(random(width), random(height), random(5, 50), random(5, 50));
}

2-2. JavaScriptの乱数

【基本形】
//0.000.... 〜 9.999...の間のランダムな小数を取得する
Math.random() * 10;

//90.000.... 〜 99.999...の間のランダムな小数を取得する
Math.random() * 10 + 90;

//90〜99の間のランダムな整数を取得する（小数点以下切り捨て）
Math.floor(Math.random() * 10) + 90;
function setup() {
  createCanvas(400, 400);

  console.log(Math.random() * 10);
}

function draw() {}

3. マウスイベント

【今までに学んだマウス関連のシステム変数】
  • mouseX：マウスのX座標の位置
  • mouseY：マウスのY座標の位置
  • pmouseX：1フレーム前のマウスのX座標の位置
  • pmouseY：1フレーム前のマウスのY座標の位置
  • mouseIsPressed：マウスをクリックしていたら「true」、していないと「false」

それ以外に、マウスに何らかのアクション（マウスイベント）が起こった時に命令を実行する書き方がある。

3-1. mousePressed

マウスを押した時に1度だけ実行される。

function mousePressed() {
  console.log(true);
}
【例】
先程の練習問題のプログラムを改造し、「途中でマウスを動かしても矩形の場所は変わらない」ようにする。 
let x = 0;
let y = 0;

function setup() {
  createCanvas(400, 400);
  rectMode(CENTER);
  colorMode(HSB);
  noStroke();
}

function draw() {
  fill(Math.random() * 360, 100, 100, 0.5);

  if (mouseIsPressed) {
    let w = Math.random() * 45 + 5;
    rect(x, y, w, w);
  }
}

function mousePressed() {
  x = mouseX;
  y = mouseY;
}

3-2. mouseReleased

マウスを離した時に1度だけ実行される。

function mouseReleased() {
  console.log(true);
}
【例】
先程の練習問題のプログラムをさらに改造し、「マウスを離すと削除」されるようにする。 
let x = 0;
let y = 0;

function setup() {
  createCanvas(400, 400);
  rectMode(CENTER);
  colorMode(HSB);
  noStroke();
}

function draw() {
  fill(Math.random() * 360, 100, 100, 0.5);

  if (mouseIsPressed) {
    let w = Math.random() * 45 + 5;
    rect(x, y, w, w);
  }
}

function mousePressed() {
  x = mouseX;
  y = mouseY;
}

function mouseReleased() {
  clear();
}
