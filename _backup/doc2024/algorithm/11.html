2. 座標変換

【例）画面中央に矩形を描画】
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);

  rect(width / 2, height / 2, 50, 50);
}

function draw(){
}

上記プログラムを改造し、矩形を回転させたい。

【CSSの場合】
transformプロパティ解説！CSSアニメーションの基礎をおさえよう！
【p5.jsの場合】
Transform - p5.js Reference
【注意点】
p5.jsは、「canvas要素」に図形を描画することしかできず、一度描画したものを変形することはできない。
図形を変形するには、あらかじめ、座標空間を変換してから図形を描画する。

2-1. translate（移動）

【準備】
function setup() {
  createCanvas(400, 400);

  rectMode(CENTER);

  line(0, 0, width, 0);
  line(0, 0, 0, height);

}

function setup() {

  colorMode(HSB);
  rectMode(CENTER);

  translate(width / 2, height / 2); //移動

2-2. rotate（回転）

【単位を度数にする】
function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  angleMode(DEGREES); //単位を度数に変換

  translate(width / 2, height / 2);
  line(0, 0, width, 0);
  line(0, 0, 0, height);

  rect(0, 0, 50, 50);
}

function draw() {
}
【座標を45度回転する】
function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  angleMode(DEGREES);

  translate(width / 2, height / 2);
  rotate(45); //回転
  line(0, 0, width, 0);
  line(0, 0, 0, height);

  rect(0, 0, 50, 50);
}

}

2-3. scale（拡大・縮小）

【座標空間を2倍にする】
function setup() {

3. 座標空間の保存・復元

【例）矩形をランダムに回転する】
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  angleMode(DEGREES);

  translate(width / 2, height / 2);
  rotate(Math.random() * 360);
  rect(0, 0, 50, 50);
}

function draw(){
}

上記プログラムを改造し、回転していない矩形をもう1つ描画したい。

push();
現在の変形状態やスタイル設定を保存する。
pop();
保存した設定に復元する。

保存される設定一覧

【回転していない矩形をもう1つ描画する】
function setup(){
  createCanvas(400, 400);
  colorMode(HSB);
  rectMode(CENTER);
  angleMode(DEGREES);

  translate(width / 2, height / 2);

  push(); //設定の保存
  rotate(Math.random() * 360);
  rect(0, 0, 50, 50);

  pop(); //設定の復元
  rect(0, 0, 50, 50);
}

function draw(){
}
