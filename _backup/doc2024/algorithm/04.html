3. 条件分岐

プログラムの重要な制御構造の一つで、ある条件を指定すると実行時にこれを評価し、条件が満たされている場合に実行するコードと、満たされていない場合に実行するコードに分岐させることができる。

つまり、 「もし〜なら」のように、条件によって処理を変えること。

多くのプログラミング言語ではif文やswitch文などの条件文が用いられる。

3-1. 基本形

if(条件式){
  //条件式に合致したときに行う処理
}
【例】
function setup() {
  createCanvas(400, 400);
}

function draw() {
  console.log(mouseX, mouseY, mouseIsPressed); //追加

  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);
  strokeWeight(weight);

  //if文に変更
  if(mouseIsPressed){
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}
mouseIsPressed
マウスがクリック状態にあるときtrue（真）を返し、マウスがクリックされていないときはfalse（偽）を返す。
【真偽値】

真偽値は、true（真）またはfalse（偽）という値を取り、if文などの条件式と合わせて使われる。 

if(true){
  line(mouseX, mouseY, pmouseX, pmouseY);
}

3-2. 比較演算子

条件分岐のカッコ内「条件式」 を設定するには、「比較演算子」を理解しておく必要がある。

【等価演算子】
演算子 用途 例 結果
A == B AとBが等しいことを確認 1 == 1 true
1 == 2 false
A != B AとBが等しくないことを確認 1 != 2 true
1 != 1 false
【関係演算子】
演算子 用途 例 結果
A < B AがBよりも小さいことを確認 1 < 2 true
A > B AがBよりも大きいことを確認 1 > 1 false
A <= B AがB以下であることを確認 1 <= 2 true
A >= B AがB以上であることを確認 1 >= 1 true 
function setup() {
  createCanvas(400, 400);
}

function draw() {
  console.log(1 == 1, mouseX > 200); //変更

  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);
  strokeWeight(weight);

  if(mouseIsPressed){
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}

☆練習

サンプルのコードを改造し、線の太さを30以内に制限する。

【プログラムを考えるコツ】
  1. まずは文章で考えてみる。（もし、変数「weight」の値が30以上なら、変数「weight」に30を代入する）
  2. 現状の変数の値をコンソールに表示する。（console.log(weight);） 
function setup() {
  createCanvas(400, 400);
}

function draw() {
  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);

  //現状の変数の値をコンソールに表示する
  console.log(weight);

  //線の太さを30以内に制限
  if (weight > 30) {
    weight = 30;
  }

  strokeWeight(weight);

  if (mouseIsPressed) {
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}

☆練習2

サンプルのコードを改造し、「何も描かずに3秒経過したら描画した線が消える」ようにする。

【ヒント】
  1. 何がどうなったら3秒経過したことになるのかを考える。
function setup() {
  createCanvas(400, 400);
}

function draw() {
  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);
  if (weight > 30) {
    weight = 30;
  }
  strokeWeight(weight);

  //3秒経過したら描画した線を消す
  if (frameCount > 180) {
    clear();
  }

  if (mouseIsPressed) {
    frameCount = 0; //線を描画しはじめたらframeCountを0に戻す
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}

3-3. if...else文

if(条件式){
  //条件式が「true」のときに行う処理
}else{
  //条件式が「false」のときに行う処理
}
【例】
function setup() {
  createCanvas(400, 400);
}

function draw() {
  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);
  strokeWeight(weight);

  //追加
  if (mouseX > 200) {
    stroke(255, 0, 0);
  } else {
    stroke(0, 0, 255);
  }

  if (mouseIsPressed) {
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}

3-3. if...else文のチェーン

if...else文をチェーン（鎖）のようにつなげて記述することで、複数の条件式を使った分岐を作成できる。 

if(条件式A){
  //条件式Aが「true」のときに行う処理
}else if(条件式B){
  //条件式Aが「false」、条件式Bが「true」のときに行う処理
}else if(条件式C){
  //条件式A・Bが「false」、条件式Cが「true」のときに行う処理
}

//最後にelseブロックを追加することも可能
if(条件式A){
  //条件式Aが「true」のときに行う処理
}else if(条件式B){
  //条件式Aが「false」、条件式Bが「true」のときに行う処理
}else{
  //上記の条件式が「false」のときに行う処理
}
【例】
function setup() {
  createCanvas(400, 400);
}

function draw() {
  //clear();
  let weight = dist(mouseX, mouseY, pmouseX, pmouseY);
  strokeWeight(weight);

  //変更
  if (mouseX > 300) {
    stroke(255, 0, 0);
  } else if (mouseX > 200) {
    stroke(0, 255, 0);
  } else if (mouseX > 100) {
    stroke(0, 0, 255);
  } else {
    stroke(255, 255, 0);
  }

  if (mouseIsPressed) {
    line(mouseX, mouseY, pmouseX, pmouseY);
  }
}
【条件式の順番に注意】

}
