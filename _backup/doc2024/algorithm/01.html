「アルゴリズム」01_p5.jsの基礎

1. 準備

1-1. p5.jsの実行方法

  1. OpenProcessingで書く。
  2. 「p5.js Web Editor」で書く。
  3. パソコン上にp5.jsを読み込んで書く。

1-1. 事前準備

デスクトップが綺麗な人は、仕事が早い！

  1. 任意の場所に「アルゴリズム」用のフォルダを作成する。（command + shift + n）
  2. コマごとにデータをフォルダ分けする。（番号、日付、単元名などをフォルダ名にする「アルゴリズム / 01_p5.jsの基礎」）

1-2. HTMLファイルの準備

  1. 「Visual Studio Code」を立ち上げる。「ようこそ」などが開いている人は閉じておく。
  2. 先ほど作成したこの単元用のフォルダを、マウスでドラッグ&ドロップ。もしくは、メニュー『ファイル > フォルダーを開く...』でフォルダを選択。
  3. 「作成者を信頼しますか？」と聞かれたら、「親フォルダーすべてを信頼します」にチェックを入れ、「はい、作成者を信頼します」をクリック。
  4. 画面左側にマウスカーソルを移動すると下図のようなアイコンが表示されるので、「新規ファイル」をクリック。
  5. 「sample.html」と入力して「returnキー」を押す。
  6. フォルダ内にファイルが作成されていることを確認して、準備完了！
  • ※ネット上に公開するファイルは、すべてアルファベットで保存すること。（文字化けや読み込みエラーの原因になる）

  3. 一覧に「html.josn」が無い人は、入力欄に「html」と入力して選択。
  4. 以下のソースコードをコピペ。

2-2. ミスしないために

  • こまめに保存しブラウザで確認すること。
  • 「.」カンマ、「,」ピリオド、「:」コロン、「;」セミコロン、の違いを理解し適切に使用すること。
  • 「()」括弧、「{}」中括弧、の違いを理解し適切に使用すること。
  • 考えながらコードを書くこと。（ただただ写しているとスペルミスが起こる）

3. 図形の描画

function setup() {
  createCanvas(400, 400);

  //点を描く point(x座標, y座標);
  point(100, 100);

  //線を描く line(始点のx座標, 始点のy座標, 終点のx座標, 終点のy座標);
  line(20, 20, 50, 100);

  //矩形を描く rect(左上のx座標, 左上のy座標, 幅, 高さ);
  rect(50, 200, 50, 100);

  //円を描く ellipse(中心のx座標, 中心のy座標, 幅, 高さ);
  ellipse(200, 50, 50, 100);

  //三角形を描く triangle(1つ目のx座標, 1つ目のy座標, 2つ目のx座標, 2つ目のy座標, 3つ目のx座標, 3つ目のy座標);
  triangle(200, 200, 250, 200, 250, 150);
}
