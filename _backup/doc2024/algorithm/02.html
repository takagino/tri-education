2. 変数とは？

プログラムで使われる値を、名前付きで管理するラベルのようなもの。

【変数の使い所】
  1. 同じ値が何度も出てくるとき。
  2. 値を変化させたいとき。

2-1. 変数宣言

変数を使うには、まず変数の宣言を行う必要がある。JavaScriptの場合は「let」というキーワードを使用し、宣言することによって初めて変数名で値を管理できる状態になる。 

let 変数名 = 初期値;

//例
let d = 50;
circle(100, 100, d, d);

※プログラムにおける等号（=）は代入を表し、数式のような左辺と右辺の値が等しいことを表すわけではないことに注意。

【値の再代入】
letを使って宣言した変数の値は、後で上書きすることができる。 
let d = 50;
circle(100, 100, d, d);

d = 100;
circle(200, 100, d, d);
【値の再宣言】
同じ変数名で重複して変数宣言を行うことを値の再宣言と言う。letや後述するconstでは、変数の再宣言を行うとエラーになるので注意。 
let d = 50;
circle(100, 100, d, d);

let d = 100;
circle(200, 100, d, d);

2-2. コンソール

コンソールとは、コンピュータの入出力を行うための装置（入出力ウィンドウ）のこと。JavaScriptにおけるコンソールとは、一般的には各ブラウザの開発者ツール（GoogleChromeデベロッパーツールなど）に備わっているコンソールのことを指す。

【コンソールの使い所】
  1. どんなエラーが出ているのかチェックしたいとき。
  2. 変数の状態を調べたいとき。
  3. 動作確認をしたいとき。 などなど

コンソールを制するものがJavaScriptを制す！

【コンソールの起動方法】
  • ショートカット『option + command + j』
  • Chromeデベロッパーツールを起動して「Console」タブを選択する。

☆エラーの意味を調べてみる。（JavaScript エラーリファレンス）

2-3. 定数（const）

「const」キーワードは、再代入できない変数の宣言とその変数が参照する値（初期値）を定義できる。意図せず値が変更されるのを防げるためエラーを減らすことができる。 

const 変数名 = 初期値;

//例
const x = 300;
line(x, 100, x, 200);
【値を再代入しようとするとエラーになる】
const x = 300;
line(x, 100, x, 200);

x = 200;
//Assignment to constant variable.（定数変数への割り当て）
【宣言と同時に値を代入しないとエラーになる】
const x;
line(x, 100, x, 200);

//Missing initializer in const declaration.（定数の初期化忘れ）

2-4. 古い書き方（var）

「var」キーワードは、値の再代入が可能な変数を宣言できる。

var 変数名 = 初期値;

//例
var w = 100;
rect(0, 0, w, 50);
【varの問題】
「var」キーワードには同じ名前の変数を再定義できてしまう問題がありエラーが起こりやすいため、現在はあまり使われていない。 
var w = 100;
var w = 200;
rect(0, 0, w, 50);

2-5. 変数の命名規則（名前のルール）

let $; // OK: $が使用できる
let _title; // OK: _が使用できる
let jquery; // OK: 小文字のアルファベットが使用できる
let TITLE; // OK: 大文字のアルファベットが使用できる
let es2015; // OK: 数字は先頭以外なら使用できる
let 日本語の変数名; // OK: 一部の漢字や日本語も使用できる（しかし、基本は使用しない）

let na-me; // NG: -は使用できない
let name!; // NG: !は使用できない
let 1st; // NG: 数字から始まっている
let 123; // NG: 数字のみで構成されている

3. 演算子

演算子とは、値をもとに何らかの処理を行い、その結果を返す記号のこと。=や+の記号などがそれに当たる。そして、演算子によって処理される値は、オペランドと呼ぶ。

3-1. 算術演算子

数値計算に使う演算子を算術演算子と呼び、JavaScriptで使用できる算術演算子には以下のようなものがある。 

/* 加算 a + b */
console.log(6 + 9); //結果：15

/* 減算 a - b */
console.log(10 - 15); //結果：-5

/* 乗算 a * b */
console.log(3 * -7); //結果：-21

/* 除算 a / b */
console.log(10 / 5); //結果：2

/* 剰余 a % b （aをbで割ったときの余り） */
console.log(7 % 3); //結果：1

/* べき乗 a ** b （aのb乗） */
console.log(3 ** 2); //結果：9
【変数による計算】
let x = 200;
console.log(x + 10);

let y = 100;
console.log(x - y / 2);

日本の国旗を変数を使って描いてみる。

☆値を変更してみる。

【幅も変数にする】
let x = 200;
let w = 200;

//日本
rect(x - w / 2, 50, w, 120);
ellipse(x, 110, 60, 60);
【y座標と高さも変数にする】
let x = 200;
let y = 50;
let w = 200;
let h = 120;

//日本
rect(x - w / 2, y, w, h);
ellipse(x, y + h / 2, h / 2, h / 2);
