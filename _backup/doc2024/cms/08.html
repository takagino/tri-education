「CMS集中制作」08_本番環境へのアップロード

1. WordPressのインストール

ロリポップには、「WordPress簡単インストール」という機能があるが、今回は授業なのですべて手動で作業していく。

1-1. WordPressのダウンロード

公式サイトから「WordPress」の最新版をダウンロードし、解凍しておく。

1-2. データベースの作成

  1. 『ロリポップの管理画面メニュー > サーバーの管理・設定 > データベース』を選択。
  2. 「データベースを作成」ボタンをクリック。
  3. 情報の入力して「作成」ボタンをクリック。
  4. データベース名やホスト名は、後で使用するのでページは開いたままにしておく。

1-3. 「wp-config.php」の編集

ローカルでは、ブラウザ上でデータベース等の設定を行ったが、今回は直接ファイルを編集する。

  1. ダウンロード＆解凍したWordPressフォルダを「wordpress」から「blog」に変更。
    ※ファルダ名がURLの末尾になるので、任意の名前で。
  2. フォルダ内の「wp-config-sample.php」を複製する。
  3. 複製したファイルを「wp-config.php」に変更し、VSCodeで開く。
  4. 23行目あたりからの項目を以下のように変更する。（コピペするとスペースなどが入るので注意） 
    // ** Database settings - You can get this info from your web host ** //
/** The name of the database for WordPress */
define( 'DB_NAME', 'データベース名' );

/** Database username */
define( 'DB_USER', 'ユーザー名' );

/** Database password */
define( 'DB_PASSWORD', 'パスワード' );

/** Database hostname */
define( 'DB_HOST', 'データベースホスト' );

/** Database charset to use in creating database tables. */
define( 'DB_CHARSET', 'utf8' );

/** The database collate type. Don't change this if in doubt. */
define( 'DB_COLLATE', '' );
  5. ついでに、69行目あたりからの接頭辞も変更しておく 
    /**
* WordPress database table prefix.
*
* You can have multiple installations in one database if you give each
* a unique prefix. Only numbers, letters, and underscores please!
*/
$table_prefix = 'blog_';

1-4. WordPressのアップロード

  1. 「blog（ダウンロードしたwordpress）」フォルダごと、「Cyberduck」にドラッグ&ドロップ。
  2. アップロードが完了したら、「http://自分のロリポップのURL/bolg」にアクセス。
  3. ブログの情報を入力し、「WordPressをインストール」をクリック。（※ユーザ名以外は後で変更可能）

4. その他の設定

4-1. faviconの設定

  1. 管理画面メニュー『テーマ > カスタマイズ』を選択。
  2. 「サイト基本設定」をクリック。
  3. サイトアイコンを選択をクリックし、画像をアップロード。（512 x 512 ピクセル推奨）
  4. 設定が完了したら「公開」をクリック。
