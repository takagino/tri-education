1-2. 主なコマンド

コマンド 説明
pwd 「print working directory」の略。
現在のフォルダ（カレントディレクトリ）のパスを表示。
ls 「list」の略。
カレントディレクトリにあるファイルを表示。
cd 「change directory」の略。
指定したファイルに移動。 
cd xxx # xxxというファイルへ移動
cd ~/ # ホームディレクトリへ移動 [$ cd] や [$ cd ~] だけでも可能
cd .. # 一つ上の階層のファイルへ移動
cd ./ # 現在いるディレクトリ階層へ移動
cd ../.. # 今より２つ上の階層へ移動

cd Desktop # デスクトップへ移動（%の前に現在のフォルダが表示される）
※「cd 」の後にファイルをドラッグ・アンド・ドロップすることで、そのファイルまでのパスを表示できる。
touch 中身が空のファイルを作成する。 
touch xxx.js # xxx.jsという空ファイルを作成
mkdir 「make directory」の略。
ディレクトリ（フォルダ）を作成する。 
mkdir xxx # xxxというフォルダを作成
