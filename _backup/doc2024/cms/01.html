「CMS集中制作」01_環境構築

1. WordPressとは？

WordPressとは、オープンソースのブログ用CMSの一つ。PHPで開発されており、データベース管理システムとしてMySQLを利用している。利用者の増加やプラグインの導入により、ブログ以外のサイトにも使われるようになっている。

1-1. 関連用語

【オープンソース】
ソフトウェアのソースコードを無償で公開し、誰でも自由に改良・再配布ができるようにしたソフトウェア。
【CMS】
「Contents Management System：コンテンツ・マネジメント・システム」の略で、テキストや画像などのコンテンツを一元管理し、Web技術者以外がサイトの構築や編集を行えるようにするシステム。
【PHP】
「PHP: Hypertext Preprocessor」の略で、動的にWebページを生成するために用いられるプログラミング言語の一つ。
【データベース管理システム】
ハードディスクなどのストレージ装置（外部記憶装置）内に専用の管理領域を設け、データを記録するための構造体の作成や消去、構造の修正、データの書き込み、上書き、削除などを行う。

※後期に受験する「Webクリエイター能力認定試験」の知識問題に出題されるかも。

2. 開発環境の準備

HTMLやCSSは、自分のPC内（ローカルホスト・ローカル環境）に保存したファイルでもブラウザで確認できたが、WordPressなどのPHPで書かれたファイルは、サーバー上（リモートホスト・リモート環境）でないと表示や確認ができず、変更のたびにアップロードしなければならない。そこで今回は、PC内にサーバーと同じ環境を再現できる便利ツールを使用する。

【代表的なツール】
  • XAMPP（どちらかというと「Windows」向き）
  • MAMP（どちらかというと「Mac」向き）
  • Local by Flywheel（WordPressに特化したツール）

授業では「MAMP」を使用します。

2-1. MAMPとは？

MAMPとは「Macintosh」「Apache」「MySQL」「PHP」の頭文字をとったもので、それぞれのソフトウェアをまとめてインストールできる開発環境構築ツールのこと。

2-2. MAMPのダウンロード

本来は公式サイトからダウンロードするが、時間がかかるのでこちらでダウンロードしておきました。

  1. Finderメニュー『移動 > サーバへ接続...』を選択。
  2. 「smb://172.24.81.240」に接続。パスワードを聞かれたら入力（生年月日8桁）。
  3. 「pub_配布用folder」を選択し「OK」をクリック。
  4. 『2024 > WF1 > 後期 > CMS集中制作』にあるファイルを、デスクトップにドラッグ&ドロップ。

2-3. MAMPのインストール

  1. ドラッグ&ドロップしたファイルをダブルクリック。
  2. 手順に従ってインストール。
  3. アプリケーションフォルダ内に「MAMPフォルダ」と「MAMP PRO」がインストールされるので、『MAMPフォルダ > MAMP』を立ち上げる。（MAMP PROは使用しない）
  4. 「Get MAMP PRO」のメッセージが毎回出てきてウザいので、「Show this window when starting application」にチェックが入っている場合はチェックを外すし、ウィンドウを閉じる。

2-4. MAMPの起動

  1. 「Web server:」の項目を「Nginx」に変更し、右上の「Start」をクリック。
  2. 「Start」が「Stop」に変わり、自動的にスタートページが立ち上がったら起動完了。

※自動的にスタートページが立ち上がらない場合は「WebStart」をクリック

2-5. PHPファイルの表示

  1. 「Visual Studio Code」を立ち上げて、以下のソースコードを記述。 
    <?php echo "Hello World!"; ?>
  2. ファイル名「hello.php」、保存場所『アプリケーション > MAMP > htdocs』に保存。
  3. 先ほど立ち上がったスタートページのURLを「http://localhost:8888/hello.php」に変更してブラウザを再読み込み。
  4. 「Hello World!」と表示されたら成功！

2-6. ドキュメントルートの変更

毎回「hdocs」フォルダにアクセスするのは面倒なので、保存先を変更しておくと便利。

  1. 書類（Documents）などの任意の場所に「MAMP」フォルダを新規作成しておく。
  2. MAMPメニュー『MAMP > Preferences...』、もしくは左上の「Preferences」アイコンを選択。
  3. 「Server」タブを選択し、「Document Root:」の項目の「Choose...」ボタンをクリック。
  4. 作成した「MAMP」フォルダを選択し、「Choose」をクリック。
  5. 「OK」をクリックすると、MAMPのサーバーが自動的に再起動される。
  6. 先ほど作成した「hello.php」をコピーし、「Choose」で選んだフォルダ内にペーストする。
  7. 「http://localhost:8888/hello.php」を再読み込みして動作確認。

2-7. PHPのエラー表示

初期設定では、PHPの記述にエラーがあっても「動作していません」と表示されるだけで、どこが違うのかわからないので、最初に設定しておくと良い。

【わざと間違えてみる】
「echo」→「ech」に。 
<?php ech "Hello World!"; ?>
【手順】
  1. 「MAMP」の「WebStart」をクリックし、スタートページを開く。
  2. 上部メニュー『TOOLS > PHPINFO』を選択。
  3. 「Loaded Configuration File」の欄に記述された場所にある「php.ini」をエディタで開く。
  4. 505目あたりにある「display_errors = Off」を「display_errors = On」に変更し、保存。
  5. 「MAMP」のサーバーを再起動（Stop & Start）する。
  6. エラーが表示されることを確認して完了！

2-8. 拡張機能の導入

  • PHP Intelephense
  • Visual Studio CodeでWordPress関連の関数に赤い波線が表示されてエラーっぽくなる件の対処方法メモ
【PHP設定のメッセージが出る場合】
  1. VSCodeの歯車アイコンから「設定」を選択。
  2. 右上の「設定（JSON）を開く」をクリック。
  3. 中括弧（{}）の中に以下のソースコードをコピペ。 
    "php.validate.executablePath": "/Applications/MAMP/bin/php/php8.2.0/bin/php",
  4. 保存して閉じる。

2-9. ポート番号の変更

ポート番号とは、コンピュータが通信に使用するプログラムを識別するための番号のこと。IPアドレスを建物の住所にたとえるなら、ポートは個別の部屋、ポート番号は部屋番号に相当する。HTTP通信には通常「80番」が使用される。

ポート (コンピュータネットワーク) - Wikipedia -

WordPressで使用するポート番号は「8888」に設定されているため、「http://localhost:8888/」のようにURLにポート番号が表示される。ポート番号を「80番」に設定することで、「http://localhost/」のシンプルな形に変更することができる。

  1. MAMPメニュー『MAMP > Preferences...』、もしくは左上の「Preferences」アイコンを選択。
  2. 「Ports」タブを選択し、Set Web & MySQL ports to：「80 & 3306」をクリック。
  3. 「OK」をクリックすると、MAMPのサーバーが自動的に再起動される。
  4. 「http://localhost/hello.php」の表示を確認して完了！

※エラーが出る人は、他の通信とバッティングしている可能性があるため、初期設定に戻しておく。

以上で「MAMP」の設定は完了です。この授業では、常に「MAMP」のサーバーを起動しておいてください。

3. WordPressの構築

3-1. WordPressのダウンロード

公式サイトから「WordPress」の最新版をダウンロードし、解凍。

3-2. データベースの作成

Webサイトを構成するテキストや画像などを保存・管理するための「データベース」を、予め作成する。

【データベースとは】
ハードディスクなどのストレージ装置（外部記憶装置）内に専用の管理領域を設け、データを記録するための構造体の作成や消去、構造の修正、データの書き込み、上書き、削除などを行う。
  1. 「MAMP」の「WebStart」をクリックし、スタートページを開く。
  2. 上部メニュー『TOOLS > PHPMYADMIN』を選択。
  3. 上部タブ「データベース」をクリックし、下図のように設定し「作成」をクリック。
  4. 左側のデータベース一覧に「blog」が追加されたら完了！

※「phpMyAdmin」のページは後で確認するので、閉じないこと。

3-3. WordPressのインストール

  1. ダウンロード＆解凍したフォルダを「wordpress」から「blog」に変更。
  2. フォルダごと、MAMPのディレクトリルート（『書類 > MAMP』など）に移動。
  3. 「http://localhost:8888/blog/」にアクセス。（もしくは「http://localhost/blog/」）
  4. 画面に表示された内容を確認し、「さあ、始めましょう！」をクリック。
  5. 下図のように情報を入力し、「送信」をクリック。
  6. 「インストール実行」をクリック。
  7. ブログの情報を入力し、「WordPressをインストール」をクリック。（※ユーザ名以外は後で変更可能）
  8. インストール完了！ログインをすると管理画面が表示される。
  9. 管理画面左上の「ブログタイトル」から、サイトと管理画面を行き来できる。
【データベースの確認】
  1. 「phpMyAdmin」ページのデータベース一覧から「blog」をクリックし、データが保存されていることを確認する。
  2. 「blog_posts」に投稿データ、「blog_users」にユーザ情報、などが保存されており、それをサイト上に表示している。
