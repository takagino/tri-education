1. テンプレート階層

前回の授業資料で、記事一覧部分の設定は完了したので、次は記事詳細ページの設定をしていく。
「single.html」を修正していきますが、その前に「テンプレート階層」について理解する必要がある。

【テンプレート階層とは？】
  • WordPressのテンプレート階層とは？ページ種類別の優先順位
  • 一覧PDF
  • ファイル名を「single.php」にすると、記事詳細ページ（個別投稿ページ）として優先的に読み込まれる。
  • テーマフォルダ内に「single.php」が存在しない場合は「index.php」が読み込まれる。

1-1. 記事詳細ページの設定

  1. 「single.html」の拡張子を「single.php」に変更。
  2. 実際のサイトで「記事詳細ページ」に飛ぶか確認しておく。
  3. 「index.php」と全く同じように、テンプレートタグを挿入していく。
【index.phpとの違い】
  • 「the_excerpt()」を「the_content()」に変更する
  • 「続きを読む」ボタンを削除

1-2. 補足

【「single.php」にWordPressループは必要なのか？】
無くても記事の情報は取得できる。ただし、テンプレートタグによっては取得できないものもあるので、書いておくほうが無難。

2. テンプレートの分割

テンプレートファイルが増えてくると、同じ内容の部分が増えてくる。変更があった際に全てのファイルを修正するのは手間なので、別ファイルに分割しておくと便利。

2-1. 「header.php」を作成する

  1. エディタで新規ファイルを作成し、ファイル名「header.php」でテーマフォルダ内に保存する
  2. 「index.php」を開き、1行目から「</header>」までの共通部分を「header.php」にコピペする
  3. 「index.php」のコピペした部分を削除し、以下のテンプレートタグを挿入する 
    <?php get_header(); ?>
<main>
  <div class="contents">
    .
    .
  4. 同様に、「single.php」の共通部分も削除し、テンプレートタグを挿入する
  • ※トップページと記事詳細ページでファーストビューのデザインがガラッと違う場合は、「head要素まで」でも良い。（まとめる範囲は自由）

2-2. 「footer.php」を作成する

  1. エディタで新規ファイルを作成し、ファイル名「footer.php」でテーマフォルダ内に保存する
  2. 「index.php」を開き、「<footer>」から最後の行までの共通部分を「footer.php」にコピペする
  3. 「index.php」のコピペした部分を削除し、以下のテンプレートタグを挿入する 
      .
  .
  </main>
<?php get_footer(); ?>
  4. 同様に、「single.php」の共通部分も削除し、テンプレートタグを挿入する

2-3. 「sidebar.php」を作成する

  1. エディタで新規ファイルを作成し、ファイル名「sidebar.php」でテーマフォルダ内に保存する
  2. 「index.php」を開き、「<div class="sidebar">」の中身（aside3つ）を「sidebar.php」にコピペする
  3. 「index.php」のコピペした部分を削除し、以下のテンプレートタグを挿入する 
    <div class="sidebar">
  <?php get_sidebar(); ?>
</div>
  4. 同様に、「single.php」の共通部分も削除し、テンプレートタグを挿入する

3-2. 「index.php」にページ送りを表示する

サンプルサイトでは、ページネーション（1,2,3,4...）が想定されてるが、まずはシンプルな形で設定してみる。
ページネーションのHTMLは削除せずに、以下のソースコードを追加する。

  • previous_posts_link()
  • next_posts_link()
<div class="nav-page">
  <ul>
    <li><?php previous_posts_link(); ?></li>
    <li><?php next_posts_link(); ?></li>
  </ul>
</div>
【設定例】
<?php previous_posts_link('新しい記事へ'); ?>
<?php next_posts_link('古い記事へ'); ?>

3-3. 「index.php」にページネーションを表示する

  • the_posts_pagination()
<div class="nav-page">
  <?php the_posts_pagination(); ?>
</div>
【設定例】
<?php the_posts_pagination(array('prev_text' => '<', 'next_text' => '>')); ?>
<?php the_posts_pagination(array('prev_text' => '<', 'next_text' => '>', 'type' => 'list')); ?>

# 見やすいように改行しておくと良い
<?php
the_posts_pagination(
  array(
    'prev_text' => '<',
    'next_text' => '>',
    'type' => 'list'
  )
);
?>

# 条件を変数に代入しておくと、より見やすくなる（argument = 引数）
<?php
$arg = array(
  'prev_text' => '<',
  'next_text' => '>',
  'type' => 'list'
);
the_posts_pagination($arg);
?>
【出力したページネーションをデザインに合わせる】
  • 要素の検証で、出力された「要素」「クラス名」「CSS」を確認しながら、自作のCSSを変更していく。
  • ※「現在のページ」にはクラス名「current」が付いている。

4. アーカイブページの追加

だいたいのブログには、「特定の月に投稿された記事だけを表示する」「特定のカテゴリーに属した記事だけを表示する」など、記事を絞り込んで表示するページが存在する。WordPressでは、それぞれのページについても「テンプレート階層」の仕組みを使って、ファイル名で判別・表示することができる。

4-1. 「archive.php」を作成する

  2. 違いを出すために、以下のソースコードを追加する

4-3. WordPressの条件分岐タグ

細かく設定したいが、1行のためだけにファイルを増やすのが面倒くさい人は条件分岐タグを使用する。

便利なWordPressの条件分岐16パターン：カスタマイズで活躍するものを厳選！

【設定例】
# archive.php

<p>
  <?php if (is_category()) : ?>
    カテゴリー「<?php single_cat_title(); ?>」に属する記事一覧
  <?php elseif (is_tag()) : ?>
    タグ「<?php single_tag_title(); ?>」が設定された記事一覧
  <?php elseif (is_date()) : ?>
    「<?php echo get_the_date('Y年n月'); ?>」に投稿された記事一覧
  <?php else: ?>
    「<?php the_archive_title(); ?>」に関する記事一覧
  <?php endif; ?>
</p>

★ 応用

【別々のCSSを読み込んでいるけど「header.php」にまとめたい場合】
<?php if ( is_single() ) : ?>
  <link rel="stylesheet" href="<?php echo get_theme_file_uri('/css/single.css'); ?>">
<?php else: ?>
  <link rel="stylesheet" href="<?php echo get_stylesheet_uri(); ?>">
<?php endif; ?>

5. サブループの設定

前述した「WordPressループ」は、テンプレートの種類によって出力される記事が決まっている。このループのことを「メインループ」という。
それに対し、自分で条件や表示場所を自由に設定できるループのことを「サブループ」という。

【サブループの基本形】
<?php
$args = array(
  # 出力したい記事の条件を記述
);
$the_query = new WP_Query($args); #設定した条件でサブループを作成

if ( $the_query->have_posts() ): #サブループの条件に合う記事があったら
while ( $the_query->have_posts() ): #記事があるだけ繰り返す
$the_query->the_post(); #記事の情報を読み込む
?>

<article class="post">
</article>

<?php
endwhile;
endif;
wp_reset_postdata(); #サブループをリセットする
?>

WP_Queryの使い方をPHPコードにまとめた便利なコード・スニペット

5-1. 出力例

【特定のカテゴリーに属する記事を3件表示したい】
<?php
$args = array(
  'category_name' => 'design',
  'posts_per_page' => 3
);
$the_query = new WP_Query($args);

if ( $the_query->have_posts() ):
while ( $the_query->have_posts() ):
$the_query->the_post();
?>

<article class="post">
</article>

<?php
endwhile;
endif;
wp_reset_postdata();
?>
【記事をランダムに6件表示したい】
<?php
$args = array(
  'orderby' => 'rand',
  'posts_per_page' => 6
);
$the_query = new WP_Query($args);

if ( $the_query->have_posts() ):
while ( $the_query->have_posts() ):
$the_query->the_post();
?>

<article class="post">
</article>

<?php
endwhile;
endif;
wp_reset_postdata();
?>
