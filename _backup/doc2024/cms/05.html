「CMS集中制作」05_設定ファイルの追加

1. 設定ファイル「functions.php」

WordPressのテーマに必須のファイルの1つ。
使用したい機能を有効にしたり、独自の設定を定義したり、WordPressを使う上で必要なコードを記述するためのファイル。

★ディフォルトテーマ「twentytwentyfour」の「functions.php」を見てみる。

作成したテーマを公開し世界中の方々に使ってもらいたい場合は、ディフォルトテーマのように設定する項目が多くあるが、今回は必要最低限の項目に絞って説明します。

2. アイキャッチ画像の設定

2-1. アイキャッチ画像とは？

アイキャッチ画像とは、記事の初めに入れて読者の興味を惹いたり、記事の概要を表したりする画像のことを指す。
情報で溢れかえっている時代においてユーザーは文字情報よりもまず初めに画像を見ているため、記事を読んでもらうためには設定しておいたほうが良い。

【single.phpの画像を削除しておく】
# 「single.php」10行目あたりの下の一文を削除する
<img src="<?php echo get_theme_file_uri('/images/pic_post01.jpg'); ?>" alt="">

2-2. アイキャッチ画像の設定

【functions.phpの設定】
  1. エディタで新規ファイルを作成し、ファイル名「functions.php」でテーマフォルダ内に保存する。
  2. 以下のソースコードを記述し「保存」。 
    <?php
add_theme_support('post-thumbnails'); #アイキャッチ画像の設定
?>
  3. 『管理画面メニュー > 投稿一覧』から新規追加した記事をクリックし、編集画面に「アイキャッチ」の項目が増えていることを確認。
【記事にアイキャッチ画像を設定する】
  1. 追加された項目「アイキャッチ画像を設定」をクリック。
  2. 「メディアライブラリ」をクリック。
  3. 任意の画像をクリック。
  4. 「アイキャッチ画像を設定」をクリック。
  5. 投稿の編集を保存。
【設定したアイキャッチ画像をサイトに表示する】
  1. 「index.php」をエディタで開く
  2. 記事の画像部分を以下のように変更 
    <article id=post-<?php the_ID(); ?> <?php post_class('post'); ?>>
  <?php the_post_thumbnail('thumbnail'); ?>
  <h2 class="post-title"><?php the_title(); ?></h2>
    .
    .
  • the_post_thumbnail()
【サムネイルとその他サイズの違い】
  • サムネイル → 管理画面で設定したサイズにトリミングされる。主にアイキャッチ画像に使用する。
  • その他のサイズ → 元画像の縦横比を保ったまま管理画面で設定したサイズに縮小される。主に記事内の画像に使用する。

3. 「functions.php」のその他設定

3-1. 追加機能を読み込むタイミングの設定

「functions.php」にアイキャッチ画像の設定などの機能を追加する際、コードをそのまま書くと、何らかの原因でエラーが起こる可能性がある。
エラーを回避するために読み込むタイミングを設定しておく必要があり、その設定のことを「アクションフック」もしくは「フィルターフック」という。

# 「functions.php」を編集

<?php
#初期設定
function my_theme_support() {
  add_theme_support( 'post-thumbnails' ); #アイキャッチ画像の設定
};

add_action( 'after_setup_theme', 'my_theme_support' );
?>

3-2. タイトルタグの出力

head内のtitle要素を、ページに合わせて自動的に出力してくれる。

<?php
#初期設定
function my_theme_support() {
  add_theme_support( 'post-thumbnails' ); #アイキャッチ画像の設定
  add_theme_support('title-tag'); #タイトルタグの出力
};

add_action( 'after_setup_theme', 'my_theme_support' );
?>

★自分で書いたタイトル要素を削除し、表示を確認する。

【区切り文字の変更】
#区切り文字の変更
function change_title_separator( $sep ){
  $sep = ' | ';
  return $sep;
}
add_filter( 'document_title_separator', 'change_title_separator' );

3-3. RSSフィードの出力

<?php
#初期設定
function my_theme_support() {
  add_theme_support( 'post-thumbnails' ); #アイキャッチ画像の設定
  add_theme_support('title-tag'); #タイトルタグの出力

add_action( 'after_setup_theme', 'my_theme_support' );
?>

3-4. HTML5に変換

<?php
#初期設定
function my_theme_support() {
  add_theme_support( 'post-thumbnails' ); #アイキャッチ画像の設定
  add_theme_support('title-tag'); #タイトルタグの出力
  add_theme_support('automatic-feed-links'); #RSSフィードの出力
  add_theme_support('html5', array('comment-list', 'comment-form', 'search-form', 'gallery', 'caption', 'style', 'script')); #HTML5に変換
};

add_action( 'after_setup_theme', 'my_theme_support' );
?>

3-6. CSS、JSの読み込み

head要素内やbody要素内に直接読み込ませても良いが、functions.phpに記述することで他のファイルとバッティングすることなく動作させることが出来る。

  • wp_enqueue_style()
【詳細】
wp_enqueue_style( $handle, $src, $deps, $ver, $media );

$handle：識別するための任意の名前（英語で） ※必須
$src：ファイルまでのパス（絶対パス） ※必須
$deps：依存するファイル（array()形式で記述）
$ver：任意のバージョン（キャッシュが残りやすくなる）
$media：media属性の設定（'all', 'print', 'screen'）
【設定例】
#cssを追加
function my_style_output() {
  wp_enqueue_style('reset', 'https://unpkg.com/modern-css-reset/dist/reset.min.css');
  wp_enqueue_style('my-style', get_stylesheet_uri(), array('reset'), '1.0.0', 'all');
}
add_action('wp_enqueue_scripts', 'my_style_output');
  • wp_enqueue_script()
【詳細】
wp_enqueue_script( $handle, $src, $deps, $ver, $args );

$handle：識別するための任意の名前（英語で） ※必須
$src：ファイルまでのパス（絶対パス） ※必須
$deps：依存するファイル（array()形式で記述）
$ver：任意のバージョン（キャッシュが残りやすくなる）
$args：その他の設定（「true」にするとwp_footer()、「false」にするとwp_head()の場所に読み込まれる）
【設定例】
#jsを追加
function my_script_output() {
  wp_enqueue_script( 'my-script', get_theme_file_uri('/script.js'), array('jquery'), '1.0.0', true);
  //最後の値を「true」にするためには、他の値を省略できない
}
add_action('wp_enqueue_scripts', 'my_script_output');
【特定のページにのみcssやjsを読み込みたい場合】
#cssを追加
function my_style_output() {
  #全ページに読み込むファイル
  wp_enqueue_style('reset', 'https://unpkg.com/modern-css-reset/dist/reset.min.css');

  #ページ別に読み込むファイル
  if ( is_single() ) {
    wp_enqueue_style('my-style', get_theme_file_uri('/css/single.css'));
  }else{
    wp_enqueue_style('my-style', get_stylesheet_uri());
  }
}
add_action('wp_enqueue_scripts', 'my_style_output');

※これらの設定は覚える必要はない。大事なのは、コメントを明記し、後で見返せるようにしておくこと。

}
add_action('wp_enqueue_scripts', 'my_style_output');
