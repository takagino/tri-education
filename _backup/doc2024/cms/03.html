「CMS集中制作」03_テーマの作成

1. WordPressのテーマとは？

Webサイト全体のテンプレートのこと。テーマは複数のファイルの集合体でデザインや設定などが一式セットになっており、管理画面から簡単に切り替えることができる。

1-1. テーマを切り替えてみる

  1. 「MAMP」を立ち上げてサーバーを起動。
  2. 管理画面のURL（http://localhost/blog/wp-admin or http://localhost:8888/blog/wp-admin）にアクセスし、ログイン。
  3. 現状のデザインを確認しておく。
  4. 左側のメインメニュー『外観 > テーマ』を選択。
  5. 好きなテーマにマウスオーバーし、「有効化」をクリック。
  6. 左上の「ブログタイトル」をクリックし、サイトを確認してみる。

1-2. テーマの保存場所

テーマファイル一式は『wp-content > themes』に格納されており、自作したテーマを追加すると管理画面に表示される。

ちなみに、「WordPressフォルダ内のファイル」は以下の通り。

index.php Webサイトにアクセスがあったとき、最初に読み込まれるファイル
license.txt、readme.html ライセンスについての説明などを記載したファイル。アップロードの必要はない
wp-activate.php ユーザーアカウントに関するファイル
wp-admin 管理画面に関するファイルを格納するディレクトリ
wp-blog-header.php WordPressの環境に関連するファイルをロードするファイル
wp-comments-post.php コメント投稿に関するファイル
wp-config-sample.php インストール時にこのファイルを元に設定ファイルを作成することができるサンプルファイル。インストール後は「wp-config.php」という設定ファイルが生成される
wp-content テーマやプラグインなどに関するファイルを格納するディレクトリ
※基本的には、このディレクトリのみ追加・変更する
wp-cron.php PHPによる擬似cronジョブ（ある種のスケジューリング機能）を担うファイル
wp-includes WordPressのシステム全般に関するファイルを格納するディレクトリ
wp-links-opml.php リンクのXML出力に関するファイル
wp-load.php WordPressの動作に必要なプログラムをロードするファイル
wp-login.php 管理画面のログインに関するファイル
wp-mail.php メールによるブログ投稿用ファイル
wp-settings.php WordPressを動かすための変数・関数・クラスの基本設定
wp-signup.php ブログ名やユーザー名などの設定に関するファイル
wp-trackback.php トラックバックとPing送信用のファイル
xmlrpc.php XML-RPC通信に関するファイル
【フォルダを辿るのが面倒臭さい人は】
「wp-content」フォルダを、一時的にサイドバーの「よく使う項目」に追加してもOK。

1-3. テーマファイルの構成

『wp-content > themes』のにある各テーマの、ファイル構成を覗いてみよう。

たくさんのファイルが入っているが、最低限必要なファイルは以下の2つのみ。

  • index.php（すべてのページの元となるテンプレート）
  • style.css（ページのスタイルと「テーマの詳細」を記述する）

2. 最小テーマの作成

各自マークアップしてもらったデータはファイル構成が違い説明しずらいため、まずはこちらで用意したサンプルデータを使用します。

  1. サンプルデータをダウンロードして解凍。
  2. 「index.html」をブラウザで開き、全体像を把握しておく。（一通りみたら閉じる）
  3. フォルダ一式を『wp-content > themes』に移動。
  4. 管理画面にテーマが増えているか確認してみる。（現状は「壊れているテーマ」が表示される）
【index.phpの作成】
  1. 「index.html」の拡張子を「index.php」に変更。
  2. 管理画面にテーマ「blog-sample」が増えていることを確認し、「有効化」をクリック。
  3. サイトの表示を確認すると、CSSが反映されていないページが表示される。
  4. 管理画面に戻る。（上部のツールバーが消えてしまうため、管理画面に戻る場合はブラウザの「戻るボタン」）

2-1. 「テーマの詳細」を記述する

正式なテーマとして認識させるために、「style.css」の最初にコメントの形式で「テーマ詳細」を記述する必要がある。 

/*
Theme Name: テーマの名前（必須）
Theme URI: テーマの説明・配布サイトのアドレス
Author: テーマの作者名
Author URI: 作者のWebサイトのアドレス
Description: テーマの説明・紹介文
Version: テーマのバージョン情報（1.0など）
License: テーマに適応されるライセンス
License URI: ライセンス内容が記載されたWebページのアドレス
Tags: テーマの特徴などを示すタグ（テーマ検索時に使用）
Text Domain: テーマを国際化（翻訳対応）する際に必要な識別用の文字列
*/


# 以下の情報を入力。

/*
Theme Name: blog-sample
Theme URI:
Author: Tarou Yamada
Author URI:
Description: WordPressを学んで、最初のテーマです。
Version: 1.0
License: GNU General Public License v2 or later
License URI: http://www.gnu.org/licenses/gpl-2.0.html
*/

※メインメニュー『外観 > テーマ』から、追加したテーマをホバーし「テーマ詳細」を確認しておく。

2-2. スクリーンショットの設定

  1. ダミー画像をデスクトップに保存。
  2. ファイル名を「screenshot.png」に変更。
  3. テーマフォルダ「blog-sample」に移動。
  4. 管理画面を確認。

※ディフォルとのテーマフォルダ内の「screenshot.png」を見ると、サイズ「1200 x 900」が無難。

  • ※「style.css」がフォルダ内にある人は、もう一つ「style.css」を新規作成しフォルダの直下に保存すること。

4. WordPressループの作成

サンプルサイトのトップページのように、管理画面から投稿した記事をすべて表示したい場合、「WordPressループ」を使用する。WordPressループはWordPressの重要な機能の1つなので、しっかりと理解すること。

その前に、テンプレートタグを使って「body要素内」の情報を動的にしておく。

4-1. body要素内のテンプレートタグ

<body <?php body_class(); ?>>
  <?php wp_body_open(); ?>
  <div class="inner">
    <header>
      <h1><a href="<?php echo home_url('/'); ?>"><?php bloginfo('name'); ?></a></h1>
      <nav class="nav-global">
        <ul>
          <li><a href="<?php echo home_url('/'); ?>">HOME</a></li>
          <li><a href="about.html">ABOUT</a></li>
          <li><a href="contact.html">CONTACT</a></li>
        </ul>
      </nav>
    </header>
body_class()
ページやサイトの状態に合わせて、動的にクラス名を出力する
# ログイン前
<body class="home blog">

# ログイン後
<body class="home blog logged-in admin-bar no-customize-support">

// カッコ内に指定して、任意のクラスを追加することもできる
<?php body_class('test'); ?>
<body class="home blog logged-in admin-bar no-customize-support test">
home_url()
サイトのトップページのURLを返す
<?php echo home_url(); ?>
# http://localhost:8888/blog

<?php echo home_url('/'); ?>
# 末尾に「/」を付けたい場合はカッコ内に指定する
# http://localhost:8888/blog/

<?php echo home_url('/about/'); ?>
# トップページ以外のページに飛ばしたい場合もカッコ内に指定する
# http://localhost:8888/blog/about/

※「ABOUT」ページと「CONTACT」ページのリンクは、まだページ自体が存在しないので後回し。

5. ダミー記事のインポート

記事数が少ないと、今後カスタマイズする際に不便なので、今のうちにダミー記事をインポート（読み込み）しておくと良い。
今回は簡単に機能を追加できる「プラグイン」を使った方法を紹介する。

【手順】
  1. 管理画面メニュー『プラグイン > 新規プラグインを追加』を選択し、「プラグインの検索」欄に「fakerpress」と入力。
  2. プラグインが表示されたら「インストール」をクリックし、「有効化」をクリック。
  3. 管理画面メニューに「FakerPress」が追加されるので、『投稿』をクリック。
  4. 数量の1つ目の欄に「10」、日付を「過去15日間」、投稿者を「自分のユーザー名」にして「生成」をクリック。
  5. しばし待つ。生成が完了したら、管理画面メニュー『投稿 > 投稿一覧』と、サイトの表示を確認。
【記事の表示数変更】
ディフォルトでは10件表示されている
管理画面メニュー『設定 > 表示設定 > 1ページに表示する最大投稿数』から変更可能

6. 補足

6-1. 重大なエラーが出た場合

# 原因はテンプレートタグのスペルミスの可能性大。

正：<?php echo get_stylesheet_uri(); ?>
誤：<?php echo get_stylesheet_url(); ?>

正：<?php while( have_posts() ): the_post(); ?>
誤：<?php while( have_post() ): the_posts(); ?>

【重要】テンプレートタグを挿入するたびに、エラーチェックと出力チェックをすること！

6-2. a要素が勝手に閉じられる問題

WordPressでは、記事全体（articleやdiv）をa要素で囲むと「正しい書き方ではない」と判断して、a要素を勝手に閉じてしまう。その影響で、他の要素が勝手にa要素で囲われるなどレイアウトが崩れる。

<a href="<?php the_permalink(); ?>">
  <article class="post">
    <img src="<?php echo get_theme_file_uri('/images/pic_post01.jpg'); ?>" alt="">
    <h2 class="post-title"><?php the_title(); ?></h2>
    <p class="post-date"><?php the_time('Y年n月j日'); ?></p>
    <div class="post-contents">
      <?php the_excerpt(); ?>
    </div>
    <a class="post-btn" href="<?php the_permalink(); ?>">続きを読む</a>
  </article>
</a>

【解決策01】
全体ではなく、個別にリンクをつける。
<article class="post">
  <a href="<?php the_permalink(); ?>">
    <img src="<?php echo get_theme_file_uri('/images/pic_post01.jpg'); ?>" alt="">
  </a>
  <h2 class="post-title">
    <a href="<?php the_permalink(); ?>"><?php the_title(); ?></a>
  </h2>
  <p class="post-date">
    <a href="<?php the_permalink(); ?>"><?php the_time('Y年n月j日'); ?></a>
  </p>
  <div class="post-contents">
    <a href="<?php the_permalink(); ?>"><?php the_excerpt(); ?></a>
  </div>
  <a class="post-btn" href="<?php the_permalink(); ?>">続きを読む</a>
</article>
【解決策02】
a要素ではなく、JavaScriptでリンクを飛ばす。
# 記事要素（見本はarticle）に「カスタムデータ属性」を追加する

<article class="post" data-link="<?php the_permalink(); ?>">
  <img src="<?php echo get_theme_file_uri('/images/pic_post01.jpg'); ?>" alt="">
  <h2 class="post-title"><?php the_title(); ?></h2>
  <p class="post-date"><?php the_time('Y年n月j日'); ?></p>
  <div class="post-contents">
    <?php the_excerpt(); ?>
  </div>
  <a class="post-btn" href="<?php the_permalink(); ?>">続きを読む</a>
</article>
# 「wp_footer();」の直線にJavaScriptを追加する

  </footer>

  <script>
    window.addEventListener('DOMContentLoaded', () => {
      const post = document.querySelectorAll('[data-link]');
      for (const element of post) {
        element.addEventListener('click', () => {
          location.href = element.dataset.link;
        });
      }
    });
  </script>
  <?php wp_footer(); ?>
</body>

</html>
