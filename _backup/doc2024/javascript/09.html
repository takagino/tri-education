2-1. 組み込みオブジェクトとは？

組み込みオブジェクト（ビルトインオブジェクト）とは、JavaScriptエンジンによってあらかじめ提供されているオブジェクト群のこと。これらのオブジェクトには、WindowオブジェクトのようにJavaScriptエンジンによってすでにインスタンス化済みでそのまま使えるものもあれば、開発者がコンストラクタを呼び出して個別にインスタンス化を行ってから使うものもある。

3. Windowオブジェクト

Windowオブジェクトには、開発者がブラウザを操作するための機能や値が格納されてる。Windowオブジェクトは、開発者が書いたコードが実行される前にすでにwindowという識別子（オブジェクト名）で使用可能な状態となっており、このwindowを通してブラウザを操作する。

  console.log(history);

4. Mathオブジェクト

Mathオブジェクトには、数学的な定数と関数を提供するプロパティとメソッドが格納されている。

Mathオブジェクト - MDN

4-1. ランダム

//「0.0000...」から「4.9999...」までのランダムな小数を取得する
let num = Math.random() * 5;

//小数を切り捨てて、「0」から「4」までのランダムな整数を取得する
num = Math.floor(Math.random() * 5);

//「1」をプラスすることで、「1」から「5」までのランダムな整数を取得する
num = Math.floor(Math.random() * 5) + 1;

console.log(num);

5. Dateオブジェクト

Dateオブジェクトは、単一の瞬間の時刻をプラットフォームに依存しない形式で表す。Dateオブジェクトは協定世界時 (UTC) の「1970年1月1日」からの経過ミリ秒数を表す値を含んでいる。 

//現在の時間を取得する
let date = new Date();
console.log(date);

//「1970年1月1日」からの経過ミリ秒数を取得する
console.log(Date.now());
//時間や分を個別に取得する
let date = new Date();
console.log(date.getFullYear());
console.log(date.getMonth());
console.log(date.getDate());
console.log(date.getHours());
console.log(date.getMinutes());
console.log(date.getSeconds());
