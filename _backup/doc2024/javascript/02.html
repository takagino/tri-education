2. 変数とは？

なんらかの値（データ）を、名前をつけて保存しておく仕組みのこと。

【変数の使い所】
  1. 同じ値が何度も出てくるとき。
  2. 値を変化させたいとき。
【変数の基本的な使い方】
  1. 変数を宣言する。
  2. 宣言した変数に値を代入する。
  3. 必要な時に変数に保存された値を取り出す（参照）、または書き換える。

2-1. 変数宣言

変数を使うには、まず変数の宣言を行う必要がある。JavaScriptの場合は「let」というキーワードを使用し、宣言することによって初めて変数名で値を管理できる状態になる。

let 変数名; //変数の宣言
let 変数名 = 初期値; //宣言と同時に値を代入する

//例
let name = 'takagi';
console.log(name);

※プログラムにおける等号（=）は代入（代入演算子）を表し、数式のような左辺と右辺の値が等しいことを表すわけではないことに注意。

【値の再代入】
letを使って宣言した変数の値は上書きすることができる。なお、変数の値を変更することを値の再代入と言う。
let name = 'takagi';
console.log(name);

name = 'kawaguchi';
console.log(name);
【値の再宣言】
同じ変数名で重複して変数宣言を行うことを値の再宣言と言う。letや後述するconstでは、変数の再宣言を行うとエラーになるので注意。
let name = 'takagi';
console.log(name);

let name = 'kawaguchi'; //エラーとなる
console.log(name);

※どんなエラーが出るのか確認する。

2-2. 定数（const）

「const」キーワードは、再代入できない変数の宣言とその変数が参照する値（初期値）を定義でき、意図せず値が変更されるのを防げるためエラーを減らすことができる。

const 変数名 = 初期値;

//例
const name = 'takagi';
console.log(name);
【宣言と同時に値を代入しないとエラーになる】
const name;

//Missing initializer in const declaration.（定数の初期化忘れ）
【値を再代入しようとするとエラーになる】
const name = 'takagi';
name = 'hirotaka';

//Assignment to constant variable.（定数変数への割り当て）

※「getElementById();」など指定した要素を変数に代入する場合、あとから値を変更する可能性は低いので「const」で宣言するのが一般的。

const submit = document.getElementById('submit');

2-3. var

「var」キーワードは、値の再代入が可能な変数を宣言できる。

var 変数名 = 初期値;

//例
var name = 'takagi';
name = 'kawaguchi';
console.log(name);
【varの問題】
「var」キーワードには同じ名前の変数を再定義できてしまう問題がありエラーが起こりやすいため、現在はあまり使われていない。 
var name = 'takagi';
var name = 'kawaguchi';
console.log(name);

3. 変数のルール

3-1. 命名規則

let $price; // OK: $が使用できる

【複数の単語を組み合わせた変数名のパターン】
//スネークケース：単語と単語をアンダースコア(_)で結合し、すべて小文字で表現する
let member_name = 'takagi';

//キャメルケース：単語と単語を結合して、1つ目の単語は小文字で始め、2つ目以降の単語の先頭は大文字にする
//最近の主流
let memberName = 'takagi';

//パスカルケース：キャメルケースと似ているが、一番最初の単語も大文字で始める
//一般的に変数には使用しない
let MemberName = 'takagi';

※授業では「キャメルケース」を使用する。

4. 演算子

演算子とは、値をもとに何らかの処理を行い、その結果を返す記号のこと。これまで使ってきた=や+の記号などがそれに当たる。そして、演算子によって処理される値は、オペランドと呼ぶ。

4-1. 算術演算子

数値計算に使う演算子を算術演算子と呼び、JavaScriptで使用できる算術演算子には以下のようなものがある。

/* 加算 a + b */
console.log(6 + 9); //結果：15

/* 減算 a - b */
console.log(10 - 15); //結果：-5

/* 乗算 a * b */
console.log(3 * -7); //結果：-21

/* 除算 a / b */
console.log(10 / 5); //結果：2

/* 剰余 a % b （aをbで割ったときの余り） */
console.log(7 % 3); //結果：1

/* べき乗 a ** b （aのb乗） */
console.log(3 ** 2); //結果：9
【変数による計算】
let x = 1;

x = x + 1; //変数xの値に1を足して、変数xに再代入する
console.log(x);

x = x * 3; //変数xの値に3を掛けて、変数xに再代入する
console.log(x);

☆ 練習01（plus.html）

+ボタンをクリックする度に数字を1ずつ増やし、コンソールに表示するプログラムを考える。

見本

<body>
  <button id="plus">+</button>

  <script>

  </script>
</body>
【手順】
  1. クリック対象である「ボタン要素」を取得し、変数に代入する。
  2. 「ボタン要素」が代入された変数に「クリックイベント」を登録する。
  3. 「クリックイベント」が発生したら、コンソールに「何かしらの値」を表示する。
  4. 「何かしらの値」を「1ずつ増える数字」に変えるため、変数を用意する。
  5. 「クリックイベント」が発生したら、コンソールに「1ずつ増える数字」を表示するように修正する。
【正解】
<body>
  <button id="plus">+</button>

  <script>
    let num = 0;
    const plusBtn = document.getElementById('plus');

    plusBtn.addEventListener('click', function () {
      num = num + 1;
      console.log(num);
    });
  </script>
</body>

4-2. 自己代入演算子

自己代入演算子を使うと、上記のような数値計算をより簡潔に記述することができる。

/* 加算の自己代入 */
a += b

/* 減算の自己代入 */
a -= b

/* 乗算の自己代入 */
a *= b

/* 除算の自己代入 */
a /= b

/* 剰余の自己代入 */
a %= b

/* べき乗の自己代入 */
a **= b

★ 応用（plus.html）

  1. 自己代入演算子の形に修正する。
  2. クリックしたら-1するボタンを追加する。

5. 文字列

文字列（文字の並び）を扱う場合はシンブルクォート(')かダブルクォート(")で囲む。

let name = 'takagi';
console.log(name);

5-1. 文字列の結合

/* 文字列同士は、プラス（+）の演算子を使って結合できる */
console.log('takagi' + 'hirotaka');

/* 文字列と数値を結合すると、数字は文字列に変換される */
console.log(10 + 'px');

/* 文字列と変数を結合すると、変数の値によって結果は変わる */
let val = 1;
console.log('url(' + val + '.png)');

/* 数値と数値を結合すると、加算になる */
console.log(20 + 10);

5-2. テンプレートリテラル

テンプレートリテラルを使う場合はバッククォート(`)で囲む。
テンプレートリテラルは、文字列の中で改行をそのまま出力したり、式や変数を埋め込んだりすることができる。

// 文字列
console.log(`Hello world`)

// 改行
console.log(`Hello
world`);

// 式
console.log(`2 + 5 equal ${2 + 5}`);

// 変数
const person = 'JS Taro';
console.log(`Hello ${person}`);

<body>
  <div>
    <button id="left">←</button>

    /* 左矢印のプログラム */

      monster.style.transform = `translateX(${num -= 5}px)`;

    /* 右矢印のプログラム */
    const rightBtn = document.getElementById('right');
    right.addEventListener('click', function () {
      monster.style.transform = `translateX(${num += 5}px)`;
    });

    /* 初期位置に戻すプログラム */
    const centerBtn = document.getElementById('center');
    centerBtn.addEventListener('click', function () {
      monster.style.transform = `translateX(${num = 0}px)`;
    });
  </script>
</body>
