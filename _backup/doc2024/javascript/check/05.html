Vol.5「while文とfor文」

解答用Googleフォーム

Q1, Q2, Q3

0から100までの数をすべて足した結果をコンソールに表示したい。[ ]に入る適切なコードを答えなさい。

let num = 0;
let sum = 0;

while ([Q1]) {
  sum += [Q2];
  [Q3] += 1;
}
console.log(sum);
【正解】
let num = 0;
let sum = 0;

while (num <= 100) {
  sum += num;
  num += 1;
}
console.log(sum);

Q4, Q5, Q6

0から100までの数をすべて足した結果をコンソールに表示したい。[ ]に入る適切なコードを答えなさい。

let sum = 0;

for(let i = 0; [Q4]; [Q5]){
  sum += [Q6];
}
console.log(sum);
【正解】
let sum = 0;

for (let i = 0; i <= 100; i++) {
  sum += i;
}
console.log(sum);

Q7, Q8, Q9, Q10

for文を使って、コンソールに「0, 1, 2, 3, 4, 5」と表示したい。[ ]に入る適切なコードを答えなさい。

let text = 0;

for(let i = [Q7]; [Q8]; [Q9]){
  text += `[Q10]`;
}
console.log(text);
【正解】
let text = 0;

for (let i = 1; i <= 5; i++) {
  text += `,${i}`;
}
console.log(text);
