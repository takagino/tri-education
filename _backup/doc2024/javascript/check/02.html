Q1

以下のプログラムを書いた時、console（コンソール）に何と表示されるか答えなさい。

Q3

以下のプログラムを書いた時、console（コンソール）に何と表示されるか答えなさい。

<script>
  const num = 100;
  if(num === '100'){
    console.log('true');
  }else{
    console.log('false');
  }
</script>

【正解】
false
※「===」は厳密な比較のため、数値と文字列は区別される。

Q4

    console.log('true');
  }else{
    console.log('false');

【正解】
<script>
let num = 0;
const btn = document.getElementById('btn');
