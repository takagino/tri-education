JavaScript基礎チェック

Vol.1「変数と演算子」

問題

以下のプログラムを書いた時、console（コンソール）に何と表示されるか答えなさい。また、エラーがでる場合は「エラー」と記述すること。

解答用Googleフォーム

Q1

<script>
  const num = 100;
  console.log(num);
</script>

【正解】
100

Q2

<script>
  const today = '10月27日';
  today = '10月28日'
  console.log(today);
</script>

【正解】
エラー
※定数は宣言後に再代入できない。

Q3

<script>
  let name;
  console.log(name);
</script>

【正解】
undefined

Q4

<script>
  let 2nd = 'apple';
  console.log(2nd);
</script>

【正解】
エラー
※変数名の先頭に数字は使えない。

Q5

<script>
  let $year = 2020,
      _month = 10,
      DAY = 27;

  console.log(DAY);
</script>

【正解】
27

Q6

<script>
  let value = 1 + 10;
  console.log(value);
</script>

【正解】
11

Q7

<script>
  let value = 1 + '10';
  console.log(value);
</script>

【正解】
110
※数値と文字列の加算は、文字列として結合される。

Q8

<script>
  let value = 'Java' + 'Script';
  console.log(value);
</script>

【正解】
JavaScript

Q9

<script>
  let value = 10;
  value /= 2;
  console.log(value);
</script>

【正解】
5

Q10

<script>
  console.log(2 ** 3);
</script>

【正解】
8
※2の3乗。（2 * 2 * 2）
