「JavaScript基礎」01_JavaScriptの基礎

1. JavaScriptとは？

JavaScript（ジャバスクリプト）とは、プログラミング言語のひとつである。Javaと名前が似ているが、全く異なるプログラミング言語である。ウェブブラウザ上で動作し動的なウェブサイト構築やリッチインターネットアプリケーションの開発に用いられる。また、2010年以降はnode.jsなどのサーバサイドJavaScript実行環境や各種ライブラリの充実により、Web開発の全ての領域で活用されるようになってきている。

JavaScriptが辿った変遷

【Webを支える3大プログラミング言語の役割】
  • HTML : ブラウザ上に表示する内容と文書構造
  • CSS : ブラウザ上に表示する内容のレイアウトと装飾
  • JavaScript : ブラウザ上に表示した内容に動きをもたせる
【目指せる職業】
  • HTML+CSS : マークアップエンジニア
  • HTML+CSS+JavaScript : フロントエンドエンジニア
  • HTML+CSS+JavaScript+PHP : サーバーサイドエンジニア

1-1. 具体的に何が起こっているのか？

JavaScriptがサイト上でやっていることは、

あるタイミングで、ある要素に、何かしらの変化を加える

基本的にはこれだけ！

【変化を見てみよう】
  1. トライデントコンピュータ専門学校のサイトを開く。
  2. 右クリックメニュー「検証」を選択し、「Elements」タブを表示。
  3. スライドショー部分のソースコードを表示して変化を見てみる。

後期の授業が終わるまでに、全員が出来るようになって欲しいことは、

  • 自分が実現したい動きが「どのタイミングで、どの要素が、どのように変化しているのか」をイメージできるようになること。
  • 「どのように変化しているのか」をプログラムで書けるようになること。

まずこの単元では詳しい内容は省き、プログラムを一通り実行して全体像を把握します。

2. JavaScriptの書き方

  1. 任意の場所に新規フォルダを作成。
  2. 「Visual Studio Code」を立ち上げ、作成したフォルダを開く。
  3. 新規ファイル「sample.html」を作成。
  4. 以下のコードを記述し、ブラウザで開く。 
    <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>sample</title>
</head>
<body>
  <script>
    alert('Hello World!');
  </script>
  </body>
</html>
  5. 「Hello World!」とメッセージが表示されたら成功。
alert();

「window.」とはブラウザそのもの。（ブラウザが持っている機能の中から「alert」を実行します。という意味）

2-1. 基本文法

  1. HTMLファイル内に記述する場合は、script要素の間に記述する。
  2. 文の最後に「;（セミコロン）」をつける。（省略も可）
  3. スペースや改行は自由にいれても良いが、単語の途中には入れない。
  4. 大文字と小文字は区別される。
  5. 文字列（文字の並び）を扱う場合はシンブルクォート(')かダブルクォート(")で囲む。
  6. 文字列以外の箇所に「全角文字（空白）」は使用しない。

※HTMLでは属性値をダブルクォート(")で囲む場合が多いので、この授業では文字列をシンブルクォート(')で囲みます。

3. 変更を加えたい要素を指定する

<!DOCTYPE html>

例えば、p要素をクリックした時に何かを変化させるプログラムを書く場合、まずはその対象を指定する必要がある。

【要素の指定方法、主要6種類】
getElementsByTagName('要素名');
getElementById('id名');
getElementsByClassName('class名');
getElementsByName('name属性値');
querySelector('セレクタ'); //「.btn」など（cssセレクタと同じ書き方）
querySelectorAll('セレクタ');
  • ※「Element」と「Elements」の違いに注意（複数ある可能性がある時は「Elements」）
  • ※大文字と小文字の違いに注意（単語の先頭を大文字にする記法のことを「キャメルケース」と呼ぶ）

3-1. id名で指定する

<p id="elem">変化させたい要素</p> <!--「elem」は「element（要素）」の略 -->

<script>
  alert( document.getElementById('elem') );
</script>

【documentオブジェクト】
「document.」とはWebサイトのドキュメント（内容）全体のこと。（内容全体の中から「任意のid名を持つ要素」を指定します。という意味）

4. 何かしらの変化を加える

様々な変更方法があらかじめ用意されているが、よく使用される代表的なものが「CSSの操作」「属性の操作」「内容（テキスト）の操作」の3つ。

4-1. CSSの操作

<script>
  document.getElementById('elem').style.color = '#ff0000';
  document.getElementById('elem').style.backgroundColor = '#00ff00';
  //単語の途中でハイフンは使えないため「キャメルケース」で記述する（計算式の「マイナス」と認識されてしまう）
</script>

複数のCSSを変更する際、「document.getElementById('elem')」をなんども記述するのは面倒くさい。その場合は「変数」を使うと便利。

4-2. 変数とは？

あとで利用するために、値（データ）に名前をつけて保存しておく仕組みのこと。

  1. 「let 変数名」で変数を宣言（新規作成）する。
  2. 「変数名 = 〇〇」で変数にデータを入れておく（代入する）。
  3. その後は、変数名を書くと代入した値が適応される。

<script>
  let elem = document.getElementById('elem');
  elem.style.color = '#ff0000';
  elem.style.backgroundColor = '#00ff00';
</script>

※「let」などの詳しい話は後日。

【変数の値をコンソールに表示する】
<script>
  let elem = document.getElementById('elem');
  console.log(elem); //変数は文字列ではないためシングルクォート「'」はいらない
</script>

⭐️ 練習

  1. 「p要素」の上に「h1要素」を追加し、CSSを変更する。（※変数に代入すること）

5. タイミングを設定する

まずは、以下の形をおぼえましょう。（このあたりから「括弧」や「ドット」が増えるので落ち着いて書いてください。）

※エラーを無くすコツは、括弧を書いたらすぐに閉じること！

<script>
  let elem = document.getElementById('elem');

  elem.addEventListener('click', function(){
    elem.style.color = '#ff0000';
  });
</script>

addEventListener（アドイベントリスナー）
要素に、イベント(Event)を監視する役割(Listener)を追加(add)する。
function(){}
イベントが発生した時に実行される命令のかたまり。（関数）

イベントリファレンス - MDN

⭐️ 練習

  1. p要素にマウスを乗せたら、フォントサイズが大きくなる。
  2. p要素からマウスを離したら、フォントサイズが元に戻る。
  3. p要素にマウスを乗せたら、h1要素のフォントサイズが大きくなる。

6. さらに変更を加える

<body>
  <!--画像を追加する-->
  <img id="image" src="https://picsum.photos/200/300?image=0">

  <script>

  </script>

6-1. 属性の操作

【属性値の変更】
<script>
  let image = document.getElementById('image');
  image.setAttribute('src', 'https://picsum.photos/200/300?image=100');
</script>

setAttribute - MDN

【属性値の取得】
<script>
  let image = document.getElementById('image');
  let src = image.getAttribute('src');

  console.log(src);
</script>

getAttribute - MDN

⭐️ 練習

  1. p要素にマウスを乗せたら画像が切り替わり、マウスを離したら元の画像に戻る。

6-2. 内容（テキスト）の操作

【内容の取得】
<script>
  let elem = document.getElementById('elem');
  let text = elem.innerHTML;
  console.log(text);
</script>
【内容の変更】
<script>
  let elem = document.getElementById('elem');
  elem.innerHTML = '変更しました！';
</script>

innerHTML - MDN

7. まとめ

【JavaScriptがサイト上でやっていること】
あるタイミングで、ある要素に、何かしらの変化を加える。
【JavaScript上達のコツ】
  1. 「console.log()」で値を可視化すること。
  2. エラーが出た時は、該当の箇所と原因を把握し素早く対処すること。（JavaScript エラーリファレンス）
  3. 繰り返しソースコードを書いて「括弧」「ドット」「カンマ」に慣れること。
