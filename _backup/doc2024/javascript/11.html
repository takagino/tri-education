3. オブジェクトの基本操作

3-1. 初期化

オブジェクトを使うには、まずオブジェクトの初期化を行う。初期化とは、何らかの機能を使用可能な状態にすること。 

const オブジェクトの名前 = {
  キー : 値,
  キー : 値,
  キー : 値,
}

//例
const obj = {
  int: 123,
  str: "りんご",
  bool: false,
  obj: {
    sub: "ばなな"
  },
  名前: "高木",
};
console.log(obj);

//空のオブジェクトを作成することもできる
const empty = {};
console.log(empty);

//別の書き方
const empty = new Object();
console.log(empty);

  • キーには任意の文字列を設定する。
  • キーには日本語を使用できるが、おすすめしない。
  • キーと値はコロン(:)で区切る。
  • キーと値のペア（プロパティ）はカンマ(,)で区切る。
  • 値には他のオブジェクトを設定することが可能。
  • 最後のペアの後のカンマは省略可能。

3-2. 値の取得・変更

オブジェクトから値を取得・変更する場合には、次の2つの方法を使用できる。

  1. ドット記法
  2. ブラケット記法
【ドット記法】
const obj = {
  int: 123,
  str: "りんご",
  bool: false,
  obj: {
    sub: "ばなな"
  },
  名前: "高木",
};

//中身の確認
console.log(obj);

//値の取得
console.log(obj.int);

//値の中のオブジェクトの値を取得
console.log(obj.obj.sub);

//値の変更
obj.str = "アップル";
console.log(obj);

//キーと値のペア（プロパティ）を追加
obj.ran = Math.floor(Math.random()*100);
console.log(obj);

//キーの削除
delete obj.bool;
console.log(obj.bool);

//変数をキーにすることはできない
const key = "str";
console.log(obj.key);
【ブラケット記法】
const obj = {
  int: 123,
  str: "りんご",
  bool: false,
  obj: {
    sub: "ばなな"
  },
  名前: "高木",
};

//値の取得（文字列でキーを指定）
console.log(obj["int"]);

//値の中のオブジェクトの値を取得
console.log(obj["obj"]["sub"]);

//値の変更
obj["str"] = "アップル";
console.log(obj);

//キーと値のペア（プロパティ）を追加
obj["ran"] = Math.floor(Math.random()*100);
console.log(obj);

//キーの削除
delete obj["bool"];
console.log(obj["bool"]);

//変数が使用できる
const key = "str";
console.log(obj[key]);
【記法の使い分け】
  1. ブラケット記法：変数を使用したい場合
  2. ドット記法：それ以外（授業では基本こちらを使う）

3-3. 値に関数を設定する

const obj = {
  int: 123,
  str: "りんご",
  bool: false,
  obj: {
    sub: "ばなな"
  },
  名前: "高木",
  play: function(){
    console.log("play!");
  }
}

obj.play();

//アロー関数の書き方
const obj = {
  play: () => {
    console.log("play!");
  }
}

//さらに省略
const obj = {
  play() {
    console.log("play!");
  }
}

⭐️ 練習

上記「練習」のオブジェクトに以下の関数を追加し、画像をクリックしたら実行されるように改造する。 

play: () => {
  console.log("play!");
}

3-4. それぞれの使い分け

【変数】
1つの値に対して、名前をつけて管理する。 
const teacher = "高木";
console.log(teachar);
【配列】
1種類の値が複数ある時に、名前をつけて管理する。 
const wf1 = ["青島", "秋田", "天久", "安藤", ....];
console.log(wf1[0]);
【オブジェクト】
関連した数種類の値が1つずつある時に、名前をつけて管理する。 
const teacher = {
  name: "高木",
  age: 44,
  blood: "B"
};
console.log(teacher.name);

★ 実践「クリックゲーム（click.html）」

見本

【サンプルコード】
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>クリックゲーム</title>
  </head>
  <body>
    <h1>click game</h1>
    <div class="monster">
      <p class="name">名前</p>
      <img class="pic" src="#" width="200" />
      <p class="hp">HP:</p>
    </div>

    <script>
      const obj = {
        name: "ピンクカバ",
        pic: "https://dotown.maeda-design-room.net/wp-content/uploads/2022/01/thing_hippo_02.png",
        hp: 10,
        clear: () => {
          alert("クリア！");
        },
      };
    </script>
  </body>
</html>
【条件】
  1. ページを表示したら、定義されているオブジェクトの値を利用して画面に「名前」「画像」「HP」を表示する。
  2. 画像にクリックイベントを登録し、クリックするたびにHPを1ずつ減らす。
  3. HPが「0」になったらオブジェクト内の関数を実行しアラートを表示する。それ以降HPは減らない。

補足

【forEachとthisキーワード】
const monsters = [
  {
    name: "ピンクカバ",
    pic: "https://dotown.maeda-design-room.net/wp-content/uploads/2022/01/thing_hippo_02.png",
    hp: 10,
    clear: function () {
      alert(`${this.name}を倒した！`);
    },
  },
  {
    name: "カマキリ",
    pic: "https://dotown.maeda-design-room.net/wp-content/uploads/2022/01/thing_mantis_01.png",
    hp: 6,
    clear: function () {
      alert(`${this.name}を倒した！`);
    },
  },
  {
    name: "ゴリラ",
    pic: "https://dotown.maeda-design-room.net/wp-content/uploads/2022/01/thing_gorilla_01.png",
    hp: 8,
    clear: function () {
      alert(`${this.name}を倒した！`);
    },
  },
];

const monsterall = document.querySelector(".monster-all");

monsters.forEach((obj) => {
  const monster = document.createElement("div");
  monster.classList.add("monster");

  const name = document.createElement("p");
  name.textContent = obj.name;
  monster.append(name);

  const pic = document.createElement("img");
  pic.setAttribute("src", obj.pic);
  pic.setAttribute("width", 200);

  pic.addEventListener("click", () => {
    if (obj.hp > 0) {
      hp.textContent = `HP: ${--obj.hp}`;
      if (obj.hp == 0) {
        obj.clear();
        pic.parentElement.classList.add("clear");
      }
    }
  });

  monster.append(pic);

  const hp = document.createElement("p");
  hp.textContent = `HP: ${obj.hp}`;
  monster.append(hp);

  monsterall.append(monster);
});
