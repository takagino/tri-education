「業界研究（Webリテラシー）」05_【本番】Webクリエイター能力認定試験

1. Web クリエイター能力認定試験

  • 試験時間は、 知識問題（20 分） と 実技問題（90 分） です。
  • 合格ラインは、両方合わせて80%です。
【日程】
2024年1月22日（水）3時限目〜
【スケジュール】
  • 13:45〜13:55 全体説明
  • 13:55〜14:00 知識問題説明
  • 14:00〜14:20 知識試験（20分）
  • 14:20〜14:25 実技問題説明
  • 14:25〜15:55 実技問題（90分）
  • （※15:15〜15:50 退室可能）
  • 16:00 終了

◎準備

【01. 試験データのダウンロード（指示があるまで進めないこと）】
  1. 資格受付 ONLINEにログイン。（ユーザーIDはGmail、パスワードは自分で設定したもの）
  2. 受験名をクリックし、試験データをダウンロードする。
  3. ダウンロードしたzipファイルをデスクトップに移動し、ダブルクリックで解凍する。
  4. 生成されたフォルダ名の末尾「xxx」を、半角数字の受験番号（学籍番号6桁）に変更する。
    例）H52D_5_Mac_212345
【02. 受験者情報入力】
  1. フォルダ内の「知識問題解答用_D.txt」をダブルクリックで開く。
  2. 会場コード「23224」、受験番号「学籍番号6桁」、氏名「漢字フルネーム（姓と名の間に全角1文字分のスペース）」を入力して保存する。
  3. ファイル内の注意事項を確認する。
  4. 以降、知識問題が終わるまで開いたままにしておく。

◎知識問題（20分）

【03. 知識問題注意事項】
  1. フォルダ内の「知識確認事項」にある「readme.html」をブラウザで表示する。
  2. 内容をよく読み、理解できたらページを閉じる。
【04. 知識問題操作練習】
  1. フォルダ内の「知識操作練習用」にある「start_rensyu.html」をブラウザで表示する。
  2. 一通り操作し、確認できたらページを閉じる。
【05. 知識問題注意事項】
  • 解答時間は20分。途中退室はできません。
  • 試験中は「知識用」以外のフォルダーや、解答用テキストファイル以外のファイルを開くことは禁止です。
  • 解答は必ず「全角カタカナ」で入力してください。
  • 早く終わった人は終了まで待機してください。（実技問題に進まないこと）
【06. 知識問題開始・終了】
  1. フォルダ内の「知識用」にある「start.html」をブラウザで表示する。
  2. 画面に表示された問題指示に従い、解答を進める。
  3. 終了したら保存し、ファイルとページを閉じる。

◎実技問題（90分）

【07. 実技問題確認事項】
  1. フォルダ内の「実技確認事項」にある「readme.html」をブラウザで表示する。
  2. 内容をよく読み、理解できたらページを閉じる。
【08. 実技問題操作練習】
  1. フォルダ内の「実技操作練習用」にある「start_rensyu.html」をブラウザで表示する。
  2. 一通り操作し、確認できたらページを閉じる。
【09. 実技問題注意事項】
  • 解答時間は90分。3限が終わるまでは途中退室はできません。
  • 試験中は「実技用」以外のフォルダーや、別のページを開くことは禁止です。
  • 終了5分前になったら、それ以降の途中退室は禁止です。
【10. 実技問題開始・終了】
  1. VSCodeを立ち上げておく。
  2. フォルダ内の「実技用」にある「site」フォルダをVSCodeで開く。
  3. フォルダ内の「実技用」にある「start.html」をブラウザで表示する。
  4. 画面に表示された問題指示に従い、解答を進める。
  5. 終了したらすべてのページを保存し、VSCodeとページを閉じる。

◎データの提出

  1. フォルダ名の末尾が、半角数字の受験番号（学籍番号6桁）になっていることを再度確認する。
  2. 「知識問題解答用_D.txt」と「実技用 > site」フォルダに作成したファイルがあるか再度確認する。
  3. Googleドライブにフォルダごと提出する。
  4. 以上で終了です。お疲れ様でした。
