問題1 基本ページの作成

【(1) 基本ページのHTMLの編集 - 設定3-2】
幅：属性は省略、高さ：属性は省略
<!-- width属性とheight属性は省略 -->
<img src="" alt="代替属性">

<!-- 省略せずに書くと -->
<img src="" alt="代替属性" width="ピクセル値" height="ピクセル値">
【(2) 基本レイアウトのCSSの編集 - 設定1】
外部スタイルシート「common.css」を設定する。
//style.cssの指定の場所に、以下の設定を追記
@import url(./common.css);
【(2) 基本レイアウトのCSSの編集 - 設定3】
左マージン：各自考える、右マージン：各自考える
//指定通りに記述しないと減点の可能性があるため注意
× margin: auto;
× margin: 0 auto;

○ margin-left: auto;
  margin-right: auto;
【(2) 基本レイアウトのCSSの編集 - 設定4-2】
リストマーカーの種類：なし
//指定通りに記述しないと減点の可能性があるため注意
× list-style: none;

○ list-style-type: none;
【(2) 基本レイアウトのCSSの編集 - 設定4-2】
オーバーフロー：hidden
overflow: hidden;
【(2) 基本レイアウトのCSSの編集 - 設定4-3】
フロート：左
float: left;
【(2) 基本レイアウトのCSSの編集 - 設定4-4、設定4-5】

【(2) 基本レイアウトのCSSの編集 - 設定7】

問題4 「スケジュール」ページの作成

【(3) 「スケジュール」ページのCSSの編集 - 設定1】
テーブルに交互の背景色を設定する。
/* 偶数のアルファベット値を設定 */
table tbody tr:nth-child(even) {
  background-color: #f2f2f2;
}

/* 奇数のアルファベット値を設定 */
table tbody tr:nth-child(odd) {
  background-color: #f2f2f2;
}

/* 偶数の値を設定 */
table tbody tr:nth-child(2n) {
  background-color: #f2f2f2;
}

/* 奇数の値を設定 */
table tbody tr:nth-child(2n+1) {
  background-color: #f2f2f2;
}

問題6 「前売り券申し込み」ページの作成

【(2) 「前売り券申し込み」ページのメイン領域のHTMLの編集 - 設定2】
テキスト「お名前（必須）」の後に、段落内改行を挿入し、続けて名前を入力するためのテキストフィールドを挿入するとともに、以下の属性を設定する。
テキスト「お名前（必須）」をlabel要素でマークアップし、以下の属性を設定する。
<p>
  <label for="">お名前（必須）</label><br>
  <input type="text" name="" id="" required>
</p>
【(2) 「お問い合わせ」ページのメイン領域のHTMLの編集 - 設定4】
テキスト「ご希望会場」の後に段落内改行を挿入し、select要素を挿入するとともに、以下の属性を設定する。
select要素の中に、以下のテキストをコピー&ペーストし、選択リストの項目をマークアップするとともに、以下の属性を設定する。
テキスト「ご希望会場」をlabel要素でマークアップし、以下の属性を設定する。
<p>
  <label for="">ご希望会場</label><br>
  <select name="" id="">
    <option value="">福岡</option>
    <option value="">名古屋</option>
    <option value="">仙台</option>
  </select>
</p>
【(2) 「お問い合わせ」ページのメイン領域のHTMLの編集 - 設定5】
テキスト「備考」の後に、段落内改行を挿入し、続けて内容を入力するためのテキストエリアを挿入するとともに、以下の属性を設定する。
テキスト「備考」をlabel要素でマークアップし、以下の属性を設定する。
<p>
  <label for="">備考</label><br>
  <textarea name="" id=""></textarea>
</p>
【(2) 「お問い合わせ」ページのメイン領域のHTMLの編集 - 設定6】
テキストエリアを内包しているp要素の次の行に、画像ボタンを挿入し、p要素でマークアップする。 なお、画像ボタンには、以下の属性を設定すること。 
<p>
  <input type="image" src="" alt="">
</p>
【(3) 「お問い合わせ」ページのCSSの編集 - 設定1】
/* 必須属性名のみ設定 */
input[required] {
  width: 250px;
