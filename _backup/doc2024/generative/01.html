1. ジェネラティブアートとは？

ジェネラティブアート（英: Generative Art）は、コンピュータソフトウェアのアルゴリズムや数学的/機械的/無作為的自律過程によってアルゴリズム的に生成・合成・構築される芸術作品を指す。コンピュータの計算の自由度と計算速度を活かし、自然科学で得られた理論を実行することで、人工と自然の中間のような、統一感を持った有機的な表現を行わせる作品が多い。（- Wikipediaより）

【参考】
  • X - #generative
  • X - #creativecoding
  • OpenProcessing - generative

1-1. 関連事項

【NFT（非代替性トークン）】
ブロックチェーン上に記録される一意で代替不可能なデータ単位である。NFTは、画像・動画・音声、およびその他の種類のデジタルファイルなど、容易に複製可能なアイテムを一意なアイテムとして関連づけられる。（- Wikipediaより）

3. 図形の描画

3-1. 座標系

  • 領域の左上が原点。
  • 横が「X軸」、縦が「Y軸」。

※Web系のプログラミングはこの形が多いので覚えておくと良い。

3-2. 基本の図形

function setup() {
  createCanvas(640, 480);

  //点の描画：point( X座標, Y座標 );
  point( 100, 200 );

  //線の描画：line( X座標始点, Y座標始点, X座標終点, Y座標終点 );
  line( 10, 10, 200, 100 );

  //矩型の描画：rect( X座標, Y座標, 幅, 高さ );
  rect( 10, 10, 200, 100 );

  //楕円の描画：ellipse( X座標, Y座標, 幅, 高さ );
  ellipse( 10, 10, 200, 100 );
}
【その他の図形】
公式リファレンス「Shape」

⭐️ 練習「日本の国旗、フランスの国旗」

3-3. 色の指定

function setup() {
  createCanvas(640, 480);

  //背景色（red：0 - 255, green：0 - 255, blue：0 - 255）
  background(0, 0, 0);

  //塗りの色
  fill(255, 0, 0);

  //線の色
  stroke(0, 0, 255);

  //値が1個の場合はグレースケール（白〜黒）
  background(0);

  //16進数コードでもOK
  stroke("#0000ff");
}

⭐️ 練習「日本の国旗、フランスの国旗に色をつける」

3-4. その他の設定

【透明度】
function setup() {
  createCanvas(640, 480);

  //値を1個追加することで、透明度を設定できる（0が透明、255が通常）
  fill(255, 0, 0, 100);

  //16進数の書き方は不可
  stroke("#0000ff", 100);
}
【その他】
function setup() {
  createCanvas(640, 480);

  //塗りなし
  noFill();

  //線なし
  noStroke();

  //線の太さ・形状
  strokeWeight(6);
  strokeCap(ROUND);
}

4. 変数によるアニメーション

4-1. 変数とは？

プログラムで使われる値を、名前付きで管理するラベルのようなもの。

【変数の使い所】
  1. 同じ値が何度も出てくるとき。
  2. 値を変化させたいとき。

新規ファイル作成「02-random.html」

let x = 50; //後から変更できる
const y = 100; //後から変更できない（定数）
var w = 200; //古い書き方なので使用しない

rect(x, y, w, 100);

4-2. 値の更新

let x = 0; //変数宣言

function setup() {
  createCanvas(640, 480);
}

function draw() {
  x = x + 1; //変数xに1を足して、xに再代入する
  rect(x, 100, 50, 50);
}
【描画した図形を消す】
let x = 0;

function setup() {
  createCanvas(640, 480);
}

function draw() {
  background(255); //背景色で塗りつぶす
  clear(); //色を考慮しなくて良いので、こちらのほうが楽

  x = x + 1;
  rect(x, 100, 50, 50);
}
【自己代入演算子】
x += 10;   //x = x + 10; （足し算）
x -= 10;  //x = x - 10; （引き算）
x *= 10;  //x = x * 10; （掛け算）
x /= 10;  //x = x / 10; （割り算）
x %= 10;  //x = x % 10; （割った時の余り）
x **= 10;  //x = x ** 10; （べき乗）
【インクリメント、デクリメント】
x++;   //x += 1; （1を足す）
x--;  //x -= 1; （1を引く）

★ 変数を宣言する場所に注意

draw関数の中で宣言すると、毎回別の変数として宣言される。

function setup() {
  createCanvas(400, 400);
}

function draw() {
  clear();

  let x = 0;
  x = x + 1;
  ellipse(x, 100, 50, 50);
}

setup関数の中で宣言するとエラーとなる。

function setup() {
  createCanvas(400, 400);
  let x = 0;
}

function draw() {
  clear();

  x = x + 1;
  ellipse(x, 100, 50, 50);
}

※letとconstは、宣言したブロック内（{}内）でしか使用できない。

5. ランダム性

random();
ランダムな小数（乱数）を取得する。
function setup() {
  createCanvas(640, 480);

  let x = random(0, 100); //最初が「0」の場合は省略できる random(100);
  let y = random(50, 100);

  console.log(x, y);
}
floor();
小数点以下を切り捨てる。
function setup() {
  createCanvas(640, 480);

  let x = floor(random(0, 100));
  let y = floor(random(50, 100));

  console.log(x, y);
}

5-1. ジェネラティブに適した設定

rectMode();
矩形の基準点（X座標、Y座標の基準）を変更する。
function setup() {
  createCanvas(640, 480);
  rectMode(CENTER); //基準点を中央にする

  rect(320, 240, 100, 100);
}
colorMode();
色の表現方法を変更する。
function setup() {
  createCanvas(640, 480);
  rectMode(CENTER);

  //RGBで色を表現する（初期値）
  colorMode(RGB);

  //HSLで色を表現する
  colorMode(HSB);
  fill(180, 100, 100);

  rect(320, 240, 100, 100);
}
【HSBとは？】
  • 色相（Hue）：0 - 360
  • 彩度（Saturation）：0（白） - 100（純色）
  • 明度（Brightness）：0（黒） - 100（純色）
angleMode();
角度の指定方法を変更する。
//以下が、setup関数のテンプレート

function setup() {
  createCanvas(640, 480);
  rectMode(CENTER);
  colorMode(HSB);
  angleMode(DEGREES);
}

6. インタラクション

【インタラクションとは】
相互作用（そうごさよう）、交互作用（こうごさよう）、相互交流（そうごこうりゅう）、相互行為（そうごこうい）、またはインタラクションとは「二つ以上のものが互いに影響を及ぼしあうこと」。派生語・形容詞形はインタラクティブ。

ここでは、「マウス」と「キーボード」に反応させる方法を学ぶ。

新規ファイル作成「03-interaction.html」

6-1. 特殊な変数

p5.jsには独自のシステム変数がある。これはp5.jsが自動的に値を設定するもので、プログラム内では同じ名前の変数を使ってはいけない。 

function setup() {
  createCanvas(640, 480);

  //width：canvas描画領域の幅
  console.log(width);

  //height：canvas描画領域の高さ
  console.log(height);
}

function draw() {
  //frameCount：経過フレーム数
  console.log(frameCount);

  //mouseX：ブラウザ内のマウスのX座標
  console.log(mouseX);

  //mouseY：ブラウザ内のマウスのY座標
  console.log(mouseY);

  //mouseIsPressed：マウスをクリックしている時はtrue、していない時はfalse
  console.log(mouseIsPressed);
}

6-2. マウスの位置に矩型を描画する

let x = 0;
let y = 0;
let c = 0;
let d = 0;

function setup() {
  createCanvas(640, 480);
  rectMode(CENTER);
  colorMode(HSB);
  angleMode(DEGREES);
  noStroke();
}

function draw() {
  // clear();

  x = mouseX;
  y = mouseY;

}

p5.jsには独自のシステム関数がある。これはp5.jsが自動的に動作を設定するもので、プログラム内では同じ名前の変数を使ってはいけない。

}

  //システム変数「keyCode」：押されたキーボードのキーコード値

7. 座標変換

以下の画像のように、少し傾いた矩型を描きたい場合。

  • CSSのように「transform」プロパティで後から回転させることはできない。

p5.jsでは、領域内の座標を変更してから描画する。

新規ファイル作成「04-coordinate.html」

7-1. 変更できる値

平行移動
translate(x方向の距離, y方向の距離);
回転
rotate(角度);
拡大縮小
scale(x方向の拡大率, y方向の拡大率)
