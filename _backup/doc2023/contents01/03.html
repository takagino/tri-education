2. ターミナルの操作

2-1. 主なコマンド

コマンド 説明
pwd 「print working directory」の略。
現在のフォルダ（カレントディレクトリ）のパスを表示。
ls 「list」の略。
カレントディレクトリにあるファイルを表示。
cd 「change directory」の略。
指定したファイルに移動。 
cd xxx  # xxxというファイルへ移動
cd ~/  # ホームディレクトリへ移動 [$ cd] や [$ cd ~] だけでも可能
cd ..  # 一つ上の階層のファイルへ移動
cd ./ # 現在いるディレクトリ階層へ移動
cd ../.. # 今より２つ上の階層へ移動

cd Desktop # デスクトップへ移動（%の前に現在のフォルダが表示される）
※「cd 」の後にファイルをドラッグ・アンド・ドロップすることで、そのファイルまでのパスを表示できる。
touch 中身が空のファイルを作成する。 
touch xxx.js  # xxx.jsという空ファイルを作成
mkdir 「make directory」の略。
ディレクトリ（フォルダ）を作成する。 
mkdir xxx  # xxxというフォルダを作成

4-4. 同期と非同期

前述の各メソッドには、以下の似たようなメソッドが存在する。
Node.jsでは、適材適所で2種類の処理を使い分ける必要がある。

【同期処理（synchronous）】
//該当の処理が終わるまで、他の処理を止める（ブロッキング）

const fs = require('fs');
let textIn;

textIn = fs.readFileSync('./txt/test.txt', 'utf-8');

console.log(textIn);
【非同期処理（asynchronous）】
//「処理が終わったら教えてね」という指示を与え、完了を待たずに別の処理を行う（ノンブロッキング）

const fs = require('fs');
let textIn;

fs.readFile('./txt/test.txt', 'utf-8', (err, data) => {
  textIn = data;
});

console.log(textIn); //結果「undefined」

//fs.readFile('ファイルのパス', '文字コード', 処理完了時に実行される関数「コールバック」);

※非同期処理を活用するためには、他にも必要な知識・用語がたくさんあるが、一旦割愛します。

【情報の追記】
const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;
const textIn = fs.readFileSync('./txt/test.txt', 'utf-8');

const server = http.createServer((req, res) => {

6. ルーティング（経路を振り分ける）

通常のWebサイトの場合は、サイトのURLに対してファイルを分けて対応するが、Node.jsは、プログラム上で動作や読み込むファイルを変更することができる。

6-1. URLの取得

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./template/index.html', 'utf-8');

const server = http.createServer((req, res) => {

  //URL（パス部分）の取得
  console.log(req.url);

  res.writeHead(200, {
    'Content-type': 'text/html'
  });

  res.end(index);
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});

6-2. if文で振り分ける

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./template/index.html', 'utf-8');

const server = http.createServer((req, res) => {

  //変更
  const pathName = req.url;

  if (pathName === '/') {
    res.writeHead(200, {
      'Content-type': 'text/html'
    });
    res.end(index);
  } else {
    res.writeHead(404); //404は「リクエストされたリソースを見つけることができない時のレスポンスコード」
    res.end('Not Found...');
  }
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});

【練習】
「template」内に「about.html」を追加し、「http://127.0.0.1:3000/about」でアクセスできるようにする。

7-1. 「package.json」の作成

実行中のプログラムの「名前」や「バージョン」、インストールされたモジュールの「名前」や「バージョン」などの情報が記載されているファイル。

7-2. 「Socket.io」のインストール

「ストリーミング」や「WebSocket」などのリアルタイム通信系のWeb技術を、簡単に使うためのフレームワーク。サーバー側の処理を実現するためのNode.jsライブラリと、クライアント側の処理を実現するためのJavaScriptライブラリで構成されている。

公式サイト

【手順】

  3. 中身を確認しておく。
  4. 「package.json」の中身の変化も確認しておく。

  1. 「app.js」を変更し、接続されている全てのブラウザに「"message"」を送り返す。

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./template/index.html', 'utf-8');

const server = http.createServer((req, res) => {
  const pathName = req.url;

  if (pathName === '/') {
    res.writeHead(200, {
      'Content-type': 'text/html'
    });
    res.end(index);
  } else {
    res.writeHead(404);
    res.end('Not Found...');
  }

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);

  const io = require("socket.io")(server);

  io.on("connection", socket => {
    console.log("connection success!");

    socket.on("message", recieve => {
      //変更　※"re_message"は任意の文字列
      io.emit('re_message', recieve);
    })
  });
});
