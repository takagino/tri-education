☆まずは「検証」をして、どんな仕組みになっているのか探ってみる。

【検証でわかること】
  • ブラウザの中央からマウスが離れると画像が動く。
  • 最初は早く動き、徐々に遅くなる。
  • 画像を動かしているのは「transform: translate();」
  • カスタムデータ属性で「0.02〜0.1」の値が設定してある。
  • 画像は「絶対配置」で表示されている。
  • 単位は「rem」。
  • html要素に「font-size: 1vw;」が指定してある。
  • ウィンドウサイズを拡大縮小すると、文字や画像もサイズが変わる。

【やるべきこと】
  1. CSSで画像を配置する。
  2. マウスを反応させたい要素に「mousemove」イベントを設定する。
  3. 要素内でのマウスの位置（x座標、y座標）を取得する。
  4. ブラウザの中心からマウスまでの距離（x方向、y方向）を取得する。
  5. 画像の移動距離を保存するための配列を用意し、値「0」を代入しておく。
  6. ブラウザの中心からマウスまでの距離に応じて、徐々に画像を移動させる。この時、マウスを動かさなくても移動させたいので「requestAnimationFrame」を使用すると良い。
  7. カスタムデータ属性で、画像ごとに動くスピードを変える。

  const area = document.querySelector('#area');

【ブラウザの中心からマウスまでの距離（x方向、y方向）を取得する】
<script>
  const area = document.querySelector('#area');
  let dist = { x: 0, y: 0 }; //初期値を代入しておく

  area.addEventListener('mousemove', (event) => {
    const rect = event.currentTarget.getBoundingClientRect();
    const pos = {
      x: event.clientX - rect.left,
      y: event.clientY - rect.top
    };
    dist = {
      x: window.innerWidth / 2 - pos.x,
      y: window.innerHeight / 2 - pos.y
    };

    console.log(dist);
  });
</script>

<script>
  const area = document.querySelector('#area');

  let dist = { x: 0, y: 0 };

</script>

【ブラウザの中心からマウスまでの距離に応じて、徐々に画像を移動させる】
<script>
const area = document.querySelector('#area');
const imgs = document.querySelectorAll('.image');
let dist = { x: 0, y: 0 };
let init = [];

area.addEventListener('mousemove', (event) => {
  const rect = event.currentTarget.getBoundingClientRect();
  const pos = {
    x: event.clientX - rect.left,
    y: event.clientY - rect.top
  };
  dist = {
    x: window.innerWidth / 2 - pos.x,
    y: window.innerHeight / 2 - pos.y
  };
});

const step = () => {
  for (const [i, img] of imgs.entries()) {
    let d = {
      x: (dist.x - init[i].x) * 0.02,
      y: (dist.y - init[i].y) * 0.02
    };
    init[i].x += d.x;
    init[i].y += d.y;
    img.style.transform = `translate(${init[i].x}px, ${init[i].y}px)`;
  };

  window.requestAnimationFrame(step);
};

window.addEventListener('load', () => {
  for (const img of imgs) {
    init.push({
      x: 0,
      y: 0
    });
  };

  window.requestAnimationFrame(step);
});
</script>
【カスタムデータ属性で、画像ごとに動くスピードを変える】
<div id="area">
  <div class="image -no01" data-scale="0.05">
    <img src="https://picsum.photos/id/237/600/380" alt="">
  </div>
  <div class="image -no02" data-scale="0.02">
    <img src="https://picsum.photos/id/238/600/380" alt="">
  </div>
  <div class="image -no03" data-scale="0.1">
    <img src="https://picsum.photos/id/239/600/380" alt="">
  </div>
  <div class="image -no04" data-scale="0.05">
    <img src="https://picsum.photos/id/240/600/380" alt="">
  </div>
  <div class="image -no05" data-scale="0.05">
    <img src="https://picsum.photos/id/241/600/380" alt="">
  </div>
  <div class="image -no06" data-scale="0.15">
    <img src="https://picsum.photos/id/242/600/380" alt="">
  </div>
  <div class="image -no07" data-scale="0.05">
    <img src="https://picsum.photos/id/243/600/380" alt="">
  </div>
</div>

<script>
  const area = document.querySelector('#area');
  const imgs = document.querySelectorAll('.image');
  let dist = { x: 0, y: 0 };
  let init = [];
  const atte = 0.02 //変数にしておく

  area.addEventListener('mousemove', (event) => {
    const rect = event.currentTarget.getBoundingClientRect();
    const pos = {
      x: event.clientX - rect.left,
      y: event.clientY - rect.top
    };
    dist = {
      x: window.innerWidth / 2 - pos.x,
      y: window.innerHeight / 2 - pos.y
    };
  });

  const step = () => {
    for (const [i, img] of imgs.entries()) {
      //変更
      let d = {
        x: (dist.x * init[i].s - init[i].x) * atte,
        y: (dist.y * init[i].s - init[i].y) * atte
      };
      init[i].x += d.x;
      init[i].y += d.y;
      img.style.transform = `translate(${init[i].x}px, ${init[i].y}px)`;
    };

    window.requestAnimationFrame(step);
  };

  window.addEventListener('load', () => {
    for (const img of imgs) {
      init.push({
        x: 0,
        y: 0,
        s: img.dataset.scale //追加
      });
    };

    window.requestAnimationFrame(step);
  });
</script>
