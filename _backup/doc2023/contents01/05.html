「コンテンツ制作」05_コンポーネント間の連携

1. 復習

1-1. Vue プロジェクトの生成

  1. プロジェクト用のフォルダをVSCodeで開く。
  2. 以下のコマンドを入力して「Enter」。 
    npm init vue@latest
  3. 順番に質問に答えていく。（全て「Enter」でOK）
  4. インストールに成功すると、最初に選択した名前のフォルダの中にたくさんのデータが生成される。
  5. 以下のようにターミナルに表示されるので、1行ずつ入力し「Enter」。 
    cd vite-project → フォルダを移動
npm install → 必要なパッケージをインストール
npm run dev → 開発環境を立ち上げる
  6. 表示されたURL（http://localhost:5173/）にアクセス。
  7. 動作確認をして完了！

1-2. コンポーネントの作り方

  1. 『src > components』フォルダに新規ファイル「OneSection.vue」を作成。
  2. 以下のコードを記述し保存。 
    <!-- OneSection.vue -->

<template>
  <section class="box">
    <h2>ひとつのコンポーネント</h2>
  </section>
</template>

<style scope> // scopeをつけることでコンポーネント内のみでCSSが反映される
  .box {
    border: 1px solid #f00;
    margin: 10px;
  }
</style>
  3. ファイル「App.vue」を開き、中身を全て削除する。
  4. 以下のコードを記述し保存。 
    <!-- App.vue -->

<script setup> // setupは必ずつける（おまじない）
  import OneSection from './components/OneSection.vue';
</script>

<template>
  <h1>コンポーネントの基礎</h1>
  <OneSection />
</template>

<style scoped>
</style>

1-3. Vue プロジェクトのビルド

このままでは本番環境（ネット上）にアップできないので、以下の手順でビルドする。

  1. 相対パスでビルドされるように「vite.config.js」を以下のように修正する。 
    import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  base: "./", // 追加
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
  2. 「control + c」で開発環境を終了し、以下のコマンドを入力して「Enter」。 
    npm run build
  3. 「dist」フォルダが生成されたことを確認し、LiveServerでブラウザに表示。

2. 値の受け渡し

表示するコンポーネントごとに内容を変えたい場合はプロパティを使用する。プロパティはコンポーネントに登録できるカスタム属性のことで、definePropsで宣言する。

2-1. App.vue（親コンポーネント）にカスタム属性を追加する

<!-- App.vue -->

<template>
  <h1>コンポーネントの基礎</h1>

  <!-- カスタム属性「title」を追加 -->
  <OneSection title="プロパティの受け渡し" />
  <OneSection title="definePropsを使用する" />
</template>

2-2. OneSection.vue（子コンポーネント）に「defineProps」を宣言する

【配列の形】
<!-- OneSection.vue -->

<script setup>
  defineProps(['title']);
</script>

<template>
  <section class="box">
    <h2>{{ title }}</h2>
  </section>
</template>
【値を増やす】
<!-- App.vue -->

<template>
  <h1>コンポーネントの基礎</h1>

  <!-- カスタム属性「name」を追加 -->
  <OneSection title="プロパティの受け渡し" name="高木" />
  <OneSection title="definePropsを使用する" name="河口" />
</template>
<!-- OneSection.vue -->

<script setup>
  defineProps(['title', 'name']);
</script>

<template>
  <section class="box">
    <h2>{{ title }}</h2>
    <p>{{ name }}</p>
  </section>
</template>
【データ型の設定】
プロパティにどのような値が入るかデータ型によってチェックすることができる。後述する「初期値」など様々な設定を追加できるため、下記の形で記述するのが一般的。
<!-- OneSection.vue -->

<script setup>
  defineProps({
    title: String,
    name: String,
  });
</script>

<template>
  <section class="box">
    <h2>{{ title }}</h2>
    <p>{{ name }}</p>
  </section>
</template>
【主なデータ型】
  • String（文字列）
  • Number（数値）
  • Boolean（真偽値）
  • Array（配列）
  • Object（オブジェクト）
  • Date（日時）
  • Function（関数）

【手順】
  1. onMountedメソッドで、マウント時にデータを取得する。（データの取得はfetchメソッド）
  2. 取得したデータを、扱いやすい形で変数に代入しておく。
  3. v-forを使用し、値の数だけコンポーネントを繰り返す。
  4. カスタム属性を動的に変更されるように修正する。
  5. 微調整して完成。
【参考】
  • 全体的な流れ
  • 現在の書き方（Composition API）
【マウント時にデータを取得する】
<!-- App.vue -->

<script setup>
  import { onMounted } from "vue"; //onMountedメソッドを読み込む
  import OneSection from './components/OneSection.vue';

  //マウントされたらfetchメソッドでデータ取得
  onMounted(() => {
    fetch('https://jsonplaceholder.typicode.com/posts/')
      .then(response => response.json())
      .then(json => {
        console.log(json);
        console.log(json[0].title);
      });
  });
</script>
【扱いやすい形で変数に代入】
<!-- App.vue -->

<script setup>
  import { ref, onMounted } from "vue"; //refメソッドを読み込む
  import OneSection from './components/OneSection.vue';

  const items = ref([]); //変数の定義

  onMounted(() => {
    fetch('https://jsonplaceholder.typicode.com/posts/')
      .then(response => response.json())
      .then(json => {
        items.value = json; //変数に代入
      });
  });
</script>
【値の数だけコンポーネントを繰り返す】
<!-- App.vue -->

<template>
  <h1>コンポーネントの基礎</h1>

  <OneSection v-for="item of items" title="プロパティの受け渡し" name="高木" />
</template>
【ディレクティブに修正】
<!-- App.vue -->

<template>
  <h1>コンポーネントの基礎</h1>

  <OneSection v-for="item of items" :title="item.title" :name="item.body" />
</template>

【手順】
  1. プロジェクト用のフォルダをVSCodeで開く。
  2. 以下のコマンドを入力して「Enter」。 
    npm init vue@latest
  3. 順番に質問に答えていく。（全て「Enter」でOK）
  4. 以下のようにターミナルに表示されるので、1行ずつ入力し「Enter」。 
    cd vite-project → フォルダを移動
npm install → 必要なパッケージをインストール
npm run dev → 開発環境を立ち上げる
  5. 相対パスでビルドされるように「vite.config.js」を以下のように修正しておく。 
    import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  base: "./", // 追加
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
  6. 『src > components』フォルダに新規ファイル「Post.vue」を作成。
  7. 以下のコードを記述し保存。 
    <!-- Post.vue -->

<script setup>
  defineProps({
    title: {
      type: String,
      required: true,
    },
    category: {
      type: String,
