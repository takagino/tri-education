「コンテンツ制作」04_ビルドツールの活用

1. ビルドツールとは

【ビルド】
ソフトウェアのビルド（英: build）は、プログラミング言語で書かれたソースコードファイルや各種リソースファイルを独立したソフトウェア生成物に変換するコンピュータ上で実行されるプロセス、またはその結果を指す。
【ビルドツール】
上記ビルドを自動的に行なってくれるツール。様々なツールが開発・公開されている。
  • Frontend Developer Roadmap
  • State of JS 2022

2. Viteとは

Vue.jsの作者が開発した、JavaScriptから流行のフレームワークであるVue.js・Svelte・Reactまで、さまざまな環境で利用可能な汎用ビルドツール。Vite（ヴィート）はフランス語の「速い」を意味する言葉で、その名の通り高速に動作することが特徴。

※Viteを利用するためには、Node.js（npm）がインストールされていることが前提。

2-1. Vite プロジェクトの生成

  1. デスクトップ等のわかりやすい場所にフォルダを新規作成。
  2. VSCodeでフォルダを開く。
  3. VSCodeのメニュー「表示 > ターミナル」からターミナルを表示。（ショートカット「control + @」）
  4. 念のため、node.jsがインストールされているか確認。 
    # 以下を入力して「Enter」
node -v

# 以下を入力して「Enter」
npm -v
  5. 以下のコマンドを入力して「Enter」。 
    npm init vite@latest
  6. 以下のように聞かれたら「y」と入力し「Enter」 
    Need to install the following packages:
create-vue@3.6.4
  7. 順番に質問に答えていく。 
    Project name: → 何も入力せず「Enter」
Select a framework: → キーボードの上下で「Vue」を選択し「Enter」
Select a variant: → キーボードの上下で「JavaScript」を選択し「Enter」
  8. インストールに成功すると、最初に選択した名前のフォルダの中にたくさんのデータが生成される。
  9. 以下のようにターミナルに表示されるので、1行ずつ入力し「Enter」。 
    cd vite-project → フォルダを移動
npm install → 必要なパッケージをインストール
npm run dev → 開発環境を立ち上げる
  10. 表示されたURL（http://localhost:5173/）にアクセス。
  11. 動作確認をして完了！
【修正する】
『srcフォルダ > App.vue』を開き、14行目の「Vite + Vue」を変更して保存。
【削除する】
  1. ターミナルを選択し、「control + c」で開発環境を終了。
  2. 生成されたフォルダごと削除。

2-3. Vue プロジェクトのビルド

このままでは本番環境（ネット上）にアップできないので、以下の手順でビルドする。

  1. 相対パスでビルドされるように「vite.config.js」を以下のように修正する。 
    import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()],
  base: "./", // 追加
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
  2. 「control + c」で開発環境を終了し、以下のコマンドを入力して「Enter」。 
    npm run build
  3. 「dist」フォルダが生成されたことを確認し、LiveServerでブラウザに表示。

3. コンポーネント

Vue.jsは、Webサイトやアプリケーションをコンポーネントという単位で制作する。コンポーネントはページの構成パーツのことで、通常「HTML」「CSS」「JavaScript」を別々のファイルに記述していく。

一方、Vue プロジェクトでは、これらの3個の要素が1つのファイルにまとめられており、以下のような形になっている。 

<!-- App.vue -->

<script setup>
  ・
  ・
</script>

<template>
  ・
  ・
</template>

<style>
  ・
  ・
</style>

このようなファイルのことを単一コンポーネントファイルと呼び、拡張子を「.vue」とする。

3-1. コンポーネントの作り方

  1. 『src > components』フォルダに新規ファイル「OneSection.vue」を作成。
  2. 以下のコードを記述し保存。 
    <!-- OneSection.vue -->

<template>
  <section class="box">
    <p>ひとつのコンポーネント</p>
  </section>
</template>

<style>
  .box {
    border: 1px solid #f00;
    margin: 10px;
  }
</style>
  3. ファイル「App.vue」を開き、中身を全て削除する。
  4. 以下のコードを記述し保存。 
    <!-- App.vue -->

<script setup>
  import OneSection from './components/OneSection.vue';
</script>

<template>
  <h1>コンポーネントの基礎</h1>
  <section>
    <OneSection />
  </section>
  <section>
    <OneSection />
    <OneSection />
  </section>
</template>

<style>
  section {
    border: 1px solid #00f;
    margin: 10px;
  }
</style>

3-2. コンポーネントの独立性

  1. 『src > components』フォルダに新規ファイル「WithModel.vue」を作成。
  2. 以下のコードを記述し保存。 
    <!-- WithModel.vue -->

<script setup>
  import { ref } from "vue";

  const name = ref("名無し");
</script>

<template>
  <section class="box">
    <p>{{ name }}</p>
    <input type="text" v-model="name">
  </section>
</template>
  3. ファイル「App.vue」を以下のように編集。 
    <!-- App.vue -->

<script setup>
  import OneSection from './components/OneSection.vue';
  import WithModel from './components/WithModel.vue'; //追加
</script>

<template>
  <h1>コンポーネントの基礎</h1>
  <section>
    <OneSection />
  </section>
  <section>
    <!-- 変更 -->
    <WithModel />
    <WithModel />
  </section>
</template>

<style>
  section {
    border: 1px solid #00f;
    margin: 10px;
  }
</style>

3-3. スタイルシートの独立性

  1. ファイル「WithModel.vue」を以下のように修正。 
    <!-- WithModel.vue -->

<script setup>

<template>

  3. CSSに独立性をもたせるために「scoped属性」を追加。 
    <!-- WithModel.vue -->

<style scoped>
  .box {

4-5. 制御関連のディレクティブ

【式の真偽に応じて表示・非表示を切り替える「v-if」】

  </div>

  </div>
</template>
【配列やオブジェクトを繰り返し処理する「v-for」】

</script>

<template>
  <ul>
    <li v-for="(item, index) of items">{{ index + ":" + item }}</li>
  </ul>
</template>

<script setup>
  import { ref, onMounted } from "vue";

  const monsters = [
    {
      name: "スライム",
      pic: "https://trident.takagino.net/doc2023/javascript/assets/03/click/images/slime.png",
      hp: 4
    },
    {
      name: "目玉",
      pic: "https://trident.takagino.net/doc2023/javascript/assets/03/click/images/eye.png",
      hp: 6
    },
    {
      name: "半魚人",
      pic: "https://trident.takagino.net/doc2023/javascript/assets/03/click/images/fish.png",
      hp: 8
    },
  ];
  let currentHp;
  let currentMonster = 0;

  const name = ref();
  const pic = ref();
  const hp = ref();

  const setMonster = () => {
    name.value = monsters[currentMonster].name;
    pic.value = monsters[currentMonster].pic;
    currentHp = monsters[currentMonster].hp;
    hp.value = `HP:${currentHp}`;
  };

  onMounted(() => {
    setMonster();
  });

  const attack = () => {
    currentHp--;
    hp.value = `HP:${currentHp}`;

    if (currentHp <= 0) {
      currentMonster++;

      if (currentMonster >= monsters.length) {
        hp.value = `クリア！`;
      } else {
        setMonster();
      }
    }
  };
  </script>

  <template>
    <dl>
      <dt class="name">{{ name }}</dt>
      <dd><img class="pic" :src="pic" @click="attack" alt="" width="200"></dd>
      <dd class="hp">{{ hp }}</dd>
    </dl>
  </template>

  <style scoped>
  dl {
    text-align: center;
  }

  dd {
    margin: 0;
  }

  .name {
    margin-bottom: 1em;
    font-weight: bold;
  }

  .pic {
    cursor: pointer;
  }

  .hp {
    margin-top: .5em;
    font-style: oblique;
  }
</style>

6. 算出プロパティ

以下のようなVue.jsのプログラムがある。 

<script setup>
  import { ref } from "vue";
  const num01 = ref(0);
  const num02 = ref(0);
</script>

<template>
  <input type="number" v-model="num01">
  <input type="number" v-model="num02">
</template>

このプログラムに改造を加え、2つの値を足した数を表示したい時、それぞれの入力欄にイベントを登録していると面倒くさい。そんな時は算出プロパティを使用すると便利。

【算出プロパティ（computed）】
あるデータや別の算出プロパティから算出される新たなデータのこと。データが更新されると、それに依存している算出プロパティも自動的に更新される。

<script setup>
  import { ref, computed } from "vue"; //機能を追加
  const num01 = ref(0);
  const num02 = ref(0);

  //算術プロパティ
  const total  = computed(() => {
    return num01.value + num02.value;
  });
</script>

<template>
  <input type="number" v-model="num01">
  <input type="number" v-model="num02">

  //追加
  {{ total }}
</template>

☆練習
上記サンプルを改造し、四角形の面積を計算する。（見本）
