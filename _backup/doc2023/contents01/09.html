1. Canvasとは？

キャンバス API (Canvas API) は JavaScript と HTML の <canvas> 要素によってグラフィックを描く方法を提供します。他にも、アニメーション、ゲームのグラフィック、データの可視化、写真加工、リアルタイム動画処理などに使用することができます。キャンバス API は全体的に 2D グラフィックを対象としています。 WebGL API は、こちらも <canvas> 要素を使用して、ハードウェアで高速化された 2D および 3D グラフィックを描きます。（ -mdn web docsより）

    <!-- 代替コンテンツを設定する -->
    Canvas not supported.
  </canvas>

  <script>
  //ページの読み込みが完了したら、init関数を実行する
  window.addEventListener('load', () => {
    init();
  });

  const init = ()  => {
    //canvas要素を抽出し、変数canvasに格納する
    const canvas = document.querySelector('#example');

    //canvasに対応していないブラウザ用にエラー処理をほどこす
    if (!canvas || !canvas.getContext) {
      return false;
    }

    //getContext('2d')を呼び出して「グラフィックコンテキスト」を取得する
    //dは必ず小文字
    const ctx = canvas.getContext('2d');

    //キャンバスに描画を行う
    ctx.fillText("Hello Canvas", 50, 50);
  }
  </script>
</body>
</html>

シェイプやテキストの描画、イメージの表示や操作に使用する仕組みを提供するグラフィックエンジン。深くは考えない。

3. 図形の描画

3-1. 座標系

3-2. 矩形を描く

ctx.fillRect(50, 50, 300, 200);
ctx.strokeRect(240, 20, 200, 300);
ctx.clearRect(80, 80, 400, 300);

fillRect(x, y, width, height)
塗りつぶした矩形を描く。x, yには矩形の左上端の座標を、widthに矩形の横幅を、heightに縦幅を引数として与える。
strokeRect(x, y, width, height)
枠線のみの矩形を描く
clearRect(x, y, width, height)
指定された領域を削除する。削除された部分は透明になる

3-3. パスを描く

canvasでは、一つにまとまった図形を描けるのは矩形のみのため、他の図形を描くには、複数のパス（線）を組み合わせて作る

//直線を描く
ctx.beginPath();
ctx.moveTo(200, 200);
ctx.lineTo(300, 300);
ctx.stroke();

//三角形を描く
ctx.beginPath();
ctx.moveTo(300, 300);
ctx.lineTo(350, 350);
ctx.lineTo(250, 350);
ctx.closePath();
ctx.fill();

beginPath()
パスをリセット（初期化）する。現在引かれている下書き線をすべて消す
moveTo(x, y)
指定した座標にパスの現在位置を設定する
lineTo(x, y)
現在位置から指定した座標まで直線を引く
stroke()
現在作られているパスに沿って線を描く
fill()
現在作られているパスに沿って塗りつぶす
closePath()
パスを閉じる

3-7. 円弧を描く

//arc1
ctx.beginPath();
ctx.arc(320, 240, 200, 0, Math.PI * 2, false);
ctx.stroke();

//arc2
ctx.beginPath();
ctx.arc(320, 240, 160, 0, Math.PI * 1.5, false);
ctx.stroke();

//arc3
ctx.beginPath();
ctx.arc(320, 240, 120, Math.PI * 0.25, Math.PI * 1.0, true);
ctx.stroke();

//arc4
ctx.beginPath();
ctx.arc(320, 240, 40, 0, Math.PI * 2.0, true);
ctx.fill();

ctx.arc(x, y, radius, startAngle, endAngle, anticlockwise)
x：円の中心のx座標
y：円の中心のy座標
radius：円の半径
startAngle：円弧を描き始める角度。x軸の向き（右方向）からみて右回りの角度をラジアンで指定
endAngle：円弧を描き終える角度
anticlockwise：円弧を描く向き。trueは反時計回り（左回り）、falseは時計回り（右回り）
【ラジアンとは】
弧度法ってなんだよ！ラジアンってなんだよ！！ってなっている君へ
【度数への変換】
度数 * Math.PI / 180
例）15°であれば、15 * Math.PI / 180

4-1. マウスを動かすと線が描ける

【手順に分解】
  • マウスが動いたことを感知する。（mousemoveイベントの登録）
  • 現在のマウスの位置と、直前のマウスの位置を取得する。
  • 2点間を結んで線を描画する。
  • マウスが動くたびに繰り返す。
【mousemoveイベントの登録】
let ctx;

window.addEventListener('load', () => {
  init();
});

const init = () => {
  const canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  //イベントの登録
  canvas.addEventListener('mousemove', onMove);
}

//イベント時に発生する関数式
const onMove = (e) => {
  console.log(e);
}
  • ※コンソールに表示される値の中で、「x」や「y」が付く値に注目。
【マウスの位置を取得する】
  • event.offsetX,Yの罠...どこが原点の座標値なのかを理解する (currentTargetとtarget)
let ctx;

window.addEventListener('load', () => {
  init();
});

const init = () => {
  const canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  canvas.addEventListener('mousemove', onMove);
}

const onMove = (e) => {
  //canvas内のマウスの位置を取得する
  let rect = e.currentTarget.getBoundingClientRect();
  let mouseX = e.clientX - rect.left;
  let mouseY = e.clientY - rect.top;
  console.log(`${mouseX} : ${mouseY}`);
}
【現在のマウスの位置と直前のマウスの位置を取得し、線で結ぶ】
let ctx;
//初期値を設定
let mouseX = 0;
let mouseY = 0;

window.addEventListener('load', () => {
  init();
});

const init = () => {
  const canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  canvas.addEventListener('mousemove', onMove);
}

const onMove = (e) => {
  //修正
  ctx.beginPath();
  ctx.moveTo(mouseX, mouseY);

  let rect = e.currentTarget.getBoundingClientRect();
  mouseX = e.clientX - rect.left;
  mouseY = e.clientY - rect.top;

  ctx.lineTo(mouseX, mouseY);
  ctx.stroke();
}

4-2. クリックしている時だけ描ける

【王道のパターン】
ブーリアン変数（trueかfalseしか入れれない変数）を使い、mousedown、mouseupイベントで切り替える。
let ctx;
let mouseX = 0;
let mouseY = 0;
//変数追加
let click = false;

window.addEventListener('load', () => {
  init();
});

const init = () => {
  const canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  canvas.addEventListener('mousemove', onMove);

  //イベント追加
  canvas.addEventListener('mousedown', onDown);
  canvas.addEventListener('mouseup', onUp);
}

const onMove = (e) => {
  //clickがtrueの時だけに制限する
  if(click){
    ctx.beginPath();
    ctx.moveTo(mouseX, mouseY);

    let rect = e.currentTarget.getBoundingClientRect();
    mouseX = e.clientX - rect.left;
    mouseY = e.clientY - rect.top;

    ctx.lineTo(mouseX, mouseY);
    ctx.stroke();
  }
}

//mousedownイベント時に発生する関数式
const onDown = (e) => {
  click = true;

  let rect = e.target.getBoundingClientRect();
  mouseX = e.clientX - rect.left;
  mouseY = e.clientY - rect.top;
}

//mouseupイベント時に発生する関数式
const onUp = (e) => {
  click = false;
}
