「コンテンツ制作」01_Vue.jsの基礎

1. Vue.jsとは

公式サイト

Vueは、ユーザーインターフェースの構築のための JavaScript フレームワーク。標準的な HTML、CSS、JavaScript を土台とする、コンポーネントベースの宣言的なプログラミングモデルを提供する。シンプルなものから複雑なものまで、ユーザーインターフェースの開発を効率的に支えるフレームワーク。

【フレームワークとは】
設計・開発でよく利用するコードをあらかじめ用意してパッケージングしてあるもの。開発者はフレームワークが提供する枠組みに沿って、固有のコードを加えていくだけで一定の品質を持ったサイト・アプリを作り上げることができる。
【具体的にできること】
  • ビルドステップなしで静的な HTML を拡充する
  • 任意のページに Web コンポーネントとして埋め込む
  • シングルページアプリケーション (SPA)
  • フルスタック / サーバーサイドレンダリング (SSR)
  • Jamstack / 静的サイトジェネレーション (SSG)
  • デスクトップ、モバイル、WebGL、さらにはターミナルをターゲットとする開発
【その他のフレームワーク】
  • Frontend Developer Roadmap
  • State of JS 2022
【Vue.jsの特徴】
  • 導入のハードル、学習コストが低い。
  • 小さな開発から大きな開発までカバーできる。
  • 日本語のドキュメントが豊富。

3. ディレクティブ

Vue.jsは標準的なHTMLに対してディレクティブと呼ばれる属性形式の命令を記述することで、ページに機能を付与することができる。ディレクティブは「v-」で始まるのが基本。

【ディレクティブの分類】
分類 概要 主なディレクティブ
データバインド 式の値をページに反映 v-bind, v-html など
イベント イベント処理を実装 v-on
制御 条件分岐や繰り返し処理など v-if, v-for など
フォーム（双方向） フォームからの入力を取得 v-model

ビルトインのディレクティブ

3-1. 属性にデータバインドする「v-bind」

/* 基本構文
v-bind:◯◯="値"
--------------------*/


/* 例
--------------------*/
<body>
  <div id="app">
    <p><a v-bind:href="url">{{ message }}</a></p>
  </div>

  <script src="https://unpkg.com/vue@next"></script>
  <script>
    const app = Vue.createApp({
      setup(){
        const message = Vue.ref("リンク");
        const url = Vue.ref("https://computer.trident.ac.jp/");

        return {
          message,
          url
        }
      }
    });

    app.mount("#app");
  </script>
</body>

☆練習

【省略形】
「v-bind」は省略できる。

【式の記述】
<p><a :href="url + 'courses/web_design/'">{{ message }}</a></p>

3-2. イベントリスナを設定する「v-on」

/* 基本構文
v-on:イベント名="イベント発生時に実行する関数"
--------------------*/


/* 例
--------------------*/
<body>
  <div id="app">
    <p>{{ count }}</p>
    <button v-on:click="plus">+</button>
  </div>

  <script src="https://unpkg.com/vue@next"></script>
  <script>
    const app = Vue.createApp({
      setup() {
        const count = Vue.ref(0);

        const plus = () => {
          count.value++;
        };

        return {
          count,
          plus
        }
      }
    });

    app.mount("#app");
  </script>
</body>

☆練習
「-」ボタンを追加してみる。
【省略形】
「v-on」は「@」に省略できる。
<button @click="plus">+</button>
【イベントオブジェクトを受け取る】
const app = Vue.createApp({
  setup() {
    const count = Vue.ref(0);

    //イベントオブジェクトを受け取る
    const plus = (e) => {
      count.value++;
      console.log(e);
    };

    return {
      count,
      plus
    }
  }
});
【引数を受け取る】
<button @click="plus(2)">+</button>
const app = Vue.createApp({
  setup() {
    const count = Vue.ref(0);

    //引数を受け取る
    const plus = (num) => {
      count.value += num;
    };

    return {
      count,
      plus
    }
  }
});
【両方を受け取る】
<button @click="plus(2, $event)">+</button>
const app = Vue.createApp({
  setup() {
    const count = Vue.ref(0);

    //両方を受け取る
    const plus = (num, e) => {
      count.value += num;
      console.log(e);
    };

    return {
      count,
      plus
    }
  }
});
