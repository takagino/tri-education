2. 連続した描画

命令を連続して実行するには、「setInterval()」「setTimeout()」「requestAnimationFrame()」などのメソッドがある。
今回は「requestAnimationFrame()」を使用する。

【requestAnimationFrame() の特徴】
フレームを描画する準備ができた時にシステムがアニメーションフレームを呼び出すことで、よりスムーズで効率的な方法でアニメーションを提供する。通常、コールバック回数は 1 秒あたり 60 回となり、バックグラウンドタブで実行している場合は、レートが低くなることがある。
【基本形】
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Canvas</title>

  <style>
    canvas {
        background: #ddd;
        border: 1px solid #aaa;
    }
  </style>
</head>

<body>
  <canvas id='example' width='640' height='480'>
    Canvas not supported.
  </canvas>

  <script>
  let canvas, ctx;
  window.addEventListener('load', () => {
    init();
  });

  const init = ()  => {
    canvas = document.querySelector('#example');
    if (!canvas || !canvas.getContext) {
      return false;
    }
    ctx = canvas.getContext('2d');

    //メソッドを実行
    window.requestAnimationFrame(draw);
  }

  const draw = () => {
    console.log("draw!");

    //再び自関数を呼び出す（再帰関数）
    window.requestAnimationFrame(draw);
  }
  </script>

3. 座標変換

上記応用のように、複雑な（値が複数ある）図形をランダムな場所に描画する場合、それぞれの値を計算するよりも、座標空間の状態を変更してから描画した方が楽な場合が多い。

【座標変換前】
const init = () => {
  canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  ctx.globalAlpha = 0.5;

  //追加
  ctx.beginPath();
  ctx.moveTo(0, 0);
  ctx.lineTo(100, 0);
  ctx.lineTo(50, 70);
  ctx.closePath();
  ctx.fill();

  //コメントアウト
  // window.requestAnimationFrame(draw);
}
【座標変換後】
const init = () => {
  canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  ctx.globalAlpha = 0.5;

  //追加
  ctx.translate(100, 100);

  ctx.beginPath();
  ctx.moveTo(0, 0);
  ctx.lineTo(100, 0);
  ctx.lineTo(50, 70);
  ctx.closePath();
  ctx.fill();

  // window.requestAnimationFrame(draw);
}
移動
ctx.translate(x方向の距離, y方向の距離);
回転
ctx.rotate(角度); //角度はMath.PI/180
拡大縮小
ctx.scale(x方向の拡大率, y方向の拡大率);

3-1. 座標空間の保存

【修正】
const init = () => {
  canvas = document.querySelector('#example');
  if (!canvas || !canvas.getContext) {
    return false;
  }
  ctx = canvas.getContext('2d');
  ctx.globalAlpha = 0.5;

  window.requestAnimationFrame(draw);
}

const draw = () => {
  ctx.fillStyle = `hsl(${Math.random() * 360}, 50%, 50%)`;

  //追加
  ctx.save();

  ctx.translate(Math.random() * canvas.width, Math.random() * canvas.height);

  ctx.beginPath();
  ctx.moveTo(0, 0);
  ctx.lineTo(100, 0);
  ctx.lineTo(50, 70);
  ctx.closePath();
  ctx.fill();

  //追加
  ctx.restore();

  window.requestAnimationFrame(draw);
}
座標空間の状態を保存する
ctx.save();
保存した状態に戻す
ctx.restore();

  • さらに改造し、三角形の大きさをランダムにする。

5. 課題

完成したサンプルを出来る限り改造する。

  1. 背景色や各種値を良い感じに調整する。
  2. マウスをクリックしている間だけアニメーションする。（見本）
  3. スペースキーを押したら再描画する。（見本）
  4. 円が跳ね返るたびに数が増える。※重くならないように数を制限すること（見本）
  5. 残像を残す。（見本）
  6. その他、自由に改造する。
