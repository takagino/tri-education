「コンテンツ制作」06_ルーティング設定

1. ルーティングとは？

【今回の成果物】
見本

画面遷移を伴うWebサイト・Webアプリケーションにおいて、表示させる画面とパスとを結びつけ、特定のパスに対応して画面表示処理を行うことをルーティングという。Vue.jsのルーティングは「Vue Router」と呼ばれるライブラリを使用する。

【ちなみに】
シングルページアプリケーション（SPA）の導入メリット＆デメリット

1-1. 「Vue Router」の導入

  1. プロジェクト用のフォルダをVSCodeで開く。
  2. 以下のコマンドを入力して「Enter」。 
    npm init vue@latest
  3. 順番に質問に答えていく。（Add Vue Router for Single Page Application development?の質問に対しては「Yes」、それ以外は全て「No」でOK）
  4. 最初に選択した名前のフォルダの中にたくさんのデータが生成される。今回は「router」と「views」のフォルダが追加されていることに注目。
  5. 以下のようにターミナルに表示されるので、1行ずつ入力し「Enter」。 
    cd vite-project → フォルダを移動
npm install → 必要なパッケージをインストール
npm run dev → 開発環境を立ち上げる
  6. 表示されたURL（http://localhost:5173/）にアクセス。
  7. 動作確認をして完了！

1-2. ソースコードの確認

  • src > main.js
  • src > App.vue
  • src > views
  • src > router > index.js

1-3. ルーティング設定の追加

  1. 『src > views』フォルダ内の「AboutView.vue」を複製し、「ContactView.vue」を作成。 
    <!-- ContactView.vue -->

<template>
  <div class="contact">
    <h1>This is an contact page</h1>
  </div>
</template>

<style>
@media (min-width: 1024px) {
  .contact {
    min-height: 100vh;
    display: flex;
    align-items: center;
  }
}
</style>
  2. 『src > router > index.js』にルーティングを登録する。 
    /* index.js */

import { createRouter, createWebHistory } from 'vue-router'
import HomeView from '../views/HomeView.vue'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: [
    {
      path: '/',
      name: 'home',
      component: HomeView
    },
    {
      path: '/about',
      name: 'about',
      component: () => import('../views/AboutView.vue')
    },
    //追加
    {
      path: '/contact',
      name: 'contact',
      component: () => import('../views/ContactView.vue')
    }
  ]
})

export default router

/* ルーティングの登録 */
{
  path: 'パス文字列',
  name: 'ルーティング名',
  component: 表示させる画面用コンポーネント
}

/* 動的インポート */
component: HomeView → Vueプロジェクトのビルド時にインポートされる。
component: () => import('../views/AboutView.vue') → ページ遷移が行われたらインポートされる。
  3. 『src > App.vue』内のグローバルナビゲーションの項目を増やす。 
    <!-- App.vue -->

<script setup>
import { RouterLink, RouterView } from 'vue-router'
import HelloWorld from './components/HelloWorld.vue'
</script>

<template>
  <header>
    <img alt="Vue logo" class="logo" src="@/assets/logo.svg" width="125" height="125" />

    <div class="wrapper">
      <HelloWorld msg="You did it!" />

      <nav>
        <RouterLink to="/">Home</RouterLink>
        <RouterLink to="/about">About</RouterLink>
        <!-- 追加 -->
        <RouterLink to="/contact">Contact</RouterLink>
      </nav>
    </div>
  </header>

  <!-- コンポーネントが読み込まれる表示領域-->
  <RouterView />
</template>

1-4. ルーティング名での指定

<!-- App.vue -->

<script setup>
import { RouterLink, RouterView } from 'vue-router'
import HelloWorld from './components/HelloWorld.vue'
</script>

<template>
  <header>
    <img alt="Vue logo" class="logo" src="@/assets/logo.svg" width="125" height="125" />

    <div class="wrapper">
      <HelloWorld msg="You did it!" />

      <!-- 変更（「v-bind:to」になっていることに注意） -->
      <nav>
        <RouterLink :to="{ name: 'home' }">Home</RouterLink>
        <RouterLink :to="{ name: 'about' }">About</RouterLink>
        <RouterLink :to="{ name: 'contact' }">Contact</RouterLink>
      </nav>
    </div>
  </header>

  <RouterView />
</template>

2. ルートパラメータ

見本

上記見本のブログのようなコンテンツを制作したい。記事詳細ページを設定する際に、パス（URL）の末尾にその画面を表示するためのデータを埋め込むことが多い。このデータのことをルートパラメータという。

<script setup>
import { ref, onMounted } from "vue";
import { RouterLink } from 'vue-router'

const items = ref([]);

onMounted(() => {

    .then(response => response.json())

【スクリプト内でパラメータの値を取得する】
<!-- PostView.vue -->

<script setup>
import { ref, onMounted } from "vue";
/* 追加 */
import { useRoute } from 'vue-router';

const item = ref([]);
/* 追加 */
const route = useRoute();

onMounted(() => {
  /* 修正 */
  fetch('https://jsonplaceholder.typicode.com/posts/' + route.params.postId)
    .then(response => response.json())
    .then(json => {
      item.value = json;
    });
});
</script>

<template>
  <main>
    <p>{{ item.body }}</p>
    <p>{{ $route.params.postId }}</p>
  </main>
</template>
