2-2. transform（変形）

要素に「移動」「回転」「拡大・縮小」「傾斜」の動きを与えられるプロパティ。この4つの変形操作を組み合わせることで自由に要素を動かせるようになる。要素は2D（縦横方向）変形だけでなく、3D（縦横奥行き方向）の変形も可能。

2D Transforms
効果 値名 指定する値
移動 translate 、translateX、translateY 移動距離（px など）
回転 rotate 角度（deg）
拡大・縮小 scale、scaleX、scaleY 倍率（1や2 …など）
傾き skew、skewX、skewY 角度（deg）
3D Transforms
効果 値名 指定する値
移動 translateZ、translate3d 移動距離（px など）
回転 rotateX、rotateY、rotateZ 角度（deg）
拡大・縮小 scaleZ、scale3d 倍率（1や2 …など） 

.fa-arrow-right {
  transform: translateX(30px);

  /* 値を組み合わせる */
  transform: translateX(30px) rotate(45deg);

  /* 順番を変えると結果も変わる */
  transform: rotate(45deg) translateX(30px);
}

【変形の基準点】
i要素は「インライン」の特徴を持っており、内容と横幅（width）が同一のためいい感じに回転してくれる。
一方、div要素やp要素などの「ブロックレベル」の特徴を持った要素は、横幅（width）が親要素の横幅と同一になるため、意図した回転にならない。
/* うまくいかない例 */
.hoge {
  background-color: #ddd;
  transform: rotate(45deg);
}

/* うまくいく例 */
.hoge {
  background-color: #ddd;
  transform: rotate(45deg);
  transform-origin: center left;
}

3. transition（遷移）

トランジション(transition)は、要素の 2 つの状態間の変化を定義するためのもの。それぞれの状態は :hover や :active のような擬似クラスで定義されたり、 JavaScript を使用して動的に設定されたりする。

transitionプロパティの種類
プロパティ名 説明 初期値
transition-duration アニメーションする時間を指定 0s
transition-delay 何秒遅らせてアニメーションを始めるかを指定 0s
transition-property どのCSSプロパティをアニメーションさせるのかを指定 all
transition-timing-function アニメーションの進捗タイミングを調整 ease
transition 上記のプロパティをまとめて設定できる - 

/* 例 */
.hoge{
  cursor: pointer;
  transition-duration: 1s;
  transition-delay: 1s;
  transition-property: background-color;
  transition-timing-function: ease;
}

.hoge:hover{
  background-color: #f00;
}

【transition-duration】
  • アニメーションする時間を指定。
  • 必ず記述が必要。
  • 数値の後ろに〜秒間を表すsをつける。1.5sなら1.5秒間。 
    .hoge{
  transition-duration: .5s; /* 0.5の場合、0は省略できる */
}
【transition-delay】
  • 何秒遅らせてアニメーションを始めるのかを指定。
  • 初期値は0sなので、必要ない場合は記述しなくてOK。
【transition-property】
  • どのCSSプロパティをアニメーションさせるのかを指定。
  • 初期値はallとなっており、何も記述しない場合はアニメーション前後で値が異なるプロパティを全て変化させることになる。
【transition-timing-function】
  • アニメーションの進捗タイミングを調整。
  • 以下の種類から選ぶことができる。
    値の種類 内容
    ease（初期値） 途中まで加速し、そこからは減速
    ease-in ゆっくり始まり徐々に加速
    ease-out はやく始まり徐々に減速
    ease-in-out ゆっくり始まり加速、途中からは減速
    linear 一定の速度で進行
    cubic-bezier(0,0,0,0) 0の箇所に0〜1の数値を入れて、変化の度合いを自由に指定できる
  • イージング関数チートシート
  • cubic-bezier.com
【transition】
  • 上記のプロパティをまとめて設定できる
  • 命令の順番の決まりはないが、transition-delayとtransition-durationを両方設定する場合、先に書いた数値が「transition-duration」になる。
  • 書くセレクタによって、動作が変わることに注意。 
    /* マウスホバー・マウスアウト、両方とも適応 */
.hoge{
  cursor: pointer;
  transition-duration: 1s;
  transition-delay: 1s;
  transition-property: background-color;
  transition-timing-function: ease;
}

.hoge:hover{
  background-color: #f00;
}

/* マウスホバーのみ適応 */
.hoge{
  cursor: pointer;
}

.hoge:hover{
  background-color: #f00;
  transition-duration: 1s;
  transition-delay: 1s;
  transition-property: background-color;
  transition-timing-function: ease;
}

6. グラデーション

CSSのグラデーションには線形グラデーション（linear-gradient）と円形グラデーション(radial-gradient)がある。今回はより使用頻度が高い線形グラデーション（linear-gradient）に絞って勉強します。

【ブラウザ対応】
linear-gradient - Can I Use?
【基本形】
<a class="btn03" href="#">グラデーション</a>

linear-gradient(開始の色, 終了の色);

.btn03{
  background: linear-gradient(#ff0000, #ffff00);
}
【方向の指定（向き）】

linear-gradient(to 方向, 開始の色, 終了の色);

/* 「top」「right」「bottom」「left」 */
.btn03{
  background: linear-gradient(to right, #ff0000, #ffff00);
}

/* 2つ方向を指定することで斜め方向へのグラデーションも設定することができる */
.btn03{
  background: linear-gradient(to bottom right, #ff0000, #ffff00);
}
【方向の指定（角度）】

linear-gradient(角度, 開始の色, 終了の色);

/* 単位はdeg */
.btn03{
  background: linear-gradient(90deg, #ff0000, #ffff00);
}

/* マイナスの値も指定できる */
.btn03{
  background: linear-gradient(-90deg, #ff0000, #ffff00);
}
【色の指定】
/* 色はいくつでも指定できる */
.btn03{
  background: linear-gradient(90deg, #ff0000, #ffff00, #ff00ff);
}

/* 色が変わる位置（色経由点）を決める */
linear-gradient(方向, 開始の色 位置, 終了の色 位置);

.btn03{
  background: linear-gradient(90deg, #ff0000 50%, #ffff00 80%, #ff00ff);
}

6-1. グラデーションとtransition

backgroundプラパティにはtransitionを設定できないため、擬似要素を使って実現する。

.btn03 {
  position: relative;
}

.btn03::before {
  content: "";
  display: block;
  position: absolute;
  top: 0;
  left: 0;
  z-index: -1;
  width: 100%;
  height: 100%;
  border-radius: 25px;
  background: linear-gradient(90deg, #ff0000 50%, #ffff00 80%, #ff00ff);
  transition: .5s;
}

.btn03::after {
  content: "";
  display: block;
  position: absolute;
  top: 0;
  left: 0;
  z-index: -2;
  width: 100%;
  height: 100%;
  border-radius: 25px;
  background: linear-gradient(90deg, #ff00ff 50%, #ffff00 80%, #ff0000);
}

.btn03:hover::before {
  opacity: 0;
}

7. フィルター

ぼかしや色変化などのグラフィック効果を要素に適用する。フィルターは画像、背景、境界の描画を調整するためによく使われる。

【ブラウザ対応】
filter - Can I Use?
【基本形】
<img class="img01" src="https://picsum.photos/300/200" alt="">

filter: 種類(値);

.img01{
  filter: blur(5px);
}
代表的なfilterの種類
フィルター名 説明 単位
blur() ガウスぼかしを適用する px、rem
brightness() 明るくしたり暗くしたりする 数値、%
contrast() コントラストを調整する 数値、%
grayscale() グレースケールに変換する 数値、%
hue-rotate() 色相の角度を回転させる 角度(deg)
invert() 階調を反転させる %
saturate() 彩度を設定する %
sepia() セピア調にする %
【参考】
  • フィルタージェネレーター - Front-end Tools

☆ 練習

  1. 自分好みのフィルターを設定する。

7-1. フィルターとtransition

.img01 {
  filter: grayscale(100%);
  transition: .3s;
}

.img01:hover {
  filter: grayscale(0);
}

8. フォーム関連

擬似クラス「:focus」を指定することで、入力フォーム等にフォーカスが当たった際のスタイルを設定できる。

【基本形】
<input class="input01" type="text">
.input01:focus {
      background-color: #ddd;
    }

    /* 周りの青い影を打ち消す */
    .input01:focus {
      outline: none;
    }

8-1. :focusとtransition

.input01{
      transition: .3s;
    }

    .input01:focus {
      outline: none;
      background-color: #ddd;
    }

9. 様々な表現

疑似要素「::before」「::after」を組み合わせることで、様々なホバーアクションを設定することができる。

☆ 練習

<a class="border01" href="#">
  <span>Zoom Corners</span>
  <div class="zoom-corners top-corners"></div>
  <div class="zoom-corners bottom-corners"></div>
</a>

.border01 {
  background: #333;
  width: 200px;
  height: 200px;
  position: relative;
  border-radius: 0;
  color: #fff;
  display: flex;
  justify-content: center;
  align-items: center;
}

.zoom-corners::before,
.zoom-corners::after {
  content: '';
  position: absolute;
  width: 8px;
  height: 8px;
  border-color: #00edff;
  border-style: solid;
  transition: 0.3s;
}

.bottom-corners::before {
  border-width: 0 0 1px 1px;
  left: 25px;
  bottom: 25px;
}

.bottom-corners::after {
  border-width: 0 1px 1px 0;
  right: 25px;
  bottom: 25px;
}

.top-corners::before {
  border-width: 1px 0 0 1px;
  left: 25px;
  top: 25px;
}

.top-corners::after {
  border-width: 1px 1px 0 0;
  right: 25px;
  top: 25px;
}

.border01:hover .top-corners::before {
  top: 0px;
  left: 0px;
}

.border01:hover .top-corners::after {
  top: 0px;
  right: 0px;
}

.border01:hover .bottom-corners::before {
  bottom: 0px;
  left: 0px;
}

.border01:hover .bottom-corners::after {
  bottom: 0px;
  right: 0px;
}
