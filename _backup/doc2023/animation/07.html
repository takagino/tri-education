1. GSAPとは？

公式サイト

GSAP（GreenSock Animation Platform）は、JSのWebアニメーションライブラリ。複雑なアニメーションも簡単に実装ができ、その使いやすさとパフォーマンスの高さから多くのサイトに導入されている。

2. 基本的な使い方

/* 基本形 - 第1引数に対象、第2引数に変化させたいプロパティーと設定値を指定 */
gsap.to(target, { options });


/* 例 */
gsap.to(".box", { backgroundColor: "#0000ff", delay: 2 });


/* 改行して見やすく書く */
gsap.to(".box", {
  width: "200px",
  backgroundColor: "#0000ff",
  delay: 2
});

2-1. 設定値

第2引数に設定できる値
プロパティ名 説明 初期値
duration 1回のアニメーションの時間を指定 0.5
delay 何秒遅らせてアニメーションを始めるかを指定 0
repeat アニメーションを繰り返す回数を指定 0
repeatDelay アニメーションをリピートするまでの時間を指定 0
yoyo リピート時に反復挙動にするかを指定 false
ease アニメーションの進捗タイミングを調整 power2.inOut
その他 Special Properties

3-1. animationプロパティ
【イージングの種類】
Ease Visualizer
【リピートの制御】
gsap.to(".box", {
  width: "200px",
  backgroundColor: "#0000ff",
  repeat: -1, // 無限に繰り返し
  repeatDelay: 0.5, // 繰り返し時に0.5秒の待機,
  yoyo: true, // 反転
});
【transformの指定】
gsap.to(".box", {
  x: 100, // 水平方向
  y: 200, // 垂直方向
  repeat: -1,
  repeatDelay: 0.5,
  yoyo: true,
});
第2引数に設定できる値
GSAPでの書き方 説明 CSSでの書き方
x: 10 水平方向への移動（px） transform: translateX(10px)
y: 10 垂直方向への移動（px） transform: translateY(10px)
xPercent: -50 水平方向への移動（要素の幅に対する割合） transform: translateX(-50%)
yPercent: -50 水平方向への移動（要素の幅に対する割合） transform: translateY(-50%)
rotate: 360 回転角度（角度） transform: rotate(360deg)
scale: 2 拡大・縮小（1.0が等倍） transform: scale(2, 2)
scaleX: 2 水平方向だけ拡大・縮小 transform: scaleX(2)
scaleY: 2 垂直方向だけ拡大・縮小 transform: scaleY(2)
【transformの変形点の指定】
gsap.to(".box", {
  rotate: 180,
  transformOrigin: "0 0", // 数値かキーワード（top, bottom, left, right）で指定（初期値："50% 50%"）
  repeat: -1,
  repeatDelay: 0.5,
  yoyo: true,
});
【相対値の指定】
gsap.to(".box", {
  rotate: "+=45", // "+=数値" "-=数値"
  transformOrigin: "0 0",
  repeat: -1,
  repeatDelay: 0.5,
  yoyo: true,
});

2-2. アニメーションの呼び出し方法（メソッド）

【gsap.to()】
ゴールの状態を指定する。（現在の状態からのアニメーション） 
gsap.to(".box", {
  x: 200,
  delay: 2
});
【gsap.from()】
スタートの状態を指定する。（現在の状態に戻るアニメーション） 
gsap.from(".box", {
  x: 200,
  delay: 2
});

※最終的な位置をCSSで設定し、「どれだけずらして演出するか」を指定するときに役立つ。

【gsap.fromTo()】
指定した状態(初期状態)から、指定した状態(完了状態)にアニメーションさせる。 
gsap.fromTo(".box", {
  x: 100
}, {
  x: 200,
  delay: 2
});
【gsap.set()】
アニメーションはされず、指定した値を即座に適用する。
gsap.set(".box", {
  x: 100
});

3. タイムライン

タイムラインはGSAPで高度な演出をつくるうえで必ず利用する重要な機能。複雑なモーションを時系列で作成できるので、多くのトゥイーンを作成したり、管理するのに便利。 

/* はじめに初期化 */
const tl = gsap.timeline({
  repeat: -1,
  repeatDelay: 0.5
});

/* 続けて動かしたい要素を追加 */
tl.add(gsap.to(".box", {
  x: 100
}));
tl.add(gsap.to(".box", {
  y: 100
}));
tl.add(gsap.to(".box", {
  rotate: 360
}));
tl.add(gsap.to(".box", {
  x: 0
}));
tl.add(gsap.to(".box", {
  y: 0
}));
タイムラインのメソッド
関数名 説明
add() トゥイーン、タイムライン、コールバック、ラベルをタイムラインに追加
to() gsap.to()トゥイーンをタイムラインの最後に追加
from() gsap.from()トゥイーンをタイムラインの最後に追加
fromTo() gsap.fromTo()トゥイーンをタイムラインの最後に追加
set() タイミングで値をセット
call() タイミングで関数を呼び出す
【to()で指定】
const tl = gsap.timeline({
  repeat: -1,
  repeatDelay: 0.5
});

tl.to(".box", {
  x: 100
});
tl.to(".box", {
  y: 100
});
tl.to(".box", {
  rotate: 360
});
tl.to(".box", {
  x: 0
});
tl.to(".box", {
  y: 0
});

3-2. タイムラインのネスト

タイムラインに別のタイムラインを追加することで、より複雑なアニメーションを管理できる。 

/* 「D」のタイムライン */
const text01 = gsap
  .timeline()
  .to(".text01", {
    y: -50
  })
  .to(".text01", {
    x: 50
  });

/* 「E」のタイムライン */
const text02 = gsap
  .timeline()
  .to(".text02", {
    y: -50
  })
  .to(".text02", {
    x: 50
  });

/* 全体のタイムライン */
gsap
  .timeline({
    repeat: -1,
    repeatDelay: 0.5,
    yoyo: true
  })
  .add(text01)
  .add(text02, "-=0.5")
