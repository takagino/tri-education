「インタラクションアニメ」03_トゥイーンアニメーション

課題「重い箱、軽い箱」

2つの箱を上から落下させる。その際、落下速度、跳ね方、モノの色、振動など、あらゆる表現を用い、重いと軽いの違いを表現する。

【注意点】
  • 同じ空間内で落下させること。（画面を仕切ったりしてはいけない）
  • 落下させるタイミングをずらしても良い。
  • 2つの箱以外の要素を登場させても良い。ただし、限度を守ること。

0. はじめに

前回の課題

1. 準備

箱が落下するアニメーションを作成しながら、「トゥイーンアニメーション」について勉強していきます。

  • サンプルデータ
【ステージの背景色を変更】
【ショートカット】
  • 『enter』：再生／停止
  • 『shift + ,』：最初のフレームへ
  • 『shift + .』：最後のフレームへ
  • 『.』：1フレーム進める
  • 『,』：1フレーム戻る
  • 『F7』：空白キーフレームに変換
  • 『F6』：キーフレームに変換
  • 『shift + F6』：キーフレームを削除
  • 『F5』：フレームを挿入
  • 『shift + F5』：フレームを削除
【キーフレームとは】
ステージに描画されている「シェイプ」や「シンボル（後で説明します）」の状態を記録し、アニメーションの始点や終点とするためのフレーム。

1-1. アニメーションの種類

  1. シェイプトゥイーン ※癖があるので極力使用しない。
  2. クラシックトゥイーン ※古いやり方なので使用しない。
  3. モーショントゥイーン
【トゥイーンとは】
トゥイーン（tween）とは、between（中間）に由来する言葉で、2つのモノが変化しながら繋がるアニメーションのことを「トゥイーンアニメーション」という。

2. シェイプトゥイーン

2つのキーフレームに描画されているシェイプ（塗り）の間を補填し変化させるアニメーション。シェイプトゥイーンが作成されたフレームは「オレンジ色」になり矢印が表示される。

【手順】
  1. 「作業レイヤー」の1フレーム目をクリックして選択する。
  2. 適当な場所に円を描画する。（線は無し）
  3. 15フレーム目をクリックで選択し、右クリック「キーフレームに変換」を選択。（もしくはショートカット『F6』）
  4. 15フレームが選択されている状態で、自由に形を変形させる。
  5. 『shift + ,』で先頭に戻り『return（enter）』で一度再生してみる。
  6. 1フレーム〜15フレームの間どこでもいいので、右クリック「シェイプトゥイーンを作成」を選択。
  7. フレーム数が書いてある箇所をマウスで左右にドラッグし、アニメーションを確認する。

☆ 練習

間に「キーフレーム」を追加して、さらにアニメーションさせる。

2-1. シェイプトゥイーンの削除

シェイプトゥイーンは自由に形を変形したい場合に使われるが、「シェイプにしか適応できない」「意図したアニメーションにするのが難しい」などの欠点があるため、今回のサンプルでは使用しない。

【シェイプトゥイーンの削除】
「オレンジ色」のフレーム間のどこかを右クリックし「シェイプトゥイーンを削除」を選択。
【キーフレームの削除】
削除したいキーフレーム上で右クリック「キーフレームを削除」を選択。（もしくはショートカット『shift + F6』）

※複数のフレームをまとめて削除する場合は、フレームをドラッグで選択し『shift + F5』

3. モーショントゥイーン

強力でありながら作成が容易で、トゥイーンアニメーションをきめ細かく制御できる新しい手法。「クラシックトゥイーン」が2つのキーフレーム間でトゥイーンさせるのに対し、描画したモノ自体（ターゲットオブジェクト）にトゥイーンを設定する。

モーショントゥイーンが作成されたフレームは「オレンジ色」になる。

3-1. シンボルに変換

モーショントゥイーンを適応するには、描画したシェイプをシンボルに変換する必要がある。

【手順】
  1. 「作業レイヤー」の1フレーム目を選択。
  2. 「矩形ツール」でステージ上に正方形を描画する。
  3. メニュー「修正」-「シンボルに変換」、もしくはショートカット『F8』。
  4. 種類を「グラフィック」、基準点を「中央」、わかりやすい名前をつけて「OK」をクリック。
  5. プロパティインスペクタ内の「ライブラリパネル」に「グラフィックシンボル」が追加される。

3-2. モーショントゥイーンの作成

【手順】
  1. 正方形を画面中央の枠外に移動。
  2. 作業レイヤーのどこかのフレーム（90フレーム等）をクリックで選択し、F5でフレームを伸ばす。
  3. 作業レイヤーのどこかのフレームを右クリック「モーショントゥイーンを作成」を選択。
  4. 46フレーム目を選択し、ステージ下部に正方形を移動させる。
  5. タイムラインには「キーフレーム」が、ステージには「軌道（モーションパス）」が表示される。
  6. 最初のフレームに戻して再生してみる。
【注意点】
  • シンボル化せずに「モーショントゥイーン」を適応すると勝手にシンボルが作られてしまう。
  • シンボル化をする際の「基準点」を変更すると「x座標」「y座標」の値が変わる。
  • 「モーショントゥイーン」が適応されているレイヤーにはシンボルが1つしか配置できない。（複数配置しようとすると「置き換えますか？」のメッセージが表示される）
【クラシックトゥイーンとの違い】
  • クラシックトゥイーン：F6でキーフレームを作成してからシンボルを変化させる
  • モーショントゥイーン：特定のフレーム上でシンボルを変化させると、自動的にキーフレームが作成される

☆ 練習

次のような、箱が落ちるアニメーションを完成させる。
※基本フォルダ内の「基本」レイヤーを参考にしても良い。

【トゥイーンのコツ】
  • フレーム数は後で簡単に調整できる（F5、shift+F5、ドラッグでの移動）ので、だいたいのアニメーションを作ってから調整すると良い。
  • 位置などの細かい調整は、プロパティパネルから値を直接入力すると良い。

4. イージング

イージングとは「動きの加減速」を示す用語で、アニメーションにおいては動きの「性格」を表すもの。適切なイージングを設定することで、ユーザーへ与える印象が変わり、世界観やユーザー体験をデザインするうえでイージングは欠かせない要素である。

イージングにはたくさんの種類があるが、大まかに以下の4つに分けられる。

  • linear： 等速で変化する。のっぺりとした安定した印象
  • easeIn： 徐々に加速する。加速するような勢いのある印象
  • easeOut： 徐々に減速する。変化の余韻が残りやすい印象
  • easeInOut： 加速してから減速。もっともメリハリのある印象

4-1. モーションエディターの表示

  1. イージングをつけたいトゥイーンをダブルクリック、もしくは右クリック「モーショーントゥイーンを調整」。
  2. 場所の項目の「Y座標」のグラフを選択する。
  3. 「グラフ上のアンカーポイントを追加」アイコンをクリックし、8フレームあたりのグラフ上をクリックする。
  4. 下図のようにグラフを調整する。
  5. ダブルクリックで「モーションエディター」を閉じ、最初のフレームに戻して再生してみる。

5. 複数の動きを組み合わせる

次のように、横への移動も追加したい。

キーフレームをひとつずつ変更するのは面倒くさい、また、横の動きと縦の動きで別々のイージングを適応できないため、動きがぎこちなくなってしまう。

こんな時は、別々のライムラインでそれぞれの動きをさせると上手くいく。

【手順】
  1. 作業レイヤーを右クリック「レイヤーをシンボルに変換」。
  2. わかりやすい名前をつけて「OK」をクリック。
  3. 箱を画面左端に持っていき、「モーショントゥイーンを作成」。
  4. 46フレーム目で、箱を右下に移動する。
  5. 最初のフレームに戻して再生してみる。

6. シンボルの回転

回転の動きも追加したい。

メインタイムライン上で回転の動きを追加すると、おかしな動きになってしまう。今回はシンボル「box_move」のタイムライン上で回転の動きを追加する。

【手順】
  1. ライブラリパネル内の「box_move」を右クリック「複製」でバックアップをとっておく。
  2. 複製元のシンボルをダブルクリックし、編集モードに入る。
  3. 46フレーム目を選択し「自由変形ツール」で180度回転させる。（それ以上回転させると、なぜかうまくいかない）
  4. モーションエディターを表示し、『回転 > z』を選択。
  5. 表示倍率を「400%」程度に変更し、微調整しやすくする。
  6. アンカーポイントをドラッグし、「720」の目盛りまで移動させる。（shiftを押しながら）
  7. 画面左上の「←」をクリックし、メインタイムラインに戻る。
  8. 再生してみる。

☆ 練習

落下する箱をもう1つ追加し、その箱に跳ね返るアニメーションを作成する。

7. モーショントゥイーンのリピート

以下のような動きを考える。

【手順】
  1. 新規レイヤーを作成し、ライブラリパネルからステージに「box」をドラッグ・アンド・ドロップする。
  2. 「選択ツール」で画面左下に配置する。
  3. どこかのフレームをクリックし、「モーショントゥイーンを作成」。

7-1. 変形点

「自由変形ツール」でシンボルを選択した際に表示される白い丸を「変形点」といい、回転や伸縮の基準となる。

【手順の続き】
  1. 1フレーム目を選択した状態で、変形点を右下に移動させる。
  2. 10フレーム目をクリックし、90度回転させる。

続けて、変形点を移動しながら回転をさせるが、意図した動きにならない。こんな時は、別々のモーショントゥイーンとして配置するとうまくいく。

【手順の続き】
  1. 10フレーム目でいったんモーショントゥイーンを終了させるため、11フレーム以降を削除する。
  2. 10フレーム目までをマウスでドラッグし、右クリック「フレームをコピー」。
  3. 11フレーム目を選択し、右クリック「フレームをペースト」。
  4. 11フレーム目が選択された状態で、「x座標」を200に変更する。
  5. あと3回繰り返す。
【注意点】
  • フレームの「x座標・y座標」と、シンボルの「x座標・y座標」の違いに注意。
