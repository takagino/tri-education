2-1. アニメーションの設定

gsap.to(".box", {
  x: 100,
});
【ScrollTriggerの設定】
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
  },
});
ScrollTriggerのプロパティ
プロパティ名 説明 単位 初期値
trigger アニメーションのトリガー要素を指定 なし なし
start アニメーション開始位置 文字列、px、% top bottom
end アニメーション終了位置 文字列、px、% bottom top
markers マーカー表示 真偽値 false
scrub スクロール量に合わせてアニメーション 真偽値 false
pin 要素を固定 真偽値 false
toggleActions アニメーション開始のタイミングと動き方を指定 文字列 play none none none
【trigger】
  • アニメーションのトリガー要素を指定。 
    //アニメーションの対象を「body」に変更してみる
gsap.to("body", {
  backgroundColor: "#ddd",
  scrollTrigger: {
    trigger: ".box",
  },
});
【start】
  • アニメーション開始位置を指定。 
    start: "トリガー要素の高さの基準 画面の位置",

//ディフォルト
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "top bottom",
  },
});

//トリガー要素が画面内に全て入った時
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "bottom bottom",
  },
});

//画面の中央に来た時
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "center center",
  },
});

//「%」で指定
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "center 30%",
  },
});

//「px」で指定
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "center 100",
  },
});

//相対値で指定
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "center bottom-=200",
  },
});
【end】
  • アニメーション終了位置を指定。
  • 指定方法は「start」と同じ。 
    end: "トリガー要素の高さの基準 画面の位置",

//ディフォルト
gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    end: "bottom top",
  },
});
  • 後述する「scrub」「toggleActions」を設定する際に必要となる。
【markers】
  • アニメーションの開始位置と終了位置を表示する。 
    gsap.to(".box", {
  x: 100,
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "bottom 20%",
    markers: true, //追加
  },
});
  • 完成したら消しておくのを忘れないこと。
【scrub】
  • スクロール量に合わせてアニメーションさせるかを指定。 
    gsap.to(".box", {
  x: 100,
  rotate: 360, //追加
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "bottom 20%",
    markers: true,
    scrub: true, //追加
  },
});
【pin】
  • 要素を固定させるかを指定。 
    gsap.to(".box", {
  x: 100,
  rotate: 360, //追加
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "bottom 20%",
    markers: true,
    scrub: true,
    pin: true, //追加
  },
});

【toggleActions】
  • アニメーション開始のタイミングと動き方を指定。 
    //ディフォルト
gsap.to(".box", {
  x: 100,
  rotate: 360,
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "bottom 20%",
    markers: true,
    toggleActions: "play none none none",
  },
});

4つの値は、左から順に以下の意味を持つ。

  1. onEnter：startで要素の位置がscroller-startの下から上に移動した時
  2. onLeave：endで要素の位置がscroller-endの下から上に移動した時
  3. onEnterBack：endで要素の位置がscroller-endの上から下に移動した時
  4. onLeaveBack：startで要素の位置がscroller-startの上から下に移動した時

わかりやすい例

指定できる値は以下の通り。

  • play：アニメーション開始（1つ目の初期値）
  • none：何もしない（2〜4つ目の初期値）
  • pause：一時停止
  • resume：アニメーションを再開
  • reset：アニメーション前の状態で停止
  • restart：最初に戻ってアニメーション開始
  • complete：アニメーション後の状態で停止
  • reverse：逆再生

公式のサンプル 

//範囲に入るたびにアニメーションさせる例
gsap.to(".box", {
  x: 100,
  rotate: 360,
  scrollTrigger: {
    trigger: ".box",
    start: "top 80%",
    end: "bottom 20%",
    markers: true,
    toggleActions: "play reverse play reverse",
  },
});

※「scrub」との共存は出来なさそう。

3. タイムライン

タイムラインはGSAPで高度な演出をつくるうえで必ず利用する重要な機能。複雑なモーションを時系列で作成できるので、多くのトゥイーンを作成したり、管理するのに便利。 

gsap
  .timeline({
    repeat: -1,
    repeatDelay: 0.5
  })
  .to(".box", {
    x: 100
  })
  .to(".box", {
    y: 100
  })
  .to(".box", {
    rotate: 360
  })
  .to(".box", {
    x: 0
  })
  .to(".box", {
    y: 0
  });
【ScrollTriggerの設定】
gsap
  .timeline({
    scrollTrigger: {
      trigger: ".box",
      start: "top 80%",
      end: "bottom 20%",
      markers: true,
      toggleActions: "play none none reset",
    },
  })
  .to(".box", {
    x: 100,
  })
  .to(".box", {
    y: 100,
  })
  .to(".box", {
    rotate: 360,
  })
  .to(".box", {
    x: 0,
  })
  .to(".box", {
    y: 0,
  });

4. 複数要素のアニメーション

  • サンプルデータ
  • 見本
【クラスの追加】
<div class="clothes__header fadeInUp">
【✕間違いやすい書き方】
gsap.from(".fadeInUp", {
  y: 100,
  opacity: 0,
  scrollTrigger: {
    trigger: ".fadeInUp",
    start: "top 80%",
    toggleActions: "play none none reverse",
  },
});
【◯正しい書き方】
gsap.utils.toArray(".fadeInUp").forEach(target => {
  gsap.from(target, {
    y: 100,
    opacity: 0,
    scrollTrigger: {
      trigger: target,
      start: "top 80%",
      toggleActions: "play none none reverse",
    },
  });
});

4-1. カスタムデータ属性でタイミングをずらす

【カスタムデータ属性の追加】
<!-- data-◯◯="値" （◯◯は自由に設定できる）-->

<div class="clothes__header fadeInUp" data-delay="0.5">
【カスタムデータ属性の取得】
gsap.utils.toArray(".fadeInUp").forEach(target => {
  //対象.dataset.◯◯; （◯◯は自分で設定した名前）
  const s = target.dataset.delay;
  console.log(s);

  gsap.from(".fadeInUp", {
    y: 100,
    opacity: 0,
    scrollTrigger: {
      trigger: target,
      start: "top 80%",
      toggleActions: "play none none reverse",
    },
  });
});
【delayの値に設定】
gsap.utils.toArray(".fadeInUp").forEach(target => {
  const s = target.dataset.delay;

  gsap.from(".fadeInUp", {
    y: 100,
    opacity: 0,
    delay: s, //追加
    scrollTrigger: {
      trigger: target,
      start: "top 80%",
      toggleActions: "play none none reverse",
    },
  });
});
【初期値を設定】
gsap.utils.toArray(".fadeInUp").forEach(target => {
  const s = target.dataset.delay || 0; //変更

  gsap.from(".fadeInUp", {
    y: 100,
    opacity: 0,
    delay: s,
    scrollTrigger: {
      trigger: target,
      start: "top 80%",
      toggleActions: "play none none reverse",
    },
  });
});

※レスポンシブ対応が必要。
