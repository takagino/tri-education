2. ターミナルの操作

【準備】
  1. 任意の場所に任意の名前でフォルダを作成。

  3. VSCodeメニュー『表示 > ターミナル』でターミナルを表示。

2-1. 主なコマンド

コマンド 説明
pwd 「print working directory」の略。
現在のフォルダ（カレントディレクトリ）のパスを表示。
ls 「list」の略。
カレントディレクトリにあるファイルを表示。
cd 「change directory」の略。
指定したファイルに移動。 
cd xxx  # xxxというファイルへ移動
cd ~/  # ホームディレクトリへ移動 [$ cd] や [$ cd ~] だけでも可能
cd ..  # 一つ上の階層のファイルへ移動
cd ./ # 現在いるディレクトリ階層へ移動
cd ../.. # 今より２つ上の階層へ移動

cd Desktop # デスクトップへ移動（%の前に現在のフォルダが表示される）
※「cd 」の後にファイルをドラッグ・アンド・ドロップすることで、そのファイルまでのパスを表示できる。
touch 中身が空のファイルを作成する。 
touch xxx.js  # xxx.jsという空ファイルを作成
mkdir 「make directory」の略。
ディレクトリ（フォルダ）を作成する。 
mkdir xxx  # xxxというフォルダを作成

4-1. Webサーバーを立ち上げる

/* app.js */

const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const server = http.createServer((req, res) => {
  res.end('Hello World');
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});

//ターミナルに出力された「http://127.0.0.1:3000」にアクセス。
//「127.0.0.1」はローカル・ループバック・アドレスと呼ばれ、自分自身を指す特別なIPアドレス。

※ファイルを編集した際は「control + c」で動作を終了し、再度「nodeコマンド」で実行する。

/* app.js */

const fs = require('fs');
const http = require('http');

const port = 3000;

5-3. ルーティング（経路を振り分ける）

現状ではサーバーにアクセスしたら必ずindex.htmlしか表示されず、CSSファイルや画像を表示することもできない。そこで、クライアントがアクセスしたアドレスによって表示する内容を変える「ルーティング」を設定する。

【URLの取得】
/* app.js */

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./index.html', 'utf-8');

const server = http.createServer((req, res) => {

  //URL（パス部分）の取得
  console.log(req.url);

  res.writeHead(200, { 'Content-type': 'text/html' });

  res.end(index);
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});

※URLの末尾に適当な文字列を追加し、ブラウザを再読み込みしてみる。

/* app.js */

const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./index.html', 'utf-8');

const server = http.createServer((req, res) => {

  //変更
  const pathName = req.url;

  if (pathName === '/') {
    res.writeHead(200, { 'Content-type': 'text/html' });
    res.end(index);
  } else {
    res.writeHead(404); /* 404は「リクエストされたリソースを見つけることができない時のレスポンスコード」*/
    res.end('Not Found...');
  }
});

server.listen(port, hostname, () => {
  console.log(`Server running at http://${hostname}:${port}/`);
});

    res.writeHead(404);

  }
});

6. モジュールのインストール

npm経由でインストール＆読み込む（require）ことで、世界中の誰かさんが作成したモジュールを使用できる。

【npmとは】
正式名称は「Node Package Manager」。その名の通り、Node.jsのパッケージ（Package）を管理する（Manager）ツール。

公式サイト

6-1. 「package.json」の作成

実行中のプログラムの「名前」や「バージョン」、インストールされたモジュールの「名前」や「バージョン」などの情報が記載されているファイル。

【手順】
  1. ターミナルを表示、以下のコードを入力し「Enter」。 
    npm init
  2. 色々と出てくるが、すべて「Enter」を押して進める。
  3. VSCodeのファイル一覧に「package.json」が追加されれば完了。
  4. 中身を確認しておく。

※初期設定で作成する場合は「npm init -y」と入力すると便利。

6-2. 「Socket.io」のインストール

「ストリーミング」や「WebSocket」などのリアルタイム通信系のWeb技術を、簡単に使うためのフレームワーク。サーバー側の処理を実現するためのNode.jsライブラリと、クライアント側の処理を実現するためのJavaScriptライブラリで構成されている。Arduinoとの連携でも必要となる。

公式サイト

【手順】
  1. ターミナルに以下のコードを入力し「Enter」。 
    npm install socket.io
  2. VSCodeのファイル一覧に「node_modules」フォルダと、「package-lock.json」が追加されれば完了。（出てこない人はFinderで確認）
  3. 中身を確認しておく。
  4. 「package.json」の中身の変化も確認しておく。
