1. 最終課題

「何かしらのセンサーおよびパーツ」を使って、ブラウザ上で「何かしらの変化」を起こす作品を制作する。

【条件】
  • 個人制作。
  • 「p5.js」の使用を推奨。
  • インターフェイス（センサー側の見た目）にもこだわること。
【進め方】
  1. 作るものを決めたら高木に相談。OKが出たら制作を進める。
  2. プログラムの難しい部分は高木がヒントを渡すので、それまではセンサーの値の取得、画像等のデータの用意、センサーを隠すためのインターフェースの制作を行う。
【参考】
【使用できるセンサおよびパーツ】
  • スイッチ
  • 距離センサ
  • 明るさセンサ
  • 振動センサ
  • 曲げセンサ
  • 感圧センサ
  • 加速度センサ

2. Arduinoとの連携

2-1. Arduino側の設定（1回やればOK）

  1. PCとArduinoを接続。
  2. 「Arduino IDE」を立ち上げる。
  3. 『Select Board』の欄が「Arduino Uno」になっていることを確認。
  4. 『File > Examples > Firmata > StandardFirmataPlus』を開く。
  5. 検証 → 書き込み
  6. 書き込みが完了したらArduinoは終了する。

2-2. 距離センサーの回路

2-3. モジュールのインストール

  1. VSCodeでターミナルを表示。
  2. 以下のコードを入力し「Enter」。（初期設定） 
    npm init -y
  3. さらに、以下のコードを入力し「Enter」。（モジュールのインストール） 
    npm install socket.io johnny-five
  4. フォルダ内に「app.js」と「index.html」を新規作成。

2-4. ソースコード

  1. 「app.js」に以下のように記述。 
    /* app.js */
const fs = require('fs');
const http = require('http');

const hostname = '127.0.0.1';
const port = 3000;

const index = fs.readFileSync('./index.html', 'utf-8');

const server = http.createServer((req, res) => {
  const pathName = req.url;

  if (pathName === '/') {
    res.writeHead(200, {
      'Content-type': 'text/html'
    });
    res.end(index);
  } else {
    res.writeHead(404);
    res.end('Not Found...');
  }
});

const five = require('johnny-five');
const board = new five.Board();

board.on("ready", () => {
  console.log("Arduino ready!");

  const sensor = new five.Sensor({
    pin: "A0",
    freq: 30
  });

  server.listen(port, hostname, () => {
    console.log(`Server running at http://${hostname}:${port}/`);

    const io = require("socket.io")(server);

    io.on("connection", (socket) => {
      console.log(`Connection completed!`);

      sensor.on("change", () => {
        io.emit('sensor_value', sensor.value);
      });

    });
  });
});
