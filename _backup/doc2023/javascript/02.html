2. 配列に関する追加知識

2-1. for...of文

for...of文は、配列などの反復可能オブジェクトに対する繰り返し処理を記述できる。 

/* 基本形
--------------------*/
for( const 変数 of 反復可能オブジェクト){
  // 繰り返し処理
};


/* 例
--------------------*/
let val = 0;
const number = [10, 20, 30];

for (const num of number) {
  val += num;
};

console.log(val);

【forEachとの違い01】
forEach は、配列と配列風オブジェクトしか反復処理できない。
【forEachとの違い02】
forEach は、break文やcontinue文が使用できない。 
/* for...ofの場合
--------------------*/
let val = 0;
const number = [10, 20, 30];

for (const num of number) {
  if (num === 20) {
    break;
  };

  val += num;
};

console.log(val);


/* forEachの場合
--------------------*/
let val = 0;
const number = [10, 20, 30];

number.forEach(num => {
  if (num === 20) {
    break; //エラーとなる
  };

  val += num;
});

console.log(val);
【インデックスの取得】
/* for...ofの場合
--------------------*/
let val = 0;
const number = [10, 20, 30];

for (const [index, num] of number.entries()) {
  val += num;
  console.log(index);
};

console.log(val);


/* forEachの場合
--------------------*/
let val = 0;
const number = [10, 20, 30];

number.forEach((num, index) => {
  val += num;
  console.log(index);
});

console.log(val);

2-2. mapメソッド

map() メソッドは、与えられた関数を配列のすべての要素に対して呼び出し、その結果からなる新しい配列を生成する。

const prices = [180, 190, 200];

const updatePrices = prices.map((price, index) => {
  return price + index;
});

console.log(updatePrices);


/* アロー関数の省略
--------------------*/
const updatePrices = prices.map((price, index) => price + 20); // 中括弧内が1行の場合は中括弧とreturnを省略できる
const updatePrices = prices.map(price => price + 20); //引数が1個の場合は括弧を省略できる

2-3. filterメソッド

filter() メソッドは、与えられた関数によって実装されたテストに合格したすべての配列からなる新しい配列を生成する。

const numbers = [1, 4, 7, 8, 10];

/* 偶数の値だけを取り出す
--------------------*/
const evenNumbers = numbers.filter(number => {
  return number % 2 == 0;
});

console.log(evenNumbers);

2-4. スプレッド演算子

スプレッド演算子（スプレッド構文）は、オブジェクトや配列のすべての要素を何らかのリストに入れる必要がある場合に使用する。

/* うまくいかない例
--------------------*/
const otherScores = [40, 50];
const scores = [10, 20, 30, otherScores];
console.log(scores);


/* スプレッド演算子を使った例
--------------------*/
const otherScores = [40, 50];
const scores = [10, 20, 30, ...otherScores];
console.log(scores);

【関数への応用】
const scores = [10, 20];

const sum = (a, b) => {
  console.log(a + b);
};

sum(...scores);
【よく使う場面「配列のコピーを作る」】
/* 普通に代入すると参照元の配列の変化に影響されてしまう
--------------------*/
const scores = [10, 20, 30];
const otherScores = scores;
console.log(otherScores);

scores[0] = 0;
console.log(otherScores[0]);


/* スプレッド演算子で代入すると影響されない
--------------------*/
const scores = [10, 20, 30];
const otherScores = [...scores];
console.log(otherScores);

scores[0] = 0;
console.log(otherScores[0]);
【よく使う場面「NodeListを配列に変換する」】
/* 要素を指定した際の配列風オブジェクト（NodeList）にはfilterなどのメソッドは使えない
--------------------*/
const btns = document.querySelectorAll('button');

const select = btns.filter(elem => {
  return elem.classList.contains('active');
});

console.log(select);


/* スプレッド演算子を通すと良い
--------------------*/
const btns = document.querySelectorAll('button');

const select = [...btns].filter(elem => {
  return elem.classList.contains('active');
});

console.log(select);

2-5. 分割代入

配列から値を取り出して、別個の変数に直接代入できる。

const scores = [10, 20, 30, 40, 50];

const [a, b, c, d, e] = scores;
console.log(a);
console.log(b);

【残余プロパティ（残余引数）】
const scores = [10, 20, 30, 40, 50];

const [a, b, ...others] = scores;
console.log(a);
console.log(b);
console.log(others);
【よく使う場面「値の入れ替え」】
let a = 10;
let b = 20;

[a, b] = [b, a];
console.log(`a:${a}, b:${b}`);
【よく使う場面「配列のシャッフル」】
const shuffle = (array) => {
  for (let i = array.length - 1; i > 0; i--) {
    let j = Math.floor(Math.random() * (i + 1));
    [array[i], array[j]] = [array[j], array[i]];
  };

  return array;
};

const scores = [10, 20, 30, 40, 50];
console.log(shuffle(scores));

3. 実践「ビンゴマシーン」

見本

【機能】
  • スタートボタンを押すとタイマーがスタートし、1から75までのランダムな数字が表示される。
  • ストップボタンを押すとタイマーがストップする。
  • タイマーがストップするとボーダーの下に出た数字が表示される。
  • 再度スタートボタンを押すとタイマーがスタートする。
  • リセットボタンを押すとタイマーがストップし、今まで出た数字がリセットされる。
  • 一度出た数字は2度と出てこない。
  • ボタンを連打してもエラーが起きない。
【手順】
  1. 1から75の数字が入った配列を用意する。
  2. 上記の配列をシャッフルした別の配列を用意する。
  3. スタートボタンをクリックしたらタイマーをスタート。シャッフルした配列の値を順番に表示する。
  4. この時、配列の最後まで進んだら最初に戻す処理と、ボタンを連打してもエラーが起きない処理をほどこす。
  5. ストップボタンをクリックしたらタイマーをストップ。出た数字を別の履歴用の配列に追加する。同時に履歴用の配列の値を画面に表示する。
  6. この時、ボタンを連打したりスタート前にストップボタンを押してもエラーが起きない処理をほどこす。
  7. リセットボタンをクリックしたらタイマーをストップ。すべての値をリセットし、シャッフルした配列を再度設定する。
