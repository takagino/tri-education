1. 自作のChrome拡張機能

1-1. 最低限必要なファイル構成

  1. 任意の場所に新規フォルダを作成。（場所を変更するとアクセス不能になるので注意）
  2. 新規ファイルを作成し、ファイル名「manifest.json」で保存。
  3. 以下のソースコードを記述し、保存。 
    {
  "name": "拡張機能のタイトル",
  "version": "1.0.0",
  "manifest_version": 3
}
  4. GoogleChromeのメニュー「拡張機能 > 拡張機能を管理」を選択し一覧を表示。
  5. 右上の「ディベロッパー モード」をオンにする。
  6. 左上の「パッケージ化されていない拡張機能を読み込む」をクリックし、制作したフォルダを選択する。
  7. 拡張機能が追加されることを確認。
  8. 右上の「パズルピースアイコン」をクリックし、拡張機能をピン止めする。
【変更と更新】
  1. 「manifest.json」に説明（description）を追加し、保存。 
    {
  "name": "拡張機能のタイトル",
  "description": "拡張機能の説明",
  "version": "1.0.0",
  "manifest_version": 3
}
  2. 拡張機能一覧ページ上部の「更新」ボタンをクリック。
【アイコンの設定】
  1. 新規フォルダ「images」を作成し、以下の画像3点を入れておく。
  2. 「manifest.json」にアイコンの設定を追加し、保存。 
    {
  "name": "拡張機能のタイトル",
  "description": "拡張機能の説明",
  "version": "1.0.0",
  "manifest_version": 3,
  "icons": {
    "16": "./images/icon16.png",
    "48": "./images/icon48.png",
    "128": "./images/icon128.png"
  }
}
  3. 「更新」ボタンをクリック。

マニフェストファイルに設定できる項目

1-2. ポップアップの表示

  1. 拡張機能フォルダ内に、新規ファイル「popup.html」を作成。
  2. 以下のソースコードを記述し、保存。 
    <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>眠気を覚ます</title>
  <link rel="stylesheet" href="https://unpkg.com/modern-css-reset/dist/reset.min.css">
  <style>
    .container {
      width: 500px;
    }
  </style>
</head>
<body>
  <div class="container">
    <img src="https://www.amepla.jp/media/wp-content/uploads/2021/12/tsubo.jpg" alt="">
  </div>
</body>
</html>
  3. 「manifest.json」に設定を追加し、保存。 
    {
  "name": "眠気を覚ます",
  "description": "眠気を覚ますツボを表示してくれます。",
  "version": "1.0.0",
  "manifest_version": 3,
  "icons": {
    "16": "./images/icon16.png",
    "48": "./images/icon48.png",
    "128": "./images/icon128.png"
  },
  "action": {
    "default_popup": "popup.html"
  }
}
  4. 「更新」ボタンをクリック。

1-3. jsの実行

  1. 拡張機能フォルダ内に、新規ファイル「popup.js」を作成。
  2. 以下のソースコードを記述し、保存。 
    const img = document.querySelector('img');
img.addEventListener('click', () => {
  alert('click!');
});
  3. 「popup.html」のbody要素内でjsを読み込む。 
    <body>
  <div class="container">
    <img src="https://www.amepla.jp/media/wp-content/uploads/2021/12/tsubo.jpg" alt="">
  </div>

  <!-- js読み込み -->
  <script src="./popup.js"></script>
</body>
  4. 「更新」ボタンをクリック。

※インラインスクリプトで読み込むとエラーがでるので注意。（セキュリティのため）
