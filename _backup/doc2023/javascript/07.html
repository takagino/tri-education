1. Firebaseとは？

【第1回】 Google の mBaaS 「 Firebase 」とは？【はじめてみよう Firebase】

1-1. Firebaseの登録

  1. ログイン画面にアクセスし、自分のGoogleアカウントでログイン。
  2. 「プロジェクトを作成」をクリック。
  3. 適当な名前をつけ、「同意」にチェックを入れて「続行」をクリック。
  4. アナリティクスのチェックを外し「プロジェクトを作成」をクリック。（公開＆運営する前提であればチェックしておいたほうがいいかも）
  5. 新しいプロジェクトの準備ができたら「続行」をクリック。

1-2. アプリの追加

  1. 遷移したページ内の「</>」アイコンをクリック。
  2. アプリに適当な名前をつけて「アプリを登録」をクリック。（「Firebase Hosting」はどちらでも）
  3. HTMLに挿入するスクリプトが表示されるが、後からでも確認できるので、そのまま「コンソールに進む」をクリック。
  4. コンソール画面に戻ったら、「1個のアプリ」のボタンをクリックし、先程作成したアプリの右側にある「歯車アイコン」をクリック。
  5. 全般タブの下部に先程のスクリプトが表示されていることを確認。

1-3. 「Cloud Firestore」の追加

  1. 左側メニュー「すべてのプロダクト > Cloud Firestore」をクリック。
  2. 「データベースの作成」をクリック。
  3. 「テストモードで開始する」を選択し、「次へ」をクリック。
  4. ロケーションから「asia-northeast1（Tokyo）」を選択し、「有効にする」をクリック。（ロケーション一覧）
【Cloud Firestoreとは】
Googleが提供しているNoSQLドキュメント指向データベース。柔軟なデータ構造、高機能なクエリ処理、リアルタイムアップデート、オフラインサポートなどが特徴。

1-4. ルールの設定

テストモードでアプリを制作すると、誰でもデータの追加・更新・削除ができるが、30日経過するとアクセス不能になる。警告メールが届き煩わしいので、今回は有効期限を無制限にしておく。（実際に公開するアプリを作る場合は自分で調べて適切なルールを設定すること）

  1. Cloud Firestoreのページを表示し、「ルール」タブをクリック。
  2. 「allow read, write: 〜」の1行を以下のように変更。 
    allow read, write: if true;
  3. 「公開」をクリック。

    correctText.textContent = `正解数：${correct}`;
    for (const item of result) {
      const li = document.createElement('li');
      for (const [key, value] of Object.entries(item)) {
        const span = document.createElement('span');
        span.textContent = `${key} : ${value}`;
        li.append(span);
      };
      list.append(li);
    }
    resultArea.style.display = 'block';
  };
});
