3. Cookie

3-1. 確認方法

  1. Chromeディベロッパーツールを表示
  2. 「Application」タブを選択
  3. 左メニューの中から「Storage > Cookies」を選択

3-2. 基本操作

【準備】
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Cookie</title>
</head>
<body>
  <button id="save">保存</button>
  <button id="get">取得</button>
  <button id="delete">削除</button>

  <script>
    const save = document.querySelector("#save");
    const get = document.querySelector("#get");
    const del = document.querySelector("#delete");
  </script>
</body>
</html>
【Cookieを保存する】
save.addEventListener('click', () => {
  document.cookie = "text=クッキー";
});
【Cookieを取得する】
get.addEventListener('click', () => {
  alert(document.cookie);
});

※ページが再読み込みされてもCookieのデータは残っているので、「取得」ボタンをクリックしたらアラートが出るはず。

【Cookieを削除する】
/*
「text」の値を空、「max-age」の値を0にして、Cookieを書き込む
*/

del.addEventListener('click', () => {
  document.cookie = "text=; max-age=0";
});
【cookieに設定できるオプション属性】
  • path・・・指定したパスがcookieの有効範囲になる
  • domain・・・指定したドメインがcookieの有効範囲になる
  • max-age・・・指定した秒数が有効範囲になる
  • expires・・・指定した日付までが有効範囲になる
  • secure・・・https通信のみcookieが有効になる
//オプション属性を追加する場合は「;」で区切る
document.cookie = `text=XXXX; max-age=XXXX; domain=XXXX; path=XXXX`;

//expiresの設定方法
let now = new Date();
now.setMinutes(now.getMinutes() + 10); // 10分後
document.cookie = `text=XXXX; expires=${now.toUTCString()};`;

//expiresでCookieを削除する
let now = new Date();
now.setMinutes(now.getMinutes() - 1); // 過去の時間を設定（1分前）
document.cookie = `text=XXXX; expires=${now.toUTCString()};`;
【複数のCookieを保存する】

save.addEventListener('click', () => {
  document.cookie = "text=クッキー";
  document.cookie = "text2=ビスケット";
});
【「=」以降の値だけ取得する】
const getCookieValue = (key) => {
  const cookies = document.cookie.split(';');
  for (const cookie of cookies) {
    let cookiesArray = cookie.split('=');
    if (cookiesArray[0].trim() == key.trim()) {
      return cookiesArray[1];
    }
  }
  return '';
}

get.addEventListener('click', () => {
  alert(getCookieValue('text'));
});
【全てのCookieを削除する】
const deleteAllCookies = () => {
  const cookies = document.cookie.split(";");
  for (const cookie of cookies) {
    let eqPos = cookie.indexOf("=");
    let name = eqPos > -1 ? cookie.substr(0, eqPos) : cookie;
    document.cookie = `${name}=; max-age=0`;
  }
};

del.addEventListener('click', () => {
  deleteAllCookies();
});

3-3. オブジェクト（配列）の扱い

Cookieは文字列しか保存できないため、オブジェクト（配列）の形のままでは渡せない。

    let cookiesArray = cookie.split('=');
    if (cookiesArray[0].trim() == key.trim()) {
      return cookiesArray[1];
    }
  }
  return '';
}

//全て削除

  const cookies = document.cookie.split(";");
  for (const cookie of cookies) {
    let eqPos = cookie.indexOf("=");
    let name = eqPos > -1 ? cookie.substr(0, eqPos) : cookie;
    document.cookie = `${name}=; max-age=0`;
  }

save.addEventListener('click', () => {
  document.cookie = `text=${obj}`;
});

get.addEventListener('click', () => {
  alert(getCookieValue('text'));
});

del.addEventListener('click', () => {
  deleteAllCookies();
});

【文字列へ変換】
save.addEventListener('click', () => {
  document.cookie = `text=${JSON.stringify(obj)}`;
});
【改めてオブジェクトへ変換】
get.addEventListener('click', () => {
  let value = JSON.parse(getCookieValue('text'));
  alert(value.name);
});

3-4. エンコード処理

保存した文字列に記号や空白が含まれていると、不具合が起こる可能性があるため、エンコード処理をしておくと安全。

【エンコード処理】
save.addEventListener('click', () => {
  document.cookie = `text=${encodeURIComponent(JSON.stringify(obj))}`;
});
【デコード処理】
//値を取り出す関数を修正
const getCookieValue = (key) => {
  const cookies = decodeURIComponent(document.cookie).split(';');
  for (const cookie of cookies) {
    let cookiesArray = cookie.split('=');
    if (cookiesArray[0].trim() == key.trim()) {
      return cookiesArray[1];
    }
  }
  return '';
}

4. Local Storage

4-1. 確認方法

  1. Chromeディベロッパーツールを表示
  2. 「Application」タブを選択
  3. 左メニューの中から「Storage > Local Storage」を選択

4-2. 基本操作

【LocalStorageを書き込む】
save.addEventListener('click', () => {
  localStorage.setItem('text', 'localStorage');
});

//以下の記述方法でもOK
localStorage.キー = 値
localStorage['キー'] = 値
【LocalStorageを取得する】
get.addEventListener('click', () => {
  alert(localStorage.getItem('text'));
});

//以下の記述方法でもOK
localStorage.キー
localStorage['キー']

※Cookieと違って、値のみが取得できるので便利。

【LocalStorageを削除する】
del.addEventListener('click', () => {
  localStorage.removeItem('text');

  //データをすべて削除する場合
  localStorage.clear();
});

☆練習

  1. エンコード処理を施す。
  2. オブジェクト形式で受け渡ししてみる。
  3. エラー処理を施す。

  age: 42
