1. 時事問題

  • Q1. 5月2日、韓国の国会議員が、日本固有の領土である島根の（竹島）に上陸したことが判明した。
  • Q2. 5月3日は「憲法記念日」の祝日であるが、日本国憲法が施行されてから今年2023年で76年経過したことになる。
  • Q3. 5月17日、公正取引委員会は、10月から始まる消費税の（インボイス）制度について、発注事業者が取引先に対して消費税分を差し引いた価格で納めるよう求めた事例があったと発表した。
  • Q4. 5月23日、岸田文雄首相が掲げる異次元の（少子化）対策を巡り、新たに18歳まで月1万円を支給する方向で調整に入った。
  • Q5. 5月24日、ホンダの目指す（カーボン）ニュートラル（※脱炭素）の方向性と合致するとして、F1に復帰することを発表した。

2. 敬語用語

  • ⑥ 相手の会社（話し言葉） → 御社
  • ⑦ 相手の会社（書き言葉） → 貴社
  • ⑧ どうもすみません → 失礼いたしました、申し訳ありませんでした
  • ⑨ わかりました → かしこまりました、承知いたしました
  • ⑩ 知っています → 存じております
  • ⑪ 今から行きます → 今からお伺いします
  • ⑫ あの人を知っていますか？ → あの方をご存じですか？
  • ⑬ 誰ですか？ → どちら様でしょうか？
  • ⑭ 何の用ですか？ → どのようなご用件でしょうか？
  • ⑮ ○○は席におりません → ○○はただいま席をはずしております
