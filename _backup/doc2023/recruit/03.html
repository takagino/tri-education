2. 敬語

  • Q6. もしもし、○○社です → はい、○○社でございます※「もしもし」を使わない
  • Q7. 誰ですか？ → どちら様でしょうか？
  • Q8. 何の用ですか？ → どのようなご用件でしょうか？※「何の」を使わない
  • Q9. ○○に代わります → ○○におつなぎします※「代わる」を使わない
  • Q10. ○○は電話中です → ○○はただいま別の電話に出ております
  • Q11. ○○は席におりません → ○○はただいま席をはずしております
  • Q12. 繰り返します → 復唱させていただきます ※「繰り返し申し上げます」は自分が言ったことを繰り返すこと
  • Q13. 声が小さいですが → お電話が遠いようですが※「声が小さい」と直接的な表現を避ける
  • Q14. また後でかけます → 後ほどおかけ直しいたします※「後で」を使わない
  • Q15. 佐藤部長に伝えます → 部長の佐藤に申し伝えます※「佐藤部長」はNG
