## 1-1. `settings.json` のおすすめ設定

VSCodeの設定画面（GUI）から1つずつ探すのではなく、設定ファイル（`settings.json`）に直接貼り付けるのが一番確実で早いです。

### `settings.json` の開き方
1. **コマンドパレットを開く**:
   - Mac: `Cmd + Shift + P`
   - Win: `Ctrl + Shift + P`
2. 検索バーに **`Preferences: Open User Settings (JSON)`**（または「基本設定: ユーザー設定 (JSON) を開く」）と入力してEnterを押す。
3. 開いた `{ ... }` の中に、以下の設定を追加（または既存の内容と統合）して保存（`Cmd + S` / `Ctrl + S`）してください。

```json
{
  // --- 1. 自動フォーマット & インデント設定 ---
  // 保存時に自動でインデントやスタイルを綺麗に整形
  "editor.formatOnSave": true,
  // Web標準のインデント幅（半角スペース2文字）
  "editor.tabSize": 2,
  // HTML標準フォーマッターでタグや属性が勝手に途中改行されるのを防止
  "html.format.wrapLineLength": 0,
  // <head> や <body> の前後に勝手に挿入される空行を削除
  "html.format.extraLiners": "",

  // --- 2. Emmet & 入力の爆速化 ---
  // ! で展開される HTML の言語を ja に変更（毎回 en から直す手間をゼロに）
  "emmet.variables": {
    "lang": "ja"
  },
  // Emmetなどのスニペット候補を最優先で一番上に表示
  "editor.snippetSuggestions": "top",
  // 開始タグを変更すると終了タグも連動して自動変更（超便利！）
  "editor.linkedEditing": true,

  // --- 3. 画面の作業領域 & 誤操作防止（事故防止） ---
  // 画面端で長いコードを自動折り返し（横スクロール防止）
  "editor.wordWrap": "on",
  // 画面右側のミニマップを非表示にしてコード領域を広く確保
  "editor.minimap.enabled": false,
  // テキストの意図しないドラッグ＆ドロップ移動を禁止（コード破壊防止）
  "editor.dragAndDrop": false,
  // ファイルをクリックした際にタブを固定表示（前のファイルが消えたと錯覚するのを防止）
  "workbench.editor.enablePreview": false,
  // フォルダの中に1つしかディレクトリがない場合でも省略表示にしない（階層の誤認防止）
  "explorer.compactFolders": false,

  // --- 4. 空白の可視化 & Git作法 ---
  // 半角スペースや全角スペースを可視化（レイアウト崩れのバグ防止）
  "editor.renderWhitespace": "boundary",
  // ファイル保存時に必ず末尾に改行を1行挿入（Gitの差分警告防止作法）
  "files.insertFinalNewline": true,
  // ファイル保存時に行末の不要な空白を自動削除
  "files.trimTrailingWhitespace": true,
  // エクスプローラーから不要なファイル（Sassの.mapやMacの.DS_Store）を隠す
  "files.exclude": {
    "**/*.map": true,
    "**/.DS_Store": true
  }
}
```

<aside>
💡 **ここがポイント！**
- **`emmet.variables: { "lang": "ja" }`**: これを設定しておくと、新規HTMLで `!` → `Tab`（または `Enter`）を押した瞬間に `<html lang="ja">` で生成されます。
- **`editor.linkedEditing: true`**: `<div>...</div>` の `div` を `section` に書き換えると、閉じタグの `</div>` も一瞬で `</section>` に連動します。
- **`editor.dragAndDrop: false`**: 初心者にありがちな「選択したコードが意図せずズレて別の場所に紛れ込む事故」を完全に防ぎます。
</aside>

## 1-2. コーディング速度が劇的に上がる便利なショートカット

マウスに持ち替える回数を減らし、キーボードだけでコードを組み替える厳選ショートカットです。今日の演習から早速使ってみましょう！

| 操作 | Mac | Windows | 解説 |
|---|---|---|---|
| **行の複製** | `Option + Shift + ↓` | `Alt + Shift + ↓` | カーソルがある行（または選択行）を真下に一瞬で複製。リストやカードの量産に必須！ |
| **行の移動** | `Option + ↑ / ↓` | `Alt + ↑ / ↓` | 切り取り＆貼り付け不要！行をそのまま上下にスイスイ移動できます。 |
| **マルチカーソル（同じ単語を選択）** | `Cmd + D` | `Ctrl + D` | 選択中の単語と同じ単語を1つずつ追加選択。クラス名やタグ名の一括変更に超便利。 |
| **コメントアウト切り替え** | `Cmd + /` | `Ctrl + /` | カーソル行や選択した複数行を瞬時にコメント化・解除します。 |
| **ファイル検索（クイックオープン）** | `Cmd + P` | `Ctrl + P` | エクスプローラーから探さず、ファイル名（例: `style.css`）を入力して一発で開けます。 |
| **コマンドパレット** | `Cmd + Shift + P` | `Ctrl + Shift + P` | すべての機能や設定を呼び出せるVSCodeの司令塔。 |

# 3. GitHub PagesでのWebサイト公開

マークアップが完了（またはキリの良いところまで進んだ）したら、GitHubリポジトリにプッシュし、世界中にWebサイトとしてプレビュー公開します。

### 公開手順
1. VSCodeのソース管理（またはターミナル）から、変更をコミットしてGitHubへプッシュします。
2. ブラウザで自分のGitHubリポジトリのページを開きます。
3. 上部メニューの **`Settings`**（歯車アイコン）をクリックします。
4. 左サイドバーの **`Pages`** をクリックします。
5. **`Build and deployment`** の `Branch` 項目で、以下を選択して **`Save`** を押します：
   - ブランチ: **`main`**（または `master`）
   - フォルダ: **`/ (root)`**
6. 1〜2分待ってページをリロードすると、上部に **`Your site is live at https://...`** と公開URLが表示されます。
7. 公開されたURLにスマートフォンやPCからアクセスし、表示崩れがないか確認しましょう。
