**【さらに追加すべき項目】**

```json
"html.format.wrapLineLength": 0, // HTML標準フォーマッターでタグや属性が勝手に途中改行されるのを防止
```

## 2-2. プログラミング用フォントの導入

コードの視認性を高め、タイポ（打ち間違い）や構文エラーを未然に防ぐプログラミング専用フォント「Cica（シカ）」の導入をおすすめします。

**【Cicaをおすすめする理由】**

- **似た文字の誤読防止：** `0`（数字ゼロ）と `O`（大文字オー）、`1`（数字イチ）と `l`（小文字エル）や `I`（大文字アイ）が一目で区別できる。
- **BEM記法のミス防止：** `--`（ハイフン2つ）や `__`（アンダースコア2つ）が勝手に合体（リガチャ）せず、はっきり2つ並んで見える。
- **インデント・全角スペースの整列：**半角と全角（日本語）の幅がぴったり「1:2」で揃い、インデントのズレや全角スペースの混入にすぐ気づける。
- **商用フリー & 無料：**個人利用・商用利用ともに完全無料で利用可能。

![font-Cica.png](01_%E7%92%B0%E5%A2%83%E8%A8%AD%E5%AE%9A%E3%81%A8%E7%A2%BA%E8%AA%8D%E8%AA%B2%E9%A1%8C/font-Cica.png)

**【インストール方法】**

ターミナルで以下のコマンドを実行するだけで完了します。

```bash
brew install --cask font-cica
```

**【VSCode（`settings.json`）への設定】**

フォントをPCにインストールしたら、`settings.json` に以下を追記して保存します。

```json
"editor.fontFamily": "Cica, Consolas, Monaco, monospace",
"editor.fontSize": 14, // フォントサイズ（読みやすい大きさに微調整）
```

※ その他のフォントを知りたい人は「プログラミング用フォント 2026」で検索。

## 2-3. 便利なショートカット

[VSCodeショートカット一覧｜Win/Mac対応130項目とAI操作・変更方法 - 株式会社RJC](https://www.r-jc.jp/news-blog/1278/vscode%E3%82%B7%E3%83%A7%E3%83%BC%E3%83%88%E3%82%AB%E3%83%83%E3%83%88%E4%B8%80%E8%A6%A7win-mac%E5%AF%BE%E5%BF%9C130%E9%A0%85%E7%9B%AE%E3%81%A8ai%E6%93%8D%E4%BD%9C%E5%A4%89%E6%9B%B4%E6%96%B9%E6%B3%95/)

**【特に便利なショートカット】**

マウスに持ち替える回数を減らし、キーボードだけでコードを組み替える厳選ショートカットです。今日の演習から早速使ってみましょう。

| 操作 | Mac | Windows | 解説 |
| --- | --- | --- | --- |
| **行の先頭 / 末尾へ** | **`Command + ← / →`** | **`Home / End`** | 行の先頭や末尾へ一瞬でカーソルをジャンプ移動できます。 |
| **ファイルの先頭 / 末尾へ** | **`Command + ↑ / ↓`** | **`Ctrl + Home / End`** | 長いコードでも一瞬で最上部・最下部へ移動できます。 |
| **下に空行を挿入** | **`Command + Enter`** | **`Ctrl + Enter`** | 行の途中にカーソルがあっても、コードを改行で崩さずに下の新しい行へ移動できます。 |
| **上に空行を挿入** | **`Shift + Command + Enter`** | **`Shift + Ctrl + Enter`** | カーソルがある行の上に新しい空行を挿入し、すぐに上の行で入力できます。 |
| **行の移動** | **`Option + ↑ / ↓`** | **`Alt + ↑ / ↓`** | 切り取り＆貼り付け不要。行をそのまま上下にスイスイ移動できます。 |
| **行の複製** | **`Option + Shift + ↓`** | **`Alt + Shift + ↓`** | カーソルがある行（または選択行）を真下に一瞬で複製。リストやカードの量産に必須。 |
| **コピー（選択なしなら行ごと）** | **`Command + C`** | **`Ctrl + C`** | 範囲選択していなくても、カーソルがある行全体をそのままコピーできます。 |
| **切り取り（選択なしなら行ごと）** | **`Command + X`** | **`Ctrl + X`** | 範囲選択していなくても、カーソルがある行全体を一瞬で切り取れます。 |
| **マルチカーソル（同じ単語を選択）** | **`Command + D`** | **`Ctrl + D`** | 選択中の単語と同じ単語を1つずつ追加選択。クラス名やタグ名の一括変更に便利。 |
| **上にカーソルを追加** | **`Option + Command + ↑`** | **`Ctrl + Alt + ↑`** | 上の行にもカーソルを追加して、複数行を同時に編集できます。 |
| **下にカーソルを追加** | **`Option + Command + ↓`** | **`Ctrl + Alt + ↓`** | 下の行にもカーソルを追加して、複数行を同時に編集できます。 |
| **コメントアウト切り替え** | **`Command + /`** | **`Ctrl + /`** | カーソル行や選択した複数行を瞬時にコメント化・解除します。 |
| **検索** | **`Command + F`** | **`Ctrl + F`** | ファイル内のキーワードを素早く検索・確認できます。 |
| **ファイル検索（クイックオープン）** | **`Command + P`** | **`Ctrl + P`** | エクスプローラーから探さず、ファイル名（例: `style.css`）を入力して一発で開けます。 |
| **最近開いたフォルダ** | **`Ctrl + R`** | **`Ctrl + R`** | 最近開いたプロジェクトやフォルダの一覧を開き、素早く切り替えられます。 |
| **コマンドパレット** | **`Command + Shift + P`** | **`Ctrl + Shift + P`** | すべての機能や設定を呼び出せます。 |

# 3. GitHub PagesでのWebサイト公開

マークアップが完了（またはキリの良いところまで進んだ）したら、GitHubリポジトリにプッシュし、世界中にWebサイトとしてプレビュー公開します。

**【公開手順】**

1. VSCodeのソース管理から、変更をコミットしてGitHubへプッシュします。
2. ブラウザで自分のGitHubリポジトリのページを開きます。
3. 上部メニューの **`Settings`**（歯車アイコン）をクリックします。
4. 左サイドバーの **`Pages`** をクリックします。
5. **`Build and deployment`** の **`Branch`** 項目で、以下を選択して **`Save`** を押します：
    - ブランチ： **`main`**
    - フォルダ： **`/ (root)`**
6. 1〜2分待ってページをリロードすると、上部に **`Your site is live at https://...`** と公開URLが表示されます。
7. 公開されたURLにスマートフォンやPCからアクセスし、表示崩れがないか確認しましょう。
