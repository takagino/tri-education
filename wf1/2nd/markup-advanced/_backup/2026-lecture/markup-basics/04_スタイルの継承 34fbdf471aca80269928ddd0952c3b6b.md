# **3. スタイルの継承**

前回マークアップしたCSSには、以下のように重複するプロパティの指定が多々あった。

```css
h2 {
  margin: 80px 0 40px;
  font-size: 48px;
  font-weight: normal;
  /* 重複 */
  color: #000000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0.1em;
  text-align: center;
}

p {
  /* 重複 */
  font-size: 16px;
  color: #000000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0;
}

li {
  margin-bottom: 30px;
  padding-bottom: 30px;
  border-bottom: 1px solid #ddd;
  /* 重複 */
  font-size: 16px;
  color: #000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0;
}
```

このような場合、「スタイルの継承」の仕組みを使うと、よりすっきりと書くことができる。

**【スタイルの継承とは？】**

要素に指定したCSSプロパティの値が、内包されている要素に引き継がれること。プロパティによって継承されるものとされないものに分かれる。

---

## **3-1. 継承される主なプロパティ**

- color
- font-size
- font-style
- font-weight
- letter-spacing
- line-height
- list-style
- text-align　など

**【修正例】**

```css
/* 修正前 */
h2 {
  margin: 80px 0 40px;
  font-size: 48px;
  font-weight: normal;
  /* 重複 */
  color: #000000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0.1em;
  text-align: center;
}

p {
  /* 重複 */
  font-size: 16px;
  color: #000000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0;
}

li {
  margin-bottom: 30px;
  padding-bottom: 30px;
  border-bottom: 1px solid #ddd;
  /* 重複 */
  font-size: 16px;
  color: #000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0;
}

　↓

/* 修正後 */
body{
  font-size: 16px;
  color: #000000;
  font-family: 'Times New Roman', Times, serif;
  line-height: 1.5;
  letter-spacing: 0;
}

h2 {
  margin: 80px 0 40px;
  font-size: 48px;
  font-weight: normal;
  letter-spacing: 0.1em;
  text-align: center;
}

li {
  margin-bottom: 30px;
  padding-bottom: 30px;
  border-bottom: 1px solid #ddd;
}
```

<aside>
💡

CSSを書くときにまずやることは、**「body要素」に共通のプロパティを指定して、一番多いであろうテキストの値に合わせておく**こと！

</aside>

## **3-2. マークアップの手順（高木の場合）**

1. デザインデータを眺めて、マークアップの計画を立てる。
    - 全体の構成は？
    - 見出しの付け方は？
    - 画像になる部分はどこか？
    - リンクになる部分はどこか？
    - **body要素に書くべき共通のプロパティは何か？**
    
2. body要素に共通のプロパティを設定する。
    
    ```css
    body {
      margin: 0;
      background: #F2F2F2;
      color: #151D41;
      font-family: Helvetica, Arial, sans-serif;
      font-size: 16px;
      line-height: 2;
      letter-spacing: 0;
      text-align: center;
    }
    ```
    
3. レイアウト崩れが起きないように、大きなところからマークアップしていく。
    
    ```css
    .wrapper{
      width: 700px;
      margin-left: auto;
      margin-right: auto;
    }
    ```
    

**【意識すべきこと】**

- わかりやすいクラス名をつける。
- 必要な箇所だけに「div要素」を使用する。
- 必要な箇所だけに「class名」を使用する。（とりあえず前期中は）
- cssを書く順番、プロパティを書く順番に、自分なりのルールを設ける。
- marginとpaddingの判断基準を持つ。
- 後から出てくる「子孫セレクタ」を深くしすぎない。（2,3個まで）
- こまめに保存、こまめに確認。
- おかしいなと思ったらchromeディベロッパーツールでcssをチェック。

# **5. 要素の親子関係**

HTMLの要素は、ある要素がある要素を含み、さらにその要素が別の要素を含む、というように階層的な構造であらわされ、この関係は一般的に親要素、子要素、孫要素などと、親子関係にたとえられて表現される。

![tree.png](04_%E3%82%B9%E3%82%BF%E3%82%A4%E3%83%AB%E3%81%AE%E7%B6%99%E6%89%BF/tree.png)

- 「li要素」の親要素は「ul要素」（「li要素」は「ul要素」の子要素であり、「body要素」の孫要素でもある）
- 「ul要素」の親要素は「body要素」
- 「body要素」の親要素は「html要素」
- 「html要素」の親要素は無い、強いて言えば「ブラウザそのもの」

---

# **6. 子孫セレクタ**

「dt要素」にCSSを適応する際、

```css
dt{
  font-size: 24px;
  font-weight: bold;
}
```

のように要素自体に適応しても良いが、今後デザイン変更などでページ内に「dt要素」が増えた時に面倒臭い。

今回は「**子孫セレクタ**」を使って書いてみる。

```css
.info dt{
  font-size: 24px;
  font-weight: bold;
}
```

# 7. **marginの相殺**

マージンの相殺は、垂直マージン（上下のマージン）を指定した2つの要素が並んだ時に起こる。

マージンの相殺が起こると、**2つのマージンのうち大きい方（等しい場合はいずれか）**が1つのマージンとしてみなされる。

以下3つのケースを、完成版をディベロパーツールで検証し実際に確認してみる。
