# **3. 便利なセレクタの書き方**

これまで要素名（`p`）やクラス名（`.hoge`）でスタイルを当ててきましたが、書き方を工夫することで「特定の場所にある要素」だけをピンポイントで狙い撃ちすることができます。

![css02.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/css02.png)

---

## **3-1. 基本的なセレクタ**

**【要素セレクタ】**

```css
p {
  color: #f00;
}
```

**【クラスセレクタ】**

```css
p.hoge {
  color: #f00;
}

.hoge{
  color: #f00;
}
```

**【idセレクタ】**

```css
/* 普段のマークアップではあまり使わない */

p#hoge {
  color: #f00;
}

#hoge{
  color: #f00;
}
```

**【ユニバーサルセレクタ】**

```css
/* すべての要素を指定（動作が重いので基本的には使わない） */

*{
  color: #f00;
}

/* リセットCSSには指定されている */

*{
  box-sizing: border-box;
}
```

---

## **3-2. 複数のセレクタ・クラス**

**【セレクタのグループ化】**

```css
/* カンマで区切ることで、複数の要素に「同時に同じスタイル」を指定できる */

h1, h2, h3 {
  color: #f00;
}
```

**【複数のクラス】**

```css
/* 「.hoge」と「.fuga」の両方のクラスを持っている要素だけを指定する */

.hoge.fuga {
  color: #f00;
}
```

---

## **3-2. 階層を使ったセレクタ**

**【子孫セレクタ（スペース区切り）】※一番よく使います！**

```css
/* 「.hoge」の中にある「p」だけを選択（間に別の要素が挟まっていてもOK） */

.hoge p {
  color: #f00;
}
```

**【子セレクタ（`>` 区切り）】**

```css
/* 「.hoge」の "直下" にある「p」だけを選択 */

.hoge > p {
  color: #f00;
}
```

```markup
<div class="hoge">
  <p>直下にあるので適用される</p>
  <div class="fuga">
    <p>直下ではない（他のdivを挟んでいる）ので適用されない</p>
  </div>
</div>
```

**【隣接兄弟セレクタ（`+` 区切り）】**

```css
/* 同じ親要素内の隣接する要素だけを選択 */

h1 + p {
  color: #f00;
}
```

```markup
<div class="hoge">
	<h1>見出し</h1>
	<p>h1に隣接しているので適応される</p>
	<p>h1に隣接していない（pには隣接している）ので適応されない</p>
</div>
```

# **4. 擬似クラス（状態や順番を指定する）**

要素に対して「マウスが乗った時」や「○番目の要素」といった**特定の状態**を指定するキーワードです。

セレクタの後に **コロン1つ（`:`）** をつけて書きます。

[擬似クラス - CSS | MDN](https://developer.mozilla.org/ja/docs/Web/CSS/Reference/Selectors/Pseudo-classes)

---

## **4-1. ユーザー操作擬似クラス**

**【マウスポインタが上に乗った時】**

```css
a:hover {
  color: #f00;
  opacity: 0.7; /* 少し透かす演出がよく使われます */
}
```

---

## **4-2. 順番を指定する擬似クラス**

リストの最初だけ線を消したり、交互に色を変えたりする時によく使います。

**【兄弟要素のうち、最初の要素 / 最後の要素】**

```css
li:first-child {
  color: #f00;
}
li:last-child {
  color: #00f;
}
```

**【兄弟要素のうち、n番目の要素を選択】**

```css
/* 上から2番目を選択 */
li:nth-child(2) {
  color: #f00;
}

/* 奇数（1, 3, 5...）を選択 */
li:nth-child(odd) {
  background-color: #eee;
}

/* 偶数（2, 4, 6...）を選択 */
li:nth-child(even) {
  background-color: #ddd;
}
```

<aside>
💡

**`nth-child` の罠と `nth-of-type` の使い分け**

実は `nth-child(2)` は、「上から2番目が『li』だった時」にしか効きません。
もしリストの最初に「見出し（`h2`）」などが混ざっていた場合、見出しが1番目とカウントされ、意図した通りの順番になりません。

このようなバグを防ぐため、実務では「要素の種類も限定して数える」ことができる **`nth-of-type`** を使うのが王道です。

```css
/* h2が混ざっていても、純粋に「liの2番目」を選択してくれる安全な書き方！ */
li:nth-of-type(2) {
  color: #f00;
}
```

</aside>

# **5. 擬似要素（HTMLにない要素を作り出す）**

選択した要素の一部に装飾を加えたり、HTMLには存在しないパーツをCSSだけで作り出すことができる機能です。

CSS3からは、擬似クラスと区別するために **コロン2つ（`::`）** をつけて書くのがルールになりました。

[擬似要素 - CSS | MDN](https://developer.mozilla.org/ja/docs/Web/CSS/Reference/Selectors/Pseudo-elements)

**【テキストの一部を選択する】**

```css
/* 最初の文字だけを大きくする（ドロップキャップス） */
p::first-letter {
  font-size: 2em;
  color: #f00;
}

/* マウスでドラッグしてテキストを選択した際の色を変える */
::selection {
  background-color: #f00;
  color: #fff;
}
```

---

## **5-1. 「`::before`」と「`::after`」**

要素の「直前（before）」や「直後（after）」に、CSSだけで新しい疑似的な要素（パーツ）を作り出します。これを使えば、HTMLを汚すことなく様々な装飾が作れます。

```css
p::before {
  content: "★ ";
  color: #f00;
}
```

**【`before` と `after` を使う時の2つのルール】**

1. **`content` プロパティが必ずに必要：**
    
    文字や記号を入れる場合は `content: "NEW";` のように書きます。もし文字が不要で「ただの図形や線」を作りたい場合でも、**`content: "";` （空っぽ）** と必ず書かないと、要素自体が出現しません。
    
2. **最初は「インライン要素」になっている：**
    
    作り出された要素は文字と同じ扱い（インライン）なので、幅（width）や高さ（height）を指定しても効きません。図形を作りたい時は **`display: block;`** や **`display: inline-block;`** を追加してあげましょう。
    

---

## **5-2. 「before」「after」の実践的な使い所**

**【使い所1】文章を記号で囲む**

HTMLに直接カギカッコを書かずに、CSSで自動的に付与します。

![01.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/01.png)

```markup
<p class="text">テキストテキスト</p>

<style>
.text::before {
  content: "『";
  color: #23cb99;
}
.text::after {
  content: "』";
  color: #23cb99;
}
</style>
```

**【使い所2】見出しに英字（サブタイトル）を配置する**

![02.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/02.png)

```markup
<section class="news">
  <h2>お知らせ</h2>
</section>

<style>
.news h2::before {
  content: "NEWS";
  display: block; /* ブロック要素にして上に配置 */
  margin-bottom: 15px;
  font-size: 18px;
  font-weight: normal;
  text-align: center;
}
</style>
```

**【使い所3】見出しの下に短い装飾線を配置する**

![03.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/03.png)

ボーダー（`border-bottom`）だとテキストと同じ幅になってしまいますが、疑似要素で線を作れば、短くてオシャレな装飾線が作れます。

```css
<section class="news">
  <h2>お知らせ</h2>
</section>

<style>
h2::after {
  content: ""; /* 文字は不要なので空っぽ */
  display: block;
  width: 100px; /* 線の長さを自由に決められる！ */
  margin: 25px auto 0;
  border-top: 2px solid #E40065;
}
</style>
```

**【使い所4】アイコンやバッジを配置する（`position` との組み合わせ）**

![04.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/04.png)

前回学んだ「親に `relative`、子に `absolute`」のテクニックを疑似要素に応用します。HTMLを増やさずにバッジが付けられるプロの技です。

```markup
<!-- クラス「new」がついている要素にだけバッジを出す -->
<div class="works-pic new">
  <img src="./images/pic_works01.png" alt="">
</div>

<style>
.works-pic {
  position: relative; /* 基準点にする！ */
}

.new::after {
  content: "NEW";
  position: absolute; /* 基準点から自由に配置する！ */
  left: 15px;
  bottom: 15px;
  display: inline-block;
  padding: 5px 15px;
  border-radius: 20px;
  background-color: #E40065;
  color: #fff;
  font-size: 12px;
  font-weight: bold;
}
</style>
```

**【使い所5】吹き出しの「しっぽ」を作る**

![05.png](12_%E6%93%AC%E4%BC%BC%E3%82%AF%E3%83%A9%E3%82%B9%E3%83%BB%E6%93%AC%E4%BC%BC%E8%A6%81%E7%B4%A0/05.png)

少し難易度が高いですが、CSSのボーダーの重なりを利用して「三角形」を作るテクニックと疑似要素を組み合わせると、きれいな吹き出しが作れます。

```markup
<div class="voice-text">
  <p>今回参加したメンバーの大半は・・・</p>
</div>

<style>
.voice-text {
  position: relative;
}

.voice-text::after {
  content: "";
  position: absolute;
  top: 50%;
  left: -30px;
  border: 15px solid transparent; /* transparent(透明) */
  border-right: 15px solid #f7f7f7;
}
</style>
```
