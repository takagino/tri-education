# 2. HTMLとは？

## 2-1. HyperText Markup Language

**【HyperText（ハイパーテキスト）】**

複数の文書を相互に関連付け、結び付ける仕組みのこと。「テキストを超える」という意味から「hyper-（～を超えた）」 「text（文書）」と名付けられた。

テキスト間を結びつける参照のことを***「*ハイパーリンク（略してリンク）*」***と呼ぶ。

![hypertext.png](01_HTML%E3%81%A8%E3%81%AF%EF%BC%9F/hypertext.png)

すなわち、

> **リンクを介して行き来できるすごいテキスト（書類）**
> 

**【Markup（マークアップ）】**

文章の中に**目印（マーク）**を付けていくこと。

元々の語源は、英語圏の出版業界で著者、編集者、印刷者の間で指示を伝える方法を意味する。（校閲／こうえつ）

![kosei_example.webp](01_HTML%E3%81%A8%E3%81%AF%EF%BC%9F/kosei_example.webp)

**【Language（ランゲージ）】**

言語。

まとめると、HTMLとは、

> **リンクを介して行き来できるすごいテキスト（書類）に目印を付けるための言語**
>

## **2-2. 何のための目印？**

「何のため？」を知るには、**それが出来た歴史（背景）**を知るべし！

**【WWW（World Wide Web）システムの発明】**

1989年、欧州原子核研究機構 (CERN) の **ティム・バーナーズ＝リー** は、「Information Management: A Proposal」（情報管理: 提案）を執筆。

「研究状況の確認、論文の資料検索など、数千人にのぼる研究者に必要な情報を効率よく行き渡らせる環境を構築するためのシステム」を考案した。

![Sir_Tim_Berners-Lee_(cropped).jpg](01_HTML%E3%81%A8%E3%81%AF%EF%BC%9F/Sir_Tim_Berners-Lee_(cropped).jpg)

**【WWWシステムの実装と公開】**

1990年、WWWをより具体化した提案書「WorldWideWeb: Proposal for a HyperText Project」を発表。

HTTP、URL、HTMLなど基幹となる仕組みや、ブラウザ、サーバなどのツールも構築し、人類初のウェブページが公開された。

**【W3C（World Wide Web Consortium）の設立】**

1994年、WWWで使用される各種技術の標準化を推進する為に設立された非営利団体。ティム・バーナーズ＝リーが創設し、率いている。

[World Wide Web Consortium](https://ja.wikipedia.org/wiki/World_Wide_Web_Consortium#%E4%B8%BB%E3%81%AA%E8%A6%8F%E6%A0%BC)

## **2-3. インターネットとは？**

インターネットとは、インターネット・プロトコル(IP)技術を利用して相互接続されたコンピュータネットワーク全体を指し、WWWはその一部の機能でしかない。

**【インターネットに含まれる主な技術】**

- telnet
- 電子メール (SMTP)
- ファイル転送 (FTP)
- チャット (IRC)
- ネットニュース (NNTP)
- WWW (HTTP)

## **3-5. 目印をつけてみる**

1. それぞれのテキストを目印で囲む。
    
    ```html
    <h1>高木寛貴</h1>
    <ul>
    <li>1981年1月15日</li>
    <li>岐阜県</li>
    <li>B型</li>
    </ul>
    ```
    
2. 保存する。（ショートカット『`command + s`』）
3. ブラウザを更新する。（ショートカット『`command + r`』）

マークアップとは、

> **効率よく情報を収集・閲覧するため、文字や文章に目印をつけて、コンピュータが構造や意味を理解できるようにすること**
> 

**【目印の正式名称】**

![element.png](01_HTML%E3%81%A8%E3%81%AF%EF%BC%9F/element.png)

- テキストにつけた目印のことを「**タグ（tag）**」と呼ぶ。
- 先頭のタグを「**開始タグ**」、末尾のタグを「**終了タグ**」と呼ぶ。
- タグで囲ったテキスト全体を「**要素（element）**」と呼ぶ。
- h1のタグを「**h1タグ**」、h1で囲った要素を「**h1要素**」と呼ぶ。

**【タグのルール】**

- タグの途中でスペース・改行を入れない。
- 大文字小文字は区別されないが、基本的にはすべて小文字。

# **4. HTMLの基本構造**

```html
<html>
  <head>
  </head>
  <body>
    <h1>高木寛貴</h1>
    <ul>
      <li>1981年1月15日</li>
      <li>岐阜県</li>
      <li>B型</li>
    </ul>
  </body>
</html>
```

| 要素 | 役割 |
| --- | --- |
| **html要素** | HTML文書の始まりと終わりを指定する。決まり文句のようなもので、全てのHTML文書はhtml要素で囲われている。 |
| **head要素** | 文書に関する機械可読な情報 （**メタデータ**）を記述する。題名や制作者名などを記述し、Webブラウザに直接は表示されない。 |
| **body要素** | HTML文書の内容を記述する。ここに記述した部分がWebブラウザに表示される。 |

---

## **4-1. 最低限のメタデータ**

```html
<html>
  <head>
    <meta charset="UTF-8">
    <title>文書のタイトル</title>
  </head>
  <body>
    <h1>高木寛貴</h1>
    <ul>
      <li>1981年1月15日</li>
      <li>岐阜県</li>
      <li>B型</li>
    </ul>
  </body>
</html>
```

**【文字コード】**

`<meta charset="UTF-8">`

文字化けを防ぐため、head要素の上の方（文章が記述される前）に記述する。

**【title要素】**

ウェブページのタイトルを記述する。ブラウザのタブや、検索結果に表示される。

## **4-2. DOCTYPE宣言**

HTMLは常にバージョンアップを繰り返しており、かつては「HTML5」というバージョンが主流でしたが、現在はバージョン番号を廃止し、常に最新の状態にアップデートされ続ける「**HTML Living Standard**」という規格が世界標準となっている。

バージョンによって多少の違いがあるため、そのファイルがどのバージョンで書かれているかを最初に宣言する必要がある。

```html
<!doctype html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>文書のタイトル</title>
  </head>
  <body>
    <h1>高木寛貴</h1>
    <ul>
      <li>1981年1月15日</li>
      <li>岐阜県</li>
      <li>B型</li>
    </ul>
  </body>
</html>
```

**【過去バージョンの書き方】**

[文書型宣言](https://ja.wikipedia.org/wiki/%E6%96%87%E6%9B%B8%E5%9E%8B%E5%AE%A3%E8%A8%80)

# **5. その他の要素と属性**

```html
<h1>高木寛貴</h1>
<p>優しくて<br>力持ち</p>
<h2>基本情報</h2>
<ul>
  <li>1981年1月15日</li>
  <li><a href="https://www.pref.gifu.lg.jp/">岐阜県</a></li>
  <li><img src="https://www.motivation-up.com/whats/images/type_b.gif"></li>
</ul>
```

| タグ | 由来（元の英単語） | 役割 |
| --- | --- | --- |
| br | break | 文章を改行する。改行については、ここからここまでという範囲は無いので、終了タグが存在しない。このようなタグを「**空タグ**」という。 |
| a | **anchor** | ハイパーリンクを設定する。「**href（hypertext reference）属性**」でリンク先を指定する必要がある。 |
| img | **image** | 画像を表示する。「**src（source）属性**」で画像ファイルの場所を指定する必要がある。
範囲は無いので「**空タグ**」。 |

---

## **5-1. 属性とは？**

![attribute.png](01_HTML%E3%81%A8%E3%81%AF%EF%BC%9F/attribute.png)

- 要素に設定を付加するもの。
- 開始タグに**半角スペース**を空け、「**属性名**」と「**属性値**」を「=（イコール）」でつないだセットで追加していく。
- 「属性値」は「**"（ダブルクォーテーション）**」もしくは「**'（シングルクォーテーション）**」で囲む。
- 複数指定する場合は、さらに半角スペースを空け追加していく。
- 要素ごとに付加できる属性は決められているため、まずは主要なものを覚える。
- 属性は英語で「**attribute**」。

**【a要素に設定できる属性】**
