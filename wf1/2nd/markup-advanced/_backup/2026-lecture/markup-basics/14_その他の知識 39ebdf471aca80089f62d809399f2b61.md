# 9. カテゴリとコンテンツモデル

**【カテゴリとは】**

カテゴリとは、各要素を類似の特性を持つもの同士で分類したものを指す。HTML4.01までは、ブロックレベル要素かインライン要素かそれ以外かというシンプルな分類だったが、HTML5では要素の役割に応じて7つに分類されている。

1. メタデータ・コンテンツ（Metadata content）
    - **役割：** ブラウザや検索エンジンに向けて、文書の情報や設定を伝えるグループ。
    - **特徴：** 基本的に画面（ブラウザ）には直接表示されません。
    - **代表的なタグ：** `<title>`, `<meta>`, `<link>`, `<style>`, `<script>` など（主に `<head>` の中に入るもの）。
    
2. フロー・コンテンツ（Flow content）
    - **役割：** Webページの中に表示される、文字通り「文書の流れ」を作るグループ。
    - **特徴：** `<body>` タグの中に入れることができる**ほぼすべての要素**がこれに属します。一番巨大なグループです。
    
3. セクショニング・コンテンツ（Sectioning content）
    - **役割：** ページのアウトライン（章立て・階層構造）を作るグループ。
    - **特徴：** このタグで囲んだ範囲が、一つの「意味のまとまり（セクション）」になります。
    - **代表的なタグ：** `<section>`, `<article>`, `<aside>`, `<nav>` の4つのみ。
    
4. ヘッディング・コンテンツ（Heading content）
    - **役割：** 各セクションの「見出し」となるグループ。
    - **特徴：** セクショニング・コンテンツとセットで使われ、アウトラインのタイトルになります。
    - **代表的なタグ：** `<h1>` 〜 `<h6>`
    
5. フレージング・コンテンツ（Phrasing content）
    - **役割：** 文章（テキスト）と、その中の一部分をマークアップするグループ。
    - **特徴：** 一昔前の「インライン要素」に一番近いイメージです。段落の中のテキストを装飾したり、リンクにしたりします。
    - **代表的なタグ：** `<span>`, `<a>`, `<img>`, `<strong>`, `<em>`, `br` など。
    
6. エンベッディッド・コンテンツ（Embedded content）
    - **役割：** 外部のリソース（画像、音声、動画、他のWebページなど）を埋め込むグループ。
    - **特徴：** HTML以外の別のファイルやデータを呼び出して表示します。
    - **代表的なタグ：** `<img>`, `<video>`, `<audio>`, `<iframe>` など。
    
7. インタラクティブ・コンテンツ（Interactive content）
    - **役割：** ユーザーがマウスやキーボードで「操作」できるグループ。
    - **特徴：** クリックしたり、文字を入力したりできる要素です。
    - **代表的なタグ：** `<a>`, `<button>`, `<input>`, `<select>`, `<textarea>` など。

[HTML LS コンテンツモデル ガイド](https://webgoto.net/html5/)

**【コンテンツモデルとは】**

コンテンツモデルとは、各要素（＝タグ）ごとに内包できるコンテンツを定義したルールのこと。

[HTML Living Standard ｜ HTML要素チートシート](https://htmlls.docs-share.com/)

**【透過的（Transparent）とは】**

親のコンテンツモデルを、そのまま自分にも引き継ぐ。

```markup
<!--
❌ NG例：
親の「p」が「フレージング（文字やインライン）」しか許していないため、
透過した「a」の中にもブロックの塊（divなど）を入れることはできません。
-->
<p>
  <a href="#">
	  <div>こちらをクリック</div>
	</a>
</p>

<!--
⭕️ OK例：
親の「div」が「フロー（ほぼ全て）」を許しているため、
透過した「a」の中にもブロックの塊（h2やpなど）をまるごと入れることができます。
-->
<div>
  <a href="#">
    <h2>見出し</h2>
    <p>本文</p>
  </a>
</div>
```

**【スクリプトサポートとは】**

JavaScriptなどのスクリプトを動かすために裏側でサポートする特別なグループ。

このグループは、「HTML内のほぼどこにでも、ルールを無視して置くことができる」特権を持っている。

- **`<script>`** （JavaScriptを読み込む、または直接書くためのタグ）
- **`<template>`** （JavaScriptで後から画面に表示させるための、隠しパーツを作っておくタグ）

# 11. トップへ戻るボタン

[ページトップへ戻るボタンをHTMLとCSSのみで実装する方法 | 株式会社リラクス](https://rilaks.jp/blog/pagetop-css/)

**【ページ内リンク】**

```html
<a class="pagetop" href="#section">
	<div class="pagetop__arrow"></div>
</a>

<!-- 飛ばしたい箇所に id名 を設定 -->
<section id="updates" class="updates">
</section>
```

**【スクロールしたらふわっと出す】**

```css
.pagetop {
  height: 50px;
  width: 50px;
  position: fixed;
  right: 30px;
  bottom: 30px;
  background: #fff;
  border: solid 2px #000;
  border-radius: 50%;
  display: flex;
  justify-content: center;
  align-items: center;
  z-index: 9999;
  
  /* 追加 */
  opacity: 0;
  visibility: hidden;
  transition: all 0.4s;
}

.pagetop.show {
  opacity: 1;
  visibility: visible;
}
```

```jsx
const pagetop = document.querySelector('.pagetop');

window.addEventListener('scroll', () => {
	if (window.scrollY > 300) {
		pagetop.classList.add('show');
  } else {
		pagetop.classList.remove('show');
  }
});
```

**【URLに「#」をつけたくない場合】**

```html
<button type="button" class="pagetop">
	<div class="pagetop__arrow"></div>
</button>
```

```jsx
pagetop.addEventListener('click', () => {
	window.scrollTo({
	  top: 0,
    behavior: 'smooth'
  });
});
```

# 12. スクロールアニメーション

[スクロール連動アニメーションをCSSで実現するには？Intersection Observerと組み合わせた使い方 ｜ 株式会社コナックス - 大阪を拠点にウェブ制作・システム開発・マーケティングまで一貫対応。](https://konux.jp/blog/scroll-animation-css-intersection-observer/)

**【何度もアニメーションできるようにする】**

```jsx
const observer = new IntersectionObserver(
	(entries, observer) => {
	  entries.forEach((entry) => {
		  // 変更
	    if (entry.isIntersecting) {
	      entry.target.classList.add('is-animated');
      } else {
	      entry.target.classList.remove('is-animated');
      }
	  });
  },
  {
	  root: null,
    threshold: 0.1,
    rootMargin: '0px 0px -100px 0px'
  }
);

document.querySelectorAll('.js-scroll-trigger').forEach((el) => {
	observer.observe(el);
});
```

**【アニメーションを遅らせる】**

```html
<div class="posts">
	<article class="js-scroll-trigger" data-animation="fade-up">
	</article>
```

```css
@media (min-width:640px) {

	.
	.
	.

  .updates article:nth-of-type(2) {
    transition-delay: 0.2s;
  }

  .updates article:nth-of-type(3) {
    transition-delay: 0.4s;
  }
}
```

【**アクセシビリティ対応**】

OSやスマホの設定で「視差効果を減らす（アニメーションを減らす）」設定をしているユーザーに対する配慮。

```css
/* アニメーションを減らす設定をしているユーザーにはトランジションを無効化する */
@media (prefers-reduced-motion: reduce) {
  .js-scroll-trigger {
    opacity: 1 !important;
    transform: none !important;
    transition: none !important;
  }
}
```
