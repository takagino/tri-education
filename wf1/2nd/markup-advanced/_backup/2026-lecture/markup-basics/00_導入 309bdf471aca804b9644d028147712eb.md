# **1. 授業について**

## 1-1. 科目のねらい

Webデザインの現場で求められる実践的なスキルの第一歩として、Webサイト構築の骨格となるHTMLと、装飾を担うCSSの役割と記述ルールを体系的に学ぶ。

単なるタグの暗記ではなく、情報が持つ意味を正しくブラウザや検索エンジンに伝える「構造的な思考」と、ユーザーにとって見やすく魅力的なインターフェースを作り上げる「表現力」の土台を築くことを目的とする。

自分の書いたコードがWebブラウザ上で視覚的なデザインとして瞬時に反映される「モノづくりの楽しさ」を体感しながら、プロのWebクリエイターとして実務に耐えうるコーディングの基礎体力を徹底的に鍛え上げる。

---

## **1-2. 授業概要**

本授業では、Webページの構造を定義するHTMLと、視覚的なスタイリングを行うCSSの基本文法から、現代の主流なレイアウト手法（FlexboxやCSS Grid）、さらにはスマートフォン対応（レスポンシブデザイン）まで、Webフロントエンド開発における必須スキルを網羅的に学習する。

講義での知識習得にとどまらず、Figma等のデザインデータをもとに実際にコードを書き起こす豊富な演習課題を通じて、正確なコーディング能力と、エラー発生時に自ら原因を特定し修正するデバッグ能力を養う。

さらに、毎回のタイピングテストを通じた入力速度・正確性の向上や、定期的な振り返りによる自己分析を組み込み、ただコードが書けるだけでなく、現場のスピード感に対応できるプロフェッショナルとしての土台を形成する。

---

## **1-3. 授業計画・方法**

- **講義と演習：** Web教材を用いた基礎知識の解説および実習。
- **課題制作：** 毎週のテーマに沿ったコーディング課題への取り組み。
- **スキルチェック：** 授業冒頭でのタイピングテスト（速度・正確性）の実施。
- **振り返り：** チェックシートを用いた習熟度の確認と自己分析。

---

## **1-4. 到達目標**

1. **コーディング速度の向上：** 講師のライブコーディングを遅滞なく正確に模写できるレベルのタイピングスキルを身につける。
2. **構造とデザインの理解：** HTML/CSSの役割を理解し、意図したデザインを正しい文法で構築できる。
3. **問題解決能力：** エラーが発生した際に、自ら原因を見つけ出し修正（デバッグ）できる。
4. **協調性と伝達力：** クラスメイトと技術的な疑問を共有・解決し合うことで、コミュニケーション能力を高める。

# **2. VSCodeの準備**

VSCodeは、正式には「Visual Studio Code」といい、Microsoft社が提供する無償のコードエディタのこと。

以下のような特徴を持っている。

- 拡張機能によりさまざまな機能を追加できる。
- macOS、Windows、Linuxといった主要なOSで使用できる。
- Git連携機能を使える。
- メジャーな多くのプログラミング言語でシンタックスハイライトが使える。
- スニペット機能が利用できる。
- インテリセンス（補完機能）が使える。

---

## **2-1. インストール（すでにインストール済み）**

1. [公式サイト](https://code.visualstudio.com/)にアクセスし「Download for MacOS」ボタンをクリック。
2. ページ遷移してしばし待つとダウンロード開始。
3. Zipファイルを解凍し、アプリケーションフォルダに移動。
4. 移動したアプリケーションを立ち上げる。
5. 「日本語」に変更するか聞かれたら指示に従って変更しておく。

---

## **2-2. 初期設定**

「Visual Studio Code」は設定画面で様々な項目を設定できるが、今回は「**JSONファイル**」を使って最低限の項目を一括設定する。

1. 画面右下にある「歯車アイコン」をクリックし、「設定」を選択。

    
    ![01.png](00_%E5%B0%8E%E5%85%A5/01.png)
    
2. 右上の「設定」アイコンをクリック。

    
    ![02.png](00_%E5%B0%8E%E5%85%A5/02.png)
    
3. 「**settings.json**」が開くので、以下の内容をコピペして「保存」。

```json
{
  "editor.wordWrap": "on", // エディターの幅で折り返し
  "editor.formatOnSave": true, // ファイル保存時に自動でフォーマット
  "editor.formatOnType": true, // 入力した行を自動でフォーマット
  "editor.formatOnPaste": true, // ペースト時に自動でフォーマット
  "editor.renderWhitespace": "all", // 半角スペースを常に表示
  "editor.renderLineHighlight": "all", // 選択行を行番号含めすべてハイライト
  "files.trimFinalNewlines": true, // ファイルの保存時に最終行以降をトリミング
  "files.trimTrailingWhitespace": true, // ファイルの保存時に行末の空白をトリミング
  "explorer.compactFolders": false, // フォルダの階層をまとめないようにする
  "workbench.startupEditor": "none", // 起動時にようこそページを非表示
}
```

※他にも設定項目はたくさんあるので、慣れてきたら自分で調べてください。
