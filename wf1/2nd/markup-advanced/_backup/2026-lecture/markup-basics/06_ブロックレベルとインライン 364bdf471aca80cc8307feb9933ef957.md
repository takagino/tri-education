# **2. マークアップの手順（現時点での）**

完全に理解するまでは、以下の手順で進めましょう。

<aside>

1. デザインの分析と計画（頭の中での組み立て）
2. HTMLの骨組み構築（構造化）
3. ベーススタイルの準備（CSSの土台作り）
4. 大きい要素から細かい要素へ（スタイリング）
</aside>

---

## **2-1. デザインの分析と計画（頭の中での組み立て）**

- **全体の構成は？**（`header`、`main`、`footer` の境界線）
- **アウトラインの設計は？**（`section`、`article` でどう区切るか、見出し `h2` `h3` のレベルはどうするか）
- **要素の種類を見極める：**
    - 画像（`img`）として書き出す部分はどこか？（本来は自分で書き出す。画像の代替テキスト `alt` に何を入れるかも考えておく）
    - リンク（`a`）になる部分はどこか？
    - テキストは `p` だけでなく、リスト（`ul`、`ol`、`dl`）を使うべき構造か？

---

## **2-2. HTMLの骨組み構築（構造化）**

アウトラインを意識しながら、計画を立てた通りに全体の構造のみを完成させます。

**【HTMLの雛形を作る】**

```markup
<!doctype html>
<html lang="ja">

<head>
    <meta charset="utf-8">
    <title>company</title>
    <link rel="stylesheet" href="./style.css">
</head>

<body>
</body>

</html>
```

**【`header`、`main`、`footer` の大枠を作る】**

まずはページ全体の「大きな3つの箱」を用意し、全体を中央に寄せるための `wrapper` で囲む。

```markup
<body>
    <div class="wrapper">
        <header>
        </header>

        <main>
        </main>

        <footer>
        </footer>
    </div>
</body>
```

<aside>
💡

- `header` は、ロゴやメニューなどの「サイトやページの導入部分」を表します。
- `main` は、そのページで一番伝えたい「メインコンテンツ」を表します。
- `footer` は、コピーライトなどをまとめた「ページの締めくくり（奥付）」を表します。
- `<div class="wrapper">` は、後でCSSを使ってデザイン全体を画面の中央に配置するための「見えない外枠」としての役割を持ちます。
</aside>

**【セクショニングコンテンツと見出しを書き、アウトラインを作る】**

次に、`main` の中をさらに意味のあるグループに分け、それぞれに「見出し（`h1〜h3`）」をつけて目次（アウトライン）を完成させます。

同時に、後でCSSを当てるためのクラス名もつけておく。

```markup
<body>
    <div class="wrapper">
        <header>
            <h1><img src="./images/img_logo.png" alt="company"></h1>
        </header>

        <main>
            <section class="services">
                <h2>MY SERVICES</h2>
                
                <article class="graphics">
                    <h3>Graphics Design</h3>
                </article>

                <article class="developement">
                    <h3>Web Developement</h3>
                </article>
            </section>

            <section class="testimonials">
                <h2>TESTIMONIALS</h2>
            </section>
        </main>

        <footer>
        </footer>
    </div>
</body>
```

<aside>
💡

- `section` は「大きなテーマの区切り」、`article` は「それだけで独立した記事の塊」を表します。
- 見出しの順番（`h1` → `h2` → `h3`）が正しく入れ子になっているか、ここでしっかりと確認しましょう。
- デザイン（テキストの大きさ・太さ）に惑わされず、「内容として見出しにふさわしいか」という観点で見出しをつけましょう。
- 後で見返した時やデザイン修正が入った時に、どこに何が書いてあるか理解しやすいクラス名をつけるようにしましょう。（内容や機能を表す英単語）
</aside>

**【テキストや画像などの細かいコンテンツを流し込む】**

アウトライン（骨組み）が完成したら、画像（`img`）やテキスト（`p`、`dl`、`a`）などの中身をすべて配置する。

これで「構造の作成」は完了です。

```markup
<body>
    <div class="wrapper">
        <header>
            <h1><img src="./images/img_logo.png" alt="company"></h1>
        </header>

        <main>
            <img src="./images/pic_mainvisual.png" alt="">

            <section class="services">
                <h2>MY SERVICES</h2>
                <p class="lead">Our Provided Features & Expertise</p>

                <article class="graphics">
                    <h3>Graphics Design</h3>
                    <p>Lorem ipsum dolor sit amet,Stet clita kasd lorem ipsum dolor sit amet. sed diam eirmod tempor dolore.</p>
                    <a href="#">Know More →</a>
                </article>

                <article class="developement">
                    <h3>Web Developement</h3>
                    <p>Lorem ipsum dolor sit amet,Stet clita kasd lorem ipsum dolor sit amet. sed diam eirmod tempor dolore.</p>
                    <a href="#">Know More →</a>
                </article>
            </section>

            <section class="testimonials">
                <h2>TESTIMONIALS</h2>
                <p class="lead">What People Says</p>
                <p>Lorem ipsum dolor sit amet,Stet clita kasd gubergren, no sea takimata sanctus est is the lorem ipsum dolor sit amet. sed diam nonumy eirmod tempor invidunt ut labore et dolore is the magna aliquyam.</p>
                
                <img src="./images/pic_testimonials01.png" alt="">
                
                <dl>
                    <dt>John Doe</dt>
                    <dd>CEO, ABC Company</dd>
                </dl>
            </section>
        </main>

        <footer>
            <p>2019 All Rights Reserved.</p>
        </footer>
    </div>
</body>
```

<aside>
💡

- 画像には必ず `alt` 属性（代替テキスト）を設定します。装飾目的の画像であっても、空の `alt=""` を必ず書くのがルールです。
- テキストを入れる際は、ただの段落なら `p`、項目と説明のペアなら `dl`（説明リスト）といったように、情報の意味に合わせて適切なタグを選びましょう。
</aside>

## 2-3. ベーススタイルの準備（CSSの土台作り）

HTMLの骨組みができたら、各要素のデザインを細かく作り込む前に「ページ全体の土台作り」をします。

**【ベーススタイル（共通設定）】**

一番多く使われるテキストの色やサイズを、大元である `body` 要素に設定します。

```css
@charset "utf-8";

body {
  margin: 0; /* ブラウザが勝手につけるページ外側の隙間をなくす */
  color: #151d41; /* 全体の基本となる文字色 */
  font-size: 16px; /* 基本の文字サイズ */
  font-family: Helvetica, Arial, sans-serif; /* 基本のフォント */
  line-height: 2; /* 基本の行間 */
  letter-spacing: 0; /* 基本の文字間隔 */
  background-color: #f2f2f2; /* ページ全体の背景色 */
}
```

<aside>
💡

- `body` に基本の文字設定をしておけば、「スタイルの継承」によって全てのテキストに適用されるため、コードを書く量を大幅に減らせます。
- 本文だけでなく、全てのテキストの色、基本フォントサイズ、行間も同時に調べ、なんとなくの当たりをつけておくとミスや余分な記述が少なくなります。
</aside>

**【デフォルトスタイルのリセット（初期化）】**

```css
ul{
	padding-left: 0; /* ul要素が最初から持っている左側の余白を消す（今回のデザインでは登場しない） */
}

dd {
  margin-left: 0; /* dd要素が最初から持っている左側の余白を消す */
}

a {
  color: #151d41; /* リンク特有の青色を、基本の文字色で上書きする */
  text-decoration: none; /* リンク特有の下線を消す */
}
```

## 2-4. 大きい要素から細かい要素へ（スタイリング）

CSSを書くときの鉄則は「外側の大きな箇所から、内側の小さな箇所へ」向かって整えていくことです。

ここで、Webデザインの最重要ルールである「ボックスモデル」を意識しましょう。

<aside>
💡

**【超重要】ボックスモデルと2つの余白**

- **padding（内側の余白）：** 枠線（border）より「内側」の空間。**背景色が塗られる領域**です。
- **margin（外側の余白）：** 枠線（border）より「外側」の空間。**隣の要素と距離をとる**ための領域です。
</aside>

**【全体を中央に寄せる（一番大きな外枠）】**

まずは、ページ全体を包んでいる `.wrapper` の幅を決め、画面の中央に配置します。

```css
.wrapper {
  width: 750px; /* サイト全体の幅を固定する */
  margin-left: auto;
  margin-right: auto; /* 左右の外側の余白をauto（自動）にすると、中央寄せになる */
}
```

<aside>
💡

左右の `margin` に `auto` を指定するのは、Webページ全体を画面の真ん中に配置するための「鉄板テクニック」です。

</aside>

**【大枠（header, footer）のレイアウト】**

次に、大きなセクションごとの余白や線を設定します。

```css
header {
  margin: 50px 0 70px; /* 上、左右、下の「外側」の余白（他の要素との距離） */
  text-align: center;
}

footer {
  margin-bottom: 50px; /* 下に50pxの「外側」の余白 */
  border-top: 3px solid #27debf; /* 上に3pxの緑色の枠線 */
  padding-top: 20px; /* 枠線とテキストの間の「内側」の余白 */
  text-align: right;
}
```

<aside>
💡

**プロの視点：なぜ `h1` ではなく `header` に margin をつけるのか？**

余白を作るとき、中の `h1` に margin をつけるのはNGです。将来「ロゴの下にメニューを追加して」とデザイン修正が入った時、h1 に余白がついているとレイアウトが崩れてしまいます。

「余白は外枠（`header`）につける」ことで、中に何が追加されても崩れない「**変更に強いCSS**」になります。

</aside>

**【各要素（article等）の作り込み】**

大きな外枠が整ったら、最後はその中にある小さな箱（記事など）を整えます。

```css
/* クラス名を増やさず、子孫セレクタ（.servicesの中のarticle）を活用 */
.services article {
  margin-bottom: 50px; /* 下の記事との距離（外側） */
  padding: 40px; /* 背景を綺麗に見せるためのゆとり（内側） */
}
```

<aside>
💡

**プロの視点：今はあえて「少ないクラス名」で書く**

ここでは `article` 自体にクラスをつけず、`.services article` という**子孫セレクタ**を使って装飾しています。無駄な `div` やクラス名をむやみに増やさないことで、HTMLがスッキリと読みやすくなります。

</aside>

【補足】

<aside>
⚠️

現在のWeb制作の現場では、すべての要素に細かくクラス名をつける手法が主流です。

しかし、今は「正しいHTMLの構造」や「余白の概念」など、他に優先して学ぶべき基礎がたくさんあります。そのため、現段階ではあえて「最小限のクラス名で効率よく書く基本の手法」で進めています。まずはこの基礎をしっかり固めましょう。

</aside>

## 4-3. リセットCSS

リセットCSSとは、ブラウザがデフォルトで持っているCSSを打ち消すためのCSS。ブラウザ間の表示の差異がなくなり作業効率も上がるため、実際の現場でも良く使われている。

授業では、以下のサイトに紹介されている中から、「The New CSS Reset」をCDN形式で使用します。

**【代表的なリセットCSS】**

| 名称 | 特徴（どんな時に使う？・何をしてくれる？） | CDNのURL・読み込み方 |
| --- | --- | --- |
| destyle.css | ブラウザが最初からつけている余白や文字の大きさを、「すべてゼロ（リセット）」にする。 | <link rel="stylesheet" href="[https://cdn.jsdelivr.net/npm/destyle.css/destyle.min.css](https://cdn.jsdelivr.net/npm/destyle.css/destyle.min.css)"> |
| A (more) Modern CSS Reset | すべてをゼロにするのではなく、最近のWebサイトを作りやすいように「良い感じの初期設定」をしてくれる。 | <link rel="stylesheet" href="[https://unpkg.com/more-modern-css-reset/dist/reset.min.css](https://unpkg.com/more-modern-css-reset/dist/reset.min.css)"> |
| Josh's Custom CSS Reset | 「画像が枠からはみ出ないようにする」「文字を読みやすくする」など、必要最低限の設定だけしてくれる。 | [公式サイト](https://www.joshwcomeau.com/css/custom-css-reset/)からコードをコピーして、自分で `reset.css` というファイルを作って読み込むのが一般的な使い方。 |

**【CDNとは】**

CDNとは「Content Delivery Network」の略。同一のコンテンツを多くの配布先、例えば多くのユーザーの端末に効率的に配布するために使われる仕組みのこと。

**【読み込む順番に注意】**

```markup
<!DOCTYPE html>
<html lang="ja">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hotelin</title>
    
    <!-- 必ずリセットCSSを先に読み込むこと！（自分で書いたCSSが上書きされてしまうため）-->
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/destyle.css/destyle.min.css">
    <link rel="stylesheet" href="./style.css">
</head>

<body>
</body>

</html>
```

## 4-4. スニペットの登録

コードを予めスニペットに登録することで短いコードで簡単に呼び出せる機能。

**【手順】**

1. 左下の「管理（歯車アイコン） - スニペット」を選択。
    
    ![CleanShot 2025-05-26 at 20.35.50.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/CleanShot_2025-05-26_at_20.35.50.png)
    
2. 画面上部に表示された入力欄に「**html**」と入力。候補として表示された「html.json」をクリック。またはキーボードの「Enter」。
    
    ![CleanShot 2025-05-26 at 20.41.07.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/CleanShot_2025-05-26_at_20.41.07.png)
    
3. **初めから記入されているサンプルコードを全て削除**し、以下のソースコードをコピペする。
    
    ```json
    "destyle.css": {
    	"prefix": "reset",
    	"scope": "html",
    	"body": [
    		"<link rel=\"stylesheet\" href=\"https://cdn.jsdelivr.net/npm/destyle.css/destyle.min.css\">"
    	]
    }
    ```
    
4. 保存して終了。
5. HTMLファイルに「reset」と入力して動作確認。

# 5. ブロックレベルとインライン

HTMLの要素には、大きく分けて「ブロックレベル」と「インライン」の2種類の性質があります。

さらにCSSを使うことで、その両方のいいとこ取りをした特殊な第3の状態（インラインブロック）を作り出すことができます。

**【ブロックレベル要素（div, p, section, h1〜h6 など）】**

- **特徴：**画面の横幅いっぱいに広がる「大きな箱」。ブロックのように縦に積み重なっていく。
- **余白と幅：**`width`、`height`、上下左右の `margin`・`padding` をすべて自由に設定できる。

**【インライン要素（a, span, img など）】**

- **特徴：**文章の中の「文字」と同じ扱い。改行されず、横に並んでいく。
- **余白と幅：**`width` と `height` は指定できない。また、上下の `margin` も効かない。

**【インラインブロック要素（主にCSSで `display: inline-block;` を指定した要素）】**

- **特徴：**インライン要素のように改行されず「横に並んでいく」が、要素自体は「箱」として振る舞う。（2つの要素のいいとこ取り）
- **余白と幅：**ブロックレベル要素と同じく、width、height、上下左右の margin・padding をすべて自由に設定できる。
- **注意点：**ブロックレベル要素のように **`margin: auto;` を使った左右の中央寄せは効かない。**（中央に寄せたい場合は、親要素に `text-align: center;` を指定する必要がある）

<aside>
💡

**`img` 要素の特殊な立ち位置について**

`img` 要素は、ブラウザの初期設定では「インライン要素」に分類されています。

本来、インライン要素は幅（width）や高さ（height）、上下の余白を指定できませんが、画像は特別です。画像のように「外部のデータ（写真など）に置き換わる要素」のことを置換要素と呼び、例外的に幅や高さを持たせることができます。

厳密な分類はインライン要素ですが、「**実質的にインラインブロックと同じ振る舞いをする特殊な要素**」だと覚えておきましょう。

</aside>

**【より詳しい説明】**

[【CSS】displayの使い方を総まとめ！inlineやblockの違いは？](https://saruwakakun.com/html-css/basic/display)

# 6. ボックスモデルの再確認（詳細と注意点）

**【大前提：ボックスモデルの概念】**

- 文書内のすべての要素は、ボックスと呼ばれる四角形の領域を生成する。
- ボックスはテキストや画像などの内容領域（Content Area）を持っており、内容領域の横幅を width(ウィドゥス)、高さを **height(ハイト)** のプロパティで指定する。
- その周辺には、**padding(パディング)**、**border(ボーダー)**、**margin(マージン)** の順に周辺領域を持つ。

[https___qiita-image-store.s3.ap-northeast-1.amazonaws.com_0_1888749_36a47d15-e9ad-d757-feec-c49cf9118b2b.avif](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/https___qiita-image-store.s3.ap-northeast-1.amazonaws.com_0_1888749_36a47d15-e9ad-d757-feec-c49cf9118b2b.avif)

**【ボックスモデルのプロパティの初期値】**

| プロパティ | 意味 | 初期値 |
| --- | --- | --- |
| width | 要素の幅 | auto |
| height | 要素の高さ | auto |
| margin | 要素の外側の余白（ボーダーの外側の余白） | 0 |
| padding | 要素の内側の余白（ボーダーの内側の余白） | 0 |

ここでは、実際のWeb制作で一番つまずきやすい「箱の横幅（width）」と「余白（padding/margin）」の関係性を、3つのステップで確認します。

## **6-1. ブロックレベル要素の幅と親要素の関係**

要素の横幅は、ブラウザの画面幅ではなく「親要素の幅」を基準に計算されます。

**【テキストは必ず要素で囲む】**

要素（タグ）で囲っていないむき出しのテキストには、そもそもボックスモデル（幅や余白）の概念が存在しません。

![SCR-20260519-bycg.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260519-bycg.png)

**【`width` を指定しない場合（初期値 `auto`）】**

ブロックレベル要素の横幅は、自動的に親要素の横幅とぴったり同じになります。

![SCR-20260526-bygv.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-bygv.png)

親要素の横幅を変更すると、`width: auto;` の状態である子要素の横幅も一緒に追従して変わります。

```css
body{
  width: 300px;
}
```

## **6-2. レイアウト崩れの罠とリセットCSS**

余白（padding）や線（border）をつける際、設定を間違えると箱が「膨張」してレイアウトが崩れてしまいます。デベロッパーツールの「Computedタブ」を見ながら、ブラウザの裏側の計算を確認しましょう。

**【`width: auto;` ＋ padding ＝ 安全】**

横幅を指定していない（`auto`）状態なら、`padding` や `border` を設定しても、親要素からはみ出しません。

```css
body {
	width: 300px;
	border: 1px solid;
}

p {
	margin: 0 10px;
	padding: 0 20px;
	border: 1px solid;
}
```

![SCR-20260526-cbhc.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-cbhc.png)

<aside>
⚠️

親要素の幅が300pxの場合、左右のmargin（10pxずつ）を引いた「280px」がこの要素が使える幅です。

画像右側の「Computed」を見ると、左右のpadding（20pxずつ）とborder（1pxずつ）の分だけ、一番内側の「青い部分（本文が入る領域）」が自動的に238pxまで縮んでくれているのがわかります。このように auto は、はみ出さないように中身を削って調整してくれます。

</aside>

**【`width` を数値で設定 ＋ padding ＝ 膨張してはみ出す場合があるので注意】**

`width: 280px;` や `width: 100%;` のように横幅を数値で固定した上で `padding` をつけると、レイアウトが崩れる場合があります。

```css
body {
	width: 300px;
	border: 1px solid;
}

p {
	width: 100%;
	margin: 0 10px;
	padding: 0 20px;
	border: 1px solid;
}
```

![SCR-20260526-chpl.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-chpl.png)

**【`box-sizing: border-box;`を指定すると計算方法が変わる】**

リセットCSSには `box-sizing: border-box;` が指定されています。これを使うと、ルールの基準が根本から変わります。

```css
body {
	width: 300px;
	border: 1px solid;
}

p {
	width: 100%;
	/* margin: 0 10px;  左右の margin は幅に含まれないので、はみ出てしまう可能性があるので注意 */
	padding: 0 20px;
	border: 1px solid;
}
```

![SCR-20260526-cisd.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-cisd.png)

<aside>
💡

**何が変わったのか？**

① まず、親要素（body）はどうなっている？

body には横幅300pxが指定されています。border-box が効いているため、左右の線（border 1pxずつ）は300pxの「内側」に含まれます。
つまり、body の中身として実際に使える幅は、300px - 2px（左右の線）＝ 298px になります。だから、width: 100%; を指定した p 要素の横幅は「298px」として計算されているのです。

② paddingとborderを指定した子要素（p）はどうなる？

p 要素は横幅298pxですが、さらに左右に20pxの padding と、1pxの border が指定されています。
もし初期状態なら箱が外側に膨張してしまいますが、border-box があるおかげで、paddingやborderの分だけ「一番内側の青い部分（本文が入る領域）」が内側にめり込んで（縮んで）くれます。
画像右側の図を見ると、青い部分が256pxまで自動で縮小し、箱全体の幅はぴったり298pxに収まっているのがわかります。

</aside>

**【`destyle.css` に書かれているCSS】**

```css
/* Reset box-model and set borders */
/* ============================================ */

*,
::before,
::after {
  box-sizing: border-box;
  border-style: solid;
  border-width: 0;
  min-width: 0;
}
```

## **6-3. 要素の動かし方と「auto」のルール**

中央寄せをする際によく使うプロパティの違いと注意点です。

**【`text-align` は「中身」を動かす】**

`text-align: right;` などを設定すると、その箱の範囲内で「内容（テキストやインライン要素など）」だけが移動します。箱自体は動きません。

```css
body {
	width: 300px;
	border: 1px solid;
}

p {
	width: 100%;
	padding: 0 20px;
	border: 1px solid;
	text-align: right;
}
```

![SCR-20260526-cnwn.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-cnwn.png)

**【`margin: auto;` は「要素自体」を動かす】**

親要素の中で「要素そのもの」を中央に配置したい場合は、左右の `margin` に `auto` を指定します。

```css
body {
	width: 300px;
	border: 1px solid;
}

p {
	width: 100px;
	margin: 0 auto;

	padding: 0 20px;
	border: 1px solid;
	text-align: right;
}
```

![SCR-20260526-cokq.png](06_%E3%83%96%E3%83%AD%E3%83%83%E3%82%AF%E3%83%AC%E3%83%99%E3%83%AB%E3%81%A8%E3%82%A4%E3%83%B3%E3%83%A9%E3%82%A4%E3%83%B3/SCR-20260526-cokq.png)

**【注意：`padding: auto;` は存在しない】**

`margin`（外側の距離）は自動計算（`auto`）できますが、`padding`（内側のクッション）には `auto` という値は使えません。必ず数値を指定します。

```css
body{
  width: 300px;
  border: 1px solid;
}

p{
  width: 100px;
  text-align: right;
  padding-left: auto; /* 何も変化しない */
}
```

# 7. 背景画像の設定

## **7-1. 個別で指定**

**background-image**

絶対パス・相対パスで画像の場所を指定する。

```css
.message {
  background-image: url(./images/pic_testimonials.png);
}

/*
ファイル名やフォルダ名に「スペース」などがある場合は「"（ダブルクォーテーション）」で囲む
ただし、基本的には「スペース」は使わないように！
*/
background-image: url("./images top/pic_testimonials.png");
```

**background-repeat**

背景画像をどのように繰り返すかを設定する。

```css
.message {
  background-repeat: repeat; /* 横方向にも縦方向にも繰り返す（初期値） */
  background-repeat: repeat-x; /* 横方向にものみ繰り返す */
  background-repeat: repeat-y; /* 縦方向のみ繰り返す */
  background-repeat: no-repeat; /* 繰り返さずに1度だけ表示する */
}
```

**background-position**

背景画像の表示位置を設定する。

```css
.message {
  /*
  background-position: 水平方向（左右）の位置 垂直方向（上下）の位置;
  */
  background-position: 0% 0%; /* 左上が基準（初期値） */
  background-position: 100px 50px; /* pxで指定可能 */
  background-position: 50% 50%; /* %で指定可能 */
  background-position: left center; /* キーワードで指定可能（left, right, top, bottom, center） */

  /*
  2つ目の値を省略すると「center」となる
  */
  background-position: left;

  /*
  右下を基準にしたい場合
  */
  background-position: right 50px bottom 25px;
}
```

**background-size**

背景画像をどうのように拡大縮小するか指定する。

```css
.message {
  /*
  background-size: 幅 高さ;
  */
  background-size: 100px 50px; /* pxで指定可能 */
  background-size: 50% 50%; /* %で指定可能 */

  /*
  2つ目の値を省略すると「auto（縦横比を保つ）」となる
  */
  background-size: 100px;

  /*
  キーワード値で指定（「cover」の使用頻度が高い）
  */
  background-size: contain; /* 画像を切り取ったり縦横比を崩したりすることなく、可能な限り大きく表示する */
  background-size: cover; /* 画像の縦横比を崩したりすることなく、何もない空間が残らないように画像を引き伸ばす */
}
```

## **7-2. 一括で指定**

**background**

```css
.message {
  /*
  値は順不同で指定可能だが、background-position と background-size は必ず続けて書く
  */
  background: url(./images/bg_mv.png) no-repeat center center / cover;

  /*
  背景色がある場合は同時に記述
  */
  background: #000 url(./images/bg_mv.png) no-repeat center center / cover;

  /*
  背景画像を複数指定したい場合は、カンマ区切りで
  */
  background: url(./images/pic_testimonials.png) no-repeat center center,
              url(./images/bg_mv.png) no-repeat center center / cover;
}
```
