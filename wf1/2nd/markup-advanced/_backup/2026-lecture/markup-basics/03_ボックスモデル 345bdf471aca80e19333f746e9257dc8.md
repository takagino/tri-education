# **3. レイアウトの種類**

Webサイトには大きくわけて「**ソリッドレイアウト**」と「**リキッドレイアウト**」があります。

**【ソリッド（固定）レイアウト】**

一般的にピクセル(px)単位で幅を設定する。ウィンドウサイズによってレイアウトが変化せず、はみ出した部分はスクロールで表示する。

**【リキッド（可変幅）レイアウト】**

一般的にパーセント(%)単位で幅を設定する。ウィンドウサイズによってレイアウトが柔軟に変化する。スマホが普及してからは、こちらのやり方が主流。

まずは「ボックスモデル」の理解に集中するため、より簡単な「***ソリッドレイアウト***」でマークアップします。

# 4. 絶対パスと相対パス

「href属性」や「src属性」などサイトやファイルを指定する際に「その場所までの道筋」を記述したものを***「*パス*」***といい、たどり着くまでのアプローチ方法として「**絶対パス**」と「**相対パス**」の2種類がある。

<aside>
💡

「画像が表示されない」や「CSSが反映されない」原因のほとんどが「**パスの指定間違い**」であるため、しっかり理解すること！

</aside>

---

## 4-1. 絶対パス

「**http://**」から始まるアドレス（URL)を使ってファイルの場所を指定すること。

どこから見てもアクセスできる。

```html
<!doctype html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>CSSとは？</title>
    <link rel="stylesheet" href="https://trident.takagino.net/doc2020/assets/css/common.css">
  </head>
  <body>
    <p>本文です。</p>
    <a href="https://computer.trident.ac.jp/">トライデントコンピュータ専門学校</a>
    <img src="https://computer.trident.ac.jp/news/topics/images/10754da50c9587e6cbb770ebf2b170b5e0af3f14.JPG">
  </body>
</html>
```

しかし、インターネット上にファイルがアップされていないとURLは存在しない、また、後で変更される可能性も高いため、自分で用意する画像やファイルは「絶対パス」で指定しないほうが無難。

---

基準となるファイルから見て、読み込ませたいファイルの場所を指定すること。

**【相対パスのルールその1】**

同じ階層内にあるファイルを参照する場合は、「**./ファイル名**」。（「./」は省略可能）

**【相対パスのルールその2】**

# **6. user agent stylesheet（ユーザーエージェントスタイルシート）**

**【ユーザーエージェントとは？】**

ユーザーがWebコンテンツを利用する際に使用しているブラウザや支援技術等の総称。

**【ユーザーエージェントスタイルシートの値】**

Chromeデベロッパーツールを使って、各要素にどんなプロパティが設定されているか確認してみる。

# **8. ボックスモデル**

**【ボックスモデルの概念】**

- 文書内のすべての要素は、ボックスと呼ばれる四角形の領域を生成する。
- ボックスはテキストや画像などの内容領域（Content Area）を持っており、内容領域の横幅を **width(ウィドゥス)**、高さを **height(ハイト)** のプロパティで指定する。
- その周辺には、**padding(パディング)**、**border(ボーダー)**、**margin(マージン)** の順に周辺領域を持つ。

[https___qiita-image-store.s3.ap-northeast-1.amazonaws.com_0_1888749_36a47d15-e9ad-d757-feec-c49cf9118b2b.avif](03_%E3%83%9C%E3%83%83%E3%82%AF%E3%82%B9%E3%83%A2%E3%83%87%E3%83%AB/https___qiita-image-store.s3.ap-northeast-1.amazonaws.com_0_1888749_36a47d15-e9ad-d757-feec-c49cf9118b2b.avif)

★**要素の検証**でボックスモデルを可視化してみよう。

---

## **8-1. margin（マージン）**

ボックスの一番外側の余白の領域。他の要素との間の余白を指定する。

**【指定方法】**

```css
p{
  /* 個別指定 */
  margin-left: 10px;
  margin-right: 20px;
  margin-top: 30px;
  margin-bottom: 40px;

  /* 上下左右すべて */
  margin: 10px;

  /* 上下 左右 */
  margin: 10px 20px;

  /* 上 左右 下 */
  margin: 10px 20px 30px;

  /* 上 右 下 左（時計回り）*/
  margin: 10px 20px 30px 40px;
}
```

---

## **8-2. padding（パディング）**

内容領域とボーダーの間にある余白の領域。要素の内側の余白を指定する。

**【指定方法】**

```css
p{
  /* 個別指定 */
  padding-left: 10px;
  padding-right: 20px;
  padding-top: 30px;
  padding-bottom: 40px;

  /* 上下左右すべて */
  padding: 10px;

  /* 上下 左右 */
  padding: 10px 20px;

  /* 上 左右 下 */
  padding: 10px 20px 30px;

  /* 上 右 下 左（時計回り）*/
  padding: 10px 20px 30px 40px;
}
```

**【paddingとmarginの違い】**

- 内容領域とボーダーの間の余白が「padding」、要素と要素の間の余白が「margin」。
- 要素の内側の余白が「padding」、要素の外側の余白が「margin」。
- 「padding」には背景色が反映される。

---

## **8-3. border（ボーダー）**

paddingの外側にある領域、いわゆる枠線。

**【指定方法】**

```css
p{
  border-width: 4px; /* 線の太さ */
  border-style: solid; /* 線の種類 */
  border-color: #ccc; /* 線の色 */

  /* まとめて書く */
  border: 4px solid #ccc;

  /* 上下左右それぞれに指定する */
  border-left: 4px solid #ccc;
  border-right: 4px dashed #ccc;
  border-top: 4px dotted #ccc;
  border-bottom: 4px double #ccc;

  /* より詳しく書く */
  border-left-width: 4px;
  border-left-style: solid;
  border-left-color: #ccc;
}
```

---

## **8-4. width（ウィドゥス）**

要素の横幅を設定する。

**【指定方法】**

```css
p{
  width: 100px;
}
```

**【要素を画面の中央に配置する】**

```css
p{
  width: 100px;
  margin-left: auto;
  margin-right: auto;
}
```

---

## **8-5. height（ハイト）**

要素の高さを設定する。

**【指定方法】**

```css
p{
  height: 100px;
}
```

<aside>
💡

理解せぬまま「height」を指定するとレイアウト崩れの原因になりやすいので、今の所は指定しない。（サンプルサイトも使用していない）

</aside>
