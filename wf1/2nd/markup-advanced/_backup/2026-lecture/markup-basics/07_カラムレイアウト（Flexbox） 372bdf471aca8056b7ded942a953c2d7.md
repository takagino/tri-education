# 3. Flexboxの基本ルール

Flexboxを使うためのルールはたった1つです。

<aside>

**横に並べたい要素たちの『親要素』に `display: flex;` を書く**

</aside>

**【参考資料】**

ただし、Flexboxには「親要素に指定する」プロパティと、「子要素に指定する」プロパティがたくさんあります。

以下のサイトに視覚的にわかりやすくまとめられています。

# 4. **Flexboxの実践（ハンズオン）**

## **3-1. 基本の横並びと配置（ヘッダー）**

まずは、一番上のヘッダー部分（ロゴとナビゲーション）を整えます。

**【手順1】親要素をFlexboxにする**

`style.css` の `header .inner` に `display: flex;` を追加します。

```css
header .inner {
  display: flex; /* 追加：子要素（ロゴとnav）が横並びになる */
}
```

<aside>
💡

`header .inner` を要素の検証をして、Flexboxを可視化してみる。

</aside>

**【手順2】左右に振り分ける**

今は左に寄ってしまっているので、これを左右の端にピンと張るように配置します。

```css
header .inner {
  display: flex;
  justify-content: space-between; /* 追加：左右の両端に配置する */
}
```

<aside>
💡

**`justify-content`（水平方向の配置）**

要素を横方向（左右）にどう並べるかを決めます。`space-between` は、最初と最後の要素を両端にくっつけて、間の余白を自動で均等にしてくれる非常に便利なプロパティです。

</aside>

**【手順3】上下の中央を揃える**

よく見ると、ロゴの画像に対して、ナビゲーションの文字が少し上にズレています。これを垂直方向のど真ん中に揃えます。

```css
header .inner {
  display: flex;
  justify-content: space-between;
  align-items: center; /* 追加：垂直（上下）方向の中央に揃える */
}
```

<aside>
💡

**`align-items`（垂直方向の配置）**

要素を縦方向（上下）にどう並べるかを決めます。`center` を指定するだけで、高さが違う要素同士でも綺麗に真ん中で揃います。

</aside>

## **3-2.  要素間の余白「gap」（ナビ・フッター）**

要素と要素の「隙間」を空ける際、これまで学んできた方法とFlexboxの新しい方法を比較してみましょう。

【 **❌ 今までの書き方（marginの罠）**】

今までなら、リスト（`li`）に `margin-left` などをつけて余白を作っていました。しかしこれだと、一番端の要素の外側にも不要な余白がついてしまい、全体のレイアウトがズレる原因になります。

```css
/* 古い書き方のイメージ（今回は書きません） */
nav li {
  margin-left: 30px;
}
```

【 **⭕️ Flexboxでの書き方（gapを使う）**】

Flexboxでは、子要素ではなく**親要素**に `gap` を指定します。コードに以下を追記しましょう。

```css
nav ul {
  display: flex;
  gap: 30px; /* 追加：要素の「間」にだけ30pxの隙間を作る */
}

footer ul {
  display: flex;
  justify-content: center;
  gap: 10px; /* 追加：要素の「間」にだけ10pxの隙間を作る */
  margin-bottom: 40px;
}
```

## **3-3. 折り返しとカードレイアウト（News）**

実務で最もよく作る「カードが並ぶレイアウト」を完成させます。

**【手順1】基本の横並びと、はみ出し（潰れ）の確認**

`.posts`（4つの記事を囲む親要素）に `display: flex;` を追加します。

```css
.posts {
  display: flex;
}
```

<aside>
⚠️

カードが潰れる、または画面からはみ出してしまいます。

Flexboxは初期設定では「**絶対に1行に収めようとする**」性質があるためです。

</aside>

**【手順2】折り返しの許可を出す**

親要素の幅に収まらなくなった時に、下の行へ折り返すように指示を出します。

```css
.posts {
  display: flex;
  flex-wrap: wrap; /* 追加：幅に入りきらない場合は下に折り返す */
}
```

---

## 3-4. カードレイアウトと「gap」

カードレイアウトの「余白の作り方」も、「gap」を使うと簡単に実装できます。

```css
.posts {
  display: flex;
  flex-wrap: wrap;
  gap: 60px 40px; /* 追加：縦の余白60px、横の余白40px */
}

.posts article {
  width: 380px; /* 追加：カードの幅を指定する */
}
```
