# **3. 表示・非表示の切り替え（PCとスマホの出し分け）**

現在の状態を見ると、ヘッダーに「文字のナビゲーション（gnav）」と「三本線のメニューアイコン（menu）」の両方が表示されてしまっています。
これを、スマホ版とPC版で切り替えて表示するようにします。

※ 今回はデザインの切り替えのみですが、実際のメニューの開閉にはJavaScriptという別の言語を使います。

1. **スマホ版（デフォルト）の指定：**スマホの時は、文字のナビゲーション（`.gnav`）を隠します。
2. **PC版（メディアクエリ内）の指定：**画面幅が640pxを超えたら、文字のナビを復活させ、代わりにメニューアイコンを隠します。

```css
.gnav {
    display: none; /* 要素を画面上から完全に消し去る */
}
```

```css
@media (640px < width) {
    .gnav {
        display: block; /* 非表示（none）を解除して表示する（nav要素の display の初期値） */
    }

    .menu {
        display: none; /* メニューアイコンを隠す */
    }
}
```

[display - CSS | MDN](https://developer.mozilla.org/ja/docs/Web/CSS/Reference/Properties/display#%E5%85%AC%E5%BC%8F%E5%AE%9A%E7%BE%A9)

# **4. ヘッダーの固定配置と重なり順（fixed と z-index）**

Webサイトを下にスクロールしても、ヘッダーがずっと上部についてくる「追従ヘッダー」を作ります。

## **4-1. 固定配置（`position: fixed`）**

**ヘッダーを画面の上部に固定する**`header` のスタイルに以下を追記します。

```css
header {
    position: fixed; /* 画面の決まった位置に要素を固定する */
    top: 0;          /* 上から 0px の位置に配置 */
    left: 0;         /* 左から 0px の位置に配置 */
    width: 100%;     /* 固定すると幅が中身のサイズに縮むため、100%を指定 */
    padding: 40px 0;
}
```

<aside>
💡

**`position: fixed;`（固定配置）とは？**

画面のスクロールとは無関係に、ブラウザの画面上の指定した位置に要素をピタッと貼り付けるプロパティです。

上下左右の位置は `top`, `bottom`, `left`, `right` で指定します。

</aside>

<aside>
⚠️

**【重要】固定すると「他の要素から存在しないもの」になる**

`fixed`（や後で学ぶ `absolute`）を指定した要素は、通常のレイアウトから外れ、**宙に浮いた状態**になります。つまり、他の要素からすると「ヘッダーが消えた（存在しない）」ように扱われます。
そのため、本来ヘッダーの下にあったメインコンテンツが、画面の一番上までズルッと潜り込んでしまいます。

一般的なWebサイトを作る時は、ヘッダーが被ってコンテンツが隠れないように「次の要素にヘッダーの高さ分の余白（margin-topなど）を空ける」という処理が必須になります。
（※今回のRenomeは、後ろの大きな写真をあえてヘッダーの裏に潜り込ませて「透かせる」デザインのため、余白は空けずにそのまま重ねています）

</aside>

---

## **4-2. 要素の重なり順（`z-index`）**

スクロールしていくと、記事の画像などがヘッダーの上に重なって見えてしまいます。ヘッダーが「一番上（手前）」にくるように指定します。

```css
header {
    position: fixed;
    top: 0;
    left: 0;
    z-index: 9999; /* 追加：重なり順を一番手前にする */
    width: 100%;
    padding: 40px 0;
}
```

<aside>
💡

**`z-index`（重なり順）とは？**

要素が重なり合った時、どれを手前に表示するかを決めるプロパティです。数値が大きいほど手前に来ます。
（※ `position` プロパティが指定されている要素にしか効かないので注意！）

実務では「絶対に一番手前にしたい要素（ヘッダーやポップアップ）」には `999` や `9999` のような大きな数値を設定するのが一般的です。

</aside>

---

## **4-3. 背景の透明度（`rgba`）**

スクロールした時に、後ろの写真がヘッダーから少し「透けて」見えるようにします。

```css
header {
    position: fixed;
    top: 0;
    left: 0;
    z-index: 9999;
    width: 100%;
    padding: 40px 0;
    background-color: rgba(255, 255, 255, 0.8); /* 追加：白を80%の不透明度にする */
}
```

<aside>
💡

**`rgba()` を使った色の指定**

今まで色は `#ffffff`（カラーコード）で指定していましたが、透明度を持たせたい時は `rgba(赤, 緑, 青, 透明度)` を使います。

最後の `0.8` が透明度（Alpha値）です。`1` が完全に不透明、`0` が完全に透明になります。

</aside>

# **5. 本来の位置からズラす相対配置（relative）**

PC版（画面幅640px以上）の時の INFORMATIONセクション の画像を少しズラして、赤い背景をドロップシャドウのように見せるプロのテクニックを実践します。

```css
@media (640px < width) {
    .information .pic {
        background-color: #ff6767; /* 親要素の背景を赤にする */
    }

    .information .pic img {
        position: relative; /* 本来あるべき位置を基準にする */
        top: 15px;          /* 本来の位置から下に 15px ズラす */
        right: -15px;       /* 本来の位置から右に 15px ズラす */
    }
}
```

<aside>
💡

**`position: relative;`（相対配置）とは？**

要素が「本来配置されるはずだった場所」を基準にして、そこからどれくらいズラすかを指定できるプロパティです。
画像だけがズレたことで、親要素の赤い背景色が見えるようになります。

</aside>

# **6. 画像の上にバッジを配置する（Relative と Absolute）**

SERVICESセクションの1つ目の画像（`.pic`）の右下に、「NEW」というバッジ（`.badge`）を重ねて配置します。

「親を基準にして、子を自由に動かす」という、実務で最も使う王道の配置テクニックです。

## **6-1. 親要素に「ここが基準だよ」と宣言する（相対配置）**

まず、親要素である画像枠（`.pic`）に「ここを起点（基準）にしてね」という目印をつけます。

先ほど学んだ `relative` は、実は「子要素の基準点になる」というもう一つの重要な役割を持っています。

```css
.services .pic {
    position: relative; /* 子要素の絶対配置の「基準点」になる */
}
```

---

## **6-2. 子要素を「親の枠内」で自由に動かす（絶対配置）**

次に、子要素であるバッジ（`.badge`）を、親要素の右下に配置します。

```css
.services .badge {
    position: absolute; /* 親要素を基準にして自由に配置する */
    bottom: 20px;       /* 下から 20px の位置 */
    right: -10px;       /* 右から -10px（少し外側にはみ出す）の位置 */
    padding: 8px 10px 8px 20px;
    background-color: #ff6767;
    color: #fff;
}
```

<aside>
💡

**絶対配置（absolute）の基準点について**

子要素に `absolute` を指定した場合、親要素（または先祖要素）に `position` の初期値（`static`）以外の値（`relative`, `absolute`, `fixed` など）が設定されていると、そこが配置の基準点になります。
もし基準点となる要素が見つからないと、「ブラウザの画面全体」が基準になって要素が飛んでいってしまいます。

実務では、他の要素のレイアウトを崩さずに（本来の占有スペースを保ったまま）基準点にできる **`relative`** が最も使い勝手が良いため、『親に relative、子に absolute』のセットで使われるのが王道パターンとなっています。

</aside>

---

## **6-3. 要素の角を部分的に丸くする（`border-radius`）**

バッジの左側の角だけを丸くして、リボンのようなデザインにします。

```css
.services .badge {
    position: absolute;
    bottom: 20px;
    right: -10px;
    padding: 8px 10px 8px 20px;
    border-radius: 20px 0 0 20px; /* 追加：左側の角だけを 20px 丸くする */
    background-color: #ff6767;
    color: #fff;
}
```

<aside>
💡

**`border-radius` の4つの値の順番**

`border-radius: 左上 右上 右下 左下;` のように、**左上から時計回り**で指定します。

今回は「左上」と「左下」に `20px` を指定し、「右上」と「右下」は `0`（丸めない）としています。

</aside>

<aside>
💡

**小技：綺麗な「丸」を作る**

プロフィール画像のアイコンなど、要素を完全な「正円」にしたい時は、長さを同じにした上で **`border-radius: 50%;`** と指定するだけで綺麗な丸が作れます。

</aside>

# **7. まとめ：position プロパティの3大要素**

| 値 | 役割・特徴 | 実務での主な使い所 |
| --- | --- | --- |
| **`fixed`**
（固定配置） | 画面上の決まった位置に要素を貼り付ける。
他の要素からは存在しないものとして扱われる。 | 追従するヘッダー、画面右下の「TOPへ戻る」ボタン |
| **`relative`**
（相対配置） | ① 本来の位置から自分自身を少しズラす。
② `absolute` を使うための**基準点**になる。 | `absolute` とセットで使う（9割はこの使い方） |
| **`absolute`**
（絶対配置） | 基準点となる要素を基準にして、自由な位置に配置する。
他の要素からは存在しないものとして扱われる。 | 画像に重なる「NEW」などのバッジ装飾 |
