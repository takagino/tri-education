# **1. 授業について**

---

## **1-1. 科目のねらい**

この授業では、現代のWeb制作現場で求められる、高品質なフロントエンド開発スキルとチームでの協業スキルを習得することを目的とする。単にWebサイトを『作る』技術だけでなく、その品質と保守性を担保し、チームで『育てていく』ためのプロフェッショナルな思考と技術を養う。これにより、見た目の美しさだけではなく、速度、使いやすさ、そして多様な人々への配慮がなされた、真に価値のあるWeb体験を創造する力を身につける。

## **1-2. 授業概要**

この授業では、個人の技術習得からチームでの実践まで、以下の内容を段階的に学ぶ。

1. **基礎技術の習得と設計思想：**
    
    保守性の高いCSS設計手法として BEM を学び、Sass による効率的な記述方法、レスポンシブ対応、rem単位などを用いた柔軟な実装基盤を固める。
    
2. **表現力の向上：**
    
    CSSの transition や transform、@keyframes を学び、簡単なJavaScriptと連携させることで、Webサイトに魅力的で意味のあるUIアニメーションを実装する技術を習得する。
    
3. **品質の担保：**
    
    サイトパフォーマンスとWebアクセシビリティの重要性を学び、専用ツールを用いてサイトの品質を測定・改善する具体的な手法を実践を通じて学ぶ。
    
4. **チーム開発ワークフロー：**
    
    個人の Git 利用から一歩進み、ブランチ機能やプルリクエストを活用した GitHub Flow を学ぶ。他者のコードをレビューする体験を通して、チームで開発を進めるための作法とコミュニケーションを習得する。
    
5. **統合的実践：**
    
    中間課題では、ここまでに学んだ技術の定着度を個人制作で確認する。最終課題では、チームで一つのWebサイトを企画・設計・実装・発表するまでの一連のプロセスを経験する。
    

## **1-3. 到達目標**

この授業を履修することで、以下の能力が身につく。

- BEM に基づいたCSS設計を行い、保守性の高いコードを記述できる。
- Sass の機能を活用し、効率的で管理しやすいスタイルシートを構築できる。
- CSS と簡単な JavaScript を連携させ、効果的なUIアニメーションを実装できる。
- パフォーマンスとアクセシビリティを考慮し、品質の高いWebサイトを構築できる。
- GitHub Flow を理解し、チームメンバーと協力してプロジェクトを計画的に遂行できる。

## **1-4. 評価の観点**

この科目の成績は、以下の点を総合的に評価する。

**※45コマ3単位**

1. **平常点：**
    - 授業への参加意欲、学習態度。
2. **毎回の課題：**
    - 各技術トピックに関する課題の完成度。
3. **中間課題：**
    - 個人制作サイトにおける、BEM の習熟度とアニメーション技術の適用。
    - パフォーマンスおよびアクセシビリティの基準スコア達成度。
4. **最終課題：**
    - チームプロジェクトにおける、設計・実装への技術的貢献度。
    - GitHub での活動や、チーム内での協調性、コミュニケーション。
