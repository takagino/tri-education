# 3. 様々な単位

---

個人的な使い分けは、

- **font-size**：「rem」
- **width**：基本は「%」、固定幅にしたい場合は「px」、文字数で計算したい場合は「em」
- **height**：極力指定せず「aspect-ratio」で対応
- margin：基本は「rem」、特定の場合に限り「em」
- padding：基本は「rem」、特定の場合に限り「em」
- border：px

以上がよく使っている印象。

<aside>

ただし、案件（デザイン）によって違いが出ることや、会社ごとにルールが決まっていることに注意。

最も大事なことは、**それぞれの単位の適正を理解し、適材適所使い分けられる知識を養うこと**。

</aside>

# 4. px（ピクセル）

---

- ディスプレイのピクセル数に対しての絶対値。

```markup
<body>
  <h1>見出し<span>です。</span><h1>
</body>
```

```scss
  body{
    font-size: 14px;
  }

  h1{
    font-size: 40px;
    margin-bottom: 32px;
  }

  span{
    font-size: 12px;
  }
```

**【メリット・デメリット】**

○：同じ環境であれば、必ず同じ長さに表示できる。

○：計算が必要ない。

✕：ブラウザの文字サイズ調節機能が作動しない。

✕：レスポンシブ対応の際に変更すべき箇所が多くなる。

# 5. **%（パーセント）**

---

- フォントサイズ：「親要素のフォントサイズ」の相対値（何%か）
- 横幅や余白：基本は「親要素の横幅」の相対値（何%か）

**【フォントサイズの指定】**

```scss
// % = 指定したいフォントサイズ(px) / 親要素のフォントサイズ(px) * 100

// 親要素(html)のフォントサイズは16px（ブラウザのディフォルト）
// body要素のフォントサイズを14pxにしたい場合 → (14/16)*100 = 87.5
body{
  font-size: 87.5%;
}

// 親要素(body)のフォントサイズは14px
// h1要素のフォントサイズを36pxにしたい場合 → (36/14)*100 = 25.7...
h1{
  font-size: 25.7%;
}

// 親要素(h1)のフォントサイズは36px
// span要素のフォントサイズを12pxにしたい場合 → (12/36)*100 = 33.3...
span{
  font-size: 33.3%;
}
```

**【Sassの記法】**

```scss
body{
  font-size: percentage(math.div(14, 16));
}
```

**【横幅や余白の指定】**

```scss
h1{
  width: 50%; // 親要素の横幅の50%
  height: 50%; // 親要素の高さの50%（ただし、親要素の高さを指定していない場合は無効）
  margin-top: 10%; // 親要素の横幅の10%
  margin-left: 10%; // 親要素の横幅の10%
  border: 1% solid; // ボーダーの太さに「%」は指定不可
}
```

**【メリット・デメリット】**

○：ブラウザの文字サイズ調節機能が正常に機能する。

○：親要素のフォントサイズを変更するだけで、子要素も相対的に変更される。

✕：プロパティによって挙動が違うため、横幅以外には使いづらい。

# 6. em（エム）

---

- **フォントサイズ**：「親要素のフォントサイズ」の相対値（何倍か）
- **横幅や余白**：「要素自身のフォントサイズ」の相対値（何倍か）

**【フォントサイズの指定】**

```scss
// em = 指定したいフォントサイズ(px) / 親要素のフォントサイズ(px)

// 親要素(html)のフォントサイズは16px（ブラウザのディフォルト）
// body要素のフォントサイズを14pxにしたい場合 → 14/16 = 0.875
body{
  font-size: 0.875em;
}

// 親要素(body)のフォントサイズは14px
// h1要素のフォントサイズを36pxにしたい場合 → 36/14 = 2.57...
h1{
  font-size: 2.57em;
}

// 親要素(h1)のフォントサイズは36px
// span要素のフォントサイズを12pxにしたい場合 → 12/36 = 0.33...
span{
  font-size: 0.33em;
}
```

**【Sassの記法】**

```scss
body{
  font-size: #{math.div(14, 16)}em;
}
```

**【横幅や余白の指定】**

```scss
// em = デザインデータで測った値(px) / 要素自身のフォントサイズ(px)

h1{
  font-size: #{math.div(36, 14)}em;
  width: #{math.div(200, 36)}em;
  margin: #{math.div(30, 36)}em;
  padding: #{math.div(30, 36)}em;
  border: #{math.div(1, 36)}em solid;
}
```

**【メリット・デメリット】**

○：ブラウザの文字サイズ調節機能が正常に機能する。

○：親要素のフォントサイズを変更するだけで、子要素も相対的に変更される。

○：フォントサイズを変更するだけで、余白等も相対的に変更される。

○：文字数で横幅を設定できる。

✕：親要素の値によって表示サイズが変わるため、個別の調整が必要。

<aside>
💡

この後出てくる「rem」の登場により、特定の場合を除いてあまり使われなくなった印象。

</aside>

## 6-1. em の使い所

**【ボタンの文字サイズと内部の余白を連動させたい】**

```scss
.btn {
	background-color: #f60;
	color: #fff;
	display: inline-block;
	padding: #{math.div(10, 18)}em; // emで指定しておく
	font-size: 2em; // フォントサイズを2倍にすると、パディングも２倍になる
}
```

**【文字数に基づいて横幅を制御したい】**

```scss
.btn {
	background-color: #f60;
	color: #fff;
	display: inline-block;
	width: 3em; // 3文字分の横幅になる
	padding: #{math.div(10, 18)}em; // パディングがあるとうまくいかないので注意
	font-size: 2em;
}
```

# 7. **rem（レム）**

---

- **フォントサイズ**：「ルート要素(html要素)のフォントサイズ」の相対値（何倍か）
- **横幅や余白**：「ルート要素(html要素)のフォントサイズ」の相対値（何倍か）

**【em との違い】**

![font-size-parent.png](05_%E6%A7%98%E3%80%85%E3%81%AA%E5%8D%98%E4%BD%8D/font-size-parent.png)

**【フォントサイズの指定】**

```scss
// rem = 指定したいフォントサイズ(px) / ルート要素(html要素)のフォントサイズ(px)

// 親要素(html)のフォントサイズは16px（ブラウザのディフォルト）
// body要素のフォントサイズを14pxにしたい場合 → 14/16 = 0.875
body{
  font-size: 0.875rem;
}

// 親要素(body)のフォントサイズは14px
// h1要素のフォントサイズを36pxにしたい場合 → 36/16 = 2.25...
h1{
  font-size: 2.25rem;
}

// 親要素(h1)のフォントサイズは36px
// span要素のフォントサイズを12pxにしたい場合 → 12/16 = 0.75...
span{
  font-size: 0.75rem;
}

// Sassの記法
body{
  font-size: #{math.div(14, 16)}rem;
}
```

**【Sassの記法】**

em とは違い「ルート要素(html要素)のフォントサイズ」は毎回共通なため、「関数」で定義しておくと便利。

```scss
/*
「@function」で関数化
引数で数字を渡し、計算した結果を呼び出し元に返す
*/
@function rem($px-value) {
  @return #{math.div($px-value, 16)}rem;
}

body{
  font-size: rem(14);
}
```

**【横幅や余白の指定】**

```scss
// rem = 指定したいフォントサイズ(px) / ルート要素(html要素)のフォントサイズ(px)

h1{
  font-size: rem(36);
  width: rem(200);
  margin: rem(30);
  padding: rem(30);
  border: rem(1) solid;
}
```

**【メリット・デメリット】**

○：ブラウザの文字サイズ調節機能が正常に機能する。

○：ルート要素のフォントサイズを変更するだけで、すべての要素が相対的に変更される。

○：「em」よりも計算が楽。

✕：「px」よりも手間がかかる。（`@function`で解決できる）

## 7-1. スペーシング・スケール

`rem()`関数を使えば、`h1 { margin-bottom: rem(30); }` のように`px`から`rem`へ正確に変換できる。

しかし、もしデザインデータに「`22px`」「`29px`」「`30px`」といったバラバラな余白（マジックナンバー）が溢れている場合、

`margin: rem(22);` や `margin: rem(29);` のように、場当たり的に値を入力していくと、以下のような問題が起こる。

1. **デザインに一貫性がなくなる**（余白のリズムがバラバラになる）
2. **保守性が著しく低い**（「全体の余白を少し広げたい」場合、何百もの値を修正する必要がある）

**【現場での解決策】**

サイト全体で使う余白の「段階」を、`rem`単位でSass変数としてあらかじめ定義しておく方法。（スペーシング・スケール）

```scss
// htmlのフォントサイズ(16px)を基準とする
$space-xs:  0.25rem;  // 4px
$space-s:   0.5rem;   // 8px
$space-m:   1rem;     // 16px
$space-l:   1.5rem;   // 24px
$space-xl:  2rem;     // 32px
```

**【使用例】**

```scss
.card {
  padding: $space-m; // rem(16) と同様
}
.section {
  margin-bottom: $space-xl; // rem(32) と同様
}
```

<aside>
💡

この手法が最も効果を発揮するのは、**デザインデータを作る段階から、デザイナーとエンジニアがこの「スケール（ルール）」を共有している場合**です。

</aside>

# 8. **vw、vh**

---

- **1vw**：「ブラウザの表示領域（ビューポート）の横幅」の1%
- **1vh**：「ブラウザの表示領域（ビューポート）の高さ」の1%

## 8-1. vh の使い所

**【画面いっぱいの高さにしたい】**

```scss
height: 100vh;

// 100vw はスクロールバーの横幅も含んでしまうため、あまり使わない。（width: 100%; を使う）
```

## 8-2. vwの使い所

**【画面幅に応じて文字サイズを変えたい】**

```scss
font-size: 5vw;
```

# 9. clamp()

---

**【構文】**

```scss
clamp(最小値, 推奨値, 最大値);

/*
最小値: これ以上は小さくならないという下限値
推奨値: 基本的に採用したい可変値（vwなどをよく使う）
最大値: これ以上は大きくならないという上限値
*/
```

**【使用例】**

```scss
h1 {
  font-size: clamp(1.5rem, 5vw, 3rem);
}

/*
--- 動作
5vwの値が1.5remを下回る小さな画面では、1.5rem(24px)が適用される。（小さすぎ防止）
5vwの値が3remを上回る大きな画面では、3rem(48px)が適用される。（大きすぎ防止）
その中間の画面幅では、5vw(画面幅の5%)が適用され、文字サイズが滑らかに変化する。
*/
```

<aside>
💡

`font-size`だけでなく、`padding`や`margin`など、あらゆる長さの指定に活用できる。

</aside>

# 10. スニペットの登録

**【授業用のテンプレート】**

```scss

// =================================================================
//  Variables
// =================================================================

// --- Spacing ---

$space-s:   0.5rem;  // 8px
$space-m:   1rem;    // 16px
$space-l:   1.5rem;  // 24px
$space-xl:  2rem;    // 32px
$space-xxl: 2.5rem;  // 40px
$space-xxxl: 3rem;   // 48px

// --- Colors ---
$color-text: #000;
$color-base: #000;
$color-main: #000;
$color-accent: #000;
$color-bg: #000;

// --- Typography ---
$font-size-base: 16;
$font-family-gothic: "Helvetica Neue", Arial, "Hiragino Kaku Gothic ProN", "Hiragino Sans", "Yu Gothic", Meiryo, sans-serif;
$font-family-mincho: "Times New Roman", Times, "Hiragino Mincho ProN", "Yu Mincho", "MS PMincho", serif;

// --- Breakpoints ---
$breakpoints: (
  "tablet": 768px,
  "desktop": 1024px
);

// =================================================================
//  Functions
// =================================================================

// pxをremに変換する
// @param {number} $px-value - px値
// @return {string} - rem値
@function rem($px-value) {
  @return #{math.div($px-value, $font-size-base)}rem;
}

// XDのトラッキング値をemに変換する
// @param {number} $xd-value - XDのトラッキング値
// @return {string} - em値
@function ls($xd-value) {
  @return #{math.div($xd-value, 1000)}em;
}

// =================================================================
//  Mixins
// =================================================================

// メディアクエリ (モバイルファースト)
// @param {string} $breakpoint - $breakpointsのキー
@mixin mq($breakpoint: desktop) {
  @media (width >= map-get($breakpoints, $breakpoint)) {
    @content;
  }
}

// インナー幅の指定
// @param {number} $mw - max-width
// @param {number} $w  - width
@mixin inner($mw: 1000px, $w: 90%) {
  max-width: $mw;
  width: $w;
  margin-left: auto;
  margin-right: auto;
}
```

    ```scss
    $space-xl:  2rem;    // 32px
    $space-xxl: 2.5rem;  // 40px
    $space-xxxl: 3rem;   // 48px
    ```
    
- 上記以外の値の場合は、remの関数（@function）で指定する。
- font-family は、スニペットの変数の第一候補に「Verdana」を追加する。
- 1ページのみだが、使い回す想定でモジュール（post, btn）を設定する。
