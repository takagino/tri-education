# **1. 授業について**

## 1-1. 科目のねらい

本授業では、現代のWeb制作現場で求められる、高品質なフロントエンド開発スキルを個人制作を通して習得することを目的とする。  

単にWebサイトを「作る」技術だけでなく、BEMなどの設計手法やSassを用いて保守性を担保し、品質（パフォーマンスやアクセシビリティ）を測定・改善することで、サイトを「育てていく」ためのプロフェッショナルな思考を養う。  

さらに、適切なアニメーションやインタラクションを取り入れることで、見た目の美しさと使いやすさ、多様な人々への配慮がなされた真に価値のあるWeb体験を創造する力を形成する。 

---

## **1-2. 授業概要**

保守性の高いCSS設計手法としてBEMやSassによる効率的な記述方法を学び、柔軟な実装基盤を固める。さらに、CSSアニメーションと簡単なJavaScriptを連携させ、魅力的で意味のあるUIアニメーションの実装技術を実践的に習得する。  

授業の後半では、サイトのパフォーマンス測定やアクセシビリティの改善など、実際の運用を見据えた品質管理の具体的な手法を学ぶ。  

中間課題での技術確認を経て、最終課題では授業で学んだ設計・アニメーション・品質管理の技術をすべて盛り込んだオリジナルのWebサイトを企画から実装まで一人で一貫して行い、現場に近い開発プロセスを総合的に実践する。

---

## **1-3. 授業計画・方法**

- **講義とハンズオン演習：**SassやBEM、CSSアニメーションなどの技術を、実際にコードを書きながら実践的に習得する。
- **質測定と改善：**実装したサイトに対し、専用ツールを用いてパフォーマンスやアクセシビリティを測定し、自ら改善策を適用する。
- **制作演習とフィードバック：**学んだ技術を用いて独自の実装を行い、より美しく保守性の高いコードを書くためのフィードバックを通して実践力を高める。

---

## **1-4. 到達目標**

1. **保守性の高いコーディング：**BEMに基づいたCSS設計とSassを活用し、効率的で管理しやすいスタイルシートを記述できる。 
2. **アニメーション実装：**CSSと簡単なJavaScriptを連携させ、効果的なUIアニメーションを実装できる。 
3. **品質管理の理解：**パフォーマンスとアクセシビリティを考慮し、品質の高いWebサイトを構築・改善できる。 
4. **総合的なWebサイト構築：**学んだ設計思想や技術を統合し、要件を満たした高品質なWebサイトを一人で最後まで作り上げることができる。

# 2. 事前準備

本授業の課題は、**自分のGitHubリポジトリにプッシュ（同期）すること**をもって提出とします。

「JavaScript基礎」では既存のリポジトリを複製（フォーク）してもらいましたが、今回は自身のPC内にリポジトリ用のフォルダを作り、GitHubに同期してもらいます。

【手順】

1. デスクトップ等に、課題同期用の新規フォルダ **`class-markup`** を作成し、VSCodeで開きます。
2. VSCode左側のメニューから「ソース管理（Source Control）」アイコンを選択し、「リポジトリの初期化（Initialize Repository）」をクリックします。
    
    ![Snapzy_2026-10-05_15-41-01_788.png](00_%E5%B0%8E%E5%85%A5/Snapzy_2026-10-05_15-41-01_788.png)
    
3. 続けて、「Branchの発行（Publish to GitHub）」をクリックし、**「Publish to GitHub public repository（パブリックリポジトリとして公開）」** を選択します。
    
    ![Snapzy_2026-10-05_15-42-32_402.png](00_%E5%B0%8E%E5%85%A5/Snapzy_2026-10-05_15-42-32_402.png)
    
4. 画面右下に「リポジトリが正常に発行されました。」と表示されれば成功です。「GitHubで開く」をクリックして、ブラウザ上でファイルが同期されたか確認しましょう。

<aside>
⚠️

**【重要】必ず「Public（パブリック）」で公開すること**

「Private repository（プライベート）」を選択してしまうと、第三者がソースコードの確認をできなくなります。今後の課題提出時のチェックや、就職活動でのポートフォリオとしても機能しなくなるため、必ずパブリックで公開してください。

</aside>
