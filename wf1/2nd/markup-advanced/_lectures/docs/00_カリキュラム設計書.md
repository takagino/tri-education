### 1-2. 受講者の属性と前提知識

1. **マークアップの基礎力**:
   - 1年前期の「markup-basics」にて、HTML5の主要タグやCSSの基本プロパティ（`display: flex`、`position: absolute / relative` 等）を用いた静的なWebページ制作は習得済み。
   - 一方で、「CSSファイルが肥大化して詳細度で崩れる」「クラス名が散らかって修正しづらい」「レスポンシブでメディアクエリが多すぎて破綻する」という初学者特有の壁に直面している段階。
2. **高度なフロントエンド技術の初習**:
   - BEMやFLOCSSといった「CSSアーキテクチャ（設計手法）」、Sass（SCSS構文とモジュール分割）、remやFluid Typography（流体タイポグラフィ）による相対単位設計、CSS Gridおよびsubgrid、Webパフォーマンス（Core Web Vitals）、Webアクセシビリティ（a11y）、GSAPによるWebアニメーションは、**本授業で初めて学習する**。
3. **デザイン志向とプロ意識**:
   - Webデザイン学科として、デザインカンプ（Figma / XD / Photoshop）の意図を1pxの狂いなく忠実に再現するだけでなく、**「保守性が高く破綻しないコード構造」「どの端末でも滑らかに伸縮するレスポンシブ性」「実務の現場基準のコーディングスピード」** を身につける意識を養う。

## 2. 科目のねらい & 技術選定・コーディングルール

### 2-1. 科目のねらい

単にWebサイトの見た目を組むだけのマークアップから脱却し、**「プロの制作現場で通用する破綻しないCSS設計力」「モダンで堅牢なレスポンシブ実装力」「パフォーマンスとアクセシビリティに配慮した品質基準」「GSAPによる洗練されたマイクロインタラクション」** を統合した、現場基準のマークアップエンジニアリング力を養成することを目的とします。

---

### 2-2. 技術スタックとコーディングルール

学生がプロの現場に直結するコード品質を身につけられるよう、以下のルールを厳格に適用します。

- **使用言語・ツール**:
  - HTML5（セマンティックマークアップ）
  - CSS3 / SCSS（Dart Sass）
  - JavaScript（ES6+）: GSAP 3.x, ScrollTrigger プラグイン
  - バージョン管理: Git / GitHub（コミット履歴の整理、GitHub Pagesでのプレビュー公開）
  - エディタ環境: VS Code（`settings.json` による保存時自動整形・インデント統一）
- **CSS設計ルール**:
  - **FLOCSSアーキテクチャ**: `foundation/`, `layout/`, `object/component/`, `object/project/`, `object/utility/` にファイルをパーシャル分割（`_*.scss`）。
  - **BEM命名規則（MindBEMding記法）**:
    - Block: `.c-card`, `.p-hero`, `.l-header`（プレフィックス併用）
    - Element: `__item`, `__title`, `__body`
    - Modifier: `--primary`, `--active`, `.is-active`（状態クラス）
  - **Sass記法**:
    - 旧 `@import` の禁止（モダンな `@use` を徹底）。
    - ネストの深さは原則「最大3階層まで」（詳細度の吊り上がり・可読性低下を防止）。
- **禁止事項**:
  - CSSフレームワーク（Tailwind CSS, Bootstrap等）の使用禁止（基礎の自力実装力を養うため）。
  - jQueryの使用禁止（Vanilla JSまたはGSAPを使用）。
  - `!important` の原則禁止（Utilityクラスや一部オーバーライド時のみ例外許可）。
  - インラインスタイルの直接記述禁止。
- **コメント作法**:
  - 各SCSSファイル先頭にコンポーネントの役割や注意事項を明記。

## 4. 全12単元 ＋ 中間課題・最終課題：キーワード・プロパティ・演習一覧

### 単元1: プロのVS Code環境設定と前期確認課題（第1週：コマ1〜3）
> **目標**: プロのフロントエンド開発に必要な品質・保守性・生産性の重要性を理解し、VS Codeの `settings.json` による保存時自動整形・事故防止設定や、コーディング速度を劇的に上げる厳選ショートカットを習得した上で、GitHub PagesによるWebサイト公開手順を復習し、提供されたデザインカンプを自力マークアップして習熟度を確認できる。

- **コマ別の授業構成**:
  - **第1コマ（Day 1前半）**: 授業ガイダンス、プロの品質基準、VS Code爆速環境設定（`settings.json` の編集、コーディング速度を劇的に上げる厳選ショートカット体験）
  - **第2コマ（Day 1後半）**: GitHub PagesによるWeb公開フローの確認、前期確認課題（`01-practice`）のデザインカンプ分析とマークアップ着手
  - **第3コマ（Day 2）**: 【演習】前期確認課題マークアップの完成、保存時自動整形でのコード美化、GitHub Pages公開・提出
- **概念・キーワード**:
  - プロのフロントエンド開発の視点（見た目の再現だけでなく、コードの可読性・インデント・表示品質）
  - `settings.json` によるエディタカスタマイズ（保存時自動フォーマット、タグ自動補完、事故防止設定）
  - Git / GitHub Pages による静的サイトホスティング

---

### 単元2: CSS設計の必要性とBEMの基本・実践（第2週：コマ4〜6）
> **目標**: なぜCSS設計が必要なのか（詳細度の破綻、命名の衝突、意図しない上書き事故）を理解し、現場標準の命名規則「BEM（Block, Element, Modifier）」の概念を体得して、再利用性の高い破綻しないクラス名付けを実践できる。

- **コマ別の授業構成**:
  - **第4コマ（Day 1前半）**: CSSが破綻するメカニズム、詳細度の落とし穴、CSS設計の歴史と思想
  - **第5コマ（Day 1後半）**: BEMの基本概念（Block, Element, Modifier）、MindBEMding記法（アンダースコア2つ `__`、ハイフン2つ `--`）、アンチパターン（孫要素ネスト・タグ名依存）
  - **第6コマ（Day 2）**: 【演習】BEMを用いたパーツ〜複数UI実装（`02-roysha-bem`, `03-newslly-bem`）
- **概念・キーワード**:
  - Block（独立した再利用可能なパーツ）
  - Element（Blockを構成する依存要素）
  - Modifier（状態やバリエーションを表す修飾子）
  - 状態クラス（`.is-active`, `.is-open`）

---

### 単元3: Sass（SCSS）の基礎とモジュール分割（第3週：コマ7〜9）
> **目標**: CSSプリプロセッサ「Sass（SCSS構文）」の導入意義と基本文法を習得し、変数・ネスト記法・`@use` によるパーシャルファイル分割・Mixinを活用して、保守性の高いコードベースを構築できる。

- **コマ別の授業構成**:
  - **第7コマ（Day 1前半）**: Sassの必要性、VS Code拡張（Live Sass Compiler）の設定、SCSS記法、変数（`$variable`）、ネスト（入れ子）記法と親セレクタ参照（`&`）
  - **第8コマ（Day 1後半）**: パーシャルファイル分割（`_*.scss`）、モダンモジュールシステム（`@use`）、スタイル再利用のための `@mixin` と `@include`
  - **第9コマ（Day 2）**: 【演習】BEMで書いた既存CSSをSCSS記法（ネスト・変数・パーシャル分割）にリファクタリング（`04-newslly-sass`）
- **構文・プロパティ**:
  - `$color-primary`, `$font-base`
  - `@use 'variables' as *;`
  - `@mixin button-base { ... }`, `@include button-base;`

---

### 単元4: モダンなCSS単位とカスタムプロパティ（第4週：コマ10〜12）
> **目標**: 絶対単位（px）への過度な依存から脱却し、アクセシビリティとスケーラビリティを担保する相対単位（`rem`, `em`, `vw`, `vh`, `svh`/`dvh`）の特性と使い分けをマスターする。また、CSSカスタムプロパティ（CSS変数）によるテーマ管理を実装できる。

- **コマ別の授業構成**:
  - **第10コマ（Day 1前半）**: px依存の弊害、ルートフォントサイズ設定（`html { font-size: 62.5%; }`）、remの計算ロジック、Viewport単位（vw, vh, svh, dvh）
  - **第11コマ（Day 1後半）**: ネイティブCSSカスタムプロパティ（`--variable`）の定義と呼び出し（`var()`）、Sass変数との違い、動的テーマ切り替え（ダークモード基礎）
  - **第12コマ（Day 2）**: 【演習】rem単位とCSS変数を駆使したスケーラブルなUIパーツ実装（`08-cubehaus-rem`, `09-mache-rem`）
- **構文・プロパティ**:
  - `html { font-size: 62.5%; }` ➔ `1.6rem = 16px`
  - `:root { --color-primary: #123456; }`
  - `var(--color-primary)`

---

### 単元5: モダン・レスポンシブWebデザインとFluid Layout（第5週：コマ13〜15）
> **目標**: メディアクエリの多用によるカクつきを防ぎ、モバイルファースト設計の思想と、`clamp()` を用いたFluid Typography（流体タイポグラフィ）および `aspect-ratio` による最新のレスポンシブ手法を実装できる。

- **コマ別の授業構成**:
  - **第13コマ（Day 1前半）**: デスクトップファースト vs モバイルファースト、SassのメディアクエリMixin設計（`@include mq(md) { ... }`）
  - **第14コマ（Day 1後半）**: `min()`, `max()`, `clamp(min, val, max)` の数理、Fluid Typography（画面幅に応じて無段階で拡大縮小する文字と余白）、`aspect-ratio` による画像枠固定（CLS防止）
  - **第15コマ（Day 2）**: 【演習】ブレークポイントを減らし、`clamp()` を活用した流麗なレスポンシブUI実装（`07-cubehaus-sass`）
- **構文・プロパティ**:
  - `font-size: clamp(1.6rem, 1.2rem + 1vw, 2.4rem);`
  - `aspect-ratio: 16 / 9; object-fit: cover;`

---

### 第6週・第7週：【中間課題】実践レスポンシブWebサイト制作（コマ16〜21）
> **目標**: 単元1〜5で学んだ知識（BEM、Sass、rem、Fluid Typography、メディアクエリMixin）を総動員し、用意されたデザインカンプをもとに、1ページ完結の本格的なレスポンシブWebサイトを自力でマークアップする。相互コードレビューを通じて設計上の課題を実感し、次週のFLOCSSへの導入に繋げる。

- **コマ別の授業構成**:
  - **第16コマ（第6週 Day 1前半）**: カンプ分析、ディレクトリ構造構築、BEMクラス名設計、全体骨格マークアップ
  - **第17コマ（第6週 Day 1後半）**: メインコンテンツの実装、Sassパーシャル分割、Fluidタイポグラフィの適用

#### ② 冒頭小テスト（Googleフォーム: 約15分）

  4. **ベストプラクティス選択**: 「CLSを防ぐために画像タグに指定すべき属性は？」

- **【Step 3】ブレークポイント・発展的スタイリング（解説15分 ＋ ワーク35分）**: レスポンシブ化やアニメーションを付加し完成形へ。
