## 2. 全12単元：キーワード・メソッド・プロパティ一覧

### 単元1: JavaScriptの基礎知識・変数・データ型
> **目標**: WebにおけるJSの役割を理解し、ブラウザの開発者ツールで変数とデータ型の出力を扱えるようになる。

- **文法・キーワード**:
  - `let`（再代入可能な変数宣言）
  - `const`（再代入不可の定数宣言・原則こちらを推奨）
  - データ型（Primitive Types）: 文字列（`String`）、数値（`Number`）、真偽値（`Boolean`）、未定義（`undefined`）、空（`null`）
  - 代入演算子（`=`）
  - コメント記法（`//`、`/* */`）
  - セミコロン（`;`）の役割
  - `<script defer src="...">` の配置と読み込みタイミング
- **オブジェクト・メソッド・プロパティ**:
  - `console.log()`: コンソールへの通常出力
  - `console.dir()`: オブジェクト構造のツリー出力
  - `console.error()`: エラーの出力確認
  - `typeof` 演算子: データ型の判定
- **演習UI・作例**:
  - 開発者ツール（Console）での対話実行
  - アラート表示（`alert()`、`confirm()`）とコンソールログでの計算結果出力

### 単元2: DOMの取得と要素の書き換え
> **目標**: HTML要素をJavaScriptで取得し、テキストやHTML、スタイルの内容を動的に書き換えられるようになる。

- **文法・キーワード**:
  - DOM（Document Object Model）の概念
  - DOMツリー（要素ノード、テキストノード）
  - ドット記法によるプロパティアクセス
  - 文字列の結合（`+` 演算子）
- **オブジェクト・メソッド・プロパティ**:
  - `document.getElementById('id')`: IDによる単一要素取得
  - `document.querySelector('selector')`: CSSセレクタによる単一要素取得
  - `element.textContent`: 要素内のテキスト読み書き
  - `element.innerHTML`: 要素内のHTML構造読み書き（基本）
  - `element.style.◯◯`: インラインスタイルの直接変更（例: `style.color`, `style.backgroundColor`）
  - `document.body`: body要素へのショートカットアクセス
- **演習UI・作例**:
  - ボタンを押すとテキストが変わるメッセージボード
  - ページ背景色の直接切り替え（カラーピッカー風）

### 単元3: イベント処理とクラス操作によるUI切替
> **目標**: ユーザーの操作（クリック）を検知し、CSSクラスを付け外して見た目をアニメーションさせる基本パターンを習得する。

- **文法・キーワード**:
  - イベント駆動型プログラミング（Event-driven）
  - コールバック関数（無名関数の基本形）
  - CSSクラス（状態クラス：`.is-active`, `.is-open` 等）によるUI設計思想
- **オブジェクト・メソッド・プロパティ**:
  - `element.addEventListener('click', function)`: クリックイベントの登録
  - `element.classList.add('className')`: クラスの追加
  - `element.classList.remove('className')`: クラスの削除
  - `element.classList.toggle('className')`: クラスのトグル（ON/OFF）切り替え
  - `element.classList.contains('className')`: クラスの所持判定（真偽値を返す）
- **演習UI・作例**:
  - **ハンバーガーメニューの開閉（基本形）**: ボタンを押すとメニューに `.is-open` が付いてスライドイン
  - モーダルウィンドウの超シンプル版（表示/非表示の切り替え）

### 単元4: 条件分岐（if文）と属性操作
> **目標**: 条件（true / false）によって処理を分岐させ、HTML属性の読み書きと連動させたインタラクションを作れるようになる。

- **文法・キーワード**:
  - `if (条件式) { ... }`
  - `else if (条件式) { ... }`
  - `else { ... }`
  - 比較演算子: 厳密等価（`===`）、厳密不等価（`!==`）、大小比較（`>`, `<`, `>=`, `<=`）
  - 論理演算子: 論理積（`&&` かつ）、論理和（`||` または）、論理否定（`!` ではない）
  - 真偽値（`true` / `false`）
  - ガード節（早期リターン: `if (...) return;`）
- **オブジェクト・メソッド・プロパティ**:
  - `element.getAttribute('attrName')`: 属性値の取得
  - `element.setAttribute('attrName', 'value')`: 属性値の設定
  - `element.removeAttribute('attrName')`: 属性の削除
  - アクセシビリティ属性: `aria-expanded`（開閉状態）、`aria-label`
  - `classList.toggle('className', boolean)`: 第2引数による真偽値連動
- **演習UI・作例**:
  - **パスワードの表示/非表示切り替え**: input要素の `type="password"` と `type="text"` をif文で交互に切り替え
  - ナビゲーションの開閉状態に応じた `aria-expanded="true/false"` の自動更新

### 単元5: 配列と繰り返し処理（for文）
> **目標**: 複数のデータを配列でまとめ、for文を使って一括処理や複数要素への一括イベント登録ができるようになる。

- **文法・キーワード**:
  - 配列リテラル（`[item0, item1, ...]`）
  - 0始まりのインデックス（添字: `array[0]`）
  - `array.length`: 配列の要素数
  - インクリメント演算子（`i++`）
  - ループ処理: `for (let i = 0; i < array.length; i++) { ... }`
  - 配列への要素追加: `array.push(newItem)`
  - NodeList（複数要素のコレクション）と配列の類似点
- **オブジェクト・メソッド・プロパティ**:
  - `document.querySelectorAll('selector')`: 条件に一致する全要素の取得（NodeList）
  - `nodeList.length`: 取得した要素の個数
  - `nodeList[i]`: i番目の要素へのアクセス
- **演習UI・作例**:
  - **タブ切り替えUI / ナビリンク一括操作**: 複数のタブボタンを `querySelectorAll` で取得し、`for` 文で一括 `addEventListener` 登録
  - クリックしたタブだけに `.is-active` を付け、他は外すリセット処理

### 単元6: ループの応用とMathオブジェクト
> **目標**: while文による繰り返し条件制御と、Mathオブジェクトを使った乱数生成を組み合わせ、ランダムなUI演出を実装できる。

- **文法・キーワード**:
  - `while (条件式) { ... }`: 条件が真の間繰り返すループ
  - 無限ループの危険性と終了条件の設計
  - 乱数を使ったインデックス計算の公式: `Math.floor(Math.random() * 配列の長さ)`
- **オブジェクト・メソッド・プロパティ**:
  - `Math.random()`: 0以上1未満の疑似乱数を生成
  - `Math.floor()`: 小数点以下を切り捨てて整数化
  - `Math.ceil()`: 小数点以下を切り上げ
  - `Math.round()`: 四捨五入
- **演習UI・作例**:
  - **おみくじ・ランダムメッセージ表示**
  - **ランダム背景画像切り替え**: 画像URL配列からランダムに選出し、`while` 文を使って「前回と同じ画像が連続で出ない」重複防止ロジックを実装

### 単元8: DOMトラバーサルとイベント委譲
> **目標**: 親・子・兄弟要素を辿るDOMトラバーサルと、親要素で子要素のイベントを一括監視する「イベント委譲」を習得する。

- **文法・キーワード**:
  - DOMトラバーサル（要素間の相対移動）
  - `this` キーワード（イベントリスナー内での呼び出し元要素）
  - イベントオブジェクト（`e` / `event`）
  - イベントバブリング（子から親へイベントが伝播する仕組み）
  - イベント委譲（Event Delegation: 親で1回 addEventListener する利点）
  - カスタムデータ属性（HTML: `data-*`、JS: `dataset.*`）
- **オブジェクト・メソッド・プロパティ**:
  - `element.parentElement`: 親要素の取得
  - `element.nextElementSibling`: 次の兄弟要素の取得
  - `element.previousElementSibling`: 前の兄弟要素の取得
  - `element.closest('selector')`: 最も近い祖先要素の検索
  - `e.target`: 実際にクリックされた要素
  - `e.target.closest('selector')`: イベント委譲での対象要素特定
  - `element.dataset.◯◯`: カスタムデータ属性の読み書き
- **演習UI・作例**:
  - **アコーディオンパネル**: `this.parentElement` と `this.nextElementSibling` を使ってクリックした質問の回答を開閉
  - **カテゴリー絞り込み / 文字サイズ変更**: 親コンテナに1つだけリスナーを付け、`e.target.closest()` と `dataset` で一括制御

### 単元9: タイマー処理と非同期アニメーション
> **目標**: 一定間隔で処理を繰り返すタイマーや遅延処理を理解し、自動再生・停止できるスライドショーの基礎を作る。

- **文法・キーワード**:
  - 非同期処理（Asynchronous）の初歩
  - タイマーIDによるタイマー管理
  - カウント変数のループ（インデックスが末尾に達したら0に戻す循環ロジック）
- **オブジェクト・メソッド・プロパティ**:
  - `setInterval(callback, delayMs)`: 指定ミリ秒ごとに繰り返し実行
  - `clearInterval(timerId)`: 定期実行タイマーの停止
  - `setTimeout(callback, delayMs)`: 指定ミリ秒後に1回だけ実行
  - `element.addEventListener('mouseenter', ...)`: マウスホバー検知
  - `element.addEventListener('mouseleave', ...)`: マウスアウト検知
- **演習UI・作例**:
  - カウントアップタイマー / ストップウォッチ
  - **自動切り替えスライドショー（基礎）**: 3秒ごとにスライド番号を進め、マウスが乗ったら `clearInterval` で一時停止、離れたら再開

### 単元10: オブジェクトとHTML動的生成
> **目標**: オブジェクトと配列を組み合わせた実務的データ構造を学び、テンプレートリテラルやcreateElementでHTMLを自動生成する。

- **文法・キーワード**:
  - オブジェクトリテラル（`{ key: value, ... }`）
  - プロパティアクセス: ドット記法（`obj.name`）とブラケット記法（`obj['name']`）
  - オブジェクトの配列: `const items = [{ id: 1, ... }, { id: 2, ... }]`
  - テンプレートリテラル（バッククォート `` ` ``、`${...}` 式展開）
  - 動的DOM生成の手法比較（`innerHTML` vs `createElement` vs `<template>`）
- **オブジェクト・メソッド・プロパティ**:
  - `document.createElement('tagName')`: 新規HTML要素ノードの作成
  - `parent.appendChild(childNode)`: 親要素の末尾に子ノードを追加
  - `<template id="...">` タグの概念
  - `template.content.cloneNode(true)`: テンプレートの複製
  - `element.remove()`: 要素をDOMツリーから削除
- **演習UI・作例**:
  - **スライドショーの動的生成**: 画像・タイトル・タグの配列からスライドHTMLを `innerHTML` で一括展開し、インジケーター丸ボタンを `createElement` で枚数分自動生成
  - **モーダルウィンドウ（template複製版）**: クリックしたカードの `dataset` を `<template>` に流し込んで表示し、閉じる時に `remove()` するクリーン設計

### 単元11: 組み込みオブジェクトとスクロール演出
> **目標**: Dateオブジェクトで日時の制御を行い、ブラウザのスクロール量や要素位置を検知してインタラクティブなUIを実装する。

- **文法・キーワード**:
  - 組み込みオブジェクト（Built-in Objects）の概要
  - `new` 演算子によるインスタンス化
  - 画面のスクロール監視とパフォーマンス（`{ passive: true }`）
  - ビューポート（表示領域）と要素の交差判定
- **オブジェクト・メソッド・プロパティ**:
  - **Date オブジェクト**:
    - `new Date()`: 現在日時の取得
    - `getFullYear()`, `getMonth()`（※0始まりの注意点）, `getDate()`, `getDay()`（曜日0〜6）
    - `getHours()`, `getMinutes()`, `getSeconds()`, `getMilliseconds()`
  - **window オブジェクト**:
    - `window.scrollY` / `window.pageYOffset`: 垂直スクロール量
    - `window.innerHeight`: ブラウザ画面の表示高さ
    - `window.addEventListener('scroll', func, { passive: true })`
  - **要素の位置取得**:
    - `element.getBoundingClientRect()`: ビューポート基準の要素位置・サイズ
    - `rect.top`: 画面上端からの距離判定（`rect.top < window.innerHeight`）
- **演習UI・作例**:
  - **リアルタイム時計と本日の日付表示**: 毎秒現在時刻を更新
  - **トップへ戻るボタン**: 300px以上スクロールしたら `is-visible` を付与
  - **スクロール連動フェードイン（getBoundingClientRect版）**: 画面内に入った要素に `.is-visible` を付与

### 単元12: フォーム操作とバリデーション
> **目標**: フォーム送信時の画面遷移をキャンセルし、各入力値の検証とエラー表示、快適な入力体験（UX・アクセシビリティ）を実装する。

- **文法・キーワード**:
  - フォームの送信処理（HTTPリクエストとページリロードの仕組み）
  - `e.preventDefault()` によるデフォルト挙動の停止
  - 入力値の検証（バリデーション）ロジック
  - フラグ管理（`let hasError = false;`）
  - リアルタイム入力フィードバック（UXの重要性）
- **オブジェクト・メソッド・プロパティ**:
  - `form.addEventListener('submit', function)`: 送信イベント
  - `input.value`: 入力テキストの取得
  - `input.value.trim()`: 前後の空白文字の除去
  - `input.value.length`: 文字数カウント
  - `input.value.includes('@')`: 特定文字の含有判定（ES2015+）
  - `input.value.indexOf('@')`: 含有判定の伝統的記法（比較として紹介）
  - `checkbox.checked`: チェックボックスのON/OFF状態（真偽値）
  - `element.focus()`: エラー項目へのフォーカス移動
  - `form.reset()`: フォーム入力値の初期化
  - `input` イベント（入力中のリアルタイム検知） / `change` イベント（状態変更の検知）
- **演習UI・作例**:
  - **お問い合わせフォームの簡易バリデーション**:
    - 名前（必須）、メール（必須＆@含有）、パスワード（6文字以上）、同意チェック
    - エラー時は該当グループに `.is-error` 付与 ＋ 最初のエラー項目へ `.focus()`
    - 入力し直したら `input` イベント委譲で即座にエラー解除
    - 送信成功時にフォームを隠しサンクスカードを表示

## 4. 各単元の授業資料（1回分＝2コマ90分×2）の標準構成テンプレート

講義が一方通行にならず、学生が常に手を動かしながら能動的に学べるよう、**「解説（10〜15分） ＋ ミニワーク（5〜10分）」を細かく繰り返すマイクロハンズオン形式**で統一します。

---

### ① 授業のゴール（Today's Goal）
- その日の180分が終わったときに「何が理解でき、どんなUIが動かせるようになっているか」を冒頭で提示。

---

### ② 冒頭小テスト（Googleフォーム・約15分）
- **形式**: Googleフォームで自動採点（または即時フィードバック）可能な3〜4問。
- **出題パターンのバリエーション**:
  1. **実行結果の予測（推論力）**:
     - 「このコードを実行したとき、Consoleには何と表示されるか？」（例: `'1020'` か `30` か等）
  2. **穴埋め・構文補完（定着度）**:
     - `element.____('click', () => { ... });` の空欄に入るメソッド名（記述式または4択）
  3. **間違い探し・バグ検出（デバッグ力）★おすすめ**:
     - 「このコードでボタンが反応しない原因はどれ？」（例: IDに`#`を書いてしまっている、スペルミス等）
  4. **ベストプラクティス選択（設計力）**:
     - 「テキストだけを変更したいとき、安全性の面から最も推奨されるプロパティはどれ？（`textContent` vs `innerHTML`）」

---

### ③ 本編：マイクロハンズオン（解説 & ミニワークの反復・約120分）
長時間の座学を避け、小さなステップごとに「インプット → 即アウトプット」を繰り返します。

- **【Step 1】最小限の基本構文（解説 10分 ＋ ミニワーク 10分）**:
  - 文法やメソッドの概念を最小限のコードで解説
  - ［ワーク1］ブラウザのコンソールや最小HTMLで動かして動作を確認する
- **【Step 2】UI操作への応用（解説 15分 ＋ ミニワーク 15分）**:
  - HTML要素を取得して操作する連携方法を解説
  - ［ワーク2］指定されたコードを書き換えて、色や文字が変わる体験をする
- **【Step 3】実務的なコンポーネント制作（解説 15分 ＋ 実践ワーク 30分）**:
  - 複数の要素を組み合わせた動くUI（例: ハンバーガー、アコーディオン等）の解説
  - ［ワーク3］完成形を目指して各自コードを組み上げる（机間巡視・個別サポート）

---

### ④ 確認課題（次週提出・約45分）
- **授業内での着手**: 授業の最後の45分で課題に着手させ、分からない点はその場で講師に質問・解決させる。
- **最終課題との接続**: 最終課題の12コンポーネントのパーツそのもの（または類似の発展UI）を課題とし、最終課題への下地を作る。
- **採点基準（ルーブリック）**: 必須要件（60点）、標準要件（80点）、発展要件（100点）を明確に明記。
