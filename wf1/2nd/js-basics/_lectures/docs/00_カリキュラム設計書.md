## 2. 科目のねらい & 技術選定・コーディングルール

### 2-1. 科目のねらい

Webサイト制作におけるJavaScriptの役割（ユーザー操作に応じた動的なUI変化、データに応じたHTMLの動的生成、フォームの入力検証）を理解し、**「外部ライブラリに頼らず、Vanilla JavaScript（素のJS）で実務レベルの主要UIコンポーネントを自力で構築・制御できる実装力」** を身につけることを目的とします。

---

### 2-2. 技術スタックと構文制限（コーディングルール）

学生が自力でコードの因果関係を読み解き、挫折せずに基礎を固められるよう、以下のルールを厳格に適用します。

- **使用言語**: HTML5、CSS3、Vanilla JavaScript（ES2015+）
- **ライブラリの禁止**: jQuery や React、Vue 等のフレームワーク・外部ライブラリは一切使用禁止。
- **構文制限（初学者配慮）**:
  - 三項演算子の多用、アロー関数の極端な省略、`map` / `filter` / `reduce` などの高度な配列高階関数は避ける（これらは2年次で習得）。
  - `let` / `const`, `if` / `switch`, `for` / `while`, `addEventListener`, `setInterval` / `setTimeout`, `parentElement` / `nextElementSibling` 等の基本文法とDOMトラバーサルを中心に構成する。
- **UI状態管理**:
  - スタイル直接変更（`element.style...`）は原則禁止とし、`classList.add` / `remove` / `toggle` による `is-active`, `is-open`, `is-error` などの状態クラス付与でCSSと連携させる。
- **コードの安全性と基本作法**:
  - `<script defer src="...">` の明記（DOM読み込み完了前のスクリプト実行エラー防止）。
  - 各UIコンポーネントの処理ブロック先頭に、何を行っている処理か丁寧な日本語コメントを記述する。

---

### 2-3. 実務に直結する重要トピックと選定理由

実務の制作現場で必須となる以下の5つのトピックを各単元へ自然に組み込んでいます：

1. **カスタムデータ属性（`data-*`）**:
   - タブ切り替えや絞り込み、文字サイズ切り替え等で、HTMLとJavaScript間で安全にデータを受け渡す手法を習得する。
2. **オブジェクトと配列を組み合わせたデータ管理**:
   - スライドショーの画像リストや記事データを `const slides = [{ src: '...', title: '...' }]` のように構造化して管理する実務的アプローチを学ぶ。
3. **テンプレートリテラル（バッククォート `${}`）**:
   - 丸ボタンナビゲーションやカード要素を動的生成する際、古い文字列結合（`+`）ではなく、可読性の高いモダンなHTML生成手法を学ぶ。
4. **イベントオブジェクト（`e.preventDefault()` / `e.target`）**:
   - フォーム送信時の画面遷移キャンセルや、イベント委譲（親要素でのクリック一括検知）に不可欠なイベント制御を学ぶ。
5. **DOMトラバーサル（相対指定）**:
   - アコーディオンやリスト等で、ID決め打ちではなく「クリックされたボタンの親要素・兄弟要素」を相対的に取得する柔軟なコード設計を習得する。

## 4. 全12単元：キーワード・メソッド・プロパティ一覧

### 単元1: JavaScriptの基礎知識・変数・データ型
> **目標**: WebにおけるJSの役割を理解し、ブラウザの開発者ツールで変数とデータ型の出力を扱えるようになる。

- **文法・キーワード**:
  - `let`（再代入可能な変数宣言）
  - `const`（再代入不可の定数宣言・原則こちらを推奨）
  - データ型（Primitive Types）: 文字列（`String`）、数値（`Number`）、真偽値（`Boolean`）、未定義（`undefined`）、空（`null`）
  - 代入演算子（`=`）
  - コメント記法（`//`、`/* */`）
  - セミコロン（`;`）の役割
  - `<script defer src="...">` の配置と読み込みタイミング
- **オブジェクト・メソッド・プロパティ**:
  - `console.log()`: コンソールへの通常出力
  - `console.dir()`: オブジェクト構造のツリー出力
  - `console.error()`: エラーの出力確認
- **演習UI・作例**:
  - コンソール上での計算・変数代入・文字列連結のテスト

---

### 単元2: DOMの取得と要素の書き換え
> **目標**: DOMツリーの仕組みを理解し、JSから特定のHTML要素を取得してテキストやHTMLを動的に書き換えることができる。

- **文法・キーワード**:
  - DOM（Document Object Model）の構造とツリー階層
  - ノード（Node）と要素（Element）の違い
- **オブジェクト・メソッド・プロパティ**:
  - `document.getElementById('id名')`: IDによる単一要素取得
  - `document.querySelector('CSSセレクタ')`: CSSセレクタによる単一要素取得
  - `element.textContent`: 要素内のテキスト読み取り・書き換え（安全・エスケープ不要）
  - `element.innerHTML`: 要素内のHTML構文を含む書き換え（※XSSの注意点も併記）
- **演習UI・作例**:
  - ボタンを押すと指定の見出しテキストやメッセージが動的に書き換わるUI

---

### 単元3: イベント処理とクラス操作によるUI切替
> **目標**: ユーザーの操作（クリック）を検知し、CSSクラスを付け外しすることで、見た目や表示状態を安全に切り替えることができる。

- **文法・キーワード**:
  - イベント駆動型プログラミング（イベントリスナー）
  - コールバック関数（無名関数・アロー関数）
  - セパレーション・オブ・コンサーンズ（JSでスタイルを直書きせず、CSSクラスで状態管理する意義）
- **オブジェクト・メソッド・プロパティ**:
  - `element.addEventListener('click', callback)`
  - `element.classList.add('クラス名')`: クラス追加
  - `element.classList.remove('クラス名')`: クラス削除
  - `element.classList.toggle('クラス名')`: クラスのON/OFF切り替え
  - `element.classList.contains('クラス名')`: クラス所持の真偽値判定
- **演習UI・作例**:
  - **ハンバーガーメニューの開閉（初歩）**: ボタンクリックでメニューに `.is-open` をトグル

---

### 単元4: 条件分岐（if文）と属性操作
> **目標**: 状態やユーザーの入力に応じた条件分岐を実装し、HTML属性の取得・設定ができるようになる。

- **文法・キーワード**:
  - `if` / `else if` / `else`
  - 比較演算子（`===`, `!==`, `<`, `>`, `<=`, `>=` ※厳密等価の推奨）
  - 論理演算子（`&&`, `||`, `!`）
  - `switch` / `case` / `break` / `default`
- **オブジェクト・メソッド・プロパティ**:
  - `element.getAttribute('属性名')`: 属性値の取得
  - `element.setAttribute('属性名', '値')`: 属性値の設定
  - `element.removeAttribute('属性名')`: 属性の削除
  - `element.hasAttribute('属性名')`: 属性の存在判定
- **演習UI・作例**:
  - **パスワードの表示/非表示切り替え**: `input` の `type="password"` と `type="text"` を切り替え
  - **文字サイズ変更ボタン**: `data-size` 属性を読み取ってルートの属性を切り替え

### 単元5: 配列と繰り返し処理（for文）
> **目標**: 複数のデータを配列で管理し、`for` ループを用いて複数のHTML要素へ一括でイベントや処理を適用できるようになる。

- **文法・キーワード**:
  - 配列（Array）の宣言（`const list = [...]`）
  - インデックス（0始まりの添字）
  - `array.length`: 配列の要素数
  - `for` 文ループ（初期化; 条件式; 増分）
  - `for...of` 文（配列の各要素に対する反復）
- **オブジェクト・メソッド・プロパティ**:
  - `document.querySelectorAll('CSSセレクタ')`: 複数要素の取得（NodeList）
  - `NodeList.length`
- **演習UI・作例**:
  - 画面上にある複数のカードやリストアイテムすべてに、ループで一括してクリックイベントを登録

---

### 単元6: ループの応用とMathオブジェクト
> **目標**: `while` ループの制御と組み込みの `Math` オブジェクトを組み合わせ、ランダム抽選や重複防止ロジックを実装できる。

- **文法・キーワード**:
  - `while` 文（条件が満たされている間の繰り返し）
  - 無限ループの危険性と回避策（終了条件の担保）
  - インデックスのランダム生成
- **オブジェクト・メソッド・プロパティ**:
  - `Math.random()`: 0以上1未満の疑似乱数生成
  - `Math.floor()`: 切り捨て
  - `Math.ceil()`: 切り上げ
  - `Math.round()`: 四捨五入
  - `Math.floor(Math.random() * N)`: 0〜N-1のランダム整数生成
- **演習UI・作例**:
  - **ランダム背景画像（直前と同じ画像が出ない重複防止ロジック付き）**

### 単元7: 関数の定義と活用（引数・戻り値）
> **目標**: 処理を関数として部品化し、引数（パラメータ）と戻り値（return）を使って柔軟に再利用できるコード設計を身につける。

- **文法・キーワード**:
  - 関数宣言（`function name() { ... }`）
  - 関数式（`const name = function() { ... }`）
  - アロー関数（`const name = () => { ... }`）
  - 仮引数と実引数
  - デフォルト引数
  - `return` 文による値の返却と処理の終了
  - スコープ（ローカルスコープとグローバルスコープ）
- **演習UI・作例**:
  - メニュー開閉関数、モーダル表示/非表示関数など、開閉処理を汎用関数にまとめて呼び出すリファクタリング

### 単元8: DOMトラバーサルとイベント委譲
> **目標**: 親・子・兄弟要素を辿るDOMトラバーサルと、動的な要素や大量の要素を効率よく制御するイベント委譲を習得する。

- **文法・キーワード**:
  - DOMトラバーサル（相対指定）の重要性
  - イベントバブリング（子要素から親要素へイベントが伝播する仕組み）
  - イベント委譲（親要素1箇所で子要素のイベントを一括監視するテクニック）
- **オブジェクト・メソッド・プロパティ**:
  - `element.parentElement`: 親要素の取得
  - `element.nextElementSibling`: 次の兄弟要素の取得
  - `element.previousElementSibling`: 前の兄弟要素の取得
  - `element.closest('セレクタ')`: 最も近い祖先要素の検索
  - `event.target`: イベントが発生した実際の要素
  - `event.currentTarget`: イベントリスナーが登録されている要素
- **演習UI・作例**:
  - **アコーディオンパネル（複数配置）**: クリックしたヘッダーの隣にある本文パネルだけを開閉
  - **モーダルウィンドウ**: 背景オーバーレイまたは閉じるボタンのクリックで閉じる

---

### 単元9: タイマー処理と非同期アニメーション
> **目標**: 一定時間ごとの繰り返し処理や遅延処理を制御し、自動再生スライドショーなどの時間連動UIを実装できる。

- **文法・キーワード**:
  - 非同期処理の第一歩（タイマーAPI）
  - タイマーIDの保持と解除の重要性
- **オブジェクト・メソッド・プロパティ**:
  - `setInterval(func, delay)`: 一定間隔での繰り返し実行
  - `clearInterval(timerId)`: 繰り返しタイマーの解除
  - `setTimeout(func, delay)`: 一定時間後の単発実行
  - `clearTimeout(timerId)`: 単発タイマーのキャンセル
  - `mouseenter` / `mouseleave` イベント
- **演習UI・作例**:
  - **自動スライドショー**: 3秒ごとに画像が切り替わり、マウスホバーで一時停止、マウスが離れたら再開

### 単元10: オブジェクトとHTML動的生成
> **目標**: 構造化されたデータをオブジェクト配列として管理し、テンプレートリテラルを用いてHTML要素を動的に生成・描画できる。

- **文法・キーワード**:
  - オブジェクトリテラル（`{ key: value }`）
  - プロパティの参照（ドット記法・ブラケット記法）
  - オブジェクト配列（`[ { ... }, { ... } ]`）
  - テンプレートリテラル（バッククォート `` ` `` と `${式}`）
- **オブジェクト・メソッド・プロパティ**:
  - `document.createElement('タグ名')`
  - `element.append()` / `element.appendChild()`
  - `dataset` プロパティ（`element.dataset.hoge` による `data-hoge` の読み書き）
- **演習UI・作例**:
  - スライドショーの画像一覧データから、丸ボタンナビゲーション（インジケーター）やスライドHTMLを枚数分自動生成する

### 単元11: 組み込みオブジェクトとスクロール演出
> **目標**: `Date` オブジェクトによる時刻の扱い、およびスクロールイベントと要素の位置判定を用いたページ演出を実装できる。

- **文法・キーワード**:
  - 組み込みオブジェクトの活用
  - スクロール連動処理のパフォーマンス考慮（パッシブリスナー）
- **オブジェクト・メソッド・プロパティ**:
  - **Date オブジェクト**:
    - `new Date()`: 現在日時の取得
    - `getFullYear()`, `getMonth()`（※0始まりの注意点）, `getDate()`, `getDay()`（曜日0〜6）
    - `getHours()`, `getMinutes()`, `getSeconds()`
    - `String(n).padStart(2, '0')`: 2桁ゼロ埋め
  - **window オブジェクト**:
    - `window.scrollY` / `window.pageYOffset`: 垂直スクロール量
    - `window.innerHeight`: ブラウザ画面の表示高さ
    - `window.addEventListener('scroll', func, { passive: true })`
  - **要素の位置取得**:
    - `element.getBoundingClientRect()`: ビューポート基準の要素位置・サイズ
    - `rect.top`: 画面上端からの距離判定（`rect.top < window.innerHeight`）
- **演習UI・作例**:
  - **リアルタイム時計と本日の日付表示**: 毎秒現在時刻を更新
  - **トップへ戻るボタン**: 300px以上スクロールしたら `.is-visible` を付与
  - **スクロール連動フェードイン**: 画面内に入った要素に `.is-visible` を付与してCSSアニメーション

### 単元12: フォーム操作とバリデーション
> **目標**: フォーム送信時の画面遷移をキャンセルし、各入力値の検証とエラー表示、快適な入力体験（UX・アクセシビリティ）を実装できる。

- **文法・キーワード**:
  - フォームの送信処理（HTTPリクエストとページリロードの仕組み）
  - `e.preventDefault()` によるデフォルト挙動の停止
  - 入力値の検証（バリデーション）ロジック
  - フラグ管理（`let hasError = false;`）
  - リアルタイム入力フィードバック（UXの重要性）
- **オブジェクト・メソッド・プロパティ**:
  - `form.addEventListener('submit', function)`: 送信イベント
  - `input.value`: 入力テキストの取得
  - `input.value.trim()`: 前後の空白文字の除去
  - `input.value.length`: 文字数カウント
  - `input.value.includes('@')`: 特定文字の含有判定
  - `checkbox.checked`: チェックボックスのON/OFF状態（真偽値）
  - `element.focus()`: エラー項目へのフォーカス移動
  - `form.reset()`: フォーム入力値の初期化
  - `input` イベント（入力中のリアルタイム検知）
- **演習UI・作例**:
  - **お問い合わせフォームの簡易バリデーション**:
    - 名前（必須）、メール（必須＆@含有）、同意チェックの検証
    - エラー時は該当グループに `.is-error` 付与 ＋ 最初のエラー項目へ `.focus()`
    - 入力し直したら即座にエラー解除、送信成功時にサンクスカードを表示

講義が教員からの一方通行にならず、学生が常に手を動かしながら能動的に学べるよう、**「解説（10〜15分） ＋ ミニワーク（5〜10分）」を細かく繰り返すマイクロハンズオン形式** で統一します。

---

### ① 授業のゴール（Today's Goal: 約5分）
- その日の180分が終わったときに「何が理解でき、どんなUIが動かせるようになっているか」を冒頭で提示（箇条書き3〜5点）。

---

### ② 冒頭小テスト（Googleフォーム: 約15分）
- **形式**: Googleフォームで自動採点可能な3〜4問。
- **出題パターン**:
  1. **実行結果の予測**: 「このコードを実行したとき、コンソールには何と出力されるか？」
  2. **穴埋め・構文補完**: `element.____('click', () => { ... });` の空欄補充
  3. **間違い探し・バグ検出**: 「ボタンが反応しない原因はどこか？（セレクタ指定ミス、スペルミス等）」
  4. **設計ベストプラクティス**: 「`textContent` と `innerHTML` の使い分けの安全性」

---

### ③ 本編：マイクロハンズオン（解説 & ミニワーク反復: 約120分）
長時間の座学を排し、「インプット → 即アウトプット」を15〜20分サイクルで反復します。
- **【Step 1】最小限の基本構文（解説 10分 ＋ ミニワーク 10分）**: 文法やメソッドの概念を最小コードで検証。
- **【Step 2】UI操作への応用（解説 15分 ＋ ミニワーク 15分）**: HTML要素を取得して色や文字を変える体験。
- **【Step 3】実務的なコンポーネント制作（解説 15分 ＋ 実践ワーク 30分）**: ハンバーガーやアコーディオン等の完成形を組み上げる。

---

### ④ 確認課題（約45分）
- **授業内での着手**: 最後の45分で課題に着手させ、つまずいた点はその場で講師に質問・解決させる。
- **採点基準（ルーブリック）**:
  - **必須要件（60点）**: 基本的な文法通りに動作し、コンソールにエラーがないこと。
  - **標準要件（80点）**: クラス操作（CSS分離）でUI状態が管理され、コードのインデントが整っていること。
  - **発展要件（100点）**: アクセシビリティ（aria属性）やUX（例外処理・フォーカス移動）への配慮がなされていること。
