## ⭐︎ 課題：いいねボタンとカウント表示を実装しよう（単元1・2・3）

ボタンをクリックするたびに「いいね」のON / OFFを切り替え、同時にいいねの合計件数をカウントして表示するUIを実装しましょう。

### 仕様・要件

1. いいね件数表示（`#like-status`）といいねボタン（`#like-btn`）を取得してください。
2. 現在のいいね数を記録する変数 `likeCount`（初期値 `0`）を用意してください。
3. ボタンがクリックされたときに以下の処理を実行してください。
	- `#like-btn` の `.is-liked` クラスを切り替える（`classList.toggle`）。
	- もしボタンに `.is-liked` クラスが付いている状態になったら、`likeCount` を `1` 増やし、ボタンの文字を `'♥ いいね済み'` に変更する。
	- そうでない状態（解除されたとき）は、`likeCount` を `1` 減らし、ボタンの文字を `'♡ いいねする'` に戻す。
	- `#like-status` のテキストを `現在のいいね数：〇〇件` の形式で更新する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- クラスが付いているかどうかの判定には `likeBtn.classList.contains('is-liked')` を使用します。
	- 文字列の中に変数の値を埋め込むには、テンプレートリテラル（`` `現在のいいね数：${likeCount}件` ``）が便利です。
</callout>

- 正解のソースコード（practice01/js/main.js）

```javascript
// 課題1：いいねボタン＆カウント
const likeStatus = document.getElementById('like-status');
const likeBtn = document.getElementById('like-btn');

let likeCount = 0;

likeBtn.addEventListener('click', () => {
  likeBtn.classList.toggle('is-liked');

  if (likeBtn.classList.contains('is-liked')) {
    likeCount++;
    likeBtn.textContent = '♥ いいね済み';
  } else {
    likeCount--;
    likeBtn.textContent = '♡ いいねする';
  }

  likeStatus.textContent = `現在のいいね数：${likeCount}件`;
});
```

## ⭐︎ 課題：ポイントに応じて会員ランクを判定しよう（単元4：if文）

「+15pt 獲得」ボタンを押すたびにポイントを加算し、合計ポイントに応じて会員ランクのテキストとバッジの色クラスを切り替えるUIを実装しましょう。

### 仕様・要件

1. ポイント表示（`#point-display`）、ランクバッジ（`#rank-badge`）、加算ボタン（`#add-point-btn`）、リセットボタン（`#reset-point-btn`）を取得してください。
2. 現在のポイントを保持する変数 `points`（初期値 `0`）を用意してください。
3. 「+15pt 獲得」ボタンがクリックされたときに以下の処理を実行してください。
	- `points` に `15` を加算し、`#point-display` を `現在のポイント：〇〇pt` に更新する。
	- まず `#rank-badge` から `.is-silver` と `.is-gold` のクラスを削除してリセットする。
	- 条件分岐を使い、ポイントに応じてランクを切り替える：
		- `60` ポイント以上の場合：テキストを `'ゴールド会員'` にし、`.is-gold` クラスを追加する。
		- `30` ポイント以上の場合：テキストを `'シルバー会員'` にし、`.is-silver` クラスを追加する。
		- それ以外（`30` 未満）の場合：テキストを `'ブロンズ会員'` にする。
4. 「リセット」ボタンがクリックされたときは、`points` を `0` に戻し、表示を `'現在のポイント：0pt'`・`'ブロンズ会員'` に戻して `.is-silver` と `.is-gold` クラスを削除してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- `if (points >= 60)` を先に判定し、その次に `else if (points >= 30)` を判定することで、30〜59ptの範囲を綺麗に振り分けることができます。
</callout>

- 正解のソースコード（practice01/js/main.js に追記）

```javascript
// 課題2：会員ランク判定
const pointDisplay = document.getElementById('point-display');
const rankBadge = document.getElementById('rank-badge');
const addPointBtn = document.getElementById('add-point-btn');
const resetPointBtn = document.getElementById('reset-point-btn');

let points = 0;

addPointBtn.addEventListener('click', () => {
  points += 15;
  pointDisplay.textContent = `現在のポイント：${points}pt`;

  rankBadge.classList.remove('is-silver', 'is-gold');

  if (points >= 60) {
    rankBadge.textContent = 'ゴールド会員';
    rankBadge.classList.add('is-gold');
  } else if (points >= 30) {
    rankBadge.textContent = 'シルバー会員';
    rankBadge.classList.add('is-silver');
  } else {
    rankBadge.textContent = 'ブロンズ会員';
  }
});

resetPointBtn.addEventListener('click', () => {
  points = 0;
  pointDisplay.textContent = '現在のポイント：0pt';
  rankBadge.textContent = 'ブロンズ会員';
  rankBadge.classList.remove('is-silver', 'is-gold');
});
```

## ⭐︎ 課題：パスワードの表示・非表示を切り替えよう（単元4：属性操作）

「表示する」ボタンをクリックするたびに、パスワード入力欄の伏字（`type="password"`）と平文（`type="text"`）を切り替えるUIを実装しましょう。

### 仕様・要件

1. パスワード入力欄（`#password-input`）と切り替えボタン（`#toggle-pw-btn`）を取得してください。
2. ボタンがクリックされたときに以下の処理を実行してください。
	- `#password-input` の現在の `type` 属性の値を取得する。
	- もし `type` 属性が `'password'` だった場合は、`type` 属性を `'text'` に書き換え、ボタンの文字を `'隠す'` に変更する。
	- そうでなければ、`type` 属性を `'password'` に書き換え、ボタンの文字を `'表示する'` に戻す。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 属性値の取得には `getAttribute('type')`、属性値の設定には `setAttribute('type', '値')` を使用します。
</callout>

- 正解のソースコード（practice01/js/main.js に追記）

```javascript
// 課題3：パスワード表示切り替え
const passwordInput = document.getElementById('password-input');
const togglePwBtn = document.getElementById('toggle-pw-btn');

togglePwBtn.addEventListener('click', () => {
  const currentType = passwordInput.getAttribute('type');

  if (currentType === 'password') {
    passwordInput.setAttribute('type', 'text');
    togglePwBtn.textContent = '隠す';
  } else {
    passwordInput.setAttribute('type', 'password');
    togglePwBtn.textContent = '表示する';
  }
});
```

## ⭐︎ 課題：配列とfor文を使って持ち物リストを追加・表示しよう（単元5）

入力欄に持ち物を入力して「追加」ボタンを押すと、配列にデータを追加し、`for` 文を使って一覧（`<ul>`）を画面に表示するUIを実装しましょう。

### 仕様・要件

1. 入力欄（`#item-input`）、追加ボタン（`#add-item-btn`）、リスト表示エリア（`#item-list`）を取得してください。
2. 持ち物データを管理する空の配列 `items` を用意してください。
3. 追加ボタンがクリックされたときに以下の処理を実行してください。
	- 入力欄の値（`.value`）が空白でない場合のみ処理を実行する。
	- 入力された文字列を配列 `items` の末尾に追加する。
	- 入力欄を空（`''`）にリセットする。
	- `<li>〇〇</li>` のHTML文字列を組み立てるため、`for` 文を使って配列 `items` の全要素を順番に連結し、`#item-list` の `innerHTML` に反映する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 配列の末尾への追加は `items.push(値)` を使います。
	- `for` 文の中で `html += \`<li>${items[i]}</li>\`;` のように文字列を溜めていき、ループ終了後に `itemList.innerHTML = html;` で流し込むと画面にリストが表示されます。
</callout>

- 正解のソースコード（practice01/js/main.js に追記）

```javascript
// 課題4：持ち物リスト追加
const itemInput = document.getElementById('item-input');
const addItemBtn = document.getElementById('add-item-btn');
const itemList = document.getElementById('item-list');

const items = [];

addItemBtn.addEventListener('click', () => {
  const newItem = itemInput.value;

  if (newItem !== '') {
    items.push(newItem);
    itemInput.value = '';

    let listHtml = '';
    for (let i = 0; i < items.length; i++) {
      listHtml += `<li>${items[i]}</li>`;
    }
    itemList.innerHTML = listHtml;
  }
});
```

## ⭐︎ 課題：複数ボタンの排他制御でサイズ選択を作ろう（単元5：querySelectorAll）

並んだ4つのサイズボタン（S / M / L / XL）のうち、クリックされた1つだけをアクティブ（`.is-active`）にし、選ばれたサイズ名を表示するUIを実装しましょう。

### 仕様・要件

1. すべてのサイズボタン（`.size-btn`）を `querySelectorAll` で取得し、結果表示要素（`#size-result`）も取得してください。
2. `for` 文を使ってすべての `.size-btn` にクリックイベントを登録してください。
3. いずれかのボタンがクリックされたときに以下の処理を実行してください。
	- `for` 文を使って、すべての `.size-btn` から `.is-active` クラスを削除してリセットする。
	- クリックされたボタン（`sizeBtns[i]`）だけに `.is-active` クラスを追加する。
	- `#size-result` のテキストを `選択中のサイズ：〇〇`（クリックされたボタンの文字）に更新する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- イベントを登録する `for` 文の変数 `i` と、クリックイベント内でクラスをリセットする `for` 文の変数が同じ `i` だとぶつかってしまいます。内側のループには `let j = 0;` のように別の変数名を使いましょう。
</callout>

- 正解のソースコード（practice01/js/main.js に追記）

```javascript
// 課題5：Tシャツサイズ選択（排他制御）
const sizeBtns = document.querySelectorAll('.size-btn');
const sizeResult = document.getElementById('size-result');

for (let i = 0; i < sizeBtns.length; i++) {
  sizeBtns[i].addEventListener('click', () => {
    for (let j = 0; j < sizeBtns.length; j++) {
      sizeBtns[j].classList.remove('is-active');
    }
    sizeBtns[i].classList.add('is-active');
    sizeResult.textContent = `選択中のサイズ：${sizeBtns[i].textContent}`;
  });
}
```

## ⭐︎ 課題：while文を使って連続重複なしでテーマカラーを切り替えよう（単元6）

「テーマを切り替える」ボタンを押すたびに、セクションの背景テーマクラスと表示名をランダムに切り替え、**直前と同じテーマが2回連続で出ないように** 実装しましょう。

### 仕様・要件

1. セクション全体（`#theme-box`）、テーマ名表示（`#theme-name`）、切り替えボタン（`#theme-btn`）を取得してください。
2. 以下の2つの配列を用意してください：
	- クラス名の配列：`['theme-blue', 'theme-green', 'theme-pink', 'theme-dark']`
	- テーマ名の配列：`['オーシャンブルー', 'フォレストグリーン', 'サクラピンク', 'ナイトダーク']`
3. 直前に選ばれたインデックス番号を保持する変数 `lastThemeIndex`（初期値 `-1`）を用意してください。
4. ボタンがクリックされたときに以下の処理を実行してください。
	- まずランダムなインデックス番号 `newIndex` を1つ生成し、`while` 文を使って `lastThemeIndex` と異なる番号になるまで再抽選する。
	- `#theme-box` から既存のテーマクラス（4種類すべて）を一旦削除してリセットする。
	- 選ばれたクラス名（`themeClasses[newIndex]`）を追加し、`#theme-name` を `現在のテーマ：〇〇` に更新する。
	- 今回選ばれた `newIndex` を `lastThemeIndex` に保存する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- `while (newIndex === lastThemeIndex)` と書くことで、直前と同じ番号が出たときだけループ内で再度ランダムな番号を引き直します。
</callout>

- 正解のソースコード（practice02/js/main.js に追記）

```javascript
// 課題7：連続重複防止テーマカラー切り替え
const themeBox = document.getElementById('theme-box');
const themeName = document.getElementById('theme-name');
const themeBtn = document.getElementById('theme-btn');

const themeClasses = ['theme-blue', 'theme-green', 'theme-pink', 'theme-dark'];
const themeLabels = ['オーシャンブルー', 'フォレストグリーン', 'サクラピンク', 'ナイトダーク'];

let lastThemeIndex = -1;

themeBtn.addEventListener('click', () => {
  let newIndex = Math.floor(Math.random() * themeClasses.length);

  while (newIndex === lastThemeIndex) {
    newIndex = Math.floor(Math.random() * themeClasses.length);
  }

  themeBox.classList.remove('theme-blue', 'theme-green', 'theme-pink', 'theme-dark');
  themeBox.classList.add(themeClasses[newIndex]);
  themeName.textContent = `現在のテーマ：${themeLabels[newIndex]}`;

  lastThemeIndex = newIndex;
});
```

## ⭐︎ 課題：splice()を使って二度と当たらない景品ガチャを作ろう（単元6）

「ガチャを引く」ボタンを押すと、配列の中から景品が1つ選ばれて削除され、すべての景品が出尽くしたらボタンを無効化するUIを実装しましょう。

### 仕様・要件

1. 結果表示（`#gacha-result`）、残り個数表示（`#gacha-remaining`）、ガチャボタン（`#gacha-btn`）を取得してください。
2. 4つの景品が入った配列 `prizes`（例：`['特賞：ワイヤレスヘッドホン', '1等：ギフト券', '2等：マグカップ', '3等：ステッカー']`）を用意してください。
3. ボタンがクリックされたときに、配列にまだ景品が残っている場合（`prizes.length > 0`）のみ以下の処理を実行してください。
	- 残っている配列の要素数をもとにランダムなインデックスを生成する。
	- `.splice()` を使って配列から選ばれた景品を1つ取り出して削除し、`#gacha-result` に表示する。
	- 残りの景品数が `0` より大きければ `#gacha-remaining` に `残りの景品：〇〇個` と表示する。
	- 残りの景品数が `0` になった場合は、`#gacha-remaining` に `'すべての景品が終了しました'` と表示し、ガチャボタンに `disabled` 属性を設定して無効化する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- `const picked = prizes.splice(randomIndex, 1)[0];` のように書くと、配列から削除すると同時に、取り出された景品の文字列を取得できます。

```javascript
const gachaRemaining = document.getElementById('gacha-remaining');
const gachaBtn = document.getElementById('gacha-btn');

const prizes = [
  '特賞：ワイヤレスヘッドホン',

      gachaRemaining.textContent = 'すべての景品が終了しました';

    }
  }
```

## ⭐︎ 課題：引数とreturnを使った割引価格計算関数を作ろう（単元7）

定価と割引率（%）を受け取って割引後の価格を計算し、`return` で返す共通関数を作成して、2つの商品ボタンから呼び出してみましょう。

### 仕様・要件

1. 計算結果表示エリア（`#discount-result`）、2つのボタン（`#item-a-btn`, `#item-b-btn`）を取得してください。
2. 定価（`price`）と割引率（`rate`：例 `20`）の2つの引数を受け取るアロー関数 **`calcDiscountPrice`** を定義してください。
	- 割引後の価格（`price * (100 - rate) / 100`）を計算し、`Math.floor()` で小数点以下を切り捨てた整数を `return` で返すこと。
3. 「スニーカー（10,000円 / 20%OFF）」ボタンがクリックされたときは、`calcDiscountPrice` に `10000` と `20` を渡して計算結果を受け取り、`#discount-result` に `割引後価格：8000円` の形式で表示してください。
4. 「ジャケット（15,000円 / 30%OFF）」ボタンがクリックされたときは、`calcDiscountPrice` に `15000` と `30` を渡して計算結果を受け取り、`#discount-result` に `割引後価格：10500円` の形式で表示してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 計算ロジックを `calcDiscountPrice` 関数1箇所にまとめることで、商品ボタンが増えても毎回計算式を書く必要がなくなります。
</callout>

- 正解のソースコード（practice02/js/main.js に追記）

```javascript
// 課題9：セール割引シミュレーター（引数とreturn）
const discountResult = document.getElementById('discount-result');
const itemABtn = document.getElementById('item-a-btn');
const itemBBtn = document.getElementById('item-b-btn');

const calcDiscountPrice = (price, rate) => {
  return Math.floor(price * (100 - rate) / 100);
};

itemABtn.addEventListener('click', () => {
  const finalPrice = calcDiscountPrice(10000, 20);
  discountResult.textContent = `割引後価格：${finalPrice}円`;
});

itemBBtn.addEventListener('click', () => {
  const finalPrice = calcDiscountPrice(15000, 30);
  discountResult.textContent = `割引後価格：${finalPrice}円`;
});
```

## ⭐︎ 練習（発展演習）：早期リターンでパスワードの登録チェックを作ろう

メインと確認用の2つのパスワード入力欄の内容を順番に検証し、条件をすべて満たしたときだけ「登録する」ボタンを有効化する関数を実装しましょう。

### 仕様・要件

1. 2つの入力欄（`#pw-main`, `#pw-confirm`）、メッセージ表示（`#pw-message`）、チェックボタン（`#pw-check-btn`）、登録ボタン（`#pw-submit-btn`）を取得してください。
2. メッセージ内容（`text`）とエラー状態かどうか（`isError`：真偽値）の2つの引数を受け取る共通関数 **`showPwMessage`** を定義してください：
	- `#pw-message` から `.is-error` と `.is-ok` を削除し、テキストを `text` に書き換える。
	- もし `isError` が `true` なら `.is-error` を付け、登録ボタンに `disabled` 属性を設定（無効化）する。
	- そうでなければ `.is-ok` を付け、登録ボタンの `disabled` 属性を削除（有効化）する。
3. 「チェックする」ボタンがクリックされたときに実行する判定関数（またはイベント内処理）で、以下の順番にチェックし、問題があれば **`return`** で処理を中断してください：
	- どちらかの入力欄が空（`=== ''`）の場合：「両方のパスワードを入力してください」とエラー表示して終了。
	- メインのパスワードが8文字未満（`.length < 8`）の場合：「8文字以上で入力してください」とエラー表示して終了。
	- 2つのパスワードが一致しない（`!==`）の場合：「確認用パスワードが一致しません」とエラー表示して終了。
	- すべてクリアした場合：「登録可能な安全なパスワードです」とOK表示にする。
4. 有効化された「登録する」ボタンがクリックされたときは、`#pw-message` に `'登録が完了しました'` と表示してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- エラー表示のたびにクラス操作と `disabled` 操作を何度も書くのではなく、`showPwMessage('エラー文', true)` のように共通関数に任せることで、判定処理が非常にすっきり見やすくなります。
	- チェック処理自体を `validatePassword` 関数として切り出しておくと、途中で `return;` を使って綺麗に処理を中断（早期リターン）できます。
</callout>

- 正解のソースコード（practice03/js/main.js）

```javascript
// チャレンジ1：パスワード検証＆確認一致チェック
const pwMain = document.getElementById('pw-main');
const pwConfirm = document.getElementById('pw-confirm');
const pwMessage = document.getElementById('pw-message');
const pwCheckBtn = document.getElementById('pw-check-btn');
const pwSubmitBtn = document.getElementById('pw-submit-btn');

const showPwMessage = (text, isError) => {
  pwMessage.classList.remove('is-error', 'is-ok');
  pwMessage.textContent = text;

  if (isError) {
    pwMessage.classList.add('is-error');
    pwSubmitBtn.setAttribute('disabled', 'true');
  } else {
    pwMessage.classList.add('is-ok');
    pwSubmitBtn.removeAttribute('disabled');
  }
};

const validatePassword = () => {
  const val1 = pwMain.value;
  const val2 = pwConfirm.value;

  if (val1 === '' || val2 === '') {
    showPwMessage('両方のパスワードを入力してください', true);
    return;
  }

  if (val1.length < 8) {
    showPwMessage('8文字以上で入力してください', true);
    return;
  }

  if (val1 !== val2) {
    showPwMessage('確認用パスワードが一致しません', true);
    return;
  }

  showPwMessage('登録可能な安全なパスワードです', false);
};

pwCheckBtn.addEventListener('click', () => {
  validatePassword();
});

pwSubmitBtn.addEventListener('click', () => {
  pwMessage.textContent = '登録が完了しました';
});
```

## ⭐︎ 練習（発展演習）：複数条件と複数引数で映画チケット料金を計算しよう

「券種選択」「レイトショー割引のON/OFF」「枚数（1〜6枚）」の3つの状態に応じて、合計金額をリアルタイムに計算・表示するUIを実装しましょう。

### 仕様・要件

3. 単価・枚数・割引フラグの3つの引数を受け取り、合計金額を計算して **`return`** する関数 **`calcTicketPrice`** を定義してください：
	- まず `unitPrice * count` で基本料金を計算する。
	- もし `isLateShow` が `true` なら、20%OFF（`* 0.8`）して `Math.floor()` で切り捨てる。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 真偽値（`true` / `false`）を反転させるには、`isLateShow = !isLateShow;` と記述します。
	- 最初に `updateTicketView();` を1回呼び出しておくと、初期状態でも「一般」ボタンが `.is-active` になった状態でスタートできます。

```javascript
// チャレンジ2：映画チケット料金シミュレーター
const ticketTypeBtns = document.querySelectorAll('.ticket-type-btn');
const lateShowBtn = document.getElementById('late-show-btn');
const ticketMinus = document.getElementById('ticket-minus');
const ticketPlus = document.getElementById('ticket-plus');
const ticketCountEl = document.getElementById('ticket-count');
const ticketTotalEl = document.getElementById('ticket-total');

const ticketPrices = [1800, 1500, 1000];
let ticketIndex = 0;
let ticketCount = 1;
let isLateShow = false;

const calcTicketPrice = (unitPrice, count, lateFlag) => {
  let total = unitPrice * count;
  if (lateFlag) {
    total = Math.floor(total * 0.8);
  }
  return total;
};

const updateTicketView = () => {
  for (let i = 0; i < ticketTypeBtns.length; i++) {
    ticketTypeBtns[i].classList.remove('is-active');
  }
  ticketTypeBtns[ticketIndex].classList.add('is-active');

  ticketCountEl.textContent = ticketCount;
  const finalTotal = calcTicketPrice(ticketPrices[ticketIndex], ticketCount, isLateShow);
  ticketTotalEl.textContent = `合計：${finalTotal}円`;
};

updateTicketView();

for (let i = 0; i < ticketTypeBtns.length; i++) {
  ticketTypeBtns[i].addEventListener('click', () => {
    ticketIndex = i;
    updateTicketView();
  });
}

lateShowBtn.addEventListener('click', () => {
  isLateShow = !isLateShow;
  lateShowBtn.classList.toggle('is-on');

  if (isLateShow) {
    lateShowBtn.textContent = 'レイトショー割引（20%OFF）：ON';
  } else {
    lateShowBtn.textContent = 'レイトショー割引（20%OFF）：OFF';
  }

  updateTicketView();
});

ticketPlus.addEventListener('click', () => {
  if (ticketCount < 6) {
    ticketCount++;
    updateTicketView();
  }
});

ticketMinus.addEventListener('click', () => {
  if (ticketCount > 1) {
    ticketCount--;
    updateTicketView();
  }
});
```

	- `for` 文を使い、`1` から `15` までの数字を `bingoNumbers` に順番に `.push()` する。
	- 画面表示（現在番号 `-`、残り `残り：15個`、履歴エリア `''`）をリセットし、引くボタンの `disabled` 属性を削除（`removeAttribute`）する。
4. ページ読み込み時に `initBingo()` を呼び出して初期準備を行ってください。
5. 「番号を引く」ボタンがクリックされたとき（`bingoNumbers.length > 0` の場合）：
	- `bingoNumbers` からランダムなインデックスを選んで `.splice()` で1つ取り出す。
	- 取り出した数字を `drawnNumbers` に `.push()` し、`#bingo-current` に表示する。
	- `for` 文を使って `drawnNumbers` の中身を `<span class="ball">〇〇</span>` の形式で連結し、`#bingo-history` の `innerHTML` に表示する。
	- 残り個数が `0` になったら、`#bingo-remaining` を `'すべて引き終わりました'` にし、引くボタンを `disabled` にする。
6. 「リセット」ボタンがクリックされたときは、`initBingo()` を呼び出して最初からやり直せるようにしてください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- `initBingo` 関数の中で `for (let i = 1; i <= 15; i++)` と書けば、1から15までの数字を配列へ手打ちせずに自動作成できます。
	- `removeAttribute('disabled')` を使うと、一度無効化したボタンを再びクリック可能な状態に戻せます。
</callout>

- 正解のソースコード（practice03/js/main.js に追記）

```javascript
// チャレンジ3：ビンゴ番号抽選機（1〜15・履歴＆リセット付き）
const bingoCurrent = document.getElementById('bingo-current');
const bingoRemaining = document.getElementById('bingo-remaining');
const bingoDrawBtn = document.getElementById('bingo-draw-btn');
const bingoResetBtn = document.getElementById('bingo-reset-btn');
const bingoHistory = document.getElementById('bingo-history');

let bingoNumbers = [];
let drawnNumbers = [];

const initBingo = () => {
  bingoNumbers = [];
  drawnNumbers = [];

  for (let i = 1; i <= 15; i++) {
    bingoNumbers.push(i);
  }

  bingoCurrent.textContent = '-';
  bingoRemaining.textContent = `残り：${bingoNumbers.length}個`;
  bingoHistory.innerHTML = '';
  bingoDrawBtn.removeAttribute('disabled');
};

initBingo();

bingoDrawBtn.addEventListener('click', () => {
  if (bingoNumbers.length > 0) {
    const randomIndex = Math.floor(Math.random() * bingoNumbers.length);
    const pickedNumber = bingoNumbers.splice(randomIndex, 1)[0];

    drawnNumbers.push(pickedNumber);
    bingoCurrent.textContent = pickedNumber;

    let historyHtml = '';
    for (let i = 0; i < drawnNumbers.length; i++) {
      historyHtml += `<span class="ball">${drawnNumbers[i]}</span>`;
    }
    bingoHistory.innerHTML = historyHtml;

    if (bingoNumbers.length > 0) {
      bingoRemaining.textContent = `残り：${bingoNumbers.length}個`;
    } else {
      bingoRemaining.textContent = 'すべて引き終わりました';
      bingoDrawBtn.setAttribute('disabled', 'true');
    }
  }
});

bingoResetBtn.addEventListener('click', () => {
  initBingo();
});
```

## ⭐︎ 練習（発展演習）：端でループするステップスライダーを作ろう

「前へ」「次へ」ボタンと「1〜4のドットボタン」の両方で操作でき、最後のスライドで「次へ」を押すと最初（1枚目）に戻り、最初で「前へ」を押すと最後（4枚目）に戻る循環スライダーを実装しましょう。

5. 「前へ」ボタンがクリックされたときは、`currentSlide` を `1` 減らし、もし `0` 未満になったら「配列の長さ - 1」に変更してから `showSlide(currentSlide)` を呼び出してください。
6. 4つのドットボタン（`.dot-btn`）に対しても `for` 文でクリックイベントを登録し、クリックされたボタンの番号で `showSlide` を呼び出してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 循環させるための条件分岐は、`if (currentSlide >= slideTitles.length) { currentSlide = 0; }` と `if (currentSlide < 0) { currentSlide = slideTitles.length - 1; }` の2つです。

## ⭐︎ 練習（発展演習）：for文×while文の3連ガチャと特賞判定関数を作ろう

「3連ガチャを引く」ボタンを1回押すと、連続して同じ結果が出ないように `while` 文で調整しながら `for` 文で3回抽選を行い、さらにその結果配列の中に `'大吉'` が1つ以上含まれているかを判定する関数で特別演出を切り替えるUIを実装しましょう。

### 仕様・要件

1. ガチャボタン（`#triple-gacha-btn`）、結果リスト（`#triple-result-list`）、判定バナー（`#jackpot-banner`）を取得してください。
2. 抽選候補の配列 `omikujiTypes = ['大吉', '中吉', '小吉', '末吉']` を用意してください。
3. 結果配列（`results`）を受け取り、配列の中に `'大吉'` が1つでも含まれていれば `true`、1つもなければ `false` を **`return`** する関数 **`hasDaikichi`** を定義してください（`for` 文と `if` 文を使用）。
4. ボタンがクリックされたときに以下の処理を実行してください：
	- 今回の3連結果を保存する空の配列 `roundResults = []` と、直前インデックスを記録する変数 `lastPick = -1` を用意する。
	- `for` 文で3回繰り返し、各回ごとに `while` 文を使って `lastPick` と異なる番号を抽選し、選ばれた文字列を `roundResults` に `.push()` して `lastPick` を更新する。
	- `for` 文で `roundResults` の中身を `<li>1回目：〇〇</li>` の形式で組み立て、`#triple-result-list` の `innerHTML` に表示する。
	- `hasDaikichi(roundResults)` を呼び出し、戻り値が `true` なら `#jackpot-banner` に `'大吉が出ました'` と表示して `.is-jackpot` クラスを付け、`false` ならクラスを外して `'また挑戦してみよう'` と表示する。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- `hasDaikichi` 関数の中では、`for` 文で配列を1つずつ確認し、`'大吉'` が見つかった瞬間に `return true;` で関数を終了させます。ループを最後まで抜けて見つからなかった場合に `return false;` を返すのが定石パターンです。
</callout>

- 正解のソースコード（practice03/js/main.js に追記）

```javascript
// チャレンジ5：3連おみくじガチャ（連続重複防止＆特賞判定）
const tripleGachaBtn = document.getElementById('triple-gacha-btn');
const tripleResultList = document.getElementById('triple-result-list');
const jackpotBanner = document.getElementById('jackpot-banner');

const omikujiTypes = ['大吉', '中吉', '小吉', '末吉'];

// 配列の中に '大吉' が含まれているか判定して true / false を返す関数
const hasDaikichi = (results) => {
  for (let i = 0; i < results.length; i++) {
    if (results[i] === '大吉') {
      return true;
    }
  }
  return false;
};

tripleGachaBtn.addEventListener('click', () => {
  const roundResults = [];
  let lastPick = -1;

  // for文で3回抽選（while文で連続重複を防止）
  for (let i = 0; i < 3; i++) {
    let newPick = Math.floor(Math.random() * omikujiTypes.length);
    while (newPick === lastPick) {
      newPick = Math.floor(Math.random() * omikujiTypes.length);
    }
    roundResults.push(omikujiTypes[newPick]);
    lastPick = newPick;
  }

  // 画面のリストを更新
  let listHtml = '';
  for (let i = 0; i < roundResults.length; i++) {
    listHtml += `<li>${i + 1}回目：${roundResults[i]}</li>`;
  }
  tripleResultList.innerHTML = listHtml;

  // 特賞判定関数を呼び出してバナーを更新
  const isJackpot = hasDaikichi(roundResults);
  if (isJackpot) {
    jackpotBanner.textContent = '大吉が出ました。おめでとうございます。';
    jackpotBanner.classList.add('is-jackpot');
  } else {
    jackpotBanner.textContent = 'また挑戦してみよう';
    jackpotBanner.classList.remove('is-jackpot');
  }
});
```
