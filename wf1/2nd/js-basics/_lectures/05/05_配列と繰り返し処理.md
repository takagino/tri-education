# 2. 配列（Array）の基礎

## 2-1. なぜ「配列」が必要なのか？

これまでの単元では、1つの変数に1つのデータ（数値や文字列）を入れて扱ってきました。
しかし、実際のWebサイト制作では、**「同じ種類の複数のデータ」** をまとめて扱いたい場面が頻繁に登場します。

- スライドショーで順番に切り替える **5枚の画像URL**
- カレンダーや時計に表示する **7つの曜日名（日〜土）**
- ショップページに並べる **10個の商品名リスト**

もしこれらを通常の変数だけで管理しようとすると、次のようになってしまいます。

```jsx
// 変数を1つずつバラバラに作る場合（非効率…）
const item1 = 'りんご';
const item2 = 'ばなな';
const item3 = 'みかん';
const item4 = 'ぶどう';
```

この書き方では、データが100個になったら100個の変数名を考えなければならず、「1番目から順番に画面に表示する」「全部で何個あるか数える」といった処理もできません。

そこで登場するのが、複数のデータを1つのグループとして順番に並べて管理できる **「配列（Array）」** です。

---

## 2-2. 配列の作り方とデータの取り出し（インデックス）

配列は、角括弧 **`[ ]`** の中にデータをカンマ **`,`** で区切って記述します。

```jsx
const 配列名 = [データ0, データ1, データ2, ...];
```

実際にコンソールで確認してみましょう。

```jsx
const fruits = ['りんご', 'ばなな', 'みかん'];
console.log(fruits); // => (3) ['りんご', 'ばなな', 'みかん']
```

### インデックス（添字）で特定のデータを取り出す

配列の中の各データには、先頭から順番に **「インデックス（添字）」** と呼ばれる管理番号が自動的に割り振られます。
取り出すときは **`配列名[インデックス番号]`** と記述します。

| インデックス番号 | `[0]` | `[1]` | `[2]` |
| :--- | :---: | :---: | :---: |
| **入っているデータ** | `'りんご'` | `'ばなな'` | `'みかん'` |

```jsx
const fruits = ['りんご', 'ばなな', 'みかん'];

console.log(fruits[0]); // => "りんご"（1番目は 0！）
console.log(fruits[1]); // => "ばなな"
console.log(fruits[2]); // => "みかん"
console.log(fruits[3]); // => undefined（存在しない番号）
```

<aside>
⚠️

**超重要：配列のインデックスは「`0`」から始まる**

プログラミングの世界では、順番を数えるとき `1` ではなく **`0` からスタート** します。
- 1番目のデータ → **`[0]`**
- 2番目のデータ → **`[1]`**
- 3番目のデータ → **`[2]`**

「3個入っている配列の最後の番号は `[3]` ではなく **`[2]`** である」という点は、今後ずっと使う最重要ルールなので必ず覚えておきましょう。
</aside>

---

## 2-3. 配列の要素数を調べる：`.length` プロパティ

配列の中に現在いくつのデータ（要素）が入っているかは、**`配列名.length`** で取得できます。

```jsx
const fruits = ['りんご', 'ばなな', 'みかん'];

console.log(fruits.length); // => 3（データが入っている個数）
```

<aside>
💡

**「要素数（`.length`）」と「最後のインデックス」の関係**

- データが **3個**（`length` が `3`）のとき、インデックスは `0, 1, 2`（最後は **`2`**）
- データが **5個**（`length` が `5`）のとき、インデックスは `0, 1, 2, 3, 4`（最後は **`4`**）

つまり、配列の最後の要素を取り出したいときは **`fruits[fruits.length - 1]`** と書けば、配列の中身が何個であっても常に一番最後のデータを取り出すことができます。
</aside>

## ⭐︎ 練習：配列を使って「ステップガイド（紙芝居UI）」を作ろう

配列のインデックス操作と、前回学んだ `if` 文を組み合わせて、ボタンをクリックするたびにメッセージが順番に切り替わる「ステップガイドUI」を作ってみましょう。

**【操作するHTML（準備済み）】**

```markup
<p id="step-indicator">STEP 1 / 4</p>
<p id="step-message">ここにガイドメッセージが表示されます。</p>
<button id="next-btn">次へ進む</button>

<!-- ※下の入力フォームは次の練習で使用します -->
<div class="add-step-form">
  <input type="text" id="new-step-input" placeholder="新しいステップを入力">
  <button type="button" id="add-btn">ステップを追加</button>
</div>
```

**【要件・実装手順】**
1. **要素の取得：**
   - ステップ番号表示エリア（`#step-indicator`）、メッセージ表示エリア（`#step-message`）、「次へ進む」ボタン（`#next-btn`）を取得します。
2. **配列と変数の準備：**
   - ガイドメッセージ用の配列 `steps` を用意します（内容は下記の配列データをそのまま使用してください）：
     ```jsx
     const steps = [
       'ようこそ！まずはアカウント登録を始めましょう。',
       'お名前とメールアドレスを入力してください。',
       '入力内容を確認し、利用規約に同意してください。',
       '登録が完了しました！サービスをお楽しみください🎉'
     ];
     ```
   - 現在何番目のステップを表示しているかを管理する変数（`currentIndex` など、初期値 `0`）を用意します。
3. **初期表示：**
   - ページを開いたときに、ステップ表示欄を「STEP 1 / 全体数」にし、メッセージ欄に配列の最初のデータを表示します。
4. **「次へ進む」ボタンをクリックしたときの処理：**
   - 現在のステップ番号を `1` つ進めます。
   - 最後のステップに到達したら、最初（`0` 番目）に戻るように条件分岐（`if` 文）でループ処理を行います。
   - ステップ表示欄とメッセージ欄のテキストを、最新のステップ情報に更新します。

💡 **ヒント：**
- 配列の全体の個数は `.length` プロパティで取得できます。
- 配列のインデックスは `0` から始まりますが、画面に表示するステップ番号は人間に合わせて `+ 1` してあげると自然です（例：`STEP 1 / 4`）。
- 文字列と変数の組み合わせには、バッククォート `` ` `` で囲むテンプレートリテラルを使うとスッキリ書けます。

- 正解のソースコード

  ```jsx
  const stepIndicator = document.getElementById('step-indicator');
  const stepMessage = document.getElementById('step-message');
  const nextBtn = document.getElementById('next-btn');

  // ガイドメッセージの配列（全4件：インデックスは 0 〜 3）
  const steps = [
    'ようこそ！まずはアカウント登録を始めましょう。',
    'お名前とメールアドレスを入力してください。',
    '入力内容を確認し、利用規約に同意してください。',
    '登録が完了しました！サービスをお楽しみください🎉'
  ];

  // 現在表示しているインデックス番号（0からスタート）
  let currentIndex = 0;

  // 初期表示の反映
  stepIndicator.textContent = `STEP ${currentIndex + 1} / ${steps.length}`;
  stepMessage.textContent = steps[currentIndex];

  // ボタンクリックで次のメッセージへ進める
  nextBtn.addEventListener('click', () => {
    // 1. インデックスを1つ進める
    currentIndex++;

    // 2. 最後まで行ったら最初（0）に戻す
    if (currentIndex >= steps.length) {
      currentIndex = 0;
    }

    // 3. 画面のテキストを更新（人間向けの表示番号は +1 する）
    stepIndicator.textContent = `STEP ${currentIndex + 1} / ${steps.length}`;
    stepMessage.textContent = steps[currentIndex];
  });
  ```

<aside>
💡

**ここがポイント**

- **プログラム用の番号（`0`始まり）と人間向けの表示番号（`1`始まり）**：
  配列からデータを取り出すときは `steps[currentIndex]`（`0〜3`）を使いますが、画面に「STEP 1 / 4」と表示するときは `${currentIndex + 1}` のように `+ 1` してあげるとユーザーにとって自然な表示になります。
</aside>

## 2-4. 配列の書き換えと末尾への追加（`.push()`）

### ① 特定の要素を上書きする

インデックスを指定して `=` で代入すると、その場所のデータを書き換えることができます。

```jsx
const fruits = ['りんご', 'ばなな', 'みかん'];

// 1番目（'ばなな'）を 'いちご' に書き換える
fruits[1] = 'いちご';

console.log(fruits); // => ['りんご', 'いちご', 'みかん']
```

### ② 配列の末尾にデータを追加する：`.push()`

配列の一番最後に新しいデータを追加したいときは、**`.push(追加する値)`** メソッドを使います。

```jsx
const fruits = ['りんご', 'ばなな', 'みかん'];

// 末尾に 'ぶどう' を追加
fruits.push('ぶどう');

console.log(fruits);        // => ['りんご', 'ばなな', 'みかん', 'ぶどう']
console.log(fruits.length); // => 4
```

<aside>
💡

**疑問：`const`（定数）で宣言したのに、なぜ中身を変更・追加できるの？**

単元01で「`const` は再代入できない」と学びました。
実は、配列における `const` は **「`fruits` という箱そのものを別の箱に丸ごとすり替えること（`fruits = ['メロン']` のような再代入）」** を禁止しているだけで、**「箱の中に入っているデータを入れ替えたり追加したりすること（`fruits[1] = ...` や `fruits.push(...)`）」は許可**されています。

そのため、実務のJavaScriptでは **配列もすべて `const` で宣言するのが標準ルール** です。
</aside>

## ⭐︎ 練習：フォームから新しいステップを配列に追加しよう（pushの活用）

先ほど作成したステップガイドUIに、入力フォームから新しいガイドメッセージを自由に追加できる機能（`.push()`）を追加してみましょう。

**【操作するHTML（準備済み）】**

```markup
<div class="add-step-form">
  <input type="text" id="new-step-input" placeholder="新しいステップを入力">
  <button type="button" id="add-btn">ステップを追加</button>
</div>
```

**【要件・実装手順】**
1. **要素の取得：**
   - 新しいステップの入力欄（`#new-step-input`）と「ステップを追加」ボタン（`#add-btn`）を取得します。
2. **「ステップを追加」ボタンをクリックしたときの処理：**
   - 入力欄に入力されたテキストを取り出します。
   - もし入力欄が空でなければ、先ほどの配列 `steps` の末尾に新しいテキストを追加します。
   - 配列のデータが増えたため、インジケーター表示の分母（全ステップ数）を最新の配列の個数で更新します。
   - 次の入力がしやすいように、入力欄の中身を空にしてリセットします。

💡 **ヒント：**
- input要素に入力された値の取得や書き換えには、`.value` プロパティを使います。
- 配列の一番最後に新しいデータを追加するには、先ほど学んだ `.push()` メソッドを使います。
- 空文字かどうかの判定には、`if (入力値 !== '')` のように不等号演算子と比較します。

- 正解のソースコード（ステップガイドUIのコードの下に書き足します）

  ```jsx
  // 入力フォームの要素を取得
  const newStepInput = document.getElementById('new-step-input');
  const addBtn = document.getElementById('add-btn');

  // 「ステップを追加」ボタンをクリックしたとき
  addBtn.addEventListener('click', () => {
    const newStepText = newStepInput.value;

    // 入力欄が空でなければ配列に追加
    if (newStepText !== '') {
      // 1. 配列の末尾に新しいメッセージを追加
      steps.push(newStepText);

      // 2. ステップ表示の分母（steps.length）を更新
      stepIndicator.textContent = `STEP ${currentIndex + 1} / ${steps.length}`;

      // 3. 入力欄をクリア
      newStepInput.value = '';

      console.log(steps); // 配列にデータが増えたことを確認
    }
  });
  ```

<aside>
💡

**ここがポイント：配列の要素数（`.length`）が自動で連動する**

先ほどのステップガイドで、ループ判定に `if (currentIndex >= 4)` ではなく **`if (currentIndex >= steps.length)`** と書いていたのを覚えていますか。
条件式を `steps.length` にしておいたおかげで、あとから `.push()` でステップが5個、6個と増えても、コードを1行も書き換えることなく自動で新しいステップまで順番に表示されるようになります。
</aside>

# 3. 繰り返し処理（for文）の基礎

## 3-1. なぜ「繰り返し処理（ループ）」が必要なのか？

たとえば、コンソールに `0` から `4` までの数字を順番に出力したいとき、これまでの知識だけで書くと次のようになります。

```jsx
console.log(0);
console.log(1);
console.log(2);
console.log(3);
console.log(4);
```

5回ならまだ手で書けますが、「100回繰り返したい」「ページ内の20個のボタンすべてにクリックイベントを登録したい」という場合、同じコードを何十行もコピー＆ペーストするのは大変ですし、修正が必要になったときに大惨事になります。

このように **「決まった回数だけ、同じ処理を自動で繰り返す」** ための構文が **`for` 文（ループ処理）** です。

---

## 3-2. `for` 文の基本構文

`for` 文は以下の形式で記述します。丸括弧 `( )` の中にセミコロン `;` で区切って **3つの設定（①初期化式、②条件式、③増分式）** を書くのが特徴です。

```jsx
for (①初期化式; ②条件式; ③増分式) {
  // 条件式が true の間、繰り返される処理
}
```

実際に5回繰り返すコードを見てみましょう。

```jsx
for (let i = 0; i < 5; i++) {
  console.log(`${i}回目の処理です`);
}
```

**【コンソールの出力結果】**
```
0回目の処理です
1回目の処理です
2回目の処理です
3回目の処理です
4回目の処理です
```

### 3つのパーツの役割と動く順番

| 順番 | パーツ | コード例 | 役割 |
| :---: | :--- | :--- | :--- |
| **①** | **初期化式** | `let i = 0` | ループが始まる最初に **1回だけ** 実行されます。カウンター用の変数 `i`（indexの頭文字）を `0` で用意します。 |
| **②** | **条件式** | `i < 5` | 各ループの開始前に毎回チェックされます。`i` が `5` 未満（`true`）なら `{ }` の処理を実行し、`false` になったらループを終了します。 |
| **③** | **増分式** | `i++` | `{ }` の中の処理が1回終わるごとに実行され、`i` の数値を `1` 増やします。その後、再び **②条件式** のチェックに戻ります。 |

<aside>
⚠️

**カウンター変数 `i` は必ず `let` で宣言する**

`for (const i = 0; ...)` と `const` で書いてしまうと、1回目のループが終わって `i++`（値を1増やす再代入）が動いた瞬間に **`TypeError: Assignment to constant variable.`（定数への再代入エラー）** が発生して止まってしまいます。
`for` 文のカウンター変数 `i` は毎回数値が変化するため、必ず **`let i = 0`** と書きましょう。
</aside>

## ⭐︎ 練習：for文で繰り返し処理を体験しよう（コンソール演習）

`js/main.js` に以下の2つの `for` 文を書いて、コンソールにどのように出力されるか試してみましょう。

1. **問題A**：`for` 文を使って、`1` から `10` までの数字のうち **偶数（2, 4, 6, 8, 10）だけ** をコンソールに出力してください。
2. **問題B**：`1` から `10` までの数字をすべて足し合わせた **合計値（55）** を計算し、最後に1回だけコンソールに出力してください。

💡 **ヒント：**
- **問題A：** 偶数かどうかは、「2で割った余りが 0 かどうか」で判定できます。余りの計算には単元01で学んだ剰余演算子（`%`）を活用しましょう。
- **問題B：** ループが始まる前に、合計値を溜めておくための変数（初期値 `0`）を用意し、ループの中で毎回の数値を足し込んでいきます。

- 正解のソースコード

  ```jsx
  // 問題A：1〜10のうち偶数だけを出力
  for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
      console.log(i); // => 2, 4, 6, 8, 10
    }
  }

  // 問題B：1〜10までの合計を計算
  let total = 0;
  for (let i = 1; i <= 10; i++) {
    total += i; // total に i を順番に足していく
  }
  console.log(`1〜10の合計は ${total} です`); // => "1〜10の合計は 55 です"
  ```

## 3-3. 配列 × `for` 文の黄金コンビ

`for` 文が最も威力を発揮するのが、セクション2で学んだ **「配列」との組み合わせ** です。

配列のインデックスは **`0` から始まり、`配列.length` より小さい間（`配列.length - 1` まで）続く** のでしたね。
つまり、`for` 文の条件式に **`i < 配列名.length`** を指定すると、配列の中身を先頭から末尾まで1つ残らず順番に取り出すことができます。

```jsx
const fruits = ['りんご', 'ばなな', 'みかん', 'ぶどう'];

// i は 0, 1, 2, 3 と変化する（fruits.length は 4）
for (let i = 0; i < fruits.length; i++) {
  console.log(`${i + 1}番目: ${fruits[i]}`);
}
```

**【コンソールの出力結果】**
```
1番目: りんご
2番目: ばなな
3番目: みかん
4番目: ぶどう
```

<aside>
💡

**`i < 4` のように数字を直接書かず、`i < fruits.length` と書くメリット**

もし条件式を `i < 4` と決め打ち（ハードコーディング）してしまうと、あとから配列にデータを追加して5個や6個になったときに、5個目以降が表示されなくなってしまいます。
**`for (let i = 0; i < 配列名.length; i++)`** という形は、データの個数が何個に変わっても自動で対応できる **JavaScriptの定型フレーズ（イディオム）** です。このまま丸ごと手に馴染ませましょう。
</aside>

## ⭐︎ 練習：配列のデータからHTMLのリスト（`<li>`）を自動生成しよう

Web制作では、配列に入ったメニュー名や記事データをもとに、`for` 文でHTMLタグ（`<li>` など）を組み立てて画面に流し込む処理を頻繁に行います。

**【操作するHTML（準備済み）】**

```markup
<h2>メニュー一覧（自動生成）</h2>
<ul id="menu-list"></ul>
```

**【要件・実装手順】**
1. **要素の取得と配列の準備：**
   - メニューを表示するリスト要素（`<ul id="menu-list">`）を取得します。
   - 表示するメニュー項目の配列を用意します：
     ```jsx
     const menus = ['ホーム', 'サービス紹介', '制作実績', '会社概要', 'お問い合わせ'];
     ```
2. **HTML文字列の生成（ループ処理）：**
   - 生成したHTML文字列を溜めておくための変数（初期値は空文字 `''`）を用意します。
   - `for` 文を使って、配列の先頭から末尾まで順番にループ処理を行います。
   - 各メニュー項目を `<li>` と `</li>` で挟んだHTMLタグ文字列を組み立て、溜めておく変数に順番に連結（追加）していきます。
3. **画面への流し込み：**
   - ループが完了したあと、完成したHTML文字列をリスト要素の中に流し込んで画面に描画します。

💡 **ヒント：**
- 文字列を少しずつ足し合わせるには、加算代入演算子（`+=`）やテンプレートリテラルが便利です。
- 文字列をHTMLタグとして要素内に描画・挿入したいときは、単元02で学んだ `.innerHTML` プロパティを使用します。

- 正解のソースコード

  ```jsx
  const menuList = document.getElementById('menu-list');

  const menus = ['ホーム', 'サービス紹介', '制作実績', '会社概要', 'お問い合わせ'];

  // 1. 生成するHTML文字列を溜めるための箱（最初は空っぽ）
  let listHtml = '';

  // 2. 配列の要素数だけループして <li> タグを繋げていく
  for (let i = 0; i < menus.length; i++) {
    listHtml += `<li>${menus[i]}</li>`;
  }

  // 3. 完成したHTML文字列を ul 要素に流し込む
  menuList.innerHTML = listHtml;
  ```

<aside>
💡

**ここがポイント**

- **文字列の加算代入（`+=`）**：
  数値の計算で `total += i` と書いたのと同じように、文字列に対しても `listHtml += '<li>...</li>'` と書くことで、既存の文字列の後ろにどんどん新しいタグを繋ぎ足していくことができます。
- **HTMLタグとして解釈させるので `innerHTML` を使う**：
  単元02で学んだ通り、`<li>` などのHTMLタグを本物の要素としてブラウザに描画させたいときは、`textContent` ではなく **`innerHTML`** を使用します。
</aside>

## 4-2. 複数要素をまとめて取得する：`querySelectorAll()`

単元02で学んだ `document.querySelector()` は、指定したCSSセレクタに一致する要素がページ内に複数あっても、**最初に見つかった1つだけ** しか取得できませんでした。

ページ内にある同じクラスの要素を **すべてまとめて取得** したいときは、**`document.querySelectorAll('CSSセレクタ')`** を使用します。

| メソッド | 取得されるもの | 戻り値の形式 |
| :--- | :--- | :--- |
| **`document.querySelector('.color-btn')`** | 最初に見つかった **1つの要素** | 単一の要素（`Element`） |
| **`document.querySelectorAll('.color-btn')`** | 一致する **すべての要素** | 配列のようなリスト（`NodeList`） |

実際に `js/main.js` で取得してコンソールに出力してみましょう。

```jsx
const colorBtns = document.querySelectorAll('.color-btn');
console.log(colorBtns);        // => NodeList(4) [button.color-btn, button.color-btn, ...]
console.log(colorBtns.length); // => 4
console.log(colorBtns[0]);     // => 1つ目の「情熱のレッド」ボタン要素
```

`querySelectorAll()` で取得したデータ（**NodeList**）は、配列とまったく同じように **`[0]`, `[1]` とインデックスで個別に取り出す** ことができ、**`.length` で要素の個数を調べる** ことができます。

<aside>
⚠️

**初心者が最もハマる罠：NodeList（箱全体）に直接命令はできない**

`querySelectorAll` で取得した変数に対して、いきなりイベントやクラス操作を書くと**エラー**になります。

```jsx
const colorBtns = document.querySelectorAll('.color-btn');

// ❌ ダメな例：4個入った「箱全体」には addEventListener は存在しない！
colorBtns.addEventListener('click', () => { ... });
// => Uncaught TypeError: colorBtns.addEventListener is not a function
```

`colorBtns` はあくまで「ボタンが4個入った箱（リスト）」です。
命令を出すときは、必ず **`for` 文で箱の中から1つずつ要素を取り出し、`colorBtns[i].addEventListener(...)` のように個別の要素に対して命令** しましょう。

```jsx
// ⭕️ 正しい例：for文で1つずつ取り出してイベントを登録する
for (let i = 0; i < colorBtns.length; i++) {
  colorBtns[i].addEventListener('click', () => {
    console.log(`${i}番目のボタンが押されました。`);
  });
}
```
</aside>

## ⭐︎ 練習：外部サイトのリンクに自動で `target="_blank"` を一括付与しよう

Webサイト制作の実務では、「自分のサイト内のページ移動は同じタブで開き、`http` から始まる外部サイトへのリンクはすべて新しいタブ（`target="_blank"`）で開く」という仕様がよくあります。
HTMLの `<a>` タグ1つずつに手作業で書くのではなく、JavaScriptで外部リンクだけを一括取得して自動設定してみましょう。（※最終課題にも登場する実践テクニックです）

**【操作するHTML（準備済み）】**

```markup
<ul class="link-list">
  <li><a href="index.html">トップページ（サイト内リンク）</a></li>
  <li><a href="https://www.google.com">Google検索（外部サイト）</a></li>
  <li><a href="about.html">会社概要（サイト内リンク）</a></li>
  <li><a href="https://computer.trident.ac.jp">トライデント公式サイト（外部サイト）</a></li>
  <li><a href="https://developer.mozilla.org/ja/">MDN Web Docs（外部サイト）</a></li>
</ul>
```

**【要件・実装手順】**
1. **要素の一括取得：**
   - ページ内にあるすべての外部リンク要素（`http` から始まる `<a>` タグ）をまとめて取得します。
2. **ループ処理による属性設定：**
   - `for` 文を使って、取得したすべての外部リンクに対して以下の設定を順番に行います：
     - 新しいタブで開くようにする属性を設定します。
     - セキュリティ対策として、リンク先から元のページを操作されないようにする安全属性（`noopener noreferrer`）を設定します。
     - ユーザーが外部リンクだとひと目で分かるように、リンク文字列の末尾にアイコン記号（` ↗`）を付け足します。

💡 **ヒント：**
- 画面上の同じ種類の要素をまとめて取得するときは、`querySelectorAll()` を使用します。
- CSSセレクタの属性前方一致（**`a[href^="http"]`**）を使うと、`href` 属性が `http` から始まるリンクだけをピンポイントで取得できます。
- HTML要素に属性を追加・設定するには、単元04で学んだ `.setAttribute('属性名', '値')` を使います。新しいタブで開く属性は `target`（値は `_blank`）、セキュリティ属性は `rel` です。

- 正解のソースコード

  ```jsx
  // href属性が "http" から始まる a タグ（外部リンク）だけをすべて取得
  const externalLinks = document.querySelectorAll('a[href^="http"]');

  // 取得したすべての外部リンクに対してループで一括設定
  for (let i = 0; i < externalLinks.length; i++) {
    // 1. 新しいタブで開く属性を設定
    externalLinks[i].setAttribute('target', '_blank');
    externalLinks[i].setAttribute('rel', 'noopener noreferrer');

    // 2. リンクテキストの末尾にアイコン記号を追加
    externalLinks[i].textContent += ' ↗';
  }
  ```

ブラウザで確認してみましょう。「トップページ」や「会社概要」には何も起きず、`https://...` の外部サイト3つだけに自動で `↗` が付き、クリックすると新しいタブで開くようになっているはずです。

<aside>
💡

**知っておきたいWebセキュリティ：`rel="noopener noreferrer"` を付ける理由**

HTMLで `target="_blank"` を使って新しいタブでリンクを開くとき、実務では必ずセットで **`rel="noopener noreferrer"`** を付与します。これには重要なセキュリティ上の理由があります。

1. **`noopener`（安全対策）：**
   `target="_blank"` で開かれた新しいページ側からは、JavaScriptの `window.opener` という仕組みを使って、元のページを勝手に操作できてしまいます。これを利用して、元のページを偽のログイン画面などにすり替えるフィッシング詐欺攻撃（リバースタブナビング）を防ぐために、元のページとの繋がりを完全に切り離す役割を持つのが `noopener` です。

2. **`noreferrer`（プライバシー保護）：**
   リンク先のWebサーバーへ「どのURLからリンクをクリックして飛んできたか」という参照元情報（リファラー）を送信しないようにし、サイトのURL構造やユーザーのプライバシーを守ります。

※ 近年の主要ブラウザでは `target="_blank"` を指定すると自動的に `noopener` が機能するようになっていますが、古いブラウザへの対応や、Web制作の実務における標準的なセキュリティ対策・コーディング規約として、明示的に `rel="noopener noreferrer"` を記述するのが鉄則となっています。
</aside>

   - `for` 文を使って、取得したすべてのカラーボタンにクリックイベントを設定します。
3. **クリックされたときの処理：**
   - プレビューエリアの背景色を、クリックされたボタンと同じ順番（インデックス番号）の色コードに変更します。
   - プレビューエリアの文字色を白色（`#ffffff`）にし、表示テキストを「ボタン名（カラーコード）」の形式に書き換えます（例：「情熱のレッド（#e74c3c）」）。

💡 **ヒント：**
- ボタンの文字は `.textContent`、配列の該当データはインデックス番号を使って `colorCodes[i]` で取り出せます。
- JavaScriptから要素のCSSスタイル（背景色や文字色）を変更するには、単元02で学んだ `.style.backgroundColor` や `.style.color` を使います。

- 正解のソースコード

  ```jsx
  const colorPreview = document.getElementById('color-preview');
  const colorBtns = document.querySelectorAll('.color-btn');

  // 各ボタン（0〜3番目）に対応するカラーコードの配列
  const colorCodes = ['#e74c3c', '#27ae60', '#2980b9', '#8e44ad'];

  // 4つのボタンすべてにクリックイベントを登録
  for (let i = 0; i < colorBtns.length; i++) {
    colorBtns[i].addEventListener('click', () => {
      // クリックされた i番目のボタンの文字と、i番目の色コードを取得
      const colorName = colorBtns[i].textContent;
      const colorCode = colorCodes[i];

      // プレビューエリアの見た目とテキストを更新
      colorPreview.style.backgroundColor = colorCode;
      colorPreview.style.color = '#ffffff';
      colorPreview.textContent = `${colorName}（${colorCode}）`;
    });
  }
  ```

<aside>
💡

**インデックス `i` で「ボタン」と「配列データ」を連動させる**

- `0` 番目のボタン（`colorBtns[0]`）を押すと → `0` 番目の色（`colorCodes[0]`）が使われる
- `1` 番目のボタン（`colorBtns[1]`）を押すと → `1` 番目の色（`colorCodes[1]`）が使われる

このように、同じインデックス番号 `i` を使うことで、複数のHTML要素と配列のデータをピタッと対応させることができます。
</aside>

# 5. 実践制作：「全員から外して、1つだけに付ける」UI制御とタブ切り替え

## 5-1. Web制作で頻出の「アクティブ状態（`.is-active`）切り替え」の鉄則

先ほどのカラーパレットのボタンで、「現在選ばれているボタンに `.is-active` クラスを付けて黒背景にしたい」とします。
もし、クリックイベントの中で単純に `colorBtns[i].classList.add('is-active')` とだけ書いたらどうなるでしょうか？

1. 「情熱のレッド」を押す → レッドが黒くなる
2. 「癒やしのグリーン」を押す → **レッドも黒いまま、グリーンも黒くなる**
3. 全部のボタンを押すと、**4つすべてのボタンが黒くなってしまう**

これでは「今どれが選ばれているか」が分かりません。
複数の選択肢の中から **「最後にクリックした1つだけをアクティブにする」** ためには、以下の **2ステップの鉄則** を使います。

```jsx
// 【鉄則】クリックされたときの処理：
// Step 1. まず for文で「すべてのボタン」から is-active クラスを一旦削除する（全員リセット）
for (let j = 0; j < colorBtns.length; j++) {
  colorBtns[j].classList.remove('is-active');
}

// Step 2. その直後に、「クリックされたボタン」だけに is-active クラスを追加する
colorBtns[i].classList.add('is-active');
```

<aside>
💡

**なぜ内側のループ変数は `j` にするの？**

外側の `for` 文ですでに `let i = 0` という変数名を使っているため、その内側でもう1つ `for` 文を書くときは、名前がぶつからないようにアルファベット順で次の **`j`**（`let j = 0`）を使うのがプログラミングの慣例です。
</aside>

## 6-3. 要件と完成イメージ

### 【仕様・要件】

1. **要素の取得と変数の準備：**
   - メイン画像（`#main-img`）、キャプション表示欄（`#caption-text`）、前へボタン（`#prev-btn`）、次へボタン（`#next-btn`）を取得します。
   - 画面内に並ぶ4枚のサムネイル画像（`.thumb-img`）をまとめて取得します。
   - 現在何番目の画像が表示されているかを管理する変数（`currentIndex` など、初期値 `0`）を用意します。

2. **サムネイル画像をクリックしたときの処理（必須要件）：**
   - すべてのサムネイル画像にクリックイベントを設定します。
   - サムネイルがクリックされたとき、以下の処理を行います：
     - 現在の表示番号を、クリックされたサムネイルの順番（インデックス）に更新します。
     - クリックされたサムネイル画像の `src`（画像URL）と `alt`（説明テキスト）の情報を取得します。
     - メイン画像の `src` と `alt` を、取得したサムネイルの情報に書き換えます。
     - キャプション欄の文字列を、「現在の番号 / 全体枚数 : 説明文」の形式に更新します（例：「1 / 4 : 北欧のフィヨルドと渓谷」）。
     - すべてのサムネイルから `is-active` クラスを外し、クリックされたサムネイルだけに `is-active` クラスを付与して枠線を表示させます。

3. **「次の写真 ▶」「◀ 前の写真」ボタンをクリックしたときの処理（発展要件）：**
   - **「次の写真 ▶」ボタン：**
     - 表示番号を `1` つ進めます。最後の写真（末尾）まで行ったら、最初（`0` 番目）に戻るようにループさせます。
     - 更新された番号のサムネイル画像の情報をもとに、メイン画像・キャプション・`is-active` クラスを最新状態に更新します。
   - **「◀ 前の写真」ボタン：**
     - 表示番号を `1` つ戻します。最初の写真（`0` 番目）より小さくなったら、一番最後の写真（末尾のインデックス番号）に移動するようにループさせます。
     - 更新された番号のサムネイル画像の情報をもとに、メイン画像・キャプション・`is-active` クラスを最新状態に更新します。

💡 **ヒント：**
- **複数要素の取得：** 単一の要素は `getElementById`、同じクラスを持つ複数の要素は `querySelectorAll` で取得します。
- **属性の取得と変更：** 要素の属性値を調べるには単元04で学んだ `.getAttribute('属性名')`、書き換えるには `.setAttribute('属性名', '新しい値')` を使います。
- **インデックスのループ判定：**
  - 次へ進める場合：番号が要素数（`.length`）以上になったら `0` に戻します。
  - 前へ戻す場合：番号が `0` より小さくなったら、一番最後の要素番号（`.length - 1`）にします。
- **アクティブ状態の切り替え：** 練習問題で学んだ「内側の `for` 文ですべての要素から `is-active` を一旦削除（`remove`）し、その直後に対象の1枚だけに `is-active` を追加（`add`）する」鉄則パターンを活用しましょう。

- 正解のソースコード（解答例）

  ```jsx
  // 1. 要素の取得
  const mainImg = document.getElementById('main-img');
  const captionText = document.getElementById('caption-text');
  const prevBtn = document.getElementById('prev-btn');
  const nextBtn = document.getElementById('next-btn');
  const thumbs = document.querySelectorAll('.thumb-img');

  // 現在選択されている画像のインデックス番号（0〜3）
  let currentIndex = 0;

  // ====================================================
  // A. サムネイル画像クリック時の切り替え処理
  // ====================================================
  for (let i = 0; i < thumbs.length; i++) {
    thumbs[i].addEventListener('click', () => {
      // 現在のインデックスを、クリックされた番号 i に更新
      currentIndex = i;

      // クリックされたサムネイルの src と alt を取得
      const newSrc = thumbs[currentIndex].getAttribute('src');
      const newAlt = thumbs[currentIndex].getAttribute('alt');

      // メイン画像の src と alt を書き換え
      mainImg.setAttribute('src', newSrc);
      mainImg.setAttribute('alt', newAlt);

      // キャプションテキストを更新
      captionText.textContent = `${currentIndex + 1} / ${thumbs.length} : ${newAlt}`;

      // 全サムネイルから is-active を外し、選択された1枚だけに付ける
      for (let j = 0; j < thumbs.length; j++) {
        thumbs[j].classList.remove('is-active');
      }
      thumbs[currentIndex].classList.add('is-active');
    });
  }

  // ====================================================
  // B. 「次の写真 ▶」ボタンの処理（発展）
  // ====================================================
  nextBtn.addEventListener('click', () => {
    currentIndex++;

    // 最後の枚数を超えたら先頭（0）に戻す
    if (currentIndex >= thumbs.length) {
      currentIndex = 0;
    }

    const newSrc = thumbs[currentIndex].getAttribute('src');
    const newAlt = thumbs[currentIndex].getAttribute('alt');
    mainImg.setAttribute('src', newSrc);
    mainImg.setAttribute('alt', newAlt);
    captionText.textContent = `${currentIndex + 1} / ${thumbs.length} : ${newAlt}`;

    for (let j = 0; j < thumbs.length; j++) {
      thumbs[j].classList.remove('is-active');
    }
    thumbs[currentIndex].classList.add('is-active');
  });

  // ====================================================
  // C. 「◀ 前の写真」ボタンの処理（発展）
  // ====================================================
  prevBtn.addEventListener('click', () => {
    currentIndex--;

    // 0より小さくなったら一番最後のインデックス（length - 1）にする
    if (currentIndex < 0) {
      currentIndex = thumbs.length - 1;
    }

    const newSrc = thumbs[currentIndex].getAttribute('src');
    const newAlt = thumbs[currentIndex].getAttribute('alt');
    mainImg.setAttribute('src', newSrc);
    mainImg.setAttribute('alt', newAlt);
    captionText.textContent = `${currentIndex + 1} / ${thumbs.length} : ${newAlt}`;

    for (let j = 0; j < thumbs.length; j++) {
      thumbs[j].classList.remove('is-active');
    }
    thumbs[currentIndex].classList.add('is-active');
  });
  ```

<aside>
💡

**次回以降の伏線：同じ処理を「関数」にまとめるともっとスッキリ書ける**

上記の解答例を見ると、A（サムネイルクリック）、B（次へボタン）、C（前へボタン）の3箇所で、「メイン画像を書き換え、キャプションを更新し、`is-active` を付け替える」という **まったく同じコードが3回繰り返されて** いますね。
単元07で学ぶ **「関数（Function）」** を使うと、この共通処理を1つにまとめて、たった1行の呼び出しで動かせるようになります。お楽しみに。
</aside>
