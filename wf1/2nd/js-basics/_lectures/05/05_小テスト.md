### 第1問 【定着度：配列のインデックスの基本規則】
- **問題文**:
以下の配列 fruits から「2番目」の要素である 'ばなな' を取り出してコンソールに表示したいです。適切なコードはどれでしょうか？

```javascript
const fruits = ['りんご', 'ばなな', 'みかん'];
```

- **選択肢**:
console.log(fruits[2]);
console.log(fruits[1]);
console.log(fruits(1));
console.log(fruits.2);

- **正解**: console.log(fruits[1]);
- **解説**:
JavaScriptの配列のインデックス（添字）は、1ではなく「0」から始まります。1番目の要素（'りんご'）が fruits[0]、2番目の要素（'ばなな'）が fruits[1]、3番目の要素（'みかん'）が fruits[2] となります。なお、fruits[3] を指定すると、存在しないインデックスのため undefined が返されます。

### 第2問 【推論力：配列の .length と最後の要素の取得】
- **問題文**:
配列 colors の「一番最後のデータ」を取り出したいとき、配列の中身が何個に増えても常に最後のデータを正しく取得できる書き方はどれでしょうか？

```javascript
const colors = ['赤', '青', '黄', '緑'];
```

- **選択肢**:
colors[colors.length]
colors[colors.length - 1]
colors[last]
colors.length[-1]

- **正解**: colors[colors.length - 1]
- **解説**:
配列の要素数は .length プロパティで取得できます。配列のインデックスは 0 から始まるため、要素数が 4 個の場合、インデックスは 0, 1, 2, 3 となり、最後のインデックスは必ず「要素数 - 1（4 - 1 = 3）」になります。colors[colors.length] と書くと colors[4] を参照することになり、存在しないため undefined になってしまいます。

### 第3問 【定着度：const 宣言した配列の操作ルール】
- **問題文**:
以下のコードを実行したときの挙動に関する説明として、最も適切なものはどれでしょうか？

```javascript
const list = ['A', 'B'];

list.push('C');
list[0] = 'Z';
```

- **選択肢**:
const で宣言された配列は完全に凍結されるため、push も要素の上書きもすべてエラーになる
push は成功するが、list[0] = 'Z' のようなインデックスによる書き換えはエラーになる
エラーは発生せず、list の中身は ['Z', 'B', 'C'] に正常に更新される
const で宣言された配列には文字列を代入できないためエラーになる

- **正解**: エラーは発生せず、list の中身は ['Z', 'B', 'C'] に正常に更新される
- **解説**:
const（定数）で宣言された変数は、「別の配列を代入し直すこと（再代入：list = ['X'] など）」は禁止されますが、「配列という箱の中身（要素）を追加したり書き換えたりすること」は許可されています。そのため、実務のJavaScript開発では、意図しない再代入を防ぎつつ中身を操作するために、配列も基本的に const で宣言します。

### 第4問 【バグ検出：for文のカウンター変数の宣言方法】
- **問題文**:
処理を5回繰り返すつもりで以下の for 文を実行したところ、エラーが発生して処理が止まってしまいました。その原因と正しい修正方法として適切なものはどれでしょうか？

```javascript
for (const i = 0; i < 5; i++) {
  console.log(i);
}
```

- **選択肢**:
for 文の中では変数名を i にしてはならないため、let count = 0 に修正する
増分式 i++ は i に 1 を足して再代入する処理であるため、const ではなく変化を許可する let i = 0 に修正する
条件式は i <= 5 と書かなければならないため、不等号を修正する
console.log は for 文の内側で呼び出せないため、ループの外側に移動する

- **正解**: 増分式 i++ は i に 1 を足して再代入する処理であるため、const ではなく変化を許可する let i = 0 に修正する
- **解説**:
for 文の増分式 i++ は、内部的に i = i + 1 という「値の再代入」を行っています。変数を const で宣言してしまうと、1回目のループが終わって i++ が実行された瞬間に TypeError: Assignment to constant variable.（定数への再代入エラー）が発生します。ループのカウンター変数は周回ごとに値が変化するため、必ず let i = 0 で宣言します。

### 第5問 【推論力：for文の条件式と実行回数】
- **問題文**:
以下のコードを実行したとき、コンソールに表示される内容として正しいものはどれでしょうか？

```javascript
for (let i = 0; i <= 3; i++) {
  console.log(i);
}
```

- **選択肢**:
0, 1, 2
0, 1, 2, 3
1, 2, 3
0, 1, 2, 3, 4

- **正解**: 0, 1, 2, 3
- **解説**:
初期化式で i = 0 からスタートし、条件式が i <= 3（3以下）となっています。そのため、i が 0, 1, 2, 3 の計4回ループが実行され、それぞれ出力されます。i が 4 になった時点で条件式 4 <= 3 が false となり、ループを終了します。条件式が i < 3（3未満）の場合は 0, 1, 2 の3回となります。

### 第6問 【バグ検出：配列とfor文を組み合わせる際の条件式】
- **問題文**:
配列 members の要素を先頭から順番にすべて出力しようとして以下のコードを実行したところ、最後に undefined が出力されてしまいました。原因として正しいものはどれでしょうか？

```javascript
const members = ['佐藤', '田中', '鈴木'];

for (let i = 0; i <= members.length; i++) {
  console.log(members[i]);
}
```

- **選択肢**:
配列のループには for 文を使うことができないから
条件式が <=（以下）になっているため、最後の周で存在しない members[3] を参照してしまったから
配列の中身をループ処理するときは i を 1 から始めなければならないから
console.log(members[i]) ではなく console.log(members) と書く必要があるから

- **正解**: 条件式が <=（以下）になっているため、最後の周で存在しない members[3] を参照してしまったから
- **解説**:
要素数が 3 の配列のインデックスは 0, 1, 2 です。条件式を i <= members.length（i <= 3）と書いてしまうと、i が 3 のときにもループが回り、存在しない members[3] を参照して undefined が出力されてしまいます。配列の全要素を過不足なくループする際は、イコールを付けずに必ず **i < members.length**（未満）と記述するのが鉄則です。

### 第7問 【定着度：querySelector と querySelectorAll の違い】
- **問題文**:
HTMLページ内に <button class="btn"> が3つ存在しています。JavaScriptでこれらを取得したときの挙動に関する説明として、最も適切なものはどれでしょうか？

- **選択肢**:
document.querySelector('.btn') は3つすべてのボタンを配列として取得する
document.querySelectorAll('.btn') はセレクタに一致する3つすべての要素をまとめた NodeList を取得する
document.querySelectorAll('.btn') は最初に見つかった1つのボタンだけを取得する
両者の機能は完全に同一であり、どちらを使っても最初の1つの要素しか取得できない

- **正解**: document.querySelectorAll('.btn') はセレクタに一致する3つすべての要素をまとめた NodeList を取得する
- **解説**:
document.querySelector() はセレクタに一致する「最初に見つかった1つの要素（Element）」を取得します。一方、document.querySelectorAll() は一致する「すべての要素」をまとめたリスト（NodeList）を取得します。戻り値の型が異なるため、目的に応じて使い分ける必要があります。

### 第8問 【バグ検出：NodeListに対する一括操作のエラー】
- **問題文**:
ページ内にある複数のボタン（.tab-btn）すべてにクリックイベントを登録しようとして以下のコードを実行したところ、エラーが発生して動作しませんでした。その原因と正しい修正方法として適切なものはどれでしょうか？

```javascript
const tabBtns = document.querySelectorAll('.tab-btn');

tabBtns.addEventListener('click', () => {
  console.log('クリックされました');
});
```

- **選択肢**:
querySelectorAll で取得した NodeList（要素のリスト）自体には addEventListener メソッドが存在しないため、for 文を使って要素を1つずつ取り出して登録する必要がある
addEventListener の第1引数は 'click' ではなく 'onclick' と指定しなければならない
NodeList はクリックイベントに対応していないため、HTML側で onclick 属性を直接書く必要がある
tabBtns を const ではなく let で宣言し直す必要がある

- **正解**: querySelectorAll で取得した NodeList（要素のリスト）自体には addEventListener メソッドが存在しないため、for 文を使って要素を1つずつ取り出して登録する必要がある
- **解説**:
querySelectorAll の戻り値である NodeList は、要素が複数入った「リスト（箱）」です。リストそのものに対して .addEventListener() や .textContent などのメソッドやプロパティを実行しようとすると、TypeError: ... is not a function エラーになります。必ず for (let i = 0; i < tabBtns.length; i++) などのループを使って、tabBtns[i].addEventListener(...) のように個別の要素に対して命令を実行する必要があります。

### 第9問 【コード穴埋め：配列とfor文を組み合わせたHTMLの自動生成】
- **問題文**:
配列 menus の各要素を取り出して <li>項目名</li> というHTML文字列を繋ぎ合わせ、最後に <ul> 要素（#menu-list）の中身として画面に描画したいです。コード中の /* 空欄 */ に入る適切なコードはどれでしょうか？

```javascript
const menuList = document.getElementById('menu-list');
const menus = ['ホーム', 'サービス紹介', 'お問い合わせ'];

let listHtml = '';

for (let i = 0; i < menus.length; i++) {
  /* 空欄 */
}

menuList.innerHTML = listHtml;
```

- **選択肢**:
listHtml += `<li>${menus[i]}</li>`;
listHtml = `<li>${menus[i]}</li>`;
listHtml += `<li>${menus}</li>`;
menuList.textContent += `<li>${menus[i]}</li>`;

- **正解**: listHtml += `<li>${menus[i]}</li>`;
- **解説**:
配列の中身をループで回しながら文字列を少しずつ後ろに繋ぎ足していくには、加算代入演算子（+=）とテンプレートリテラルを組み合わせて listHtml += ... と記述します。イコール1つ（=）で代入してしまうと、毎周回で文字列が上書きされ、ループが終わったときに最後の1個（'お問い合わせ'）しか残りません。また、配列全体ではなくその周のデータを取り出すため、インデックスを指定して ${menus[i]} と書く必要があります。

### 第10問 【コード穴埋め：複数ボタンのアクティブ状態切り替え（排他制御）】
- **問題文**:
ページ内にあるすべてのタブボタン（.tab-btn）を取得し、いずれかのボタンがクリックされたときに「まずすべてのボタンから is-active クラスを削除し、クリックされたボタンだけに is-active クラスを追加する」排他制御を行いたいと考えています。コード中の /* 空欄 */ に入る適切なコードはどれでしょうか？

```javascript
const tabBtns = document.querySelectorAll('.tab-btn');

for (let i = 0; i < tabBtns.length; i++) {
  tabBtns[i].addEventListener('click', () => {
    // Step 1: すべてのボタンから is-active を削除（全員リセット）
    for (let j = 0; j < tabBtns.length; j++) {
      tabBtns[j].classList.remove('is-active');
    }

    // Step 2: クリックされた i 番目のボタンだけに is-active を付与
    /* 空欄 */
  });
}
```

- **選択肢**:
tabBtns[i].classList.add('is-active');
tabBtns.classList.add('is-active');
tabBtns[j].classList.add('is-active');
tabBtns[i].classList.toggle('is-active');

- **正解**: tabBtns[i].classList.add('is-active');
- **解説**:
クリックされたボタンだけにクラスを付与したいときは、外側のループのカウンター変数 i を使って tabBtns[i].classList.add('is-active') と指定します。tabBtns（NodeList全体）に直接 .classList を実行することはできずエラーになります。また、j は直前の内側ループの中で宣言された変数であるため外側では使えません。toggle を使ってしまうと、すでにアクティブなボタンを再度クリックした際にクラスが外れて非アクティブになってしまうため、確実に付与する add を使用します。
