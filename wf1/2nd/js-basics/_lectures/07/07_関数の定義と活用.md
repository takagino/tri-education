# 2. 関数（Function）の基礎と定義方法

## 2-1. なぜ「関数」が必要なのか？（重複コードを1つにまとめる）

前回の単元06の総合課題（ランダム背景ヒーローセクション）で書いたコードを振り返ってみましょう。
「ページを開いた最初のタイミング」と「ボタンをクリックしたタイミング」の2箇所で、画面の背景画像やテキストを更新する以下のようなコードを書いていました。

```javascript
// 【1回目】ページを開いた初回の表示更新
heroHeader.style.backgroundImage = `url("${imageUrls[lastIndex]}")`;
heroTitle.textContent = titles[lastIndex];
heroLocation.textContent = locations[lastIndex];

changeBgBtn.addEventListener('click', () => {
  // （中略：ランダム抽選処理）

  // 【2回目】ボタンをクリックしたときの表示更新（1回目とほぼ同じ処理）
  heroHeader.style.backgroundImage = `url("${imageUrls[newIndex]}")`;
  heroTitle.textContent = titles[newIndex];
  heroLocation.textContent = locations[newIndex];
});
```

同じような処理が2箇所に書かれています。
もし後から「やっぱりタグの文字（`#hero-tag`）も一緒に書き換えよう」と仕様変更が入った場合、2箇所とも忘れずに修正しなければなりません。さらに、同じ処理を呼び出すボタンが3個、4個と増えた場合、コピー＆ペーストだらけになり、修正漏れによるバグが必ず発生します。

そこで登場するのが **「関数（Function）」** です。

<callout icon="💡" color="gray_bg">
	**関数（Function）とは**

	よく使う一連の処理を1つのグループにまとめて **「名前」** をつけたものです。
	一度関数として登録（定義）しておけば、必要なタイミングでその名前を **呼び出す（Call）** だけで、何度でも同じ処理を実行できるようになります。
</callout>

プログラミングの世界には **「DRY原則（Don't Repeat Yourself：同じことを繰り返すな）」** という有名な鉄則があります。重複する処理を関数にまとめることで、コードが劇的に短く読みやすくなり、修正も1箇所だけで済むようになります。

## 2-2. 関数の基本：関数宣言（`function`）と呼び出し

関数を使うには、**「① 関数を定義する（作る）」** と **「② 関数を呼び出す（使う）」** の2つのステップが必要です。

### ステップ1：関数を定義する（`function` 文）

最も基本的な定義方法は、`function` キーワードを使う **関数宣言** です。

```javascript
function 関数名() {
  // まとめたい処理を書く
}
```

### ステップ2：関数を呼び出す

関数は **定義しただけでは実行されません**（料理のレシピをノートに書いただけでは、料理が完成しないのと同じです）。
実際に処理を実行するには、`関数名()` のように名前の後ろに丸カッコ `()` をつけて呼び出します。

```javascript
// 1. 関数の定義（この時点ではまだ画面には何も出ない）
function showWelcome() {
  console.log('いらっしゃいませ。');
  console.log('本日のセール品をご覧ください。');
}

// 2. 関数の呼び出し（ここで初めて { } の中が実行される）
showWelcome();

// 何度でも呼び出すことができる
showWelcome();
```

コンソールの出力結果：

```
いらっしゃいませ。
本日のセール品をご覧ください。
いらっしゃいませ。
本日のセール品をご覧ください。
```

<callout icon="📌" color="gray_bg">
	**関数名の付け方のルール（キャメルケース）**

	変数名と同じく、関数名も英語のキャメルケースで名付けます。
	関数は「何かの動作・処理」を行うものなので、**「動詞 ＋ 名詞」** の形で名前をつけると、何をする関数なのかが一目で分かりやすくなります。
	- `openModal`（モーダルを開く）
	- `updateView`（画面表示を更新する）
	- `calcTotalPrice`（合計金額を計算する）
</callout>

## 2-3. 関数式とアロー関数（`const 関数名 = () => {}`）

JavaScriptには、関数を定義する方法が3種類あります。すべて同じように `関数名()` で呼び出すことができます。

```javascript
// ① 関数宣言（昔からある基本の書き方）
function greet() {
  console.log('こんにちは');
}

// ② 関数式（無名関数を変数に代入する書き方）
const greet = function() {
  console.log('こんにちは');
};

// ③ アロー関数（現在のモダンJavaScriptで最も主流の書き方）
const greet = () => {
  console.log('こんにちは');
};
```

### なぜ「アロー関数」がよく使われるのか？

現在のWeb制作現場では、**③のアロー関数（`const 関数名 = () => { ... };`）** が最も広く使われています。理由は大きく3つあります。

| メリット | 理由・詳細 |
|---|---|
| **1. 上書きミスを防げる** | `const`（定数）に入れて管理するため、誤って同じ名前の関数を後から作って上書きしてしまうバグを防げます。 |
| **2. 実行順序が明確になる** | `function` 宣言には「定義より上の行でも呼び出せてしまう（巻き上げ／ホイスティング）」という特殊な性質がありますが、アロー関数は変数と同じく **「定義した行より下でしか呼び出せない」** ため、上から下へ順番に読む自然なコードになります。 |
| **3. イベントリスナーと形が同じ** | 単元03から毎回書いている `btn.addEventListener('click', () => { ... })` の `() => { ... }` は、実はアロー関数そのものです。書き方を統一できるため迷いません。 |

本授業でも、これ以降は実務標準である **アロー関数（`const 関数名 = () => {}`）** をメインに使用していきます（古いコードや参考記事を読むために、`function 関数名() {}` の形も読めるようにしておきましょう）。

## ⭐︎ 練習：最初の関数を定義してコンソールに出力しよう（コンソール演習）

まずは画面の操作に入る前に、コンソールを使ってアロー関数の「定義」と「呼び出し」の流れを体験してみましょう。

### 仕様・要件

1. アロー関数を使って `printLog` という名前の関数を定義してください。
2. 関数が呼び出されたとき、コンソールに以下の2行が出力されるようにしてください。
	- `--- システムチェック開始 ---`
	- `異常はありませんでした。`
3. 定義した `printLog` 関数を **2回連続で呼び出し**、コンソールに計4行のメッセージが表示されることを確認してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- アロー関数の基本形は `const 関数名 = () => { 処理 };` です。
	- 定義しただけでは何も表示されません。下の行で `printLog();` と丸カッコをつけて呼び出すのを忘れないようにしましょう。
</callout>

- 正解のソースコード（practice01/js/main.js）

```javascript
// 1. アロー関数の定義
const printLog = () => {
  console.log('--- システムチェック開始 ---');
  console.log('異常はありませんでした。');
};

// 2. 関数の呼び出し（2回実行）
printLog();
printLog();
```

ブラウザのコンソールを確認し、2行のメッセージが2セット出力されていれば成功です。

## ⭐︎ 練習：初期表示とリセットボタンの処理を関数で共通化しよう

コンソールで関数の動きが掴めたら、次は画面のDOM操作を関数にまとめてみましょう。
画面上の「システムステータスの管理」セクションでは、**「ページを開いた最初のタイミング」** と **「リセットボタンを押したタイミング」** の2つの場面で、ステータス表示を初期状態（待機中）にする必要があります。この共通処理を1つの関数にまとめてみましょう。

### 仕様・要件

1. ステータス表示要素（`#status-display`）、「作業中にする」ボタン（`#working-btn`）、「初期状態にリセット」ボタン（`#reset-btn`）を取得してください。
2. ステータスを初期状態に戻す関数 **`resetStatus`** を定義してください。関数の中の処理は以下の通りです：
	- `#status-display` のテキストを `'現在：待機中です'` に書き換える。
	- `#status-display` から `.is-working` クラスを削除する。
3. ページを開いた直後の初期表示として、まず1回 **`resetStatus`** 関数を呼び出してください（これにより、HTMLに書かれていた `'読み込み中...'` が即座に `'現在：待機中です'` に変わります）。
4. 「作業中にする」ボタンがクリックされたときは、`#status-display` のテキストを `'現在：作業を実行中です'` に変え、`.is-working` クラスを追加してください。
5. 「初期状態にリセット」ボタンがクリックされたときは、手順2で作った **`resetStatus`** 関数を呼び出して初期状態に戻してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- ページ読み込み直後とリセットボタンクリック時の両方で、同じ `resetStatus()` を呼び出すだけで済むため、同じDOM操作コードを2回書く必要がなくなります。
</callout>

- 正解のソースコード（practice01/js/main.js に上書き）

```javascript
const statusDisplay = document.getElementById('status-display');
const workingBtn = document.getElementById('working-btn');
const resetBtn = document.getElementById('reset-btn');

// 初期状態に戻す共通関数を定義
const resetStatus = () => {
  statusDisplay.textContent = '現在：待機中です';
  statusDisplay.classList.remove('is-working');
};

// 1. ページを開いた最初のタイミングで実行
resetStatus();

// 2. 「作業中にする」ボタンが押されたとき
workingBtn.addEventListener('click', () => {
  statusDisplay.textContent = '現在：作業を実行中です';
  statusDisplay.classList.add('is-working');
});

// 3. 「初期状態にリセット」ボタンが押されたとき（共通関数を呼び出す）
resetBtn.addEventListener('click', () => {
  resetStatus();
});
```

ページを開いた瞬間に「現在：待機中です」と表示され、「作業中にする」で黄色に変化し、「初期状態にリセット」で再び元の状態に戻ることを確認してください。

# 3. 引数（パラメータ）：関数にデータを渡して動きを変える

## 3-1. 仮引数と実引数の仕組み

前章で作った `resetStatus()` は、何回呼び出しても毎回まったく同じ文字（`'現在：待機中です'`）を表示する関数でした。
しかし、関数を呼び出すときに **「今回はこの文字を表示して」「今回はこの数値で計算して」** と材料（データ）を外から渡すことができれば、関数の使い道は何十倍にも広がります。

関数を呼び出すときに渡すデータのことを **「引数（ひきすう）」** と呼びます。

```javascript
// 1. 関数の定義：丸カッコの中に、データを受け取る変数名（仮引数）を書く
const greetUser = (userName) => {
  console.log(`こんにちは、${userName}さん。`);
};

// 2. 関数の呼び出し：丸カッコの中に、渡したい実際のデータ（実引数）を入れる
greetUser('佐藤'); // => こんにちは、佐藤さん。
greetUser('鈴木'); // => こんにちは、鈴木さん。
greetUser('高橋'); // => こんにちは、高橋さん。
```

### 用語の整理：実引数と仮引数

| 用語 | 意味 | コード上の位置 |
|---|---|---|
| **実引数（じつひきすう）** | 関数を呼び出すときに渡す **実際のデータ（値）** | `greetUser('佐藤')` の `'佐藤'` |
| **仮引数（かりひきすう）** | 関数側でデータを受け取るための **専用の変数（箱）** | `const greetUser = (userName) =>` の `userName` |

仮引数（`userName`）は、`let` や `const` を書かずに丸カッコの中に名前を書くだけで、その関数の `{ }` の中だけで使える変数として自動的に準備されます。

---

## 3-2. 複数の引数とデフォルト引数

### 複数の引数を渡す

引数は1つだけでなく、カンマ `,` で区切って2つ、3つと複数渡すことができます。
渡した順番通りに、左から順番に仮引数へと代入されます。

```javascript
// 2つの引数（商品名と個数）を受け取る関数
const showOrder = (itemName, count) => {
  console.log(`${itemName}を ${count}個 注文しました。`);
};

// 第1引数に 'カフェラテ'、第2引数に 2 が渡される
showOrder('カフェラテ', 2); // => カフェラテを 2個 注文しました。
showOrder('クロワッサン', 3); // => クロワッサンを 3個 注文しました。
```

### デフォルト引数（引数が省略されたときの初期値）

引数を受け取る関数を `greetUser()` のように空っぽのまま呼び出すと、仮引数の中身は `undefined`（未定義）になってしまいます。
これを防ぐため、`仮引数 = 初期値` と書いておくことで、**引数が渡されなかったときに自動で使われる初期値（デフォルト引数）** を設定できます。

```javascript
// 引数が省略された場合は 'ゲスト' を使うように設定
const greetUser = (userName = 'ゲスト') => {
  console.log(`ようこそ、${userName}さん。`);
};

greetUser('田中'); // => ようこそ、田中さん。（渡した値が使われる）
greetUser();       // => ようこそ、ゲストさん。（初期値が使われる）
```

## ⭐︎ 練習：引数を使って通知バナーの表示を1つの関数にまとめよう

# 4. 戻り値（`return`）と変数のスコープ

## 4-1. 処理の結果を呼び出し元へ返す：`return` 文

前回の単元06で使った `Math.floor(4.6)` を思い出してみましょう。

```javascript
const num = Math.floor(4.6);
console.log(num); // => 4
```

`Math.floor` という関数に `4.6` という引数を渡して呼び出すと、関数の中で切り捨て計算が行われ、その結果である **`4` というデータが呼び出し元へ返却されて変数 `num` に代入** されました。

このように、関数が処理を終えたあとに呼び出し元へ返してくれる結果の値を **「戻り値（もどりち） / 返り値（かえりち）」** と呼びます。
自分で作った関数から戻り値を返すには、関数の中で **`return`** 文を使います。

```javascript
// 2つの数値を足し算して、結果を return で返す関数
const addNumbers = (a, b) => {
  const sum = a + b;
  return sum; // 計算結果を呼び出し元へ返す
};

// 関数を呼び出すと、その部分が return された値（30）に置き換わる
const result = addNumbers(10, 20);
console.log(result); // => 30
```

### 「関数の中で表示する」のと「`return` で値を返す」のは何が違うのか？

初学者が最も疑問に思いやすいポイントです。
もし関数の中で `console.log(sum)` や `element.textContent = sum` まで書いてしまうと、その関数は「コンソールに出すこと（または特定の要素に出すこと）」にしか使えなくなってしまいます。

一方、計算結果だけを **`return` で返す純粋な計算関数** にしておけば、受け取った側で「画面のAに表示する」「さらに送料を足して計算を続ける」「コンソールに出す」など、**結果の使い道を呼び出し元で自由に決められる** ようになります。

---

## 4-2. `return` のもう1つの重要な性質：「関数の強制終了」

`return` 文には、値を返すだけでなく **「その行が実行された瞬間に、関数の処理を終了して外へ抜ける」** という非常に重要な性質があります。

```javascript
const checkTest = () => {
  console.log('1. 処理を開始します');
  return '完了';
  console.log('2. この行は絶対に実行されません'); // return より下は無視される
};

checkTest();
```

この性質を利用すると、「条件を満たさない場合は、関数の最初で `return;` して処理を中断する（**早期リターン / ガード節**）」という実務でよく使われる安全なコードが書けるようになります。

```javascript
const buyTicket = (age) => {
  // 18歳未満なら、ここでメッセージを出して関数を即終了する
  if (age < 18) {
    console.log('18歳未満の方は購入できません。');
    return;
  }

  // 18歳以上の場合だけ、以下の処理に進む
  console.log('チケットの購入手続きを進めます。');
};
```

## 4-3. 変数のスコープ（グローバルスコープとローカルスコープ）

変数を宣言した場所によって、「その変数をどこから使えるか」という有効範囲が決まっています。この有効範囲のことを **「スコープ（Scope）」** と呼びます。

```javascript
// 【グローバル変数】関数の外側で宣言した変数（どこからでも使える）
const shopName = 'トライデントカフェ';

const showReceipt = (price) => {
  // 【ローカル変数】関数の { } の中で宣言した変数（この関数の中でしか使えない）
  const tax = 0.1;
  const total = price + price * tax;

  console.log(`${shopName}：お会計は ${total}円 です`); // OK（グローバル変数は使える）
};

showReceipt(1000);

// 関数の外からローカル変数を使おうとするとエラーになる
// console.log(total); // => Uncaught ReferenceError: total is not defined
// console.log(price); // => Uncaught ReferenceError: price is not defined（仮引数もローカル）
```

<callout icon="📌" color="gray_bg">
	**スコープの2大ルール**

	1. **ローカルスコープ（関数内の変数・仮引数）：**
	   関数の `{ }` の中で作った変数や仮引数は、**その関数の中だけで有効** です。関数が終了すると消えるため、別の関数の中で同じ変数名（`total` や `result` など）を使っても名前が衝突せず、安全にプログラムを作ることができます。
	2. **グローバルスコープ（一番外側の変数）：**
	   関数の外（ファイルの先頭など）で作った変数は、どの関数の中からも読み書きできます。前週学んだ `lastIndex` のように「関数が終わったあともずっと記憶し続けたいデータ」や、最初に取得したDOM要素はグローバルスコープに置きます。
</callout>

## ⭐︎ 練習：returnを使って税込価格を返す関数を作ろう（コンソール演習）

まずはコンソールを使って、計算結果を `return` で返す関数の動きを確認しましょう。

### 仕様・要件

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 10%加算して切り捨てる計算は `Math.floor(price * 1.1)` で求めることができます。

## 5-2. 複数箇所から呼ばれる「開く・閉じる」処理を関数にまとめる

Webサイトでよく使われる「モーダルウィンドウ（ポップアップ）」や「ハンバーガーメニュー」を考えてみましょう。
モーダルを **「閉じる」きっかけ（トリガー）** は、画面上に1つだけではありません。

1. モーダル右上の **「×（閉じる）」ボタン** をクリックしたとき
2. モーダル下部の **「内容を確認して閉じる」ボタン** をクリックしたとき
3. モーダル外側の **「黒い半透明の背景（オーバーレイ）」** をクリックしたとき

これら3つの場所すべてに同じ「クラスを外す処理」をバラバラに書くと、後から「閉じるときにコンソールにもログを出そう」「背景のスクロール固定も解除しよう」と処理が増えた際、3箇所すべてを書き直さなければなりません。

そこで、**「開く関数（`openModal`）」** と **「閉じる関数（`closeModal`）」** をあらかじめ定義しておきます。

```javascript
// 開く処理を関数にまとめる
const openModal = () => {
  modalContainer.classList.add('is-open');
};

// 閉じる処理を関数にまとめる
const closeModal = () => {
  modalContainer.classList.remove('is-open');
};

// どの閉じるトリガーが押されても、同じ closeModal 関数を呼び出す
closeIconBtn.addEventListener('click', () => {
  closeModal();
});
agreeCloseBtn.addEventListener('click', () => {
  closeModal();
});
modalOverlay.addEventListener('click', () => {
  closeModal();
});
```

<callout icon="💡" color="gray_bg">
	**知っておくと便利な省略記法：関数名をそのままイベントに渡す**

	引数を必要としない関数を呼び出すだけの場合、`addEventListener` の第2引数に **`() => { closeModal(); }` と書く代わりに、関数名 `closeModal` をそのまま渡す** こともできます。

	```javascript
	closeIconBtn.addEventListener('click', closeModal);
	agreeCloseBtn.addEventListener('click', closeModal);
	modalOverlay.addEventListener('click', closeModal);
	```

	**【注意点】** この書き方をするときは、関数名の後ろに **`()` を絶対につけない** でください。`addEventListener('click', closeModal())` と書いてしまうと、クリックされるのを待たずにページを開いた瞬間に勝手に関数が実行されてしまいます。迷ったときは、これまで通り `() => { closeModal(); }` と書けば確実です。
</callout>

## 5-3. インデックスを引数に取る「画面更新関数」の設計（単元05・06の統合）

ここで、第2章の冒頭で触れた「単元06の課題で画面更新コードが重複していた問題」を解決しましょう。
さらに今回は、単元05で学んだ **「番号ボタンを押して切り替える（排他制御）」** と、単元06で学んだ **「ランダムに選ぶ（重複防止）」**、そして **「ページを開いた初回表示」** の3つをすべて1つの関数で統合します。

ポイントは、**「何番目のデータを表示したいか（`index`）」を引数として受け取る関数 `showSpot(index)` を1つ作ること** です。

```javascript
// 指定された番号（index）のデータに画面を一括更新する関数
const showSpot = (index) => {
  // 1. 画像・タイトル・説明文を index 番目のデータに書き換える
  spotImage.setAttribute('src', spotImages[index]);
  spotTitle.textContent = spotTitles[index];
  spotDesc.textContent = spotDescs[index];

  // 2. すべての番号ボタンから is-active を外し、index 番目のボタンだけを光らせる
  for (let i = 0; i < spotBtns.length; i++) {
    spotBtns[i].classList.remove('is-active');
  }
  spotBtns[index].classList.add('is-active');

  // 3. 現在表示中の番号を記録しておく（ランダムの連続重複防止用）
  currentIndex = index;
};
```

この万能な `showSpot(index)` 関数を1つ作っておけば、あとはどんなきっかけであっても **番号を渡して呼ぶだけ** で画面とボタンのハイライトが完璧に連動します。

- **ページを開いた最初の表示：** `showSpot(0);`（0番目を表示）
- **番号ボタン（`i` 番目）を押したとき：** `showSpot(i);`
- **ランダムボタンを押したとき：** `showSpot(newIndex);`

## ⭐︎ 練習：番号ボタンとランダム抽選の両方で動くスポット紹介UIを作ろう

「スポット1〜4」のボタンを押したときも、「ランダムに選ぶ」ボタンを押したときも、共通の関数 **`showSpot(index)`** を呼び出して画像・テキスト・ボタンのアクティブ状態が一括更新されるプログラムを実装しましょう。

### 仕様・要件

1. 以下の要素を取得してください：
	- スポット画像（`#spot-image`）、タイトル（`#spot-title`）、説明文（`#spot-desc`）

	- ランダム選択ボタン（`#random-spot-btn`）

3. インデックス番号（`index`）を引数に受け取る共通関数 **`showSpot(index)`** を定義してください。関数の中の処理は以下の通りです：
	- `#spot-image` の `src` 属性、`#spot-title` のテキスト、`#spot-desc` のテキストを、それぞれ配列の `index` 番目の内容に更新する。
	- `for` 文を使って4つの `.spot-btn` 全員から `.is-active` クラスを削除し、`spotBtns[index]` だけに `.is-active` クラスを付与する。
	- 変数 `currentIndex` に今回の `index` を保存する。
4. **初回表示：** ページを開いた直後に `showSpot(0)` を呼び出し、最初のスポットを表示状態にしてください。
5. **番号ボタンのイベント：** `for` 文で4つの `.spot-btn` それぞれにクリックイベントを登録し、クリックされたら `showSpot(i)` を呼び出してください。
6. **ランダムボタンのイベント：** クリックされたら `while` 文を使って `currentIndex` と異なるランダムな番号 `newIndex` を抽選し、`showSpot(newIndex)` を呼び出してください。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- ランダムボタンで選ばれたときも `showSpot(newIndex)` を通るため、自動的にその番号に対応するボタン（例：スポット3）が青く光り（`.is-active`）、今何番が表示されているかが一目で分かるようになります。

</callout>

## 6-3. 仕様・要件

### 必須要件（基本機能）

1. **データの準備（配列と状態変数）**：
	- 3つのツアープランの情報を管理する以下の4つの配列を用意してください：
		- プラン名配列（`planTitles`）：例 `['北海道グルメ満喫 3日間', '京都・古都の歴史めぐり 3日間', '沖縄美ら海リゾート滞在 4日間']`
		- 説明文配列（`planDescs`）：各プランの魅力を紹介するテキスト
		- 画像URL配列（`planImages`）：各プランの風景写真URL
		- 1名あたりの税抜料金配列（`planPrices`）：例 `[35000, 28000, 42000]`
	- 現在選択されているプランのインデックス番号を保持する変数 `currentPlanIndex`（初期値 `0`）と、現在の参加人数を保持する変数 `people`（初期値 `1`）を用意してください。
2. **関数①：税込合計金額を計算して返す関数 `calcTotal`**：
	- 1名あたりの税抜料金（`unitPrice`）と人数（`count`）の2つの引数を受け取る。
	- 「1名料金 × 人数」に消費税10%を加算し、小数点以下を切り捨てた税込合計金額を **`return`** で返すこと。
3. **関数②：画面表示を一括更新する関数 `updateView`**：
	- プラン番号（`index`）を引数として受け取り、`currentPlanIndex` を更新する。
	- プレビューエリアの写真（`#plan-image`）、タイトル（`#plan-title`）、説明文（`#plan-desc`）、1名料金（`#plan-unit-price`）を該当プランのデータに書き換える。
	- 3つのプラン選択ボタン（`.plan-btn`）に対して `for` 文で排他制御を行い、選ばれた番号のボタンだけに `.is-active` クラスを付与する。
	- 現在の参加人数（`#people-count`）を表示し、関数① `calcTotal` を呼び出して求めた税込合計金額を `#total-price` に表示する。
4. **関数③：確認モーダルを開閉する関数 `openConfirmModal` / `closeConfirmModal`**：
	- `openConfirmModal` では、モーダル内のプラン名（`#modal-plan-title`）、参加人数（`#modal-people-count`）、合計金額（`#modal-total-price`）に現在の選択内容を反映させた上で、`#confirm-modal` に `.is-open` クラスを追加する。
	- `closeConfirmModal` では、`#confirm-modal` から `.is-open` クラスを削除する。
5. **各種イベントの登録と初期表示**：
	- ページを開いた直後に `updateView` 関数に `0` を渡して呼び出し、初期表示を行うこと。
	- 3つのプランボタン、おまかせランダムボタン（`while` 文による連続重複防止付き）、人数の「＋」「−」ボタン（人数が `1` 未満にならないよう条件分岐で制限）、モーダルの開くボタンおよび3つの閉じる箇所（「×」ボタン、「戻って修正する」ボタン、背景オーバーレイ）にそれぞれイベントを設定すること。

<callout icon="💡" color="gray_bg">
	**ヒント**
	- 税込合計金額の計算式は `Math.floor(unitPrice * count * 1.1)` で求められます。
	- 人数の「＋」ボタンを押したときは `people++` したあとに `updateView(currentPlanIndex)` を呼び出すだけで、画面の人数表示と合計金額の再計算が一気に完了します。
	- 人数の「−」ボタンを押したときは、`if (people > 1)` の条件をつけて `1` 名より少なくならないように保護しましょう。
	- モーダルを開くときも、`calcTotal(planPrices[currentPlanIndex], people)` を呼び出せば、いつでも最新の正しい税込合計金額を取得できます。
</callout>

const confirmModal = document.getElementById('confirm-modal');

const backBtn = document.getElementById('back-btn');

const modalPlanTitle = document.getElementById('modal-plan-title');
const modalPeopleCount = document.getElementById('modal-people-count');
const modalTotalPrice = document.getElementById('modal-total-price');

// 2. ツアープランのデータ配列
const planTitles = [
  '北海道グルメ満喫 3日間',
  '京都・古都の歴史めぐり 3日間',
  '沖縄美ら海リゾート滞在 4日間'
];

const planDescs = [
  '新鮮な海の幸と広大な大地を巡る人気プランです。札幌・小樽・富良野を周遊します。',
  '四季折々の美しい寺社仏閣と伝統的な京懐石をじっくり味わう大人の散策ツアーです。',
  '透き通るエメラルドグリーンの海とオーシャンビューホテルで極上の休日を過ごせます。'
];

const planImages = [
  'https://picsum.photos/id/1018/700/360',
  'https://picsum.photos/id/1043/700/360',
  'https://picsum.photos/id/1015/700/360'
];

const planPrices = [35000, 28000, 42000];

// 現在の状態を管理するグローバル変数
let currentPlanIndex = 0;
let people = 1;

// 3. 関数①：税込合計金額を計算して return で返す関数
const calcTotal = (unitPrice, count) => {
  return Math.floor(unitPrice * count * 1.1);
};

// 4. 関数②：画面表示を一括更新する関数
const updateView = (index) => {
  currentPlanIndex = index;

  // プラン情報の更新
  planImage.setAttribute('src', planImages[index]);
  planTitle.textContent = planTitles[index];
  planDesc.textContent = planDescs[index];
  planUnitPrice.textContent = planPrices[index];

  // プラン選択ボタンの排他制御
  for (let i = 0; i < planBtns.length; i++) {
    planBtns[i].classList.remove('is-active');
  }
  planBtns[index].classList.add('is-active');

  // 人数と税込合計金額の更新
  peopleCount.textContent = people;
  const total = calcTotal(planPrices[index], people);
  totalPrice.textContent = total;
};

// 5. 関数③：予約確認モーダルを開く関数・閉じる関数
const openConfirmModal = () => {
  const total = calcTotal(planPrices[currentPlanIndex], people);

  modalPlanTitle.textContent = planTitles[currentPlanIndex];
  modalPeopleCount.textContent = `${people}名様`;
  modalTotalPrice.textContent = `${total}円（税込）`;

  confirmModal.classList.add('is-open');
};

const closeConfirmModal = () => {
  confirmModal.classList.remove('is-open');
};

// 6. ページ読み込み時の初回表示
updateView(0);

// 7. プラン選択ボタンのイベント設定
for (let i = 0; i < planBtns.length; i++) {
  planBtns[i].addEventListener('click', () => {
    updateView(i);
  });
}

// 8. おまかせ（ランダム）ボタンのイベント設定（連続重複防止付き）
randomPlanBtn.addEventListener('click', () => {
  let newIndex = Math.floor(Math.random() * planTitles.length);

  while (newIndex === currentPlanIndex) {
    newIndex = Math.floor(Math.random() * planTitles.length);
  }

  updateView(newIndex);
});

// 9. 人数増減ボタンのイベント設定
plusBtn.addEventListener('click', () => {
  people++;
  updateView(currentPlanIndex);
});

minusBtn.addEventListener('click', () => {
  if (people > 1) {
    people--;
    updateView(currentPlanIndex);
  }
});

// 10. モーダル開閉のイベント設定
openConfirmBtn.addEventListener('click', () => {
  openConfirmModal();
});

closeModalIcon.addEventListener('click', () => {
  closeConfirmModal();
});

backBtn.addEventListener('click', () => {
  closeConfirmModal();
});

modalOverlay.addEventListener('click', () => {
  closeConfirmModal();
