### 第1問 【定着度：関数を使う目的とメリット】
- **問題文**:
プログラムの中で同じ処理が複数箇所に出てくるときに関数へまとめる主な理由（メリット）として、最も適切なものはどれでしょうか？

- **選択肢**:
よく使う処理を1箇所に部品化することで、コードの重複を減らし、修正や再利用を簡単にできるから
HTMLやCSSのファイルを自動的に作成して、サーバーへアップロードしてくれるから
ブラウザのキャッシュを消去して、Webページの画像サイズを自動的に小さくできるから
変数の数を増やして、すべてのデータをグローバル変数として管理できるようになるから

- **正解**: よく使う処理を1箇所に部品化することで、コードの重複を減らし、修正や再利用を簡単にできるから
- **解説**:
関数は、一連の処理に名前をつけて1つの部品にまとめる仕組みです。同じ処理を何度もコピー＆ペーストせずに済み（DRY原則）、仕様変更があった際も関数の中身を1箇所修正するだけで呼び出しているすべての箇所に反映できます。

### 第2問 【定着度：アロー関数の定義と呼び出し】
- **問題文**:
アロー関数を使って greet という名前の関数を定義し、それを呼び出して実行する正しいコードの組み合わせはどれでしょうか？

- **選択肢**:
const greet = () => { console.log('こんにちは'); }; のあと、greet(); で呼び出す
const greet = () { console.log('こんにちは'); }; のあと、greet; で呼び出す
function greet => () { console.log('こんにちは'); }; のあと、call greet(); で呼び出す
const greet => () { console.log('こんにちは'); }; のあと、greet(); で呼び出す

- **正解**: const greet = () => { console.log('こんにちは'); }; のあと、greet(); で呼び出す
- **解説**:
アロー関数は const 関数名 = () => { 処理 }; の形式で定義します。定義しただけでは処理は実行されないため、実行するときは関数名の後ろに丸カッコをつけて greet(); のように呼び出します。

### 第3問 【バグ検出：イベントリスナーに関数名を渡す際の注意点】
- **問題文**:
モーダルを閉じる closeModal 関数をボタンのクリックイベントに登録しようとして、誤って以下のように記述してしまいました。このコードを実行するとどのような問題が起きるでしょうか？

```javascript
const closeModal = () => {
  modalContainer.classList.remove('is-open');
};

// クリックイベントに () をつけて渡してしまった
closeBtn.addEventListener('click', closeModal());
```

- **選択肢**:
ボタンがクリックされるのを待たずに、ページを開いた瞬間に closeModal が実行されてしまう
クリックした瞬間にブラウザが無限ループに入り、画面がフリーズしてしまう
closeModal 関数が2回連続で実行されてしまう
エラーにならず、ボタンをクリックしたときだけ正常にモーダルが閉じる

- **正解**: ボタンがクリックされるのを待たずに、ページを開いた瞬間に closeModal が実行されてしまう
- **解説**:
関数名の後ろに () をつけると「今すぐ関数を実行する」という意味になります。addEventListener の第2引数に関数を渡す際は、() をつけずに closeModal と関数名だけを渡すか、() => { closeModal(); } のようにアロー関数で包む必要があります。

### 第4問 【推論力：仮引数と実引数の受け渡し】
- **問題文**:
以下のコードを実行したとき、コンソールに出力される結果として正しいものはどれでしょうか？

```javascript
const showPrice = (itemName, price) => {
  console.log(`${itemName}は${price}円です`);
};

showPrice('コーヒー', 500);
```

- **選択肢**:
コーヒーは500円です
itemNameはprice円です
500はコーヒー円です
undefinedはundefined円です

- **正解**: コーヒーは500円です
- **解説**:
関数を呼び出す際に渡した実引数（'コーヒー', 500）は、定義側の仮引数（itemName, price）へ左から順番に代入されます。そのため、itemName には 'コーヒー'、price には 500 が入り、「コーヒーは500円です」と出力されます。

### 第5問 【推論力：デフォルト引数の動作】
- **問題文**:
以下のコードを実行したとき、コンソールに出力される結果として正しいものはどれでしょうか？

```javascript
const orderDrink = (drink, size = 'M') => {
  console.log(`${drink}の${size}サイズ`);
};

orderDrink('オレンジジュース');
```

- **選択肢**:
オレンジジュースのMサイズ
オレンジジュースのundefinedサイズ
オレンジジュースのLサイズ
引数が足りないためエラーになる

- **正解**: オレンジジュースのMサイズ
- **解説**:
仮引数に size = 'M' のように初期値を設定しておくと（デフォルト引数）、関数呼び出し時に第2引数が省略された場合でも、自動的に設定した初期値 'M' が使われます。

### 第6問 【推論力：戻り値（return）の仕組み】
- **問題文**:
税抜価格を受け取って消費税10%を加算した税込価格を計算し、呼び出し元へ返す関数 calcTaxPrice を作成しました。コード中の /* 空欄 */ に入る適切なキーワードはどれでしょうか？

```javascript
const calcTaxPrice = (price) => {
  const taxed = Math.floor(price * 1.1);
  /* 空欄 */ taxed;
};

const total = calcTaxPrice(500);
console.log(total); // => 550
```

- **選択肢**:
return
console.log
break
const

- **正解**: return
- **解説**:
関数の中で計算した結果を呼び出し元（const total = calcTaxPrice(500);）へ返却するには、return キーワードを使用します。return がない関数を呼び出して変数に代入すると、結果は undefined になります。

### 第7問 【推論力：returnによる関数の強制終了】
- **問題文**:
以下のコードを実行したとき、コンソールに順番に出力される結果として正しいものはどれでしょうか？

```javascript
const checkNumber = (num) => {
  if (num < 0) {
    console.log('マイナスの値です');
    return;
  }
  console.log('チェック完了');
};

checkNumber(-5);
```

- **選択肢**:
「マイナスの値です」だけが出力される
「マイナスの値です」と「チェック完了」の両方が出力される
「チェック完了」だけが出力される
何も出力されない

- **正解**: 「マイナスの値です」だけが出力される
- **解説**:
return 文には値を返すだけでなく、「その行が実行された瞬間に、関数の処理を終了して外へ抜ける」という性質があります。今回は -5 が渡されて if 文の中に入り、return; が実行されたため、その下にある console.log('チェック完了') は実行されずに終了します。

### 第8問 【定着度：変数のスコープ（ローカル変数）】
- **問題文**:
以下のコードを実行したとき、最後の行の console.log(taxed) の結果として正しいものはどれでしょうか？

```javascript
const calcPrice = (price) => {
  const taxed = price * 1.1;
  console.log(taxed);
};

calcPrice(1000);
console.log(taxed);
```

- **選択肢**:
最後の行でエラー（ReferenceError: taxed is not defined）になる
1100 と 1100 が2回出力される
1100 と undefined が出力される
1100 と 0 が出力される

- **正解**: 最後の行でエラー（ReferenceError: taxed is not defined）になる
- **解説**:
関数の { } の中で宣言された変数（ローカル変数）は、その関数の中だけで有効（ローカルスコープ）です。関数の外側から直接参照しようとすると、そのような変数は存在しないため ReferenceError になります。

### 第9問 【コード穴埋め：引数を使ったクラス操作の共通化】
- **問題文**:
引数で受け取ったメッセージとクラス名を通知バナーに反映する関数 updateBanner を作成しています。コード中の /* 空欄 */ に入る適切な記述はどれでしょうか？

```javascript
const alertBanner = document.getElementById('alert-banner');

const updateBanner = (message, typeClass) => {
  alertBanner.textContent = message;
  alertBanner.classList.remove('is-success', 'is-warning', 'is-error');
  /* 空欄 */
};

updateBanner('保存が完了しました', 'is-success');
```

- **選択肢**:
alertBanner.classList.add(typeClass);
alertBanner.classList.add('typeClass');
alertBanner.classList.add(message);
alertBanner.textContent = typeClass;

- **正解**: alertBanner.classList.add(typeClass);
- **解説**:
仮引数 typeClass に受け取った文字列（'is-success' など）をそのままクラス名として追加するには、クォーテーションをつけずに変数名（仮引数名）のまま alertBanner.classList.add(typeClass); と書きます。'typeClass' とクォーテーションで囲むと、文字通りの「typeClass」というクラスが付与されてしまいます。

### 第10問 【コード穴埋め：インデックス引数による画面更新と排他制御】
- **問題文**:
選択されたプラン番号（index）を受け取り、すべてのプランボタンから is-active クラスを外したあと、選ばれた番号のボタンだけに is-active クラスを付与したいです。コード中の /* 空欄 */ に入る適切なコードはどれでしょうか？

```javascript
const planBtns = document.querySelectorAll('.plan-btn');

const updateView = (index) => {
  for (let i = 0; i < planBtns.length; i++) {
    planBtns[i].classList.remove('is-active');
  }
  /* 空欄 */
};

updateView(0);
```

- **選択肢**:
planBtns[index].classList.add('is-active');
planBtns[i].classList.add('is-active');
planBtns.classList.add('is-active');
index.classList.add('is-active');

- **正解**: planBtns[index].classList.add('is-active');
- **解説**:
関数の引数として受け取った番号 index を使って特定のボタンを指定するため、planBtns[index].classList.add('is-active'); と記述します。変数 i は直前の for ループの中で宣言された変数なのでループの外側では使えず、planBtns（リスト全体）や index（単なる数値）には classList プロパティが存在しません。
