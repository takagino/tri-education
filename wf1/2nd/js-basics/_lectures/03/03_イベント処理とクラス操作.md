# 2. イベント処理の基本と復習（click・scroll・resize）

## 2-1. クリックイベントの復習

前回の単元2の最後で、ボタンをクリックしたときのイベントを少しだけ体験しました。

JavaScriptに「〜したときに、この処理を実行してね」と教え込む命令を **イベントリスナー（`addEventListener`）** と呼びます。

```jsx
対象要素.addEventListener('イベント名', () => {
  // そのイベントが起きたときに実行したい処理
});
```

まずは前回の復習として、ボタンをクリックしたときに文字と色を変えてみましょう。

```jsx
const btn = document.getElementById('btn');
const mainTitle = document.getElementById('main-title');

btn.addEventListener('click', () => {
  mainTitle.textContent = 'ボタンがクリックされました！';
  mainTitle.style.color = '#e67e22';
});
```

---

## 2-2. 画面全体を監視する：スクロールイベント（scroll）

イベントはボタンなどの特定のHTML要素だけでなく、**ブラウザのウィンドウ全体（`window`）** に対しても設定できます。

その代表例が、ページがスクロールされた瞬間を監視する **`'scroll'` イベント** です。

### 1. スクロール量の取得：`window.scrollY`

現在ページが上から何ピクセルスクロールされているかは、**`window.scrollY`** という値で取得できます。

```jsx
window.addEventListener('scroll', () => {
  console.log(`現在のスクロール量: ${window.scrollY}px`);
});
```

※ページに高さがないとスクロールできないため、CSSで一時的に `body { height: 2000px; }` を指定して試してみましょう。

### 2. スクロールに合わせてスタイルを動かす

単元1で学んだテンプレートリテラルと、単元2で学んだ `style` を組み合わせて、スクロール量に応じて画面を変化させてみます。

例えば、スクロール量に合わせて要素をクルクルと回転させてみましょう。

```jsx
// HTMLに <div id="box" class="box"></div> がある場合
const box = document.getElementById('box');

window.addEventListener('scroll', () => {
  // スクロールされたピクセル数（px）をそのまま回転角度（deg）に変換
  box.style.transform = `rotate(${window.scrollY}deg)`;
});
```

または、スクロール量に応じて背景グラデーションの向き（角度）を変化させることもできます。

```jsx
window.addEventListener('scroll', () => {
  // スクロールされたピクセル数（px）をそのままグラデーションの角度（deg）に変換
  document.body.style.backgroundImage = `linear-gradient(${window.scrollY}deg, #ff9a9e, #fad0c4)`;
});
```

<aside>
💡

**トピックス：今は際限なく変化するけれど…**

このコードを実行すると、スクロールすればするほどボックスが無限に回り続けたり、背景のグラデーションがぐるぐると変わり続けたりします。

実務のWebサイトでは「300pxスクロールしたらボタンをふわっと表示する」「ページ最下部に到達したらメニューを出す」といった制御を行います。
**「◯◯pxを超えたら〜する」という条件制御は、次回の単元4で学習する「if文（条件分岐）」** を使うことで実現できます！

</aside>

## 2-3. ウィンドウサイズを監視する：リサイズイベント（resize）

もう1つの重要な全体イベントが、ブラウザのウィンドウサイズが変更された瞬間に発生する **`'resize'` イベント** です。

### 1. 現在のウィンドウ幅の取得：`window.innerWidth`

現在開いているブラウザの内側の横幅（ピクセル数）は、**`window.innerWidth`** で取得できます。

### 2. 実践：リアルタイム・ウィンドウ幅インジケーター

Webデザインにおいて、PC・タブレット・スマートフォンのブレイクポイント（画面幅）を意識することは非常に重要です。
画面を伸縮するたびに現在のウィンドウ幅をリアルタイムに表示するUIを作成してみましょう。

**`index.html`** に表示用の要素を追加します：

```markup
<div class="size-display">
  現在の画面幅：<span id="window-width">0</span>px
</div>
```

**`js/main.js`**：

```jsx
const windowWidthText = document.getElementById('window-width');

// 画面を開いた瞬間の幅を表示
windowWidthText.textContent = window.innerWidth;

// ウィンドウがリサイズされるたびに数値を更新
window.addEventListener('resize', () => {
  windowWidthText.textContent = window.innerWidth;
});
```

ブラウザの端をドラッグしてウィンドウの大きさを変えると、画面上の数値がリアルタイムにカタカタと更新されます。

# 3. なぜ style を直接変更せず「クラス」を操作するのか？

ここまで、`element.style` を使って文字色や背景色、回転などをJavaScriptから直接書き換えてきました。

しかし、実際のWeb制作現場では、`element.style` で見た目を細かく制御することはほとんどありません。
その代わりに、**「あらかじめCSSにクラスを定義しておき、JavaScriptからはそのクラスを付け外しする」** という手法が業界標準として使われます。なぜでしょうか？

---

## 3-1. `element.style` の課題

1. **JavaScriptのコードがデザイン情報で散らかる**
   要素の「色」「フォントサイズ」「余白」「背景」「影」「アニメーション時間」など、変更したいCSSプロパティが増えるたびに、JavaScript側のコードが何十行も長くなってしまいます。
2. **インラインスタイルになってしまう**
   `element.style` で変更すると、HTMLタグの中に直接 `style="..."` が書き込まれます（インラインスタイル）。インラインスタイルはCSSの優先順位が非常に強いため、外部CSSファイルからの上書きやレスポンシブ対応が難しくなります。

---

## 3-2. 役割分担の原則

Web制作では、言語ごとの役割分担を明確に保つことが基本です。

- **HTML**：構造・意味（何がどこにあるか）
- **CSS**：**見た目・装飾・アニメーション（どう見えるか、どう動くか）**
- **JavaScript**：**状態の切り替えスイッチ（いつ変わるか）**

JavaScriptは「今どんな状態なのかを表すクラスを付ける・外す」というスイッチの操作だけに専念し、実際の見た目や色の変化、アニメーションはすべてCSSに任せます。

---

## 3-3. 「状態クラス（State Class）」の設計思想

Web制作では、現在の状態を表す専用のクラスを用意して付け外しします。
これを**状態クラス（State Class）**と呼び、慣例として **`is-`** という接頭辞をつけて命名します。

| 状態クラス名 | 意味・使われる場面 |
| --- | --- |
| **`.is-active`** | アクティブ状態（現在選択されているタブ、押されているボタンなど） |
| **`.is-open`** | 開いている状態（開いたメニュー、開いたアコーディオンなど） |
| **`.is-visible`** | 表示されている状態（ふわっと現れたモーダルやトップへ戻るボタンなど） |

```css
/* 通常状態（CSSに書いておく） */
.btn {
  background-color: #ffffff;
  color: #333333;
  transition: all 0.3s ease;
}

/* is-active が付いたときの状態（CSSに書いておく） */
.btn.is-active {
  background-color: #0066cc;
  color: #ffffff;
}
```

JavaScriptの役割は、ボタンが押されたときにこの `.is-active` を付ける・外すことだけです。

# 4. クラスを自由自在に操る（classList）

要素が持っているクラスを操作するには、要素の **`classList` プロパティ** を使用します。

---

## 4-1. クラスを追加する：`classList.add()`

要素に指定したクラスを追加します。

```jsx
要素.classList.add('クラス名');
```

```jsx
const title = document.getElementById('main-title');

// 'highlight' クラスを追加する
title.classList.add('highlight');
// 結果のHTML: <h1 id="main-title" class="highlight">...</h1>
```

すでにそのクラスが付いている場合は、二重に追加されることはありません。

---

## 4-2. クラスを削除する：`classList.remove()`

要素から指定したクラスを取り除きます。

```jsx
要素.classList.remove('クラス名');
```

```jsx
// 'highlight' クラスを削除する
title.classList.remove('highlight');
```

最初からそのクラスが付いていない場合でも、エラーにならず安全に無視されます。

---

## 4-3. クラスを反転切り替えする：`classList.toggle()`

クラスが「付いていなければ追加し、付いていれば削除する」という**反転切り替え（トグル）**を一発で行います。

スイッチのON/OFFや、メニューの開閉などを作る際に最も頻繁に使われる命令です。

```jsx
要素.classList.toggle('クラス名');
```

```jsx
const btn = document.getElementById('btn');

btn.addEventListener('click', () => {
  // クリックするたびに is-active の追加と削除が交互に切り替わる
  btn.classList.toggle('is-active');
});
```

---

## 4-4. クラスの有無を判定する：`classList.contains()`

要素が指定したクラスを持っているかどうかを確認し、結果を真偽値（**`true`** または **`false`**）で返します。

```jsx
const hasClass = 要素.classList.contains('クラス名');
```

```jsx
if (btn.classList.contains('is-active')) {
  console.log('ボタンはアクティブ状態です');
} else {
  console.log('ボタンは通常状態です');
}
```

---

<aside>
⚠️

**超重要ルール：`classList` の引数にはドット（`.`）を付けない！**

`querySelector` ではセレクタとしてドット（`.btn`）を付けましたが、`classList` は「クラスを操作するための専用命令」なので、**ドットは不要**です。

- ❌ `btn.classList.add('.is-active');` （`.is-active` という奇妙なクラス名が付いてしまう）
- ⭕ `btn.classList.add('is-active');` （ドットを付けずに名前だけを指定する）

</aside>

---

## 4-5. `classList` の命令まとめ

| 命令 | 役割 | 戻り値 |
| --- | --- | --- |
| **`element.classList.add('name')`** | クラスを追加する | なし（`undefined`） |
| **`element.classList.remove('name')`** | クラスを削除する | なし（`undefined`） |
| **`element.classList.toggle('name')`** | クラスを反転切り替えする（ON/OFF） | 付与されたら `true`、削除されたら `false` |
| **`element.classList.contains('name')`** | クラスがついているか確認する | ついていれば `true`、なければ `false` |

## 6-2. 実装の手順

1. 操作したい要素（質問ボタン、回答コンテンツ）を `document.getElementById()` で取得し、変数に代入する。
2. 質問ボタンにクリックイベント（`addEventListener`）を登録する。
3. ボタンをクリックしたときに、回答コンテンツ（`#accordion-content`）に開閉用のクラス（`.is-open`）を `toggle` する。
