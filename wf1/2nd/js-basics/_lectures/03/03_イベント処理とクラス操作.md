# 2. イベント処理の基本と復習（click・scroll・load・resize）

## 2-1. クリックイベントの復習

前回、ボタンをクリックしたときのイベントを少しだけ体験しました。

JavaScriptに「〜したときに、この処理を実行してね」と教え込む命令を **イベントリスナー（`addEventListener`）** と呼びます。

```jsx
対象要素.addEventListener('イベント名', () => {
  // そのイベントが起きたときに実行したい処理
});
```

まずは前回の復習として、ボタンをクリックしたときに文字と色を変えてみましょう。

**`js/main.js`**

```jsx
const btn = document.getElementById('btn');
const mainTitle = document.getElementById('main-title');

btn.addEventListener('click', () => {
  mainTitle.textContent = 'ボタンがクリックされました！';
  mainTitle.style.color = '#e67e22';
});
```

## 2-2. 画面全体を監視する：スクロールイベント（scroll）

イベントはボタンなどの特定のHTML要素だけでなく、**ブラウザのウィンドウ全体（`window`）** に対しても設定できます。

その代表例が、ページがスクロールされた瞬間を監視する **`'scroll'` イベント** です。

**【スクロール量の取得：`window.scrollY` 】**

現在ページが上から何ピクセルスクロールされているかは、**`window.scrollY`** という値で取得できます。

```jsx
window.addEventListener('scroll', () => {
  console.log(`現在のスクロール量: ${window.scrollY}px`);
});
```

**【スクロールに合わせてスタイルを動かす】**

テンプレートリテラルと、 `style` を組み合わせて、スクロール量に応じて画面を変化させてみます。

例えば、スクロール量に合わせて要素をクルクルと回転させてみましょう。

**`js/main.js`**

```jsx
window.addEventListener('scroll', () => {
  // スクロールされたピクセル数（px）をそのまま回転角度（deg）に変換
  btn.style.transform = `rotate(${window.scrollY}deg)`;
});
```

ページに高さがないとスクロールできないため、CSSで一時的に **`.btn { margin: 1000px 0; }`** を指定して試してみましょう。

**`css/style.css`**

```css
.btn {
    margin: 1000px 0; /* 追加 */
    padding: 12px 24px;
    font-size: 16px;
    border: 1px solid #cccccc;
    border-radius: 8px;
    background-color: #ffffff;
    cursor: pointer;
}
```

または、スクロール量に応じて背景グラデーションの向き（角度）を変化させることもできます。

```jsx
window.addEventListener('scroll', () => {
  // スクロールされたピクセル数（px）をそのままグラデーションの角度（deg）に変換
  document.body.style.backgroundImage = `linear-gradient(${window.scrollY}deg, #ff9a9e, #fad0c4)`;
});
```

<aside>
⚠️

**今は際限なく変化するけれど**

このコードを実行すると、スクロールすればするほどボックスが無限に回り続けたり、背景色が延々と変わり続けたりします。

実務のWebサイトでは「300pxスクロールしたらボタンをふわっと表示する」「ページ最下部に到達したらメニューを出す」といった制御を行います。
**「◯◯pxを超えたら〜する」という条件制御は、次回の単元で学習する「if文（条件分岐）」** を使うことで実現できます。

</aside>

**【再読み込み時の落とし穴：スクロール途中だとスタイルが効かない？】**

ここで、少し実験をしてみましょう。

1. ページを少し下までスクロールします（ボタンが回転した状態にします）。
2. その位置のまま、ブラウザを**再読み込み（リロード）**してみてください。

画面は途中のスクロール位置から始まっているのに、**ボタンの傾きが「0度（初期状態）」に戻ってしまっていませんか？**
そして、1pxでもスクロールすると、急にカクッと現在のスクロール位置の角度まで回転するはずです。

<aside>
💡

**なぜリロード直後はスタイルが効かないのか？**

`'scroll'` イベントは、あくまで**「ユーザーがスクロール操作を行った瞬間」**にしか実行されません。
ブラウザを再読み込みした直後は、まだ一度もスクロール操作をしていないため、イベントリスナー内の処理が一度も動いていないのです。

</aside>

**【画面の読み込み完了を監視する：`load` イベント】**

この問題を解決するには、「スクロールした時」だけでなく、**「ページ全体の読み込みが完了した瞬間」** にも同じスタイルを適用してあげる必要があります。

ブラウザがHTMLやCSS、画像などの全リソースを読み込み終わった瞬間に発生するのが **`'load'` イベント** です。

```jsx
window.addEventListener('load', () => {
  console.log('ページの読み込みが完了しました！');
});
```

---

### ⭐︎ 練習：loadイベントでリロード時のスタイルを完成させよう

ページを開いた（読み込んだ）直後にも、現在のスクロール位置に応じた回転角度が適用されるようにコードを完成させてみましょう。

1. `js/main.js` に `window.addEventListener('load', ...)` を追加します。
2. その中に、スクロール時と同じように `btn.style.transform` を設定するコードを記述してください。
3. ページを途中までスクロールした状態でリロードし、読み込んだ瞬間からボタンが正しく傾いて表示されるか確認しましょう。

- 正解のソースコード
    
    ```jsx
    // スクロールしたとき
    window.addEventListener('scroll', () => {
      btn.style.transform = `rotate(${window.scrollY}deg)`;
    });

    // ページの読み込みが完了したとき（リロード時にも適用）
    window.addEventListener('load', () => {
      btn.style.transform = `rotate(${window.scrollY}deg)`;
    });
    ```

<aside>
💬

**同じコードを2回書いているけれど…？**

`'scroll'` と `'load'` の中に全く同じ処理を書いており、「ちょっとコードが重複していて冗長だな」と感じたかもしれません。
実務では、このような重複を避けるために処理を**「関数（function）」**として1つにまとめ、両方のイベントから呼び出すのがスマートな書き方です。
関数の作り方については、**単元07「関数の定義と活用」**でじっくり学習します！

</aside>

## 2-3. ウィンドウサイズを監視する：リサイズイベント（resize）

もう1つの重要な全体イベントが、ブラウザのウィンドウサイズが変更された瞬間に発生する **`'resize'` イベント** です。

**【現在のウィンドウ幅の取得：`window.innerWidth` 】**

現在開いているブラウザの内側の横幅（ピクセル数）は、**`window.innerWidth`** で取得できます。

```jsx
window.addEventListener('resize', () => {
  console.log(`現在のブラウザ幅: ${window.innerWidth}px`);
});
```

**【実践：リアルタイム・ウィンドウ幅インジケーター】**

画面を伸縮するたびに現在のウィンドウ幅をリアルタイムに表示するUIを作成してみましょう。

**`index.html`** に表示用の要素を追加します：

```markup
<div class="size-display">
  現在の画面幅：<span id="window-width">0</span>px
</div>
```

**`js/main.js`**：

```jsx
const windowWidthText = document.getElementById('window-width');

// 画面を開いた瞬間の幅を表示
windowWidthText.textContent = window.innerWidth;

// ウィンドウがリサイズされるたびに数値を更新
window.addEventListener('resize', () => {
  windowWidthText.textContent = window.innerWidth;
});
```

## ⭐︎ 練習：リサイズイベントを活用してみよう

### 【基本】画面の「高さ」もリアルタイムに表示してみよう

現在は「画面幅」のみが表示されています。これに加えて、ウィンドウの**「高さ（縦幅）」**も一緒に取得して表示してみましょう。

ブラウザのウィンドウの高さは、**`window.innerHeight`** で取得できます。

1. `index.html` に高さを表示するための要素（`<span id="window-height">0</span>`）を追加します。
2. `js/main.js` でその要素を取得します。
3. 画面を開いた瞬間と、ウィンドウがリサイズされた瞬間の両方で、`window.innerHeight` の値を反映させましょう。
   （※ または、`.size-display` 全体をテンプレートリテラルで一気に書き換えるアプローチでもOKです）

- 正解のソースコード
    
    #### パターン1：各数値を `<span>` で個別に書き換える方法
    
    **`index.html`**
    ```markup
    <div class="size-display">
      現在の画面サイズ：<span id="window-width">0</span>px × <span id="window-height">0</span>px
    </div>
    ```
    
    **`js/main.js`**
    ```jsx
    const windowWidthText = document.getElementById('window-width');
    const windowHeightText = document.getElementById('window-height');
    
    // 画面を開いた瞬間の幅と高さを表示
    windowWidthText.textContent = window.innerWidth;
    windowHeightText.textContent = window.innerHeight;
    
    // ウィンドウがリサイズされるたびに数値を更新
    window.addEventListener('resize', () => {
      windowWidthText.textContent = window.innerWidth;
      windowHeightText.textContent = window.innerHeight;
    });
    ```
    
    #### パターン2：`.size-display` の `textContent` を一気に書き換える方法（テンプレートリテラル活用）
    
    **`index.html`**
    ```markup
    <div id="size-display" class="size-display">
      現在の画面サイズ：0px × 0px
    </div>
    ```
    
    **`js/main.js`**
    ```jsx
    const sizeDisplay = document.getElementById('size-display');
    // または const sizeDisplay = document.querySelector('.size-display');
    
    // 画面を開いた瞬間にテンプレートリテラルで一括書き換え
    sizeDisplay.textContent = `現在の画面サイズ：${window.innerWidth}px × ${window.innerHeight}px`;
    
    // ウィンドウがリサイズされるたびに数値を更新
    window.addEventListener('resize', () => {
      sizeDisplay.textContent = `現在の画面サイズ：${window.innerWidth}px × ${window.innerHeight}px`;
    });
    ```

### 【チャレンジ】画面幅に合わせて文字サイズを伸縮させてみよう

画面幅（`window.innerWidth`）の数値を使って、タイトル見出し（`#main-title`）の文字サイズ（`style.fontSize`）を画面幅に連動させてみましょう。

1. タイトル要素（`#main-title`）を `getElementById` で取得します。
2. 画面を開いた瞬間、およびリサイズイベントの中で、画面幅に応じた文字サイズを `style.fontSize` に代入してみましょう。
   （例：画面幅の25分の1のサイズにする場合 → `${window.innerWidth / 25}px`）
3. ブラウザの幅をぐーっと狭めたり広げたりして、文字サイズが滑らかに伸縮するか確認してみましょう！

- 正解のソースコード
    
    **`js/main.js`**
    ```jsx
    const mainTitle = document.getElementById('main-title');
    
    // 画面を開いた瞬間の文字サイズを設定（画面幅の1/25）
    mainTitle.style.fontSize = `${window.innerWidth / 25}px`;
    
    // リサイズされるたびに文字サイズを更新
    window.addEventListener('resize', () => {
      mainTitle.style.fontSize = `${window.innerWidth / 25}px`;
    });
    ```

# 3. クラス名の操作

ここまで、`element.style` を使って文字色や背景色、回転などをJavaScriptから直接書き換えてきました。

しかし、実際のWeb制作現場では**「あらかじめCSSにクラスを定義しておき、JavaScriptからはそのクラスを付け外しする」** という手法が標準として使われます。

<aside>
💡

**element.style の課題**

1. **JavaScriptのコードがデザイン情報で散らかる**
    
    要素の「色」「フォントサイズ」「余白」「背景」など、変更したいCSSプロパティが増えるたびに、JavaScript側のコードが何十行も長くなってしまいます。
    
2. **インラインスタイルになってしまう**
    
    `element.style` で変更すると、HTMLタグの中に直接 `style="..."` が書き込まれます（インラインスタイル）。インラインスタイルはCSSの優先順位が非常に強いため、外部CSSファイルからの上書きやレスポンシブ対応が難しくなります。
    
</aside>

---

## 3-1. 「状態クラス（State Class）」の設計思想

Web制作では、現在の状態を表す専用のクラスを用意して付け外しします。
これを **状態クラス（State Class）**と呼び、慣例として **`is-`** という接頭辞をつけて命名することが多いです。

| 状態クラス名 | 意味・使われる場面 |
| --- | --- |
| **`.is-active`** | アクティブ状態（現在選択されているタブ、押されているボタンなど） |
| **`.is-open`** | 開いている状態（開いたメニュー、開いたアコーディオンなど） |
| **`.is-visible`** | 表示されている状態（ふわっと現れたモーダルやトップへ戻るボタンなど） |

```css
/* 通常状態（CSSに書いておく） */
.btn {
  background-color: #ffffff;
  color: #333333;
}

/* is-active が付いたときの状態（CSSに書いておく） */
.btn.is-active {
  background-color: #0066cc;
  color: #ffffff;
}
```

JavaScriptの役割は、ボタンが押されたときにこの `.is-active` を付ける・外すことだけです。

---

## 3-2. クラスを追加する：`classList.add()`

要素に指定したクラスを追加します。

すでにそのクラスが付いている場合は、二重に追加されることはありません。

```jsx
要素.classList.add('クラス名');
```

```jsx
const btn = document.getElementById('btn');

// 'is-active' クラスを追加する
btn.classList.add('is-active');
```

---

## 3-3. クラスを削除する：`classList.remove()`

要素から指定したクラスを取り除きます。

最初からそのクラスが付いていない場合でも、エラーにならず安全に無視されます。

```jsx
要素.classList.remove('クラス名');
```

```jsx
// 'is-active' クラスを削除する
btn.classList.remove('is-active');
```

---

## 3-4. クラスを反転切り替えする：`classList.toggle()`

クラスが「付いていなければ追加し、付いていれば削除する」という**反転切り替え（トグル）**を一発で行います。

スイッチのON/OFFや、メニューの開閉などを作る際に最も頻繁に使われる命令です。

```jsx
要素.classList.toggle('クラス名');
```

```jsx
btn.addEventListener('click', () => {
  // クリックするたびに is-active の追加と削除が交互に切り替わる
  btn.classList.toggle('is-active');
});
```

---

## 3-5. クラスの有無を判定する：`classList.contains()`

要素が指定したクラスを持っているかどうかを確認し、結果を真偽値（**`true`** または **`false`**）で返します。

```jsx
const hasClass = 要素.classList.contains('クラス名');
```

```jsx
btn.addEventListener('click', () => {
  btn.classList.toggle('is-active');
  
  if (btn.classList.contains('is-active')) {
	  btn.textContent = 'ボタンはアクティブ状態です';
	} else {
	  btn.textContent = 'ボタンは通常状態です';
	}
})
```

<aside>
⚠️

**`classList` の引数にはドット（`.`）を付けない**

`querySelector` ではセレクタとしてドット（`.btn`）を付けましたが、`classList` は「クラスを操作するための専用命令」なので、**ドットは不要**です。

- ❌ `btn.classList.add('.is-active');` （`.is-active` という奇妙なクラス名が付いてしまう）
- ⭕ `btn.classList.add('is-active');` （ドットを付けずに名前だけを指定する）
</aside>

---

## 3-6. `classList` の命令まとめ

| 命令 | 役割 | 戻り値 |
| --- | --- | --- |
| **`element.classList.add('name')`** | クラスを追加する | なし（`undefined`） |
| **`element.classList.remove('name')`** | クラスを削除する | なし（`undefined`） |
| **`element.classList.toggle('name')`** | クラスを反転切り替えする（ON/OFF） | 付与されたら `true`、削除されたら `false` |
| **`element.classList.contains('name')`** | クラスがついているか確認する | ついていれば `true`、なければ `false` |

## 4-4. `js/main.js` のロジック（クラスのトグル処理）

### ⭐︎ 練習：ボタンクリックでクラスをトグルさせよう

HTMLと通常状態のCSSが準備できたので、まずはJavaScriptでボタンがクリックされたときに `.is-open` クラスを付け外し（トグル）する処理を書いてみましょう。

1. 操作したい2つの要素（`#menu-btn` と `#nav-menu`）を取得して変数に代入します。
2. `menuBtn` に対して `'click'` イベントリスナーを設定します。
3. ボタンがクリックされたら、`menuBtn` と `navMenu` の両方に対して `classList.toggle('is-open')` を実行してください。

- 正解のソースコード
    
    **`js/main.js`**
    ```jsx
    // 1. 操作したい要素を取得する
    const menuBtn = document.getElementById('menu-btn');
    const navMenu = document.getElementById('nav-menu');
    
    // 2. ボタンクリックでクラスをトグル（切り替え）する
    menuBtn.addEventListener('click', () => {
      menuBtn.classList.toggle('is-open');
      navMenu.classList.toggle('is-open');
    });
    ```

<aside>
💡

**クリックしても見た目が変わらない！？（DevToolsで確認してみよう）**

このコードを書いてブラウザでボタンをクリックしても、**まだ画面の見た目は何も変化しません**。
しかし、ブラウザのデベロッパーツール（検証）の「Elements（要素）」タブを開いた状態でボタンをクリックしてみてください。

クリックするたびに、HTMLタグのクラス名が以下のようにリアルタイムで切り替わっているはずです！
- `<button class="menu-btn">` ⇄ `<button class="menu-btn is-open">`
- `<nav class="nav-menu">` ⇄ `<nav class="nav-menu is-open">`

「**JavaScriptの役割はクラスを付け外しすることだけ**」。
あとは、この `.is-open` が付いたときの見た目をCSSで作れば完成です！

</aside>

## 4-5. 開いた状態（`.is-open`）のスタイリング

### ⭐︎ 練習：開いた状態のスタイルを定義して完成させよう！

JavaScriptによって `.is-open` クラスが正しく付け外しされるようになったので、最後に `.is-open` が付いたときのスタイルを `css/style.css` に追加してハンバーガーメニューを完成させましょう。

#### 【課題内容】
1. **メニューが開いた状態（`.nav-menu.is-open`）**:
   画面外（`right: -260px`）にあるメニューを、画面右端（`right: 0;`）にスライドインさせましょう。
2. **ボタンが「×」に変形した状態（`.menu-btn.is-open span`）**:
   - 1本目のバー（`span:nth-child(1)`）：下へ8px移動して45度回転（`transform: translateY(8px) rotate(45deg);`）
   - 2本目のバー（`span:nth-child(2)`）：透明にして非表示（`opacity: 0;`）
   - 3本目のバー（`span:nth-child(3)`）：上へ8px移動して-45度回転（`transform: translateY(-8px) rotate(-45deg);`）

- 正解のソースコード
    
    **`css/style.css` に追加するコード**
    ```css
    /* ボタンが開いた時（×印に変形） */
    .menu-btn.is-open span:nth-child(1) {
      transform: translateY(8px) rotate(45deg);
    }
    
    .menu-btn.is-open span:nth-child(2) {
      opacity: 0;
    }
    
    .menu-btn.is-open span:nth-child(3) {
      transform: translateY(-8px) rotate(-45deg);
    }
    
    /* メニューが開いた時（画面内にスライドイン） */
    .nav-menu.is-open {
      right: 0;
    }
    ```

スタイルが保存できたら、ブラウザでボタンをクリックしてみましょう。
ボタンが「×」に変わり、メニューが右からスッと現れる完璧なハンバーガーメニューの完成です！
