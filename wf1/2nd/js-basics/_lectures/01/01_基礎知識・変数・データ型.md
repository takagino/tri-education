# 1. **JavaScriptとは？**

JavaScript（ジャバスクリプト）とは、プログラミング言語のひとつである。**Javaと名前が似ているが、全く異なるプログラミング言語**である。

ウェブブラウザ上で動作し動的なウェブサイト構築やリッチインターネットアプリケーションの開発に用いられる。また、2010年以降はNode.jsなどのサーバサイドJavaScript実行環境や各種ライブラリの充実により、Web開発の全ての領域で活用されるようになってきている。

[JavaScriptが辿った変遷](https://zenn.dev/naoki_mochizuki/articles/46928ccb420ee733f78f)

**【Webを支える3大プログラミング言語の役割】**

- **HTML：構造・骨組み**（見出し、段落、画像、リンクを配置する）
- **CSS：見た目・装飾**（色、レイアウト、余白、タイポグラフィを整える）
- **JavaScript：動き・振る舞い**（クリックでメニューが開く、画像が切り替わる、入力チェックをする）

**【目指せる職業】**

- HTML + CSS：マークアップエンジニア
- HTML + CSS + JavaScript：フロントエンドエンジニア
- HTML + CSS + JavaScript + PHP：サーバーサイドエンジニア（バックエンドエンジニア）
- HTML + CSS + JavaScript + PHP + データベース・インフラ構築：フルスタックエンジニア

[Developer Roadmaps - roadmap.sh](https://roadmap.sh/)

## 1-2. **プログラミング（JavaScript）が書けるようになるコツ**

1. **実現したい動きの解像度を上げること**
    
    基本的にJavaScriptがWebサイトで行っているのは、「ある要素の内容（テキストや画像など）やCSSの値を変化させているだけ」です。
    いきなりコードを書こうとするのではなく、まずは「どのタイミングで、どの要素の、何を変化させているのか」を言葉にして考えるようにしましょう。
    
2. **小さな塊（チャンク）に分け、手順を構築すること**
    
    複雑な動きも、分解すれば単純な処理の連続です。
    頭の中だけで考えるのではなく、まずはエディタ上に **`// 1. ボタンを取得する`** **`// 2. メニューを取得する`** のように、日本語のコメントアウトで手順（アルゴリズム）を書き出す癖をつけてください。
    
3. **エラーを恐れず、コンソール画面と友達になること**
    
    動かない時は必ず原因があります。「なんとなく書き直す」のではなく、ブラウザの検証ツール（Consoleタブ）に表示される赤いエラーメッセージを読むことが、自力で解決する（デバッグ）ための第一歩です。
    
4. 「楽しいと理解が早い、理解できると楽しくなる」
    
    どうしたら楽しく学べるかを常に考え、自分なりに工夫する姿勢が上達への最大の近道です。
    与えられた課題のコードをただ写すだけでなく、自分の好きなデザインや興味のある趣味のテーマなどに絡めて実装を試みることで、プログラミングは一気に面白くなります。

## **3-2. 基本的な書き方ルール**

- **文の末尾にはセミコロン（`;`）をつける**
    
    文の終わりには「`;`」をつけるのがJavaScriptの標準作法です。（省略も可能ですが、意図しない文の結合トラブルを防ぐため必ずつける習慣をつけましょう）
    
- **半角英数字・記号で記述する**
    
    プログラムのコードはすべて半角で入力します。特に**全角スペース**がコード内に紛れ込むと、見た目では気づきにくいエラーの原因になるため注意してください。
    
- **大文字と小文字は区別される**
    
    例えば `console.log` を `Console.log` と書いたり、変数名を `name` と `Name` で書くと別物として扱われ、エラーになります。
    
- **スペースや改行は自由に入れてよい**
    
    コードを読みやすくするためにスペースや改行を自由に使えます。ただし、単語（`console` や `let` など）の途中にスペースを入れてはなりません。
    
- **文字列はクォーテーションで囲む**
    
    文字列（文字の並び）を扱う場合はシングルクォート（`'`）またはダブルクォート（`"`）で囲みます。
    ※HTMLでは属性値をダブルクォート（`"`）で囲むことが多いため、この授業では文字列を**シングルクォート（`'`）**で囲む記述に統一します。

## **3-3. コンソールへの出力（console.logと主な命令）**

コンソール画面にデータやメッセージを出力する命令です。

⭐️ コンソール画面を見て、警告（黄色背景）やエラー（赤色背景）、表形式でどのように表示されるか確認してみましょう。

**【よく使う console の主な命令】**

| 命令 | 説明 |
| --- | --- |
| **`console.log()`** | 通常のメッセージを出力する（最も頻繁に使用する） |

# **4. 変数**

## **4-1. 変数とは？**

なんらかの値（データ）を、名前をつけて保存しておく仕組み（**「名前のついた箱」**）のこと。

<aside>
💡

**変数の使い所**

- **同じ値が何度も出てくるとき：** 一箇所を変更するだけで、使っている全ての箇所に反映できる。
- **値を変化させたいとき：** ゲームのスコア、HPの増減、カートの合計金額などを管理できる。
</aside>

**【変数の基本的な使い方】**

1. 変数を宣言する。
2. 宣言した変数に値を代入する。
3. 必要な時に変数に保存された値を取り出す（参照）、または書き換える。

```jsx
let 変数名; //変数の宣言
let 変数名 = 初期値; //宣言と同時に値を代入する

//例
let name = 'takagi';
console.log(name);
```

---

## **4-2. 変数宣言（const と let）**

現代のJavaScriptでは、変数を宣言するキーワードとして主に **`const`** と **`let`** を使用します。

**【定数（const）の使い方】**

一度値を入れたら、後から別の値を入れ直す（再代入する）ことができない宣言です。

**`index.html`**

```jsx
const name = 'takagi';
console.log(name);
```

- **宣言と同時に値を代入しないとエラーになる**
    
    ```jsx
    const name;
    // SyntaxError: Missing initializer in const declaration（定数の初期化忘れエラー）
    ```
    
- **値を再代入しようとするとエラーになる**
    
    ```jsx
    const name = 'takagi';
    name = 'kawaguchi';
    // TypeError: Assignment to constant variable.（定数への再代入エラー）
    ```
    

**【変数（let）の使い方】**

後から中身の値を変更（再代入）できる宣言です。

**`index.html`**

```jsx
let name = 'takagi';
console.log(name); // takagi

// 値の再代入（※再代入するときは let は不要）
name = 'kawaguchi';
console.log(name); // kawaguchi
```

**【値の再宣言のエラー】**

同じ変数名で重複して変数宣言を行うことを「値の再宣言」と言います。**`let`** や **`const`** では再宣言を行うとエラーになります。

```jsx
let name = 'takagi';
let name = 'kawaguchi';
// SyntaxError: Identifier 'myName' has already been declared（再宣言エラー）
```

**【const と let の比較】**

| キーワード | 種類 | 再代入 | 再宣言 | 使い分けのルール |
| --- | --- | --- | --- | --- |
| **`const`** | **定数** | ❌ **不可** | ❌ **不可** | **原則すべて `const` で書く**（値が変わらない箱） |
| **`let`** | **変数** | ⭕ **可能** | ❌ **不可** | **後から中身を上書き・変更する場合のみ使う** |

<aside>
⚠️

**`var` は現代では使用しない**

古い書籍やWeb記事では `var` という宣言が見られますが、同じ変数名を何度でも再定義できてしまう問題があり、予期せぬバグの温床となるため現代の実務では使用しません。

```jsx
// varの問題：同じ名前で再宣言できてしまい、意図せず値が上書きされる
var name = 'takagi';
var name = 'kawaguchi'; // エラーにならず上書きされてしまう
console.log(name);
```

</aside>

<aside>
💡

**プログラムにおける等号（`=`）の意味**

プログラムにおける「`=`」は、数学のような「左辺と右辺が等しい」という意味ではありません。

「**右辺の値を左辺の変数に入れる（代入する）**」という命令（**代入演算子**）を表します。

</aside>

**【値が未代入の場合は「undefined」となる】**

`let` で変数を宣言しただけで初期値を代入していない場合、値を取り出すと「未定義」を表す **`undefined`** が出力されます。

```jsx
let score;
console.log(score); // undefined
```

## **4-3. 変数のルールと命名規則**

**【使える文字・使えない文字】**

```jsx
let $price;         // ⭕ OK: $記号が使用できる
let _title;         // ⭕ OK: _（アンダースコア）が使用できる
let menuBtn;        // ⭕ OK: 小文字のアルファベットが使用できる
let TITLE;          // ⭕ OK: 大文字のアルファベットが使用できる
let es2026;         // ⭕ OK: 数字は先頭以外なら使用できる
let 日本語の変数名;   // ⭕ OK: 一部の漢字や日本語も使用できる（※しかし現場では厳禁）

let na-me;          // ❌ NG: ハイフン（-）は引き算記号とみなされるため使用できない
let name!;          // ❌ NG: ! などの記号は使用できない
let 1st;            // ❌ NG: 数字から始めることはできない
```

**【複数の単語を組み合わせた命名パターン】**

```jsx
//スネークケース**（snake_case）**：単語と単語をアンダースコア(_)で結合し、すべて小文字で表現する
let member_name = 'takagi';

//キャメルケース**（CamelCase）**：単語と単語を結合して、1つ目の単語は小文字で始め、2つ目以降の単語の先頭は大文字にする
//最近の主流
let memberName = 'takagi';

//パスカルケース**（PascalCase）**：キャメルケースと似ているが、一番最初の単語も大文字で始める
//一般的に変数には使用しない
let MemberName = 'takagi';
```

**【予約語】**

JavaScriptの言語仕様としてあらかじめ用途が決まっている単語（予約語）は、変数名として使用できません。

```jsx
// let var;  // ❌ NG: var は予約語のため使用できない
// let if;   // ❌ NG: if は予約語のため使用できない
```

[字句文法 - JavaScript | MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Lexical_grammar#%E4%BA%88%E7%B4%84%E8%AA%9E)

**【複数の変数を同時に宣言する】**

変数同士を「`,`（カンマ）」で区切ることで、同時に複数の変数を定義できます。

```jsx
let userName = 'takagi',
    userAge = 39,
    userJob = '講師';

console.log(userJob); // 講師
```

## **⭐︎ 確認クイズ**

エラーとなるのはどの変数宣言でしょうか？

```jsx
1. let $price = 120;
2. let newCount;
3. let class = 'webdesign';
4. const _age01 = 40;
5. const get_value;
```

- **【正解】**
    
    **3** と **5** 
    
    - **3**：`class` はJavaScriptの予約語（クラス定義用）のため変数名に使えません。
    - **5**：`const`（定数）は宣言と同時に初期値を代入する必要があるため、代入がないと `Missing initializer in const declaration` エラーになります。

気になる人は「良い変数名」で検索してみましょう。

</aside>

# **5. 演算子**

演算子（オペレータ）とは、値をもとに何らかの処理（計算や比較など）を行い、その結果を返す記号のこと。

演算子によって処理される値（演算の対象）のことを**オペランド**と呼びます。

## **5-1. 算術演算子**

数値計算に使う基本的な演算子です。

| 演算子 | 名前 | 記述例 | 結果 |
| --- | --- | --- | --- |
| **`+`** | 加算（足し算） | `6 + 9` | `15` |
| **`-`** | 減算（引き算） | `10 - 15` | `-5` |
| **`*`** | 乗算（掛け算） | `3 * 7` | `21` |
| **`/`** | 除算（割り算） | `10 / 5` | `2` |
| **`%`** | 剰余（割った余り） | `7 % 3` | `1` |
| **`**`** | べき乗（累乗） | `3 ** 2` | `9` |

**`index.html`**

```jsx
console.log(6 + 9);   // 結果：15
console.log(10 - 15); // 結果：-5
console.log(3 * 7);   // 結果：21
console.log(10 / 5);  // 結果：2
console.log(7 % 3);   // 結果：1（7÷3 = 2 あまり 1）
console.log(3 ** 2);  // 結果：9（3の2乗 = 3×3）
```

**【変数による計算】**

変数に代入された値を使って計算し、結果を再び変数に代入することもできます。

```jsx
let x = 1;

x = x + 1; // 変数xの値(1)に1を足して、変数xに再代入する
console.log(x); // 2

x = x * 3; // 変数xの値(2)に3を掛けて、変数xに再代入する
console.log(x); // 6
```

---

## **5-2. 自己代入演算子（複合代入演算子）**

自己代入演算子を使うと、「計算してその変数自身に再代入する」処理をより簡潔に記述できます。

| 演算子 | 意味 | 同じ意味の式 |
| --- | --- | --- |
| **`+=`** | 加算の自己代入 | `a = a + b` |
| **`-=`** | 減算の自己代入 | `a = a - b` |
| **`*=`** | 乗算の自己代入 | `a = a * b` |
| **`/=`** | 除算の自己代入 | `a = a / b` |
| **`%=`** | 剰余の自己代入 | `a = a % b` |
| **`**=`** | べき乗の自己代入 | `a = a ** b` |

**`index.html`**

```jsx
let score = 100;
score += 20; // score = score + 20 と同じ
console.log(score); // 120

score -= 50; // score = score - 50 と同じ
console.log(score); // 70
```

---

## **5-3. インクリメントとデクリメント**

変数の値を「1だけ増やす」「1だけ減らす」処理をさらに短く書くための演算子です。

| 演算子 | 名前 | 意味 | 同じ意味の式 |
| --- | --- | --- | --- |
| **`++`** | インクリメント | 変数の値を1増やす | `a += 1` または `a = a + 1` |
| **`--`** | デクリメント | 変数の値を1減らす | `a -= 1` または `a = a - 1` |

**`index.html`**

```jsx
let count = 0;
count++; // 値を1増やす
console.log(count); // 1

count++; // さらに1増やす
console.log(count); // 2

count--; // 値を1減らす
console.log(count); // 1
```

<aside>
💡

インクリメント（`++`）は、今後学習する「繰り返し処理（for文）」のカウントアップ処理で必ずと言っていいほど使います。

</aside>

## **⭐︎ 確認クイズ**

以下のコードを実行したとき、コンソールの【 ① 】〜【 ⑥ 】に出力される数値は何でしょうか？

```jsx
// Q1.
console.log('Q1', 14 % 4); // 出力: 【 ① 】

// Q2.
console.log('Q2', 2 ** 4); // 出力: 【 ② 】

// Q3.
let a = 15;
a += 7;
console.log('Q3', a); // 出力: 【 ③ 】

// Q4.
const b = 3;
b /= 3;
console.log('Q4', b); // 出力: 【 ④ 】

// Q5.
let count = 10;
count++;
count++;
count--;
console.log('Q5', count); // 出力: 【 ⑤ 】
```

- **【正解】**
    - **Q1： `2`**
        
        14 ÷ 4 = 3 あまり **`2`** です。
        
    - **Q2： `16`**
        
        2の4乗（2 × 2 × 2 × 2）なので **`16`** です。
        
    - **Q3： `22`**
        
        `a += 7` は `a = a + 7`（15 + 7）と同じなので **`22`** です。
        
    - **Q4： エラー**
        
        `const`（定数）で宣言された変数 `b` に対して、自己代入演算子（`/=`）を使って値を上書き（再代入）しようとしているためエラーになります。
        
    - **Q5： `11`**
        
        10にインクリメントで1足され（11）、もう一度1足され（12）、最後にデクリメントで1引かれるため **`11`** です。

# **6. データ型とテンプレートリテラル**

## **6-1. 基本データ型**

JavaScriptで扱うデータにはいくつかの「型（データタイプ）」があります。

| データ型 | 英語名 | 説明 | 記述例 |
| --- | --- | --- | --- |
| **文字列型** | `String` | 文字の並びを表すデータ。シングルクォート（`'`）またはダブルクォート（`"`）で囲む。 | `'こんにちは'`, `'JavaScript'`, `'123'` |
| **数値型** | `Number` | 計算ができる数値のデータ。クォートで囲まない。 | `100`, `3.14`, `-50` |
| **真偽値型** | `Boolean` | 「正しい（`true`）」か「正しくない（`false`）」の2値のみを表すデータ。条件分岐で使用する。 | `true`, `false` |

**【データの型を調べる typeof】**

データ型を確認したいときは **`typeof`** 演算子を使用します。

**`index.html`**

```jsx
console.log(typeof 'Hello'); // "string"
console.log(typeof 100);     // "number"
console.log(typeof true);    // "boolean"
```

| 命令 | 説明 |
| --- | --- |
| **`typeof`** | 値のデータ型を文字列として返す演算子 |

---

## **6-2. 文字列の結合と計算の注意点**

文字列（文字の並び）同士は、プラス記号（**`+`**）を使って結合できます。

**`index.html`**

```jsx
/* 文字列同士は、プラス（+）を使って結合できる */
console.log('takagi' + 'hirotaka'); // "takagihirotaka"

/* 文字列と数値を結合すると、数値は文字列に変換される */
console.log(10 + 'px'); // "10px"

/* 文字列と変数を結合すると、変数の値が埋め込まれる */
let val = 1;
console.log('url(' + val + '.png)'); // "url(1.png)"

/* 数値と数値を結合すると、加算（計算）になる */
console.log(20 + 10); // 30
```

<aside>
⚠️

**初心者が必ずハマる「足し算の罠」**

引き算（`-`）や掛け算（`*`）、割り算（`/`）は文字列の数字であっても自動で数値として計算されますが、**`+` 記号だけは片方に文字列があると文字の連結になってしまいます**。
フォームから入力値を受け取った時などに頻出するバグなので、十分に注意しましょう！

```jsx
// ⭕ 数値同士の足し算（計算）
console.log(100 + 200);     // 300

// ⚠️ 文字列同士の足し算（文字がつながる）
console.log('100' + '200'); // "100200"

// 🚨 最も危険！数値と文字列の足し算
console.log(100 + '200');   // "100200" （数値が文字列に変換されて結合される）
```

</aside>

## **6-3. テンプレートリテラル**

文字列全体を **バッククォート（ ``` ）** で囲むことで、文字列の中に変数や計算式を自然に埋め込むことができる現代の記法です。

**【バッククォートの入力方法】**

- **JIS（日本語）配列キーボード**：『**`Shift`** + **`@`**』
- **US配列キーボード**：『**`~`**』のキー単体（タブキーの上）

**【特徴とメリット】**

- **変数の埋め込み：** **`${変数名}`** でスッキリ記述できる（`+` による複雑なパズルから解放される）。
- **計算式の埋め込み：** **`${2 + 5}`** のように波括弧内で計算ができる。
- **改行の維持：** 文字列内の改行がそのまま反映される。

**`index.html`**

```jsx
const person = 'JS太郎';
const points = 120;

// 昔の書き方（+で繋ぐ：クォーテーションのミスが起きやすい）
console.log('こんにちは、' + person + 'さん！ 現在のポイントは ' + points + 'pt です。');

// 現代の書き方（テンプレートリテラル）
console.log(`こんにちは、${person}さん！ 現在のポイントは ${points}pt です。`);

// 式の埋め込み
console.log(`2 + 5 equal ${2 + 5}`); // "2 + 5 equal 7"

// 改行の維持
console.log(`Hello
world`);
```
