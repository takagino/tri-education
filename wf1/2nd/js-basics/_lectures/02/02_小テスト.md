## 問題一覧（全10問）

### 第1問 【定着度：getElementByIdの引数指定】
- **問題文**:
HTML内に <h1 id="title">見出し</h1> があります。この要素を document.getElementById() で取得するコードとして正しいものはどれでしょうか？

- **選択肢**:
document.getElementById('#title');
document.getElementById('title');
document.getElementById('.title');
document.getElementById('<title>');

- **正解**: document.getElementById('title');
- **解説**:
getElementById は「ID名で探す」という専用の命令であるため、シャープ（#）は不要で、純粋なIDの名前だけ（'title'）を渡します。'#title' と書いてしまうと、#title という名前のIDを探そうとして要素が見つからず、null が返ってしまいます。

---

### 第2問 【定着度：querySelectorのセレクタ記法】
- **問題文**:
HTML内に <p class="desc">説明文</p> があります。この要素を document.querySelector() で取得するコードとして正しいものはどれでしょうか？

- **選択肢**:
document.querySelector('desc');
document.querySelector('.desc');
document.querySelector('#desc');
document.querySelector('class="desc"');

- **正解**: document.querySelector('.desc');
- **解説**:
querySelector はCSSと同じセレクタ記法を使って要素を指定します。クラス名を指定する場合は、CSSと同様に先頭にドット（.）を付けて '.desc' と指定します。

---

### 第3問 【バグ検出：<script defer> の役割とnullエラー】
- **問題文**:
<head> タグ内で <script src="js/main.js"></script> と記述し、main.js の中で document.getElementById('main-title') を実行したところ、コンソールに null と出力されました。HTML側に <h1 id="main-title"> は存在しています。この原因として最も適切なものはどれでしょうか？

- **選択肢**:
JavaScriptで大文字と小文字が間違っているため
HTMLの解析が終わる前にJavaScriptが実行され、まだ要素が画面上に作られていなかったため
getElementById は <head> 内でしか呼び出せないため
JavaScriptで h1 要素を取得することは禁止されているため

- **正解**: HTMLの解析が終わる前にJavaScriptが実行され、まだ要素が画面上に作られていなかったため
- **解説**:
HTMLファイルは上から下へ順番に読み込まれます。<head> 内のスクリプトに defer 属性を付けていないと、HTMLの本文（<body>）が作られる前にJavaScriptが実行されてしまうため、要素が見つからず null になります。<script defer src="..."> と書くことで、HTMLの構造をすべて読み込んでから安全にJavaScriptを実行できます。

### 第4問 【推論力：console.log と console.dir の違い】
- **問題文**:
取得した要素の内部設定やプロパティ一覧（textContent や style など）を詳しくツリー形式で確認したいとき、最も適したコンソール出力命令はどれでしょうか？

- **選択肢**:
console.log(element);
console.dir(element);
console.error(element);
console.warn(element);

- **正解**: console.dir(element);
- **解説**:
console.log() は要素を「HTMLタグの見た目」としてコンソールに表示します。一方、console.dir() は要素が内部で持っているプロパティや設定値の一覧（命令や値の塊）をツリー形式で展開して表示するため、どんなプロパティが存在するか確認する際に適しています。

---

### 第5問 【定着度：最上位要素のショートカット】
- **問題文**:
Webページの最上位にある <html> 要素（ルート要素）を取得するJavaScriptのショートカットプロパティとして正しいものはどれでしょうか？

- **選択肢**:
document.html
document.root
document.documentElement
document.head

- **正解**: document.documentElement
- **解説**:
<body> 要素のショートカットは document.body ですが、<html> 要素は document.html ではなく document.documentElement を使用します（document.html というプロパティは存在せず undefined になります）。

---

### 第6問 【定着度：DOMツリーの用語】
- **問題文**:
DOMツリーにおいて、<h1> や <p> などのHTMLタグそのものを表すノードの種類として正しいものはどれでしょうか？

- **選択肢**:
テキストノード（Text Node）
要素ノード（Element Node）
ルートノード（Root Node）
属性ノード（Attribute Node）

- **正解**: 要素ノード（Element Node）
- **解説**:
DOMツリーを構成する部品を「ノード」と呼びます。そのうち、<h1> や <p> などのHTMLタグそのものは「要素ノード（Element Node）」、タグの中に挟まれた文字データは「テキストノード（Text Node）」と呼びます。

### 第7問 【推論力：textContentによる中身の参照】
- **問題文**:
以下のHTML構造があるとき、console.log(document.body.textContent); を実行すると出力される内容として最も適切なものはどれでしょうか？

```html
<body>
  <h1>こんにちは</h1>
  <p>Web制作の<strong>基礎</strong>を学びます。</p>
</body>
```

- **選択肢**:
<h1>こんにちは</h1><p>Web制作の<strong>基礎</strong>を学びます。</p>
タグがすべて取り除かれたテキスト文字（「こんにちは」や「Web制作の基礎を学びます。」など）だけが取得される
null
エラーが発生する

- **正解**: タグがすべて取り除かれたテキスト文字（「こんにちは」や「Web制作の基礎を学びます。」など）だけが取得される
- **解説**:
textContent で要素の中身を参照（読み取り）すると、内部に含まれるすべてのHTMLタグ（<h1>, <p>, <strong> など）が削ぎ落とされ、純粋なテキスト文字のみが連結されて取得されます。タグ構造も含めて取得したい場合は innerHTML を使用します。

---

### 第8問 【バグ検出：textContentにHTMLタグを代入した場合】
- **問題文**:
取得した要素 title に対し、以下のコードを実行しました。ブラウザの画面にはどのように表示されるでしょうか？

```javascript
title.textContent = '<strong>重要なお知らせ</strong>';
```

- **選択肢**:
「重要なお知らせ」という文字が太字で表示される
<strong>重要なお知らせ</strong> というタグ文字がそのまま画面に表示される
何も表示されず空白になる
JavaScriptのエラーが発生する

- **正解**: <strong>重要なお知らせ</strong> というタグ文字がそのまま画面に表示される
- **解説**:
textContent は渡された文字列をHTMLタグとして解釈せず、ただの「文字データ」として扱います。そのため、<strong> というタグ文字自体がそのまま画面に描画されます。太字として装飾させたい場合は、HTMLタグとして解釈する innerHTML を使用する必要があります。

---

### 第9問 【定着度：JavaScriptでのスタイル指定（キャメルケース）】
- **問題文**:
要素 box の背景色を黄色（'yellow'）に変更したいです。JavaScript（element.style）のコードとして正しいものはどれでしょうか？

- **選択肢**:
box.style.background-color = 'yellow';
box.style.backgroundColor = 'yellow';
box.style.BackgroundColor = 'yellow';
box.style.background_color = 'yellow';

- **正解**: box.style.backgroundColor = 'yellow';
- **解説**:
JavaScriptではハイフン（-）が引き算の記号とみなされてしまうため、CSSのケバブケース（background-color）はキャメルケース（backgroundColor：2単語目の先頭を大文字にする）に変換して指定します。また、先頭の文字は小文字です。

---

### 第10問 【推論力：addEventListenerの基本形】
- **問題文**:
ボタン要素 btn がクリックされたときに、画面の見出し title のテキストを '完了' に変更したいです。空欄に入る適切な記述はどれでしょうか？

```javascript
btn.addEventListener(【 空欄 】, () => {
  title.textContent = '完了';
});
```

- **選択肢**:
'onclick'
'click'
'press'
'hover'

- **正解**: 'click'
- **解説**:
addEventListener の第1引数に指定するイベントの種類（イベント名）では、'on' を付けずにイベント名そのものを指定します。クリックイベントの場合は 'click' を指定します（'onclick' はHTMLの属性名や古いプロパティ名です）。
