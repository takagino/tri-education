### 第1問 【定着度：Math.random() の戻り値の範囲】
- **問題文**:
JavaScriptの組み込みオブジェクトである Math.random() が返す数値の範囲として正しいものはどれでしょうか？

- **選択肢**:
0 以上 1 未満のランダムな小数（0 は含まれるが、1 は絶対に含まれない）
0 以上 1 以下のランダムな小数（0 も 1 も含まれる）
1 以上 100 以下のランダムな整数
-1 以上 1 以下のランダムな小数

- **正解**: 0 以上 1 未満のランダムな小数（0 は含まれるが、1 は絶対に含まれない）
- **解説**:
Math.random() は 0 以上 1 未満（0 <= x < 1）の小数をランダムに生成して返します。0 ちょうどが出る可能性はありますが、1 ちょうどが出ることは絶対にありません。そのため、実務で使えるきれいな整数を作るには掛け算や Math.floor() と組み合わせる必要があります。

### 第2問 【定着度：端数処理メソッド（floor / ceil / round）の違い】
- **問題文**:
変数 num の値が 4.6 のとき、小数点以下を「切り捨て」て 4 にしたいです。使用すべき Math オブジェクトのメソッドとして正しいものはどれでしょうか？

- **選択肢**:
Math.floor(num)
Math.ceil(num)
Math.round(num)
Math.down(num)

- **正解**: Math.floor(num)
- **解説**:
Math.floor() は床（floor）を意味し、小数点以下を切り捨てます（4.6 は 4 になります）。Math.ceil() は天井（ceiling）で切り上げ（4.6 は 5）、Math.round() は四捨五入（4.6 は 5）を行います。ランダムな整数生成や配列のインデックス計算では、切り捨てを行う Math.floor() が最も頻繁に使われます。

### 第3問 【推論力：ランダムな整数の生成式】
- **問題文**:
サイコロのように、1 から 6 までの整数（1, 2, 3, 4, 5, 6）をランダムに1つ生成するコードとして正しいものはどれでしょうか？

- **選択肢**:
Math.floor(Math.random() * 6) + 1
Math.floor(Math.random() * 6)
Math.floor(Math.random() * 7)
Math.round(Math.random() * 6)

- **正解**: Math.floor(Math.random() * 6) + 1
- **解説**:
Math.floor(Math.random() * 6) を実行すると、生成される整数は 0 から 5 までの 6 通り（0, 1, 2, 3, 4, 5）になります。サイコロの目は 1 から 6 なので、全体に + 1 を足すことで 1 から 6 の整数を作ることができます。

### 第4問 【推論力：配列とランダムインデックスの組み合わせ】
- **問題文**:
配列 omikujiList からランダムに1つの要素を取り出してコンソールに表示したいです。コード中の /* 空欄 */ に入る適切な記述はどれでしょうか？

```javascript
const omikujiList = ['大吉', '中吉', '小吉', '吉', '凶'];
const randomIndex = /* 空欄 */;

console.log(omikujiList[randomIndex]);
```

- **選択肢**:
Math.floor(Math.random() * omikujiList.length)
Math.floor(Math.random() * 5) + 1
Math.random(omikujiList.length)
omikujiList.length[Math.random()]

- **正解**: Math.floor(Math.random() * omikujiList.length)
- **解説**:
要素数が 5 個の配列のインデックスは 0 から 4 です。Math.floor(Math.random() * omikujiList.length) と書くことで、0 から omikujiList.length - 1 までのランダムな整数が生成され、配列のインデックスと一致します。数値を直接 5 と書かず omikujiList.length を使うことで、将来配列の要素数が増減してもコードを書き直す必要がなくなります。

### 第5問 【定着度：for文とwhile文の使い分けの基準】
- **問題文**:
JavaScriptにおける for 文と while 文の使い分けの基準として、最も適切な説明はどれでしょうか？

- **選択肢**:
for 文は繰り返す回数が事前に決まっているときに使い、while 文は特定の条件を満たすまで繰り返す回数が決まっていないときに使う
for 文は配列にしか使えず、while 文は数値の計算にしか使えない
for 文は画面の表示に使い、while 文はコンソールの出力に使う
現代のJavaScriptでは while 文は廃止されており、すべての繰り返しは for 文で書かなければならない

- **正解**: for 文は繰り返す回数が事前に決まっているときに使い、while 文は特定の条件を満たすまで繰り返す回数が決まっていないときに使う
- **解説**:
「10回繰り返す」「配列の要素数ぶん繰り返す」のように事前にループ回数が決まっている場合は for 文が適しています。一方、「直前と異なる番号が出るまで再抽選する」「目標の目が出るまでサイコロを振り続ける」のように、何回繰り返すか事前に分からない場合は while 文を使用します。

### 第6問 【バグ検出：while文における無限ループの原因】
- **問題文**:
以下の while 文を実行したところ、ブラウザがフリーズして応答しなくなってしまいました。その原因として最も適切なものはどれでしょうか？

```javascript
let count = 0;

while (count < 3) {
  console.log(count);
}
```

- **選択肢**:
ループの中で count の値を増やす処理（count++ など）を書いていないため、count < 3 が一生 true のまま終わらない無限ループになったから
while 文の条件式には不等号（<）を使うことができないから
count を let で宣言しているためエラーになったから
while 文の中では console.log を呼び出すことができないから

- **正解**: ループの中で count の値を増やす処理（count++ など）を書いていないため、count < 3 が一生 true のまま終わらない無限ループになったから
- **解説**:
while 文は条件式が true である間、中の処理を繰り返します。このコードでは count の値が 0 のまま変化しないため、条件式 count < 3 は一生 true のままであり、無限にループが回り続けてブラウザがフリーズ（無限ループ）します。ループの中で count++ など、条件を false に変化させる処理が不可欠です。

### 第7問 【コード穴埋め：while文を使った連続重複防止ロジック】
- **問題文**:
ボタンを押すたびに名言をランダムに表示するプログラムで、「直前に表示された番号（lastIndex）と同じ番号が選ばれた場合は、違う番号が出るまで再抽選する」処理を作りたいです。コード中の /* 空欄 */ に入る適切な条件式はどれでしょうか？

```javascript
let lastIndex = -1;

btn.addEventListener('click', () => {
  let newIndex = Math.floor(Math.random() * quotes.length);

  // 直前と同じ番号である間は引き直す
  while (/* 空欄 */) {
    newIndex = Math.floor(Math.random() * quotes.length);
  }

  result.textContent = quotes[newIndex];
  lastIndex = newIndex;
});
```

- **選択肢**:
newIndex === lastIndex
newIndex !== lastIndex
newIndex < lastIndex
lastIndex === -1

- **正解**: newIndex === lastIndex
- **解説**:
while 文は「条件が true の間」繰り返します。引き直したいのは「新しく選んだ番号（newIndex）が直前の番号（lastIndex）と等しいとき」なので、条件式は newIndex === lastIndex となります。違う番号が選ばれた瞬間に条件が false になり、ループを抜けて画面更新へ進みます。

### 第8問 【推論力：配列の splice() による要素の取り出しと削除】
- **問題文**:
以下のコードを実行したとき、コンソールに表示される fruits.length の値として正しいものはどれでしょうか？

```javascript
const fruits = ['りんご', 'ばなな', 'みかん', 'ぶどう'];

const selected = fruits.splice(1, 1);

console.log(fruits.length);
```

- **選択肢**:
3
4
1
2

- **正解**: 3
- **解説**:
配列.splice(開始インデックス, 削除個数) は、指定した位置から指定した個数の要素を配列から完全に取り除きます。元の配列から 'ばなな'（インデックス 1）が 1 つ削除されるため、fruits の中身は ['りんご', 'みかん', 'ぶどう'] となり、要素数（fruits.length）は 4 から 3 に減ります。

### 第9問 【推論力：querySelectorAllと組み合わせたランダムハイライト】
- **問題文**:
画面上に並んだ複数のカード要素（.card）の中から、ランダムに選ばれた1枚だけに is-active クラスを付与して強調表示したいです。コード中の /* 空欄 */ に入る適切なコードはどれでしょうか？

```javascript
const cards = document.querySelectorAll('.card');

btn.addEventListener('click', () => {
  // 1. 全員の is-active クラスを削除してリセット
  for (let i = 0; i < cards.length; i++) {
    cards[i].classList.remove('is-active');
  }

  // 2. ランダムなインデックスを1つ生成
  const randomIndex = Math.floor(Math.random() * cards.length);

  // 3. 選ばれたカードだけに is-active を付与
  /* 空欄 */
});
```

- **選択肢**:
cards[randomIndex].classList.add('is-active');
cards.classList.add('is-active');
cards[i].classList.add('is-active');
randomIndex.classList.add('is-active');

- **正解**: cards[randomIndex].classList.add('is-active');
- **解説**:
querySelectorAll で取得したリストの中から特定の1要素を操作するには、インデックスを指定して cards[randomIndex] とアクセスします。cards（NodeList全体）に直接 classList を実行することはできません。また、i は直前の for ループの変数であるためループの外では使えず、randomIndex は単なる数値であるため classList プロパティは存在しません。

### 第10問 【コード穴埋め：ランダム背景画像のスタイル適用】
- **問題文**:
ランダムに選ばれた画像URL（imageUrls[newIndex]）を使って、ヒーローヘッダー要素（heroHeader）の背景画像を変更したいです。コード中の /* 空欄 */ に入る適切なコードはどれでしょうか？

```javascript
const imageUrls = ['scene1.jpg', 'scene2.jpg', 'scene3.jpg'];
const newIndex = Math.floor(Math.random() * imageUrls.length);

// ヒーローヘッダーの背景画像を変更する
/* 空欄 */
```

- **選択肢**:
heroHeader.style.backgroundImage = `url("${imageUrls[newIndex]}")`;
heroHeader.style.backgroundImage = imageUrls[newIndex];
heroHeader.style.backgroundColor = `url("${imageUrls[newIndex]}")`;
heroHeader.setAttribute('src', imageUrls[newIndex]);

- **正解**: heroHeader.style.backgroundImage = `url("${imageUrls[newIndex]}")`;
- **解説**:
背景画像を変更するには style.backgroundImage を使用し、値にはCSSと同じように url("画像URL") という形式の文字列を代入する必要があります。画像のURL文字列だけを直接代入したり、img タグ用の src 属性を指定しても背景画像は適用されません。
