## Step 1: JavaScriptとは？ & コンソールの体験（約15分）

### 1-1. Webサイトを構成する「3つの言語」
前期で学んだHTMLとCSSに、後期ではJavaScriptが加わります。

- **HTML**: **構造・骨組み**（見出し、段落、画像、リンクを配置する）
- **CSS**: **見た目・装飾**（色、レイアウト、余白、タイポグラフィを整える）
- **JavaScript**: **動き・振る舞い**（クリックでメニューが開く、画像が切り替わる、入力チェックをする）

> 💡 **イメージ**:
> - HTMLは「家の骨組みや壁」
> - CSSは「壁紙やインテリア、ペンキ」
> - JavaScriptは「自動ドア、照明のスイッチ、エアコンのリモコン」

### 1-2. ブラウザの開発者ツール（Console）を開いてみよう
JavaScriptの学習やエラー探しで、最も頻繁に使うのがブラウザの**「Console（コンソール）」**です。  
※コンソールは「コードを書く場所」というより、**「JavaScriptの実行結果やエラーを表示するモニター画面」**です。

- **起動方法（Google Chrome / Safari）**:
  - 画面のどこでも良いので **右クリック →「検証」**
  - またはショートカットキー:
    - **Mac**: `Command + Option + I`
    - **Windows**: `F12` または `Ctrl + Shift + I`
  - 開いたパネル上部のタブから **「Console（コンソール）」** を選択します。

## Step 2: 開発環境の準備（HTMLとJSの連携・defer属性）（約20分）

前期のHTML/CSS制作と同じように、**「VSCodeでコードを書いて保存（Cmd+S） → ブラウザで更新（Cmd+R）してコンソールで結果を見る」** という基本ワークフローを作ります。

### 2-1. フォルダとファイル構成
デスクトップ等に本日の練習用フォルダを作成し、VSCodeで開きます。

```text
lesson01/
  ├── index.html
  └── js/
       └── main.js
```

### 2-2. `index.html` の作成
以下のHTMLを作成します。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>第1回 JavaScript基礎</title>
  <!-- defer を付けることで、HTMLの読み込み完了後に安全にJSを実行する -->
  <script defer src="js/main.js"></script>
</head>
<body>
  <h1>JavaScript基礎 第1回</h1>
  <p>開発者ツールのConsole（コンソール）を開いて結果を確認してください。</p>
</body>
</html>
```

> 🛡️ **超重要：なぜ `<script defer>` なのか？**
> `defer`（ディファー）属性がないと、ブラウザはHTMLを読み終わる前にJavaScriptを実行してしまい、「まだ画面にないHTML要素を探そうとしてエラーになる」という重大なバグの原因になります。  
> **「`<script>` タグには必ず `defer` を書く」** のが現代フロントエンドの基本作法です。

## Step 3: 基本文法と変数・定数（const / let）（約35分）

これ以降のコードはすべて **`js/main.js`** に書き込んでいきます！

### 3-1. コンソールに出力する `console.log()`
`console.log()` は、指定したデータや変数の値をコンソール画面に表示する命令です。

```javascript
console.log('こんにちは');
console.log(12345);
console.log('りんご', 150, '円'); // カンマで区切ると複数同時に出力できる
```

- **セミコロン（`;`）**: 文の終わりにはセミコロンを書くのがJavaScriptの標準作法です。
- **コメント（メモ書き）**:
  - `// 1行コメント`
  - `/* 複数行コメント */`

### 3-2. 変数とは？
データ（文字列や数値など）を入れておく**「名前のついた箱」**です。

### 3-3. 現代の変数宣言: `const` と `let`
JavaScriptには変数を宣言する方法が主に2つあります。

| キーワード | 種類 | 再代入 | 使い分けのルール |
|:---:|:---:|:---:|---|
| **`const`** | **定数** | ❌ **不可** | **原則すべて `const` で書く！**（値が変わらない箱） |
| **`let`** | **変数** | ⭕ **可能** | **後から中身を上書き・変更する場合のみ使う** |

> ⚠️ **注意：`var` は使わない！**
> 昔の教科書やネットの記事では `var` という宣言が見られますが、予期せぬバグを引き起こしやすいため、現代の実務では使用しません。

### 3-4. `const`（定数）の使い方
一度値を入れたら、後から別の値を入れ直す（再代入する）ことはできません。

```javascript
const schoolName = 'トライデントコンピュータ専門学校';
console.log(schoolName);

// ❌ エラーになります（再代入禁止）
// schoolName = '別の学校'; // TypeError: Assignment to constant variable.
```

### 3-5. `let`（変数）の使い方
後から中身の値を変更（再代入）できます。※再代入するときは `let` は不要です。

```javascript
let score = 50;
console.log(score); // 50

// ⭕ 値を上書き（再代入）
score = 80;
console.log(score); // 80

score = score + 10;
console.log(score); // 90
```

### 3-6. 変数の命名ルール（キャメルケース）
- 英語で意味の通じる名前をつける（`a` や `x` などは避ける）。
- 2単語以上を繋ぐときは、2つ目の単語の頭文字を大文字にする（**キャメルケース**）。
  - ⭕ `userName`, `totalPrice`, `maxCount`
  - ❌ `username`（読みにくい）, `user_name`（スネークケース：JSでは非推奨）

## Step 4: データ型と計算の落とし穴（約25分）

### 4-1. 主な基本データ型
JavaScriptで扱うデータには「型（タイプ）」があります。

1. **文字列型（String）**:
   文字のデータ。シングルクォーテーション `'` またはダブルクォーテーション `"` で囲む。
   ```javascript
   const subject = 'JavaScript基礎';
   const studentId = '26W001'; // 数字でもクォーテーションで囲めば文字列！
   ```
2. **数値型（Number）**:
   計算ができる数値のデータ。クォーテーションで囲まない。
   ```javascript
   const price = 1200;
   const taxRate = 0.1;
   const discount = -300;
   ```
3. **真偽値型（Boolean）**:
   「正しい（`true`）」か「正しくない（`false`）」の2値のみ。次回以降の条件分岐で使います。
   ```javascript
   const isLogin = true;
   const hasError = false;
   ```

### 4-2. データの型を調べる `typeof`
データの型が何かわからなくなったときは、`typeof` 演算子を使います。

```javascript
console.log(typeof 'Hello'); // "string"
console.log(typeof 100);     // "number"
console.log(typeof true);    // "boolean"
```

### 4-3. 【超重要】初心者が必ずハマる足し算の罠！
JavaScriptの `+` 記号には、**「数値の足し算」** と **「文字列の連結」** の2つの役割があります。

```javascript
// ⭕ 数値同士の足し算
console.log(100 + 200); // 300

// ⚠️ 文字列同士の足し算（文字がつながる）
console.log('100' + '200'); // "100200"

// 🚨 最も危険！数値と文字列の足し算
console.log(100 + '200'); // "100200" （数値が自動で文字列に変換されて連結される）
```

> 💡 **ポイント**:
> 引き算（`-`）や掛け算（`*`）、割り算（`/`）は数値として計算されますが、**`+` だけは片方に文字列があると文字の連結になってしまいます**。Web制作でフォームから数値を読み取った時によく起きるバグです！

## Step 5: テンプレートリテラル（現代の文字列結合）（約20分）

### 5-1. 昔の書き方（`+` による連結）
文字列と変数を繋げるとき、昔は `+` を使ってパズルのように繋げていました。

```javascript
const userName = '山田';
const points = 120;

// 昔の書き方（クォーテーションの閉じ忘れやスペースのミスが頻発する）
console.log('こんにちは、' + userName + 'さん！ 現在のポイントは ' + points + 'pt です。');
```

### 5-2. 現代のベストプラクティス：テンプレートリテラル
文字列全体を **バッククォート（ `` ` `` ）** で囲み、変数を **`${変数名}`** で埋め込みます。

```javascript
// 現代の書き方（テンプレートリテラル）
console.log(`こんにちは、${userName}さん！ 現在のポイントは ${points}pt です。`);
```

- **バッククォートの打ち方**:
  - **Mac**: `Shift + @`
  - **Windows**: `Shift + @`（または `Shift + 7` や `Alt + 半角/全角`）
- **メリット**:
  1. `+` や `'` を何度も書く必要がなく、文章の構造が一目でわかる。
  2. `${100 * 1.1}` のように、波かっこの中で直接計算もできる。
  3. コード内で改行してもそのまま改行として扱われる。
