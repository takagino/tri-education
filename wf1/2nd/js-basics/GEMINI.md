# 講義教材（Markdown）作成・編集ルール

## 1. 文末の表記ルール
- 文の終わりに「！」（全角感嘆符）や「!」（半角感嘆符）は一切使用しないこと。
- 見出し、本文、リスト、コールアウトを含め、文末は「。」（句点）または通常の体言止め・語尾で記述すること。
- ※ プログラムコード内の構文やMarkdown構文としての記号（画像記法等）は除く。

## 2. サンプル・練習問題のCSS作成方針
- JavaScriptの学習に集中できるよう、CSSのセレクタは最小限に抑え、コード量を短く保つこと。
- ただし、ブラウザ上での十分な視認性・余白・レイアウトは担保すること。
- JavaScriptから操作・取得するIDやクラス名（`.is-active` 等）は厳密に維持すること。

## 3. Notion連携ルール
- 講義資料をNotionへ同期する際は、`scripts/sync_lecture_to_notion.py` を使用して全自動で反映すること。
- H1の先頭スペース保持（`# \ `）や余白の相殺ルールを崩さないこと。
