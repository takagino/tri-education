# **1. Web標準とマークアップ言語の基礎**

## **1-1. Web標準（Web Standards）とは**

Web技術の互換性とアクセシビリティを世界共通で担保するための規格体系と準拠メリットです。

### **【Web標準の定義と目的】**
インターネット上でWebサイトやWebアプリケーションを制作・公開する際に、世界共通で利用できるように定められた標準規格・技術仕様の総称。特定の企業による独自仕様の乱立（ブラウザ戦争）を防ぎ、どの環境でも同じように閲覧・利用できるように策定されています。

### **【Web標準に準拠するメリット】**
- **クロスブラウザ・マルチデバイス対応：** 異なるOS（Windows, Mac, iOS, Android）やブラウザ（Chrome, Safari, Edge, Firefox等）で意図通りに正しく表示・機能します。
- **アクセシビリティの向上：** スクリーンリーダーなどの支援技術が文書構造を正確に解釈できるようになります。
- **SEO効果：** 検索エンジンのクローラーが文書の意味や構造を正しく理解し、検索結果に適切に反映されます。
- **保守性と効率の向上：** HTML（構造）とCSS（デザイン）が明確に分離され、更新作業が容易になります。

---

## **1-2. マークアップ言語の系譜**

Webで使われる言語の歴史的経緯と、現在の標準仕様に至る流れです。

```
［マークアップ言語の発展系譜］
  SGML（元祖・汎用規格）
    ├── HTML（Web向けに簡略化）
    │     ├── HTML 1.0 〜 HTML 4.01
    │     └── HTML5 ──> HTML Living Standard（WHATWGが策定する現在の唯一の標準）
    └── XML（データ交換向け）
          └── XHTML（XML準拠の厳格なHTML）
```

### **【SGML（Standard Generalized Markup Language）】**
1986年にISOで標準化された、文書構造を定義するための元祖マークアップ言語。仕様が巨大で複雑だったため、Webブラウザで直接扱うには不向きでした。

### **【HTML（HyperText Markup Language）】**
ティム・バーナーズ＝リーによって考案された、ハイパーリンク機能を持つマークアップ言語。SGMLをベースにWeb向けに簡略化されました。

### **【XML（Extensible Markup Language）】**
インターネット上でのデータ交換を目的として策定された言語。タグ名を開発者が自由に独自定義できる柔軟性を持ちます。

### **【XHTML（Extensible HyperText Markup Language）】**
HTMLをXMLの文法規則に沿って再定義した厳格なマークアップ言語。小文字表記の徹底や、すべてのタグを閉じる（終了タグまたは空要素のスラッシュ `/>`）ことが義務付けられました。

### **【HTML Living Standard（現在の標準仕様）】**
Apple、Mozilla、Google、Operaの技術者らによって結成された組織「WHATWG（ワットダブルジー）」が策定する現在の標準仕様。従来の「HTML 4.01」「HTML5」のようなバージョン番号を廃止し、常に改善・更新され続ける生きた標準（Living Standard）として運用されています。2019年にW3CとWHATWGが合意し、WHATWGのHTML Living Standardが唯一の公式標準となっています。

## **1-3. CSSの標準化とCSSモジュール（CSS Snapshot）**

CSSは機能ごとの「モジュール」に分割して独立策定されており、スナップショットとして整理されています。

### **【CSSのモジュール化】**
CSSはCSS2.1以降、仕様全体を一度に改訂する方式を改め、機能ごとに独立した「モジュール」として分割して策定されています（セレクタ、フォント、カラー、ボックスモデルなど）。各モジュールは進捗に応じて個別に「Level 3」「Level 4」へと進化します。

### **【CSS Snapshot（CSSスナップショット）】**
W3CのCSSワーキンググループが定期的に発行する文書。その時点で仕様が十分に安定し、ブラウザ実装が進んでいる各モジュールの安定版コレクションを公表したものです。

# **2. HTML文書の基本構造と文法規則**

## **2-1. HTML文書の骨格と階層構造**

HTML文書は厳格な木構造（DOMツリー）を持ち、最上位のルート要素の中にhead要素とbody要素が配置されます。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>ページタイトル</title>
  </head>
  <body>
    <!-- 画面に表示されるコンテンツ -->
  </body>
</html>
```

### **【DOCTYPE宣言（文書型宣言）】**
文書の先頭に記述し、ブラウザに「この文書がHTML Living Standard仕様に準拠している」ことを宣言するコード。ブラウザが「標準モード（Standards Mode）」でレンダリングするために必須です（大文字小文字は区別されません）。

### **【`<html>` 要素（ルート要素）】**
HTML文書のすべての要素の親（最上位）にあたるルート要素。`<head>` 要素と `<body>` 要素は `<html>` 要素の直下に配置される子要素です。

### **【`<head>` 要素と主要な子要素】**
ブラウザ画面上には直接表示されない、文書のメタデータ（付加情報）を定義する要素。
- `<meta charset="UTF-8">`：文書の文字エンコーディングを指定（日本語ページではUTF-8が標準）。
- `<meta name="viewport" content="width=device-width, initial-scale=1.0">`：スマートフォン等のモバイル端末で画面幅に応じたレスポンシブ表示を行うための設定。
- `<title>`：ブラウザのタブや検索結果のタイトルとして表示される文書名。
- `<link rel="stylesheet" href="style.css">`：外部CSSファイルを読み込む要素。

### **【`<body>` 要素】**
ブラウザの画面上に実際に表示されるすべてのコンテンツ（テキスト、画像、ボタン等）を配置する要素。

---

## **2-2. グローバル属性**

すべてのHTML要素に対して共通して指定できる基本的な属性です。

- **`id` 属性：** ページ内で重複しない「一意（ユニーク）な識別名」を指定する属性。CSSのIDセレクタ（`#`）やJavaScriptの要素取得、ページ内リンクのアンカーとして用います。
- **`class` 属性：** 要素に「分類名・グループ名」を指定する属性。同一ページ内で同一のclass名を何箇所でも繰り返し使用できます。CSSのクラスセレクタ（`.`）の対象となります。
- **`style` 属性：** HTML要素内に直接インラインCSSスタイルを記述する属性。
- **`title` 属性：** 要素に関する補足情報を指定する属性。PC環境でマウスカーソルを乗せた際にツールチップとして表示されます。
- **`lang` 属性：** 要素内のテキストの言語コードを指定する属性（日本語なら `ja`、英語なら `en`）。`<html>` 要素だけでなく任意の要素に個別指定できます。
- **`tabindex` 属性：** キーボードのTabキーによるフォーカス順序を制御する属性。

---

## **2-3. コンテンツカテゴリと要素の包含ルール**

HTMLの要素は役割に応じたカテゴリに分類されており、入れ子（親子関係）の文法ルールが定められています。

### **【主要なコンテンツカテゴリ】**
- **メタデータコンテンツ（Metadata）：** 文書の付加情報を定義する要素（`<head>`, `<title>`, `<meta>`, `<link>`, `<style>`, `<script>`）。
- **フローコンテンツ（Flow）：** `<body>` 内に配置されるほぼすべての要素の包括カテゴリ。
- **セクショニングコンテンツ（Sectioning）：** 文書の章や節、明示的な構造を区切る要素（`<article>`, `<section>`, `<nav>`, `<aside>`）。
- **ヘッディングコンテンツ（Heading）：** 見出し要素（`<h1>` 〜 `<h6>`）。
- **フレージングコンテンツ（Phrasing）：** 文書内のテキストおよびテキストレベルをマークアップするインライン要素（`<span>`, `<a>`, `<strong>`, `<em>`, `<img>`, `<small>`, `<code>`, `<input>`, `<label>` 等）。

### **【重要な包含ルール（入れ子の制限）】**
- **`<p>` 要素の入れ子制限：** `<p>` 要素の内部にはフレージングコンテンツ（テキストや `<span>`, `<a>`, `<strong>` など）のみ配置できます。`<p>` の中に `<div>`, `<ul>`, `<h1>`, 別の `<p>` などのブロックレベル要素を配置することは文法違反です。
- **`<span>` 要素の内部：** `<span>` 要素の内部にはフレージングコンテンツを配置できます（HTML Living Standardでは `<a>` 要素もフレージングコンテンツに属するため、`<span>` 内に `<a>` を入れることは文法上正当です）。
- **`<a>` 要素のトランスペアレントモデル：** `<a>` 要素は「透明（Transparent）」なモデルを持ち、親要素が許容するコンテンツを内部にそのまま内包できます（複数の段落やセクション全体を `<a>` で囲むことが可能）。

# **3. セマンティックWebと主要なHTML要素**

## **3-1. セマンティック（意味論的）マークアップ**

見た目の装飾目的ではなく、情報が持つ「本来の意味・役割」に基づいて適切なHTMLタグを選択することです。

- **セマンティックの意義：** 検索エンジン（SEO）やスクリーンリーダー（音声読み上げ）がページ内の各部分の役割を正しく理解できるようになります。
- **非セマンティックなマークアップの回避：** 単に文字を太くしたいだけで `<b>` を多用したり、レイアウト目的だけで無意味に `<div>` や `<table>` を使うことを避け、意味に合致したタグを選択します。

---

## **3-2. 構造・セクションを定義する要素**

Webページ全体のレイアウトや記事構造を論理的に分割するためのセクショニング関連要素です。

- **`<main>`（メインコンテンツ）：**
  ページ内の「主要な中心コンテンツ」を表す要素。1ページにつき1つのみ配置します（他の `<article>` や `<aside>` などの内部には入れられません）。
- **`<header>`（ヘッダー）：**
  ページ全体、または各セクションの先頭にある導入部や見出し群を表す要素。同一ページ内に複数配置可能です。
- **`<footer>`（フッター）：**
  ページ全体、または各セクションの末尾にある著者情報、著作権表示、関連リンクなどを表す要素。同一ページ内に複数配置可能です。
- **`<nav>`（ナビゲーション）：**
  主要なナビゲーションリンクのグループを表す要素（グローバルナビゲーション、パンくずリスト、ページネーション等）。
- **`<article>`（独立した記事）：**
  それ単体で切り離しても内容が完結し、独立して配布・再利用可能な記事やコンテンツを表す要素（ブログ記事、ニュース記事、ユーザーコメント等）。
- **`<section>`（一般的なセクション）：**
  主題（テーマ）を持つ一般的な節・章を表す要素。原則として内部に見出し（`<h1>`〜`<h6>`）を含めることが推奨されます。
- **`<aside>`（余談・補足情報）：**
  メインコンテンツから切り離しても成立する、補足情報・余談・関連リンク・サイドバーを表す要素。

---

## **3-3. テキスト・図版・注釈のセマンティック要素**

文書内の詳細な意味や注釈を正しく表現するための要素です。

- **`<h1>` 〜 `<h6>`（見出し）：**
  文書の見出しを表す要素。数字が小さいほど上位の見出しを表し、`<h1>` から `<h6>` へ順序よく階層構造を保って使用します。
- **`<figure>` と `<figcaption>`：**
  図版、写真、コードブロックなどを独立した参照単位としてグループ化する要素が `<figure>`、そのキャプション（図の表題・説明文）を添える要素が `<figcaption>`。
- **`<blockquote>` と `<cite>`：**
  他所からのまとまった引用を表すブロック要素が `<blockquote>`、引用元の出典・著者・タイトルを表す要素が `<cite>`。
- **`<strong>` と `<b>` の違い：**
  - `<strong>`：内容が**「強い重要性・深刻さ・緊急性」**を持つことを表すセマンティック要素（ブラウザは太字で表示）。
  - `<b>`：特別な重要性を持たず、他と区別するために単に太字で際立たせたいテキストを表す要素。
- **`<em>` と `<i>` の違い：**
  - `<em>`：文脈上の**「強調（Stress Emphasis）」**を表すセマンティック要素（ブラウザは斜体で表示）。
  - `<i>`：技術用語、学名、思考の声、外国語のフレーズなど、通常の文章とトーンを区別するための斜体要素。
- **`<mark>`：**
  ユーザーの現在の操作や関心に関連して、ハイライト（蛍光ペン）表示されたテキストを表す要素。
- **`<small>`：**
  免責事項、著作権表示（コピーライト）、法的通知など、細則・注釈テキストを表す要素。
- **`<time>`：**
  日時や時刻を表す要素。`datetime` 属性を用いて機械可読な形式（例：`datetime="2026-10-10"`）で指定します。
- **`<address>`：**
  文書またはセクションの「作成者・運営者への連絡先情報（メールアドレス、所在地、電話番号等）」を表す要素。
- **`<hr>`：**
  段落レベルにおける「テーマの区切り・場面転換」を表す要素。
- **`<pre>` と `<code>`：**
  整形済みテキスト（改行や空白をそのまま表示）を表すのが `<pre>`、プログラムコードの断片を表すのが `<code>`。
- **ルビ関連要素（`<ruby>`, `<rt>`, `<rp>`）：**
  漢字等にふりがな（ルビ）を振るための要素。`<ruby>` 内に漢字と `<rt>`（ルビのテキスト）を記述し、ルビ非対応ブラウザ向けの括弧を `<rp>` で指定します。

---

## **3-4. 廃止された要素（HTML Living Standardで削除）**

現代のHTML仕様では、見た目の装飾のみを目的とした以下の古い要素は完全に廃止（Obsolete）されており、使用してはなりません（CSSで実装します）。

- `<center>`：テキストや画像を中央揃えにする（CSSの `text-align: center;` や `margin: auto;` を使用）。
- `<font>`：文字の色やサイズを指定する（CSSの `color`, `font-size` を使用）。
- `<frame>`, `<frameset>`, `<noframes>`：画面を分割して複数ページを表示する（現代は非推奨。必要時は `<iframe>` を使用）。
- `<marquee>`：文字列を横スクロール・点滅させる。
- `<big>`, `<strike>`, `<tt>`：文字装飾タグ（CSSを使用）。

---

# **4. 主要なHTMLコンポーネント（表組み・フォーム・メディア）**

## **4-1. テーブル（表組み）関連要素**

表形式の二次元データを正しくマークアップするための要素群です。

- **`<table>`：** それが「表組み（データテーブル）」であることを示す要素。
- **`<caption>`：** 表のタイトル（表題）を表す要素。`<table>` の直後（最初の要素）に配置します。
- **`<tr>`：** 表の「行（Table Row）」を定義する要素。
- **`<th>`：** 表の「見出しセル（Table Header）」を定義する要素。デフォルトで太字・中央揃えで表示されます。
- **`<td>`：** 表の「データセル（Table Data）」を定義する要素。
- **`<thead>`, `<tbody>`, `<tfoot>`：** 表のヘッダー行グループ、本体行グループ、フッター行グループを構造的にグループ化する要素。
- **セル結合の属性：**
  - `colspan="数値"`：セルを横方向（列方向）に結合。
  - `rowspan="数値"`：セルを縦方向（行方向）に結合。

---

## **4-2. フォーム関連要素と属性**

ユーザーからの入力データを受け付け、サーバーに送信するための対話型インターフェース要素です。

- **`<form>` 要素：** フォーム全体を囲む要素。`action` 属性（送信先URL）と `method` 属性（送信方式: `GET` または `POST`）を指定します。form要素の中に別のform要素を入れ子にすることはできません。
- **`<label>` 要素：** フォーム部品の項目名を関連付ける要素。`for` 属性で入力部品の `id` と紐付けるか、内部に入力部品を内包することで、ラベルをクリックした際に入力部品にフォーカスやチェックが入ります。
- **`<input>` 要素の主要な `type`：**
  - `type="text"`：1行テキスト入力欄。
  - `type="password"`：入力文字が伏せ字（●や＊）になるパスワード入力欄。
  - `type="radio"`：同一 `name` 属性のグループから1つだけ選ぶラジオボタン。
  - `type="checkbox"`：複数選択が可能なチェックボックス（`<input>` 要素はラジオボタンとチェックボックスのいずれも作成可能）。
  - `type="hidden"`：画面には表示されないが、プログラムで必要なデータをサーバーに送信する隠しフィールド。
  - `type="submit"`：フォームの入力内容を送信する送信ボタン。
  - `type="file"`：ファイル選択・アップロード。
  - HTML5追加type：`email`, `tel`, `url`, `number`, `date` 等。
- **`<select>` と `<option>`（セレクトボックス）：**
  ドロップダウン形式の選択肢を作成する要素。項目を `<option>` で並べ、`disabled` 属性を指定するとその項目を選択不可に設定できます。
- **`<textarea>`：** 複数行のテキスト入力エリアを作成する要素。
- **`<button>` 要素：** 汎用ボタン要素。`type="submit"`（送信）、`type="reset"`（リセット）、`type="button"`（JavaScript用の汎用ボタン）を指定します。内部に画像やアイコンを含めることができます。
- **`<fieldset>` と `<legend>`：** 複数の入力項目をグループ化する枠線要素が `<fieldset>`、そのグループの見出し名が `<legend>`。
- **主要な入力制御属性：**
  - `required`：必須入力項目に設定。
  - `disabled`：入力や選択を無効化（送信対象外）。
  - `readonly`：読み取り専用に設定（送信対象）。
  - `placeholder`：入力例や薄いヒント文字を表示。
  - `checked`：ラジオボタンやチェックボックスの初期選択状態。

---

## **4-3. リスト関連要素**

情報を箇条書きや一覧形式で整理するための要素です。

- **`<ul>`（Unordered List）：** 順序に意味がない「箇条書きリスト」を表す要素（行頭に記号が付く）。
- **`<ol>`（Ordered List）：** 手順やランキングなど「順序に意味があるリスト」を表す要素（行頭に番号が付く）。
- **`<li>`（List Item）：** `<ul>` または `<ol>` の直下に配置し、それが「リストの項目」であることを示す要素。
- **`<dl>`, `<dt>`, `<dd>`（記述・定義リスト）：**
  説明リスト全体を `<dl>`、用語や項目名を `<dt>`、その説明や定義内容を `<dd>` でペアにしてマークアップします。

---

## **4-4. 埋め込み・進捗・スクリプト要素**

外部リソースや動的要素をページに組み込むための要素です。

- **`<iframe>`：** 別のWebページを現在のページ内にインラインフレームとして埋め込む要素。
- **`<video>` と `<audio>`：** 動画や音声をページ内に埋め込む要素。
  - `controls` 属性：再生・一時停止・音量調節などの操作バーを表示。
  - `autoplay` 属性：自動再生（ブラウザの仕様により通常 `muted` 属性が必要）。
  - `poster` 属性：動画再生前に表示するプレビュー静止画像。
- **`<progress>` 要素：** タスクの進捗状況（進行率）を視覚的にバー形式（プログレスバー）で表示する要素。
- **`<script>` 要素：** JavaScriptなどのスクリプトを読み込み・実行する要素。1つのHTML文書内に複数の `<script>` 要素を配置・読み込むことができます。

---

# **5. CSSの基本プロパティとレイアウト設計**

## **5-1. 色・背景・フォントの指定**

画面上のテキストや背景の視覚的表現を制御するCSSの基本プロパティです。

- **前景色・文字色（`color`）：**
  テキストの前景色（文字色）を指定するプロパティ（例：`color: #ff0000;`）。
- **透明キーワード（`transparent`）：**
  CSSにおいて「完全に透明」を表すキーワード。背景や枠線、文字色を透明にする際に用います（例：`background-color: transparent;`）。
- **背景色（`background-color`）：**
  要素の背景の単色を指定するプロパティ。
- **色指定の方式：**
  - 16進数カラーコード（`#RRGGBB`）：`#000000` は「黒」、`#ffffff` は「白」。16進数の値が大きいほど明るくなります（`#eeeeee` > `#999999` > `#666666`）。
  - RGB表記（`rgb(r, g, b)`）：0〜255で光の三原色の強さを指定。
- **フォント指定（`font-family`）：**
  - `serif`：明朝体、セリフ（文字の端に飾りがある書体）。
  - `sans-serif`：ゴシック体、サンセリフ（飾りのないシンプルな書体）。
  - `monospace`：等幅フォント（プログラムコード等）。
  - `cursive`：筆記体、手書き風フォント。

---

## **5-2. ボックスモデルとサイズ計算**

すべてのHTML要素がブラウザ上で矩形（四角形）の領域として描画される構造とサイズ計算です。

```
［ボックスモデルの構造］
  +-----------------------------------+
  |              Margin               |  <- 外側の余白（透明）
  |  +-----------------------------+  |
  |  |           Border            |  |  <- 境界線（枠線）
  |  |  +-----------------------+  |  |
  |  |  |        Padding        |  |  |  <- 内側の余白
  |  |  |  +-----------------+  |  |  |
  |  |  |  |     Content     |  |  |  |  <- コンテンツ表示領域（幅・高さ）
  |  |  |  +-----------------+  |  |  |
  |  |  +-----------------------+  |  |
  |  +-----------------------------+  |
  +-----------------------------------+
```

- **構成要素：**
  - **Content：** テキストや画像が実際に表示される中心領域。
  - **Padding：** ボーダーの内側にある余白。
  - **Border：** パディングの外側を取り囲む境界線。
  - **Margin：** ボーダーの外側にある要素同士の間隔（外部余白）。
- **サイズ計算の制御（`box-sizing`）：**
  - `box-sizing: content-box;`（初期値）：指定した `width` や `height` はContent領域のみに適用され、PaddingやBorderを加算した分だけ全体のサイズが広がります。
  - `box-sizing: border-box;`：指定した `width` や `height` の中にPaddingとBorderが含まれるため、全体のレイアウト幅の計算が直感的になり崩れを防げます。

---

## **5-3. 表示形式と配置・スクロール制御**

要素の並び方や画面上での配置位置、はみ出し表示を制御するプロパティです。

- **表示形式（`display`）：**
  - `display: block;`：前後に改行が入り、横幅いっぱいに広がるブロックレベル表示。
  - `display: inline;`：テキストのように横に並び、幅や高さを指定できないインライン表示。
  - `display: inline-block;`：横に並びつつ、幅や高さ、余白を指定できる表示形式。
  - `display: flex;`：柔軟な1次元レイアウトを実現するフレックスボックス表示。
  - `display: none;`：要素を画面上から完全に非表示にし、領域も確保しない設定。
- **配置位置（`position`）：**
  - `static`（初期値）：通常の文書フローに従って配置。
  - `relative`：通常の基準位置からの相対的な移動。
  - `absolute`：直近の配置基準（`position: relative` 等が指定された祖先要素）を基準とした絶対配置。
  - `fixed`：ブラウザ画面（ビューポート）を基準に固定配置され、スクロールしても画面上の同じ位置に留まります。
  - `sticky`：通常は文書フローに従い、指定スクロール位置に達すると画面に固定されます。
- **回り込み配置（`float` と `clear`）：**
  - `float: left;` / `float: right;`：要素を左端または右端に寄せて配置し、後続のテキスト等を回り込ませます。
  - `clear: both;`：左右の回り込みを解除します。
- **はみ出しスクロール制御（`overflow`）：**
  - `overflow: visible;`（初期値）：要素の枠からはみ出してそのまま表示。
  - `overflow: hidden;`：枠からはみ出した部分を非表示（トリミング）にする。
  - `overflow: scroll;`：枠からはみ出すかどうかにかかわらず、常にスクロールバーを表示する。
  - `overflow: auto;`：コンテンツが枠からはみ出した場合のみ、必要に応じてスクロールバーを表示する。
  - `overflow-y: scroll;`：垂直方向（縦方向）に常にスクロールバーを表示してスクロール可能にする。

---

## **5-4. CSSの単位体系**

要素の寸法やフォントサイズを指定する単位は、絶対単位と相対単位に分類されます。

- **絶対単位（画面解像度や周囲の環境に依存せず固定的な物理サイズ）：**
  - `px`（ピクセル）：画面表示における基本単位。
  - `pt`（ポイント）：印刷物で標準的に用いられる単位（1pt ＝ 1/72インチ）。
  - `cm`, `mm`, `in`（センチ、ミリ、インチ）：物理的な長さの単位。
- **相対単位（他の要素や親要素、画面幅などの基準に比例して変化するサイズ）：**
  - `%`（パーセント）：親要素のサイズに対する割合。
  - `em`：親要素（または現在の要素）のフォントサイズを「1」とした相対値。
  - `rem`（Root EM）：ルート要素（`<html>`）のフォントサイズを「1」とした相対値。全体の文字サイズ連動が容易。
  - `vw`（Viewport Width）：画面幅の1%を「1」とする単位。
  - `vh`（Viewport Height）：画面高さの1%を「1」とする単位。

---

# **6. CSSの適用規則とセレクタの詳細度（Specificity）**

## **6-1. カスケードと適用の優先順位**

同一のHTML要素に複数のCSSルールが競合した場合、優先順位に従って最終的なスタイルが決定されます。

- **スタイルの記述場所による優先順位：**
  1. **インラインスタイル（HTMLタグの `style` 属性）：** 最も優先度が高い。
  2. **内部CSS（`<style>` タグ）および外部CSS（`<link>` タグ）：** 同等であり、後に読み込まれた記述が上書き優先されます。
  3. **ブラウザのデフォルトスタイル（User Agent Stylesheet）：** 最も優先度が低い。
- **特例（`!important`）：**
  プロパティ値の末尾に `!important` を付与すると、すべての詳細度や記述位置を飛び越えて最優先で適用されます。

---

## **6-2. セレクタの種類と詳細度の計算規則**

同じ記述場所内でセレクタが競合した場合、セレクタの「詳細度（点数）」が高いものが適用されます。

```
［セレクタ詳細度のウェイト体系］
  ［インラインスタイル］  style属性              ＝ 1000点
  ［A: IDセレクタ］      #main-content          ＝  100点
  ［B: クラス/疑似クラス/属性］ .menu, :hover, [type] ＝   10点
  ［C: 要素/疑似要素］    p, div, li, ::after    ＝    1点
  ［* ユニバーサル/結合子］ *, >, +, ~           ＝    0点
```

- **詳細度の比較ルール：**
  詳細度は足し算ではなく、上位桁（左側のカテゴリ）が多い方が無条件で優先されます（クラスセレクタが10個集まっても、1個のIDセレクタには勝てません）。詳細度が完全に同じ場合は、**「後から書かれた記述」**が上書き適用されます。
- **具体例での計算比較：**
  - `p` ➔ 要素1個 ＝ (0, 0, 1)
  - `.text` ➔ クラス1個 ＝ (0, 1, 0)
  - `div p.text` ➔ 要素2個 ＋ クラス1個 ＝ (0, 1, 2)
  - `#header .nav a` ➔ ID 1個 ＋ クラス1個 ＋ 要素1個 ＝ (1, 1, 1)
