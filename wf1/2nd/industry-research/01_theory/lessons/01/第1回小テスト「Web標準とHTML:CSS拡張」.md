### 【セットA 解説】
* 第1問 [正解: 2]：HTML Living Standardでは、属性値に空白や「"」「'」「=」「<」「>」などの記号が含まれていなければ、クォートを省略して <html lang=ja> と記述しても文法エラーにはならない。よって「エラーである」とする設問は誤り。
* 第2問 [正解: 1]：<p> 要素の内容モデルは「フレージングコンテンツ（旧インライン要素に相当）」に限定されている。<h2>（ヘッディング）や <div>（フロー）などのブロック要素を中に入れることは文法上禁止されている。
* 第3問 [正解: 1]：<script src="..."> タグは、1つのHTML文書内に複数行記述して、複数の外部JavaScriptライブラリやファイルを読み込むことができる。
* 第4問 [正解: 2]：<header> と <footer> はページ全体の導入・結びだけでなく、<article> や <section> などの各セクション内にも配置可能であるため、同一ページ内に複数配置できる。
* 第5問 [正解: 1]：<video> や <audio> 要素は、論理属性である controls を付与しないと、ブラウザ標準の再生バーや音量スライダー等のコントロールUIが表示されない。
* 第6問 [正解: 2]：HTML Living Standardは、従来のバージョン番号による改訂を廃止し、「常に進化し続ける1つの標準仕様」として策定・保守されている。
* 第7問 [正解: 3]：CSS3でモジュール化された仕様のうち、CSS Color Module Level 3 は2011年に早々とW3C勧告となった（検定頻出問題）。
* 第8問 [正解: 3]：<html> 要素は文書全体のルート（最上位）要素であり、<head> と <body> の親にあたる（headとbodyは兄弟関係）。
* 第9問 [正解: 4]：class や id、style、title、lang、data-* などは、すべての要素に共通して指定できる「グローバル属性」である（href や src、action は特定の要素専用の属性）。
* 第10問 [正解: 2]：セクショニングコンテンツに該当するのは article, aside, nav, section の4つのみである（header、footer、main は含まれない）。
* 第11問 [正解: 1]：比較的長い引用文をブロックとして囲むのは <blockquote>（引用元URLはcite属性）、出典や作品名を表すインライン要素は <cite> である。
* 第12問 [正解: 3]：<mark> 要素は、検索語の一致箇所など、文脈の中で参照用にハイライト表示されたテキストを表す。
* 第13問 [正解: 4]：<center> や <font>、<big>、<frame> などはHTML Living Standardで完全廃止された（<s> や <small>、<iframe> は現在も有効な要素）。
* 第14問 [正解: 2]：scope="col" はそのセルが「列（column）」の見出しであることを示し、scope="row" は「行（row）」の見出しであることを示す。
* 第15問 [正解: 2]：横方向（列）の結合は colspan（column span）、縦方向（行）の結合は rowspan である。
* 第16問 [正解: 3]：<form> 要素はJavaScript（DOM）から document.forms やイベントリスナーを通じてアクセス・操作が可能である。入れ子は禁止、内部に見出しや段落の配置は許可、タグ省略は不可。
* 第17問 [正解: 2]：単一選択は <input type="radio">。同じ name 属性を付与したグループの中で1つだけ選択できる。複数選択は checkbox。
* 第18問 [正解: 3]：<textarea> は空要素ではなく終了タグが必須。また初期値は value 属性ではなく、<textarea>初期値</textarea> のようにタグで挟んで指定する。
* 第19問 [正解: 1]：インラインフレームを作成する要素は <iframe>。スクリーンリーダー利用者が内容を判別できるよう、title 属性でフレームの概要を明記することが強く推奨される。
* 第20問 [正解: 1]：CSS宣言の末尾に !important（例: color: red !important;）を付加すると、詳細度やインライン指定を問わず最優先で適用される。
