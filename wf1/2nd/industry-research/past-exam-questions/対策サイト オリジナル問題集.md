# 対策サイト オリジナル問題集

HTMLにおいて、別のページへのハイパーリンクを作成する要素はどれか。

<link>

<a>

<href>

<nav>

**【正解】2（<a>）**

【解説】
<a>（Anchor）要素を使用し、href属性にリンク先URLを指定することでハイパーリンクを作成します。<link>は外部リソース（CSSなど）の読み込みに使用します。

CSSにおいて、要素の枠からはみ出したコンテンツを非表示にする設定はどれか。

overflow: visible;

overflow: auto;

overflow: scroll;

overflow: hidden;

**【正解】4（overflow: hidden;）**

【解説】
1. visibleははみ出して表示されます（初期値）。
2. autoは必要に応じてスクロールバーを表示します。
3. scrollは常にスクロールバーを表示します。
4. hiddenははみ出した部分を隠します。

top.html

index.html

**【正解】4（index.html）**

【解説】
1. home.html も使用できますが、デフォルトドキュメントとして設定されていないと自動的には表示されません。
2. main.html も同様です。
3. top.html も同様です。
4. 多くのウェブサーバーでは、ディレクトリにアクセスした際に最初に表示するファイル（デフォルトドキュメント）として index.html が設定されています。

次のCSSコード `.box { width: 100px; }` において、「.box」の部分の名称として正しいものはどれか。

プロパティ

デクラレーション（宣言）

バリュー（値）

セレクタ

**【正解】4（セレクタ）**

【解説】
1. プロパティ（Property）は、変更したいスタイルの種類（この例では `width`）です。
2. デクラレーションは、プロパティと値を組み合わせた `width: 100px;` の部分全体を指します。
3. バリュー（Value）は、プロパティに設定する具体的な値（この例では `100px`）です。
4. セレクタ（Selector）は、スタイルを適用する対象を指定する部分です。
