## 2. 各作業の解答・差分・採点ポイント

### 【作業 1】ディレクトリ構成およびパスの修復（配点: 20点）
`fs.jpg` の指示通りにフォルダを作成し、ファイルを移動して相対パスを修正する問題です。

#### ディレクトリ構造の正解
```
wd3/a1/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── header_logo.png
    └── top_banner.jpg
```

#### `index.html` の変更箇所（Diff）
```diff
 <head>
   <meta charset="UTF-8">
   <title>みなと市立図書館</title>
-  <link rel="stylesheet" href="style.css">
+  <link rel="stylesheet" href="css/style.css">
 </head>
 <body>
   <header>
     <div class="logo">
-      <img src="header_logo.png" alt="MINATO CITY PUBLIC LIBRARY">
+      <img src="images/header_logo.png" alt="MINATO CITY PUBLIC LIBRARY">
     </div>
   </header>
   <main>
     <div class="hero">
-      <img src="top_banner.jpg" alt="秋の読書週間 特別資料展示バナー">
+      <img src="images/top_banner.jpg" alt="秋の読書週間 特別資料展示バナー">
     </div>
```

#### 採点基準・よくある減点ミス
* **フォルダ名間違い（-10点〜-20点）**：`images` を `image` や `img` にしてしまうミス。指示画像 `fs.jpg` を必ず確認すること。
* **リンク切れ（-5点/箇所）**：パスが正しく書き換わっておらず、ブラウザで表示した際にCSSや画像が読み込まれていない。
* **不要なファイル残存（-2点）**：移動ではなくコピーをしてしまい、ルート直下にも画像が残っている状態。

### 【作業 3】コンテンツの水平中央揃え（配点: 20点）
CSSでブロック要素を中央寄せにする問題です。

#### `style.css` の変更箇所（Diff）
```diff
 #wrap {
   width: 740px;
+  margin: 0 auto;
   background-color: #ffffff;
```
※ `margin: auto;` や `margin-left: auto; margin-right: auto;` でも正解です。

#### 採点基準・よくある減点ミス
* **text-align: center を指定してしまう（-15点）**：コンテナ自体ではなく中の文字が中央寄せになってしまうミス。
* **上下中央寄せの不要なプロパティ（減点対象外または軽微減点）**：問題文に「横方向の中央であって、縦方向の中央に配置する必要はない」とあるため、余計な flex や position を使ってレイアウトを崩さないこと。

---

### 【作業 4】h1 要素の背景色・文字色変更（配点: 20点）
指定されたカラーコード（`#222222`, `#ffffff`）を正確に適用する問題です。

#### `style.css` の変更箇所（Diff）
```diff
 h1 {
+  background-color: #222222;
+  color: #ffffff;
   padding: 12px 16px;
   font-size: 22px;
   border-radius: 4px;
 }
```
※ `background: #222222;` でも可。

#### 採点基準・よくある減点ミス
* **16進数カラーコードのタイプミス（各-10点）**：桁不足や小文字/大文字の誤記など。指示通りのコード `#222222` を指定すること。
* **プロパティの取り違え（-10点）**：`color` と `background-color` を逆に設定してしまうミス。

### 【作業 5】CSSによる背景画像の適用（配点: 20点）
完成見本画像（`img.png`）を観察し、適切な画像を選択して適用する問題です。

#### `style.css` の変更箇所（Diff）
```diff
 body {
   margin: 0;
   padding: 30px 20px;
   font-family: sans-serif;
   color: #1e293b;
   background-color: #eef2ff;
+  background-image: url("img/tile_check.png");
 }

 #wrap {
   width: 560px;
   margin: 0 auto;
   background-color: #ffffff;
   border-radius: 6px;
   box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
   border: 1px solid ...;
   padding: 30px;
   box-sizing: border-box;
+  background-image: url("img/title_line.png");
+  background-repeat: repeat-x;
+  background-position: top left;
 }
```
※ショートハンド記法 `background: #ffffff url("img/title_line.png") repeat-x top;` でも可。

#### 採点基準・よくある減点ミス
* **画像の選択ミス（-10点/箇所）**：ダミー画像を選んでしまう。
* **相対パスの間違い（-10点）**：`url("tile_check.png")` のように `img/` が抜けて画像が表示されない。
* **リピート指定の不足（-3点）**：上部のバーが意図せず全体にタイル状に敷き詰められてしまう（`repeat-x` や `no-repeat` の未指定）。

### 【作業 6】文章のセマンティック構造化（配点: 20点）
プレーンテキストから適切なタグ（`h1`, `h2`, `p`, `ol`, `ul`）を選択し、もれなく適用する問題です。

#### `index.html` の `<main>` 内の正解コード
```html
  <main>
    <h1>タブレットで描く デジタルイラスト体験ワークショップ</h1>

    <h2>ワークショップの概要</h2>
    <p>液晶タブレットとペイントソフトの基本操作を学びながら、光と色彩を活かしたオリジナルイラスト作品を制作します。</p>

    <h2>制作の進め方</h2>
    <ol>
      <li>ペイントソフトの基本操作練習</li>
      <li>ラフスケッチと構図の作成</li>
      <li>ベースカラーの着彩と影つけ</li>
      <li>光のエフェクト仕上げと作品保存</li>
    </ol>

    <h2>当日ご持参いただくもの</h2>
    <ul>
      <li>参加確認メール（画面提示または印刷）</li>
      <li>作品データを持ち帰るためのUSBメモリ</li>
      <li>アイデアメモ用の筆記用具</li>
    </ul>
  </main>
```

#### 採点基準・よくある減点ミス
* **指定タグの未使用（各-5点）**：問題文に「h1, h2, p, ol, ul のすべてをもれなく使用し」とあるため、1つでも欠けると減点。
* **リストマーカーをテキストに残してしまう（-5点）**：
  * × `<li>1. ペイントソフトの基本操作練習</li>`
  * × `<li>・参加確認メール（画面提示または印刷）</li>`
  * 問題文にある「各リスト項目の文頭につくマーカーについては、ol 要素、ul 要素のデフォルトのスタイルを適用させ実現すること」に反するため、数字や「・」はテキストから削除するのが正解。
* **指定外タグの使用（-3点）**：不要な `<div>` や `<span>`、`<br>` での段落分け。

## 3. 指導・受検戦略アドバイス
1. **問題選択のセオリー（本番対策）**
   * **作業3（中央揃え）** と **作業4（文字・背景色）** は開始2分以内に完答できるボーナス問題です。本番では確実に選択するよう指導してください。
   * 次に確実なのは **作業2（ナビリンクとタイトル置換）** です。タイポさえしなければ満点が取れます。
   * 残りの2枠は、**作業5（背景画像）** と、**作業1（パス修復）** または **作業6（マークアップ）** から得意な方を選ぶのが安全です。
2. **提出フォルダ名・構造の絶対厳守**
   * 実技試験で最も多い不合格理由は「フォルダ名のタイポ」「提出先フォルダ（`wd3`）の階層ミス」です。
   * ラスト5分間はブラウザでの表示確認とフォルダ名の見直しを徹底させましょう。
