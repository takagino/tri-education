## 2. 各作業の解答・差分・採点ポイント

### 【作業 1】ディレクトリ構成およびパスの修復（配点: 20点）
`fs.jpg` の指示通りにフォルダを作成し、ファイルを移動して相対パスを修正する問題です。

#### ディレクトリ構造の正解
```
wd3/a1/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── site_logo.png
    └── keyvisual.jpg
```

#### `index.html` の変更箇所（Diff）
```diff
 <head>
   <meta charset="UTF-8">
   <title>あおぞら写真館</title>
-  <link rel="stylesheet" href="style.css">
+  <link rel="stylesheet" href="css/style.css">
 </head>
 <body>
   <header>
     <div class="logo">
-      <img src="site_logo.png" alt="AOZORA PHOTO STUDIO">
+      <img src="images/site_logo.png" alt="AOZORA PHOTO STUDIO">
     </div>
   </header>
   <main>
     <div class="hero">
-      <img src="keyvisual.jpg" alt="春の記念撮影キャンペーン キービジュアル">
+      <img src="images/keyvisual.jpg" alt="春の記念撮影キャンペーン キービジュアル">
     </div>
```

#### 採点基準・よくある減点ミス
* **フォルダ名間違い（-10点〜-20点）**：`images` を `image` や `img` にしてしまうミス。指示画像 `fs.jpg` を必ず確認すること。
* **リンク切れ（-5点/箇所）**：パスが正しく書き換わっておらず、ブラウザで表示した際にCSSや画像が読み込まれていない。
* **不要なファイル残存（-2点）**：移動ではなくコピーをしてしまい、ルート直下にも画像が残っている状態。

### 【作業 2】グローバルナビのリンク設定 ＆ テキスト置換（配点: 20点）
全4ファイルのナビゲーションリンクを張り、ダミー文字（A/B/C）を各ページのタイトルに置き換える問題です。
※本回では **`app.html`（エントリー方法）** と **`faq.html`（よくある質問）** が指定されています。

#### 各HTMLのナビゲーション（Diff）
`index.html`, `info.html`, `app.html`, `faq.html` すべてで共通：
```diff
     <nav>
       <ul>
-        <li><a href="#">TOP</a></li>
-        <li><a href="#">コンテスト概要</a></li>
-        <li><a href="#">エントリー方法</a></li>
-        <li><a href="#">よくある質問</a></li>
+        <li><a href="index.html">TOP</a></li>
+        <li><a href="info.html">コンテスト概要</a></li>
+        <li><a href="app.html">エントリー方法</a></li>
+        <li><a href="faq.html">よくある質問</a></li>
       </ul>

```

#### 各HTMLの見出し修正（Diff）
* **`info.html`**：
  ```diff
  -    <h1>A</h1>
  +    <h1>コンテスト概要</h1>
  ```
* **`app.html`**：
  ```diff

  +    <h1>エントリー方法</h1>
  ```
* **`faq.html`**：
  ```diff

  +    <h1>よくある質問</h1>
  ```

#### 採点基準・よくある減点ミス
* **リンクの更新漏れ（-3点/箇所）**：1ファイルだけ修正して他の3ファイルの修正を忘れるミス。
* **テキストのタイポ（-3点/箇所）**：タイトルと一致しない表記ゆれ。
* **cssフォルダの入れ忘れ（-5点）**：HTMLだけ `a2` に入れて `css` フォルダを入れ忘れ、スタイルが外れてしまうミス。

### 【作業 3】コンテンツの水平中央揃え（配点: 20点）
CSSでブロック要素を中央寄せにする問題です。

#### `style.css` の変更箇所（Diff）
```diff
 #wrap {
   width: 780px;
+  margin: 0 auto;
   background-color: #ffffff;
```
※ `margin: auto;` や `margin-left: auto; margin-right: auto;` でも正解です。

#### 採点基準・よくある減点ミス
* **text-align: center を指定してしまう（-15点）**：コンテナ自体ではなく中の文字が中央寄せになってしまうミス。
* **上下中央寄せの不要なプロパティ（減点対象外または軽微減点）**：問題文に「横方向の中央であって、縦方向の中央に配置する必要はない」とあるため、余計な flex や position を使ってレイアウトを崩さないこと。

### 【作業 4】h1 要素の背景色・文字色変更（配点: 20点）
指定されたカラーコード（`#bbaa77`, `#ffffff`）を正確に適用する問題です。

#### `style.css` の変更箇所（Diff）
```diff
 h1 {
+  background-color: #bbaa77;
+  color: #ffffff;
   padding: 12px 16px;
   font-size: 22px;
   border-radius: 4px;
 }
```
※ `background: #bbaa77;` でも可。

#### 採点基準・よくある減点ミス
* **16進数カラーコードのタイプミス（各-10点）**：桁不足や小文字/大文字の誤記など。指示通りのコード `#bbaa77` を指定すること。
* **プロパティの取り違え（-10点）**：`color` と `background-color` を逆に設定してしまうミス。

### 【作業 5】CSSによる背景画像の適用（配点: 20点）
完成見本画像（`img.png`）を観察し、適切な画像を選択して適用する問題です。

#### `style.css` の変更箇所（Diff）
```diff
 body {
   margin: 0;
   padding: 30px 20px;
   font-family: sans-serif;
   color: #1e293b;
   background-color: #fff8ed;
+  background-image: url("img/bg_dot.png");
 }

 #wrap {
   width: 560px;
   margin: 0 auto;
   background-color: #ffffff;
   border-radius: 6px;
   box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
   border: 1px solid ...;
   padding: 30px;
   box-sizing: border-box;
+  background-image: url("img/head_accent.png");
+  background-repeat: repeat-x;
+  background-position: top left;
 }
```
※ショートハンド記法 `background: #ffffff url("img/head_accent.png") repeat-x top;` でも可。

#### 採点基準・よくある減点ミス
* **画像の選択ミス（-10点/箇所）**：ダミー画像を選んでしまう。
* **相対パスの間違い（-10点）**：`url("bg_dot.png")` のように `img/` が抜けて画像が表示されない。
* **リピート指定の不足（-3点）**：上部のバーが意図せず全体にタイル状に敷き詰められてしまう（`repeat-x` や `no-repeat` の未指定）。

### 【作業 6】文章のセマンティック構造化（配点: 20点）
プレーンテキストから適切なタグ（`h1`, `h2`, `p`, `ol`, `ul`）を選択し、もれなく適用する問題です。

#### `index.html` の `<main>` 内の正解コード
```html
  <main>
    <h1>地域総合防災訓練・避難体験デイのご案内</h1>

    <h2>訓練の目的</h2>
    <p>災害発生時の初期対応や安全な避難経路の確認、応急手当の基本を地域住民の皆さまと実践的に確認することを目的としています。</p>

    <h2>当日の訓練プログラム</h2>
    <ol>
      <li>避難受付および班分け確認</li>
      <li>初期消火と消火器の操作体験</li>
      <li>応急手当とAEDの使用実習</li>
      <li>非常食の試食と備蓄品展示</li>
    </ol>

    <h2>参加時の服装・持ち物</h2>
    <ul>
      <li>動きやすい服装と履き慣れた運動靴</li>
      <li>飲み物（水分補給用）</li>
      <li>タオルおよび筆記用具</li>
    </ul>
  </main>
```

#### 採点基準・よくある減点ミス
* **指定タグの未使用（各-5点）**：問題文に「h1, h2, p, ol, ul のすべてをもれなく使用し」とあるため、1つでも欠けると減点。
* **リストマーカーをテキストに残してしまう（-5点）**：
  * × `<li>1. 避難受付および班分け確認</li>`
  * × `<li>・動きやすい服装と履き慣れた運動靴</li>`
  * 問題文にある「各リスト項目の文頭につくマーカーについては、ol 要素、ul 要素のデフォルトのスタイルを適用させ実現すること」に反するため、数字や「・」はテキストから削除するのが正解。
* **指定外タグの使用（-3点）**：不要な `<div>` や `<span>`、`<br>` での段落分け。
