# 実技試験 模範解答・解説・採点マニュアル

## 1. 配点と合格基準
* **配点目安**：各問 20点 × 5問選択 ＝ **100点満点**
* **合格基準**：原則として **60点以上 / 100点**（各作業ごとの足切りがある場合もあります）
* **試験時間**：60分（目安：1問あたり8〜10分、見直し10分）

---

## 2. 各作業の解答・差分・採点ポイント

### 【作業 1】ディレクトリ構成およびパスの修復（配点: 20点）
`fs.jpg` の指示通りにフォルダを作成し、ファイルを移動して相対パスを修正する問題です。

#### ディレクトリ構造の正解
```
wd3/a1/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── logo.png
    └── banner.jpg
```

#### `index.html` の変更箇所（Diff）
```diff
 <head>
   <meta charset="UTF-8">
   <title>ウェブデザインアカデミー</title>
-  <link rel="stylesheet" href="style.css">
+  <link rel="stylesheet" href="css/style.css">
 </head>
 <body>
   <header>
     <div class="logo">
-      <img src="logo.png" alt="WEB DESIGN ACADEMY">
+      <img src="images/logo.png" alt="WEB DESIGN ACADEMY">
     </div>
   </header>
   <main>
     <div class="hero">
-      <img src="banner.jpg" alt="受講生募集中 バナー">
+      <img src="images/banner.jpg" alt="受講生募集中 バナー">
     </div>
```

#### 採点基準・よくある減点ミス
* **フォルダ名間違い（-10点〜-20点）**：`images` を `image` や `img` にしてしまうミス。指示画像 `fs.jpg` を必ず確認すること。
* **リンク切れ（-5点/箇所）**：パスが正しく書き換わっておらず、ブラウザで表示した際にCSSや画像が読み込まれていない。
* **不要なファイル残存（-2点）**：移動ではなくコピーをしてしまい、ルート直下にも画像が残っている状態。

### 【作業 2】グローバルナビのリンク設定 ＆ テキスト置換（配点: 20点）
全4ファイルのナビゲーションリンクを張り、ダミー文字（A/B/C）を各ページのタイトルに置き換える問題です。

#### 各HTMLのナビゲーション（Diff）
`index.html`, `info.html`, `skilltest.html`, `form.html` すべてで共通：
```diff
     <nav>
       <ul>

-        <li><a href="#">協会情報</a></li>
-        <li><a href="#">試験概要</a></li>
-        <li><a href="#">お問い合わせ</a></li>
+        <li><a href="index.html">ホーム</a></li>
+        <li><a href="info.html">協会情報</a></li>
+        <li><a href="skilltest.html">試験概要</a></li>
+        <li><a href="form.html">お問い合わせ</a></li>
       </ul>
     </nav>
```

#### 各HTMLの見出し修正（Diff）
* **`info.html`**：
  ```diff
  -    <h1>A</h1>
  +    <h1>協会情報</h1>
  ```
* **`skilltest.html`**：
  ```diff
  -    <h1>B</h1>

  ```
* **`form.html`**：
  ```diff
  -    <h1>C</h1>

  ```

#### 採点基準・よくある減点ミス
* **リンクの更新漏れ（-3点/箇所）**：1ファイルだけ修正して他の3ファイルの修正を忘れるミス。
* **テキストのタイポ（-3点/箇所）**：「お問合せ」「問い合わせ」など、タイトルと一致しない表記ゆれ。
* **cssフォルダの入れ忘れ（-5点）**：HTMLだけ `a2` に入れて `css` フォルダを入れ忘れ、スタイルが外れてしまうミス。

### 【作業 3】コンテンツの水平中央揃え（配点: 20点）
CSSでブロック要素を中央寄せにする超頻出・秒殺ボーナス問題です。

#### `style.css` の変更箇所（Diff）
```diff
 #wrap {
   width: 800px;
+  margin: 0 auto;
   background-color: #ffffff;
```
※ `margin: auto;` や `margin-left: auto; margin-right: auto;` でも正解です。

#### 採点基準・よくある減点ミス
* **text-align: center を指定してしまう（-15点）**：コンテナ自体ではなく中の文字が中央寄せになってしまうミス。
* **上下中央寄せの不要なプロパティ（減点対象外または軽微減点）**：問題文に「横方向の中央であって、縦方向の中央に配置する必要はない」とあるため、余計な flex や position を使ってレイアウトを崩さないこと。

### 【作業 4】h1 要素の背景色・文字色変更（配点: 20点）
指定されたカラーコード（`#222222`, `#ffffff`）を正確に適用するボーナス問題です。

#### `style.css` の変更箇所（Diff）
```diff
 h1 {
+  background-color: #222222;
+  color: #ffffff;
   padding: 12px 16px;
   font-size: 22px;
 }
```
※ `background: #222222;` でも可。

#### 採点基準・よくある減点ミス
* **16進数カラーコードのタイプミス（各-10点）**：`#22222`（桁不足）や `#222`、`#fff` など。問題文で `#222222`, `#ffffff` と6桁指定されている場合は、指示通りの文字列で記述するのが安全です。
* **プロパティの取り違え（-10点）**：`color` と `background-color` を逆に設定してしまうミス。

### 【作業 5】CSSによる背景画像の適用（配点: 20点）
完成見本画像（`img.png`）を観察し、適切な画像を選択して適用する問題です。

#### `style.css` の変更箇所（Diff）
```diff
 body {
   margin: 0;
   padding: 30px 20px;
   font-family: sans-serif;
   color: #1e293b;
   background-color: #f0f4f8;
+  background-image: url("img/bg_grid.png");
 }

 #wrap {
   width: 560px;
   margin: 0 auto;
   background-color: #ffffff;
+  background-image: url("img/bg_card_top.png");
+  background-repeat: repeat-x;
+  background-position: top left;
   border-radius: 6px;
```
※ショートハンド記法 `background: #ffffff url("img/bg_card_top.png") repeat-x top;` でも可。

#### 採点基準・よくある減点ミス
* **画像の選択ミス（-10点/箇所）**：ダミー画像（ストライプやドット）を選んでしまう。
* **相対パスの間違い（-10点）**：`url("bg_grid.png")` のように `img/` が抜けて画像が表示されない。
* **リピート指定の不足（-3点）**：上部のバーが意図せず全体にタイル状に敷き詰められてしまう（`repeat-x` や `no-repeat` の未指定）。

### 【作業 6】文章のセマンティック構造化（配点: 20点）
プレーンテキストから適切なタグ（`h1`, `h2`, `p`, `ol`, `ul`）を選択し、もれなく適用する問題です。

#### `index.html` の `<main>` 内の正解コード
```html
  <main>
    <h1>ウェブデザイン技能検定 3級対策セミナー</h1>

    <h2>セミナーの概要</h2>
    <p>本セミナーでは、ウェブデザイン技能検定3級の学科および実技試験合格に向けた基礎知識と制作技術を体系的に習得します。</p>

    <h2>当日のタイムスケジュール</h2>
    <ol>
      <li>受付および資料配布</li>
      <li>学科試験の重要ポイント解説</li>
      <li>実技試験の模擬演習</li>
      <li>質疑応答とアドバイス</li>
    </ol>

    <h2>受講時の持ち物</h2>
    <ul>
      <li>筆記用具</li>
      <li>受講票</li>
      <li>本人確認書類</li>
    </ul>
  </main>
```

#### 採点基準・よくある減点ミス
* **指定タグの未使用（各-5点）**：問題文に「h1, h2, p, ol, ul のすべてをもれなく使用し」とあるため、1つでも欠けると減点。
* **リストマーカーをテキストに残してしまう（-5点）**：
  * × `<li>1. 受付および資料配布</li>`
  * × `<li>・筆記用具</li>`
  * 問題文にある「各リスト項目の文頭につくマーカーについては、ol 要素、ul 要素のデフォルトのスタイルを適用させ実現すること」に反するため、数字や「・」はテキストから削除するのが正解。
* **指定外タグの使用（-3点）**：不要な `<div>` や `<span>`、`<br>` での段落分け。

## 3. 指導・受検戦略アドバイス
1. **問題選択のセオリー**
   * **作業3（中央揃え）** と **作業4（文字・背景色）** は開始2分以内に完答できる「確実に満点が取れる問題」です。必ず選択するよう指導してください。
   * 次に確実なのは **作業2（ナビリンクとタイトル置換）** です。タイポさえしなければ満点が取れます。
   * 残りの2枠は、**作業5（背景画像）** と、**作業1（パス修復）** または **作業6（マークアップ）** から得意な方を選ぶのが安全です。
2. **提出フォルダ名・構造の絶対厳守**
   * 実技試験で最も多い不合格理由は「フォルダ名のタイポ（`a1` を `A1` や `q1` にした）」「提出先フォルダ（`wd3`）の階層ミス」です。
   * 試験終了前のラスト10分間は、ブラウザで実際に表示確認をし、ファイル名・フォルダ名を見直す時間を確保させましょう。
