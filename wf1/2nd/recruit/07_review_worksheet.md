## 🔍 パート1：提出前セルフチェック（自分で確認）
作品まとめページを提出・公開する前に、以下の項目がクリアできているか自分でチェックしよう！

### 1. 基本データ
- [ ] 作品の「メイン画像（スクリーンショット）」が一番上に貼ってあるか？
- [ ] 制作期間（実働時間）や制作形態（個人/チーム）が書かれているか？
- [ ] 使用ツール・言語が具体的に書かれているか？（例：Figma, HTML, CSS, JavaScript など）
- [ ] リンク（公開URL / GitHub / Figma）が正しく機能しているか？

### 2. なぜ作ったか？（背景・ターゲット）
- [ ] 「授業の課題だから」以外の、**ターゲット（誰向け？）** が明確に書かれているか？
- [ ] その制作物を通して**解決したかった課題**が書かれているか？

### 3. こだわり・工夫した点（最重要！）
- [ ] 単に「見やすくした」「おしゃれにした」ではなく、**「なぜその配色・レイアウト・機能にしたのか」の理由**が書かれているか？
- [ ] デザイナー志望：デザインやUIの意図が具体的に書かれているか？
- [ ] エンジニア志望：実装した機能一覧と、コード・技術のこだわりが具体的に書かれているか？

### 4. つまずいた点と解決策（企業の注目ポイント！）
- [ ] 制作中につまずいたエラーや苦労した点が具体的に書かれているか？
- [ ] それを**どうやって調べ、どうやって解決したか（自走力）** が書かれているか？

### 5. 振り返りと今後
- [ ] 今の自分から見て「ここをもっと直したい」「今後追加したい」という改善点が書かれているか？
