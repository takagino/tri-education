# 🚀 実践ガイド：Notionから各サービスへ公開する手順書

> 💡 「作品まとめ」と「自己紹介」がNotionに書けたら、いよいよ企業の採用担当者が見られる場所へ公開（デプロイ）しましょう！

---

## 📌 方法1：Notion自体を「Web公開」してポートフォリオにする（全員共通）

Notionで作ったページは、設定を1つ変えるだけで**「誰でもブラウザで見られるWebサイト」**になります。
「自己紹介トップページ」に「作品詳細ページ」をリンクさせれば、URLを1本送るだけで企業に提出可能です。

### 🌟 トップページをWebサイト風に整える2つの小ワザ

#### ① スキルを横並びにする（2列カラムレイアウト）
1. スキルの見出しの下で、半角スラッシュ `/col2` と入力してEnterを押す（自動的に左右2列の空枠が作られます）。
2. 左側の枠に「🎨 デザイン系スキル」、右側の枠に「💻 開発系スキル」のブロックをそれぞれドラッグして入れる。
3. 👉 これだけで、縦スクロールが半分に圧縮され、WebデザインのカードUIのように美しく整います！
   * 💡 **安心の自動レスポンシブ対応**：Notionは最初からスマホ対応しています。スマートフォンで閲覧された時は、自動的に**「左カラムが上、右カラムが下」の1列（縦積み）**に切り替わるので、文字が潰れたり崩れたりする心配はありません。ブラウザの横幅を狭めて確かめてみよう！

#### ② 作品詳細ページを美しくつなぐ（ギャラリービュー）
1. **トップページの「Works」の見出しの下で半角スラッシュ `/gallery` と入力**し、「ギャラリービュー - インライン」を選択する。
2. 表示されたカードを1つ開き、タイトルに作品名を入力する。
3. **【超重要】タグ（プロパティ）を設定する**
   * カード内の「プロパティを追加」から、以下の2つのタグを作ると企業が見やすくなります！
     * **「カテゴリ」**（セレクト）：`🌐 Webサイト` / `📱 UI・Webアプリ` / `🎨 グラフィック` / `✨ その他`
     * **「使用ツール」**（マルチセレクト）：`Figma` `HTML/CSS` `JavaScript` `Illustrator` `Photoshop`
4. カードの本文に、`02_template_work` で書いた作品の解説文章を丸ごとペーストする。
5. ページの先頭に「カバー画像を追加」して作品のスクリーンショットを設定する（または本文中に画像を貼る）。
6. **プロっぽく見せる表示設定（タグの表示）**
   * ギャラリー右上の「`…`」アイコン ➔ **「レイアウト」** ➔ **「カードプレビュー」** を「ページカバー」にする。
   * ギャラリー右上の「`…`」アイコン ➔ **「プロパティ」** ➔ 「カテゴリ」と「使用ツール」の目のアイコンをONにして「表示」にする。
   * 👉 これで、カードの画像の下にカラフルなタグバッジが並ぶ、Webサイト風の作品一覧が完成します！

### 🌐 Web公開の手順
1. 完成した**自己紹介トップページ**の右上にある **「共有（Share）」** をクリックする。
2. **「Web公開（Publish）」** タブを開き、**「公開（Publish to web）」** ボタンを押す。
3. **【重要】公開設定のチェック項目を確認する**
   * ❌ **「編集を許可」**：必ず**OFF**にする（他の人に書き換えられないようにするため）。
   * ❌ **「テンプレートとして複製を許可」**：企業に提出する時は**OFF**にする。
4. **「リンクをコピー」** を押し、ブラウザのシークレットウィンドウ（プライベートブラウズ）で開いてみて、ログインしなくてもトップから作品詳細まで閲覧できるか確認する。

> ⚠️ **注意**：親ページ（自己紹介トップページ）をWeb公開すると、その中に入っている子ページ（各作品ページ）も自動的に公開されます。見られたくないメモなどは同じページ内に入れないようにしましょう！

## 🎨 方法2：Webサービスに登録する（デザイナー・企画・Web志望）

Notionに書いた原稿を使って、以下のサービスに作品を登録しましょう。複数のサービスに同じ原稿をコピペして登録してもOKです！

### どのサービスを選ぶ？
| サービス名 | 特徴・こんな人におすすめ |
| :--- | :--- |
| **ViViViT** | クリエイティブ就活の王道。デザインの過程やコンセプトも含めて投稿でき、企業から直接スカウトが届く。 |
| **MATCHBOX** | マイナビクリエイター運営。「概要」「工夫した点」など項目に沿って文章を入力しやすく、Web・ゲーム・CG業界の応募時にそのまま提出できる。 |
| **ReDesigner for Student** | Web・UI/UXデザインやIT・スタートアップ企業志望に特に強い。「なぜ作ったか」の思考プロセスや言語化が最も評価される。 |

### 手順と高評価のポイント
1. **プロフィール欄を埋める**
   * `04_template_profile` で書いた自己紹介やスキルを、マイページのプロフィール欄にコピペする。
2. **「作品を投稿」から1つずつ作品を登録する**
   * **1枚目の画像（サムネイル）が命！**
     * 一覧画面では「1枚目の画像」しか見えません。ただのスクリーンショットだけでなく、できればFigma等で「作品タイトル＋キャッチコピー＋画面モックアップ」を並べた表紙画像を1枚目に設定するとクリック率が劇的に上がります。
   * **説明文はNotionからコピペ**
     * `02_template_work` で書いた「背景・目的」「工夫した点」「乗り越えた点」をそのまま貼り付けます。
3. **【超重要】タグ・使用ツールをすべて登録する**
   * 採用担当者は「`28卒` × `Figma` × `HTML`」のように**タグ検索**で学生を探します。使ったツールや言語は1つ残らず設定しましょう。

## 💻 方法3：GitHubの `README.md` を充実させる（エンジニア志望）

エンジニア採用では、採用担当者や現場のエンジニアが必ずあなたのGitHubを見に来ます。コードが置いてあるだけでなく、**「どんなアプリか」「どこを工夫したか」が書いてある `README.md`（説明書）** があると一気に評価が上がります。

### A. 各作品リポジトリの `README.md` を作る手順
1. GitHubで自分の作品のリポジトリを開く。
2. ファイル一覧の下にある **「Add a README」** ボタン（すでにある場合は `README.md` 右上の **鉛筆マーク**）をクリックする。
3. Notionの「作品まとめページ」の文章をすべて選択してコピーし、GitHubの編集画面にそのままペーストする。
   * 💡 *Notionの見出しや箇条書きは、自動的にMarkdown記法（`#` や `*`）に変換されます！*
4. **スクリーンショット画像を貼る**
   * パソコンのフォルダからスクリーンショット画像（`.png` / `.jpg` / `.gif`）を選び、**GitHubのテキスト編集画面にそのままドラッグ＆ドロップ**します。
   * 数秒待つと `![image](https://github.com/...)` というコードに変わり、画像がアップロードされます。
5. 上部の **「Preview」** タブで見た目を確認し、右上の緑のボタン **「Commit changes...」** を押して保存する。

---

### B. 【応用】GitHubのトップページに「自己紹介（Profile README）」を表示する裏ワザ
GitHubでは、**「自分のユーザーIDと全く同じ名前のリポジトリ」**を作ると、その中の `README.md` があなたのGitHubプロフィール画面のトップに大きく表示される特別な機能があります。

1. GitHub右上の「`＋`」ボタンから **「New repository」** を開く。
2. **Repository name** に、**自分のGitHubユーザーIDと全く同じ文字列**を入力する（緑色の枠で「✨ 〇〇 is a special repository...」という秘密のメッセージが出れば成功！）。
3. **「Public」** を選び、**「Add a README file」** にチェックを入れて **「Create repository」** を押す。
4. 作成された `README.md` の編集画面に、`04_template_profile` で作った自己紹介と作品リンク集をコピペして保存する！
